Connectors are used to facilitate communication between your chatbot and external APIs. They allow your chatbot to send messages to and receive responses from various services, enabling functionalities like fetching data, processing user requests, or integrating with other systems.

### Key Fields in a Connector Configuration

Here are the main fields typically found in a connector configuration:

1. **name**: A friendly name for your chatbot connector.
2. **base_url**: The base URL of the chatbot API that you want to connect to.
3. **send_message**: This section defines how to send messages to the API:
   - **path**: The specific endpoint path (appended to the base URL).
   - **method**: The HTTP method to use (e.g., POST, GET).
   - **headers**: Any custom headers required for the API request (like authorization tokens).
   - **payload_template**: The structure of the message to be sent, often including placeholders for dynamic content (e.g., user messages).
4. **response_path**: A dot-separated path used to extract the bot's reply from the JSON response received from the API.

These fields help define how your chatbot interacts with external services, ensuring that messages are sent correctly and responses are parsed appropriately. If you have more specific questions about connectors or need help with a particular configuration, feel free to ask! 😊
