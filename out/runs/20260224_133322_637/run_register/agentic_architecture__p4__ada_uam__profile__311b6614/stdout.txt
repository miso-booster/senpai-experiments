¡Hola! 😊 He revisado la documentación sobre perfiles y estoy listo para ayudarte a crear un perfil para el chatbot de la UAM que brinde soporte sobre el CAU. 

### Estructura del Perfil
Para tu perfil, necesitamos definir los siguientes elementos en el YAML:

1. **Nombre de la prueba (`test_name`)**: Un nombre descriptivo para el perfil.
2. **Modelo de lenguaje (`llm`)**: Configuración del modelo que se utilizará.
3. **Usuario (`user`)**: Definición del usuario simulado, incluyendo su idioma, rol y objetivos.
4. **Chatbot (`chatbot`)**: Especificaciones sobre cómo debe comportarse el chatbot y qué salidas debe proporcionar.
5. **Conversación (`conversation`)**: Detalles sobre cómo se desarrollará la conversación.

### Campos a Incluir
Para el soporte del CAU, los campos que deseas obtener son:
- Número de teléfono
- Correo electrónico
- Dirección física
- Horarios

### Ejemplo de Perfil
Aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "Soporte_CA_UAM"

llm:
  temperature: 0.7
  model: "gpt-4o"
  model_prov: "openai"
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca soporte del CAU de la UAM."
  context:
    - "El usuario necesita información sobre contacto y horarios del CAU."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Cuál es el correo electrónico del CAU?"
    - "¿Dónde se encuentra la dirección física del CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: true
  fallback: "Lo siento, no pude encontrar esa información."
  output:
    - telefono:
        type: string
        description: "Número de teléfono del CAU"
    - email:
        type: string
        description: "Correo electrónico del CAU"
    - direccion:
        type: string
        description: "Dirección física del CAU"
    - horarios:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - random:
      - long phrases
      - single questions
```
