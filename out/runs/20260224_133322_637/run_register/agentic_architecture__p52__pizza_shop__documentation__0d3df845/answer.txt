Connectors in SENSEI are used to integrate chatbots with external APIs without needing to write code. They allow you to define how to communicate with your chatbot's API through a YAML configuration file. Here's a breakdown of their purpose and the fields they include:

### Purpose of Connectors
- **Integration**: Connectors facilitate the connection between your chatbot and external services or APIs.
- **Configuration**: They allow you to specify how to send messages and handle responses from the API.

### Configuration Fields
Here are the key fields that you can include in a connector YAML file:

| Field                          | Description                                                       | Required          |
|--------------------------------|-------------------------------------------------------------------|-------------------|
| `name`                         | Friendly name for your chatbot                                     | No                |
| `base_url`                    | Base URL of the chatbot API                                       | Yes               |
| `send_message.path`           | API endpoint path (appended to base_url)                         | Yes               |
| `send_message.method`         | HTTP method (POST, GET, PUT, DELETE)                             | No (default: POST)|
| `send_message.headers`        | Custom headers (e.g., Authorization)                              | No                |
| `send_message.payload_template`| JSON structure with `{user_msg}` placeholder                     | Yes               |
| `response_path`               | Dot-separated path to extract the bot's reply from JSON response  | Yes               |

### Example Connector Configuration
Here's a simple example of a connector configuration:

```yaml
name: "My Custom Bot"
base_url: "https://api.mychatbot.com"
send_message:
  path: "/chat"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

### Additional Notes
- The `response_path` field is particularly important as it defines how to navigate through the JSON response to extract the bot's reply.
- You can also include authentication headers if required by the API.
