Absolutely! To ensure that your chatbot responds in the same language as the user, we can create a metamorphic rule using the `responds_in_same_language()` helper. This will check if the chatbot's responses are consistent with the user's language throughout the conversation.

Here’s a sample rule you can use:

```yaml
name: language_consistency
description: Ensure the chatbot responds in the same language as the user.
conversations: all
oracle: responds_in_same_language() is True
```

### Explanation:
- **name**: This is a unique identifier for your rule.
- **description**: A brief explanation of what the rule does.
- **conversations**: Set to `all`, meaning it will check all conversations in your dataset.
- **oracle**: This uses the `responds_in_same_language()` helper to verify that the chatbot's responses match the user's language.
