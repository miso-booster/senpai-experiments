Let's create a profile for a pizza shop where the user is rude and wants things done quickly. We'll include four goals, with two of them using pairwise functions to allow for conversation number determination via the pairwise matrix.

Here's a proposed YAML structure for the profile:

```yaml
test_name: "pizza_shop_user"

llm:
  temperature: 0.5
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a rude customer who demands fast service."
  context:
    - "You expect quick responses and are impatient."
  goals:
    - "Order a {{size}} pizza with {{toppings}}."
    - "Get the total price in {{currency}}."
    - "Ask for a delivery time."
    - "Request a discount if the order is late."
    - size:
        function: random()
        type: string
        data: [small, medium, large]
    - toppings:
        function: pairwise()
        type: string
        data: [pepperoni, mushrooms, onions, olives]
    - currency:
        function: random()
        type: string
        data: [USD, EUR, GBP]
    - extras:
        function: pairwise()
        type: string
        data: [extra cheese, garlic bread, soda]

chatbot:
  is_starter: true
  fallback: "I don't have time for this nonsense!"
  output:
    - total_price:
        type: currency
        description: "Final price of the pizza order."
    - delivery_time:
        type: string
        description: "Estimated delivery time."
    - discount:
        type: string
        description: "Discount applied if the order is late."

conversation:
  number: combinations(0.5, pairwise)
  goal_style:
    steps: 5
  interaction_style:
    - long phrases
    - make spelling mistakes
```

### Summary of the Profile:
- **User Role**: Rude customer demanding fast service.
- **Goals**: Includes ordering pizza, asking for price, delivery time, and requesting discounts.
- **Variables**: 
  - `size` (random selection from small, medium, large).
  - `toppings` (pairwise combinations of various toppings).
  - `currency` (random selection from different currencies).
  - `extras` (pairwise combinations of additional items).
- **Chatbot Output**: Captures total price, delivery time, and discount information.
- **Conversation Control**: Uses a combination of pairwise functions to determine conversation numbers.
