¡Claro! Vamos a crear un perfil para que puedas testear el chatbot de la UAM en el contexto de soporte del CAU. Aquí tienes un ejemplo de cómo podría verse tu perfil en YAML:

```yaml
test_name: "Soporte CAU - Información de Contacto"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita información sobre el CAU."
  context:
    - "Buscas obtener detalles de contacto del Centro de Atención a Usuarios."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico de contacto del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar sobre los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "¿Me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico de contacto del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

### Desglose del perfil:

- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario y el contexto de la conversación.
- **goals**: Las preguntas específicas que el usuario hará para obtener la información deseada.
- **chatbot**: Define cómo se comporta el chatbot, incluyendo el mensaje de fallback y los campos de salida que se desean extraer.
- **conversation**: Controla el número de interacciones y el estilo de interacción.

Puedes ajustar cualquier parte de este perfil según tus necesidades. ¡Espero que esto te ayude a comenzar! Si necesitas más ajustes o tienes alguna otra pregunta, no dudes en decírmelo 😊.
