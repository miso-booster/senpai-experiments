Sure! To create a rule that checks if the order ID was provided by the chatbot, you can use a simple single-conversation oracle. Here's how it would look in YAML format:

```yaml
name: order_id_provided
description: The chatbot must return an order ID.
conversations: 1
oracle: "'order_id' in data_output"
```

In this rule:

- **name**: This is the identifier for the rule, which is "order_id_provided."
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to 1, as this is a single-conversation check.
- **oracle**: This checks if the `order_id` field is present in the `data_output`.
