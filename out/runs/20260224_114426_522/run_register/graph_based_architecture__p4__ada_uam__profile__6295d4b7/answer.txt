¡Claro! Vamos a crear un perfil para que puedas testear el chatbot de la UAM y obtener la información que necesitas sobre el CAU. Aquí tienes un ejemplo de cómo podría verse el perfil en formato YAML:

```yaml
test_name: "Soporte CAU - Información de Contacto"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita obtener información de contacto del CAU."
  context:
    - "Buscas información sobre cómo contactar al Centro de Atención a Usuarios."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico de contacto del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar sobre los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "¿Puedes preguntarlo de otra forma? O, si lo prefieres, consulta nuestro catálogo de servicios."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico de contacto del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

### Explicación de cada sección:

- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje que se usará.
- **user**: Define el usuario simulado, su rol y contexto.
- **goals**: Las preguntas específicas que el usuario hará para obtener la información deseada.
- **chatbot**: Configuración del chatbot, incluyendo el mensaje de fallback y los campos de salida que se quieren extraer.
- **conversation**: Controla el número de interacciones y el estilo de interacción.

Puedes ajustar los valores según tus necesidades. ¡Espero que esto te ayude a comenzar! Si necesitas más cambios o detalles, no dudes en decírmelo 😊.
