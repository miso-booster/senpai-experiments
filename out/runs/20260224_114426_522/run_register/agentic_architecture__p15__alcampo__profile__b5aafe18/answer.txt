He cargado la documentación sobre perfiles desde el archivo `sensei-chat-guide.md`. Aquí hay algunos puntos clave que podemos usar para crear un perfil que permita al chatbot de Alcampo recomendar recetas y planificar menús:

### Estructura del Perfil
Un perfil se define en un archivo YAML y tiene varias secciones importantes:

1. **test_name**: Un nombre descriptivo para el perfil.
2. **llm**: Configuración del modelo de lenguaje (opcional).
3. **user**: Define el comportamiento del usuario simulado, incluyendo:
   - **language**: Idioma del usuario.
   - **role**: Descripción del rol del usuario.
   - **context**: Información adicional sobre el usuario.
   - **goals**: Objetivos del usuario, que pueden incluir variables para recetas y menús.
4. **chatbot**: Define cómo se comporta el chatbot, incluyendo los campos de salida que se quieren extraer.
5. **conversation**: Controla la ejecución de la conversación, como el número de interacciones y el estilo de interacción.

### Sugerencia de Perfil
Aquí tienes un ejemplo de cómo podría verse el perfil para recomendar recetas y planificar menús:

```yaml
test_name: "Alcampo Recipe Recommendation"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Eres un cliente que busca recomendaciones de recetas y planificación de menús."
  context:
    - "Te gusta la comida saludable y prefieres recetas rápidas."
  goals:
    - "Recomiéndame una receta con {{ingrediente}}."
    - "Planifica un menú para {{número_días}} días."
    - ingrediente:
        function: random()
        type: string
        data: [pollo, verduras, pescado, pasta]
    - número_días:
        function: random()
        type: int
        data:
          min: 1
          max: 7

chatbot:
  is_starter: true
  fallback: "Lo siento, no entiendo. ¿Puedes reformularlo?"
  output:
    - receta:
        type: string
        description: "La receta recomendada."
    - menú:
        type: list[string]
        description: "El menú planificado para los días solicitados."

conversation:
  number: combinations(0.5, pairwise)
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Resumen
- **Nombre del perfil**: "Alcampo Recipe Recommendation".
- **Objetivos**: Recomendar recetas y planificar menús.
- **Campos de salida**: `receta` y `menú`.
