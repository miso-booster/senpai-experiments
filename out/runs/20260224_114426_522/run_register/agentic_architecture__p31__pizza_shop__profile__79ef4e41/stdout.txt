Let's create a profile for a pizza shop that reflects a rude user who wants things done quickly. This profile will include four goals, with two variables utilizing pairwise functions for conversation number determination.

### Pizza Shop Profile YAML

Here's the YAML structure for the profile:

```yaml
test_name: "pizza_shop_rude_user"

llm:
  temperature: 0.5
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A rude customer who demands fast service."
  context:
    - "The user is impatient and expects quick responses."
  goals:
    - "Order a {{size}} pizza with {{toppings}}."
    - "Add {{drinks}} to the order."
    - "Make sure the total price is {{total_price}}."
    - "I want it ready in {{time}} minutes."
    - size:
        function: random()
        type: string
        data: [small, medium, large]
    - toppings:
        function: pairwise()
        type: string
        data: [pepperoni, mushrooms, onions, olives]
    - drinks:
        function: random()
        type: string
        data: [Coke, Sprite, Fanta]
    - total_price:
        function: forward()
        type: float
        data:
          min: 5.0
          max: 30.0
    - time:
        function: pairwise()
        type: int
        data:
          min: 10
          max: 30

chatbot:
  is_starter: false
  fallback: "What do you want? Make it quick!"
  output:
    - total_price:
        type: currency
        description: "Final price for the order"
    - order_id:
        type: string
        description: "Confirmation number for the order"
    - ready_time:
        type: time("hh:mm")
        description: "Time when the order will be ready"

conversation:
  number: combinations(0.5, pairwise) # Two pairwise functions declared
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - make spelling mistakes
```

### Summary of the Profile
- **User Role**: A rude customer who demands quick service.
- **Goals**: 
  - Ordering pizza with size and toppings.
  - Adding drinks.
  - Confirming the total price.
  - Specifying a quick preparation time.
- **Variables**: 
  - `size` and `toppings` use pairwise functions to ensure diverse combinations.
  - `time` also uses a pairwise function to determine the conversation number.
- **Chatbot Outputs**: Includes total price, order ID, and ready time.

This profile is designed to simulate a fast-paced, rude customer experience in a pizza shop setting. If you need any adjustments or additional features, feel free to ask! 🍕
