¡Claro! Para crear una regla que verifique que el chatbot ha devuelto una lista de juguetes eco-friendly, primero asegúrate de que el perfil tenga un output llamado `eco_friendly_toys`. Luego, aquí tienes un ejemplo de cómo podría ser la regla en YAML:

```yaml
name: eco_friendly_toys_check
description: Verificar que el chatbot devuelve una lista de juguetes eco-friendly
conversations: 1
oracle: eco_friendly_toys is not None and len(eco_friendly_toys) > 0
```

Esta regla comprueba que el output `eco_friendly_toys` no sea `None` y que contenga al menos un elemento en la lista. Asegúrate de ajustar el nombre del output si es necesario. ¡Espero que esto te ayude! Si necesitas algo más, no dudes en decírmelo 😊.
