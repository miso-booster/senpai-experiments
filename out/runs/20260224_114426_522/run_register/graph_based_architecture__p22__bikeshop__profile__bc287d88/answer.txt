That sounds like a great scenario to create a profile for! 😊 Let's put together a profile that captures the user's needs for customizing their new bike. Here’s a basic outline you can use, and feel free to adjust any details to better fit your testing requirements!

```yaml
test_name: "bike_setup_request"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer who recently purchased a new bike and wants to customize it."
  context:
    - "You have a new bike that you want to set up to your liking."
    - "You want to change the seat and handlebar grips."
  goals:
    - "Inquire about the options for changing the seat."
    - "Ask about the available handlebar grips."
    - "Request a quote for the customization services."
    - "Confirm if the shop can do the setup today."

chatbot:
  is_starter: false
  fallback: "I'm sorry, it's a little loud in my shop, can you say that again?"
  output:
    - seat_options:
        type: string
        description: "Information about the types of seats available for customization."
    - grip_options:
        type: string
        description: "Information about the types of handlebar grips available."
    - customization_quote:
        type: money
        description: "The estimated cost for changing the seat and handlebar grips."
    - setup_availability:
        type: string
        description: "Confirmation of whether the shop can perform the setup today."

conversation:
  number: 4
  goal_style:
    all_answered:
      export: true
      limit: 4
  interaction_style:
    - single questions
```

### Explanation of the Profile:
- **Test Name**: A clear identifier for the scenario.
- **User Role**: Describes the user's situation and needs.
- **Context**: Provides background on the user's intent.
- **Goals**: Lists specific inquiries the user will make during the conversation.
- **Chatbot Output**: Defines what the chatbot should provide in response to the user's inquiries.
- **Conversation Controls**: Sets the number of interactions and how the conversation should flow.
