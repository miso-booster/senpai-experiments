To create a metamorphic rule that checks if adding a drink costs an extra $2, we need to ensure that the rule references the appropriate output field from the profile. The output field for the drink will be named "drink," and we will compare the prices of two conversations while ensuring that the drink is included.

Here's how the metamorphic rule will look in YAML format:

```yaml
name: drink_cost_increase
description: Adding a drink costs an extra $2 (same size and toppings)
conversations: 2
when: conv[0].size == conv[1].size and conv[0].toppings == conv[1].toppings
if: conv[0].drink is not None and conv[1].drink is not None
then: extract_float(conv[0].price) == extract_float(conv[1].price) + 2
```

### Explanation:
- **name**: The rule is named `drink_cost_increase`.
- **description**: This describes what the rule checks for.
- **conversations**: Set to 2, as we need to compare two conversations.
- **when**: This condition ensures that the size and toppings are the same for both conversations.
- **if**: This checks that both conversations have a drink.
- **then**: This asserts that the price of the first conversation should be $2 more than the price of the second conversation.
