### Connector Structure

Here’s how the connector will be structured based on the request:

- **name**: A friendly name for your connector.
- **base_url**: The base URL of the API.
- **send_message**: This will include the path, method, headers, and payload template.
- **response_path**: This will specify how to extract the bot's reply from the JSON response.

### YAML Connector

Here’s the YAML configuration for your connector:

```yaml
name: "Alcampo Bot Connector"
base_url: "https://alcampo.botslovers.com/bot/web"
send_message:
  path: "/bot/web"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Accept: "*/*"
    Accept-Language: "en-US,en;q=0.9"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
  payload_template:
    data:
      id_user: "{id_user}"
      idweb_user: "{idweb_user}"
      session: "{session}"
      message:
        message:
          message:
            text: "{user_msg}"
        iduser: "{id_user}"
        session: "{session}"
        channel: "web"
      widget_form: "TRUE"
      contexto_extra: []
      lang: "es"
      accion: "response_bot"
response_path: "messages.0.message.text"
```

### Explanation

- **name**: "Alcampo Bot Connector" is a friendly name for the connector.
- **base_url**: The base URL is set to the endpoint provided in your request.
- **send_message**:
  - **path**: The path to send the POST request.
  - **method**: Set to POST as per your request.
  - **headers**: Includes necessary headers from your request.
  - **payload_template**: This is structured to match the request format you provided, using placeholders like `{id_user}`, `{idweb_user}`, `{session}`, and `{user_msg}` for dynamic data.
- **response_path**: This specifies how to extract the response text from the JSON response.
