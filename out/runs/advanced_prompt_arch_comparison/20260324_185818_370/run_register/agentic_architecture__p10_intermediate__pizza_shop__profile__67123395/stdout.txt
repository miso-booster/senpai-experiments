Here are the details for the connectors using **1millionbot** and a comparison with a non-1millionbot connector:

### 1millionbot Connectors

1. **Ada UAM**
   - **Base URL**: `https://api.1millionbot.com`
   - **Send Message Endpoint**:
     - **Path**: `/api/public/messages`
     - **Method**: `POST`
     - **Headers**:
       - `Content-Type`: `application/json`
       - `Authorization`: `60a3bee2e3987316fed3218f`
     - **Payload Template**:
       ```json
       {
         "conversation": "682ce1ce271ce860cffde0fd",
         "sender_type": "User",
         "sender": "682ce1cefe831160cee700ed",
         "bot": "60a3be81f9a6b98f7659a6f9",
         "language": "es",
         "url": "https://www.uam.es/uam/tecnologias-informacion/servicios-ti/acceso-remoto-red",
         "message": {
           "text": "{user_msg}"
         }
       }
       ```
   - **Response Path**: `response.0.text`

### Non-1millionbot Connector

2. **Postman Echo**
   - **Base URL**: `https://postman-echo.com`
   - **Send Message Endpoint**:
     - **Path**: `/post`
     - **Method**: `POST`
     - **Payload Template**:
       ```json
       {
         "message": "{user_msg}"
       }
       ```
   - **Response Path**: `json.message`

### Comparison of Differences

- **Base URL**:
  - **Ada UAM**: `https://api.1millionbot.com`
  - **Postman Echo**: `https://postman-echo.com`
  
- **Endpoint Path**:
  - **Ada UAM**: `/api/public/messages`
  - **Postman Echo**: `/post`
  
- **Headers**:
  - **Ada UAM**: Requires `Content-Type` and `Authorization`.
  - **Postman Echo**: No specific headers are required.

- **Payload Structure**:
  - **Ada UAM**: More complex structure with multiple fields including `conversation`, `sender_type`, `sender`, `bot`, `language`, `url`, and a nested `message` object.
  - **Postman Echo**: Simple structure with a single `message` field.

- **Response Path**:
  - **Ada UAM**: `response.0.text`
  - **Postman Echo**: `json.message`

### Summary
The **1millionbot** connector (Ada UAM) has a more complex payload structure and requires authorization, while the non-1millionbot connector (Postman Echo) is simpler and does not require specific headers.
