### Steps to Conduct a Coverage Audit

1. **List All Profiles and Their Outputs**:
   - Review each profile in your `profiles/` directory.
   - Note down the `chatbot.output` fields for each profile.

2. **List All Rules**:
   - Go through the rules in your `rules/` directory.
   - Identify the conditions and what outputs they are validating.

3. **Map Rules to Profile Outputs**:
   - Create a table or a mapping document where you list each profile output and the corresponding rules that validate them.
   - For example:
     ```
     | Profile Output          | Validating Rules                        |
     |-------------------------|----------------------------------------|
     | available_information    | only_talks_about_pizza                |
     | opening_hours           | (No rules validating this output)      |
     | total_cost              | more_toppings_cost_more                |
     ```

4. **Identify Gaps**:
   - Look for profile outputs that do not have any associated rules. These are your gaps.
   - Consider the business logic and user interactions to determine what additional rules might be necessary to cover those outputs.

5. **Create New Rules**:
   - For any identified gaps, draft new rules that validate the missing outputs.
   - Ensure they follow the best practices for writing rules, as outlined in the documentation.
