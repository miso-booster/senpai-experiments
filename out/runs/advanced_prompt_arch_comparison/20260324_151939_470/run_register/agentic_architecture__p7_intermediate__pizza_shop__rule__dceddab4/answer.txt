### Rule Overview
The rule **"same_number_of_toppings_cost_the_same"** checks that pizzas with the same number of toppings cost the same. Here's how it works:

- **When**: It compares two conversations (like two orders).
- **If**: The size of the pizzas is the same, and the number of toppings is the same.
- **Then**: It checks if the prices of both pizzas are equal.

### Required Fields
This rule needs the following fields:
- `conv[0].size` (size of the first pizza)
- `conv[1].size` (size of the second pizza)
- `len(conv[0].toppings)` (number of toppings on the first pizza)
- `len(conv[1].toppings)` (number of toppings on the second pizza)
- `extract_float(conv[0].price)` (price of the first pizza)
- `extract_float(conv[1].price)` (price of the second pizza)

### Explanation Like You're 5
Imagine you have two boxes of pizza, and you want to see if they cost the same. You check:
- Are they the same size? (like big or small)
- Do they have the same number of toppings? (like cheese, pepperoni, etc.)

If both pizzas are the same size and have the same number of toppings, then they should cost the same! If one is more expensive, that's not fair, right? This rule helps us check that! 🍕✨
