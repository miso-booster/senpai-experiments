### Step 1: List All Profiles and Their Outputs
Start by reviewing each profile in your project. For each profile, note down the outputs defined in the `chatbot.output` section. Here’s a quick example of what to look for:

- **Profile Name:** `pizza_and_drink_order_placement`
  - **Outputs:**
    - `pizza_options`
    - `drink_options`
    - `order_summary`
    - `total_cost`
    - `estimated_readiness_time`
    - `pickup_location`
    - `order_id`

### Step 2: List All Rules and Their Conditions
Next, go through each rule in your project and document what each rule checks. For example:

- **Rule Name:** `more_toppings_cost_more`
  - **Checks:** 
    - Compares the number of toppings between two conversations.
    - Validates that the price of the pizza increases with more toppings.

### Step 3: Map Rules to Profile Outputs
Create a mapping between the rules and the profile outputs they validate. This will help you see which outputs are covered by which rules. You can create a simple table or a spreadsheet for this.

| Profile Output                     | Rule Name                        | Description of Validation                                   |
|------------------------------------|----------------------------------|-----------------------------------------------------------|
| `total_cost`                       | `more_toppings_cost_more`       | Ensures price increases with more toppings.               |
| `order_summary`                    | `only_talks_about_pizzas`       | Confirms the order summary is relevant to pizza orders.   |
| `estimated_readiness_time`         | `ordering_conversation_turns`    | Validates that the assistant confirms order readiness.     |
| `order_id`                         | `same_number_of_toppings_cost_the_same` | Checks if order IDs are unique.                      |

### Step 4: Identify Gaps in Testing
After mapping, look for any outputs that do not have corresponding rules. For example, if you find that `pickup_location` is not covered by any rules, that’s a gap you might want to address.

### Step 5: Create New Rules for Gaps
For each identified gap, brainstorm what kind of rules could validate those outputs. For instance:

- **Output:** `pickup_location`
  - **Proposed Rule:** Ensure that the pickup location is mentioned in the order confirmation.

### Step 6: Review and Prioritize
Once you have a list of new rules to create, prioritize them based on their importance to the functionality of your chatbot and the user experience.

### Step 7: Implement and Test
Finally, implement the new rules and run your tests to ensure everything is working as expected.
