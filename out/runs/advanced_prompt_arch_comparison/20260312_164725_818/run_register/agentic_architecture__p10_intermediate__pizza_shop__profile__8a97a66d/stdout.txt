Here's a comparison of the connectors that use **1millionbot** against a **non-1millionbot** connector:

### 1millionbot Connectors

1. **Ada UAM**
   - **Base URL:** `https://api.1millionbot.com`
   - **Send Message Endpoint:**
     - **Path:** `/api/public/messages`
     - **Method:** `POST`
     - **Headers:**
       - `Content-Type: application/json`
       - `Authorization: 60a3bee2e3987316fed3218f`
     - **Payload Template:**
       ```json
       {
         "conversation": "682ce1ce271ce860cffde0fd",
         "sender_type": "User",
         "sender": "682ce1cefe831160cee700ed",
         "bot": "60a3be81f9a6b98f7659a6f9",
         "language": "es",
         "url": "https://www.uam.es/uam/tecnologias-informacion/servicios-ti/acceso-remoto-red",
         "message": {
           "text": "{user_msg}"
         }
       }
       ```
   - **Response Path:** `response.0.text`

### Non-1millionbot Connector

2. **Postman Echo**
   - **Base URL:** `https://postman-echo.com`
   - **Send Message Endpoint:**
     - **Path:** `/post`
     - **Method:** `POST`
     - **Payload Template:**
       ```json
       {
         "message": "{user_msg}"
       }
       ```
   - **Response Path:** `json.message`

### Differences

- **Base URL:**
  - **Ada UAM:** Uses a specific 1millionbot API URL.
  - **Postman Echo:** Uses a generic echo service URL.

- **Send Message Endpoint:**
  - **Ada UAM:** Has a specific path for sending messages related to 1millionbot.
  - **Postman Echo:** Uses a simple echo path.

- **Headers:**
  - **Ada UAM:** Requires specific headers including `Content-Type` and `Authorization`.
  - **Postman Echo:** Does not require any special headers.

- **Payload Structure:**
  - **Ada UAM:** Has a more complex payload structure with multiple fields including `conversation`, `sender`, `bot`, and `url`.
  - **Postman Echo:** Has a simpler payload with just a `message` field.

- **Response Path:**
  - **Ada UAM:** Extracts the response from `response.0.text`.
  - **Postman Echo:** Extracts the response from `json.message`.

### Summary
The **1millionbot** connector (Ada UAM) is designed for specific interactions with the 1millionbot API, requiring detailed payloads and authorization, while the **Postman Echo** connector serves a more generic purpose with a simpler structure and no authentication requirements.
