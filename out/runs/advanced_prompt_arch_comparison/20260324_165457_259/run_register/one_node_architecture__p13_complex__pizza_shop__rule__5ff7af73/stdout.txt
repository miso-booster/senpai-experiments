### Step-by-Step Approach for Coverage Audit

1. **List All Profiles and Their Outputs**:
   - Identify the key outputs defined in each profile's `chatbot.output`. This will help you understand what each profile is designed to validate.

2. **List All Rules**:
   - Review each rule and note the conditions and outputs they validate. Pay special attention to the `when`, `if`, and `then` statements to see which profile outputs they reference.

3. **Map Rules to Profile Outputs**:
   - Create a mapping table that connects each rule to the profile outputs it validates. This will help you visualize which outputs are currently being tested.

4. **Identify Gaps**:
   - Look for profile outputs that are not referenced in any rules. These are your gaps in testing. Consider whether these outputs are important for the functionality of your chatbot.

5. **Review Rule Logic**:
   - Ensure that the logic in the rules is sound and that they are effectively validating the outputs as intended. Check for any potential overlaps or redundancies in rules.
