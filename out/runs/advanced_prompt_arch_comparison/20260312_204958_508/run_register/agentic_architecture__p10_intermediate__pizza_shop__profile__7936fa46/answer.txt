- **Base URL:**

- **Send Message Endpoint:**

  - **Non-1millionbot:** Uses a simpler path (`/post`) without any special headers.

- **Headers:**
  - **1millionbot:** Requires `Content-Type` and `Authorization` headers.
  - **Non-1millionbot:** Does not require any headers.

- **Payload Structure:**
  - **1millionbot:** Has a complex payload including fields like `conversation`, `sender_type`, `sender`, `bot`, `language`, `url`, and a structured message.
  - **Non-1millionbot:** Uses a much simpler payload structure with just a `message` field.

- **Response Path:**
  - **1millionbot:** Extracts the response from `response.0.text`.
  - **Non-1millionbot:** Extracts the response from `json.message`.
