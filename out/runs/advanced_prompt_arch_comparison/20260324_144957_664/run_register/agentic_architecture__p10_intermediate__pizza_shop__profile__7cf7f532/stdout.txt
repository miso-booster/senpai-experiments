Here are the details of the connectors that use **1millionbot** and one non-1millionbot connector:

### 1millionbot Connectors

1. **Ada UAM**
   - **Base URL:** `https://api.1millionbot.com`
   - **Send Message Endpoint:**
     - **Path:** `/api/public/messages`
     - **Method:** `POST`
     - **Headers:**
       - `Content-Type: application/json`
       - `Authorization: 60a3bee2e3987316fed3218f`
     - **Payload Template:**
       ```json
       {
         "conversation": "682ce1ce271ce860cffde0fd",
         "sender_type": "User",
         "sender": "682ce1cefe831160cee700ed",
         "bot": "60a3be81f9a6b98f7659a6f9",
         "language": "es",
         "url": "https://www.uam.es/uam/tecnologias-informacion/servicios-ti/acceso-remoto-red",
         "message": {
           "text": "{user_msg}"
         }
       }
       ```
   - **Response Path:** `response.0.text`

### Non-1millionbot Connector

2. **Echo Bot**
   - **Base URL:** `https://postman-echo.com`
   - **Send Message Endpoint:**
     - **Path:** `/post`
     - **Method:** `POST`
     - **Payload Template:**
       ```json
       {
         "message": "{user_msg}"
       }
       ```
   - **Response Path:** `json.message`

### Differences

- **Base URL:**
  - **Ada UAM:** Uses `https://api.1millionbot.com`
  - **Echo Bot:** Uses `https://postman-echo.com`

- **Send Message Endpoint:**
  - **Ada UAM:** 
    - Path: `/api/public/messages`
    - Requires specific headers including `Authorization`.
    - Payload includes additional fields like `conversation`, `sender_type`, `sender`, `bot`, and `url`.
  - **Echo Bot:** 
    - Path: `/post`
    - No specific headers required.
    - Payload is simpler, containing only the `message` field.

- **Response Path:**
  - **Ada UAM:** `response.0.text`
  - **Echo Bot:** `json.message`

### Summary
The **Ada UAM** connector is specifically designed for the **1millionbot** API, featuring a more complex payload and additional headers, while the **Echo Bot** connector is simpler and does not require authentication or specific headers. This highlights the differences in complexity and requirements between the two types of connectors.
