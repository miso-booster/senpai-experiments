### Rule Overview: Topping Price Consistency

The rule **"same_number_of_toppings_cost_the_same"** checks if pizzas with the same number of toppings cost the same. Here's how it works:

- **When**: It compares two conversations (like two orders).
- **If**: Both orders have the same drink and the same pizza size, and they have the same number of toppings.
- **Then**: It checks if the prices of both pizzas are the same.

### Explanation Like You’re 5

Imagine you and your friend are ordering pizzas. You both want the same size pizza and the same number of toppings, like pepperoni and cheese. This rule is like a game that checks if your pizzas cost the same. If you both ordered a pizza with 2 toppings, and yours costs $10 and your friend's also costs $10, then the game says, "Yay! You both paid the same!" But if one pizza costs $10 and the other costs $12, the game would say, "Oh no! That's not right!" 

So, this rule helps make sure that if you and your friend order the same kind of pizza, you should pay the same amount! 🍕✨
