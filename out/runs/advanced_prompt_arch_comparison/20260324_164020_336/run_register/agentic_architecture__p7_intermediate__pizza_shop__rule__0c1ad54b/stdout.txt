### Rule Overview
The rule **"same_number_of_toppings_cost_the_same"** checks that pizzas with the same number of toppings and the same size cost the same. Here’s a simple breakdown:

- **When**: The drinks are the same for both orders.
- **If**: The sizes are the same and the number of toppings is the same.
- **Then**: The prices should be equal.
