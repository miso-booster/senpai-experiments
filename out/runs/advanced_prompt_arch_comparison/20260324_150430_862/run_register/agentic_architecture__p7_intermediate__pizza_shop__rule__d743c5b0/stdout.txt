### Rule Overview
The rule **"same_number_of_toppings_cost_the_same"** checks that pizzas with the same number of toppings cost the same. Here's how it works:

- **When**: It compares two conversations (orders).
- **If**: The drinks are the same, the sizes are the same, and the number of toppings is the same.
- **Then**: It checks if the prices of both pizzas are equal.
