### Differences

- **Base URL:**
  - **1millionbot:** Uses `https://api.1millionbot.com`
  - **Non-1millionbot:** Uses `https://postman-echo.com`

- **Send Message Endpoint:**
  - **1millionbot:** Has a specific path `/api/public/messages` with additional headers and a complex payload structure.
  - **Non-1millionbot:** Uses a simple path `/post` with a straightforward payload.

- **Headers:**
  - **1millionbot:** Requires specific headers including `Content-Type` and `Authorization`.
  - **Non-1millionbot:** Does not require any headers.

- **Payload Structure:**
  - **1millionbot:** Includes multiple fields such as `conversation`, `sender_type`, `sender`, `bot`, `language`, `url`, and `message.text`.
  - **Non-1millionbot:** Only includes a single field for the message.

- **Response Path:**
  - **1millionbot:** Extracts the response from `response.0.text`.
  - **Non-1millionbot:** Extracts the response from `json.message`.

### Summary
The **1millionbot** connectors are more complex, requiring specific headers and a detailed payload structure, while the non-1millionbot connector (Echo Bot) is simpler and more straightforward.
