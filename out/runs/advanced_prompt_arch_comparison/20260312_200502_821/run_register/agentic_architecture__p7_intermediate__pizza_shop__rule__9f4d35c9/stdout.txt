### Rule Overview
The rule **"same_number_of_toppings_cost_the_same"** checks that pizzas with the same number of toppings cost the same. Here’s how it works:

- **Condition**: It compares two conversations (like two orders).
- **Checks**:
  - If both orders have the same drink.
  - If both orders are the same size.
  - If both orders have the same number of toppings.
- **Action**: If all these conditions are true, it checks if the prices of both orders are equal.
