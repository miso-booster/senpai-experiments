Here are the connectors that utilize **1millionbot** and their endpoints, along with a comparison to a non-1millionbot connector:

### 1millionbot Connectors

1. **Ada UAM**
   - **Base URL:** `https://api.1millionbot.com`
   - **Send Message Endpoint:**
     - **Path:** `/api/public/messages`
     - **Method:** `POST`
     - **Headers:**
       - `Content-Type: application/json`
       - `Authorization: 60a3bee2e3987316fed3218f`
     - **Payload Template:**
       ```json
       {
         "conversation": "682ce1ce271ce860cffde0fd",
         "sender_type": "User",
         "sender": "682ce1cefe831160cee700ed",
         "bot": "60a3be81f9a6b98f7659a6f9",
         "language": "es",
         "url": "https://www.uam.es/uam/tecnologias-informacion/servicios-ti/acceso-remoto-red",
         "message": {
           "text": "{user_msg}"
         }
       }
       ```
   - **Response Path:** `response.0.text`

### Non-1millionbot Connector

2. **Postman Echo**
   - **Base URL:** `https://postman-echo.com`
   - **Send Message Endpoint:**
     - **Path:** `/post`
     - **Method:** `POST`
     - **Payload Template:**
       ```json
       {
         "message": "{user_msg}"
       }
       ```
   - **Response Path:** `json.message`

### Comparison and Differences

- **Base URL:**
  - **1millionbot:** Uses `https://api.1millionbot.com`
  - **Non-1millionbot:** Uses `https://postman-echo.com`

- **Send Message Endpoint:**
  - **1millionbot:** 
    - Path: `/api/public/messages`
    - Requires specific headers including `Authorization`.
    - Payload is more complex, including conversation ID, sender details, and language.
  - **Non-1millionbot:** 
    - Path: `/post`
    - No special headers required.
    - Simpler payload with just a message field.

- **Response Path:**
  - **1millionbot:** `response.0.text`
  - **Non-1millionbot:** `json.message`

### Summary
The **1millionbot** connector (Ada UAM) has a more complex structure with specific authorization requirements and a detailed payload, while the **Postman Echo** connector is simpler, requiring no special headers and having a straightforward payload. This highlights the differences in complexity and requirements between the two types of connectors.
