The connector that uses the 1millionbot API is:

- **Ada UAM**: 
  - Base URL: `https://api.1millionbot.com`
  - Response Path: `response.0.text`
  - Send Message Configuration includes headers for `Authorization` and `Content-Type`, and a payload template that includes the message structure.

If you need more details about this connector or how to use it, feel free to ask! 😊
