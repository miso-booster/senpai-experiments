### Rule Name: Same Number of Toppings Cost the Same

**What it means:**
- If you have two pizzas, and they both have the same number of toppings, they should cost the same amount of money. 

**How it works:**
1. **Two Pizzas:** We look at two pizzas that people are talking about.
2. **Same Drink:** First, we check if both pizzas come with the same drink. If they do, we move to the next step.
3. **Same Size and Toppings:** Next, we check if both pizzas are the same size (like small, medium, or large) and if they have the same number of toppings (like pepperoni, cheese, or veggies).
4. **Price Check:** Finally, if both pizzas are the same size and have the same number of toppings, we say their prices should be the same.

So, if you order a pizza with 3 toppings and it costs $10, another pizza with 3 toppings should also cost $10! 🍕✨

This rule helps make sure that pizza prices are fair and consistent!
