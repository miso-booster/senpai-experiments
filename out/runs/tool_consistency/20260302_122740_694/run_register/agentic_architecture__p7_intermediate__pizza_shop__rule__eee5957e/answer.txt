I found the rule about topping price consistency! Here’s a simple explanation:

### Rule: Same Number of Toppings Cost the Same 🍕💰

- **What it says**: If two pizzas have the same number of toppings and are the same size, they should cost the same amount of money.
  
- **How it works**:
  - **When**: We look at two pizza orders.
  - **If**: Both pizzas are the same size and have the same number of toppings.
  - **Then**: Their prices should be the same!

### Imagine This:
Think of it like this: If you have two toy boxes, and both have 3 toys inside, they should be the same price when you buy them. If one box costs more, that's not fair! So, this rule makes sure that pizzas with the same number of toppings are treated the same way. 😊
