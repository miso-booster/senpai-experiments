Let's check if the **pizza order test custom** profile will work with the rules **more toppings cost more** and **same number of toppings cost the same**.

### Profile Overview
The profile `pizza_order_test_custom.yml` has the following relevant `chatbot.output` fields:
- **price**: The final price of the pizza order (type: currency)
- **time**: Just the opening time (type: time)
- **order_id**: My order ID (type: string)

### Rule Details

1. **More Toppings Cost More**
   ```yaml
   name: more_toppings_cost_more
   description: Adding more toppings to a custom pizza cost more
   active: True
   conversations: 2
   when: conv[0].size == conv[1].size and conv[0].drink == conv[1].drink
   if:   len(conv[0].toppings) > len(conv[1].toppings)
   then: extract_float(conv[0].price) > extract_float(conv[1].price)
   ```
   - **Purpose**: This rule checks that if two pizzas have the same size and drink, the one with more toppings should cost more.
   - **Compatibility**: This rule is **active** and uses the `price` field from the profile, which is compatible.

2. **Same Number of Toppings Cost the Same**
   ```yaml
   name: same_number_of_toppings_cost_the_same
   description: Pizzas with same number of toppings cost the same
   conversations: 2
   active: False
   when: conv[0].drink == conv[1].drink
   if: conv[0].size == conv[1].size and len(conv[0].toppings)==len(conv[1].toppings)
   then: extract_float(conv[0].price) == extract_float(conv[1].price)
   ```
   - **Purpose**: This rule checks that if two pizzas have the same size and the same number of toppings, they should cost the same.
   - **Compatibility**: This rule is **inactive**, so it won't be executed. However, it also uses the `price` field from the profile, which is compatible.

### Conclusion
- The **more toppings cost more** rule will work with the **pizza_order_test_custom** profile as it actively checks the price based on the number of toppings.
- The **same number of toppings cost the same** rule is currently inactive, so it won't affect the testing process unless activated.
