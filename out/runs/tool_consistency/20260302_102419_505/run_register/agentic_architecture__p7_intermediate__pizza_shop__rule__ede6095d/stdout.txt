### Rule: Same Number of Toppings Cost the Same 🍕💰

- **What it says:** If two pizzas have the same number of toppings and are the same size, they should cost the same amount of money.
  
- **How it works:**
  - It checks if both pizzas have the same drink (like soda).
  - Then, it looks at the size of the pizzas (like small, medium, or large).
  - Finally, it counts how many toppings each pizza has.
  - If everything matches (same size and same number of toppings), it makes sure that the prices are the same.

So, if you order two medium pizzas with 3 toppings each, they should cost the same! 🎉
