Here are the details of the connectors that use **1millionbot** and their endpoints, along with a comparison against a non-1millionbot connector:

### 1millionbot Connectors

1. **Ada UAM**
   - **Base URL:** `https://api.1millionbot.com`
   - **Send Message Endpoint:**
     - **Path:** `/api/public/messages`
     - **Method:** `POST`
     - **Headers:**
       - `Content-Type: application/json`
       - `Authorization: 60a3bee2e3987316fed3218f`
     - **Payload Template:**
       ```json
       {
         "conversation": "682ce1ce271ce860cffde0fd",
         "sender_type": "User",
         "sender": "682ce1cefe831160cee700ed",
         "bot": "60a3be81f9a6b98f7659a6f9",
         "language": "es",
         "url": "https://www.uam.es/uam/tecnologias-informacion/servicios-ti/acceso-remoto-red",
         "message": {
           "text": "{user_msg}"
         }
       }
       ```
   - **Response Path:** `response.0.text`

### Non-1millionbot Connector

2. **Postman Echo**
   - **Base URL:** `https://postman-echo.com`
   - **Send Message Endpoint:**
     - **Path:** `/post`
     - **Method:** `POST`
     - **Payload Template:**
       ```json
       {
         "message": "{user_msg}"
       }
       ```
   - **Response Path:** `json.message`

### Comparison of Differences

| Feature               | Ada UAM (1millionbot)                                      | Postman Echo (Non-1millionbot)                |
|-----------------------|-----------------------------------------------------------|------------------------------------------------|
| **Base URL**          | `https://api.1millionbot.com`                             | `https://postman-echo.com`                     |
| **Send Message Path** | `/api/public/messages`                                    | `/post`                                        |
| **Method**            | `POST`                                                    | `POST`                                         |
| **Headers**           | `Content-Type: application/json`, `Authorization`        | `Content-Type: application/json` (not specified) |
| **Payload Structure** | More complex with multiple fields including `conversation`, `sender_type`, `bot`, etc. | Simple structure with just `message`          |
| **Response Path**     | `response.0.text`                                        | `json.message`                                 |

### Summary of Differences
- The **Ada UAM** connector has a more complex payload structure and requires authorization headers, while the **Postman Echo** connector has a simpler payload and does not specify any headers.
- The response paths also differ in structure, reflecting the different APIs they interact with.
