- **Base URL:**
  - **Ada UAM:** Uses `1millionbot` API.
  - **Postman Echo:** Uses `postman-echo.com`.

- **Send Message Endpoint:**

    - Requires specific headers including `Authorization`.
    - Includes additional fields in the payload such as `conversation`, `sender_type`, `sender`, `bot`, `language`, and a `url`.
  - **Postman Echo:**
    - Uses a simpler path (`/post`).
    - No headers required.
    - Payload only includes a single field for the message.

- **Response Path:**
  - **Ada UAM:** `response.0.text`
  - **Postman Echo:** `json.message`
