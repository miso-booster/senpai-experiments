### Rule Overview
The rule **"same_number_of_toppings_cost_the_same"** checks that pizzas with the same number of toppings cost the same. Here's a simple breakdown of how it works:

- **When**: It compares two conversations (like two orders).
- **If**: Both orders have the same drink and the same pizza size, and they have the same number of toppings.
- **Then**: It checks if the prices of these two pizzas are the same.
