### Rules and Their Validations

Here are the rules and their descriptions:

1. **Conversation Lengths**
   - Checks if the number of turns of the user and the chatbot equals the conversation length.

2. **More Toppings Cost More**
   - If two pizzas have the same size and drink, the one with more toppings must cost more.

3. **Only Talks About Pizzas**
   - The chatbot should only talk about pizza-related topics.

4. **Ordering Conversation Turns**
   - The user should always order a pizza before ordering drinks.

5. **Ordering Conversation Turns Assistant**
   - The assistant should confirm the pizza order after the user orders a pizza.

6. **Same Number of Toppings Cost the Same**
   - Pizzas with the same number of toppings should cost the same.
