### Rule: Same Number of Toppings Cost the Same 🍕💰

- **What It Means**: If you have two pizzas that have the same number of toppings and are the same size, they should cost the same amount of money!

### How It Works:
1. **Two Conversations**: The rule looks at two different pizza orders (like two friends ordering pizzas).
2. **Same Drink**: It checks if both friends ordered the same drink.
3. **Same Size and Toppings**: Then, it checks if both pizzas are the same size and have the same number of toppings.
4. **Price Check**: If everything is the same, the rule says their prices should also be the same!

So, if you and your friend both order a medium pizza with 3 toppings and the same drink, you should pay the same amount! 🎉
