I found the rule about topping price consistency! Here's a simple explanation:

### Rule: Same Number of Toppings Cost the Same 🍕
- **What it says**: If two pizzas have the same number of toppings and are the same size, they should cost the same amount of money.
  
### How it works:
1. **Two Pizzas**: Imagine you have two pizzas.
2. **Same Size**: Both pizzas are the same size (like both are medium).
3. **Same Toppings Count**: Both pizzas have the same number of toppings (like 3 toppings each).
4. **Price Check**: The rule checks if the price of both pizzas is the same. If they are, everything is good! If not, something is wrong.

So, if you order two medium pizzas with 3 toppings each, they should cost the same amount! 🎉
