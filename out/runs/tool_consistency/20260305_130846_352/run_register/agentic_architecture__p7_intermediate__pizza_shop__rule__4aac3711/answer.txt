The rule **"same_number_of_toppings_cost_the_same"** checks if pizzas with the same number of toppings and size have the same price. Here’s how it works:

- **When**: It compares two conversations (like two orders).
- **If**: Both orders have the same drink, the same size, and the same number of toppings.
- **Then**: It checks if the prices of both pizzas are the same.
