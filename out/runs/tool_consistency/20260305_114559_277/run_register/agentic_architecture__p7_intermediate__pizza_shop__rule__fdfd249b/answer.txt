### Rule Overview
The rule **"same_number_of_toppings_cost_the_same"** checks if pizzas with the same number of toppings cost the same. Here's a simple breakdown:

- **What it does**: If two pizzas have the same drink, size, and number of toppings, it checks if their prices are the same.
- **How it works**: It compares the price of the first pizza (`conv[0].price`) with the second pizza (`conv[1].price`) after confirming that they have the same size and number of toppings.
