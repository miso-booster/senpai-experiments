### Rule: Same Number of Toppings Cost the Same 🍕💰

- **What it says**: If two pizzas have the same number of toppings and are the same size, they should cost the same amount of money.

### How it works:
1. **Two Conversations**: The rule checks two different pizza orders (conversations).
2. **Same Drink**: It first makes sure that both pizzas have the same drink ordered with them.
3. **Same Size and Toppings**: Then, it checks if both pizzas are the same size and have the same number of toppings.
4. **Price Check**: If everything matches, it says that the prices of both pizzas should be equal.

### Why it matters:
This rule helps make sure that if you order two pizzas that are the same in size and toppings, you won't be surprised by different prices! It keeps things fair and simple. 😊
