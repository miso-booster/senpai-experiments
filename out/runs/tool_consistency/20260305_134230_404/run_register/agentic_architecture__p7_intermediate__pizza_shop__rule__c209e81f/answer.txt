### Rule Overview: Same Number of Toppings Cost the Same

The rule **"same_number_of_toppings_cost_the_same"** checks if pizzas with the same number of toppings cost the same. Here's how it works:

- **When**: It compares two conversations (like two orders).
- **If**: Both pizzas have the same size and the same number of toppings.
- **Then**: It checks if the prices of both pizzas are the same.

### Explanation Like You're 5

Imagine you have two boxes of pizza. If both boxes have the same number of toppings, like 3 pieces of pepperoni, the rule says they should cost the same amount of money. So, if one box costs $10 and the other also has 3 pieces of pepperoni, it should also cost $10!
