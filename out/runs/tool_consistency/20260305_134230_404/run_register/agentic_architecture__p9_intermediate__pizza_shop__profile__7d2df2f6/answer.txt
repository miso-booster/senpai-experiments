### 2. **Ada UAM Connector**

  - Authorization: `60a3bee2e3987316fed3218f`

### 3. **Metro Madrid Connector**
- **Base URL:** `https://kdcaapi.metromadrid.es`
- **Send Message Path:** `/api/KDCA/WidgetMessage`
- **Response Path:** `messages.0.content`
- **Method:** POST
- **Headers:**
  - Content-Type: application/json
  - Origin: `https://www.metromadrid.es`
  - Referer: `https://www.metromadrid.es/`
  - User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:141.0) Gecko/20100101 Firefox/141.0
- **Payload Template:**
  - Includes project ID, client ID, message type, content, button ID, user nickname, and session ID.

### 4. **Postman Connector (Echo Bot)**
- **Base URL:** `https://postman-echo.com`
- **Send Message Path:** `/post`
- **Response Path:** `json.message`
- **Method:** POST
- **Payload Template:**
