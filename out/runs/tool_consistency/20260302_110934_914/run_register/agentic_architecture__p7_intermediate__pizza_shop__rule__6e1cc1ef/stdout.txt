I found the rule about topping price consistency! Here’s a simple explanation of it:

### Rule Overview
- **Name**: Same Number of Toppings Cost the Same
- **Description**: This rule says that if two pizzas have the same number of toppings, they should cost the same.

### How It Works
1. **Two Conversations**: The rule checks two different pizza orders.
2. **Same Drink**: It first makes sure both orders have the same drink.
3. **Same Size and Toppings**: Then, it checks if both pizzas are the same size and have the same number of toppings.
4. **Price Check**: If all those things match, the rule says that the prices of the two pizzas should also be the same.

### In Simple Terms
Imagine you have two pizzas. If both pizzas have 3 pepperonis and 2 mushrooms, they should cost the same amount of money. If one is more expensive than the other, that’s not fair! 🍕💰

This rule helps make sure that if you order the same kind of pizza, you pay the same price every time!
