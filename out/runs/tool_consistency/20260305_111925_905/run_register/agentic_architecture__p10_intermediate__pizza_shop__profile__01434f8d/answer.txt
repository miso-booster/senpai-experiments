Here’s a comparison of the connectors using **1millionbot** against a **non-1millionbot** connector:

### 1millionbot Connectors

1. **Ada UAM**
   - **Base URL**: `https://api.1millionbot.com`
   - **Send Message Endpoint**:
     - **Path**: `/api/public/messages`
     - **Method**: `POST`
     - **Headers**:
       - `Content-Type`: `application/json`
       - `Authorization`: `60a3bee2e3987316fed3218f`
     - **Payload Template**:
       ```json
       {
         "conversation": "682ce1ce271ce860cffde0fd",
         "sender_type": "User",
         "sender": "682ce1cefe831160cee700ed",
         "bot": "60a3be81f9a6b98f7659a6f9",
         "language": "es",
         "url": "https://www.uam.es/uam/tecnologias-informacion/servicios-ti/acceso-remoto-red",
         "message": {
           "text": "{user_msg}"
         }
       }
       ```
   - **Response Path**: `response.0.text`

### Non-1millionbot Connector

2. **Echo Bot**
   - **Base URL**: `https://postman-echo.com`
   - **Send Message Endpoint**:
     - **Path**: `/post`
     - **Method**: `POST`
     - **Payload Template**:
       ```json
       {
         "message": "{user_msg}"
       }
       ```
   - **Response Path**: `json.message`

3. **Metro Madrid**
   - **Base URL**: `https://kdcaapi.metromadrid.es`
   - **Send Message Endpoint**:
     - **Path**: `/api/KDCA/WidgetMessage`
     - **Method**: `POST`
     - **Headers**:
       - `Content-Type`: `application/json`
       - `Origin`: `https://www.metromadrid.es`
       - `Referer`: `https://www.metromadrid.es/`
       - `User-Agent`: `Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:141.0) Gecko/20100101 Firefox/141.0`
     - **Payload Template**:
       ```json
       {
         "idProject": "Mzpv0w4t71t",
         "idClient": "0",
         "data": {
           "type": "text",
           "content": "{user_msg}",
           "buttonId": null,
           "user": {
             "nickname": "visitor22842",
             "session": "abbda0f6-2197-4787-9d7d-c5107491f7a1"
           }
         }
       }
       ```
   - **Response Path**: `messages.0.content`

### Differences

- **Base URL**:
  - **1millionbot**: Uses `https://api.1millionbot.com`
  - **Non-1millionbot**: Uses `https://postman-echo.com` or `https://kdcaapi.metromadrid.es`

- **Send Message Endpoint**:
  - **1millionbot**: Has a specific path `/api/public/messages` with structured payload including conversation and sender details.
  - **Non-1millionbot**: The Echo Bot uses a simple `/post` endpoint with a basic message structure. The Metro Madrid connector has a more complex structure with project and client IDs.

- **Headers**:
  - **1millionbot**: Requires an `Authorization` header.
  - **Non-1millionbot (Metro Madrid)**: Includes multiple headers for `Origin`, `Referer`, and `User-Agent`.

- **Payload Structure**:
  - **1millionbot**: Includes fields for conversation, sender type, language, and a URL.
  - **Non-1millionbot**: The Echo Bot has a very simple payload, while the Metro Madrid connector includes additional fields like `idProject` and user session details.

### Summary
The **1millionbot** connectors have a more complex structure with specific requirements for authorization and detailed payloads, while the **non-1millionbot** connectors (like Echo Bot) have simpler structures and fewer requirements. The Metro Madrid connector adds complexity with project-specific identifiers and user session management.
