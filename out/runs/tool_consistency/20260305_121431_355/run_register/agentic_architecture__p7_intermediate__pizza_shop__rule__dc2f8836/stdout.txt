### Rule Overview: Topping Price Consistency

The rule **"same_number_of_toppings_cost_the_same"** checks if pizzas with the same number of toppings cost the same. Here's how it works:

- **When**: It compares two conversations (orders).
- **If**: The size of the pizzas and the number of toppings are the same.
- **Then**: It checks if the prices of these pizzas are equal.

### Explanation for a 5-Year-Old

Imagine you have two pizzas, and both have the same number of toppings, like cheese and pepperoni. This rule is like a game where we check if both pizzas cost the same amount of money. 

- If one pizza has 3 toppings and costs $10, and the other pizza also has 3 toppings, we want to see if it also costs $10. 
- If they do, then the rule says, "Yay! They are the same price!" If not, we say, "Oh no! They should cost the same!"

So, this rule helps us make sure that if two pizzas have the same number of toppings, they should have the same price! 🍕💰
