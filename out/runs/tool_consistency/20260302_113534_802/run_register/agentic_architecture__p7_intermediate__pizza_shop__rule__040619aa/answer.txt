I found the rule about topping price consistency! Here’s a simple explanation:

### Rule: Same Number of Toppings Cost the Same 🍕💰

- **What it says**: If two pizzas have the same number of toppings and are the same size, they should cost the same amount of money.

### How it works:
1. **Two Conversations**: The rule looks at two different pizza orders (we call them conversations).
2. **Same Drink**: It checks if both orders have the same drink.
3. **Same Size**: It checks if both pizzas are the same size.
4. **Same Number of Toppings**: It counts how many toppings each pizza has.
5. **Price Check**: If everything matches (same drink, same size, and same number of toppings), then the prices of both pizzas should be equal.

So, if you order two pizzas that are exactly alike, they should cost the same! If one is more expensive, that's not right! 😊
