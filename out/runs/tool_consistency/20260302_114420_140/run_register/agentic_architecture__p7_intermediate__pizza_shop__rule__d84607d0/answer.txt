I found the rule about topping price consistency! Here’s a simple explanation:

### Rule: Same Number of Toppings Cost the Same 🍕💰

- **What it means**: If two pizzas have the same number of toppings, they should cost the same amount of money.
  
- **How it works**:
  - Imagine you have two pizzas. You look at their sizes and how many toppings each one has.
  - If both pizzas are the same size and have the same number of toppings, then their prices should be the same too!

So, if you order one pizza with 3 toppings for $10, another pizza with 3 toppings should also cost $10. If they don’t, something is wrong! 😊
