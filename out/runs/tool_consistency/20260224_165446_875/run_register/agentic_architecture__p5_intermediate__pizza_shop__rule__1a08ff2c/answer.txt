I found the rule about topping price consistency! 🎉 Here’s how it works, explained simply:

### Rule: More Toppings Cost More 🍕
- **Name:** More Toppings Cost More
- **Description:** If you add more toppings to a pizza, it should cost more.
- **How It Works:**
  - **When:** We look at two pizzas that are the same size and have the same drink.
  - **If:** One pizza has more toppings than the other.
  - **Then:** The pizza with more toppings must have a higher price.

### Example for a 5-Year-Old:
Imagine you have two pizzas:
- **Pizza A:** Has 2 toppings (like cheese and pepperoni).
- **Pizza B:** Has 4 toppings (like cheese, pepperoni, mushrooms, and olives).

If both pizzas are the same size and come with the same drink, Pizza B should cost more money because it has more yummy toppings! 🍕💰

This rule helps make sure that when you order pizza, you always get what you pay for!
