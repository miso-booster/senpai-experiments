### Rule Name: Same Number of Toppings Cost the Same

**What it means:**
- If you order two pizzas and they have the same number of toppings and are the same size, then they should cost the same amount of money.

### How it works:
1. **Two Conversations:** The rule checks two different pizza orders.
2. **Same Drink:** It first looks to see if both orders have the same drink.
3. **Same Size and Toppings:** Then, it checks if both pizzas are the same size and have the same number of toppings.
4. **Price Check:** If both pizzas meet these conditions, the rule says their prices should be equal.

### In Kid Terms:
Imagine you have two pizzas. If one pizza has 3 pepperonis and the other pizza also has 3 pepperonis, and they are both big, they should cost the same amount of money! 🍕💰

This rule helps make sure that when you order pizzas, you don’t pay more for the same thing!
