### Rule Name: Same Number of Toppings Cost the Same

**What it Means:**
- If you order two pizzas that have the same number of toppings and are the same size, they should cost the same amount of money.

### How It Works:
1. **Two Conversations:** The rule looks at two different pizza orders (conversations).
2. **Same Drink:** It checks if both pizzas have the same drink ordered with them.
3. **Same Size and Toppings:** It makes sure both pizzas are the same size and have the same number of toppings.
4. **Price Check:** Finally, it checks if the prices of both pizzas are the same.

### Why It’s Important:
This rule helps make sure that if you order two pizzas that are alike, you won't be surprised by different prices. It keeps things fair and simple! 🍕✨
