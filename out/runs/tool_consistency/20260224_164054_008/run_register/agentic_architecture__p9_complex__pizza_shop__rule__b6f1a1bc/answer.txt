### Rules Overview

1. **conversation_lengths.yaml**
   - **Description**: Checks if the number of turns of the user and the chatbot equals the conversation length.
   - **Active**: False

2. **more_toppings_cost_more.yaml**
   - **Description**: Validates that adding more toppings to a custom pizza costs more.
   - **Active**: True
   - **Conversations**: 2
   - **When**: `conv[0].size == conv[1].size and conv[0].drink == conv[1].drink`
   - **If**: `len(conv[0].toppings) > len(conv[1].toppings)`
   - **Then**: `extract_float(conv[0].price) > extract_float(conv[1].price)`

3. **only_talks_about_pizza.yaml**
   - **Description**: Ensures the chatbot only talks about pizzas.
   - **Active**: True
   - **Oracle**: `only_talks_about('pizza orders, drink orders, information on delivery of pizzas, information about the pizza shop')`

4. **ordering_conversation_turns.yaml**
   - **Description**: Validates that the user always orders a pizza before drinks.
   - **Active**: False
   - **Oracle**: `utterance_index('user', 'ordering a pizza') < utterance_index('user', 'ordering drink')`

5. **ordering_conversation_turns_assistant.yaml**
   - **Description**: Checks that the assistant confirms the pizza order after the user orders a pizza.
   - **Active**: False
   - **Oracle**: `utterance_index('user', 'ordering a pizza') < utterance_index('assistant', 'confirms pizza order')`

6. **same_number_of_toppings_cost_the_same.yaml**
   - **Description**: Ensures pizzas with the same number of toppings cost the same.
   - **Active**: False
   - **When**: `conv[0].drink == conv[1].drink`
   - **If**: `conv[0].size == conv[1].size and len(conv[0].toppings) == len(conv[1].toppings)`
   - **Then**: `extract_float(conv[0].price) == extract_float(conv[1].price)`
