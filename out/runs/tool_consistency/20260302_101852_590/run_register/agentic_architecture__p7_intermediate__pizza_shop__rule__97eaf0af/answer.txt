Here's the rule I found about topping price consistency, explained simply:

### Rule: Same Number of Toppings Cost the Same 🍕
- **Name**: This rule is called "same_number_of_toppings_cost_the_same."
- **What it means**: If you order two pizzas that have the same number of toppings, they should cost the same amount of money.
  
### How it Works:
1. **Two Conversations**: The rule checks two different pizza orders (like two kids ordering pizza).
2. **Same Drink**: It first makes sure both kids ordered the same drink.
3. **Same Size and Toppings**: Then, it checks if both pizzas are the same size and have the same number of toppings.
4. **Price Check**: If everything matches, it says that the prices of both pizzas should be the same.

### Why is it Important?
This rule helps make sure that if you order the same kind of pizza, you won't be surprised by different prices. It keeps things fair! 😊
