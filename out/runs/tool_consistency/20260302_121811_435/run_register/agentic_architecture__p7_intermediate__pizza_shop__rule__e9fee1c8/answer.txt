### Rule: Same Number of Toppings Cost the Same 🍕💰

- **What it says**: If two pizzas have the same number of toppings and are the same size, they should cost the same amount of money.
  
- **How it works**:
  - Imagine you have two pizzas. If both pizzas are the same size and have, let's say, 3 toppings each (like cheese, pepperoni, and mushrooms), then they should have the same price.
  - If one pizza costs $10 and the other also has 3 toppings and costs $12, that's not fair! They should both cost $10.

- **Why it matters**: This rule helps make sure that when you order pizzas, you know that if they look the same (same size and same number of toppings), they will cost the same. It keeps things fair and simple! 😊
