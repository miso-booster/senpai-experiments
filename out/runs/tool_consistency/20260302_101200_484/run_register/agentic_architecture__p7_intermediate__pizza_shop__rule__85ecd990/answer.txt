I found the rule about topping price consistency! Here's a simple explanation of it:

### Rule: Same Number of Toppings Cost the Same 🍕💰

- **What it says**: If you order two pizzas that have the same size and the same number of toppings, they should cost the same amount of money.
  
- **How it works**:
  - It checks if both pizzas have the same drink (like soda).
  - Then, it looks at the size of the pizzas (small, medium, or large).
  - Finally, it counts how many toppings each pizza has (like pepperoni, mushrooms, or cheese).
  - If all those things match, the rule says their prices should also match!

So, if you and your friend both order a medium pizza with 3 toppings, you should pay the same amount! 😊
