I found the rule about topping price consistency! 🎉 Here’s how it works, explained simply:

### Rule Overview
- **Name:** More Toppings Cost More
- **Description:** If you add more toppings to a pizza, it should cost more money.
- **How it Works:** 
  - The rule checks two pizza orders (let's call them Order 1 and Order 2).
  - It looks at the size of the pizzas and the drinks to make sure they are the same.
  - Then, it counts the number of toppings on each pizza.
  - If Order 1 has more toppings than Order 2, then the price of Order 1 should be higher than the price of Order 2.

### In Kid-Friendly Terms
Imagine you have two pizzas:
- **Pizza A** has 3 toppings (like cheese, pepperoni, and mushrooms).
- **Pizza B** has 1 topping (just cheese).

If Pizza A has more toppings, it should cost more money than Pizza B. So, if Pizza A costs $15, Pizza B should cost less, like $10. 

This rule makes sure that when you add yummy toppings, the price goes up! 🍕💰
