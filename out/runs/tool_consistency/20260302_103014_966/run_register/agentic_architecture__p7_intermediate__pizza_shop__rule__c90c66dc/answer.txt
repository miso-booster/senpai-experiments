### Rule: Same Number of Toppings Cost the Same 🍕💰

- **What it says**: If two pizzas have the same number of toppings and are the same size, they should cost the same amount of money.

### How it works:

1. **Two Conversations**: The rule checks two different pizza orders (we call them conversations).
2. **Same Drink**: It first looks to see if both orders have the same drink (like Coke or Sprite).
3. **Same Size and Toppings**: Then, it checks if both pizzas are the same size (like small, medium, or large) and if they have the same number of toppings (like pepperoni or mushrooms).
4. **Price Check**: If both pizzas match in size and number of toppings, the rule says their prices should be the same!

### Why it's important:
This rule helps make sure that if you order two pizzas that are the same in size and toppings, you don’t get charged differently. It's like saying, "If I have two identical toys, they should cost the same!" 🎉
