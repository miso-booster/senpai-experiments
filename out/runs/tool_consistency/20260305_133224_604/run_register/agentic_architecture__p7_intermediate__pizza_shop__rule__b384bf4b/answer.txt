### Rule Overview: Topping Price Consistency
The rule we found is called **"same_number_of_toppings_cost_the_same"**. Here's a simple breakdown of what it does:

- **Purpose**: It checks if two pizzas with the same number of toppings cost the same.
- **Conditions**:
  - Both pizzas must be the same size.
  - Both pizzas must have the same drink.
  - The number of toppings on both pizzas must be equal.
- **Action**: If these conditions are met, it confirms that the prices of the two pizzas are the same.
