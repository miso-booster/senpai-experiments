I found the rule about topping price consistency! Here's a simple explanation of it, just like you're 5 years old 😊:

### Rule: More Toppings Cost More 🍕
- **What it says**: If you have two pizzas that are the same size and drink, and one pizza has more toppings than the other, then the pizza with more toppings should cost more money.
  
### How it Works:
1. **Same Size and Drink**: We check if both pizzas are the same size and have the same drink.
2. **Count Toppings**: We look at how many toppings each pizza has.
3. **Price Check**: If one pizza has more toppings, it should have a higher price than the other pizza.

### Example:
- If Pizza A has 3 toppings and Pizza B has 5 toppings, and they are both medium size with the same drink, then Pizza B should cost more than Pizza A!

This rule helps make sure that when you add more yummy toppings to your pizza, you also pay a little extra for them! 🍕💰
