### Rule: Same Number of Toppings Cost the Same 🍕
- **What it says:** If two pizzas have the same number of toppings and are the same size, they should cost the same amount of money.
  
### How it works:
1. **Two Conversations:** The rule looks at two different pizza orders (conversations).
2. **Same Drink:** It checks if both orders have the same drink.
3. **Same Size & Toppings:** Then, it makes sure both pizzas are the same size and have the same number of toppings.
4. **Price Check:** Finally, it checks if the prices of both pizzas are the same.

### Why is it important?
This rule helps make sure that if you order two pizzas that look the same (same size and same number of toppings), you pay the same price for both. It’s like making sure that if you buy two ice cream cones with the same scoops, they cost the same! 🍦
