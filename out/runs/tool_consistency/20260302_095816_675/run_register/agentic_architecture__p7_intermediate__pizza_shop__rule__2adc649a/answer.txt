### Rule Name: Same Number of Toppings Cost the Same

- **What it means**: If two pizzas have the same number of toppings, they should cost the same amount of money.

### How it works:
1. **Two Conversations**: The rule looks at two different pizza orders (like two friends ordering pizza).
2. **Same Drink**: It checks if both friends ordered the same drink (like soda).
3. **Same Size**: It also checks if both pizzas are the same size (like both being medium).
4. **Count Toppings**: Then, it counts how many toppings are on each pizza.
5. **Price Check**: Finally, if both pizzas have the same number of toppings, their prices should be the same!

### Why is this important?
This rule helps make sure that if you order a pizza with, say, 3 toppings, it costs the same as another pizza with 3 toppings. It keeps things fair! 🍕✨
