Let's check if the **pizza order test custom** profile will work with the rules **more toppings cost more** and **same number of toppings cost the same**.

### Profile Overview
**Filename:** `pizza_order_test_custom.yml`

- **User Role:** Acts as a user ordering a pizza.
- **Goals:**
  - Order a custom pizza with size and toppings.
  - Order a specified number of cans of drink.
  - Inquire about opening and closing times.
  - Ask for the total cost.
- **Chatbot Output:**
  - `price`: Final price of the pizza order.
  - `time`: Opening time.
  - `order_id`: Order ID.

### Rule 1: More Toppings Cost More
**Filename:** `more_toppings_cost_more.yaml`
```yaml
name: more_toppings_cost_more
description: Adding more toppings to a custom pizza cost more
active: True
conversations: 2
when: conv[0].size == conv[1].size and conv[0].drink == conv[1].drink
if:   len(conv[0].toppings) > len(conv[1].toppings)
then: extract_float(conv[0].price) > extract_float(conv[1].price)
```
- **Description:** This rule checks that if two pizzas have the same size and drink, the one with more toppings must cost more.
- **Status:** Active.

### Rule 2: Same Number of Toppings Cost the Same
