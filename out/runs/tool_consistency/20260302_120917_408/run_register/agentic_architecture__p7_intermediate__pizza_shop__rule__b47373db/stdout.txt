### Rule: Same Number of Toppings Cost the Same 🍕💰

- **What it means**: If two pizzas have the same number of toppings, they should cost the same amount of money.
  
- **How it works**:
  - **When**: The rule checks if two pizza orders have the same drink.
  - **If**: It looks at the size of the pizzas and counts how many toppings each one has.
  - **Then**: If both pizzas are the same size and have the same number of toppings, their prices should also be the same.

### Imagine This:
Think of it like this: If you have two pizzas, one with 3 pepperonis and another with 3 pepperonis, they should cost the same. But if one has 2 toppings and the other has 3, they might not cost the same. This rule helps make sure that if they have the same number of toppings, they are fair and cost the same! 😊
