- **Base URL:**

  - **Non-1millionbot:** Metro Madrid includes multiple headers for `Origin`, `Referer`, and `User-Agent`, while Echo Bot does not require any headers.

- **Payload Structure:**
  - **1millionbot:** More complex with multiple fields specific to the bot's functionality.
  - **Non-1millionbot:** Simpler structure, focusing primarily on the user message.

- **Response Path:**
  - **1millionbot:** Returns a specific field from the response.
  - **Non-1millionbot:** Different response paths based on the connector's functionality.

These differences highlight how the 1millionbot connectors are tailored for specific use cases, with more complex payloads and authentication requirements compared to the simpler non-1millionbot connectors.
