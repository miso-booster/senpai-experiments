¡Claro! Aquí tienes un perfil de ejemplo que puedes usar para probar el chatbot de una pizzería. Este perfil está diseñado para que el output incluya el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares. 😊

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "You are a customer placing an order for pizza and drinks."
  context:
    - "You want to explore available pizza options and drink choices."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Select a {{drink_type}} to go with the pizza."
    - "Confirm the order and ask for the total price."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Vegetarian, BBQ Chicken]
    - drink_type:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Can you please rephrase?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink_type:
        type: string
        description: "The type of drink ordered."
    - order_id:
        type: string
        description: "A unique identifier for the order."
    - total_price:
        type: currency
        description: "The final price of the order in dollars."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - random:
        - long phrases
        - single questions
```

### Explicación de las secciones:
- **test_name**: El nombre del perfil para identificarlo fácilmente.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario, su contexto y los objetivos de la conversación.
- **chatbot**: Contiene la configuración del chatbot, incluyendo el output que deseas extraer.
- **conversation**: Controla el número de interacciones y el estilo de la conversación.
