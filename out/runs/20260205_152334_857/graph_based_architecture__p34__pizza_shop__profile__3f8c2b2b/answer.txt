The `chatbot` section typically includes the `is_starter`, `fallback`, and `output` fields. Here's a suggestion for how you can fill it out:

```yaml
test_name: "pizza_information_seeker"

user:
  language: English
  role: "A customer seeking information about pizza types, prices, and delivery."
  context: 
    - "You are planning to order pizza and want to know the options available."
  goals:
    - "Ask about the available pizza types."
    - "Inquire about the price of a Margarita pizza."
    - "Ask about the available drinks and their prices."
    - "Ask about the shop's operating hours."
    - "Inquire if the shop delivers."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: false
      limit: 20

chatbot:
  is_starter: false  # Set to true if the chatbot should initiate the conversation
  fallback: "I'm sorry, I didn't quite catch that. Can you please rephrase your question?"  # A fallback message for unrecognized queries
  output:
    - pizza_types:
        type: string
        description: "A list of the pizza types offered by the shop."
    - margarita_price:
        type: money
        description: "The price of a Margarita pizza."
    - drinks_and_prices:
        type: string
        description: "A list of available drinks and their corresponding prices."
    - operating_hours:
        type: string
        description: "The shop's operating hours."
    - delivery_availability:
        type: string
        description: "Indication of whether the shop delivers or not."
```

### Breakdown of the Fields:
- **is_starter**: Set to `false` since the user is initiating the conversation.
- **fallback**: This message will be used if the chatbot doesn't understand the user's input.
- **output**: This section defines what information you want to extract from the chatbot's responses. Each item includes a `type` and a `description` to clarify what the output represents.

Feel free to adjust any of the descriptions or types to better fit your chatbot's capabilities! If you need further assistance or tweaks, just let me know! 😊
