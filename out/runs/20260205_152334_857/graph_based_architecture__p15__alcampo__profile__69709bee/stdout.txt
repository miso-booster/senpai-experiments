¡Claro! Aquí tienes un ejemplo de perfil que puedes usar para probar la capacidad del chatbot de Alcampo en recomendar recetas y planificación de menús. Este perfil está diseñado para simular un usuario que busca ayuda con recetas y planificación de comidas.

```yaml
test_name: "Recetas y Planificación de Menús"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "You are a user looking for recipe recommendations and meal planning assistance."
  context:
    - "You want to explore healthy recipes that incorporate seasonal ingredients."
    - "You're interested in meal prep ideas for the week."
    - "You would like suggestions for family-friendly meals."
  goals:
    - "Ask for healthy recipes that include {{main_ingredient}}."
    - "Request meal prep ideas for {{number_of_days}} days."
    - "Inquire about family-friendly recipes for dinner."
    - "Ask for tips on how to plan a weekly menu."
    - main_ingredient:
        function: random()
        type: string
        data: [chicken, vegetables, pasta, fish, beans]
    - number_of_days:
        function: random(3)
        type: int
        data: [3, 4, 5]

chatbot:
  is_starter: false
  fallback: "Lo siento, no entendí eso. ¿Puedes intentar preguntar de nuevo sobre recetas o planificación de menús?"
  output:
    - recipe_recommendations:
        type: string
        description: "Recommended recipes based on user queries."
    - meal_prep_ideas:
        type: string
        description: "Ideas for meal prep for the specified number of days."
    - family_friendly_recipes:
        type: string
        description: "Recipes that are suitable for families."
    - weekly_menu_tips:
        type: string
        description: "Tips for planning a weekly menu."

conversation:
  number: 3
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```

### Explicación del perfil:
- **test_name**: Nombre del perfil para identificar la prueba.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario, su contexto y los objetivos que desea alcanzar.
- **chatbot**: Define el comportamiento del chatbot, incluyendo un mensaje de fallback y los campos de salida que se desean extraer.
- **conversation**: Controla la cantidad de interacciones y el estilo de interacción.

Puedes ajustar los ingredientes y los días según tus necesidades. ¡Espero que esto te ayude a probar el chatbot de Alcampo! Si necesitas más ajustes o información, ¡no dudes en decírmelo! 😊
