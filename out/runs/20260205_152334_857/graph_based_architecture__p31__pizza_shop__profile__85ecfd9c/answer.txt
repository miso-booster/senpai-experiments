Sure! Here’s a profile for a pizza shop where the user is rude and wants things done quickly. I've included four goals with four variables, and two of them use pairwise functions to help determine the conversation number based on the pairwise matrix. 

Feel free to adjust any details to better fit your needs! 😊

```yaml
test_name: "rude_fast_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a rude customer who wants to place a pizza order quickly."
  context:
    - "You don't have time for small talk."
    - "You expect fast responses and efficiency."
  goals:
    - "Get me a {{pizza_type}} pizza!"
    - "I want it {{pizza_size}} and with {{toppings}}!"
    - "How long until it's ready?"
    - "I also need {{number_of_drinks}} {{drink_type}} drinks!"

    - pizza_type:
        function: pairwise()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian]
    - pizza_size:
        function: pairwise()
        type: string
        data: [small, medium, large]
    - toppings:
        function: random()
        type: string
        data: [extra cheese, mushrooms, olives, peppers]
    - number_of_drinks:
        function: forward()
        type: int
        data:
          min: 1
          max: 5
    - drink_type:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Fanta]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't catch that. Can you be more specific?"
  output:
    - order_confirmation:
        type: string
        description: "Confirmation of the pizza order and drinks."
    - estimated_time:
        type: time("hh:mm:ss")
        description: "Estimated time for the order to be ready."

conversation:
  number: combinations(0.5, pairwise) # Using pairwise functions for conversation number
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - long phrases
    - change your mind
```

This profile sets the stage for a fast-paced, rude interaction where the user is clear about their demands. The use of pairwise functions will help generate a variety of combinations for testing. If you need any more adjustments or have other requests, just let me know! 🍕✨
