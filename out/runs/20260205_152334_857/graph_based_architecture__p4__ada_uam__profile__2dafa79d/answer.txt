¡Claro! Estoy aquí para ayudarte a crear un perfil para testear el chatbot de la UAM sobre el CAU. Vamos a estructurarlo para que el usuario pueda obtener la información que necesitas: número de teléfono, correo electrónico, dirección física y horarios.

Aquí tienes un ejemplo de cómo podría verse tu perfil en YAML:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita soporte del Centro de Atención a Usuarios (CAU)."
  context:
    - "Buscas información sobre cómo contactar al CAU para resolver dudas."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico de contacto del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar sobre los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "¿Me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - phone_contact:
        type: string
        description: "Número de teléfono de contacto del CAU."
    - email_contact:
        type: string
        description: "Correo electrónico de contacto del CAU."
    - physical_address:
        type: string
        description: "Dirección física del CAU."
    - service_hours:
        type: string
        description: "Horarios de atención del CAU."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

### Explicación de cada sección:
- **test_name**: Un nombre descriptivo para tu perfil.
- **llm**: Configuración del modelo de lenguaje, puedes ajustar la temperatura según lo que necesites.
- **user**: Define el rol del usuario y el contexto de la conversación.
- **goals**: Aquí se listan las preguntas que el usuario hará para obtener la información deseada.
- **chatbot**: Define cómo se comporta el chatbot, incluyendo su mensaje de fallback y los campos que se extraerán al final de la conversación.
- **conversation**: Configura el número de interacciones y el estilo de interacción.

Puedes ajustar cualquier parte de este perfil según tus necesidades. ¡Espero que esto te ayude a comenzar! Si necesitas más ajustes o detalles, no dudes en decírmelo 😊.
