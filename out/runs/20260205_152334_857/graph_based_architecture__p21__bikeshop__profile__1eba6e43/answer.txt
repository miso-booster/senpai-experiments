Sure thing! Let's create a profile for a user who wants to set an appointment to have their wheels changed at a bike shop. This profile will include variables for different days and times to thoroughly test how the chatbot manages scheduling. Here’s a sample YAML profile for you:

```yaml
test_name: "wheel_change_appointment"

llm:
  temperature: 0.5
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer looking to set an appointment to change their bike wheels."
  context:
    - "You want to ensure your bike is ready for the upcoming biking season."
    - "You have a flexible schedule and can choose from various days and times."
  goals:
    - "I would like to schedule an appointment to change my bike wheels on {{appointment_date}} at {{appointment_time}}."
    - appointment_date:
        function: random()
        type: string
        data: [tomorrow, "November 6th, 2024", "next Monday", "next Saturday", "in two days"]
    - appointment_time:
        function: random()
        type: string
        data: ["10:00 AM", "2:00 PM", "3:30 PM", "11:00 AM", "1:00 PM"]

chatbot:
  is_starter: true
  fallback: "I'm sorry, it's a little loud in my shop, can you say that again?"
  output:
    - appointment_confirmation:
        type: string
        description: "Confirmation of the scheduled appointment, including the date and time."

conversation:
  number: 5
  goal_style:
    all_answered:
      export: true
      limit: 5
  interaction_style:
    - default
```

### Breakdown of the Profile:
- **Test Name**: Clearly identifies the purpose of the profile.
- **User Role**: Describes the simulated user's intention.
- **Context**: Provides background information about the user's needs.
- **Goals**: Includes a goal to schedule an appointment with variables for different dates and times.
- **Chatbot Output**: Specifies what the chatbot should confirm after the appointment is set.
- **Conversation Controls**: Sets the number of conversations and how the goals should be handled.
