Creating a profile for an Erasmus user who needs help setting up their Moodle and Sigma accounts sounds like a great idea! Let's structure a simple profile that captures the essence of their situation while ensuring we have the necessary outputs for validation. Here’s a basic template you can use:

```yaml
test_name: "Erasmus User Setup Assistance"

llm:
  temperature: 0.8
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Erasmus student who needs help with setting up Moodle and Sigma."
  context:
    - "You are new to the university and need guidance on accessing digital platforms."
    - "You are not familiar with the setup process for Moodle and Sigma."
  goals:
    - "Solicitar ayuda para configurar mi cuenta de Moodle."
    - "Preguntar sobre cómo acceder a Sigma."
    - "Consultar qué información necesito para iniciar sesión en ambas plataformas."

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - moodle_setup_info:
        type: string
        description: "Instrucciones para configurar la cuenta de Moodle."
    - sigma_access_info:
        type: string
        description: "Instrucciones para acceder a Sigma."
    - required_information:
        type: string
        description: "Información necesaria para iniciar sesión en Moodle y Sigma."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

### Explanation:
- **Test Name**: A clear identifier for the profile.
- **LLM Settings**: Adjusted for a conversational tone.
- **User Role**: Defines the user as an Erasmus student needing assistance.
- **Context**: Provides background on the user's situation.
- **Goals**: Specific requests for help regarding Moodle and Sigma.
- **Chatbot Outputs**: Clearly defined outputs that will help validate if the chatbot provides the necessary support.
- **Conversation Controls**: Simple structure to allow for a few interactions.
