¡Hola! 😊 He revisado la documentación sobre perfiles y estoy listo para ayudarte a crear un perfil para el chatbot de soporte del CAU (Centro de Atención a Usuarios). 

### Estructura del Perfil

Para tu perfil, necesitamos definir los siguientes campos en `chatbot.output`:

- **Número de teléfono**
- **Email**
- **Dirección física**
- **Horarios**

### Propuesta de Perfil

Aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "CAU_Support_Profile"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca soporte del CAU."
  context:
    - "El usuario necesita información sobre el CAU."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Cuál es el email del CAU?"
    - "¿Dónde se encuentra la dirección física del CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: false
  fallback: "Lo siento, no puedo ayudar con eso."
  output:
    - telefono:
        type: string
        description: "Número de teléfono del CAU"
    - email:
        type: string
        description: "Email del CAU"
    - direccion:
        type: string
        description: "Dirección física del CAU"
    - horarios:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Resumen

- **`chatbot.output`** define los campos que queremos extraer al final de la conversación.
- **`goals`** contiene las preguntas que el usuario podría hacer sobre el CAU.
