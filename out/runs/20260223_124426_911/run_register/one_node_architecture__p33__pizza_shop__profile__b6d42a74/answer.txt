¡Claro! Aquí tienes un perfil de ejemplo para probar el chatbot de una pizzería. Este perfil está diseñado para extraer el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares.

```yaml
test_name: "pizza_order_profile"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza."
  context:
    - "You want to know about pizza options and place an order."
  goals:
    - "What types of pizza do you have?"
    - "I would like to order a pizza with a drink."
    - "Can you give me the total price for my order?"
  
chatbot:
  is_starter: true
  fallback: "I'm sorry, I didn't understand that."
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink:
        type: string
        description: "The drink ordered."
    - order_id:
        type: string
        description: "Unique identifier for the order."
    - final_price:
        type: currency
        description: "Final price of the order in dollars."

conversation:
  number: 2
  goal_style:
    steps: 5
  interaction_style:
    - long phrases
```

Este perfil está diseñado para interactuar con el chatbot de la pizzería y extraer la información necesaria. Puedes ajustarlo según tus necesidades específicas. ¡Espero que te sea útil! 🍕😊
