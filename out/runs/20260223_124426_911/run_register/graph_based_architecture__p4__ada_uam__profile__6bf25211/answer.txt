¡Claro! Vamos a crear un perfil para que puedas testear el chatbot de la UAM en el contexto de soporte del CAU. Este perfil incluirá los detalles que mencionaste: número de teléfono, email, dirección física y horarios. Aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca información sobre el CAU."
  context:
    - "Necesito obtener información de contacto y horarios del Centro de Atención a Usuarios."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico de contacto del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar sobre los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "¿Me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico de contacto del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

### Desglose del perfil:

- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje que se utilizará.
- **user**: Define el contexto y los objetivos del usuario.
- **chatbot**: Aquí se especifica la salida esperada del chatbot, que incluye el número de teléfono, correo electrónico, dirección física y horarios.
- **conversation**: Controla el número de interacciones y el estilo de la conversación.

Puedes ajustar los detalles según lo que necesites. ¡Espero que esto te ayude a empezar! Si necesitas más cambios o tienes alguna otra pregunta, ¡no dudes en decírmelo! 😊
