Claro, aquí tienes una propuesta de perfil para que el chatbot de Alcampo pueda recomendar recetas y planificar menús. He ajustado los objetivos para asegurarme de que todas las variables estén correctamente declaradas.

### Propuesta de Perfil

```yaml
test_name: "recetas_y_planificacion_de_menus"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Eres un cliente que busca recomendaciones de recetas y planificación de menús."
  context:
    - "Prefieres recetas saludables y rápidas."
  goals:
    - "Recomiéndame una receta para {{tipo_comida}}."
    - "¿Cuáles son los ingredientes necesarios para {{receta}}?"
    - "Ayúdame a planificar un menú para {{numero_dias}} días."
    - tipo_comida:
        function: random()
        type: string
        data: [desayuno, almuerzo, cena]
    - receta:
        function: random()
        type: string
        data: [ensalada, pasta, pollo al horno, sopa]
    - numero_dias:
        function: random(3)
        type: int
        data:
          min: 1
          max: 7

chatbot:
  is_starter: true
  fallback: "Lo siento, no entendí eso. ¿Podrías reformularlo?"
  output:
    - receta:
        type: string
        description: "Nombre de la receta recomendada."
    - ingredientes:
        type: list[string]
        description: "Lista de ingredientes necesarios."
    - tiempo_preparacion:
        type: string
        description: "Tiempo estimado de preparación."

conversation:
  number: combinations(0.5, pairwise)
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
```
