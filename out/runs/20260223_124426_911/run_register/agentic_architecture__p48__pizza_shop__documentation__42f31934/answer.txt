A metamorphic rule in the context of Sensei is a type of rule that allows for the verification of chatbot behavior by defining relationships between different outputs or states. These rules help ensure that the chatbot behaves consistently and correctly across various scenarios.

### Key Features of Metamorphic Rules:
- **Relationships**: They establish relationships between different outputs based on certain conditions.
- **Consistency Checking**: They are used to check if the chatbot's responses remain consistent when certain inputs are varied.
- **Validation**: Metamorphic rules help validate the chatbot's logic and functionality by ensuring that expected transformations hold true.

### Example:
For instance, if a chatbot is designed to provide information about pizza orders, a metamorphic rule might state that if the order size increases, the total price should also increase proportionally.
