¡Claro! 😊 Aquí tienes un ejemplo de perfil que puedes usar para probar la capacidad del chatbot de Alcampo en recomendar recetas y planificación de menús. Puedes ajustarlo según tus necesidades específicas:

```yaml
test_name: "Recetas y Planificación de Menús"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A user looking for recipe recommendations and menu planning assistance."
  context:
    - "You are interested in healthy meals and seasonal ingredients."
    - "You want to explore new recipes to diversify your meals."
  goals:
    - "Suggest a recipe for a healthy dinner using seasonal vegetables."
    - "Provide a weekly meal plan that includes breakfast, lunch, and dinner."
    - "Recommend a recipe for a special occasion dinner."
    - "Ask for tips on meal prepping for the week."
    - "Inquire about popular recipes among Alcampo customers."

chatbot:
  is_starter: false
  fallback: "Lo siento, no entendí tu pregunta. ¿Puedes reformularla? Estoy aquí para ayudarte con recetas y planificación de menús. 😊"
  output:
    - recipe_suggestion:
        type: string
        description: "A suggested recipe based on user preferences."
    - weekly_meal_plan:
        type: string
        description: "A detailed meal plan for the week."
    - special_occasion_recipe:
        type: string
        description: "A recipe suitable for a special occasion."
    - meal_prepping_tips:
        type: string
        description: "Tips for effective meal prepping."
    - popular_recipes:
        type: string
        description: "List of popular recipes among Alcampo customers."

conversation:
  number: 5
  goal_style:
    steps: 10
  interaction_style:
    - random:
        - single questions
        - long phrases
```

Este perfil está diseñado para interactuar con el chatbot de Alcampo y evaluar su capacidad para proporcionar recetas y asistencia en la planificación de menús. Puedes ejecutarlo en tu entorno de prueba de Sensei. ¡Espero que te sea útil! Si necesitas más ajustes o información, ¡no dudes en preguntar! 🍽️✨
