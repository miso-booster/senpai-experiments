Here’s a simple example of how you might write this rule in YAML format:

```yaml
name: appointment_confirmation_check
description: Ensure the chatbot confirms the appointment when a user requests to schedule a bike service.
conversations: 1
when: 'conv[0].confirmed_service is not None and conv[0].confirmed_date is not None and conv[0].confirmed_time is not None'
oracle: |
  'appointment_confirmation' in chatbot.output
```

### Explanation:
- **name**: A unique name for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: This rule checks a single conversation.
- **when**: This condition checks if the `confirmed_service`, `confirmed_date`, and `confirmed_time` fields are not `None`, meaning the user has requested an appointment.
- **oracle**: This checks if the `appointment_confirmation` is present in the chatbot's output, indicating that the appointment has been confirmed.
