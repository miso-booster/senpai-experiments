Let's create a profile for a pizza shop where the user is rude and wants things done quickly. This profile will include four goals, two of which will utilize pairwise functions to determine the conversation number through a pairwise matrix.

Here's the proposed YAML structure for the pizza shop profile:

```yaml
test_name: "pizza_shop_profile"

llm:
  temperature: 0.5
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A rude customer who demands quick service."
  context:
    - "The user is impatient and expects fast responses."
  goals:
    - "Order a {{size}} pizza with {{toppings}}."
    - "Request a total price in {{currency}}."
    - "Ask for a delivery time of {{delivery_time}}."
    - "Inquire about available drinks: {{drinks}}."
    - size:
        function: random()
        type: string
        data: [small, medium, large]
    - toppings:
        function: pairwise()
        type: string
        data: [pepperoni, mushrooms, onions, olives]
    - currency:
        function: random()
        type: string
        data: [USD, EUR, GBP]
    - delivery_time:
        function: forward()
        type: string
        data: [30 minutes, 45 minutes, 1 hour]
    - drinks:
        function: pairwise()
        type: string
        data: [soda, water, juice]

chatbot:
  is_starter: false
  fallback: "I don't have time for this, just get my order right!"
  output:
    - total_price:
        type: currency
        description: "Final price including taxes and add-ons"
    - delivery_time:
        type: string
        description: "Estimated delivery time for the order"
    - order_id:
        type: string
        description: "Order confirmation ID"

conversation:
  number: combinations(0.5, pairwise) # Two pairwise functions declared
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - make spelling mistakes
      - single questions
```

### Summary of the Profile:
- **User Role**: A rude customer expecting fast service.
- **Goals**: Includes ordering pizza, asking for prices, delivery times, and drinks.
- **Variables**: Two variables (`toppings` and `drinks`) use the `pairwise()` function to generate combinations for conversation coverage.
- **Chatbot Output**: Defines what will be extracted after the conversation, such as total price and delivery time.
