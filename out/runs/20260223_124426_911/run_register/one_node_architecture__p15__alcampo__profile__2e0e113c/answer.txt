¡Claro! Aquí tienes un perfil que puedes usar para probar la capacidad del chatbot de Alcampo para recomendar recetas y planificar menús. Este perfil incluye metas relacionadas con la búsqueda de recetas y la planificación de comidas.

```yaml
test_name: "recetas_y_planificacion_de_menus"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Eres un cliente que busca recomendaciones de recetas y planificación de menús."
  context:
    - "Te gusta cocinar y quieres ideas para tus comidas."
  goals:
    - "Pedir recetas para una cena especial."
    - "Solicitar ideas de menús para una semana."
    - "Preguntar sobre ingredientes para una receta específica."
    - "Inquirir sobre opciones saludables para el almuerzo."
    - "Solicitar consejos para planificar comidas familiares."

chatbot:
  is_starter: false
  fallback: "Lo siento, no entendí eso. ¿Puedes reformular tu pregunta?"
  output:
    - recipe_recommendation:
        type: string
        description: "Recomendaciones de recetas basadas en la solicitud del usuario."
    - menu_plan:
        type: string
        description: "Planificación de menús para la semana."
    - ingredient_info:
        type: string
        description: "Información sobre ingredientes necesarios para las recetas."
    - healthy_options:
        type: string
        description: "Opciones saludables para el almuerzo."

conversation:
  number: combinations(0.5, pairwise) # Usar combinaciones para cubrir diferentes solicitudes
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
```

Este perfil está diseñado para interactuar con el chatbot de Alcampo y evaluar su capacidad para proporcionar recomendaciones útiles sobre recetas y planificación de menús. ¡Espero que te sea útil! 😊
