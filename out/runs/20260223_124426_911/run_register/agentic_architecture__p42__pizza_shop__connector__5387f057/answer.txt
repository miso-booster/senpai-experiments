Based on the provided request and the documentation for custom connectors, here's how we can create the YAML configuration for your connector to the Alcampo chatbot API.

### YAML Connector Configuration

```yaml
name: "Alcampo Chatbot"
base_url: "https://alcampo.botslovers.com/bot/web"
send_message:
  path: "/bot/web"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Accept: "*/*"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
    Referer: "https://alcampo.botslovers.com/Admin/Widget?mobile=0&user=0&lang=es"
  payload_template:
    data:
      id_user: "{id_user}"
      idweb_user: "{idweb_user}"
      session: "{session}"
      message:
        message:
          message:
            text: "{user_msg}"
        iduser: "{id_user}"
        session: "{session}"
        channel: "web"
      widget_form: "TRUE"
      contexto_extra: []
      lang: "es"
      accion: "response_bot"
response_path: "messages.0.0.message.text"
```

### Explanation of the Configuration

- **name**: A friendly name for your connector.
- **base_url**: The base URL of the Alcampo chatbot API.
- **send_message**:
  - **path**: The endpoint where the POST request is sent.
  - **method**: The HTTP method used for the request (POST).
  - **headers**: Custom headers required for the request.
  - **payload_template**: The structure of the JSON payload sent to the API, with placeholders for dynamic values like `id_user`, `idweb_user`, `session`, and `user_msg`.
- **response_path**: This specifies how to extract the bot's reply from the JSON response.
