```yaml
test_name: "custom_to_predefined_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer who initially wants a custom pizza but changes their mind halfway through."
  context:
    - "You are planning a pizza night and want to explore options."
  goals:
    - "I would like to order a custom pizza with {{custom_toppings}}."
    - "Actually, can I get a {{predefined_pizza}} instead?"
    - custom_toppings:
        function: random()
        type: string
        data: [pepperoni, mushrooms, olives, onions]
    - predefined_pizza:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, BBQ Chicken]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't quite catch that. Can you repeat your order?"
  output:
    - order_confirmation:
        type: string
        description: "Confirmation of the pizza order."

conversation:
  number: 2
  goal_style:
    all_answered:
      export: true
  interaction_style:
    - change your mind
    - long phrases
```

### Key Elements:
- **Goals**: The user first expresses a desire for a custom pizza and then changes their mind to ask for a predefined pizza.
- **Interaction Style**: The `change your mind` style allows the user to switch their request during the conversation.
- **Output**: You can customize the output fields based on what you want to extract after the conversation.

Feel free to modify the toppings and predefined pizza options as needed! Happy testing! 🍕✨
