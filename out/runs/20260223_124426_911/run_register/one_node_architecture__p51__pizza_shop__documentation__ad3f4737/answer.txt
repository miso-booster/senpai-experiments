In the context of Sensei-check, an **oracle** is a method or mechanism used to determine the correctness of the outputs generated by your chatbot during testing. It essentially provides a reference or a standard against which the chatbot's responses can be evaluated.

Here's a simple way to think about it:

- **Single-conversation oracle**: This checks the output of a single conversation to see if it meets certain criteria. For example, you might have a rule that states the price of a small pizza should always be at least $10. If the chatbot returns a price lower than that, it fails the oracle check.

- **Metamorphic oracle**: This is a bit more complex! It checks relationships between multiple conversations. For instance, if two conversations have the same pizza size and drink, the one with more toppings should cost more. This type of oracle helps ensure that the chatbot's responses maintain consistent logic across different scenarios.

Oracles help to ensure that your chatbot behaves correctly and consistently, making them a crucial part of testing! If you have any specific questions about how to implement or use oracles in your Sensei project, feel free to ask! 😊
