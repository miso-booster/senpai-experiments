Sure! Since you want to create a rule that checks if the chatbot provided information about current promotions and it's not based on any specific profile, we can use a general/global rule. Here’s how you can structure it:

```yaml
name: current_promotions_check
description: Check if the chatbot provides information about current promotions.
conversations: 1
oracle: |
  'current_promotions' in chatbot.output
```

### Explanation:
- **name**: This is the identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to 1 since we are checking a single conversation.
- **oracle**: This checks if the `current_promotions` field is present in the chatbot's output.
