¡Hola! 😊 He revisado la documentación sobre perfiles y estoy listo para ayudarte a crear un perfil para probar el chatbot de una pizzería. 

### Estructura del Perfil
El perfil que vamos a crear incluirá los siguientes campos en `chatbot.output`:
- **tipo de pizza**: el tipo de pizza que se está pidiendo.
- **bebida**: la bebida que se acompaña con la pizza.
- **id del pedido**: un identificador único para el pedido.
- **precio final**: el precio total en dólares.

### Perfil Propuesto
Aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "pizza_order_profile"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Eres un cliente que quiere pedir una pizza."
  goals:
    - "Quiero una pizza de {{tipo_pizza}} y una bebida {{bebida}}."
    - tipo_pizza:
        function: random()
        type: string
        data: [margarita, pepperoni, cuatro quesos, vegetariana]
    - bebida:
        function: random()
        type: string
        data: [coca-cola, fanta, agua, cerveza]

chatbot:
  is_starter: true
  fallback: "Lo siento, no entendí eso."
  output:
    - tipo_pizza:
        type: string
        description: "Tipo de pizza pedida."
    - bebida:
        type: string
        description: "Bebida pedida."
    - order_id:
        type: string
        description: "ID del pedido."
    - total_price:
        type: currency
        description: "Precio total en dólares."

conversation:
  number: 5
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Resumen
- **Nombre del perfil**: `pizza_order_profile`
- **Campos de salida**: tipo de pizza, bebida, id del pedido, precio total.
- **Interacción**: el usuario puede hacer preguntas de manera aleatoria y con frases largas.
