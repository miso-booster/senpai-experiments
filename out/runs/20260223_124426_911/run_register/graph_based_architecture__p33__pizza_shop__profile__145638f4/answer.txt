¡Claro! Aquí tienes un perfil de ejemplo para probar el chatbot de una pizzería. Este perfil está diseñado para que el output muestre el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares. Puedes ajustarlo según tus necesidades 😊.

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering a pizza and drinks from a pizzeria."
  context:
    - "You want to choose a pizza type and a drink for your order."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Select a {{drink_type}} to go with the pizza."
    - "Ask for the total price."
    - "Get the order ID."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Vegetarian, BBQ Chicken]
    - drink_type:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Can you please repeat?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink_type:
        type: string
        description: "The drink selected with the pizza."
    - order_id:
        type: string
        description: "The unique identifier for the order."
    - total_price:
        type: currency
        description: "The final price of the order in dollars."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 10
  interaction_style:
    - random:
      - long phrases
      - single questions
```

Este perfil cubre los aspectos que mencionaste y está listo para ser utilizado. Puedes copiarlo y pegarlo en un archivo YAML en la carpeta de perfiles de tu proyecto. ¡Espero que te sea útil! Si necesitas más ayuda, no dudes en preguntar. 🍕✨
