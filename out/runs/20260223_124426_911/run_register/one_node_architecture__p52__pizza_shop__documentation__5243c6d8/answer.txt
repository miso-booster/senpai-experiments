Connectors are used to integrate your chatbot with external APIs, allowing it to send and receive messages from different platforms or services. They act as a bridge between your chatbot and the API, enabling seamless communication.

### Key Fields in a Connector

Here are the main fields typically found in a connector configuration:

1. **name**: A friendly name for your chatbot connector.
2. **base_url**: The base URL of the chatbot API you are connecting to.
3. **send_message**: This section contains details about how to send a message to the chatbot API:
   - **path**: The specific endpoint path (appended to the base URL) for sending messages.
   - **method**: The HTTP method to use (e.g., POST, GET). Defaults to POST if not specified.
   - **headers**: Any custom headers required for the API request (e.g., for authentication).
   - **payload_template**: The structure of the message being sent, often containing a placeholder for the user's message (e.g., `{user_msg}`).
4. **response_path**: A dot-separated path to extract the bot's reply from the JSON response returned by the API.

These fields help define how your chatbot interacts with external systems, making it versatile and capable of handling various tasks! If you have any specific questions about creating or using connectors, feel free to ask! 😊
