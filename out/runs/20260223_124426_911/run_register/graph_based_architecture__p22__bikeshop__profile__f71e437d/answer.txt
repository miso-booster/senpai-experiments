```yaml
test_name: "bike_setup_customization"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer who recently purchased a new bike and wants to customize it."
  context:
    - "You want to change the seat and handlebar grips to suit your preferences."
    - "You are looking for recommendations on seat types and grip materials."
  goals:
    - "Ask about the available options for bike seats."
    - "Inquire about different types of handlebar grips."
    - "Request assistance in customizing the bike to fit your preferences."
    - "Ask for the estimated time for the customization process."
    - seat_type:
        function: random()
        type: string
        data: [comfort, racing, gel, leather]
    - grip_material:
        function: random()
        type: string
        data: [foam, rubber, silicone, leather]

chatbot:
  is_starter: true
  fallback: "I'm sorry, it's a little loud in my shop, can you say that again?"
  output:
    - seat_options:
        type: string
        description: "Information about the available seat types."
    - grip_options:
        type: string
        description: "Information about the available handlebar grip materials."
    - customization_time:
        type: string
        description: "Estimated time for the customization process."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 5
  interaction_style:
    - long phrases
    - single questions
```

### Explanation of the Profile:

1. **User Role and Context**: This defines the user's situation and what they want to achieve during their visit.
2. **Goals**: These are the specific inquiries the user will make, including asking about seat options, grip materials, and customization assistance.
3. **Chatbot Output**: This section defines what information the chatbot should provide in response to the user's inquiries.
4. **Conversation Controls**: This specifies how many interactions will occur and the style of those interactions.
