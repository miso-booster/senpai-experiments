Connectors are used to facilitate communication between your chatbot and various external APIs or services. They allow your chatbot to send messages, receive responses, and interact with different platforms seamlessly. This is especially useful for chatbots that need to fetch data from external sources or perform actions based on user inputs.

### Key Fields in Connectors

Here are the main fields you typically find in a connector configuration:

1. **name**: A friendly name for your chatbot connector, making it easier to identify.

2. **base_url**: The base URL of the chatbot API you are connecting to. This is the starting point for all API requests.

3. **send_message**: This section contains details about how to send a message to the chatbot API:
   - **path**: The specific endpoint path that will be appended to the base URL for sending messages.
   - **method**: The HTTP method to use (e.g., POST, GET). The default is usually POST.
   - **headers**: Any custom headers required for the API request (e.g., authentication tokens).
   - **payload_template**: The structure of the message being sent, often including placeholders (like `{user_msg}`) for dynamic content.

4. **response_path**: A dot-separated path used to extract the bot's reply from the JSON response received from the API. This tells the connector where to find the relevant data in the response.

### Example of a Connector Configuration

Here's a simple example of what a connector configuration might look like:

```yaml
name: "My Custom Bot"
base_url: "https://api.mychatbot.com"
send_message:
  path: "/chat"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

In this example:
- The connector is named "My Custom Bot."
- It connects to an API at `https://api.mychatbot.com`.
- It sends messages to the `/chat` endpoint using a POST request.
- The response is expected to contain the bot's reply in the `response.text` field.
