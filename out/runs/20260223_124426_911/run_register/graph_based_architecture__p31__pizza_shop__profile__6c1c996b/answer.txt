Sure thing! Here’s a profile for a pizza shop where the user is rude and wants things done quickly. I've included 4 goals with 4 variables, and I've set 2 of them to use pairwise functions to help determine the conversation number. Let’s dive in! 🍕✨

```yaml
test_name: "rude_fast_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A rude customer who wants their pizza order done quickly."
  context:
    - "You expect fast service and don't have time for small talk."
    - "You want to get straight to the point."
  goals:
    - "I want a {{pizza_type}} pizza, and make it quick!"
    - "Get me a {{drink_type}} to go with that."
    - "I need it in {{pickup_time}}. Don't mess around!"
    - "How much is it for {{number_of_toppings}} toppings?"

    - pizza_type:
        function: forward()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian]
    - drink_type:
        function: pairwise()
        type: string
        data: [Coke, Sprite, Water, Beer]
    - pickup_time:
        function: random()
        type: string
        data: [15 minutes, 30 minutes, 45 minutes]
    - number_of_toppings:
        function: pairwise()
        type: int
        data: [1, 2, 3, 4]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't catch that. Can you be more specific?"
  output:
    - order_confirmation:
        type: string
        description: "Confirmation of the pizza order and total price."
    - estimated_time:
        type: string
        description: "Estimated time for the order to be ready."
    - total_price:
        type: currency
        description: "Total price of the order."

conversation:
  number: combinations(0.5, pairwise) # Using pairwise functions for conversation number
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - single questions
```

### Breakdown:
- **User Role**: The user is characterized as rude and impatient, which sets the tone for the conversation.
- **Goals**: There are four goals with variables:
  - **pizza_type**: A straightforward request for a pizza type.
  - **drink_type**: Uses a pairwise function to cover combinations of drink options.
  - **pickup_time**: A random selection for when they want to pick up their order.
  - **number_of_toppings**: Another pairwise function to test different topping combinations.
- **Conversation Number**: The combination of pairwise functions ensures that the conversation number can be determined effectively.
