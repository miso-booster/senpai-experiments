Now, let's generate a complete Python script to send multiple requests to this connector. 

### Python Script

```python
import requests
import json

# Configuration for the connector
base_url = "https://api.1millionbot.com/api/public/messages"
headers = {
    "Content-Type": "application/json",
    "Authorization": "64e5d1af081211d24e2cfecd"
}

# Function to send a message
def send_message(conversation_id, sender_id, user_msg):
    payload = {
        "conversation": conversation_id,
        "sender_type": "User",
        "sender": sender_id,
        "bot": "64e5d1af081211d24e2cfec8",
        "language": "es",
        "url": "https://saic.malaga.eu/",
        "message": {
            "text": user_msg
        }
    }
    
    response = requests.post(base_url, headers=headers, data=json.dumps(payload))
    
    if response.status_code == 200:
        return response.json()["response"][0]["text"]
    else:
        return f"Error: {response.status_code}, {response.text}"

# Sending multiple requests
conversation_id = "6977595c744ccf01954b8797"
sender_id = "6977595c3e4824018e496b0c"
messages = ["hola", "¿cómo estás?", "¿qué puedes hacer?"]

for msg in messages:
    reply = send_message(conversation_id, sender_id, msg)
    print(f"User: {msg}\nBot: {reply}\n")
```

### Explanation of the Python Script
- **requests**: A library to make HTTP requests.
- **send_message function**: Takes the conversation ID, sender ID, and user message as parameters, constructs the payload, and sends a POST request to the API.
- **Loop**: Sends multiple messages and prints the bot's replies.
