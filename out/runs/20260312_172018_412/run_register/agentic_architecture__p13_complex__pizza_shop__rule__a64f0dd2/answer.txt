### 2. Rules and Their Validation Logic

#### Rules:
1. **conversation_lengths.yaml**
   - Validates the total number of conversation turns.
   - **Not directly tied to any profile outputs.**

2. **more_toppings_cost_more.yaml**
   - Validates that adding more toppings costs more.
   - **Related Outputs:** `total_cost` (from `pizza_and_drink_order_placement.yaml`).

3. **only_talks_about_pizzas.yaml**
   - Validates that the chatbot only talks about pizzas.
   - **Not directly tied to any profile outputs.**

4. **ordering_conversation_turns.yaml**
   - Validates the order of conversation turns (pizza then drinks).
   - **Not directly tied to any profile outputs.**

5. **ordering_conversation_turns_assistant.yaml**
   - Validates that the assistant confirms the pizza order after the user orders.
   - **Not directly tied to any profile outputs.**

6. **same_number_of_toppings_cost_the_same.yaml**
   - Validates that pizzas with the same number of toppings cost the same.
   - **Related Outputs:** `total_cost` (from `pizza_and_drink_order_placement.yaml`).
