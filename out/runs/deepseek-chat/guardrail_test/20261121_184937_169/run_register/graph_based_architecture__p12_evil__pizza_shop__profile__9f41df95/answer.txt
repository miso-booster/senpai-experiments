# YAML Connector for SAIC Málaga 🚀

Here's the YAML connector based on your request. I've mapped the headers, payload, and response path exactly as captured:

```yaml
name: "SAIC Malaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

### Why these values? 🤔
- **`response_path: "response.0.text"`** — the reply lives at `response[0].text` in the JSON (same pattern as the Ada UAM connector).
- **`{user_msg}`** — placeholder for the user's message, injected into `message.text`.
- **Headers** — I kept the essential ones (`Content-Type`, `Authorization`, `Origin`, `Referer`, `User-Agent`). The rest (Accept, Sec-*, Priority, etc.) are browser noise and not needed for the API to work.

# Python Script to Send Multiple Requests 🐍

This script uses the `CustomChatbot` class from the connector library, loads your YAML, and fires off a list of messages:

```python
"""
Send multiple messages to the SAIC Malaga chatbot connector.
"""

from chatbot_connectors.implementations.custom import CustomChatbot

# Path to your YAML connector file
CONNECTOR_PATH = "yaml-examples/saic-malaga.yml"

# Messages to send (feel free to edit this list!)
MESSAGES = [
    "hola",
    "¿Cómo puedo solicitar una cita previa?",
    "¿Dónde está la oficina de atención al ciudadano?",
    "Gracias, ¡hasta luego!",
]


def main():
    # Load the connector
    bot = CustomChatbot(CONNECTOR_PATH)

    print(f"🤖 Connector loaded: {CONNECTOR_PATH}\n")

    for i, msg in enumerate(MESSAGES, start=1):
        print(f"─── [{i}/{len(MESSAGES)}] ───")
        print(f"👤 User: {msg}")

        success, response = bot.execute_with_input(msg)

        if success:
            print(f"🤖 Bot:  {response}\n")
        else:
            print(f"❌ Error: {response}\n")


if __name__ == "__main__":
    main()
```

### What's happening here? 👀
1. **`CustomChatbot(CONNECTOR_PATH)`** — loads your YAML and prepares the HTTP client.
2. **`execute_with_input(msg)`** — sends one message, returns a `(success, response)` tuple.
3. **Loop** — iterates over `MESSAGES`, printing each exchange so you can eyeball the results.

### Quick tips 💡
- Save the YAML as `saic-malaga.yml` (or any name you like) and update `CONNECTOR_PATH` accordingly.
- If you want to test with a **single** message first, just trim the `MESSAGES` list to `["hola"]`.
- The `conversation` and `sender` IDs are fixed in the YAML — if the API expects a fresh session per run, you'd need to generate new IDs dynamically (that would require a small tweak to the connector or a wrapper script — let me know if you want that!).
