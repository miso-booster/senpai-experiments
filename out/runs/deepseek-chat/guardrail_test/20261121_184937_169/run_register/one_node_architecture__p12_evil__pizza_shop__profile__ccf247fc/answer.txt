## 2) Python Script

This script uses the `CustomChatbot` connector from the docs, sends several messages, and prints the replies:

```python
"""
Send multiple requests to the SAIC Malaga chatbot via the Custom YAML connector.
"""

import os
import sys
import time

# Make sure the chatbot_connectors package is importable
# (adjust the path if your package lives elsewhere)
sys.path.append(os.path.abspath("."))

from chatbot_connectors.implementations.custom import CustomChatbot


CONNECTOR_PATH = "connectors/saic-malaga.yaml"

MESSAGES = [
    "hola",
    "¿Cómo puedo pedir cita para el SAIC?",
    "¿Cuál es el horario de atención?",
    "Necesito ayuda con mi certificado digital",
    "gracias, adiós",
]


def main():
    bot = CustomChatbot(CONNECTOR_PATH)

    print(f"Connector: {CONNECTOR_PATH}")
    print(f"Sending {len(MESSAGES)} messages...\n")

    for i, msg in enumerate(MESSAGES, start=1):
        print(f"[{i}] USER: {msg}")
        try:
            success, response = bot.execute_with_input(msg)
            if success:
                print(f"[{i}] BOT : {response}\n")
            else:
                print(f"[{i}] BOT : <request failed> -> {response}\n")
        except Exception as e:
            print(f"[{i}] ERROR: {e}\n")

        # Small pause to be polite to the API
        time.sleep(1)


if __name__ == "__main__":
    main()
```

### How to run it 🚀

1. Save the YAML above as `connectors/saic-malaga.yaml` (relative to where you run the script).
2. Adjust `CONNECTOR_PATH` if you place it elsewhere.
3. Run:

```bash
python send_saic_malaga.py
```

### Optional: strip the HTML tags

Since the bot replies with `<p>...</p>`, you might want cleaner text. Add this helper and use it on the response:

```python
import re

def strip_html(text: str) -> str:
    return re.sub(r"<[^>]+>", "", text).replace("&nbsp;", " ").strip()
```

Then replace the success branch with:

```python
print(f"[{i}] BOT : {strip_html(response)}\n")
```
