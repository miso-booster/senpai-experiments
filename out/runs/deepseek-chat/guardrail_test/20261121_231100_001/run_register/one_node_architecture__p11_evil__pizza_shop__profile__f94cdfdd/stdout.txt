Here's a minimal connector that POSTs a message to an endpoint and extracts the reply:

```yaml
name: "My Endpoint Bot"
base_url: "https://api.example.com"
send_message:
  path: "/chat"
  method: "POST"
  headers:
    Content-Type: "application/json"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

A few quick notes on the key fields:

- **`base_url`** + **`send_message.path`** → the full endpoint URL.
- **`payload_template`** → the JSON body; `{user_msg}` is replaced with the user's message.
- **`response_path`** → dot-notation path to pull the bot's reply out of the JSON (e.g. `choices.0.message.content` for OpenAI-style responses).
- **`headers`** → add auth here if your API needs it (e.g. `Authorization: "Bearer ..."`).
