## 1) YAML connector

Puntos clave de la traducción:
- `base_url` = `https://api.1millionbot.com`, `path` = `/api/public/messages`.
- `Authorization` va en `headers` (tu token `64e5d1af081211d24e2cfecd`).
- Los campos fijos del payload (`conversation`, `sender`, `bot`, `language`, `url`) van en `payload_template`, y solo `message.text` usa el placeholder `{user_msg}`.
- `response_path` = `response.0.text`, porque la respuesta es `{"response": [{"text": "..."}]}` (el `.0` navega al primer elemento del array, tal como explica la sección "How `response_path` Works").

```yaml
name: "SAIC Malaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Accept: "*/*"
    Accept-Language: "en-US,en;q=0.9"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
    Authorization: "64e5d1af081211d24e2cfecd"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

⚠️ Nota: `Content-Length`, `Host`, `Connection`, `Sec-Fetch-*`, `Priority`, `Pragma`, `Cache-Control` y `Accept-Encoding` los he omitido a propósito — son cabeceras que gestiona el cliente HTTP (requests/urllib) y fijarlas a mano puede romper la petición (por ejemplo, un `Content-Length` incorrecto o un `Accept-Encoding` que devuelva gzip sin descomprimir).

## 2) Script Python completo

El script hace lo siguiente:
- Carga el YAML del connector (misma estructura que usa `CustomChatbot`).
- Construye la URL y el payload sustituyendo `{user_msg}`.
- Envía N mensajes (lista configurable o modo interactivo).
- Extrae la respuesta con la misma lógica de `response_path` (dot notation con índices numéricos).
- Limpia el HTML de la respuesta (`<p>...</p>`, `<br>`).
- Reutiliza la misma `conversation` para mantener el hilo, con opción de generar una nueva por sesión.
- Guarda un log JSON con todas las peticiones/respuestas.

```python
#!/usr/bin/env python3
"""
send_multiple.py — Envía múltiples mensajes a un chatbot configurado
mediante un connector YAML (formato Custom YAML Connector de Chatbot Dojo).

Uso:
    python send_multiple.py
    python send_multiple.py --connector saic_malaga.yml --messages "hola" "¿dónde está el SAIC?"
    python send_multiple.py --interactive
"""

import argparse
import copy
import json
import re
import sys
import time
import uuid
from pathlib import Path
from typing import Any, Dict, List, Optional, Tuple

import requests
import yaml

DEFAULT_CONNECTOR = "saic_malaga.yml"
DEFAULT_TIMEOUT = 30
USER_MSG_PLACEHOLDER = "{user_msg}"


# --------------------------------------------------------------------------
# Carga del connector
# --------------------------------------------------------------------------
def load_connector(path: str) -> Dict[str, Any]:
    """Carga y valida mínimamente el YAML del connector."""
    file_path = Path(path)
    if not file_path.exists():
        raise FileNotFoundError(f"No se encuentra el connector: {file_path}")

    with file_path.open("r", encoding="utf-8") as fh:
        config = yaml.safe_load(fh)

    if not isinstance(config, dict):
        raise ValueError("El connector YAML debe ser un diccionario.")

    for required in ("base_url", "send_message", "response_path"):
        if required not in config:
            raise ValueError(f"Falta el campo obligatorio '{required}' en el connector.")

    send_message = config["send_message"]
    for required in ("path", "payload_template"):
        if required not in send_message:
            raise ValueError(f"Falta el campo obligatorio 'send_message.{required}'.")

    return config


# --------------------------------------------------------------------------
# Utilidades de payload / respuesta
# --------------------------------------------------------------------------
def build_payload(template: Any, user_msg: str) -> Any:
    """
    Sustituye recursivamente el placeholder {user_msg} en el payload_template.
    Mantiene la estructura anidada (dicts, listas) intacta.
    """
    if isinstance(template, dict):
        return {k: build_payload(v, user_msg) for k, v in template.items()}
    if isinstance(template, list):
        return [build_payload(v, user_msg) for v in template]
    if isinstance(template, str):
        return template.replace(USER_MSG_PLACEHOLDER, user_msg)
    return template


def extract_by_path(data: Any, path: str) -> Any:
    """
    Navega el JSON con notación de puntos, soportando índices numéricos.
    Ej: "response.0.text" -> data["response"][0]["text"]
    """
    current = data
    for part in path.split("."):
        if isinstance(current, list):
            current = current[int(part)]
        elif isinstance(current, dict):
            current = current[part]
        else:
            raise KeyError(f"No se puede navegar '{part}' en {type(current).__name__}")
    return current


def strip_html(text: str) -> str:
    """Convierte el HTML de la respuesta en texto plano legible."""
    if not isinstance(text, str):
        return str(text)
    text = re.sub(r"<br\s*/?>", "\n", text, flags=re.IGNORECASE)
    text = re.sub(r"</p>\s*<p>", "\n\n", text, flags=re.IGNORECASE)
    text = re.sub(r"<[^>]+>", "", text)
    text = text.replace("&nbsp;", " ").replace("&amp;", "&")
    text = text.replace("&lt;", "<").replace("&gt;", ">").replace("&quot;", '"')
    return re.sub(r"\n{3,}", "\n\n", text).strip()


# --------------------------------------------------------------------------
# Cliente del chatbot
# --------------------------------------------------------------------------
class YamlChatbot:
    """Cliente mínimo equivalente a CustomChatbot basado en un connector YAML."""

    def __init__(self, config: Dict[str, Any], timeout: int = DEFAULT_TIMEOUT):
        self.config = config
        self.timeout = timeout
        self.session = requests.Session()
        self.base_url = config["base_url"].rstrip("/")
        self.send_message = config["send_message"]
        self.response_path = config["response_path"]

        # Cabeceras del connector + User-Agent por defecto si no hay
        self.headers = dict(self.send_message.get("headers") or {})
        self.headers.setdefault("Content-Type", "application/json")

    @property
    def url(self) -> str:
        return f"{self.base_url}{self.send_message['path']}"

    def new_conversation_id(self) -> str:
        """Genera un id de conversación nuevo (24 hex chars, estilo Mongo ObjectId)."""
        return uuid.uuid4().hex[:24]

    def send(self, user_msg: str, conversation_id: Optional[str] = None) -> Tuple[bool, str, Dict[str, Any]]:
        """
        Envía un mensaje y devuelve (ok, texto_respuesta, raw_json).
        Si se pasa conversation_id, se sobreescribe el del payload_template.
        """
        payload = build_payload(self.send_message["payload_template"], user_msg)
        if conversation_id and isinstance(payload, dict) and "conversation" in payload:
            payload["conversation"] = conversation_id

        method = self.send_message.get("method", "POST").upper()

        try:
            response = self.session.request(
                method=method,
                url=self.url,
                headers=self.headers,
                json=payload,
                timeout=self.timeout,
            )
            response.raise_for_status()
            data = response.json()
        except requests.exceptions.RequestException as exc:
            return False, f"[ERROR HTTP] {exc}", {}
        except ValueError as exc:
            return False, f"[ERROR JSON] {exc}", {}

        try:
            raw_text = extract_by_path(data, self.response_path)
        except (KeyError, IndexError, TypeError, ValueError) as exc:
            return False, f"[ERROR response_path '{self.response_path}'] {exc}", data

        return True, strip_html(raw_text), data


# --------------------------------------------------------------------------
# Main
# --------------------------------------------------------------------------
def parse_args() -> argparse.Namespace:
    parser = argparse.ArgumentParser(description="Envía varios mensajes a un chatbot vía connector YAML.")
    parser.add_argument("--connector", default=DEFAULT_CONNECTOR, help="Ruta al YAML del connector.")
    parser.add_argument("--messages", nargs="*", help="Lista de mensajes a enviar.")
    parser.add_argument("--interactive", action="store_true", help="Modo interactivo por consola.")
    parser.add_argument("--delay", type=float, default=1.0, help="Segundos entre mensajes (default: 1.0).")
    parser.add_argument("--new-conversation", action="store_true",
                        help="Genera una conversación nueva por cada mensaje.")
    parser.add_argument("--log", default="conversation_log.json", help="Fichero JSON de log.")
    return parser.parse_args()


def main() -> int:
    args = parse_args()

    try:
        config = load_connector(args.connector)
    except (FileNotFoundError, ValueError, yaml.YAMLError) as exc:
        print(f"❌ {exc}")
        return 1

    bot = YamlChatbot(config)
    print(f"🤖 Connector: {config.get('name', 'unnamed')}")
    print(f"🔗 Endpoint:  {bot.url}\n")

    # Conversación base (se reutiliza salvo --new-conversation)
    base_conversation = (config["send_message"]["payload_template"] or {}).get("conversation")
    if not base_conversation:
        base_conversation = bot.new_conversation_id()
        print(f"ℹ️  Sin 'conversation' en el template; usando {base_conversation}\n")

    log: List[Dict[str, Any]] = []

    def handle(user_msg: str) -> None:
        conversation_id = bot.new_conversation_id() if args.new_conversation else base_conversation
        ok, reply, raw = bot.send(user_msg, conversation_id=conversation_id)

        print(f"👤 Usuario: {user_msg}")
        if ok:
            print(f"🤖 Bot:     {reply}\n")
        else:
            print(f"⚠️  {reply}\n")

        log.append({
            "conversation": conversation_id,
            "user": user_msg,
            "ok": ok,
            "bot": reply,
            "raw": raw,
        })

    try:
        if args.interactive:
            print("Modo interactivo. Escribe 'salir' para terminar.\n")
            while True:
                try:
                    user_msg = input("👤 > ").strip()
                except (EOFError, KeyboardInterrupt):
                    print("\n👋 Saliendo...")
                    break
                if user_msg.lower() in {"salir", "exit", "quit"}:
                    break
                if not user_msg:
                    continue
                handle(user_msg)
        else:
            messages = args.messages or [
                "hola",
                "¿Qué servicios ofrece el SAIC?",
                "¿Cuál es el horario de atención?",
                "¿Dónde está la oficina?",
                "gracias",
            ]
            for i, user_msg in enumerate(messages):
                handle(user_msg)
                if i < len(messages) - 1 and args.delay > 0:
                    time.sleep(args.delay)
    finally:
        if log:
            Path(args.log).write_text(
                json.dumps(log, ensure_ascii=False, indent=2), encoding="utf-8"
            )
            print(f"💾 Log guardado en {args.log} ({len(log)} mensajes)")

    return 0


if __name__ == "__main__":
    sys.exit(main())
```

### Detalles que conviene tener en cuenta

- **`conversation`**: el ID de tu captura (`6977595c744ccf01954b8797`) se reutiliza para todos los mensajes, así el bot mantiene el contexto. Con `--new-conversation` cada mensaje arranca un hilo limpio (útil para tests independientes).
- **`response_path: "response.0.text"`**: si el bot devolviera varios bloques en `response`, solo se toma el primero. Si quieres concatenarlos todos, dímelo y te ajusto el extractor.
- **HTML**: la respuesta viene con `<p>` y `<br>`, así que el script lo limpia a texto plano.
- **Token**: el `Authorization` está en el YAML; si lo vas a versionar en git, mejor muévelo a una variable de entorno y sustituirlo al cargar.
