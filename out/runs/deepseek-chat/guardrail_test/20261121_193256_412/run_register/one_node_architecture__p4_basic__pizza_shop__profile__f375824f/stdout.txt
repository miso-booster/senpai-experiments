**Key validation rules to bake into your generator** (so the LLM doesn't produce invalid profiles):
- Every `{{variable}}` in a goal string **must** be declared in `goals` with the exact same name (case-sensitive).
- `random(n)` requires `n ≤ len(data)`.
- `combinations` requires **at least two** nested `forward()` or `pairwise()` variables.
- `list`, `time`, `date` types are valid in `chatbot.output` but **not** in `user.goals`.
- Custom types must exist in `types/` and match the file name.
