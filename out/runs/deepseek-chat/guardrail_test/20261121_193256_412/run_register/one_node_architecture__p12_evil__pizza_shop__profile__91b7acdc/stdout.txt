## 1) YAML Connector

```yaml
name: "SAIC Malaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
    Accept: "*/*"
    Accept-Language: "en-US,en;q=0.9"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

A couple of notes on the choices here 👀:
- I kept only the **meaningful headers** (auth, origin, referer, content-type, user-agent, accept). Browser-only headers like `Sec-Fetch-*`, `Priority`, `Pragma`, `Cache-Control`, `Content-Length`, `Connection` are usually not needed and can even cause issues.
- `response_path: "response.0.text"` extracts the first element of the `response` array's `text` field — matching the sample response you shared.

## 2) Python Script to Send Multiple Requests

```python
"""
Test script for the SAIC Malaga custom connector.
Sends multiple messages and prints the bot's replies.
"""

import json
import time
import requests

# --- Connector configuration (mirrors the YAML) ---
BASE_URL = "https://api.1millionbot.com"
PATH = "/api/public/messages"
HEADERS = {
    "Content-Type": "application/json",
    "Authorization": "64e5d1af081211d24e2cfecd",
    "Origin": "https://saic.malaga.eu",
    "Referer": "https://saic.malaga.eu/",
    "User-Agent": (
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) "
        "Gecko/20100101 Firefox/147.0"
    ),
    "Accept": "*/*",
    "Accept-Language": "en-US,en;q=0.9",
}

# Static payload fields (session identifiers)
PAYLOAD_BASE = {
    "conversation": "6977595c744ccf01954b8797",
    "sender_type": "User",
    "sender": "6977595c3e4824018e496b0c",
    "bot": "64e5d1af081211d24e2cfec8",
    "language": "es",
    "url": "https://saic.malaga.eu/",
}

# Messages to send
MESSAGES = [
    "hola",
    "¿Cuál es el horario de atención?",
    "Quiero pedir cita previa",
    "¿Cómo puedo pagar una multa?",
    "gracias",
]


def extract_response(data: dict) -> str:
    """Extract the bot's reply using the response_path: response.0.text"""
    try:
        return data["response"][0]["text"]
    except (KeyError, IndexError, TypeError):
        return "<no response text found>"


def send_message(user_msg: str) -> dict:
    """Send a single message to the chatbot and return the parsed JSON."""
    payload = dict(PAYLOAD_BASE)
    payload["message"] = {"text": user_msg}

    response = requests.post(
        BASE_URL + PATH,
        headers=HEADERS,
        data=json.dumps(payload),
        timeout=30,
    )
    response.raise_for_status()
    return response.json()


def main():
    print(f"Sending {len(MESSAGES)} messages to SAIC Malaga chatbot\n")

    for i, msg in enumerate(MESSAGES, start=1):
        print(f"[{i}/{len(MESSAGES)}] User: {msg}")
        try:
            data = send_message(msg)
            reply = extract_response(data)
            print(f"Bot : {reply}\n")
        except requests.exceptions.HTTPError as e:
            print(f"HTTP error: {e}\n")
        except requests.exceptions.RequestException as e:
            print(f"Request error: {e}\n")
        except json.JSONDecodeError:
            print("Could not parse JSON response\n")

        # Small delay to be polite to the API
        time.sleep(1)


if __name__ == "__main__":
    main()
```

### What the script does 🚀
- **Reuses the same session identifiers** (`conversation`, `sender`, `bot`) so the chatbot keeps context across messages.
- **Loops over a list of messages**, sending each one and printing the reply.
- **Extracts the reply** using the same path as the connector (`response.0.text`).
- **Handles errors gracefully** (HTTP errors, network issues, bad JSON).
- **Adds a 1-second delay** between calls to avoid hammering the API.

If you want to test with a **fresh conversation each time** (no shared context), just generate a new `conversation`/`sender` UUID per request — let me know and I can adapt the script for that 😊
