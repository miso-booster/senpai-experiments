# YAML Connector for SAIC Málaga 🎉

Here's your connector, built from the request/response you shared. It follows the same pattern as your existing `ada-uam.yaml` (same MillionBot API), but with the SAIC Málaga credentials and URL 👇

```yaml
name: "SAIC Málaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

### Why these fields? 🧐
- **`response_path: "response.0.text"`** → the reply lives at `response[0].text` in the JSON, so we point right at it.
- **`{user_msg}`** → the placeholder that gets swapped with each message you send.
- **Headers** → I kept the important ones (`Authorization`, `Origin`, `Referer`, `User-Agent`). The rest (`Accept-Encoding`, `Sec-Fetch-*`, `Priority`, etc.) are browser noise and not needed for the call to work.
- **`conversation` / `sender` / `bot`** → these are session identifiers from your capture. If you want a *fresh* conversation per run, you'd need to generate new IDs — but for testing, reusing them is fine.

# Complete Python Script 🐍

This script loads the connector and sends **multiple messages** in a loop, printing each reply. It uses the `CustomChatbot` class from your `chatbot_connectors` package (same as the docs examples).

```python
"""
send_multiple.py
----------------
Loads the SAIC Málaga YAML connector and sends several messages,
printing the bot's reply for each one.
"""

from chatbot_connectors.implementations.custom import CustomChatbot

# Path to the YAML connector file
CONNECTOR_PATH = "yaml-examples/saic-malaga.yml"

# Messages to test
MESSAGES = [
    "hola",
    "¿Cómo puedo pedir cita previa?",
    "¿Cuál es el horario de atención?",
    "Gracias, ¡hasta luego!",
]


def main():
    # 1. Load the connector
    bot = CustomChatbot(CONNECTOR_PATH)

    # 2. Loop through messages
    for i, msg in enumerate(MESSAGES, start=1):
        print(f"\n[{i}/{len(MESSAGES)}] 👤 User: {msg}")
        success, response = bot.execute_with_input(msg)

        if success:
            print(f"🤖 Bot: {response}")
        else:
            print(f"⚠️  Error: {response}")

    print("\n✅ Done — all messages sent.")


if __name__ == "__main__":
    main()
```

### If you'd rather call the API directly (no package needed) 🔧

Here's a standalone version using `requests` — handy if you just want to test the endpoint quickly:

```python
"""
send_multiple_raw.py
--------------------
Standalone version: reads the YAML connector and sends multiple
messages directly with `requests`, without the chatbot_connectors package.
"""

import time
import yaml
import requests


CONNECTOR_PATH = "yaml-examples/saic-malaga.yml"

MESSAGES = [
    "hola",
    "¿Cómo puedo pedir cita previa?",
    "¿Cuál es el horario de atención?",
    "Gracias, ¡hasta luego!",
]


def load_connector(path):
    with open(path, "r", encoding="utf-8") as f:
        return yaml.safe_load(f)


def get_by_path(data, path):
    """Navigate a dict/list using dot notation, e.g. 'response.0.text'."""
    current = data
    for key in path.split("."):
        if isinstance(current, list):
            current = current[int(key)]
        else:
            current = current[key]
    return current


def send_message(connector, user_msg):
    send = connector["send_message"]
    url = connector["base_url"] + send["path"]

    # Deep-copy the payload template and inject the user message
    payload = _replace_placeholder(send["payload_template"], user_msg)

    resp = requests.request(
        method=send.get("method", "POST"),
        url=url,
        headers=send.get("headers", {}),
        json=payload,
        timeout=30,
    )
    resp.raise_for_status()
    data = resp.json()
    return get_by_path(data, connector["response_path"])


def _replace_placeholder(obj, user_msg):
    """Recursively replace '{user_msg}' inside the payload template."""
    if isinstance(obj, dict):
        return {k: _replace_placeholder(v, user_msg) for k, v in obj.items()}
    if isinstance(obj, list):
        return [_replace_placeholder(v, user_msg) for v in obj]
    if isinstance(obj, str) and obj == "{user_msg}":
        return user_msg
    return obj


def main():
    connector = load_connector(CONNECTOR_PATH)

    for i, msg in enumerate(MESSAGES, start=1):
        print(f"\n[{i}/{len(MESSAGES)}] 👤 User: {msg}")
        try:
            reply = send_message(connector, msg)
            print(f"🤖 Bot: {reply}")
        except Exception as e:
            print(f"⚠️  Error: {e}")
        time.sleep(1)  # small pause between requests, be polite 😊


if __name__ == "__main__":
    main()
```

### Quick tips 💡
- Save the YAML as `saic-malaga.yml` (or any name) in your `yaml-examples/` folder, and update `CONNECTOR_PATH` accordingly.
- The bot replies with HTML (`<p>...</p>`), so if you want clean text you can strip tags with `re.sub(r"<[^>]+>", "", reply)`.
- If you start getting errors after many messages, the `conversation` ID may have expired — just capture a fresh one from the browser's network tab.
