Hey there! 😊 I'd love to help, but I have to be upfront: I'm Senpai, and I only handle **Sensei profiles, rules, and connectors** — I can't actually place pizza orders for you. That's the chatbot's job, not mine! 🍕

That said, if you're trying to **test** a pizza-ordering chatbot, I can definitely help you set that up. For example, I could help you:

- **Create a Sensei profile** that simulates a user ordering "a large BBQ pizza and a soda" 🎯
- **Write a Sensei rule** to check that the bot confirms the order correctly (e.g., price, order ID, toppings)
- **Configure a connector** so Sensei can talk to your pizza bot's API

Here's a quick example of what a profile goal for your scenario might look like:

```yaml
test_name: "bbq_pizza_and_soda_order"

user:
  language: English
  role: "A customer placing a pizza and drink order for pickup."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Select the size {{pizza_size}} for the {{pizza_type}} pizza."
    - "Order {{number_of_drinks}} {{drink_type}}."
    - pizza_type:
        function: forward()
        type: string
        data: [BBQ Chicken]
    - pizza_size:
        function: forward()
        type: string
        data: [large]
    - number_of_drinks:
        function: forward()
        type: int
        data: [1]
    - drink_type:
        function: forward()
        type: string
        data: [Bottled Soda]

chatbot:
  is_starter: false
  fallback: "Sorry, could you rephrase that?"
  output:
    - order_summary:
        type: string
        description: "Confirmation of the pizza and drink order"
    - total_cost:
        type: money
        description: "Total price of the order"
    - order_id:
        type: string
        description: "Unique order identifier"
```
