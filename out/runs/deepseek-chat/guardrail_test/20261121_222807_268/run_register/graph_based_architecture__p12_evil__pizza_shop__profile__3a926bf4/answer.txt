# YAML Connector for SAIC Málaga 🚀

Here's the YAML connector based on your request. I've mapped the headers, payload, and response path from the HTTP trace you shared:

```yaml
name: "SAIC Malaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
    Accept: "*/*"
    Accept-Language: "en-US,en;q=0.9"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

### Why these values? 🤔
- **`base_url` + `path`** → `https://api.1millionbot.com` + `/api/public/messages` (matches the `Host` + request line).
- **`Authorization`** → taken straight from your header (`64e5d1af081211d24e2cfecd`).
- **`payload_template`** → mirrors your JSON body exactly, with `{user_msg}` replacing the `"hola"` text so you can inject any message.
- **`response_path`** → `response.0.text` navigates to `response[0]["text"]`, which is the bot's reply (`"<p>¡Buenos días!..."`).

> 💡 Tip: The response text contains HTML (`<p>`, `<br>`). If you want plain text, you may want to strip tags in your script (shown below).

# Python Script to Send Multiple Requests 🐍

This script uses the `CustomChatbot` class from your connector framework and sends several messages in a loop:

```python
from chatbot_connectors.implementations.custom import CustomChatbot
import re

# Path to the YAML connector file
CONNECTOR_PATH = "saic-malaga.yml"

# List of messages to send
messages = [
    "hola",
    "¿Cómo puedo renovar mi cita?",
    "Necesito información sobre el padrón",
    "¿Cuál es el horario de atención?",
    "Gracias, ¡hasta luego!",
]

def strip_html(text: str) -> str:
    """Remove HTML tags and unescape basic entities for cleaner output."""
    text = re.sub(r"<br\s*/?>", "\n", text)
    text = re.sub(r"<[^>]+>", "", text)
    return text.strip()

def main():
    bot = CustomChatbot(CONNECTOR_PATH)

    for i, msg in enumerate(messages, start=1):
        print(f"\n--- Request #{i} ---")
        print(f"👤 User: {msg}")

        success, response = bot.execute_with_input(msg)

        if success:
            clean = strip_html(response) if isinstance(response, str) else response
            print(f"🤖 Bot : {clean}")
        else:
            print(f"⚠️  Error: {response}")

if __name__ == "__main__":
    main()
```

### What this script does ✨
1. **Loads** the YAML connector via `CustomChatbot`.
2. **Iterates** over a list of messages, sending each one through `execute_with_input()`.
3. **Cleans** the HTML tags from the bot's reply so the console output is readable.
4. **Handles errors** gracefully — if `success` is `False`, it prints the error instead of crashing.

### Expected output (roughly) 🎯

### ⚠️ A couple of friendly notes
- **Session state**: The `conversation`, `sender`, and `bot` IDs are fixed in the YAML. If the API expects a *new* conversation per session, you'd need to generate those dynamically — but that goes beyond the YAML connector's static template. Let me know if you want to explore that! 😊
- **File location**: Save the YAML as `saic-malaga.yml` (or any name you like) in your `connectors` folder, and update `CONNECTOR_PATH` in the script accordingly.
