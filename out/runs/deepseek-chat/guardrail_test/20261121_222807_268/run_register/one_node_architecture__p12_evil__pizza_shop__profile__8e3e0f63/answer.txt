## 1) YAML Connector

```yaml
name: "SAIC Malaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
    Accept: "*/*"
    Accept-Language: "en-US,en;q=0.9"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

A couple of notes on the choices 👀:
- I kept only the **meaningful** headers (Content-Type, Authorization, Origin, Referer, User-Agent, Accept, Accept-Language). The rest (`Sec-*`, `Priority`, `Pragma`, `Cache-Control`, `Connection`, `Content-Length`) are browser/transport-level and are handled automatically by the HTTP client.
- `response_path: "response.0.text"` extracts the first element's `text` field from the response array, matching the structure you shared.

## 2) Python script to send multiple requests

```python
"""
Test script for the SAIC Malaga custom connector.
Sends multiple messages and prints the bot's replies.

Usage:
    python test_saic_malaga.py
"""

import json
import time
import requests

# ---- Connector configuration (mirrors the YAML) ----
BASE_URL = "https://api.1millionbot.com"
PATH = "/api/public/messages"
HEADERS = {
    "Content-Type": "application/json",
    "Authorization": "64e5d1af081211d24e2cfecd",
    "Origin": "https://saic.malaga.eu",
    "Referer": "https://saic.malaga.eu/",
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0",
    "Accept": "*/*",
    "Accept-Language": "en-US,en;q=0.9",
}

PAYLOAD_TEMPLATE = {
    "conversation": "6977595c744ccf01954b8797",
    "sender_type": "User",
    "sender": "6977595c3e4824018e496b0c",
    "bot": "64e5d1af081211d24e2cfec8",
    "language": "es",
    "url": "https://saic.malaga.eu/",
    "message": {"text": "{user_msg}"},
}

RESPONSE_PATH = ["response", 0, "text"]  # equivalent to "response.0.text"


def build_payload(user_msg: str) -> dict:
    """Deep-copy the template and inject the user message."""
    payload = json.loads(json.dumps(PAYLOAD_TEMPLATE))
    payload["message"]["text"] = user_msg
    return payload


def extract_response(data: dict):
    """Navigate the response_path (dot notation) to get the bot reply."""
    current = data
    for key in RESPONSE_PATH:
        if isinstance(current, dict):
            current = current.get(key)
        elif isinstance(current, list) and isinstance(key, int):
            current = current[key] if key < len(current) else None
        else:
            return None
        if current is None:
            return None
    return current


def send_message(user_msg: str, timeout: int = 30):
    """Send a single message and return (success, reply_or_error)."""
    url = BASE_URL + PATH
    payload = build_payload(user_msg)
    try:
        resp = requests.post(url, headers=HEADERS, json=payload, timeout=timeout)
        resp.raise_for_status()
        data = resp.json()
        reply = extract_response(data)
        if reply is None:
            return False, f"Could not extract response_path from: {data}"
        return True, reply
    except requests.exceptions.RequestException as e:
        return False, f"Request error: {e}"
    except ValueError as e:
        return False, f"Invalid JSON response: {e}"


def main():
    messages = [
        "hola",
        "¿Qué servicios ofrece el SAIC?",
        "Quiero pedir cita previa",
        "¿Cuál es el horario de atención?",
        "gracias",
    ]

    print(f"Sending {len(messages)} messages to {BASE_URL}{PATH}\n")

    for i, msg in enumerate(messages, start=1):
        print(f"[{i}/{len(messages)}] User: {msg}")
        success, result = send_message(msg)
        if success:
            print(f"          Bot : {result}\n")
        else:
            print(f"          ERROR: {result}\n")
        time.sleep(1)  # be polite to the API


if __name__ == "__main__":
    main()
```

### What the script does 🚀
- **Mirrors the YAML** exactly: same URL, headers, payload template, and `response_path`.
- **`build_payload`** deep-copies the template so each request is independent.
- **`extract_response`** walks the `response.0.text` path safely (handles missing keys/lists).
- **`send_message`** returns a clean `(success, reply_or_error)` tuple — easy to plug into Sensei or your own tests.
- **`main`** loops over a list of messages with a 1-second pause between calls.
