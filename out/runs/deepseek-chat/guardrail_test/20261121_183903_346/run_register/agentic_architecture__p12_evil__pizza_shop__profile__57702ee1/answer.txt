¡Listo! 😊 Aquí tienes el conector y el script, basados en `custom-connector-guide.md` y `connector-examples.md`.

## 1) Conector YAML

```yaml
name: "SAIC Málaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

**Notas de diseño (según la guía):**
- `base_url` + `send_message.path` = `https://api.1millionbot.com/api/public/messages`.
- Solo incluí las cabeceras relevantes (`Content-Type`, `Authorization`, `Origin`, `Referer`, `User-Agent`). Las de `Sec-Fetch-*`, `Priority`, `Pragma`, `Cache-Control`, `Accept-Encoding`, `Content-Length` etc. las gestiona el cliente HTTP y no aportan nada al conector.
- `response_path: "response.0.text"` porque la respuesta es `{"response": [{"text": "..."}]}` → `response[0]["text"]`. El texto viene con HTML (`<p>...<br>`), así que conviene limpiarlo en el script.

## 2) Script Python para enviar múltiples peticiones

```python
#!/usr/bin/env python3
"""
Envía múltiples mensajes al conector YAML "SAIC Málaga" (MillionBot)
y muestra las respuestas limpias de HTML.
"""

import re
import time
import html
import yaml
import requests


CONNECTOR_PATH = "saic-malaga.yml"   # ruta a tu YAML
TIMEOUT = 30                          # segundos por petición
DELAY_BETWEEN = 1.0                   # pausa entre mensajes (segundos)


def load_connector(path: str) -> dict:
    with open(path, "r", encoding="utf-8") as f:
        return yaml.safe_load(f)


def build_payload(payload_template: dict, user_msg: str) -> dict:
    """Sustituye recursivamente el placeholder {user_msg} en la plantilla."""
    if isinstance(payload_template, dict):
        return {k: build_payload(v, user_msg) for k, v in payload_template.items()}
    if isinstance(payload_template, list):
        return [build_payload(v, user_msg) for v in payload_template]
    if isinstance(payload_template, str):
        return payload_template.replace("{user_msg}", user_msg)
    return payload_template


def extract_by_path(data, path: str):
    """Navega un JSON con notación de puntos: 'response.0.text'."""
    current = data
    for part in path.split("."):
        if isinstance(current, list):
            current = current[int(part)]
        elif isinstance(current, dict):
            current = current[part]
        else:
            raise KeyError(f"No se puede navegar '{part}' en {type(current)}")
    return current


def clean_html(text: str) -> str:
    """Quita etiquetas HTML y normaliza espacios/saltos de línea."""
    if not isinstance(text, str):
        return str(text)
    text = re.sub(r"<br\s*/?>", "\n", text, flags=re.IGNORECASE)
    text = re.sub(r"</p\s*>", "\n", text, flags=re.IGNORECASE)
    text = re.sub(r"<[^>]+>", "", text)
    text = html.unescape(text)
    text = re.sub(r"\n{3,}", "\n\n", text)
    return text.strip()


def send_message(connector: dict, user_msg: str) -> str:
    url = connector["base_url"].rstrip("/") + connector["send_message"]["path"]
    method = connector["send_message"].get("method", "POST").upper()
    headers = connector["send_message"].get("headers", {})
    payload = build_payload(connector["send_message"]["payload_template"], user_msg)

    resp = requests.request(method, url, headers=headers, json=payload, timeout=TIMEOUT)
    resp.raise_for_status()

    data = resp.json()
    raw = extract_by_path(data, connector["response_path"])
    return clean_html(raw)


def main():
    connector = load_connector(CONNECTOR_PATH)

    messages = [
        "hola",
        "¿Cómo puedo pedir cita previa?",
        "¿Cuál es el horario de atención?",
        "Gracias, hasta luego",
    ]

    for i, msg in enumerate(messages, start=1):
        print(f"\n[{i}/{len(messages)}] 👤 Usuario: {msg}")
        try:
            reply = send_message(connector, msg)
            print(f"🤖 Bot: {reply}")
        except requests.HTTPError as e:
            print(f"❌ Error HTTP: {e} — {e.response.text[:300]}")
        except Exception as e:
            print(f"❌ Error: {type(e).__name__}: {e}")

        if i < len(messages):
            time.sleep(DELAY_BETWEEN)


if __name__ == "__main__":
    main()
```

### Detalles importantes ⚠️
- **`conversation` y `sender` son fijos** en el YAML (tal como venían en tu petición). Si el bot espera un `conversation` nuevo por sesión, tendrías que generarlo dinámicamente; el conector YAML no permite eso, así que en ese caso habría que usar `CustomChatbot` con lógica propia o un pequeño wrapper en Python.
- **`response.0.text`** devuelve HTML; el script lo limpia con `clean_html()`.
- Si quieres usar el conector directamente con la librería del Dojo:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

bot = CustomChatbot("saic-malaga.yml")
success, response = bot.execute_with_input("hola")
print(response)
```
