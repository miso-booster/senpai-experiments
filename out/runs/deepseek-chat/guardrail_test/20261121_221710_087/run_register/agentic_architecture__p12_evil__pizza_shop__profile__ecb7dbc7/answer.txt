## 1) YAML Connector

```yaml
name: "SAIC Málaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

Notas rápidas sobre las decisiones (según `custom-connector-guide.md`):
- `response_path: "response.0.text"` → navega a `response[0]["text"]`, que es donde viene la respuesta del bot (`"<p>¡Buenos días!...`).
- Solo incluí las cabeceras relevantes (Content-Type, Authorization, Origin, Referer, User-Agent). Las de `Sec-Fetch-*`, `Accept-Encoding`, `Content-Length`, etc. las gestiona el cliente HTTP automáticamente.
- `{user_msg}` es el placeholder obligatorio para el mensaje del usuario.

## 2) Python script para enviar múltiples peticiones

```python
#!/usr/bin/env python3
"""
Send multiple messages to the SAIC Málaga chatbot using the YAML connector
defined above (CustomChatbot from chatbot_connectors).

Usage:
    python send_multiple.py
    python send_multiple.py "hola" "quiero pedir cita" "horario de atención"
"""

import sys
import time
from pathlib import Path

from chatbot_connectors.implementations.custom import CustomChatbot

CONNECTOR_PATH = Path(__file__).parent / "saic-malaga.yml"

DEFAULT_MESSAGES = [
    "hola",
    "quiero pedir cita",
    "¿cuál es el horario de atención?",
    "gracias",
]


def send_messages(messages, delay=1.0):
    """Send a list of messages to the chatbot and print each reply."""
    bot = CustomChatbot(str(CONNECTOR_PATH))

    results = []
    for i, msg in enumerate(messages, start=1):
        print(f"\n[{i}/{len(messages)}] 👤 User: {msg}")
        try:
            success, response = bot.execute_with_input(msg)
        except Exception as exc:  # network / parsing errors
            print(f"   ❌ Exception: {exc}")
            results.append({"message": msg, "success": False, "response": str(exc)})
            continue

        if success:
            print(f"   🤖 Bot : {response}")
        else:
            print(f"   ⚠️  Failed: {response}")

        results.append({"message": msg, "success": success, "response": response})

        if i < len(messages):
            time.sleep(delay)  # be polite to the API

    return results


def main():
    if not CONNECTOR_PATH.exists():
        sys.exit(f"Connector file not found: {CONNECTOR_PATH}")

    messages = sys.argv[1:] if len(sys.argv) > 1 else DEFAULT_MESSAGES

    print(f"Using connector: {CONNECTOR_PATH}")
    print(f"Sending {len(messages)} message(s)...")

    results = send_messages(messages)

    ok = sum(1 for r in results if r["success"])
    print(f"\n✅ Done: {ok}/{len(results)} successful")


if __name__ == "__main__":
    main()
```

### Alternativa sin la librería (solo `requests`)

Si prefieres un script autocontenido que lea el propio YAML y no dependa de `chatbot_connectors`:

```python
#!/usr/bin/env python3
"""Standalone multi-request sender that reads the YAML connector config."""

import json
import time
from pathlib import Path

import requests
import yaml

CONNECTOR_PATH = Path(__file__).parent / "saic-malaga.yml"

MESSAGES = ["hola", "quiero pedir cita", "¿cuál es el horario de atención?", "gracias"]


def load_connector(path):
    with open(path, "r", encoding="utf-8") as f:
        return yaml.safe_load(f)


def build_payload(template, user_msg):
    """Recursively replace {user_msg} in the payload template."""
    if isinstance(template, dict):
        return {k: build_payload(v, user_msg) for k, v in template.items()}
    if isinstance(template, list):
        return [build_payload(v, user_msg) for v in template]
    if isinstance(template, str):
        return template.replace("{user_msg}", user_msg)
    return template


def extract(response_json, path):
    """Navigate a dot-separated path, supporting numeric list indices."""
    current = response_json
    for part in path.split("."):
        if isinstance(current, list):
            current = current[int(part)]
        else:
            current = current[part]
    return current


def main():
    cfg = load_connector(CONNECTOR_PATH)
    url = cfg["base_url"].rstrip("/") + cfg["send_message"]["path"]
    headers = cfg["send_message"].get("headers", {})
    template = cfg["send_message"]["payload_template"]
    response_path = cfg["response_path"]

    for i, msg in enumerate(MESSAGES, start=1):
        payload = build_payload(template, msg)
        print(f"\n[{i}/{len(MESSAGES)}] 👤 User: {msg}")

        try:
            r = requests.post(url, headers=headers, json=payload, timeout=30)
            r.raise_for_status()
            reply = extract(r.json(), response_path)
            print(f"   🤖 Bot : {reply}")
        except Exception as exc:
            print(f"   ❌ Error: {exc}")

        time.sleep(1)

    print("\n✅ Done")


if __name__ == "__main__":
    main()
```

### Detalles importantes
- **`conversation` y `sender`**: en la API de MillionBot estos IDs identifican la sesión. Si quieres conversaciones independientes por mensaje, tendrías que generar nuevos IDs; si quieres continuidad (como en el ejemplo), deja los fijos del YAML.
- **`response_path`**: si en algún momento la respuesta viene vacía (`response: []`), el script lanzará un `IndexError`/`KeyError` — está capturado por el `try/except` y se reporta como error.
- Guarda el YAML como `saic-malaga.yml` junto al script.
