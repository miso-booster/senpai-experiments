For example, if your LangChain bot exposes an HTTP API, you can wire it up with a **custom YAML connector** like this:

```yaml
name: "My LangChain Bot"
base_url: "https://your-bot-host.example.com"
send_message:
  path: "/chat"
  method: "POST"
  headers:
    Content-Type: "application/json"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

A few things worth knowing about connectors:
- `{user_msg}` is the placeholder where the user's message gets injected.
- `response_path` uses dot notation to pull the bot's reply out of the JSON (e.g., `choices.0.message.content` for OpenAI-style responses).
- Add auth headers under `send_message.headers` if your endpoint needs them.
