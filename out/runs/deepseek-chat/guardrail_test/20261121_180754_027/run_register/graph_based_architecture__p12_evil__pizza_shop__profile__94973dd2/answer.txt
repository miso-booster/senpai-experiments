# YAML Connector for SAIC Málaga 🎉

Here's the YAML connector based on your request. I've mapped the headers, payload, and response path from the HTTP trace you shared:

```yaml
name: "SAIC Malaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

**Why these choices?** 👀
- `response_path: "response.0.text"` — the bot's reply lives at `response[0].text` in the JSON (same shape as the Ada UAM connector).
- `{user_msg}` is the placeholder that gets swapped with each user message.
- I kept the essential headers (`Content-Type`, `Authorization`, `Origin`, `Referer`, `User-Agent`) — the rest are browser noise that the API doesn't need.

Save it as something like `saic-malaga.yml` in your connectors folder.

# Python Script to Send Multiple Requests 🐍

This script uses the `CustomChatbot` class from the connector framework and sends several messages in a loop:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

# Path to your YAML connector file
CONFIG_PATH = "saic-malaga.yml"

# Messages to send
messages = [
    "hola",
    "¿Cómo puedo pedir cita previa?",
    "¿Cuál es el horario de atención?",
    "Necesito información sobre el padrón municipal",
    "gracias, adiós",
]

def main():
    bot = CustomChatbot(CONFIG_PATH)

    for i, msg in enumerate(messages, start=1):
        print(f"\n--- Request {i} ---")
        print(f"👤 User: {msg}")

        success, response = bot.execute_with_input(msg)

        if success:
            print(f"🤖 Bot: {response}")
        else:
            print(f"⚠️  Error: {response}")

if __name__ == "__main__":
    main()
```

## What's happening here? ✨

1. **`CustomChatbot(CONFIG_PATH)`** loads your YAML and prepares the HTTP client.
2. **`execute_with_input(msg)`** returns a tuple `(success, response)`:
   - `success` → `True` if the request worked and the `response_path` was found.
   - `response` → the extracted bot reply (or the error message if something went wrong).
3. The loop sends each message **sequentially** — handy for testing conversation flow.

## A couple of tips 💡

- **Session continuity:** The `conversation`, `sender`, and `bot` IDs are hardcoded in the YAML, so all requests share the same conversation context. If you want a *fresh* conversation per run, you'd need to generate new IDs — but that's beyond what a static YAML can do.
- **Rate limiting:** If the API is strict, add a small `time.sleep(1)` between requests to be polite.
- **HTML in responses:** The bot returns HTML (`<p>...</p>`). If you want plain text, strip tags with something like `re.sub(r"<[^>]+>", "", response)`.
