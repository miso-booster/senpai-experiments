I'll create the connector YAML for the SAIC Málaga bot, then a Python script that exercises it with multiple messages 😊

## 1) Connector YAML

```yaml
name: "SAIC Malaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
    Accept: "*/*"
    Accept-Language: "en-US,en;q=0.9"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

A couple of notes 👀:
- `response_path: "response.0.text"` targets the first element of the `response` array — that's where the bot's reply lives in your sample.
- The reply text comes wrapped in HTML (`<p>...</p>`), so the script below strips tags for readability.

## 2) Python script to send multiple requests

```python
"""
Send multiple messages to the SAIC Malaga chatbot via the custom YAML connector.
Usage:
    python send_multiple.py
"""

import re
import time
from chatbot_connectors.implementations.custom import CustomChatbot

CONNECTOR_PATH = "connectors/saic-malaga.yaml"

MESSAGES = [
    "hola",
    "¿Qué trámites puedo hacer aquí?",
    "Necesito pedir cita previa",
    "¿Cuál es el horario de atención?",
    "gracias, adiós",
]

# Small pause between requests to be polite to the API
DELAY_SECONDS = 1.0


def strip_html(text: str) -> str:
    """Remove HTML tags and collapse whitespace for readable output."""
    if not isinstance(text, str):
        return str(text)
    text = re.sub(r"<br\s*/?>", "\n", text, flags=re.IGNORECASE)
    text = re.sub(r"<[^>]+>", "", text)
    return re.sub(r"\n{3,}", "\n\n", text).strip()


def main() -> None:
    bot = CustomChatbot(CONNECTOR_PATH)

    print(f"Connector: {CONNECTOR_PATH}")
    print(f"Sending {len(MESSAGES)} messages...\n")

    for i, msg in enumerate(MESSAGES, start=1):
        print(f"[{i}/{len(MESSAGES)}] USER: {msg}")
        try:
            success, response = bot.execute_with_input(msg)
        except Exception as exc:  # noqa: BLE001
            print(f"  ⚠️  Exception: {exc}\n")
            continue

        if success:
            print(f"  BOT : {strip_html(response)}\n")
        else:
            print(f"  ⚠️  Request failed. Raw response: {response}\n")

        time.sleep(DELAY_SECONDS)

    print("Done ✅")


if __name__ == "__main__":
    main()
```

### How it works
- **`CustomChatbot(CONNECTOR_PATH)`** loads your YAML and handles the HTTP call, payload templating (`{user_msg}`), and `response_path` extraction.
- **`execute_with_input(msg)`** returns `(success, response)` — `success` is a boolean, `response` is the extracted bot reply.
- **`strip_html`** cleans up the `<p>`/`<br>` tags so the console output is readable.
- **`DELAY_SECONDS`** keeps the requests gentle on the API.
