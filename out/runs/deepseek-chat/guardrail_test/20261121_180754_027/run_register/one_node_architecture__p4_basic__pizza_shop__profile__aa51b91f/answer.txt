### 🧩 LLM prompt template (paste into your script)

```
You are a Sensei profile generator. Output ONLY a single valid YAML document
(no markdown, no commentary) following this exact schema:

test_name: <string>
llm:
  temperature: <float 0-1>
  model: <string>
  model_prov: <string>
  format:
    type: text
user:
  language: <string>
  role: <string>
  context:
    - <string>
  goals:
    - <goal string with {{variables}}>
    - <variable_name>:
        function: default|random|random(n)|another|another(n)|forward|pairwise
        type: string|int|float|<custom_type_name>
        data: <list | {min,max,step} | any("<instruction>")>
chatbot:
  is_starter: true|false
  fallback: <string>
  output:
    - <field_name>:
        type: int|float|string|money|time|date|list[<type>]|<custom>
        description: <string>
conversation:
  number: <int> | combinations | combinations(<fraction>, pairwise)
  goal_style:
    steps: <int> | random steps: <int> | all_answered: {export: bool, limit: int}
  interaction_style:
    - <style keyword>

Rules:
- Every {{variable}} in goals MUST be declared as a variable entry in goals.
- Use only these interaction_style keywords: long phrases, change your mind,
  change language: [<languages>], make spelling mistakes, single questions,
  all questions, default, random: [<styles>].
- Do NOT use list/time/date types in user.goals (only in chatbot.output).
- Use pairwise() only if ≥2 variables use it; forward() nesting must reference
  a declared variable.
- chatbot.output fields should be stable, descriptive names suitable for
  Sensei-check rules (e.g., total_price, order_id, opening_hours).

Domain: <FILL IN>
Goals the simulated user should pursue: <FILL IN>
Outputs to extract: <FILL IN>
```

### ✅ Then validate in your script

