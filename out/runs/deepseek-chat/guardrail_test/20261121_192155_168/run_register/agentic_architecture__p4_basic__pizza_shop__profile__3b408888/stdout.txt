  context:

    - variable:
        function: random()          # default|random|another|forward|pairwise
        type: string                # int|float|string|<custom type>
        data: [option1, option2]

chatbot:
  is_starter: false
  fallback: "the bot's real fallback message"
  output:
    - important_field:
        type: string                # int|float|string|time(...)|date(...)|list[...]|<custom>
        description: "what to extract"

conversation:
  number: 2
  goal_style:
    steps: 5
  interaction_style:
    - random:

      - make spelling mistakes

**Key gotchas** your automation must enforce (these are the #1 sources of invalid profiles):
- Every `{{variable}}` in a goal string **must** be declared in `goals` with the *exact same name* (case-sensitive).
- `random(n)` requires `n ≤ list length`.
- `conversation.number: combinations(...)` requires **≥2** nested `forward()` or `pairwise()` variables.
- `list`, `time`, `date` types are valid in `chatbot.output` but **not** in `user.goals`.
- `interaction_style` values are **reserved keywords** — never translate them.
