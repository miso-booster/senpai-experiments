
A couple of notes 👀:
- I kept only the **meaningful headers** (the browser-specific ones like `Sec-Fetch-*`, `Priority`, `Pragma`, `Cache-Control`, `Content-Length`, `Connection` are usually not needed and can even cause issues).
- The `response_path` is `response.0.text` — matching your sample response (`response` is a list, first element's `text`).
- The bot replies with HTML (`<p>...</p>`), so you may want to strip tags in your script (I do that below).

## 2) Python Script

This script uses the `CustomChatbot` connector from the docs, sends several messages, and prints cleaned responses:

```python
"""
Send multiple messages to the SAIC Malaga chatbot via the Custom YAML connector.
"""

import re
import time
from chatbot_connectors.implementations.custom import CustomChatbot

CONNECTOR_PATH = "connectors/saic-malaga.yaml"

MESSAGES = [
    "hola",
    "¿Cuál es el horario de atención?",
    "Quiero pedir cita previa",
    "¿Cómo puedo consultar el estado de mi trámite?",
    "gracias",
]


def clean_html(text: str) -> str:
    """Remove HTML tags and collapse whitespace."""
    if not text:
        return ""
    text = re.sub(r"<br\s*/?>", "\n", text, flags=re.IGNORECASE)
    text = re.sub(r"<[^>]+>", "", text)
    return re.sub(r"\n{3,}", "\n\n", text).strip()


def main():
    bot = CustomChatbot(CONNECTOR_PATH)

    for i, msg in enumerate(MESSAGES, start=1):
        print(f"\n[{i}/{len(MESSAGES)}] 👤 User: {msg}")
        try:
            success, response = bot.execute_with_input(msg)
        except Exception as e:
            print(f"   ❌ Exception: {e}")
            continue

        if not success:
            print(f"   ⚠️ Request failed. Raw response: {response}")
            continue

        print(f"   🤖 Bot: {clean_html(response)}")
        time.sleep(1)  # be gentle with the API


if __name__ == "__main__":
    main()
```

### How to run it 🚀

1. Save the YAML as `connectors/saic-malaga.yaml` (adjust the path in the script if needed).
2. Make sure `chatbot_connectors` is importable (same environment where Sensei runs).
3. Run:

```bash
python send_saic_malaga.py
```
