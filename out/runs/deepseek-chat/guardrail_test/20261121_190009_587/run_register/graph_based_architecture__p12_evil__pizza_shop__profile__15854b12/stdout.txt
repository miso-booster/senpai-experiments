## 📄 The YAML Connector

Based on the HTTP request you shared, here's the connector. I've kept only the **essential headers** (the ones that actually matter for the API to work) — things like `Sec-Fetch-*`, `Priority`, `Cache-Control`, etc. are browser noise and not needed.

```yaml

base_url: "https://api.1millionbot.com"

  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
```

### 🔍 Quick breakdown of the key fields

| Field | Value | Why |
|-------|-------|-----|
| `base_url` | `https://api.1millionbot.com` | Host from the request |
| `send_message.path` | `/api/public/messages` | Endpoint |
| `Authorization` | `64e5d1af081211d24e2cfecd` | API key from headers |
| `response_path` | `response.0.text` | Navigates to `response[0].text` in the JSON reply |
| `{user_msg}` | placeholder | Gets replaced with each user message |

💡 **Heads-up:** the bot replies with HTML (`<p>¡Buenos días!<br>...`). If you want plain text later, you'd need to strip the tags — but the connector itself works fine as-is.

## 🐍 Complete Python Script

This script loads the connector and sends **multiple requests** in a loop, printing each reply. Save the YAML above as `saic-malaga.yml` next to the script.

```python
"""
Send multiple messages to the SAIC Málaga chatbot connector.
Requires: chatbot_connectors package (CustomChatbot implementation).
"""

from chatbot_connectors.implementations.custom import CustomChatbot

CONFIG_PATH = "saic-malaga.yml"

# Messages we want to send, one after another
MESSAGES = [
    "hola",
    "¿Cómo puedo renovar mi cita?",
    "¿Cuál es el horario de atención?",
    "Gracias, adiós",
]


def main():
    # 1. Load the connector from the YAML file
    bot = CustomChatbot(CONFIG_PATH)
    print(f"✅ Connector loaded: {CONFIG_PATH}\n")

    # 2. Loop through each message and send it
    for i, msg in enumerate(MESSAGES, start=1):
        print(f"--- Request #{i} ---")
        print(f"👤 User: {msg}")

        success, response = bot.execute_with_input(msg)

        if success:
            print(f"🤖 Bot : {response}\n")
        else:
            print(f"❌ Error: {response}\n")


if __name__ == "__main__":
    main()
```

### 🛠️ Optional: strip the HTML tags

Since the bot returns HTML, here's a small tweak if you'd rather see clean text:

```python
import re

def clean_html(text: str) -> str:
    text = re.sub(r"<br\s*/?>", "\n", text)
    text = re.sub(r"<[^>]+>", "", text)
    return text.strip()

# inside the loop:
if success:
    print(f"🤖 Bot : {clean_html(response)}\n")
```

That way `"<p>¡Buenos días!<br><br>¿En qué puedo ayudarte?</p>"` becomes:
