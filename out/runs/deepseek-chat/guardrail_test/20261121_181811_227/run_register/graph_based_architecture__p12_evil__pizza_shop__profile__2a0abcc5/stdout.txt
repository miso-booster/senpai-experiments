# YAML Connector for SAIC Málaga 🎉

Here's your connector, built from the request/response you shared. It's a MillionBot-based API (same family as the Ada UAM example), so the structure is very similar 😊

```yaml
name: "SAIC Malaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

### Why these values? 👀
- **`response_path: "response.0.text"`** → the bot's reply lives at `response[0].text` in the JSON.
- **`{user_msg}`** → placeholder that gets replaced with each user message.
- **Headers** → I kept the essential ones (`Authorization`, `Content-Type`, `Origin`, `Referer`, `User-Agent`). The rest (Accept, Sec-Fetch-*, etc.) are browser noise and not needed for the API to work.
- **`conversation` / `sender` / `bot`** → these are session identifiers from your captured request. If you start a fresh conversation, you'll likely need new values here.

Save it as something like `saic-malaga.yml` in your connectors folder. ✅

# Python Script to Send Multiple Requests 🐍

This script uses the `CustomChatbot` class from the connector guide and fires several messages at your new connector:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

# Path to your YAML connector
CONNECTOR_PATH = "saic-malaga.yml"

# Messages to send, one after another
MESSAGES = [
    "hola",
    "¿Cómo puedo pedir cita previa?",
    "¿Cuál es el horario de atención?",
    "Gracias, ¡hasta luego!",
]

def main():
    bot = CustomChatbot(CONNECTOR_PATH)

    for i, msg in enumerate(MESSAGES, start=1):
        print(f"\n--- [{i}/{len(MESSAGES)}] User: {msg}")
        success, response = bot.execute_with_input(msg)

        if success:
            print(f"Bot: {response}")
        else:
            print(f"⚠️  Error: {response}")

if __name__ == "__main__":
    main()
```

### What it does 🚀
1. Loads your YAML connector once.
2. Loops through the `MESSAGES` list.
3. For each message, calls `execute_with_input()` and prints the bot's reply.
4. Handles failures gracefully with a warning instead of crashing.

### Tips 💡
- **Keep the same `conversation` ID** across messages if you want the bot to remember context (as configured in the YAML).
- If the API starts rejecting requests, the `conversation`/`sender` IDs may have expired — recapture a fresh request from the browser and update the YAML.
- Want to test with a single message first? Just trim the `MESSAGES` list to `["hola"]`.
