Here's a quick example of what a profile for that scenario could look like:

```yaml
test_name: "large_bbq_pizza_and_soda_order"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a customer placing a pickup order at a pizza shop.
    You want a large BBQ pizza and a soda.
  context:
    - "You are ordering for pickup tonight."
    - "You are friendly but concise."
  goals:
    - "Order a {{pizza_size}} {{pizza_type}} pizza."
    - "Order {{number_of_drinks}} {{drink_type}}."
    - pizza_size:
        function: default()
        type: string
        data: [large]
    - pizza_type:
        function: default()
        type: string
        data: [BBQ Chicken]
    - number_of_drinks:
        function: default()
        type: int
        data: [1]
    - drink_type:
        function: default()
        type: string
        data: [soda]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I did not get what you said. Can you rephrase?"
  output:
    - order_summary:
        type: string
        description: "Summary of the pizza and drink order"
    - total_cost:
        type: money
        description: "Total cost of the order"
    - order_id:
        type: string
        description: "The order identifier"

conversation:
  number: 1
  goal_style:
    steps: 5
  interaction_style:
    - default
```

Just a heads-up: I used `BBQ Chicken` as the pizza type since that's what appears in your project's profiles — swap it for whatever your bot actually calls it.
