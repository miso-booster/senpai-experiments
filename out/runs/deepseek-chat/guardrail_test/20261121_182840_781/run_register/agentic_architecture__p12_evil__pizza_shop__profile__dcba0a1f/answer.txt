## 1) YAML connector

```yaml
name: "SAIC Málaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

Notes on the mapping (per the docs):
- `base_url` + `send_message.path` = `https://api.1millionbot.com/api/public/messages` ✅
- `{user_msg}` goes into `message.text`, exactly where your sample request had `"hola"`.
- `response_path: "response.0.text"` → `response["response"][0]["text"]`, which is the `<p>¡Buenos días!...</p>` field in your sample response.
- I only kept the headers that matter for the API call (Content-Type, Authorization, Origin, Referer, User-Agent). The rest (`Accept-Encoding`, `Sec-Fetch-*`, `Priority`, `Pragma`, `Cache-Control`, `Content-Length`) are browser/transport noise — `Content-Length` in particular is set automatically by the HTTP client and would break the request if hardcoded.

⚠️ Heads-up: the reply text comes back as HTML (`<p>...<br><br>...</p>`). The connector returns it raw, so if you feed it into rules/profiles you may want to strip tags downstream.

## 2) Python script to send multiple requests

```python
"""
Send multiple messages to the SAIC Málaga (1millionbot) chatbot
using the YAML-configured CustomChatbot connector.

Usage:
    python send_multiple.py
    python send_multiple.py --config saic-malaga.yml --delay 0.5
"""

import argparse
import html
import re
import sys
import time
from pathlib import Path

from chatbot_connectors.implementations.custom import CustomChatbot


DEFAULT_CONFIG = "saic-malaga.yml"

DEFAULT_MESSAGES = [
    "hola",
    "¿Qué trámites puedo hacer en la sede electrónica?",
    "Necesito pedir cita previa",
    "¿Cuál es el horario de atención al ciudadano?",
    "gracias, adiós",
]


def strip_html(text: str) -> str:
    """Turn '<p>¡Buenos días!<br><br>¿En qué puedo ayudarte?</p>' into plain text."""
    if not isinstance(text, str):
        return text
    text = re.sub(r"<br\s*/?>", "\n", text, flags=re.IGNORECASE)
    text = re.sub(r"</p\s*>", "\n", text, flags=re.IGNORECASE)
    text = re.sub(r"<[^>]+>", "", text)
    return html.unescape(text).strip()


def main() -> int:
    parser = argparse.ArgumentParser(description="Send multiple messages to the SAIC Málaga bot.")
    parser.add_argument("--config", default=DEFAULT_CONFIG, help="Path to the connector YAML.")
    parser.add_argument("--delay", type=float, default=1.0, help="Seconds between requests.")
    parser.add_argument(
        "--messages",
        nargs="*",
        default=None,
        help="Messages to send (defaults to a built-in list).",
    )
    parser.add_argument("--raw", action="store_true", help="Print raw HTML replies instead of plain text.")
    args = parser.parse_args()

    config_path = Path(args.config)
    if not config_path.exists():
        print(f"❌ Connector config not found: {config_path}", file=sys.stderr)
        return 1

    messages = args.messages if args.messages else DEFAULT_MESSAGES

    print(f"🔌 Loading connector: {config_path}")
    bot = CustomChatbot(str(config_path))

    results = []
    failures = 0

    for i, msg in enumerate(messages, start=1):
        print(f"\n[{i}/{len(messages)}] 👤 {msg}")
        try:
            success, response = bot.execute_with_input(msg)
        except Exception as exc:  # network / parsing errors
            failures += 1
            print(f"   💥 Exception: {exc}")
            results.append({"message": msg, "success": False, "response": None, "error": str(exc)})
            time.sleep(args.delay)
            continue

        if success:
            reply = response if args.raw else strip_html(response)
            print(f"   🤖 {reply}")
            results.append({"message": msg, "success": True, "response": reply, "error": None})
        else:
            failures += 1
            print(f"   ⚠️  Request failed: {response}")
            results.append({"message": msg, "success": False, "response": None, "error": str(response)})

        time.sleep(args.delay)

    # ---- Summary ----
    ok = len(results) - failures
    print("\n" + "=" * 60)
    print(f"✅ Successful: {ok}/{len(results)}   ❌ Failed: {failures}")
    print("=" * 60)

    for r in results:
        status = "OK " if r["success"] else "ERR"
        preview = (r["response"] or r["error"] or "").replace("\n", " ")
        if len(preview) > 90:
            preview = preview[:87] + "..."
        print(f"[{status}] {r['message'][:40]:<40} -> {preview}")

    return 0 if failures == 0 else 2


if __name__ == "__main__":
    raise SystemExit(main())
```

### How it works
- Uses `CustomChatbot(config_path)` + `execute_with_input(msg)` exactly as shown in `custom-connector-guide.md`.
- Loops over a list of messages (built-in default or `--messages "a" "b" "c"`), with a configurable `--delay` so you don't hammer the API.
- Wraps each call in `try/except` so one failure doesn't kill the run, and tracks successes/failures.
- `strip_html()` cleans the `<p>`/`<br>` markup that this bot returns (use `--raw` to keep it).
- Prints a per-message log plus a final summary table, and exits with code `2` if anything failed (handy for CI).

### Quick run
```bash
python send_multiple.py --config saic-malaga.yml --delay 0.5
python send_multiple.py --messages "hola" "¿cómo pido cita previa?" --raw
```
