### Why these values? 🤔
- **`response_path: "response.0.text"`** → In the response JSON, the bot's reply lives at `response[0].text`. That's exactly what dot notation `response.0.text` resolves to.
- **`Authorization`** → Kept as a plain string (same style as your existing `ada-uam.yaml`).

- **Extra headers** (`Origin`, `Referer`, `User-Agent`) → Included because the API is called cross-site from `saic.malaga.eu`, so they help mimic the real browser request.

# Complete Python Script 🐍

This script uses the `CustomChatbot` implementation from your connector guide, sends multiple messages, and cleans the HTML from the responses.

```python
"""
Send multiple messages to the SAIC Malaga chatbot connector.
"""

import re
from chatbot_connectors.implementations.custom import CustomChatbot


def strip_html(text: str) -> str:
    """Remove HTML tags and collapse whitespace."""
    if not text:
        return ""
    clean = re.sub(r"<[^>]+>", "", text)
    return re.sub(r"\s+", " ", clean).strip()


def main():
    # Path to the YAML connector file
    connector_path = "yaml-examples/saic-malaga.yml"

    # Create the chatbot instance
    bot = CustomChatbot(connector_path)

    # Messages to send
    messages = [
        "hola",
        "¿Cómo puedo pedir cita previa?",
        "¿Cuál es el horario de atención?",
        "Gracias, adiós",
    ]

    print("=" * 60)
    print("SAIC Malaga Chatbot - Multi-message Test")
    print("=" * 60)

    for i, msg in enumerate(messages, start=1):
        print(f"\n[{i}] 👤 User: {msg}")

        success, response = bot.execute_with_input(msg)

        if success:
            clean_reply = strip_html(response)
            print(f"    🤖 Bot : {clean_reply}")
        else:
            print(f"    ❌ Error: {response}")

    print("\n" + "=" * 60)
    print("Done ✅")
    print("=" * 60)


if __name__ == "__main__":
    main()
```

### What's happening here? 👀
1. **`CustomChatbot(connector_path)`** loads your YAML config.
2. **`execute_with_input(msg)`** sends the message and returns `(success, response)`.
3. **`strip_html()`** cleans the `<p>...</p>` tags so the output is readable.
4. The loop sends **multiple messages** in sequence — handy for testing conversation flow.
