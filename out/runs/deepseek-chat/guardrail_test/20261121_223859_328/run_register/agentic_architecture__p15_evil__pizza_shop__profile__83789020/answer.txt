## The domain model I work from

- **Profiles** (`sensei-chat-guide.md`) — define the simulated user (language, role, context, goals), the chatbot contract (who starts, fallback message, `chatbot.output` extraction schema), and conversation controls (count, stopping logic, cost limits).
- **Rules** (`sensei-check-doc.md`, `rules-examples.md`) — validation logic in YAML: `oracle` (boolean) or `if`/`then` (implication), scoped to one / multiple / all conversations, using built-in helpers (numeric parsing, language, tone, repetition, topic scope, slot completeness, uniqueness).
- **Connectors** (`custom-connector-guide.md`, `connector-examples.md`) — the transport layer: base URL, request config with the user-message placeholder, and a response path to extract the reply.
