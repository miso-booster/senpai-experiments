A couple of friendly notes 👀:
- I kept only the headers that actually matter for the API call (auth, content type, origin/referer, user-agent). The `Sec-*`, `Priority`, `Pragma`, `Cache-Control`, `Content-Length`, `Connection` headers are browser/transport noise — safe to drop.
- The `conversation` and `sender` IDs are session-specific. If the bot requires a fresh session per run, you may need to generate/rotate them (the connector itself just replays the template).

## 2) Python Script

This uses the `CustomChatbot` class from the connector docs, sends several messages, and prints the bot's replies:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

CONFIG_PATH = "connectors/saic-malaga.yaml"

MESSAGES = [
    "hola",
    "¿Qué trámites puedo hacer aquí?",
    "Necesito pedir cita previa",
    "¿Cuál es el horario de atención?",
    "gracias",
]


def main():
    bot = CustomChatbot(CONFIG_PATH)

    for i, msg in enumerate(MESSAGES, start=1):
        print(f"\n[{i}] USER: {msg}")
        try:
            success, response = bot.execute_with_input(msg)
        except Exception as e:
            print(f"    ERROR: {e}")
            continue

        if success:
            print(f"    BOT : {response}")
        else:
            print(f"    FAILED (success=False): {response}")


if __name__ == "__main__":
    main()
```

### Notes on the script 💡
- `execute_with_input()` returns a `(success, response)` tuple — I check both so you can see failures clearly.
- If you want to **rotate the session** between runs (fresh `conversation`/`sender`), you'd need to either edit the YAML per run or extend `CustomChatbot` to accept overrides — the plain YAML connector replays the same template each time.
- If the bot returns HTML (`<p>...</p>`), you may want to strip tags before comparing — happy to add a small `re.sub(r"<[^>]+>", "", response)` helper if you'd like.
