Here's a quick taste of what a profile for that scenario could look like:

```yaml
test_name: "bike_shop_appointment_booking"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a customer trying to book a bike repair appointment at a local shop.
    Ask about available services, then book a slot for a specific date and time.
  context:
    - "You need a tune-up before a weekend ride."
    - "You prefer morning appointments."
  goals:
    - "Ask what repair services are available."
    - "Book a {{service_type}} appointment on {{appointment_date}} at {{appointment_time}}."
    - service_type:
        function: forward()
        type: string
        data: [tune-up, brake adjustment, wheel truing, full service]
    - appointment_date:
        function: another()
        type: string
        data:
          - any(3 dates within the next 14 days)
    - appointment_time:
        function: random()
        type: string
        data: ["09:00", "10:30", "14:00", "16:30"]

chatbot:
  is_starter: false
  fallback: "Sorry, could you rephrase that?"
  output:
    - appointment_date:
        type: date(mm/dd/yyyy)
        description: "The confirmed appointment date"
    - appointment_time:
        type: time(hh:mm)
        description: "The confirmed appointment time"
    - service_type:
        type: string
        description: "The service booked"
    - booking_id:
        type: string
        description: "The appointment confirmation ID"

conversation:
  number: 4
  goal_style:
    steps: 6
  interaction_style:
    - single questions
```
