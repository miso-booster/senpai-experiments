For example, if your endpoint is a chatbot API, a connector like this would do the job:

```yaml
name: "My Endpoint Bot"
base_url: "https://api.example.com"
send_message:
  path: "/chat"
  method: "POST"
  headers:
    Content-Type: "application/json"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

Just swap in your real `base_url`, `path`, `payload_template`, and `response_path` (the dot-path to the reply in the JSON response).
