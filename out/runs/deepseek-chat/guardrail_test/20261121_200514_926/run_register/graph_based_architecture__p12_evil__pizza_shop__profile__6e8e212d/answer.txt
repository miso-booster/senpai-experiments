# YAML Connector for SAIC Málaga 🚀

Here's the YAML connector based on your request. I've mapped the headers, payload, and response path carefully:

```yaml
name: "SAIC Malaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

### Why these choices? 🤔
- **`response_path: "response.0.text"`** — the reply lives at `response[0].text` in the JSON, so dot notation with `0` for the array index gets us there.
- **`{user_msg}` placeholder** — this is where each user message gets injected (replacing the `"hola"` from your sample).
- **Headers** — I kept the essential ones (`Content-Type`, `Authorization`, `Origin`, `Referer`, `User-Agent`). The rest (Sec-Fetch-*, Priority, etc.) are browser-generated and not needed for the API to work.
- **`conversation`, `sender`, `bot`** — these are session/identity IDs from your sample request. If you want a *fresh* conversation per run, you'd need to generate new IDs — but for now, reusing them keeps things simple.

# Complete Python Script 🐍

This script uses the `CustomChatbot` class from the connector framework and sends multiple messages in a loop:

```python
"""
Send multiple messages to the SAIC Malaga chatbot connector.

Usage:
    python saic_malaga_test.py
"""

from chatbot_connectors.implementations.custom import CustomChatbot


# Path to the YAML connector file
CONNECTOR_PATH = "saic-malaga.yml"

# Messages to send, one after another
MESSAGES = [
    "hola",
    "¿Cómo puedo renovar mi certificado digital?",
    "¿Dónde está la oficina de atención al ciudadano?",
    "Gracias, eso es todo",
]


def main():
    print("=" * 60)
    print("SAIC Malaga Chatbot - Multi-message Test")
    print("=" * 60)

    # Initialize the connector
    bot = CustomChatbot(CONNECTOR_PATH)

    # Send each message and print the response
    for i, msg in enumerate(MESSAGES, start=1):
        print(f"\n[{i}/{len(MESSAGES)}] 👤 User: {msg}")

        success, response = bot.execute_with_input(msg)

        if success:
            print(f"🤖 Bot: {response}")
        else:
            print(f"❌ Error: {response}")

    print("\n" + "=" * 60)
    print("Done! ✅")
    print("=" * 60)


if __name__ == "__main__":
    main()
```

### How it works 💡
1. **`CustomChatbot(CONNECTOR_PATH)`** — loads your YAML file and prepares the HTTP client.
2. **`bot.execute_with_input(msg)`** — sends one message, returns a tuple `(success, response)`.
3. **The loop** — iterates over `MESSAGES`, printing each user message and the bot's reply.

### Tips for a smoother run ✨
- **Save the YAML** as `saic-malaga.yml` in the same folder as the script (or update `CONNECTOR_PATH`).
- **HTML in responses** — the bot returns HTML (`<p>...</p>`). If you want plain text, you can strip tags with `re.sub(r"<[^>]+>", "", response)`.
- **Session continuity** — since `conversation`, `sender`, and `bot` are fixed in the YAML, all messages share the same session. That's usually what you want for a coherent conversation 😊.
- **Rate limiting** — if you send many messages quickly, add a small `time.sleep(1)` between requests to be polite to the API.
