## 1) YAML Connector

```yaml
name: "SAIC Malaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
    Accept: "*/*"
    Accept-Language: "en-US,en;q=0.9"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

A couple of notes 👀:
- I kept the essential headers (auth, origin, referer, content-type, user-agent). The `Sec-*`, `Priority`, `Pragma`, `Cache-Control`, `Connection`, `Content-Length` headers are browser-managed and not needed — `Content-Length` in particular is auto-computed by the HTTP client.
- `response_path: "response.0.text"` extracts the first element's `text` field from the response array, which matches your sample response.

## 2) Python Script to Send Multiple Requests

```python
"""
Test script for the SAIC Malaga custom connector.
Sends multiple messages to the chatbot and prints the responses.
"""

import json
import time
import requests

# --- Connector configuration (mirrors the YAML) ---
BASE_URL = "https://api.1millionbot.com"
PATH = "/api/public/messages"

HEADERS = {
    "Content-Type": "application/json",
    "Authorization": "64e5d1af081211d24e2cfecd",
    "Origin": "https://saic.malaga.eu",
    "Referer": "https://saic.malaga.eu/",
    "User-Agent": (
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) "
        "Gecko/20100101 Firefox/147.0"
    ),
    "Accept": "*/*",
    "Accept-Language": "en-US,en;q=0.9",
}

PAYLOAD_TEMPLATE = {
    "conversation": "6977595c744ccf01954b8797",
    "sender_type": "User",
    "sender": "6977595c3e4824018e496b0c",
    "bot": "64e5d1af081211d24e2cfec8",
    "language": "es",
    "url": "https://saic.malaga.eu/",
    "message": {"text": "{user_msg}"},
}

RESPONSE_PATH = ["response", 0, "text"]  # equivalent to "response.0.text"


def build_payload(user_msg: str) -> dict:
    """Deep-copy the template and inject the user message."""
    payload = json.loads(json.dumps(PAYLOAD_TEMPLATE))
    payload["message"]["text"] = user_msg
    return payload


def extract_response(data: dict, path: list):
    """Navigate a dot-path (list form) through the JSON response."""
    current = data
    for key in path:
        if isinstance(key, int):
            current = current[key]
        else:
            current = current[key]
    return current


def send_message(user_msg: str, timeout: int = 30) -> str:
    """Send a single message and return the extracted bot reply."""
    url = BASE_URL + PATH
    payload = build_payload(user_msg)

    response = requests.post(url, headers=HEADERS, json=payload, timeout=timeout)
    response.raise_for_status()

    data = response.json()
    try:
        return extract_response(data, RESPONSE_PATH)
    except (KeyError, IndexError, TypeError) as exc:
        raise RuntimeError(
            f"Could not extract response at path {RESPONSE_PATH}. "
            f"Raw JSON: {json.dumps(data, ensure_ascii=False)}"
        ) from exc


def main():
    # Multiple test messages (Spanish, since language="es")
    messages = [
        "hola",
        "¿Cuáles son los horarios de atención?",
        "Quiero pedir cita previa",
        "¿Cómo puedo acceder a mi expediente?",
        "gracias",
    ]

    print("=" * 70)
    print("SAIC Malaga Connector — Multi-request Test")
    print("=" * 70)

    for i, msg in enumerate(messages, start=1):
        print(f"\n[{i}/{len(messages)}] USER: {msg}")
        try:
            reply = send_message(msg)
            print(f"BOT : {reply}")
        except requests.HTTPError as exc:
            print(f"HTTP ERROR: {exc} — {exc.response.text[:300]}")
        except Exception as exc:
            print(f"ERROR: {exc}")

        # Small pause to be polite to the API
        time.sleep(1)

    print("\n" + "=" * 70)
    print("Done ✅")
    print("=" * 70)


if __name__ == "__main__":
    main()
```

### How it works 🧠
- **`build_payload`** clones the template and swaps `{user_msg}` for the actual message — same idea as the YAML's `payload_template`.
- **`extract_response`** walks the `["response", 0, "text"]` path, which is exactly what `response_path: "response.0.text"` does in the connector.
- **`send_message`** does the POST, raises on HTTP errors, and returns the bot's reply.
- **`main`** loops over several test messages with a 1-second pause between calls.

### Optional: use the actual `CustomChatbot` class instead
