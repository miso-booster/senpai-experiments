## 1️⃣ YAML Connector

Basándome en los headers y el payload que me pasaste (¡muy bien detallados, por cierto! 👏), aquí tienes el conector:

```yaml
name: "SAIC Málaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

### 🔍 Un par de notas rápidas

- **`response_path: "response.0.text"`** → porque en la respuesta el texto está en `response[0].text`. ¡Justo como en el ejemplo de Ada UAM! 😉
- **Headers incluidos**: dejé los más relevantes (`Content-Type`, `Authorization`, `Origin`, `Referer`, `User-Agent`). Los headers tipo `Sec-Fetch-*`, `Priority`, `Pragma`, etc. son generados automáticamente por el navegador y normalmente **no son necesarios** para que la API responda. Si algún día te da problemas, se pueden añadir, pero con estos debería bastar. 🙌
- **`{user_msg}`** es el placeholder que se sustituye por cada mensaje que envíes.

## 2️⃣ Python Script para enviar múltiples requests

Aquí tienes un script completo y listo para usar. Lo hice con `requests` (más directo y fácil de leer) y con un pequeño manejo de errores para que sea robusto 💪:

```python
"""
Script para probar el conector SAIC Málaga (1millionbot).
Envía múltiples mensajes al chatbot y muestra las respuestas.
"""

import requests
import time

# --- Configuración del conector (equivalente al YAML) ---
BASE_URL = "https://api.1millionbot.com"
PATH = "/api/public/messages"
URL = BASE_URL + PATH

HEADERS = {
    "Content-Type": "application/json",
    "Authorization": "64e5d1af081211d24e2cfecd",
    "Origin": "https://saic.malaga.eu",
    "Referer": "https://saic.malaga.eu/",
    "User-Agent": (
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) "
        "Gecko/20100101 Firefox/147.0"
    ),
}

PAYLOAD_TEMPLATE = {
    "conversation": "6977595c744ccf01954b8797",
    "sender_type": "User",
    "sender": "6977595c3e4824018e496b0c",
    "bot": "64e5d1af081211d24e2cfec8",
    "language": "es",
    "url": "https://saic.malaga.eu/",
    "message": {"text": "{user_msg}"},
}

RESPONSE_PATH = ["response", 0, "text"]  # equivalente a "response.0.text"


def extract_response(data, path):
    """Extrae un valor anidado del JSON usando una lista de claves/índices."""
    current = data
    for key in path:
        current = current[key]
    return current


def send_message(user_msg):
    """Envía un mensaje al chatbot y devuelve la respuesta de texto."""
    payload = {
        **PAYLOAD_TEMPLATE,
        "message": {"text": user_msg},
    }

    try:
        response = requests.post(URL, headers=HEADERS, json=payload, timeout=15)
        response.raise_for_status()
        data = response.json()
        return extract_response(data, RESPONSE_PATH)
    except requests.exceptions.RequestException as e:
        return f"[ERROR de red] {e}"
    except (KeyError, IndexError, TypeError) as e:
        return f"[ERROR al parsear respuesta] {e}"


def main():
    messages = [
        "hola",
        "¿Cómo puedo pedir cita previa?",
        "¿Dónde está la oficina del SAIC?",
        "Gracias, ¡hasta luego!",
    ]

    for i, msg in enumerate(messages, start=1):
        print(f"\n🧑 [{i}] Usuario: {msg}")
        reply = send_message(msg)
        print(f"🤖 Bot: {reply}")
        time.sleep(1)  # pequeña pausa entre peticiones, por cortesía 🙂


if __name__ == "__main__":
    main()
```

---

### 🧠 ¿Qué hace este script?

1. **Replica el conector YAML** en constantes de Python (URL, headers, payload).
2. **`send_message()`** construye el payload sustituyendo `{user_msg}` y hace el POST.
3. **`extract_response()`** navega el JSON igual que `response_path: "response.0.text"`.
4. **`main()`** envía una lista de mensajes de ejemplo, con una pausa de 1 segundo entre cada uno para no saturar la API 😌.

- Si quieres **probar con el `CustomChatbot`** del proyecto, guarda el YAML como `saic-malaga.yml` y usa:
