I'll create the YAML connector for the SAIC Málaga chatbot first, then a Python script to test it with multiple messages 😊

## 1) YAML Connector

```yaml
name: "SAIC Malaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
    Accept: "*/*"
    Accept-Language: "en-US,en;q=0.9"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

A couple of notes 👀:
- I kept only the **meaningful headers** (Content-Type, Authorization, Origin, Referer, User-Agent, Accept, Accept-Language). The `Sec-*`, `Priority`, `Pragma`, `Cache-Control`, `Connection`, and `Content-Length` headers are browser/transport noise — `Content-Length` in particular is auto-computed by the HTTP client, so hardcoding it would break requests.
- `response_path: "response.0.text"` extracts the first element's `text` field from the JSON response (which is what you showed in the example).

## 2) Python Script to Send Multiple Requests

```python
"""
Test script for the SAIC Malaga custom connector.

Sends multiple messages to the chatbot API defined in the YAML connector
and prints each response. Uses the same request structure as the connector.
"""

import json
import time
import requests


# --- Connector configuration (mirrors the YAML) ---
BASE_URL = "https://api.1millionbot.com"
PATH = "/api/public/messages"
METHOD = "POST"

HEADERS = {
    "Content-Type": "application/json",
    "Authorization": "64e5d1af081211d24e2cfecd",
    "Origin": "https://saic.malaga.eu",
    "Referer": "https://saic.malaga.eu/",
    "User-Agent": (
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) "
        "Gecko/20100101 Firefox/147.0"
    ),
    "Accept": "*/*",
    "Accept-Language": "en-US,en;q=0.9",
}

PAYLOAD_TEMPLATE = {
    "conversation": "6977595c744ccf01954b8797",
    "sender_type": "User",
    "sender": "6977595c3e4824018e496b0c",
    "bot": "64e5d1af081211d24e2cfec8",
    "language": "es",
    "url": "https://saic.malaga.eu/",
    "message": {"text": "{user_msg}"},
}

RESPONSE_PATH = ["response", 0, "text"]


def build_payload(user_msg: str) -> dict:
    """Deep-copy the template and inject the user message."""
    payload = json.loads(json.dumps(PAYLOAD_TEMPLATE))
    payload["message"]["text"] = user_msg
    return payload


def extract_response(data: dict):
    """Navigate the response_path (dot notation with list indices)."""
    current = data
    for key in RESPONSE_PATH:
        if isinstance(key, int):
            current = current[key]
        else:
            current = current[key]
    return current


def send_message(user_msg: str, timeout: int = 30) -> str:
    """Send a single message and return the bot's reply text."""
    url = BASE_URL + PATH
    payload = build_payload(user_msg)

    response = requests.request(
        method=METHOD,
        url=url,
        headers=HEADERS,
        json=payload,
        timeout=timeout,
    )
    response.raise_for_status()

    data = response.json()
    return extract_response(data)


def main():
    messages = [
        "hola",
        "¿Qué servicios ofrece el SAIC?",
        "¿Cómo puedo pedir cita previa?",
        "¿Cuál es el horario de atención?",
        "gracias",
    ]

    for i, msg in enumerate(messages, start=1):
        print(f"\n[{i}/{len(messages)}] 👤 User: {msg}")
        try:
            reply = send_message(msg)
            print(f"🤖 Bot : {reply}")
        except requests.HTTPError as e:
            print(f"❌ HTTP error: {e} — body: {e.response.text}")
        except Exception as e:
            print(f"❌ Unexpected error: {e}")

        # Small pause to be polite to the API
        time.sleep(1)


if __name__ == "__main__":
    main()
```

### How it works 🚀
- **`build_payload`** deep-copies the template so each request is independent (important if you later loop over many messages).
- **`extract_response`** walks the `response_path` (`response.0.text`) — same logic the connector uses.
- **`send_message`** does the actual HTTP call with `requests.request(...)`, using `json=payload` so `Content-Length` is set automatically.
- **`main`** iterates over a list of test messages, prints each reply, and sleeps 1s between calls.

### Tips 💡
- If the API starts returning errors, check whether the `conversation` / `sender` IDs **expire** — many MillionBot deployments rotate them per session. If so, you'd need to fetch fresh IDs from an init endpoint first.
- The bot returns HTML (`<p>...</p>`). If you want plain text, add a small `re.sub(r"<[^>]+>", "", reply)` cleanup step.
- To reuse this with the actual `CustomChatbot` class, just point it at the YAML file:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

bot = CustomChatbot("connectors/saic-malaga.yaml")
success, response = bot.execute_with_input("hola")
print(response)
```
