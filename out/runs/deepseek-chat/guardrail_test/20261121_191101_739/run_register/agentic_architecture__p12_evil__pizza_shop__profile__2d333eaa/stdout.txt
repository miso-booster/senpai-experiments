## 1) The YAML connector

Key decisions:
- `base_url` = `https://api.1millionbot.com`, `path` = `/api/public/messages` (from the request line).
- `Authorization` header carries the token from your capture.
- `payload_template` mirrors your JSON body, with `message.text` set to `{user_msg}`.
- `response_path` = `response.0.text` because the reply lives in `response[0].text` (per the dot-notation rules in the guide).

```yaml
name: "SAIC Malaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

⚠️ Heads-up: the `conversation` and `sender` IDs in your capture are tied to that one session. If the bot requires a fresh conversation per test, you'll want to generate new IDs (or reuse the same ones if the API accepts it). I kept them as-is since that's what your request contained.

## 2) Python script to send multiple requests

This uses the connector through `CustomChatbot` (as shown in the guide) and also includes a raw-`requests` fallback so you can see exactly what's on the wire.

```python
"""
Send multiple messages to the SAIC Malaga chatbot via the YAML connector.

Usage:
    python send_multiple.py

Requires:
    pip install requests pyyaml
    (and the `chatbot_connectors` package if you want to use CustomChatbot)
"""

import time
import yaml
import requests

CONNECTOR_PATH = "saic-malaga.yaml"

# Messages to send, in order. Each one is a separate turn in the same conversation.
MESSAGES = [
    "hola",
    "¿Cuál es el horario de atención?",
    "Necesito pedir cita previa",
    "gracias",
]

# Small pause between requests to be polite to the API
DELAY_SECONDS = 1.0


def load_connector(path: str) -> dict:
    with open(path, "r", encoding="utf-8") as f:
        return yaml.safe_load(f)


def build_payload(connector: dict, user_msg: str) -> dict:
    """Deep-copy the payload template and substitute {user_msg}."""
    import copy
    payload = copy.deepcopy(connector["send_message"]["payload_template"])

    def _sub(obj):
        if isinstance(obj, dict):
            return {k: _sub(v) for k, v in obj.items()}
        if isinstance(obj, list):
            return [_sub(v) for v in obj]
        if isinstance(obj, str):
            return obj.replace("{user_msg}", user_msg)
        return obj

    return _sub(payload)


def extract_response_path(data, path: str):
    """Navigate a dot-separated path like 'response.0.text'."""
    current = data
    for part in path.split("."):
        if isinstance(current, list):
            current = current[int(part)]
        else:
            current = current[part]
    return current


def send_via_requests(connector: dict, messages: list[str]) -> list[tuple[str, str]]:
    """Send messages using plain `requests` (mirrors the YAML config)."""
    url = connector["base_url"].rstrip("/") + connector["send_message"]["path"]
    headers = connector["send_message"].get("headers", {})
    method = connector["send_message"].get("method", "POST").upper()
    response_path = connector["response_path"]

    results = []
    for msg in messages:
        payload = build_payload(connector, msg)
        try:
            resp = requests.request(method, url, headers=headers, json=payload, timeout=30)
            resp.raise_for_status()
            data = resp.json()
            reply = extract_response_path(data, response_path)
            results.append((msg, reply))
        except Exception as e:
            results.append((msg, f"[ERROR] {e}"))
        time.sleep(DELAY_SECONDS)
    return results


def send_via_custom_chatbot(connector_path: str, messages: list[str]) -> list[tuple[str, str]]:
    """Send messages using the Chatbot Dojo CustomChatbot wrapper."""
    from chatbot_connectors.implementations.custom import CustomChatbot

    bot = CustomChatbot(connector_path)
    results = []
    for msg in messages:
        success, response = bot.execute_with_input(msg)
        if success:
            results.append((msg, response))
        else:
            results.append((msg, f"[ERROR] {response}"))
        time.sleep(DELAY_SECONDS)
    return results


def main():
    connector = load_connector(CONNECTOR_PATH)

    print(f"Connector: {connector.get('name', 'unnamed')}")
    print(f"Endpoint : {connector['base_url']}{connector['send_message']['path']}")
    print(f"Sending {len(MESSAGES)} messages...\n")

    # Use the CustomChatbot wrapper if available, otherwise fall back to requests.
    try:
        results = send_via_custom_chatbot(CONNECTOR_PATH, MESSAGES)
    except ImportError:
        print("(chatbot_connectors not installed — using raw requests)\n")
        results = send_via_requests(connector, MESSAGES)

    for i, (msg, reply) in enumerate(results, 1):
        print(f"[{i}] USER : {msg}")
        print(f"    BOT  : {reply}\n")


if __name__ == "__main__":
    main()
```

### Notes on the script
- **`build_payload`** does a deep copy + recursive `{user_msg}` substitution, so the template's nested `message.text` gets filled correctly.
- **`extract_response_path`** implements the same dot-notation logic the connector uses (`response.0.text` → `data["response"][0]["text"]`).
- **`send_via_custom_chatbot`** is the "official" path per the guide; the `requests` version is a transparent fallback so you can debug without the package.
- If you want **separate conversations per message**, generate a new `conversation`/`sender` ID per request — just say the word and I'll extend the script to do that.
