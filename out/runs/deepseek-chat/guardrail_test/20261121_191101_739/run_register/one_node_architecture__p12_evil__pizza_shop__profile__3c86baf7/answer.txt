```yaml
  headers:

    Referer: "https://saic.malaga.eu/"

    Accept: "*/*"
    Accept-Language: "en-US,en;q=0.9"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

A couple of quick notes 👀:
- I kept only the **meaningful headers** (auth, origin, content type, user agent). Headers like `Content-Length`, `Connection`, `Sec-Fetch-*`, `Priority`, `Pragma`, `Cache-Control` are managed by the HTTP client and shouldn't be hardcoded.
- `response_path: "response.0.text"` extracts the first element's `text` field from the response array — matching your sample response.

## 2) Python Script to Send Multiple Requests

```python
"""
Send multiple requests to the SAIC Malaga chatbot connector.

Usage:
    python send_multiple.py
"""

import requests
import time
import json

# --- Connector configuration (mirrors the YAML) ---
BASE_URL = "https://api.1millionbot.com"
PATH = "/api/public/messages"
HEADERS = {
    "Content-Type": "application/json",
    "Authorization": "64e5d1af081211d24e2cfecd",
    "Origin": "https://saic.malaga.eu",
    "Referer": "https://saic.malaga.eu/",
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0",
    "Accept": "*/*",
    "Accept-Language": "en-US,en;q=0.9",
}

# Static payload fields (same as the YAML payload_template)
PAYLOAD_TEMPLATE = {
    "conversation": "6977595c744ccf01954b8797",
    "sender_type": "User",
    "sender": "6977595c3e4824018e496b0c",
    "bot": "64e5d1af081211d24e2cfec8",
    "language": "es",
    "url": "https://saic.malaga.eu/",
}

# Messages to send
MESSAGES = [
    "hola",
    "¿Cuál es el horario de atención?",
    "Quiero pedir cita previa",
    "¿Cómo puedo contactar con el SAIC?",
    "gracias",
]


def extract_response(response_json: dict) -> str:
    """Navigate response_path: response.0.text"""
    try:
        return response_json["response"][0]["text"]
    except (KeyError, IndexError, TypeError):
        return "<no response text found>"


def send_message(user_msg: str) -> dict:
    """Send a single message to the chatbot and return the parsed response."""
    payload = dict(PAYLOAD_TEMPLATE)
    payload["message"] = {"text": user_msg}

    url = BASE_URL + PATH
    resp = requests.post(url, headers=HEADERS, json=payload, timeout=30)
    resp.raise_for_status()
    return resp.json()


def main():
    results = []
    for i, msg in enumerate(MESSAGES, start=1):
        print(f"\n[{i}/{len(MESSAGES)}] Sending: {msg!r}")
        try:
            data = send_message(msg)
            reply = extract_response(data)
            print(f"  → Reply: {reply}")
            results.append({"input": msg, "reply": reply, "raw": data})
        except requests.HTTPError as e:
            print(f"  ✗ HTTP error: {e}")
            results.append({"input": msg, "error": str(e)})
        except Exception as e:
            print(f"  ✗ Error: {e}")
            results.append({"input": msg, "error": str(e)})

        # Small pause between requests to be polite to the API
        time.sleep(1)

    # Save results to a JSON file
    with open("saic_malaga_results.json", "w", encoding="utf-8") as f:
        json.dump(results, f, ensure_ascii=False, indent=2)
    print("\n✅ Results saved to saic_malaga_results.json")


if __name__ == "__main__":
    main()
```

### What this script does 🚀
1. **Replicates the connector** — same URL, headers, and payload structure as the YAML.
2. **Sends a list of messages** sequentially (`MESSAGES` — edit freely).
3. **Extracts the reply** using the same `response.0.text` path.
4. **Handles errors gracefully** (HTTP errors, missing fields).
5. **Saves everything** to `saic_malaga_results.json` for inspection.

### Tips 💡
- If you want to test **multiple conversations**, change the `conversation` and `sender` IDs per request — some APIs require a fresh `conversation` ID for each new session.
- The `Authorization` header here is the bot's public token — keep it safe if you commit this file.
- If the API rate-limits you, bump the `time.sleep(1)` value.
