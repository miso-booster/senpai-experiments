## 🐍 Complete Python Script

Here's a full script that loads the connector and sends **multiple requests** to it. It uses the `CustomChatbot` class from your `chatbot_connectors` package, and includes a small HTML-stripping helper so the replies look clean.

```python
"""
send_multiple.py
----------------
Loads the SAIC Málaga YAML connector and sends multiple messages to it.
"""

import re
from chatbot_connectors.implementations.custom import CustomChatbot


def strip_html(text: str) -> str:
    """Remove HTML tags and decode basic entities from a response string."""
    if not text:
        return ""
    # Remove tags
    clean = re.sub(r"<[^>]+>", "", text)
    # Decode common entities
    clean = (
        clean.replace("&nbsp;", " ")
             .replace("&amp;", "&")
             .replace("&lt;", "<")
             .replace("&gt;", ">")
             .replace("&quot;", '"')
             .replace("&#39;", "'")
    )
    # Collapse whitespace
    return re.sub(r"\s+", " ", clean).strip()


def main():
    # 1. Load the connector
    bot = CustomChatbot("saic-malaga.yml")

    # 2. Define the messages you want to send
    messages = [
        "hola",
        "¿Cómo puedo pedir cita previa?",
        "¿Cuál es el horario de atención?",
        "Gracias, ¡hasta luego!",
    ]

    # 3. Send each message and print the reply
    for i, msg in enumerate(messages, start=1):
        print(f"\n[{i}/{len(messages)}] 👤 User: {msg}")
        success, response = bot.execute_with_input(msg)

        if success:
            clean_reply = strip_html(response)
            print(f"🤖 Bot : {clean_reply}")
        else:
            print(f"❌ Error: {response}")


if __name__ == "__main__":
    main()
```

### 🧪 What this script does

1. **Loads** the YAML connector via `CustomChatbot("saic-malaga.yml")`.
2. **Iterates** over a list of messages — you can add as many as you like.
3. **Calls** `execute_with_input(msg)` for each one, which returns `(success, response)`.
4. **Cleans** the HTML tags from the bot's reply so it's readable in the terminal.
5. **Prints** a friendly log for each exchange.

## ⚠️ A couple of things to keep in mind

- **Session continuity:** The `conversation` and `sender` IDs are fixed in the YAML. That means all messages in the script share the same conversation context — which is usually what you want for a coherent dialogue. If you need a *fresh* conversation per message, you'd have to generate new IDs dynamically (that would require a small code tweak, not just YAML).
- **HTML in responses:** As noted, the bot returns HTML. The `strip_html()` helper handles the common cases, but if you see leftover tags, you can swap it for `BeautifulSoup` for a more robust cleanup.
- **Rate limits:** If you're sending many messages quickly, add a small `time.sleep(0.5)` between calls to be polite to the API 🙏
