### What this profile does 🚀

- **`setup_method` is the core variable** — it uses `forward()` so each conversation walks through a *different* way of setting up eduroam (auto-installer → manual config → CAT profile → geteduroam app → captive portal). That gives you clean, non-repeating coverage of each method.
- **`device`** and **`error_message`** are randomized per conversation, so the same setup method gets tested against different failure scenarios.
- **`chatbot.output`** captures what a rule would likely want to check later: which method was recommended, the steps given, whether it was resolved, and whether an alternative was suggested.
