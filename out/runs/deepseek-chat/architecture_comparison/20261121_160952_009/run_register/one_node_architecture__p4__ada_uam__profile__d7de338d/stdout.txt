¡Claro que sí! 😊 Vamos a crear un perfil enfocado en obtener los datos de contacto del CAU (teléfono, email, dirección física y horarios). Te dejo un YAML listo para usar, con variables declaradas y `chatbot.output` alineado con lo que quieres extraer.

```yaml
test_name: "Soporte CAU - Datos de contacto"

llm:
  temperature: 0.6
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres un usuario que necesita contactar con el Centro de Atención a Usuarios (CAU)
    de la UAM para resolver una incidencia con tu cuenta ID-UAM. Quieres obtener
    los datos de contacto y el horario de atención para saber cuándo y cómo dirigirte.
  context:
    - personality: personalities/formal-user
    - "Tienes una incidencia con tu cuenta ID-UAM y necesitas contactar con el CAU."
    - "Prefieres tener todos los canales de contacto a mano antes de escribir o llamar."
    - "Te interesa saber el horario de atención para no contactar fuera de plazo."
  goals:
    - "Solicitar el número de teléfono de contacto del CAU."
    - "Pedir la dirección de correo electrónico del CAU."
    - "Preguntar por la dirección física de la oficina de atención del CAU."
    - "Consultar el horario de atención del CAU."

chatbot:
  is_starter: false
  fallback: "¿Me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios. Respondo a preguntas dirigidas al Centro de Atención a Usuarios del servicio de Tecnologías de la Información."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono de contacto del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico de contacto del CAU"
    - physical_address:
        type: string
        description: "Dirección física de la oficina de atención del CAU"
    - service_hours:
        type: string
        description: "Horario de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 15
    max_cost: 0.5
  interaction_style:
    - single questions
```

Un par de notas rápidas 👀:

- Los cuatro campos de `chatbot.output` (`contact_phone`, `contact_email`, `physical_address`, `service_hours`) son los que luego podrás usar en reglas Sensei-check como `conv[0].contact_phone`, etc.
- Si quieres que el perfil sea más exigente, puedes añadir una regla global tipo `data_collected() == True` para verificar que el bot efectivamente entrega los cuatro datos.
- Si prefieres variar el estilo del usuario (por ejemplo, `long phrases` o `make spelling mistakes`), solo tienes que añadirlo dentro de `interaction_style`.
