A few quick notes to make it click 👇

- **`is_starter: false`** — the user speaks first (your goals kick things off), so the bot doesn't need to open the conversation.
- **`fallback`** — I reused the real fallback text from your other pizza profiles so the simulator doesn't loop forever if the bot gets confused. Swap it if your bot's actual fallback differs.
- **`output` fields** — each one maps 1:1 to a goal, so every question you ask has a matching slot to extract. That's the "contract" your rules will rely on later (e.g. a rule could check `conv[0].margarita_price` or `conv[0].delivery_availability`).
- **`margarita_price` uses `type: currency`** — that way `extract_float(...)` and `currency(...)` helpers work nicely on it in rules. If you'd rather keep it as raw text, `string` is fine too.
