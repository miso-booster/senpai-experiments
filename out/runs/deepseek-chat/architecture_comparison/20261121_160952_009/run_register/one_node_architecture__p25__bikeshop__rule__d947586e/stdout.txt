```yaml
name: qa_prices_and_hours
description: Checks opening/closing hours are within 10-20, tune-up is 50, seat is 20, and tire is 20
conversations: 1
active: True
oracle: |
  extract_float(opening_and_closing[0]) >= 10 and extract_float(opening_and_closing[0]) <= 20

```
