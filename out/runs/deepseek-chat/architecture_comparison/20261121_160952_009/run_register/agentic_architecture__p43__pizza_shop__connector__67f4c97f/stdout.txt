```yaml
name: "Test Connector 2"
base_url: "https://api.anotherexample.com"

  path: "/api/chat"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Accept: "application/json"

    message:
      text: "{user_msg}"
response_path: "response.text"
```

## 📋 Qué cambié y por qué

| Cambio | Motivo |
|--------|--------|
| Añadí `Accept: "application/json"` | Muchas APIs devuelven HTML si no se lo pides explícitamente; eso rompería `response.text`. |
| Mantuve `response_path: "response.text"` | Es **correcto** para tu JSON: navega `response → text`. |
| Mantuve el `payload_template` anidado | Coincide exactamente con tu request de ejemplo (`message.text`). |
