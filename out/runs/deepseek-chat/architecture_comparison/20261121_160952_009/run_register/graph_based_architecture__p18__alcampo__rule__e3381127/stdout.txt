## 1) Regla Sensei-check

```yaml
name: eco_friendly_toys_returned
description: El chatbot devuelve una lista no vacía de juguetes eco-friendly (campo eco_friendly_toys del perfil)
conversations: 1
oracle: conv[0].eco_friendly_toys is not None and len(conv[0].eco_friendly_toys) > 0
on-error: "El chatbot no devolvió una lista de juguetes eco-friendly (eco_friendly_toys={conv[0].eco_friendly_toys})"
```

Qué hace exactamente:
- `conversations: 1` → es un oráculo de una sola conversación (no metamórfico).
- `conv[0].eco_friendly_toys is not None` → el slot se ha rellenado (no ha quedado vacío).
- `len(conv[0].eco_friendly_toys) > 0` → la lista tiene al menos un juguete.
- `on-error` → mensaje claro cuando falla, mostrando el valor recibido.
