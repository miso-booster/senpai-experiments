## What's broken 🔍

The main issue is **structure**: your `chatbot:` block (`is_starter`, `fallback`, `output`) got accidentally nested **inside** `user:` — it's indented under `user.goals`. That means Sensei will try to read `is_starter`, `fallback`, and `output` as part of the user definition, which will fail validation.

There are also a couple of smaller issues:
- `custom_pizza_pricing` uses `type: str` — should be `type: string` (Sensei uses `string`, not `str`).
- `export: 1` — should be a boolean (`true`/`false`), not `1`.
- `interaction_style: single question` — the reserved keyword is **`single questions`** (plural). Using the wrong keyword will raise an error.
