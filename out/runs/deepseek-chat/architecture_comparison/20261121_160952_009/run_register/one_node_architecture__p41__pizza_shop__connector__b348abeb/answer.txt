A couple of quick notes 👀:

- **`response_path`** — the reply lives at `messages[0][0].message.text`, so the dot path is `messages.0.0.message.text`. The `data.response_gpt.answer` field also contains the same text, so if you ever prefer that one you can switch to `data.response_gpt.answer`.
- **Session / user IDs** — I kept the values from your sample request. If the bot expects a fresh `session` / `idweb_user` per conversation, you'd need to generate those dynamically (the static YAML connector can't rotate them on its own).
- **Headers** — I only kept the meaningful ones (`Content-Type`, `Accept*`, `Origin`, `Referer`, `User-Agent`). Browser-only headers like `Sec-Fetch-*`, `Priority`, `TE`, `Content-Length`, etc. are usually not required and are safer to omit.
