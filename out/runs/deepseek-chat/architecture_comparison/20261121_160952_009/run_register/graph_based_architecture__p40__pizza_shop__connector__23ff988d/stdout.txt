```yaml
      text: "{user_msg}"

```

### Un par de detalles que te pueden interesar 👀

- **`response_path: "response.0.text"`** → apunta al primer elemento del array `response` y extrae su campo `text`. En tu respuesta de ejemplo eso devuelve `"<p>¡Buenos días!<br><br>¿En qué puedo ayudarte?</p>"`. Ojo: viene con etiquetas HTML, así que si quieres texto limpio tendrás que hacer un pequeño `strip` de HTML después.
- **Headers incluidos**: dejé los que realmente importan para que la API responda bien (`Content-Type`, `Authorization`, `Origin`, `Referer`, `User-Agent`). Los headers de navegador tipo `Sec-Fetch-*`, `Priority`, `Pragma`, etc. no son necesarios para el connector y solo añaden ruido.
- **`{user_msg}`** es el placeholder donde se inyectará el mensaje del usuario en cada llamada.

¿Quieres que te lo deje también con un `name` distinto o que ajuste algo del `response_path`? ¡Dime y lo afinamos! 🙌
