Great question! 😊 Let me walk you through which fields in a SENSEI profile are **not mandatory** — based on the profile documentation.

## Fields you can safely omit

### 1. `llm` (the whole block) 🧠
This is **optional**. If you leave it out, Sensei applies sensible defaults (model, temperature, and `format: text`). You only need it when you want to override the model, set a temperature, or switch to `speech` mode.

> From the FAQ: *"Do I have to define `llm`? No. If omitted, defaults are applied."*

### 2. `chatbot.is_starter` and `chatbot.fallback` ⚙️
These are helpful but not strictly required. `fallback` is strongly recommended (it prevents endless loops when the bot doesn't understand), but it's not a hard requirement.

### 3. `chatbot.output` fields 📦
The `output` list itself is optional — you only need it if you want to extract structured values for validation **or** for Sensei-check rules to read via `conv[i].field`. If you're not validating anything, you can skip it.

### 4. `user.context` 🗒️
Optional. It's great for adding persona details, constraints, or a `personality:` reference, but a profile can run without it.

### 5. `conversation.max_cost` and `goal_style.max_cost` 💸
Both are optional safety caps. Omit them if you don't need spend limits.

### 6. `conversation.interaction_style` 🎭
Optional. If you don't specify it, the simulator just converses naturally (effectively `default`).

### 7. `conversation.goal_style` 🎯
Optional in principle — but note that without it, Sensei won't know how/when to end the conversation, so in practice you'll almost always want to set it (`steps`, `random steps`, or `all_answered`).

---

## What *is* effectively required ✅

To have a meaningful, runnable profile you'll want at minimum:

- `test_name`
- `user.language`
- `user.role`
- `user.goals` (with any `{{variables}}` properly declared)
- `conversation.number`

---

### Quick analogy 🍕
Think of a profile like ordering a pizza: the **crust, sauce, and cheese** are required (name, role, goals, language, number). The **toppings** — `llm`, `context`, `output`, cost caps, interaction styles — are all optional extras you add when you want a specific flavor. 😄
