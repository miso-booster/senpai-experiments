## What's broken 🔍

**1. `is_starter`, `fallback`, and `output` are in the wrong place** 🚨
In your YAML, these three keys are indented under `user:` — but they belong under `chatbot:`. Right now Sensei would try to read them as user fields and fail (or silently ignore them).

**2. `interaction_style` uses an invalid keyword** ❌
`single question` isn't a valid style — the reserved keyword is **`single questions`** (plural). Same family as `all questions`. This one would raise an error.

**3. `export: 1` should be a boolean** ⚠️
`export` expects `true` or `false`, not `1`. Use `export: false` (or `true` if you actually want the CSV).

**4. `type: str` in `custom_pizza_pricing`** ⚠️
The default primitive is **`string`**, not `str`. `str` would only work if you had a custom type named `str` in `types/` — you don't. Change it to `string`.

**5. Missing `number` in `conversation`** ⚠️
Your `conversation` block has no `number` field. Add it (e.g. `number: 3`) so Sensei knows how many conversations to run.
