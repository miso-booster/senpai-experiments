## Why this design works 👀

- **`chatbot.output` is your contract with Sensei-check.** Each field (e.g. `moodle_access_requirements`, `vpn_installation_steps`) can be referenced in rules as `conv[i].<field_name>`. So you can write checks like *"if the user asked about VPN, then `vpn_installation_steps` must not be None"*.
- **`support_confirmation`** is a nice catch-all: it lets you verify the bot didn't just dump a link but actually acknowledged and guided the user.
- **No variables** → `conversation.number: 3` is a plain integer (no `combinations` needed, since there are no `forward`/`pairwise` functions).
- **`single questions`** keeps each turn focused, which makes extraction cleaner and cheaper.
