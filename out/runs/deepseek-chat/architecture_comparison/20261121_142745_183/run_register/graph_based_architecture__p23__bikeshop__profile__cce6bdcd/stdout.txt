## 🔍 What's wrong

### 1. `llm.temperature: low` ❌
Temperature must be a **float** (e.g. `0.0`, `0.7`). `low` is not a valid value — Sensei expects a number.

### 2. `chatbot.output` types `str` and `money` ❌
- `str` is **not** a valid type — the correct primitive is **`string`**.
- `money` is **not** a built-in type. The built-in currency-like type is **`currency`** (or you'd need a custom type in `types/`). Since your project already uses `money` in other profiles, you likely have a custom `types/money.yml` — but if it's not there, it'll fail. Safest bet: use `currency` (built-in) or confirm `types/money.yml` exists.

### 3. `seat_price` and `care_bike` have **no `type`** ❌
Every output field **must** declare a `type`. Without it, extraction fails.

### 4. `conversation.goal_style` is missing ⚠️
You have `number: 5` but no `goal_style`. That means Sensei won't know how/when to end each conversation. You should add one (e.g. `all_answered` or `steps`).

### 5. `conversation.number: 5` with no variables ⚠️
That's fine technically (it just runs 5 conversations), but since you have no `{{variables}}` in your goals, all 5 conversations will be identical. Consider `number: 1` unless you *want* repeated runs.

### 6. `is_starter: False` — check your bot 🤔
Your original `qa.yml` had `is_starter: true`. If your bot **waits** for the user to speak first, keep `true`. If the bot greets first, `false` is correct. Just make sure it matches reality, otherwise the conversation may stall.
