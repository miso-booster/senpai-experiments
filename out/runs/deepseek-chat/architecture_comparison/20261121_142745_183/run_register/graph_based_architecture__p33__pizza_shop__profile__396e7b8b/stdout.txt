Hey there! 😊 Great question — the `chatbot` field is basically the "contract" between your profile and the rest of Sensei (especially the rules you might write later). Let me walk you through it and then give you a ready-to-paste version for your profile.

## What goes in `chatbot`

There are three things you can define:

1. **`is_starter`** — `true` if the *chatbot* sends the first message, `false` if the *user* does. For an information-seeker profile, the user starts, so `false`.
2. **`fallback`** — the bot's *real* fallback message. This helps Sensei avoid endless loops when the bot doesn't understand. Paste the actual text your bot replies with.
3. **`output`** — a schema of fields you want extracted at the end of each conversation. Each field has a `type` and a `description`. These become `conv[i].<field_name>` in Sensei-check rules later.

## Matching your goals to output fields

Your goals ask about five things, so let's extract exactly those five 👇

- **Pizza types** → `pizza_types` (`string`)
- **Margarita price** → `margarita_price` (`money`)
- **Drinks + prices** → `drinks_and_prices` (`string`)
- **Operating hours** → `operating_hours` (`string`)
- **Delivery availability** → `delivery_availability` (`string`)

A couple of quick notes on types:
- `money` is a custom type in your project (used elsewhere in your profiles), so it's safe to reuse here for the price.
- The rest are plain `string` because you're capturing a list or a sentence, not a single number.

## Ready-to-paste `chatbot` block

```yaml
test_name: pizza_and_drinks_information_seeker

llm:
  temperature: 0.3
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer seeking information about pizza types, prices, available drinks, and shop hours before potentially placing an order."
  context:
    - personality: personalities/skeptical-user
    - "You're planning a casual pizza night at home with friends this weekend and are considering ordering from a local pizzeria."
    - "You want to gather all the necessary information before deciding what to order and whether to pick it up or have it delivered."
    - "You have a variety of preferences among your friends, so you need to find options that cater to different tastes."
  goals:
    - "Ask about the available pizza types."
    - "Ask about the price of a Margarita pizza."
    - "Ask about the available drinks and their prices."
    - "Ask about the shop's operating hours."
    - "Ask if they deliver."

chatbot:
  is_starter: false
  fallback: "I'm sorry, I did not get what you said. I can help you ordering predefined or custom pizzas, and then drinks."
  output:
    - pizza_types:
        type: string
        description: "A list of the pizza types offered by the shop. Look for phrases like 'We offer [pizza types]' or a list of available pizzas."
    - margarita_price:
        type: money
        description: "The price of a Margarita pizza. Extract the price, including currency if present. If multiple sizes are mentioned, extract the price for all sizes mentioned."
    - drinks_and_prices:
        type: string
        description: "A list of available drinks and their corresponding prices. Extract the name and price of each drink."
    - operating_hours:
        type: string
        description: "The shop's operating hours, including opening and closing times."
    - delivery_availability:
        type: string
        description: "Indication of whether the shop delivers or not. Look for phrases like 'We deliver' or 'We do not offer delivery'."

conversation:
  number: 3
  max_cost: 0.5
  goal_style:
    all_answered:
      export: false
      limit: 20
  interaction_style:
    - single questions
```
