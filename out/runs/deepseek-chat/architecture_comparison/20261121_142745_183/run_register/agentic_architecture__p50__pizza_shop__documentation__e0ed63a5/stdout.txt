# What is an oracle? 🔍

In SENSEI-check, an **oracle** is the part of a rule that states the **condition to check** — the actual "expected truth" you want to verify over a conversation (or set of conversations). It's a Python-style boolean expression that must evaluate to `True` for the rule to pass.

Based on `sensei-check-doc.md` and `rules-examples.md`, here's the mental model:

## Where it fits in a rule
A rule can express its check in **one of two ways**:

1. **`oracle:`** — a single boolean expression (the "traditional oracle").
2. **`if:` / `then:`** — an implication ("if X, then Y should hold"), which is the preferred style for metamorphic relations.

So `oracle` is the direct, one-shot version: *"this statement must be true."*

## Scope: single vs. multiple conversations
- With `conversations: 1`, the oracle checks **one** conversation (a classic oracle).
- With `conversations: 2` (or more), you can still use `oracle` but you'd reference `conv[0]`, `conv[1]`, etc. — this is where metamorphic testing comes in.
- With `conversations: all`, the oracle runs over the whole batch (global checks).

## Examples from the docs

Single-conversation oracle:
```yaml
name: small_base_price_floor
description: Small pizzas should cost at least $10
conversations: 1
when: size == 'small'
oracle: extract_float(price) >= 10 and currency(price) == 'USD'
```

Global oracle (all conversations):
```yaml
name: unique_order_ids
description: No duplicate order_id across all conversations
conversations: all
oracle: is_unique('order_id')
```

Style/scope oracle:
```yaml
name: scope_guardrails
description: Assistant does not drift from pizza domain
conversations: 1
oracle: only_talks_about('pizza and drink orders, delivery, store info')
```

## Key points to remember
- The oracle is a **boolean expression** — it must be `True` to pass.
- It can use the **helper library** (`extract_float`, `currency`, `language`, `only_talks_about`, `is_unique`, `repeated_answers`, `data_collected`, etc.).
- When it references fields like `price` or `order_id`, those come from the **profile's `chatbot.output`** (or `conv[i].field` for multi-conversation rules).
- You can pair it with `when:` to filter which conversations it applies to, and `yields:` / `on-error:` to produce a helpful failure message.
