Antes de nada, un detalle importante: tu `chatbot.output` declara `application_fee` con `type: money`, pero **`money` no es un tipo por defecto** en Sensei (los válidos son `int`, `float`, `string`, `time(...)`, `date(...)`, `list[...]` o un tipo custom en `types/`). Si no tienes un `types/money.yml`, esa extracción podría fallar. Te dejo una regla que lo verifica, pero ojo con eso ⚠️

### 8) Metamórfica: mismo grado ⇒ misma info de admisión

Como tu perfil usa `forward()` en `grados` y `cursos`, se generan combinaciones. Esta regla compara dos conversaciones con el **mismo grado** y comprueba que la info de admisión sea consistente (mismo enlace):

```yaml
name: same_grado_same_admission_link
description: Dos conversaciones con el mismo grado deben devolver el mismo enlace de admisión
conversations: 2
active: true
when: conv[0].grados_available == conv[1].grados_available
if: conv[0].admission_to_grados_link is not None and conv[1].admission_to_grados_link is not None
then: conv[0].admission_to_grados_link == conv[1].admission_to_grados_link
yields: f"Enlaces de admisión distintos para el mismo grado: {conv[0].admission_to_grados_link} vs {conv[1].admission_to_grados_link}"
```
