Since there's no profile yet, we're in **rule-first design** territory — so I'll pick sensible field names and document them clearly in the `description`. The rule checks that when a user asks about lactose-free products, the chatbot actually confirms availability (and doesn't leave the slot empty).

Here's a single-conversation rule using the `chatbot.output` field `lactose_free_availability`:

```yaml
name: lactose_free_availability_check
description: >
  Checks that when the user asks about lactose-free products, the chatbot
  confirms their availability. Assumes a profile exposing the chatbot.output
  field `lactose_free_availability` (type: string). The rule is profile-bound:
  if the field is renamed or removed in the profile, update this rule.
conversations: 1
active: true
when: utterance_index('user', 'lactose-free products') >= 0
oracle: lactose_free_availability is not None and len(lactose_free_availability) > 0
yields: f"No lactose-free availability info returned: {lactose_free_availability}"
```

A couple of quick notes 👀:

- **`when:`** filters to conversations where the user actually asked about lactose-free products, so the rule doesn't fire on unrelated chats.
- **`lactose_free_availability`** is the field name I chose — when you build the profile, make sure `chatbot.output` includes it, e.g.:

```yaml
chatbot:
  output:
    - lactose_free_availability:
        type: string
        description: Confirmation and details of lactose-free products availability
```

- If you'd rather check that the bot **explicitly confirms** availability (not just returns any text), you can swap the oracle for a semantic check:

```yaml
name: lactose_free_availability_semantic
description: >
  Checks that the chatbot semantically confirms lactose-free product availability.
  Assumes a profile exposing `lactose_free_availability` (type: string).
conversations: 1
active: true
when: utterance_index('user', 'lactose-free products') >= 0
oracle: semantic_content(lactose_free_availability, 'lactose-free products are available') is True
yields: f"Availability not clearly confirmed: {lactose_free_availability}"
```
