1. **`base_url` is wrong** → the request goes to `api.1millionbot.com`, not `api.bot.com`.
2. **`path` is wrong** → it's `/api/public/messages`, not `/api/messages`.
3. **Missing `Authorization` header** → the API requires it (`64e5d1af081211d24e2cfecd`).
4. **Payload is incomplete** → the API needs `conversation`, `sender_type`, `sender`, `bot`, and `url` too.
5. **`response_path` is wrong** → `request.text` just echoes your own message back. The bot's reply lives at `response.0.text`.

```yaml
name: "Connector"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

- The `conversation`, `sender`, and `bot` IDs look like **session-specific values** captured from your browser. If the bot stops responding after a while, you may need to refresh those IDs (or check whether the API lets you start a new conversation dynamically).
