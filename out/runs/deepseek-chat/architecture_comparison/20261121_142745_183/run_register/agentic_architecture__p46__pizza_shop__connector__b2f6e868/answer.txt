**What was fixed** (per `custom-connector-guide.md` and `connector-examples.md`):
- `base_url` → `https://api.1millionbot.com` (from the trace `Host`), not `api.bot.com`.
- `path` → `/api/public/messages` (from the trace request line).
- `headers` → added `Authorization: "64e5d1af081211d24e2cfecd"` exactly as provided (no `Bearer`).
- `payload_template` → full body from the trace (`conversation`, `sender_type`, `sender`, `bot`, `language`, `url`, nested `message.text: "{user_msg}"`).
- `response_path` → `response.0.text` (the assistant reply), instead of `request.text` which returned the user's own message.
