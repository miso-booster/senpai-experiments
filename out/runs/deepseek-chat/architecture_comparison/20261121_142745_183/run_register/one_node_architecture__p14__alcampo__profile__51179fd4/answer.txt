¡Buena idea! 🍳 Un perfil enfocado en recomendaciones de recetas y planificación de menús encaja perfecto con el dominio de Alcampo. Te dejo un perfil listo para usar, siguiendo la estructura de tus otros perfiles (mismo estilo de `llm`, `conversation`, `interaction_style`, etc.).

Un par de notas rápidas antes del YAML 👇
- Uso `single questions` para que el usuario vaya preguntando de a una cosa, igual que en tus perfiles existentes.
- Incluí variables con `forward()` para variar el tipo de menú/ocasión y así generar combinaciones.
- Los campos de `chatbot.output` están pensados para que luego puedas escribir reglas (por ejemplo, que las recetas siempre incluyan ingredientes, o que el menú cubra las comidas pedidas).

```yaml
test_name: Recipe Recommendations and Menu Planning

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: >
    You are a home cook planning meals for the week and looking for recipe
    ideas and menu planning help from the Alcampo chatbot.
  context:
    - "personality: personalities/conversational-user"
    - You want to plan balanced meals for the week and are looking for recipe suggestions that use ingredients available at Alcampo.
    - You care about using seasonal ingredients and keeping the menu varied and healthy.
    - You also want practical help turning a chosen recipe into a shopping list.
  goals:
    - "Ask the chatbot to recommend recipes for a {{meal_occasion}}."
    - "Request a weekly menu plan focused on {{dietary_focus}} meals."
    - "Ask which seasonal ingredients are best to use for {{season}} cooking."
    - "Ask the chatbot to list the ingredients needed for a chosen recipe."
    - "Request help adding the ingredients of a recipe to your shopping list."
    - meal_occasion:
        function: forward()
        type: string
        data: [family dinner, quick weekday lunch, weekend brunch, special celebration]
    - dietary_focus:
        function: forward()
        type: string
        data: [vegetarian, high-protein, low-carb, balanced and healthy]
    - season:
        function: forward()
        type: string
        data: [spring, summer, autumn, winter]

chatbot:
  is_starter: false
  fallback: "Parece que tu mensaje no es claro o no es una pregunta relacionada con Alcampo. 😊 ¿En qué puedo ayudarte hoy? Estoy aquí para resolver tus dudas sobre nuestros productos y servicios."
  output:
    - recipe_recommendations:
        type: string
        description: List of recipes recommended by the chatbot
    - menu_plan:
        type: string
        description: Suggested weekly menu plan
    - seasonal_ingredients:
        type: string
        description: Seasonal ingredients suggested for cooking
    - recipe_ingredients:
        type: string
        description: Ingredients listed for a chosen recipe
    - shopping_list_instructions:
        type: string
        description: Steps to add recipe ingredients to the shopping list
    - recipe_search_options:
        type: string
        description: Methods to search recipes by season or category

conversation:
  number: combinations
  max_cost: 0.5
  goal_style:
    steps: 24
  interaction_style:
    - single questions
```

Si quieres, puedo también proponerte una **regla de Sensei-check** que verifique, por ejemplo, que cuando el usuario pide ingredientes de una receta, el chatbot efectivamente los devuelva (`recipe_ingredients` no vacío). ¿Te la preparo? 😊
