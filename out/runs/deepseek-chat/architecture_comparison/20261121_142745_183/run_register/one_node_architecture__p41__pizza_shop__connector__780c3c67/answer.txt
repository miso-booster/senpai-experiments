A couple of quick notes so it behaves as expected 👀:

- **`response_path`** — the reply lives at `messages[0][0].message.text`, so the dot path is `messages.0.0.message.text`. If the bot ever returns multiple message bubbles, you may want to check whether the first one is always the right one to extract.
- **Session / user IDs** — I kept the values from your sample (`id_user`, `idweb_user`, `session`). If the API expects a fresh session per run, you'd need to generate those dynamically; the static YAML connector just replays the same ones.
- **Headers** — I only kept the meaningful ones (`Content-Type`, `Accept`, `Accept-Language`, `Origin`, `Referer`). Browser-only headers like `Sec-Fetch-*`, `Priority`, `TE`, `Content-Length`, etc. are added automatically by the HTTP client and aren't needed here.
