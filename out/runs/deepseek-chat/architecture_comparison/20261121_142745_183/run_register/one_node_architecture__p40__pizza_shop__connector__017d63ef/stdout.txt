A couple of quick notes so it behaves nicely 👀:

- **`response_path: "response.0.text"`** — your response nests the reply inside an array, so this grabs the first element's `text` field. The value comes back wrapped in HTML (`<p>...</p>`), so if you want clean text downstream you may want to strip tags later.
- **`{user_msg}`** is the placeholder that gets swapped with the simulated user's message — that's why the payload keeps `message.text` as `"{user_msg}"` instead of the literal `"hola"`.
- I kept the `Authorization`, `Origin`, and `Referer` headers since they look required by the API. The other browser-y headers (`Accept-Language`, `Sec-Fetch-*`, `Priority`, etc.) are usually optional — I left them out to keep it tidy, but you can add them back if the API ever complains.
