        type: string

  number: 3
  max_cost: 0.5
  goal_style:
    steps: 8
  interaction_style:
    - single questions

### What this profile does and why

- **`user.role` / `context`** — describes a UAM community member whose sole mission is to get the CAU's contact details, matching your scenario.
- **`user.goals`** — four plain-string goals, one per requested detail (phone, email, location, hours). No variables needed here, so it stays simple and readable.
- **`chatbot.output`** — the extraction schema, and importantly the **contract for future rules**. I named the fields to match the existing CAU profile conventions (`contact_phone`, `contact_email`, `physical_address`, `service_hours`) so any profile-bound rules you write later can reuse the same field names. These are the fields a rule would read as `conv[i].contact_phone`, etc.
- **`chatbot.fallback`** — I reused the real fallback message from the existing CAU profile to avoid endless loops.
- **`conversation`** — 3 conversations, `single questions` style (asks one thing at a time, natural for gathering contact details), a modest `steps: 8` and a `max_cost` cap for cost safety.
