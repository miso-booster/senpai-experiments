Here's a rule for that — a single-conversation oracle checking that small pizzas cost at least $10 in USD 🍕

```yaml
name: small_pizza_price
description: Checks the base price of small pizzas is at least $10 USD
conversations: 1
active: true
when: size[0] == 'small'
oracle: extract_float(price) >= 10 and currency(price) == 'USD'
yields: f"Wrong price for small pizzas, expected >= $10 USD but got {price}"
```

A couple of things worth flagging 👀:

- **Field names must match your profile's `chatbot.output`.** This rule reads `size` and `price`, so whichever profile you run it against needs to expose those exact slots. Looking at your project, `pizza_order_test_custom.yml` and `pizzaorder_ivan_test.yml` expose `price`, but I don't see a `size` output slot in them — you may need to add one (or adjust the field name) for the `when` filter to work.
- **`>= 10` vs `== 10`:** I used `>=` because a "base price of $10" usually means a floor (add-ons push it higher). If you truly want an exact equality check, swap it to `extract_float(price) == 10` — but be careful, that'll fail on any pizza with toppings.
