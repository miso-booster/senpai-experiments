¡Claro que sí! 😊 Un perfil para un estudiante Erasmus recién llegado encaja perfecto con tu proyecto de la UAM. Te propongo un perfil que:

### Por qué este perfil te sirve para reglas 🔍

Con estos `chatbot.output` puedes escribir reglas como:

- **Completitud**: `data_collected() == True` para asegurar que el bot cubrió cuenta institucional, contraseña, Moodle, Sigma y contacto del CAU.
- **Alcance temático**: `only_talks_about('soporte técnico UAM, ID-UAM, Moodle, Sigma, CAU, VPN')`.
- **Idioma**: `responds_in_same_language()` (útil si algún día añades `change language`).
- **Presencia de contacto**: `semantic_content(cau_contact_info, 'email o teléfono del CAU')`.
