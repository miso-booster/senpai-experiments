### Entonces, ¿qué podría estar fallando?

Si el conector no te funciona, el problema probablemente **no está en el YAML**, sino en otra parte. Te dejo un checklist rápido:

1. **¿La URL completa es correcta?** El conector concatena `base_url` + `path` → `https://api.anotherexample.com/api/chat`. Verifica que ese endpoint exista realmente.
2. **¿El servidor espera algún header extra?** (Authorization, API key, etc.) Si es así, agrégalo en `headers`.
3. **¿El método es POST?** Sí, lo tienes bien.
4. **¿El servidor devuelve el JSON con ese formato exacto?** Si en algún caso devuelve `status: "error"` sin `response.text`, el `response_path` fallará. Podrías probarlo primero con `curl` o Postman.
