## Regla propuesta

```yaml
name: eco_friendly_toys_returned
description: The chatbot must return a non-empty list of eco-friendly toys during the conversation
conversations: 1
oracle: conv[0].eco_friendly_toys is not None and len(conv[0].eco_friendly_toys) > 0
on-error: "Expected a non-empty eco_friendly_toys list, got: {conv[0].eco_friendly_toys}"
```

### Qué hace esta regla 👀

- **`conversations: 1`** → es una regla de una sola conversación (un oráculo clásico, no metamórfico).
- **`conv[0].eco_friendly_toys`** → accede al slot del perfil. Recuerda: el nombre debe coincidir **exactamente** con el campo declarado en `chatbot.output`.
- **`is not None and len(...) > 0`** → comprueba que el slot se ha rellenado y que la lista no está vacía.
- **`on-error`** → mensaje útil para depurar cuando falla.
