¡Hola! 😊 ¡Claro que sí! Te ayudo a crear un perfil de Sensei para simular a un usuario que quiere configurar **eduroam** en su dispositivo pero no lo consigue. Antes de escribir el YAML, déjame contarte cómo lo voy a estructurar para que encaje bien con tus perfiles existentes del proyecto `ada_uam`:

- **Variables en `user.goals`**: usaré `forward()` para recorrer los distintos **métodos de configuración** que el usuario podría intentar (app oficial, manual, asistente web, etc.) y también el **sistema operativo** del dispositivo, así generamos combinaciones realistas.
- **`chatbot.output`**: campos pensados para que luego puedas escribir reglas de Sensei-check (por ejemplo, verificar que se mencione el método correcto, que se dé un enlace de descarga, etc.).
- **`interaction_style`**: mantengo `single questions` como en el resto de tus perfiles, para ser consistente.

Aquí tienes el perfil completo 👇

```yaml
test_name: "Configuración de eduroam en el dispositivo"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Usuario que intenta configurar la red eduroam en su dispositivo pero no lo
    consigue. Está frustrado porque necesita conexión a internet para sus tareas
    académicas y no entiende por qué la configuración falla.
  context:
    - personality: personalities/impatient-user
    - "Eres miembro de la comunidad universitaria y necesitas eduroam para acceder a los recursos del campus y trabajar desde cualquier lugar."
    - "Ya has intentado configurarlo por tu cuenta siguiendo tutoriales, pero algo siempre sale mal (no conecta, pide credenciales incorrectas, el certificado no valida...)."
    - "No sabes si el problema es tu dispositivo, tus credenciales o el método que estás usando."
    - "Necesitas instrucciones claras y específicas para tu sistema operativo."
  goals:
    - "Explicar que no consigo conectarme a eduroam en mi dispositivo con {{sistema_operativo}} y pedir ayuda."
    - "Preguntar cuál es el método recomendado para configurar eduroam usando {{metodo_configuracion}}."
    - "Solicitar los pasos detallados para configurar eduroam en {{sistema_operativo}} mediante {{metodo_configuracion}}."
    - "Preguntar qué credenciales debo usar (usuario y contraseña) para eduroam y si son las mismas que las de ID-UAM."
    - "Consultar qué hacer si la configuración falla o el dispositivo no se conecta tras seguir los pasos."
    - sistema_operativo:
        function: forward()
        type: string
        data: [Windows, macOS, Android, iOS, Linux]
    - metodo_configuracion:
        function: forward(sistema_operativo)
        type: string
        data:
          - "la aplicación oficial eduroam CAT"
          - "la configuración manual de la red"
          - "el asistente web de configuración"
          - "el instalador descargado desde el portal del CAU"

chatbot:
  is_starter: false
  fallback: "¿Puedes preguntármelo de otra forma? o, si lo prefieres, puedes consultar nuestro catálogo de servicios. Respondo a preguntas dirigidas al Centro de Atención a Usuarios del servicio de Tecnologías de la Información."
  output:
    - recommended_method:
        type: string
        description: "Método de configuración recomendado para eduroam"
    - configuration_steps:
        type: string
        description: "Pasos detallados para configurar eduroam"
    - credentials_info:
        type: string
        description: "Credenciales necesarias (usuario y contraseña) para eduroam"
    - download_link:
        type: string
        description: "Enlace de descarga del instalador o app de configuración"
    - troubleshooting_info:
        type: string
        description: "Indicaciones para resolver fallos de conexión"
    - support_contact:
        type: string
        description: "Información de contacto del CAU para soporte adicional"

conversation:
  number: combinations(0.5, forward)
  goal_style:
    steps: 20
    max_cost: 0.1
  interaction_style:
    - single questions
  max_cost: 0.5
```

### Un par de notas rápidas para que lo aproveches al máximo ✨

1. **`combinations(0.5, forward)`**: como tienes dos `forward()` anidados (`metodo_configuracion` depende de `sistema_operativo`), Sensei genera una matriz de combinaciones. Con `0.5` ejecutas la mitad de ellas — si quieres cubrirlas todas, cambia a `combinations` o `combinations(1, forward)`.
2. **`chatbot.output`**: los campos están pensados para que puedas escribir reglas después, por ejemplo:
   ```yaml
name: recommended_method_implies_configuration_steps
description: If a recommended method is provided, configuration steps must also be present
conversations: 1
if: conv[0].recommended_method is not None
then: conv[0].configuration_steps is not None
```
   Así verificas que el bot no recomiende un método sin dar los pasos. 😉
3. **Personalidad**: usé `impatient-user` porque encaja con la frustración de no poder conectarse. Si prefieres otro tono, cámbialo por `formal-user` o `curious-user` (los que ya usas en tus otros perfiles).
