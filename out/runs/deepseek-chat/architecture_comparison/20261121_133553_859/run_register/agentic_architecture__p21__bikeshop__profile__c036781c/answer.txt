- **Scenario fit:** The simulated user is a new-bike owner who wants the shop to set the bike up and swap the **seat** and **handlebar grips** — exactly your use case.
- **Conventions matched:** I followed the style of your existing bike profiles (`bike_repair_and_maintenance_scheduler.yaml`, `bike_service_and_repair_inquirer.yaml`): same `llm` block, the same shop `fallback` line, the `single questions` interaction style, and the `all_answered` goal style with a `limit`.
- **`chatbot.output` as the rules contract:** Per `sensei-chat-guide.md` (§2.1), these output fields are what Sensei-check rules will later read as `conv[i].<field>`. - **Price type:** I used `currency` for the price, which is the built-in type the docs recommend for monetary values.
