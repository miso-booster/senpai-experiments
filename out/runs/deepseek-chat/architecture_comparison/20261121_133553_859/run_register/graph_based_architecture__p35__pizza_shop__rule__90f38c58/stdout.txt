A few quick notes so it works smoothly for you 👇

- **`when: size == 'small'`** — this filters to only the conversations where the pizza size is `small`, so the rule only fires on relevant cases. (In single-conversation rules you reference fields directly, without the `conv[i].` prefix.)
- **`extract_float(price) == 10`** — this pulls the numeric value out of your `price` field (e.g. `"10.00 USD"` → `10.0`) and compares it. Using `extract_float` is safer than a substring check.
- **Field names** — `size` and `price` must exist in your profile's `chatbot.output`. Since your `more_toppings_cost_more` rule already uses `conv[0].size` and `conv[0].price`, you're all set there ✅
