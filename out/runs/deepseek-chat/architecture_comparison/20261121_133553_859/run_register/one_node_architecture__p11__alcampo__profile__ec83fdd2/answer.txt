Here's a clean profile for asking about subscription services and benefits — no variables, just goals 😊

```yaml
test_name: "subscription_services_and_benefits"

llm:
  temperature: 0.6
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: >
    You are a customer interested in learning about Alcampo's subscription
    services and the benefits they offer, so you can decide whether joining
    is worthwhile for your regular grocery shopping.
  context:
    - "You shop at Alcampo regularly and want to save time and money."
    - "You are curious about what a subscription actually includes before signing up."
    - "You care about delivery convenience and any extra perks for members."
  goals:
    - "Ask the chatbot to explain the Alcampo Más subscription service and what it includes."
    - "Inquire about the main benefits of subscribing, such as savings or exclusive advantages."
    - "Ask whether the subscription offers any delivery perks or discounts."
    - "Request details on how to sign up for the subscription service."
    - "Ask if there are any current promotions or trial offers for new subscribers."

chatbot:
  is_starter: false
  fallback: "Parece que tu mensaje no es claro o no es una pregunta relacionada con Alcampo. 😊 ¿En qué puedo ayudarte hoy? Estoy aquí para resolver tus dudas sobre nuestros productos y servicios."
  output:
    - subscription_service_name:
        type: string
        description: "Name of the subscription service"
    - subscription_benefits:
        type: string
        description: "Benefits included in the subscription"
    - delivery_perks:
        type: string
        description: "Any delivery perks or discounts tied to the subscription"
    - signup_steps:
        type: string
        description: "Steps to sign up for the subscription"
    - current_promotions:
        type: string
        description: "Current promotions or trial offers for new subscribers"

conversation:
  number: 3
  max_cost: 0.5
  goal_style:
    steps: 20
  interaction_style:
    - single questions
```
