Quick heads-up before the YAML: for this rule to work, your profile's `chatbot.output` needs a `drink` field (so the rule can tell "with drink" vs "without drink") and a `price` field. Your `pizza_and_drink_order_placement` profile exposes `total_cost` rather than `price`, so if you're targeting that one, swap `price` → `total_cost` in the rule below. 👇

```yaml
name: adding_drink_costs_two_extra
description: Adding a drink to an otherwise identical pizza order costs exactly 2 dollars more
conversations: 2
when: conv[0].size == conv[1].size and conv[0].pizza_type == conv[1].pizza_type and conv[0].number == conv[1].number
if:   conv[0].drink is not None and conv[1].drink is None
then: extract_float(conv[0].price) - extract_float(conv[1].price) == 2
```

A few notes so it behaves nicely 🧠:

- **`when`** keeps the two conversations comparable (same pizza size, type, and quantity) — that's the *ceteris paribus* part of metamorphic testing.
- **`if`/`then`** reads like a law: *"If one order has a drink and the other doesn't, then the price difference is exactly $2."*
- If your drink price can vary (e.g., different drink types), you might want `>= 2` or a tolerance like `abs(... - 2) < 0.01` to avoid float rounding issues.
