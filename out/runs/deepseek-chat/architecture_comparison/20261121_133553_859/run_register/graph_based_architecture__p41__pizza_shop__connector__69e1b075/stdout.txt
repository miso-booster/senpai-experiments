### 🔍 Un par de detalles importantes

- **`response_path`**: la respuesta viene con una estructura de doble array (`messages` → array → array → objeto). Por eso usamos `messages.0.0.message.text` para llegar al texto del bot. Si en algún momento la API devuelve un array con varios mensajes, este path toma el primero.
- **`session` e `id_user`**: los he dejado fijos tal como venían en tu captura. Si quieres que cada conversación tenga una sesión distinta, tendrías que generarlos dinámicamente (eso ya requeriría tocar código, no solo YAML).
- **Headers**: solo incluí los que realmente importan para que la petición funcione (Content-Type, Origin, Referer, User-Agent). Los demás (`Sec-Fetch-*`, `Priority`, `TE`, etc.) son generados automáticamente por el navegador y no suelen ser necesarios.
