## What I found in your project

Three profiles already expose an `order_id` field in `chatbot.output`:

| Profile | `order_id` type | Other outputs |
|---|---|---|
| `pizza_and_drink_order_placement.yaml` | `string` | pizza_options, drink_options, order_summary, total_cost, estimated_readiness_time, pickup_location |

Since the field name is `order_id` in all of them, the rule below works for any of these profiles. 👇

## The rule

```yaml
name: order_id_provided
description: The chatbot must provide an order_id at the end of the conversation (profile-bound, reads chatbot.output.order_id)
active: True
conversations: 1
oracle: order_id is not None and str(order_id).strip() != ""
yields: "Chatbot did not provide an order_id (got: {order_id})"
```

## Why it's written this way

- **`conversations: 1`** → this is a single-conversation oracle, not a metamorphic relation. We're checking one conversation's extracted output.
- **`oracle: order_id is not None and str(order_id).strip() != ""`** → the extractor fills `order_id` from `chatbot.output`; if the bot never gave one, it stays `None`. The extra `strip()` guard also rejects empty/whitespace-only values, which is a common false positive.
- **`yields`** → gives you a helpful failure message showing what was actually extracted (per the `yields` pattern in `rules-examples.md`).
- **`active: True`** → the rule runs by default; flip to `False` to park it.

## Two alternatives depending on what you mean by "provided"

**1. Stricter — the whole output schema must be complete** (uses the `data_collected()` / `missing_slots()` helpers from `sensei-check-doc.md`):

```yaml
name: order_id_provided_strict
description: All chatbot.output slots are filled, including order_id
active: True
conversations: 1
oracle: data_collected() is True and 'order_id' not in missing_slots()
yields: "Missing slots: {missing_slots()}"
```

**2. Global — order IDs must also be unique across the batch** (from the docs' `is_unique` example):

```yaml
name: unique_order_ids
description: Every conversation has a unique order_id
active: True
conversations: all
oracle: is_unique('order_id')
```
