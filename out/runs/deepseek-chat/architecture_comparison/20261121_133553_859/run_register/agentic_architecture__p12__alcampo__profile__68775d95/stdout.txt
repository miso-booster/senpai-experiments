Here's a profile that simulates a user asking the chatbot to add items to their shopping cart. I matched the project's conventions (Alcampo grocery bot, English, `gpt-4o-mini`, `single questions`, Spanish fallback) and used variables so each conversation covers different products/quantities.

```yaml
test_name: Shopping Cart Item Addition

llm:
  temperature: 0.9
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: >
    You are a customer shopping online at Alcampo and you want to build up your
    shopping cart by asking the chatbot to add specific products to it.
  context:
    - "personality: personalities/formal-user"
    - You are preparing your weekly grocery order and adding items one by one to your cart.
    - You care about getting the right product and the correct quantity added.
    - You want to confirm what is currently in your cart after adding items.
  goals:
    - "Ask the chatbot to add {{quantity}} {{product}} to your shopping cart."
    - "Ask the chatbot to add {{second_product}} to your cart as well."
    - "Ask the chatbot to confirm what items are currently in your shopping cart."
    - "Ask the chatbot for the current total number of items in your cart."
    - product:
        function: forward()
        type: string
        data:
          - milk
          - eggs
          - whole wheat bread
          - olive oil
          - chicken breast
    - quantity:
        function: random()
        type: int
        data:
          min: 1
          max: 6
          step: 1
    - second_product:
        function: another()
        type: string
        data:
          - bananas
          - tomatoes
          - rice
          - pasta
          - yogurt

chatbot:
  is_starter: false
  fallback: Parece que tu mensaje no es claro o no es una pregunta relacionada con Alcampo. 😊 ¿En qué puedo ayudarte hoy? Estoy aquí para resolver tus dudas sobre nuestros productos y servicios.
  output:
    - added_product:
        type: string
        description: The product the user asked to add to the cart
    - added_quantity:
        type: int
        description: The quantity of the product added to the cart
    - cart_contents:
        type: list[string]
        description: The items currently in the shopping cart
    - cart_item_count:
        type: int
        description: Total number of items currently in the shopping cart
    - confirmation_message:
        type: string
        description: The chatbot's confirmation that the item was added

conversation:
  number: 3
  max_cost: 0.5
  goal_style:
    steps: 20
  interaction_style:
    - single questions
```

### What this profile does
- **Role & context**: simulates a customer building a grocery cart at Alcampo, adding products one by one and checking the cart.
- **Goals with variables**: uses `{{product}}` (forward), `{{quantity}}` (random int 1–6), and `{{second_product}}` (another) so each run covers different items and quantities — following the variable/function guidance in `sensei-chat-guide.md` §4.
- **`chatbot.output`**: defines the extraction schema (`added_product`, `added_quantity`, `cart_contents`, `cart_item_count`, `confirmation_message`). These are the fields any profile-bound rules can later reference as `conv[i].<field>` (§2.1.1).
- **Conversation controls**: `number: 3`, `max_cost: 0.5`, `steps: 20`, `single questions` — consistent with the other ordering profiles in your project.
