Here's a profile that simulates a shopper asking the chatbot to add items to their cart 🛒 — it uses `forward()` nesting so you get a nice grid of category × product combinations, and exposes `chatbot.output` fields you can later check with rules.

```yaml
test_name: "add_items_to_cart"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a shopper doing your weekly grocery run on Alcampo's online store.
    You want the chatbot to help you add specific products to your shopping cart,
    confirm quantities, and tell you what is currently in the cart.
  context:
    - "You are a Club Alcampo member and shop online regularly."
    - "You prefer to add items one at a time and confirm each addition."
    - "You care about the running total of your cart."
  goals:
    - "Ask the chatbot to add {{quantity}} unit(s) of {{product}} from the {{category}} category to my cart."
    - "Ask the chatbot to confirm the current contents of my shopping cart."
    - "Ask for the total price of the items currently in my cart."
    - "Ask the chatbot to remove {{product}} from my cart if it was added by mistake."
    - category:
        function: forward()
        type: string
        data: [fresh produce, dairy, beverages, snacks]
    - product:
        function: forward(category)
        type: string
        data:
          - any(3 typical products from the selected category)
    - quantity:
        function: random()
        type: int
        data:
          min: 1
          max: 5
          step: 1

chatbot:
  is_starter: false
  fallback: "Parece que tu mensaje no es claro o no es una pregunta relacionada con Alcampo. 😊 ¿En qué puedo ayudarte hoy?"
  output:
    - added_product:
        type: string
        description: "Name of the product the chatbot added to the cart"
    - added_quantity:
        type: int
        description: "Quantity of the product added to the cart"
    - cart_contents:
        type: list[string]
        description: "Items currently in the shopping cart"
    - cart_total:
        type: currency
        description: "Total price of the items in the cart"
    - removal_confirmation:
        type: string
        description: "Confirmation that the product was removed from the cart"

conversation:
  number: combinations(0.5, forward)
  max_cost: 0.5
  goal_style:
    steps: 10
  interaction_style:
    - random:
      - single questions
      - make spelling mistakes
      - long phrases
```

A couple of notes so it runs smoothly 👇

- **`combinations(0.5, forward)`** works here because you have two nested `forward()` variables (`category` → `product`). If you'd rather keep it simple, swap it for a fixed `number: 3`.
- The `chatbot.output` fields (`added_product`, `cart_total`, etc.) are the contract for any rules you write later — e.g. a rule checking that `cart_total` increases after adding an item would read `conv[0].cart_total`.
- The `any(...)` inside `product.data` asks the LLM to generate realistic product names per category, so you don't have to hardcode a big list.
