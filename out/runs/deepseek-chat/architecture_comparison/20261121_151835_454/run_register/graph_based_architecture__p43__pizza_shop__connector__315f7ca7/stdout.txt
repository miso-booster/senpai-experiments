## ¿Por qué funciona?

**1. El payload coincide con tu request** 🎯
Tu `payload_template` genera exactamente esto:
```json
{
  "message": {
    "text": "hola"
  }
}
```
Que es justo lo que espera la API. El placeholder `{user_msg}` se sustituye por el mensaje del usuario. ¡Perfecto!

**2. El `response_path` apunta bien** 🎯
Tu respuesta es:
```json
{
  "status": "success",
  "response": {
    "text": "¡Hola! ¿Cómo puedo ayudarte hoy?"
  }
}
```
Con `response_path: "response.text"` navegas a `response["text"]` → `"¡Hola! ¿Cómo puedo ayudarte hoy?"`. ¡Exacto! ✅

## Un detalle a tener en cuenta ⚠️

El único punto que **no puedo verificar** es si la API requiere algún tipo de **autenticación** (token, API key, etc.). Si al probarlo recibes un `401` o `403`, tendrías que añadir la cabecera correspondiente, por ejemplo:

```yaml
name: "My Custom Bot"
base_url: "https://api.mychatbot.com"
send_message:
  path: "/chat"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "Bearer tu-api-key"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```
