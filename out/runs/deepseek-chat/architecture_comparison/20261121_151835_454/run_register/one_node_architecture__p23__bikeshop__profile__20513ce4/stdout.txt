Hey there! 👋 Happy to help you fix this profile — I can spot a few things that will definitely cause it to fail. Let me walk you through them and then give you a clean version 😊

## What's broken 🔧

1. **`llm.temperature: low`** → must be a **float** (e.g. `0.0`, `0.6`). `low` is not valid.
2. **`type: str`** → the correct primitive is **`string`** (not `str`).
3. **`type: money`** → `money` is **not a built-in type**. You'd need a custom type in `types/money.yml`, or use `currency` (also custom) — simplest is to use `float` or `string` unless you actually have that custom type defined.
4. **`seat_price` and `care_bike` have no `type`** → every output field **requires** a `type`.
5. **`conversation.goal_style` is missing** → you need to tell Sensei how/when the conversation ends (e.g. `steps` or `all_answered`).
6. **`interaction_style: [default]`** → `default` is fine as a keyword, but combined with no `goal_style` the run has no stopping rule. I'll add `all_answered` which fits your "ask these 5 things" setup nicely.

  temperature: 0.0
  model: gpt-4o-mini

  language: English

  is_starter: false
  fallback: "I'm sorry it's a little loud in my shop, can you say that again?"
  output:
    - opening_and_closing:
        type: string
        description: the opening and closing time of the shop
    - tire:

        type: float

        type: float

        type: string
        description: actions to take care of the bike

  number: 5
  goal_style:
    all_answered:
      export: true
      limit: 9
  interaction_style:
    - default
