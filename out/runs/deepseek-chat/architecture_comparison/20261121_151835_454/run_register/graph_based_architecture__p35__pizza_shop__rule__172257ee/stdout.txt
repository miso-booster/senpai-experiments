- **`extract_float(price) == 10`** — this pulls the number out of the price field (e.g. `"10.00 EUR"` → `10.0`) and compares it. If you also want to pin the currency, you can extend it like this:

```yaml

description: A small pizza must cost $10 USD
conversations: 1
when: size == 'small'
oracle: extract_float(price) == 10 and currency(price) == 'USD'
```

- **Exact match caveat** ⚠️ — `== 10` is strict. If your prices might include cents or rounding (e.g. `10.50`), consider a tolerance instead, like `abs(extract_float(price) - 10) < 0.01`.
