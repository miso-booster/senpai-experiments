```yaml
name: bike_shop_price_and_hours_check

  Checks the bike_shop profile outputs: opening/closing time between 10 and 20,
```

## A couple of things to double-check ⚠️

1. **`opening_and_closing` is a `str`** — so `extract_float` will grab the *first* number it finds. If the assistant says something like `"We open at 10 and close at 20"`, `extract_float` returns `10` and the `<= 20` check passes ✅. But if it says `"9 to 21"`, it'll return `9` and fail — which is actually what you want (out of range). Just be aware it only checks the **first** number, not both. If you need to verify *both* opening and closing are in range, you'd need to split the string first — let me know and I can help with that! 🔧

2. **`seat_price` is typed as `str`** in your profile, but you're comparing it to `20`. `extract_float` handles that fine (it parses `"20"` or `"$20"` → `20.0`), so no problem there. Same for `tire` and `tune_up` (typed `money`).

3. **`care_bike`** — you didn't specify a constraint for it, so I left it out. If you want to check it (e.g., that it's non-empty, or mentions something specific), just say the word and I'll add a `semantic_content(...)` or `data_collected()` check. 🚲

```yaml
name: bike_shop_hours_and_prices_strict

```
