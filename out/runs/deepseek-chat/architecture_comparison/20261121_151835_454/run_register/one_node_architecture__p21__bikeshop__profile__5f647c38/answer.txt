Hey there! 😊 Happy to help you build that profile — a customer bringing in a freshly bought bike to get it set up to their liking (new seat + handlebar grips). Here's a profile that fits your bikeshop project and follows the same style as your existing ones:

```yaml
test_name: bike_setup_customization

llm:
  temperature: 0.6
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: >
    You are a customer who recently bought a new bike and wants the shop to set it
    up to your liking. You want to change the seat and the handlebar grips so the
    bike feels comfortable and fits you well.
  context:
    - "You just bought a new bike and haven't ridden it much yet."
    - "The stock seat is uncomfortable and the handlebar grips feel too thin for your hands."
    - "You want the shop to help you pick suitable replacements and install them."
    - "You care about comfort and a good fit more than about looks."
  goals:
    - "Explain that you recently bought a new bike and want it set up to your liking."
    - "Ask if the shop can replace the seat with a more comfortable {{seat_type}} one."
    - "Ask if they can swap the handlebar grips for {{grip_type}} grips."
    - "Ask for the price of the new seat and the new grips."
    - "Ask if the shop can install both for you and how long it would take."
    - "Ask if you can schedule an appointment to have the bike set up."
    - seat_type:
        function: forward()
        type: string
        data: [gel, ergonomic, wide, memory foam]
    - grip_type:
        function: forward()
        type: string
        data: [ergonomic, rubber, lock-on, soft]

chatbot:
  is_starter: false
  fallback: "I'm sorry it's a little loud in my shop, can you say that again?"
  output:
    - seat_replacement_confirmation:
        type: string
        description: >
          Confirmation from the chatbot about whether the shop can replace the seat.
          Look for phrases like "Yes, we can replace your seat" or a similar confirmation.
    - grip_replacement_confirmation:
        type: string
        description: >
          Confirmation from the chatbot about whether the shop can replace the handlebar
          grips. Look for phrases like "Yes, we can swap your grips" or similar.
    - seat_price:
        type: money
        description: The price the chatbot provides for the new seat.
    - grip_price:
        type: money
        description: The price the chatbot provides for the new handlebar grips.
    - installation_details:
        type: string
        description: >
          The chatbot's explanation of whether it can install the seat and grips and
          how long the installation would take.
    - appointment_confirmation:
        type: string
        description: >
          Confirmation of the scheduled setup appointment, including the date and time
          if provided.

conversation:
  number: 4
  goal_style:
    all_answered:
      export: false
      limit: 20
  interaction_style:
    - single question
  max_cost: 0.5
```

A few notes so it fits nicely with the rest of your project 👇

- **`chatbot.output` fields** (`seat_price`, `grip_price`, etc.) are the contract for any future Sensei-check rules — you can reference them as `conv[i].seat_price`, `conv[i].grip_price`, etc.
- I used `forward()` on both `seat_type` and `grip_type` so you get a nice deterministic grid of combinations across the 4 conversations. If you'd rather cover more variety with fewer runs, swap them to `pairwise()` and set `number: combinations(0.6, pairwise)`.
- The `fallback` matches the one used across your other bikeshop profiles, so the simulator behaves consistently.
