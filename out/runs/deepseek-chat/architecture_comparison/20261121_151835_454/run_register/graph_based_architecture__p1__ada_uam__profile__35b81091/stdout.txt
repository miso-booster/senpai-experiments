test_name: "Configuración de eduroam en el dispositivo"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >

    has probado varias veces y sigues sin poder conectarte. Pides ayuda paso a paso
    y quieres entender por qué falla.
  context:
    - personality: personalities/impatient-user
    - "Tienes credenciales institucionales válidas (usuario y contraseña de la universidad)."
    - "Ya has intentado conectarte a la red 'eduroam' pero el dispositivo no completa la autenticación."
    - "No estás seguro de si el problema es el certificado, el método de configuración o tu contraseña."
    - "Necesitas instrucciones claras y específicas para tu sistema operativo."
  goals:
    - "Explicar que no consigues conectarte a eduroam en tu dispositivo {{dispositivo}} con {{sistema_operativo}} y pedir ayuda."
    - "Preguntar cuál es el método de configuración recomendado: {{metodo_configuracion}}."
    - "Pedir los pasos detallados para configurar eduroam usando {{metodo_configuracion}} en {{sistema_operativo}}."
    - "Preguntar qué certificado o datos de autenticación debes introducir y si el usuario es {{formato_usuario}}."
    - "Consultar qué hacer si tras seguir los pasos sigue sin conectar, y a quién contactar para soporte."
    - dispositivo:
        function: forward()
        type: string
        data: [portátil, móvil, tablet]
    - sistema_operativo:
        function: forward(dispositivo)
        type: string
        data: [Windows, macOS, Android, iOS]
    - metodo_configuracion:
        function: pairwise()
        type: string
        data:
          - "la aplicación oficial eduroam CAT"
          - "la configuración manual con certificado"
          - "el asistente web de configuración"
          - "el perfil de configuración descargable"
    - formato_usuario:
        function: pairwise()
        type: string
        data:
          - "usuario@universidad.es"
          - "usuario sin dominio"
          - "el correo institucional completo"

chatbot:
  is_starter: false
  fallback: "¿Me puedes repetir la pregunta con otras palabras? También puedes consultar nuestro catálogo de servicios. Respondo a preguntas dirigidas al Centro de Atención a Usuarios del servicio de Tecnologías de la Información."
  output:

### Un par de notas rápidas para que lo aproveches al máximo ✨

- **`forward()` anidado** (`sistema_operativo` depende de `dispositivo`) genera una matriz de combinaciones dispositivo × SO. Con `pairwise()` en `metodo_configuracion` cubres todos los pares método × dispositivo/SO sin explotar el número total de casos.
- **`conversation.number: combinations(0.6, pairwise)`** toma el 60 % de la matriz de combinaciones pairwise — recuerda que necesitas al menos dos funciones `pairwise`/`forward` anidadas para que esto funcione (aquí las tienes 👍).
- **`chatbot.output`** está pensado para que luego puedas escribir reglas tipo `conv[0].recommended_method is not None` o comprobar que `configuration_steps` menciona el SO pedido.
