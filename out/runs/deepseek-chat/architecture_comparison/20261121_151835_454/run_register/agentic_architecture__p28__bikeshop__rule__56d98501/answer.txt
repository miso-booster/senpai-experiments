oracle: responds_in_same_language()

### Why this works
- **`responds_in_same_language()`** is a built-in helper (from `sensei-check-doc.md` and `rules-examples.md`) that checks whether the assistant's replies match the language the user wrote in. It returns `True`/`False`.
- **`conversations: 1`** — this is a single-conversation oracle, so it's evaluated per conversation.
- **`yields`** — a helpful message shown when the rule fails (the docs use `yields` for the failure message; note the canonical example in `rules-examples.md` uses exactly this pattern).

- This is a **profile-agnostic / global rule** — it relies only on the generic helper and doesn't reference any `chatbot.output` fields, so it works across all your profiles. No profile confirmation needed. ✅
