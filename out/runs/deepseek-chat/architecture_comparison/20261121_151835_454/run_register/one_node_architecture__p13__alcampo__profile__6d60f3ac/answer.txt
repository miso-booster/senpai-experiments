### Qué estaba mal 🔍
En tu versión, el primer elemento de `output` se veía así:

```yaml
  output:

      type: string
      description: Focus of the 'Cultivamos lo Bueno' label
```

Faltaba la línea `- label_focus:` — sin ella, YAML no sabe a qué campo pertenecen `type` y `description`, y el parser se rompe. En la versión corregida ya está restaurado. ✅
