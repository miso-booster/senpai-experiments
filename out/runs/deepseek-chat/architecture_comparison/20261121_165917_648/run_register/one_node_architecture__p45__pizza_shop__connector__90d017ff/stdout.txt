    Authorization: "64e5d1af081211d24e2cfecd"

A couple of friendly notes 😊:

- **Minimal headers** — I kept `Content-Type`, `Authorization`, `Origin`, and `Referer` (the last two are often required by 1millionbot's CORS-style checks), and dropped any `Sec-Fetch-*` / `User-Agent` browser noise as you asked.
- **HTML stripping** — the YAML connector spec only supports extracting a value via `response_path`; it doesn't run transformations. So `response.0.text` will come back as `"<p>¡Buenos días!<br><br>¿En qué puedo ayudarte?</p>"`. If you need clean text, the usual approach is to strip tags in the calling code (e.g., a small regex or `BeautifulSoup`), or add a post-processing step in your pipeline.
