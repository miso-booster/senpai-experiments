¡Hola! 😊 ¡Claro que sí! Te ayudo a crear un perfil para Sensei sobre un usuario que intenta configurar eduroam en su dispositivo y no lo consigue. Antes de escribir el YAML, déjame contarte cómo lo voy a plantear para que encaje bien con tu proyecto `ada_uam`:

- **Rol y contexto**: un usuario (estudiante o personal) que necesita conectar su dispositivo a la red eduroam y está frustrado porque no lo logra.
- **Variables**: las distintas formas/métodos que podría intentar para configurarlo (sistema operativo, tipo de dispositivo, método de configuración, etc.), usando `forward()` para que se cubran combinaciones y `pairwise()` donde tenga sentido.
- **`chatbot.output`**: campos que luego podrás usar en reglas de Sensei-check (pasos de configuración, requisitos, contacto de soporte, etc.).
- **Estilo de interacción**: `single questions` para ir preguntando paso a paso, igual que en tus otros perfiles.

Aquí tienes el perfil completo 👇

```yaml
test_name: "Configuración de eduroam en el dispositivo"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Usuario que necesita configurar la red eduroam en su dispositivo para
    acceder a internet en el campus, pero no consigue completar la configuración
    y busca ayuda paso a paso.
  context:
    - personality: personalities/impatient-user
    - "Eres miembro de la comunidad universitaria (estudiante o personal) y necesitas conexión a internet para tus tareas diarias."
    - "Has intentado configurar eduroam varias veces siguiendo instrucciones que encontraste, pero algo falla y no logras conectarte."
    - "No estás seguro de qué credenciales usar ni de si tu dispositivo es compatible con el método de configuración que estás probando."
  goals:
    - "Explicar que no consigo conectarme a eduroam desde mi {{dispositivo}} y pedir ayuda para configurarlo."
    - "Preguntar cuál es el método de configuración recomendado para {{sistema_operativo}}."
    - "Solicitar los pasos detallados para configurar eduroam usando {{metodo_configuracion}}."
    - "Preguntar qué credenciales debo introducir (usuario y contraseña) para eduroam."
    - "Consultar a quién puedo contactar si sigo sin poder conectarme tras intentarlo."
    - dispositivo:
        function: forward()
        type: string
        data: [portátil, móvil, tablet]
    - sistema_operativo:
        function: forward(dispositivo)
        type: string
        data: [Windows, macOS, Linux, Android, iOS]
    - metodo_configuracion:
        function: forward()
        type: string
        data:
          - instalador automático (eduroam CAT)
          - configuración manual de la red
          - perfil de configuración descargable
          - asistente del servicio de TI

chatbot:
  is_starter: false
  fallback: "¿Me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios. Respondo a preguntas dirigidas al Centro de Atención a Usuarios del servicio de Tecnologías de la Información."
  output:
    - eduroam_setup_steps:
        type: string
        description: "Pasos para configurar eduroam en el dispositivo"
    - recommended_method:
        type: string
        description: "Método de configuración recomendado para el sistema operativo"
    - required_credentials:
        type: string
        description: "Credenciales necesarias (usuario y contraseña) para eduroam"
    - device_compatibility:
        type: string
        description: "Compatibilidad del dispositivo con eduroam"
    - support_contact:
        type: string
        description: "Contacto de soporte para problemas de conexión"
    - troubleshooting_tips:
        type: string
        description: "Consejos para resolver problemas de conexión"

conversation:
  number: combinations(0.6, forward)
  goal_style:
    steps: 25
    max_cost: 0.5
  interaction_style:
    - single questions
  max_cost: 0.5
```

### Un par de notas rápidas para que lo tengas claro 💡

- **`forward(dispositivo)` en `sistema_operativo`**: así cada dispositivo se empareja con sistemas operativos coherentes en la matriz de combinaciones. Si prefieres que se generen todas las combinaciones sin restricción, puedes dejarlo como `forward()` sin argumento.
- **`pairwise()` en `metodo_configuracion`**: cubre que cada método se pruebe al menos una vez junto a cada dispositivo/SO, sin explotar en combinaciones. Recuerda que necesitas **al menos dos funciones `pairwise()`** para usar `combinations(..., pairwise)`; aquí solo hay una, así que si quieres ese `number`, añade otra variable con `pairwise()` o cambia a `combinations` simple. Si no, con `number: 3` o similar también funciona perfecto.
- **`chatbot.output`**: los campos están pensados para que luego puedas escribir reglas de Sensei-check, por ejemplo verificando que `eduroam_setup_steps` no esté vacío o que `support_contact` incluya un correo/teléfono.

¿Quieres que ajuste algo? Por ejemplo, añadir más métodos de configuración, cambiar el idioma a inglés, o incluir una variable con `pairwise()` extra para que el `combinations(0.6, pairwise)` funcione tal cual. ¡Dime y lo pulimos juntos! 🙌
