## The rule

```yaml
name: promotions_mentioned
description: The chatbot must provide information about current promotions when asked
conversations: 1
oracle: utterance_index('assistant', 'current promotions or discounts') > 0
```

## Why this works 🧠

Since you don't want it tied to any profile, we lean on **generic helpers** — no `chatbot.output` fields involved. Here's the breakdown:

- **`conversations: 1`** → it's a single-conversation oracle, so each conversation is checked on its own.
- **`utterance_index('assistant', 'current promotions or discounts')`** → this is an LLM-backed helper that returns the turn index where the assistant mentions the topic. If it returns `> 0`, the bot did bring up promotions somewhere in the dialogue. If it never does, you get `0` (or a non-positive value) and the rule fails. ✅

`utterance_index` is **LLM-backed**, so expect a little natural variability — it's great for "did the bot mention X?" checks, but don't rely on exact turn numbers being rock-solid across runs. If you want a more deterministic feel, keep the threshold loose (like `> 0`).
