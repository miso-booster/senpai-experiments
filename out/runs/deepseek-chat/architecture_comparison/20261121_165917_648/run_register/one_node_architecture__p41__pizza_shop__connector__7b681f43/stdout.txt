A couple of quick notes so it behaves nicely 😊:

- **`response_path`** → the reply lives at `messages[0][0].message.text`, so the dot path is `messages.0.0.message.text`. If the API ever returns multiple bubbles, you may want to check the other indexes too.
- **Session / user IDs** are hardcoded from your sample. If the bot expects a fresh `session` per conversation, you'd need to generate one dynamically — the plain YAML connector can't do that on its own, so let me know if that's a requirement and we can look at options.
- **`Content-Length`, `Host`, `Connection`, `Sec-Fetch-*`, `Priority`, `TE`, `Pragma`, `Cache-Control`** were intentionally left out — those are transport-level headers that the HTTP client sets automatically, and hardcoding them can actually break requests.
