### A solid starting point (single-conversation)

Assuming your profile exposes something like `appointment_confirmed` and `service_type`, here's a clean rule you can adapt:

```yaml
name: bike_service_appointment_confirmed
description: When the user requests a bike service appointment, the chatbot confirms it
conversations: 1
when: service_type == 'bike_service'
if:   appointment_requested is True
then: appointment_confirmed is True
```

Or, if you'd rather check the **dialogue text** (no dedicated boolean slot), you can lean on the `utterance_index` helper:

```yaml
name: bike_service_confirmation_phrase
description: Chatbot must explicitly confirm the bike service appointment
conversations: 1
when: service_type == 'bike_service'
oracle: utterance_index('assistant', 'appointment confirmed') > 0
```
