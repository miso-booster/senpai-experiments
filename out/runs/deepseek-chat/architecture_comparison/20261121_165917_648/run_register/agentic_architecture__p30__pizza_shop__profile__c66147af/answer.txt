### What this does & how it maps to the docs (`sensei-chat-guide.md`)

- **Rude + fast user** 🏃: The `user.role` and `context` describe an impatient, blunt customer who pushes the bot to hurry — no "please/thank you", short demanding phrases.
- **4 goals**: Four goal strings (order the pizza, ask ETA, ask price, demand order id), each using `{{variables}}`.
- **4 variables**: `size`, `crust`, `topping`, `drink` — plus `price` and `order_id` used as phrasing helpers in the goals. (If you want *strictly* 4 declared variables, tell me and I'll fold `price`/`order_id` into plain text.)
- **2 pairwise functions**: `size` and `crust` both use `function: pairwise()`. Per §5 of the guide, **two pairwise variables are required** to derive `conversation.number` from a combination matrix — so I set `number: combinations(1, pairwise)` to use the full pairwise matrix. You can switch to `combinations(0.6, pairwise)` to use 60% of it.
- **`chatbot.output`**: Defines the extraction schema (`pizza_size`, `crust_type`, `topping`, `drink`, `total_price`, `order_id`) so future Sensei-check rules can read them as `conv[i].<field>`.
