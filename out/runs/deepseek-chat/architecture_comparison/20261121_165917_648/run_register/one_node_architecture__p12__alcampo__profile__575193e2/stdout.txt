Here's a profile for a user who wants to add items to their shopping cart 🛒 — I've kept it aligned with the Alcampo project style (English, `gpt-4o-mini`, single questions, and `chatbot.output` fields that rules can later inspect).

```yaml
test_name: Shopping Cart Item Addition

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: >
    You are a customer shopping online at Alcampo who wants to add specific
    products to your shopping cart. You ask the chatbot which items are available,
    request to add them to your cart, and confirm the cart contents.
  context:
    - "You are preparing a weekly grocery order and want to build your cart step by step."
    - "You prefer to add a few staple items first, then check what is in your cart."
    - "You want to make sure the chatbot confirms each item was added successfully."
  goals:
    - "Ask the chatbot which {{product_category}} products are available to add to your cart."
    - "Request to add {{product_name}} to your shopping cart."
    - "Ask how many units of {{product_name}} are currently in your cart."
    - "Ask the chatbot to confirm the total number of items in your cart."
    - "Request to remove {{product_name}} from your cart if it was added by mistake."
    - product_category:
        function: forward()
        type: string
        data: [fresh produce, dairy, beverages, snacks]
    - product_name:
        function: forward(product_category)
        type: string
        data:
          - any(3 products from the selected category available at Alcampo)

chatbot:
  is_starter: false
  fallback: "Parece que tu mensaje no es claro o no es una pregunta relacionada con Alcampo. 😊 ¿En qué puedo ayudarte hoy? Estoy aquí para resolver tus dudas sobre nuestros productos y servicios."
  output:
    - available_products:
        type: string
        description: Products available in the requested category
    - added_product_name:
        type: string
        description: Name of the product the user asked to add to the cart
    - cart_item_count:
        type: int
        description: Total number of items currently in the shopping cart
    - product_quantity_in_cart:
        type: int
        description: Number of units of the specific product in the cart
    - removal_confirmation:
        type: string
        description: Confirmation that the product was removed from the cart

conversation:
  number: combinations
  goal_style:
    steps: 20
  interaction_style:
    - single questions
```

A couple of quick notes so it behaves nicely 👇

- **`combinations`** works here because you have two nested `forward()` variables (`product_category` → `product_name`), which creates the combination matrix the `conversation.number` needs.
- The `chatbot.output` fields (`cart_item_count`, `product_quantity_in_cart`, etc.) are ready to be referenced by rules later, e.g. `conv[0].cart_item_count` — so if you want a cart-related rule next, we're all set 😊
