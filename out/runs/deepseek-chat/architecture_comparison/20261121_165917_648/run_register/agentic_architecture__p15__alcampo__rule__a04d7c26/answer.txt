## What's broken in your rule

Based on `sensei-check-doc.md` and `rules-examples.md`, there are several issues:

1. **Typo in the key**: `descriptin` → should be `description` (otherwise it's an unknown field).
2. **`when` uses fields that don't exist**: `conv[0].user_request` and `conv[1].user_request` are **not** in `chatbot.output`. Rules can only reference extracted output fields (or helpers) — `user_request` isn't one of them. This filter would fail.
3. **`if`/`then` misuse**: You wrote `if:` with a condition but **no `then:`**. Per the docs, `if`/`then` is an implication pair — if you only have a single boolean condition to assert, you should use `oracle:` instead.
4. **`is not None` on a 2-conversation rule**: This is fine syntactically, but the real intent seems to be "the bot provides these fields" — which is better expressed as a single-conversation check, or as a 2-conv check that both conversations expose the fields.
