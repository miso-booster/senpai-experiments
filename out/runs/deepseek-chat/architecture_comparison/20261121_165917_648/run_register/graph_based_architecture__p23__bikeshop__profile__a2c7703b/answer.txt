## What's broken 🔧

### 1. `llm.temperature: low` isn't valid
Temperature must be a **float** (e.g., `0.0`, `0.5`, `0.8`). The word `low` will fail validation.

```yaml
test_name: "my_first_sensei_profile"

llm:
  temperature: 0.0
  model: gpt-4o-mini

user:
  language: English
  role: "Describe what the simulated user wants and how they behave."
  context:
    - "Who the user is, constraints, preferences, availability, etc."
  goals:
    - "Main request with a {{variable}}"
    - variable:
        function: random()
        type: string
        data: [option1, option2, option3]

chatbot:
  is_starter: false
  fallback: "Paste your bot’s real fallback here"
  output:
    - important_field:
        type: string
        description: "What you want to extract/validate"

conversation:
  number: 2
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - make spelling mistakes
```

### 2. `type: str` and `type: money` aren't valid output types
In `chatbot.output`, valid types are the primitives (`int`, `float`, `string`), plus `time(...)`, `date(...)`, and `list[...]`. Custom types like `money` only work if you've defined a `types/money.yml` file in your project. Since I can't see one here, let's use `string` (or `float` if you want to extract just the number).

Also note: `str` is **not** a valid type — it must be `string`.

### 3. `seat_price` and `care_bike` are missing a `type`
Every output field needs a `type`. Without it, extraction will fail.

### 4. `conversation.number: 5` with no variables
That's fine on its own — but since your goals have no `{{variables}}`, each of the 5 conversations will just repeat the same 5 questions. That's okay for a smoke test, but if you want variety, you'd need variables. Not an error, just a heads-up 😉

### 5. `goal_style` is missing
Not strictly required, but without it, Sensei won't know when to stop. Since you want all 5 questions answered, `all_answered` is the natural fit (and it matches your original profile).

## Fixed version ✅

```yaml
test_name: qa

llm:
  temperature: 0.0
  model: gpt-4o-mini

user:
  language: English
  role: you have to act as a user talking to a virtual assistant of a bike shop
  context:
    - You are interested in asking the items below.
    - Just stick to asking opening times, prices of tire, price of tune-up, price of seat, and actions to the care of bike. Do not ask anything else.
  goals:
    - "opening and closing time of the bike shop"
    - "Which is the price of a new tire?"
    - "Which is the price of a tune-up?"
    - "Which is the price of a new seat?"
    - "What can I do to take care of my bike?"

chatbot:
  is_starter: false
  fallback: "I'm sorry it's a little loud in my shop, can you say that again?"
  output:
    - opening_and_closing:
        type: string
        description: the opening and closing time of the shop
    - tire:
        type: string
        description: the price of a new tire
    - tune_up:
        type: string
        description: the price of a tune-up
    - seat_price:
        type: string
        description: the price of a new seat
    - care_bike:
        type: string
        description: actions to take care of the bike

conversation:
  number: 1
  goal_style:
    all_answered:
      export: true
      limit: 9
  interaction_style:
    - default
```

## A couple of notes 💡

- **`number: 1` vs `number: 5`** — I set it to `1` because with no variables, running 5 identical conversations just burns cost. If you want 5, that's totally fine — just change it back. Your original profile used `number: 1` for exactly this reason.
- **`type: money`** — if you *really* want a money type, you'd need to create `types/money.yml` in your project. Something like:

  ```yaml
test_name: "money_type_profile"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A user asking about a monetary amount."
  context:
    - "You want to know the price of an item."
  goals:
    - "Ask for the price of a {{item}}"
    - item:
        function: random()
        type: string
        data: [tire, tune-up, seat]

chatbot:
  is_starter: false
  fallback: "I'm sorry it's a little loud in my shop, can you say that again?"
  output:
    - amount:
        type: money
        description: "A monetary amount, e.g. 18.50 EUR"

conversation:
  number: 1
  goal_style:
    steps: 3
  interaction_style:
    - default
```

  Then `type: money` would work in `chatbot.output`. But for a quick fix, `string` is the safest bet 👍
