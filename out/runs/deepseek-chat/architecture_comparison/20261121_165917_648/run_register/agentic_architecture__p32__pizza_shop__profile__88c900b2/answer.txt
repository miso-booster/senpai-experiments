¡Listo! Aquí tienes el perfil 🍕. Me basé en `sensei-chat-guide.md` (secciones 3, 4, 6 y 7) y seguí las convenciones de tus perfiles existentes (`pizza_and_drink_order_placement.yaml`).

```yaml
test_name: "pizzeria_order_summary"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: >
    You are a hungry customer ordering a pizza and a drink from a pizzeria
    for delivery or pickup. You want to confirm the full order details and
    the final price in US dollars before finishing.
  context:
    - "You are ordering dinner for yourself tonight."
    - "You want a single pizza and one drink."
    - "You care about the final price and want it quoted in US dollars (USD)."
  goals:
    - "Ask what kinds of pizzas are available."
    - "Order a {{pizza_type}} pizza."
    - "Ask what drinks are available."
    - "Order a {{drink}}."
    - "Ask for the order id and the final price in US dollars."
    - pizza_type:
        function: forward()
        type: string
        data:
          - Margherita
          - Pepperoni
          - Four cheese
          - Hawaiian
          - Vegetarian
          - Carbonara
    - drink:
        function: forward()
        type: string
        data:
          - Coca-Cola
          - Fanta
          - Water
          - Iced Tea
          - Orange Juice

chatbot:
  is_starter: false
  fallback: "I'm sorry, I did not get what you said. I can help you order a pizza and a drink."
  output:
    - pizza_type:
        type: string
        description: "The type of pizza the customer ordered (e.g. Margherita, Pepperoni). Look for phrases like 'You ordered a ... pizza'."
    - drink:
        type: string
        description: "The drink the customer ordered (e.g. Coca-Cola, Water). Look for phrases like 'with a ...' or 'and a ... to drink'."
    - order_id:
        type: string
        description: "The unique identifier for the order. Look for phrases like 'order number' or 'order ID'."
    - final_price:
        type: currency
        description: "The final price of the order in US dollars (USD), including the pizza and the drink. Look for currency symbols like '$' or 'USD'."

conversation:
  number: 5
  max_cost: 1.0
  goal_style:
    all_answered:
      export: false
      limit: 20
  interaction_style:
    - random:
        - long phrases
        - make spelling mistakes
        - change your mind
```

### Qué hace y cómo se relaciona con la doc 📚

- **`chatbot.output`** (guía §6) define el contrato que luego leerán las reglas como `conv[i].<campo>`:
  - `pizza_type` → tipo de pizza (string)
  - `drink` → bebida (string)
  - `order_id` → id del pedido (string)
  - `final_price` → precio final en dólares, usando el tipo `currency` (el mismo que usa tu perfil existente `total_cost`), que es el adecuado para precios y para reglas numéricas.
- **`user.goals`** (§4) declara las variables `pizza_type` y `drink` con `forward()` para cubrir combinaciones de forma determinista.
- **`conversation`** (§5) usa `all_answered` para terminar cuando se hayan cubierto todos los objetivos, con `max_cost` como tope de gasto y estilos de interacción variados.

### Nota importante ⚠️
El tipo `currency` es un **tipo personalizado**: para que funcione necesitas tener `types/currency.yml` en tu proyecto (la guía §4.2 muestra el ejemplo). Si no lo tienes, puedo cambiarlo a `string` o `float` — dime cuál prefieres.

¿Quieres que además te cree una **regla** que valide este perfil (por ejemplo, que `final_price` sea mayor que 0 cuando exista `order_id`)? 😊
