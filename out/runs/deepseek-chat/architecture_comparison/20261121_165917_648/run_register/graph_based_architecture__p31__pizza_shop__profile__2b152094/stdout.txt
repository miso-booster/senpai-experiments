## What's wrong 🔍

1. **`chatbot:` section is missing.** Your `is_starter`, `fallback`, and `output` are currently nested under `user:` (because of the indentation). They need to be their own top-level `chatbot:` block. This is the biggest issue — as written, Sensei won't find any output schema.

2. **`conversation.number` is missing.** It's a required field. You'll want to set it (e.g. `number: 3`).

3. **`export: 1`** — this should be a boolean (`true`/`false`), not an integer. Use `export: false` (or `true` if you want the CSV).

4. **`interaction_style: single question`** — the reserved keyword is **`single questions`** (plural). Also, interaction styles are a list, so it should be `- single questions`.

5. **`type: str`** on `custom_pizza_pricing` — the valid primitive is **`string`**, not `str`. (Note: `str` *is* valid inside a custom type's `extraction`, but not in `chatbot.output`.)

6. **`llm.model_prov` is missing.** Not strictly required, but recommended — add `model_prov: openai` for clarity.
