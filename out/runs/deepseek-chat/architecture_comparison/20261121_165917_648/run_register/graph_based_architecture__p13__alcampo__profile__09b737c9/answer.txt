**2. Los demás campos no están alineados como lista**

En tu versión, los campos como `organic_fruit_availability` están indentados con 2 espacios, pero el primer elemento de la lista (`- label_focus:`) usa el guion `-`. Todos los elementos de `output` deben empezar con `- ` al mismo nivel. Si mezclas, el parser se lía.

## 💡 Un par de consejos extra

- **Campos de `output` sin usar en los goals:** tienes campos como `banana_quality_guarantees`, `red_banana_characteristics` y `wine_types_available` que no aparecen en ningún goal. No rompen nada, pero si no los vas a extraer, quizá quieras quitarlos para mantener el perfil limpio. Si los quieres conservar, considera añadir goals que los cubran. 👀
- **`personality` en `context`:** lo tienes como string (`'personality: personalities/formal-user'`). En la documentación se usa como clave (`- personality: personalities/formal-user`). Funciona como string en muchos casos, pero si quieres seguir el formato canónico, quita las comillas y déjalo como clave. 😊
- **Valida antes de ejecutar:** puedes correr `validation_check.py` con `--profile` para detectar este tipo de errores de formato antes de lanzar la conversación. ¡Te ahorra sustos!
