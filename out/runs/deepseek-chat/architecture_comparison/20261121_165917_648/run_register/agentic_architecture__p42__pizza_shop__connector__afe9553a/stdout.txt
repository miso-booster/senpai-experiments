## 🔍 Qué está mal

1. **`base_url` incorrecto** → tienes `https://api.bot.com`, pero el host real es `api.1millionbot.com`.
2. **`path` incorrecto** → tienes `/api/messages`, pero el endpoint real es `/api/public/messages`.
3. **Falta el header `Authorization`** → la API lo requiere (`Authorization: 64e5d1af081211d24e2cfecd`). Sin él, la petición falla.
4. **`payload_template` incompleto** → tu API necesita `conversation`, `sender_type`, `sender`, `bot`, `url` y `language`. Solo envías `language` y `message.text`.
5. **`response_path` incorrecto** → tienes `request.text`, pero la respuesta real es un **array**:
   ```json
   {"request":{"text":"hola"},"response":[{"text":"<p>...</p>", ...}]}
   ```
   El texto del bot está en `response[0].text`, es decir, `response.0.text` (¡ojo, `request.text` es solo el eco del mensaje del usuario!).

| `payload_template` | solo `language` + `message.text` | añadidos `conversation`, `sender_type`, `sender`, `bot`, `url` | Campos obligatorios del body |
