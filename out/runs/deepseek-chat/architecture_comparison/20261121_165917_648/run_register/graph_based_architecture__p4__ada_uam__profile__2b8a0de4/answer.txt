        type: string

    - service_hours:
        type: string

## 🧠 Por qué está montado así

- **`chatbot.output`** es el contrato con las reglas de Sensei-check: cada campo (`contact_phone`, `contact_email`, etc.) podrá leerse luego como `conv[i].contact_phone`, etc. Los nombres son estables y descriptivos 👍
- **`goal_style.steps: 20`** es suficiente para 4 preguntas cortas, y el `max_cost` mantiene el gasto controlado.
- **`interaction_style: single questions`** hace que el usuario pregunte de una en una, lo que encaja perfecto con "quiero conseguir estos 4 datos".
- **`fallback`** usa el mensaje real del bot de la UAM para evitar bucles raros.
