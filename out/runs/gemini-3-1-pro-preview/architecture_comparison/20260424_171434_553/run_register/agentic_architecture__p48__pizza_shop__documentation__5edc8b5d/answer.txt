Based on the SENSEI documentation, here are the fields that are explicitly marked as **optional** (not mandatory) when creating a profile:

*   **`llm` (The entire section):** You do not have to define the `llm` block. If you omit it, SENSEI will automatically apply default settings (such as a default model, temperature, and text format). You only need to add it if you want to override the defaults or use `speech` mode.
*   **`user.context.personality`:** When defining the user's context, linking to a separate personality YAML file (e.g., `personality: personalities/calm-user.yml`) is completely optional. You can just write freeform text constraints instead.
*   **`conversation.max_cost`:** This field is optional. It is used if you want to set a maximum cost cap (in $) for the *entire run* of the profile.
*   **`conversation.goal_style.max_cost`:** Also optional. This sets a cost cap (in $) for *each individual conversation*.
*   **`export` and `limit` (under `goal_style: all_answered`):** If you choose `all_answered` as your goal style, the `export: true/false` (which exports a verification dataframe) and `limit: <int>` (a safety stop limit) are optional. If you omit the limit, it defaults to 30 steps.

Everything else—like the `test_name`, `user` (language, role, context, goals), `chatbot` (output schema), and basic `conversation` controls (number and goal style)—forms the core structure needed to run a simulation successfully! 😊 Let me know if you need help setting up a profile.
