To check the exact price of a small pizza, we can create a single-conversation rule (often called an oracle). This rule will filter for conversations where the size is "small" and then verify that the extracted price equals 10 and the currency is USD. 

Here is the rule ready for your project:

```yaml
name: small_pizza_price_exact
description: Checks that the price of a small pizza is exactly $10
conversations: 1
when: size == 'small'
oracle: extract_float(price) == 10 and currency(price) == 'USD'
```

### How it works:
* **`conversations: 1`**: Tells Sensei-check to evaluate this rule on individual conversations rather than comparing multiple ones.
* **`when: size == 'small'`**: This acts as a filter so the rule only runs when the simulated user ordered a small pizza.
* **`oracle: ...`**: This is the condition that must pass! We use the handy `extract_float()` helper to pull the number out of the text, and `currency()` to ensure it's in US Dollars. 

Just make sure that the profile you are testing this against actually exposes `size` and `price` in its `chatbot.output` section! Let me know if you need help tweaking this or adding it to your project! 😊
