### 👀 A quick note about removing HTML tags:
According to our SENSEI CONNECTORS documentation, the `response_path` simply navigates the JSON and extracts the exact string found at that location (in this case, `response.0.text`). 

Because the YAML configuration itself doesn't have a built-in feature to parse or strip HTML, the connector will return the raw string: `"<p>¡Buenos días!<br><br>¿En qué puedo ayudarte?</p>"`. To return plain text with the HTML tags removed, you will need to clean that string inside your Python code right after the connector fetches it, like this:

```python
import re
from chatbot_connectors.implementations.custom import CustomChatbot

bot = CustomChatbot("connectors/saic-malaga.yml")
success, response = bot.execute_with_input("hola")

# Strip HTML tags from the response
clean_response = re.sub(r'<[^>]+>', '', response)
print(clean_response)
```
