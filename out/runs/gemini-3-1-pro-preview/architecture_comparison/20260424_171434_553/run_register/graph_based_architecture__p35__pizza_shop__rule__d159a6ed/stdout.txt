To check the price of a small pizza, we'll want to create a **single-conversation rule** (also known as an oracle). We will use a `when` filter to isolate the conversations where a small pizza was ordered, and then an `oracle` expression to verify the price.

Here is the YAML code you can use for your Sensei-check rule:

```yaml
name: small_pizza_price
description: The price of a small pizza must be exactly $10.
conversations: 1
when: size == 'small'
oracle: extract_float(price) == 10
```

### 📝 A quick breakdown of how this works:
* **`conversations: 1`**: Tells Sensei-check to evaluate one conversation at a time, rather than comparing multiple conversations together.
* **`when: size == 'small'`**: This is our filter! It ensures the rule only runs if the `size` slot extracted from the conversation is exactly 'small'.
* **`oracle: extract_float(price) == 10`**: This is the actual test. We use the handy `extract_float()` helper function to pull the number out of the `price` string (just in case the bot replies with something like "$10.00" or "10 USD") and check if it equals 10.

*💡 Senpai's Tip:* Make sure that your SENSEI Chat profile actually exposes `size` and `price` in its `chatbot.output` schema. If your profile uses different names (like `pizza_size` or `total_price`), just update the variables in the rule to match those exact names!
