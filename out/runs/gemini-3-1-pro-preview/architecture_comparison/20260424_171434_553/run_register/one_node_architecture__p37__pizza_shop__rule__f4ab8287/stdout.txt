¡Hola! Claro que sí, te ayudo a crear esa regla. 🥤

Para comprobar que el asistente confirma la bebida *después* de que el usuario la haya pedido, podemos usar la función `utterance_index`. Esta función busca en qué turno de la conversación se habla de un tema específico. 

Así, podemos decirle a Sensei que el turno donde el usuario pide la bebida debe ser menor (es decir, ocurrir antes) que el turno donde el asistente lo confirma.

Aquí tienes la regla lista para añadir a tu proyecto:

```yaml
name: assistant_confirms_drink_order
description: The assistant confirms the drink order after the user orders a drink
conversations: 1
active: true
oracle: utterance_index('user', 'ordering a drink') < utterance_index('assistant', 'confirms drink order')
```

Guarda este código en un archivo dentro de tu carpeta `rules/` (por ejemplo, `assistant_confirms_drink.yaml`). 

¿Te gustaría que ajustemos algo más o necesitas ayuda con alguna otra regla? 😊
