Hello there! 😊 When creating a SENSEI Chat profile, you have a lot of flexibility. While some fields are essential to tell the simulator what to do, there are several fields that are completely optional! 

Here is a list of the non-mandatory fields you can skip if you don't need them:

*   **The entire `llm` block:** You don't actually have to define this! If you leave it out, Sensei will automatically apply its default settings (like a default model, temperature, and text format). You only need to include it if you want to override those defaults or use `speech` mode. 🤖
*   **`personality` (inside `user.context`):** You can link to a specific personality YAML file (like `personalities/calm-user.yml`), but it's totally optional. You can just use plain text strings to describe the user's context and constraints instead!
*   **`max_cost`:** Both `conversation.max_cost` (which caps the spend for the *whole run*) and `goal_style.max_cost` (which caps the spend *per conversation*) are optional. They are just handy safety limits to keep your LLM spending in check! 💸
*   **Variables in `user.goals`:** If your simulated user just has simple, fixed goals, you don't need to use `{{variables}}` or define custom data functions. Plain strings (like `"Ask about the opening hours"`) work perfectly fine!
*   **`export` and `limit` (under `goal_style: all_answered`):** If you use the `all_answered` goal style, you don't have to specify these. They have built-in defaults (`export: false` and a safety stop `limit: 30`), so you only need to include them if you want to change those defaults.

If you ever want to keep your profile as simple as possible, you can just stick to the basics: a `test_name`, a `user` description with some `goals`, a `chatbot` section with the expected `output`, and the `conversation` rules.
