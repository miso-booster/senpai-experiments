Hello there! 😊 I can definitely help you with that. Ensuring your chatbot speaks the right language is super important for a great user experience!

Sensei-check has a built-in helper function called `responds_in_same_language()` that makes this incredibly easy. Since this is a general style check, it works across any of your profiles without needing specific `chatbot.output` fields.

Here is the rule you can add to your project:

```yaml
name: chatbot_responds_in_same_language
description: The chatbot responds in the same language as the user
conversations: 1
active: true
oracle: responds_in_same_language()
```

### How it works:
* **`conversations: 1`**: It evaluates each conversation individually.
* **`oracle: responds_in_same_language()`**: This uses an LLM-backed helper under the hood to detect the language of the user's prompts and verifies that the assistant's replies match it.

If you want to test this rule in action, you can use the `change language` interaction style in one of your profiles (like your `language_issue.yaml` profile) to simulate a user switching languages! 🌍💬
