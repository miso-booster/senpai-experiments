Hello there! 😊 That is a fantastic idea. Making sure your chatbot speaks the user's language is super important for a great user experience! 

Luckily, Sensei-check makes this incredibly easy. We have a built-in helper function called `responds_in_same_language()` designed exactly for this purpose. Because this rule checks the general conversational style rather than specific extracted data, it's considered a **global rule** — meaning you can use it across any of your SENSEI Chat profiles without needing to set up specific `chatbot.output` fields!

Here is the ready-to-use YAML rule you can add to your project:

```yaml
name: language_matching
description: The assistant must reply in the same language that the user is speaking.
conversations: 1
oracle: responds_in_same_language() is True
```

### 🧠 A quick breakdown of how it works:
* **`conversations: 1`**: This tells Sensei-check to evaluate the rule on a single conversation at a time (rather than comparing multiple conversations together).
* **`oracle`**: This is the condition that must pass. We simply call the LLM-backed helper `responds_in_same_language()`, which automatically analyzes the user's input and the assistant's replies to ensure they match!

Just save this as a `.yaml` file in your rules folder, and Sensei-check will handle the rest.
