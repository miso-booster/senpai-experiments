To check if the chatbot successfully confirms an appointment, we can write a single-conversation rule (an oracle) that verifies if the specific appointment fields defined in your profile's `chatbot.output` were successfully extracted.

Here is a rule tailored for your **`appointment.yml`** profile. It checks that the `confirmed_date`, `confirmed_time`, and `confirmed_service` fields are all captured:

```yaml
name: appointment_is_confirmed
description: The chatbot successfully confirms the appointment date, time, and service.
conversations: 1
active: true
oracle: confirmed_date is not None and confirmed_time is not None and confirmed_service is not None
```
