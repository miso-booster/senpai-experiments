Para comprobar si el asistente confirma algo específico durante la charla, podemos usar la función `utterance_index(who, what)`. Esta función es genial porque busca en qué turno exacto de la conversación alguien (el usuario o el asistente) mencionó cierto tema.

Basándome en las reglas que ya tienes en tu proyecto (como `ordering_conversation_turns_assistant`), he diseñado esta nueva regla. Utiliza una estructura `if/then` para asegurarse de que, **si** el usuario pide una bebida, **entonces** el asistente la confirma después.

Aquí tienes el código YAML listo para usar:

```yaml
name: assistant_confirms_drink
description: El asistente confirma que añadió la bebida después de que el usuario la pide.
conversations: 1
if: utterance_index('user', 'ordering drink') > 0
then: utterance_index('user', 'ordering drink') < utterance_index('assistant', 'confirms adding the drink')
```

### 🤓 ¿Cómo funciona esta regla?
1. **`conversations: 1`**: Analiza cada conversación de forma individual.
2. **`if`**: Primero verifica si el usuario realmente pidió una bebida (`> 0` significa que sí ocurrió en algún turno).
3. **`then`**: Comprueba que el número de turno donde el asistente confirma la bebida sea *mayor* (es decir, que ocurra *después*) que el turno donde el usuario la pidió.

Puedes guardar este bloque de código en un nuevo archivo dentro de tu carpeta de reglas, por ejemplo: `assistant_confirms_drink.yaml`.
