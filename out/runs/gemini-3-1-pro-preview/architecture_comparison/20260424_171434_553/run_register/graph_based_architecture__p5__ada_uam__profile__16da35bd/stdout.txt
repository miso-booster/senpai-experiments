Since the UAM chatbot operates in Spanish, I have set the `user.language` to Spanish and written the prompts accordingly. This ensures our simulated user interacts naturally with the bot. I've also used the `all_answered` goal style, which is perfect for this scenario—it tells Sensei to end the conversation as soon as the bot has provided all the requested information! 🎯

Here is the complete YAML profile you can use. You can save this file as `cau_support_inquiry.yml` inside your project's `profiles/` folder:

```yaml
test_name: "cau_support_inquiry"

llm:
  temperature: 0.5
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Estudiante o miembro del personal que necesita contactar al Centro de Atención a Usuarios (CAU)."
  context:
    - "Tienes una consulta técnica y necesitas asistencia directa del CAU."
    - "Quieres recopilar todas las vías de contacto posibles antes de decidir cómo comunicarte con ellos."
  goals:
    - "Preguntar por el número de teléfono del CAU."
    - "Solicitar la dirección de correo electrónico del CAU."
    - "Consultar la ubicación física o dirección de las oficinas del CAU."
    - "Preguntar por el horario de atención al público del CAU."

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me lo puedes decir con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios. Respondo a preguntas dirigidas al Centro de Atención a Usuarios del servicio de Tecnologías de la Información."
  output:
    - cau_phone:
        type: string
        description: "El número de teléfono del CAU extraído de la conversación"
    - cau_email:
        type: string
        description: "La dirección de correo electrónico del CAU"
    - cau_location:
        type: string
        description: "La ubicación física o dirección del CAU"
    - cau_hours:
        type: string
        description: "El horario de apertura y cierre del CAU"

conversation:
  number: 1
  goal_style:
    all_answered:
      export: true
      limit: 15
  interaction_style:
    - single questions
```

### 💡 A quick breakdown of what makes this profile tick:
* **`user.goals`**: These are the specific pieces of information our simulated user will try to get from the UAM chatbot.
* **`chatbot.output`**: This is our extraction schema! At the end of the conversation, Sensei will look at the chat history and extract the phone, email, location, and hours into these neat little variables. Later on, you can use Sensei Rules to verify if these extracted values are correct! 👀
* **`interaction_style: [single questions]`**: This tells our simulated user to ask for things one by one, rather than overwhelming the bot with a massive paragraph. It's a great way to test the bot's multi-turn conversational skills.
