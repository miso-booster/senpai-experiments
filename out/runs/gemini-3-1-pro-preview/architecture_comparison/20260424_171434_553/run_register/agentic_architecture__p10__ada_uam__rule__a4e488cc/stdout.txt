Based on the SENSEI documentation (`sensei-check-doc.md` and `rules-examples.md`), rules are designed to validate the behaviour of the chatbot by checking the fields defined in your profile's `chatbot.output` and the overall conversational style.

Since your profile simulates a potential student asking about admissions, courses, and the Welcome Day in Spanish, here are **three different rules** you can use to test it. I have included a mix of single-conversation checks and metamorphic (multi-conversation) checks.

### 1. Completeness Rule (Single Conversation)
This rule checks if the chatbot successfully provided all the information requested by the user. It uses the `data_collected()` helper to ensure that none of the fields in your `chatbot.output` (like `welcome_day_date`, `admission_to_grados_link`, etc.) are left empty.

```yaml
name: all_information_collected
description: The chatbot successfully provides all the requested information for new students.
conversations: 1
active: true
oracle: data_collected() == True
yields: f"Missing slots: {missing_slots()}"
```

### 2. Language Consistency Rule (Single Conversation)
Since your user profile is explicitly set to `language: Spanish`, the chatbot should reply in the same language. This global rule uses the `responds_in_same_language()` helper to verify that the chatbot doesn't suddenly switch to English or another language.

```yaml
name: responds_in_spanish
description: The chatbot responds in the same language as the user (Spanish).
conversations: 1
active: true
oracle: responds_in_same_language()
yields: "The chatbot did not respond in the expected language."
```

### 3. Consistent Welcome Day Date (Metamorphic Rule - 2 Conversations)
Metamorphic rules compare two or more conversations. Even if the simulated user asks about different degrees (`grados`) or courses (`cursos`), the date for the Welcome Day should be a fixed event and remain exactly the same across all conversations. This rule checks that consistency using the `welcome_day_date` field from your `chatbot.output`.

```yaml
name: consistent_welcome_day
description: The Welcome Day date should be consistent across all conversations, regardless of the degree asked about.
conversations: 2
active: true
if: conv[0].welcome_day_date is not None and conv[1].welcome_day_date is not None
then: conv[0].welcome_day_date == conv[1].welcome_day_date
```

2. When you run Sensei-check, it will automatically read the outputs generated by your profile and apply these rules to see if the chatbot behaves correctly!
