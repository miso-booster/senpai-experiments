### 1. Welcome Day Consistency (Metamorphic Rule)
Since the "Welcome Day" is a specific university event, its date and time should remain exactly the same regardless of which degree (`grados`) or course (`cursos`) the user asks about. We can use a 2-conversation metamorphic rule to check this invariant!

```yaml
name: consistent_welcome_day
description: The Welcome Day date and time should be the same across different degree inquiries.
conversations: 2
if: conv[0].grados != conv[1].grados
then: conv[0].welcome_day_date == conv[1].welcome_day_date and conv[0].welcome_day_time == conv[1].welcome_day_time
```

### 2. Data Completeness (Single Conversation)
You have defined a lot of fields in your `chatbot.output`. A great baseline rule is to ensure that the chatbot successfully provides all the requested information before the conversation ends.

```yaml

active: true
```

### 3. Language Consistency (Single Conversation)

### 4. Topic Guardrail (Single Conversation)
To ensure the chatbot doesn't hallucinate or drift into unrelated topics (like sports or movies), you can restrict its scope to admissions and university events.

