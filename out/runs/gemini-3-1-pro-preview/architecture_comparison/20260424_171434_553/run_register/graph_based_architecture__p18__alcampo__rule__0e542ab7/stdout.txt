¡Hola! 👋 ¡Claro que sí! Me encanta la idea de buscar juguetes eco-friendly. 🌱🧸

Para esto, vamos a crear una **regla de una sola conversación** (lo que en SENSEI llamamos un oráculo tradicional). Esta regla se encargará de verificar que el campo `eco_friendly_toys` no esté vacío al final de la conversación.

Aquí tienes el código YAML listo para tu regla de **SENSEI Check**:

```yaml
name: eco_friendly_toys_returned
description: Verifica que el chatbot haya proporcionado una lista de juguetes eco-friendly durante la conversación.
conversations: 1
oracle: eco_friendly_toys is not None and len(eco_friendly_toys) > 0
```

### 💡 El consejo de Senpai: ¡No olvides el Perfil!
Recuerda que, como nos indica la documentación, las reglas de Sensei-check están conectadas directamente con los perfiles de **SENSEI Chat**. Para que esta regla funcione a la perfección, tu perfil debe tener definido ese mismo campo en su sección `chatbot.output`. 

Debería verse algo así en el archivo de tu perfil:

```yaml
test_name: "eco_friendly_toys_test"

user:
  language: Spanish
  role: "Eres un cliente buscando juguetes eco-friendly."
  goals:
    - "Preguntar por juguetes eco-friendly."

chatbot:
  is_starter: false
  fallback: "Lo siento, no te he entendido."
  output:
    - eco_friendly_toys:
        type: list[string]
        description: Lista de juguetes eco-friendly recomendados por el asistente.

conversation:
  number: 1
  goal_style:
    steps: 3
  interaction_style:
    - default
```

De esta manera, cuando SENSEI Chat simule la conversación, extraerá la lista de juguetes y SENSEI Check podrá evaluarla correctamente con la regla que acabamos de crear. ✨
