### What changed in the `chatbot` section?
1. **`is_starter: false`**: Tells Sensei that the user should send the first message. (Change to `true` if your chatbot always greets the user first).
2. **`fallback`**: A string containing your bot's real fallback message. This helps Sensei recognize if the bot gets stuck in a loop.
3. **`output`**: We defined 5 fields (`available_pizzas`, `margarita_price`, `available_drinks`, `operating_hours`, and `delivery_available`). At the end of the conversation, Sensei will read the chat history and populate these fields based on the chatbot's answers.
