To thoroughly test how the chatbot manages dates and times, we can use the `forward()` function in the user's goals. By nesting the time variable inside the date variable, we can generate a combination matrix. Then, by setting `conversation.number: combinations`, Sensei will automatically run a conversation for every possible pair of dates and times!

Here is the YAML profile. You can save this as `wheel_change_appointment.yml` inside your `profiles/` folder:

```yaml
test_name: "wheel_change_appointment"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer who wants to schedule an appointment to have their bike wheels changed."
  context:
    - "You have purchased new wheels and need a professional to install them."
    - "You have a busy schedule and want to see if the shop can accommodate specific dates and times."
  goals:
    - "Ask to schedule an appointment for a wheel change."
    - "Request the appointment for {{appointment_date}} at {{appointment_time}}."
    - appointment_date:
        function: forward()
        type: string
        data: ["tomorrow", "next Friday", "November 12th"]
    - appointment_time:
        function: forward(appointment_date)
        type: string
        data: ["09:00 AM", "1:30 PM", "17:45"]

chatbot:
  is_starter: false
  fallback: "I'm sorry it's a little loud in my shop, can you say that again?"
  output:
    - confirmed_date:
        type: date
        description: "The date of the appointment confirmed by the assistant."
    - confirmed_time:
        type: string
        description: "The time of the appointment confirmed by the assistant."
    - confirmed_service:
        type: string
        description: "The service to be performed, which should be a wheel change."

conversation:
  number: combinations
  goal_style:
    all_answered:
      export: true
      limit: 15
  interaction_style:
    - default
```

### What's happening in this profile? 👀
1. **Variables & Combinations:** We defined `appointment_date` and `appointment_time` using `forward()`. Because `appointment_time` depends on `appointment_date` (`forward(appointment_date)`), Sensei will test all 9 combinations (3 dates × 3 times).
2. **Outputs:** The `chatbot.output` section is set up to extract the `confirmed_date`, `confirmed_time`, and `confirmed_service`. This is super useful if you want to write a Sensei Rule later to verify that the chatbot actually booked the exact date and time the user requested!
