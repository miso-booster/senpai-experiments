Since we are checking an absolute condition for a single conversation (rather than comparing two different ones), we'll use what we call a **single-conversation oracle**. 

Here is the YAML code for your Sensei-check rule. You can save this in your `rules` folder:

```yaml
name: small_pizza_price
description: The price of a small pizza must be exactly $10.
conversations: 1
when: size == 'small'
oracle: extract_float(price) == 10
```

### 💡 A quick breakdown of how this works:
* **`conversations: 1`**: Tells Sensei-check that we only need to look at one conversation at a time.
* **`when: size == 'small'`**: This is our filter! The rule will only run on conversations where the user ordered a small pizza.
* **`oracle: extract_float(price) == 10`**: This is the actual test. We use the handy `extract_float()` helper function to pull the number out of the price text (so if the bot says "10.00 USD" or "$10", it safely reads it as `10`) and checks that it equals 10.

**⚠️ Senpai's Friendly Reminder:** 
For this rule to work perfectly, make sure that `size` and `price` are the exact names of the fields exposed in your SENSEI Chat profile's `chatbot.output`. If your profile uses a different name like `total_price`, just update the rule to match!
