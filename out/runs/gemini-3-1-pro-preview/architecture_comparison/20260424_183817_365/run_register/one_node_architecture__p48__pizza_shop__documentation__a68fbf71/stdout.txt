When creating a SENSEI Profile, you have a lot of flexibility. While you need the core structure (like `user`, `chatbot`, and `conversation` goals), several fields and sections are completely **optional**:

*   **`llm` block:** You actually don't have to define the `llm` section at all! If you leave it out, Sensei will automatically apply default settings (like a default model and temperature) and assume the format is text. You only need it if you want to override the defaults or use `speech` mode.
*   **`user.context.personality`:** You don't need to link to an external personality YAML file. You can just write freeform constraints and facts directly in the `context` list!
*   **`conversation.max_cost` & `goal_style.max_cost`:** These are optional safety caps. You can use them to limit the spending for the entire run or per conversation, but they aren't required to run the profile.
*   **`interaction_style`:** If you don't specify an interaction style (like `make spelling mistakes` or `change language`), the simulated user will just default to carrying out the conversation in a standard, natural way.
*   **`chatbot.fallback`:** While it is *highly recommended* to include your bot's real fallback message here to prevent endless loops, it is technically optional. 

If you ever want to start with a minimal profile, you can focus just on defining who the user is (`user.role`, `user.goals`), what you want to extract (`chatbot.output`), and how many conversations to run (`conversation.number` and `goal_style.steps`). 

Let me know if you need help building a minimal profile or if you have any other questions! 🍕✨
