Testing how a chatbot handles Wi-Fi troubleshooting (especially the notorious eduroam! 😅) is a fantastic use case. To make this profile super effective, we will use **variables** for the device type, the operating system, and the setup method they tried. 

Since we have multiple variables, I'll use the `pairwise()` function. This is a neat little trick in Sensei that mixes and matches your variables to cover all pairs of combinations without creating a massive, overwhelming number of conversations. 

Here is the complete, ready-to-run YAML profile. You can save this as `eduroam_troubleshooting.yml` inside your `profiles/` folder! 📁

```yaml
test_name: "eduroam_setup_troubleshooting"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a university student who urgently needs to connect to the eduroam Wi-Fi network, 
    but you are completely unable to do so despite trying different methods.
  context:
    - "You have an important online assignment due soon and need internet access."
    - "You are a bit frustrated but trying to be polite with the support bot."
  goals:
    - "Tell the chatbot that you are trying to connect your {{device_type}} to eduroam but it keeps failing."
    - "Explain that you already tried using the {{setup_method}} to configure it."
    - "Mention that your device is running on {{operating_system}}."
    - "Ask for step-by-step troubleshooting or if there is a known network outage."
    
    # --- Variables Definition ---
    - device_type:
        function: pairwise()
        type: string
        data: [laptop, smartphone, tablet]
    - setup_method:
        function: pairwise()
        type: string
        data: [eduroam CAT tool, manual configuration, QR code scanner]
    - operating_system:
        function: pairwise()
        type: string
        data: [Windows 11, macOS, Android, iOS, Ubuntu]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I couldn't understand that. Could you please rephrase your issue?"
  output:
    - user_os:
        type: string
        description: "The operating system the user is trying to connect with"
    - setup_method_attempted:
        type: string
        description: "The setup method the user already tried"
    - provided_solution:
        type: string
        description: "The troubleshooting steps provided by the chatbot"

conversation:
  # This tells Sensei to run 100% of the combinations generated by the pairwise functions!
  number: combinations(1, pairwise)
  goal_style:
    steps: 8
  interaction_style:
    - random:
      - long phrases
      - make spelling mistakes
```

### 👀 A quick look at what's happening here:
1. **The Variables (`{{...}}`)**: Inside `user.goals`, we placed `{{device_type}}`, `{{setup_method}}`, and `{{operating_system}}`. Sensei will dynamically swap these out using the lists provided in the `data` fields.
2. **The `pairwise()` function**: By assigning `pairwise()` to all three variables, Sensei will intelligently pair them up (e.g., *laptop + CAT tool + Windows 11*, then *smartphone + manual config + Android*, etc.) to ensure every combination of two variables is tested at least once!
3. **`chatbot.output`**: At the end of the conversation, Sensei will extract the OS, the method the user tried, and the solution the bot gave. This is super helpful if you want to write **Sensei Rules** later to verify that the bot gave the correct instructions for Windows vs. macOS! 🕵️‍♂️
