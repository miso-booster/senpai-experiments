Since we want to verify that the chatbot provides specific, factual information in a single chat, we will create a **single-conversation rule** (`conversations: 1`). 

To make this rule as robust as possible, I highly recommend using our built-in `semantic_content()` helper for the physical address and the phone number. This is super useful because the chatbot might format the phone number with different spaces (like '914974029') or translate "Higher Polytechnic School" into Spanish ("Escuela Politécnica Superior"). The `semantic_content()` helper uses an LLM under the hood to check if the meaning matches, so it won't fail over minor formatting differences! 🧠✨

Here is the ready-to-use YAML rule based on the `chatbot.output` fields you provided:

```yaml
name: cau_information_accuracy
description: Verifies that Ada UAM provides the correct CAU email, phone, and physical address.
conversations: 1
oracle: contact_email == 'cau@uam.es' and semantic_content(contact_phone, '91 497 4029') and semantic_content(physical_address, 'Higher Polytechnic School, C/ Francisco Tomás y Valiente nº 11, Building B, first floor, office TI-107')
```

### How it works:
* **`conversations: 1`**: Tells Sensei-check to evaluate this on individual conversations rather than comparing multiple ones.
* **`contact_email == 'cau@uam.es'`**: A strict check to ensure the email is exactly right.
* **`semantic_content(...)`**: Flexibly checks that the extracted phone and address match the meaning of your provided text, saving you from annoying false positives due to formatting!
