Para comprobar si el asistente confirma algo específico después de que el usuario lo pide, podemos usar una regla de una sola conversación (`conversations: 1`) y aprovechar la función auxiliar **`utterance_index(who, what)`**. Esta función busca en qué turno de la conversación un rol específico (usuario o asistente) menciona un tema.

Aquí tienes el código YAML listo para tu regla. Puedes guardarlo en un archivo llamado, por ejemplo, `assistant_confirms_drink.yaml` dentro de tu carpeta de reglas:

```yaml
name: assistant_confirms_drink
description: Si el usuario pide una bebida, el asistente debe confirmar que la añadió a la orden.
conversations: 1
if: utterance_index('user', 'ordering a drink') > 0
then: utterance_index('user', 'ordering a drink') < utterance_index('assistant', 'confirms adding the drink')
```

### 👀 ¿Cómo funciona esta regla?
1. **`conversations: 1`**: Le dice a Sensei-check que evalúe las conversaciones de forma individual.
2. **`if` (Condición)**: Primero verificamos si el usuario realmente pidió una bebida (`utterance_index('user', 'ordering a drink') > 0`). Si el usuario no pide bebida en esa conversación, la regla simplemente se ignora y no falla.
3. **`then` (Validación)**: Si la condición anterior se cumple, comprobamos que el turno donde el usuario pide la bebida sea **menor** (es decir, que ocurra antes) que el turno donde el asistente confirma que la añadió (`utterance_index('assistant', 'confirms adding the drink')`).
