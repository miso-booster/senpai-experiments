I've prepared two different rules for you. One is a **metamorphic rule** (comparing two conversations), and the other is a **single-conversation rule** (checking just one). You can use either or both!

### 1. Metamorphic Rule: Lactose-Free Price Premium 🥛
This rule compares two conversations where the user asks for the *exact same product* and *quantity*, but one is lactose-free and the other is regular. It checks that the lactose-free version costs the same or slightly more than the regular version (a classic monotonicity check!).

```yaml
name: lactose_free_price_premium
description: A lactose-free version of the same product should cost the same or more than the regular version.
conversations: 2
when: conv[0].product_name == conv[1].product_name and conv[0].quantity == conv[1].quantity
if: conv[0].is_lactose_free == True and conv[1].is_lactose_free == False
then: extract_float(conv[0].price) >= extract_float(conv[1].price)
```

### 2. Single-Conversation Rule: Availability Confirmation ✅
This rule looks at a single conversation. If the user specifically requests a lactose-free product, it uses our handy LLM-backed `semantic_content` helper to ensure the chatbot actually addresses whether the item is in stock or not.

```yaml
name: lactose_free_availability_check
description: If a lactose-free product is requested, the assistant must explicitly confirm its availability.
conversations: 1
when: is_lactose_free == True
oracle: semantic_content(chatbot_phrases, 'confirms if the lactose-free product is available or out of stock')
```
