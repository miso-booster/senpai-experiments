Hello there! 😊 I'd be happy to explain connectors to you!

In Sensei, **Connectors** (specifically the Custom YAML Connectors) are used to connect Sensei to any external chatbot API without needing to write a single line of code. You just create a simple YAML configuration file that tells Sensei exactly how to send messages to your chatbot and how to read its replies. 

Think of a connector as a bridge or a translator that helps Sensei and your specific chatbot understand each other perfectly! 🌉🤖

Here are the fields you can use to configure a connector, along with what they do:

*   **`name`** *(Optional)*: A friendly name for your chatbot.
*   **`base_url`** *(Required)*: The main URL of your chatbot's API (for example, `https://api.mychatbot.com`).
*   **`send_message.path`** *(Required)*: The specific endpoint path that gets appended to the base URL (like `/chat` or `/api/messages`).
*   **`send_message.method`** *(Optional)*: The HTTP method used to send the request (e.g., `POST`, `GET`, `PUT`, `DELETE`). If you leave this out, it defaults to `POST`.
*   **`send_message.headers`** *(Optional)*: Any custom headers your API needs to accept the request, such as `Authorization` tokens or `Content-Type`.
*   **`send_message.payload_template`** *(Required)*: The JSON structure that your API expects to receive. This is where you place the magic placeholder `{user_msg}` so Sensei knows exactly where to inject the simulated user's text! ✨
*   **`response_path`** *(Required)*: A dot-separated path that tells Sensei how to navigate the JSON response to find the bot's actual reply. For example, if the API returns `{ "data": { "text": "Hello!" } }`, your response path would be `data.text`.
