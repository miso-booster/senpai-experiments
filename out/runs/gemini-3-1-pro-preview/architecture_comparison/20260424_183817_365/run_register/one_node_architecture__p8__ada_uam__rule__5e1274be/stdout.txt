1. **The `conv[0]` prefix:** Because this is a single-conversation rule (`conversations: 1`), you don't need to use the `conv[0]` array notation. You can just call the variables directly by their names (e.g., `contact_email`). The `conv[i]` syntax is reserved for metamorphic rules that compare multiple conversations (`conversations: 2` or `all`).
2. **The `when` and `oracle` are identical:** The `when` clause acts as a filter. If you filter the conversations so that you *only* evaluate the ones where the email, phone, and address are already correct, your `oracle` will always pass, but it will ignore any conversations where the chatbot got the information wrong! To actually test if the chatbot is giving the right answers, we should remove the `when` clause and let the `oracle` do the checking.
