Para comprobar que el chatbot efectivamente ha devuelto esa información durante la conversación, necesitamos una regla de **una sola conversación** (un oráculo tradicional) que verifique que ese campo no esté vacío al finalizar el test.

Aquí tienes la regla lista para añadir a tu carpeta `rules/`:

```yaml
name: eco_friendly_toys_returned
description: Verifica que el chatbot ha devuelto una lista de juguetes eco-friendly durante la conversación.
conversations: 1
active: true
oracle: eco_friendly_toys is not None and len(eco_friendly_toys) > 0
```

### ¿Qué hace esta regla? 👀
* **`conversations: 1`**: Le dice a Sensei-check que evalúe las conversaciones de una en una.
* **`oracle`**: Es la condición que debe cumplirse. En este caso, comprueba que la variable `eco_friendly_toys` (que viene directamente del output de tu perfil) no sea nula (`is not None`) y que contenga algún texto (`len(...) > 0`).

Puedes guardar este bloque de código en un archivo llamado, por ejemplo, `eco_friendly_toys_returned.yaml` dentro de tu carpeta `rules/`.
