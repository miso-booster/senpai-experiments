¡Hola! Claro que sí, te ayudo a crear esa regla. 🍕🥤

Para comprobar si el asistente confirma la bebida que pidió el usuario, podemos usar la función de ayuda `utterance_index`. Esta función impulsada por LLM busca en qué turno de la conversación un rol específico habla de un tema. 

Lo ideal para este caso es verificar que el turno donde el **asistente confirma la bebida** ocurre *después* del turno donde el **usuario la pide**. 

Aquí tienes la regla lista para guardar en tu carpeta `rules/`:

```yaml
name: assistant_confirms_drink
description: El asistente confirma que ha añadido la bebida después de que el usuario la pide.
conversations: 1
active: true
oracle: utterance_index('user', 'ordering a drink') < utterance_index('assistant', 'confirms the drink order')
```

**💡 Un pequeño tip:** Si en algún perfil el usuario no siempre pide bebida, podrías añadir un `when: utterance_index('user', 'ordering a drink') > -1` para que la regla solo se evalúe en las conversaciones donde efectivamente se pidió una.
