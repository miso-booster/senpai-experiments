Based on the SENSEI documentation (`sensei-check-doc.md`), there is actually **no built-in `pairwise` function** in the SENSEI-check DSL. 

However, if you are looking to compare pairs of conversations (which is the core of **metamorphic testing** in SENSEI), you don't need a specific function for it! Instead, SENSEI handles pairwise comparisons natively through the rule's structure.

Here is how you do it:

1. **Set `conversations: 2`**: This tells SENSEI that the rule needs to evaluate a pair of conversations.
2. **Use the `conv` array**: You can access the specific conversations in the pair using `conv[0]` and `conv[1]`.
3. **Filter with `when`**: You can use the `when` clause to ensure the pair of conversations you are comparing are actually related (e.g., they have the same pizza size).

### Example: Pairwise Comparison in Action

Here is a classic example of a metamorphic rule that compares a pair of conversations to ensure that adding more toppings to a pizza increases the price:

```yaml
name: toppings_monotonicity
description: Adding more toppings to a custom pizza costs more (same size/drink/qty)
conversations: 2
when: conv[0].size == conv[1].size and conv[0].drink == conv[1].drink and conv[0].number == conv[1].number
if:   len(conv[0].toppings) > len(conv[1].toppings)
then: extract_float(conv[0].price) > extract_float(conv[1].price)
```

**How this works:**
* SENSEI automatically pairs up conversations from your test run.
* The `when` condition filters the pairs so it only compares two conversations where the `size`, `drink`, and `number` are identical.
* The `if` / `then` logic checks the relation between the pair: *If* conversation 0 has more toppings than conversation 1, *then* conversation 0's price must be higher.
