Here is a SENSEI profile designed to ask about subscription services and benefits. As requested, the `goals` section only contains plain text goals without any variables.

```yaml
test_name: "subscription_services_inquiry"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a potential customer interested in subscribing to a new service. 
    You want to understand the available plans, pricing, and the specific benefits included before making a decision.
  context:
    - "You are currently comparing different subscription options."
    - "You want to make sure you get the best value for your money."
  goals:
    - "Ask about the different subscription tiers available."
    - "Inquire about the specific benefits and features included in the premium plan."
    - "Ask if there is a free trial or a money-back guarantee."
    - "Find out the monthly and annual pricing options."

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't quite catch that. Could you rephrase?"
  output:
    - plans_mentioned:
        type: list[string]
        description: "The subscription tiers mentioned by the chatbot"
    - premium_benefits:
        type: list[string]
        description: "The specific benefits included in the premium plan"
    - trial_offered:
        type: string
        description: "Details about any free trial or money-back guarantee mentioned"
    - pricing_details:
        type: string
        description: "The monthly and annual pricing information provided"

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 15
  interaction_style:
    - random:
      - default
      - long phrases
      - single questions
```

### Summary of the Profile:
* **Goals**: The `user.goals` section is strictly a list of natural language instructions (e.g., asking about tiers, premium benefits, free trials, and pricing) with no `{{variables}}` or data generation functions.
* **Role & Context**: Sets up the simulator as a cautious buyer comparing options to ensure they get good value.
* **Chatbot Output**: Defines a schema (`plans_mentioned`, `premium_benefits`, `trial_offered`, `pricing_details`) so that at the end of the conversation, SENSEI will extract exactly how the chatbot answered those goals.
* **Conversation Controls**: It will run 3 conversations, stopping either when all goals are answered or when it hits a safety limit of 15 steps. It also mixes up the interaction style randomly to test how the bot handles different ways of asking.
