Based on the SENSEI documentation (`sensei-chat-guide.md`), here are the fields that are **not mandatory (optional)** when creating a profile:

### 1. The entire `llm` block
You do not have to define the `llm` section. If you omit it, SENSEI will automatically apply default settings (such as a default model, temperature, and text format). 
*(If you do include it, fields like `temperature`, `model`, `model_prov`, and `format` are used to override the defaults).*

### 2. Cost Limits (`max_cost`)
Cost caps are entirely optional but highly recommended for safety:
*   **`conversation.max_cost`**: An optional float value (e.g., `0.5`) to cap the spend for the *entire run*.
*   **`conversation.goal_style.max_cost`**: An optional float value to cap the spend *per conversation*.

### 3. User Context & Personalities
*   **`user.context`**: While it's good practice to give the user context, referencing a specific personality file (e.g., `- personality: personalities/calm-user.yml`) is completely optional. You can just use freeform text or omit the context if the `role` is descriptive enough.

### 4. `goal_style.all_answered` parameters
If you choose `all_answered` as your `goal_style` (instead of a fixed or random number of steps), its sub-fields are optional:
*   **`export`**: Optional boolean (`true`/`false`). If set to true, it exports a verification dataframe.
*   **`limit`**: Optional safety stop limit (integer). If omitted, it defaults to `30` steps.

### 5. Interaction Styles
*   **`conversation.interaction_style`**: You don't have to define complex interaction styles (like `make spelling mistakes` or `change language`). If you omit it or use `default`, the simulated user will just carry out the conversation in a natural way.

Everything else—like the `test_name`, `user.language`, `user.role`, `user.goals`, `chatbot.is_starter`, `chatbot.fallback`, `chatbot.output`, and `conversation.number`—forms the core contract of the profile and should be included! 😊
