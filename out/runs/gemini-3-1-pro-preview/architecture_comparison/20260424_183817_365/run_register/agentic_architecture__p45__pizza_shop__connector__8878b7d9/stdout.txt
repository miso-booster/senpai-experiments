### A quick note on stripping HTML tags:
Based on the `custom-connector-guide.md` documentation, the YAML connector extracts the exact string found at the `response_path` (which in this case includes the `<p>` and `<br>` tags). **There is no documented YAML field (like `strip_html: true`) to natively remove HTML tags within the connector configuration itself.** 

Because I cannot fabricate undocumented features, the connector above will return the raw HTML string. If you strictly need plain text, this HTML stripping will likely need to be handled by the Chatbot Dojo platform's internal text processing or by wrapping this configuration in a custom Python connector script! 😊 Let me know if you need help with anything else.
