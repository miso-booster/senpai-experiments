In Sensei-check, when you write a metamorphic rule using a `then` statement, it **must** be paired with an `if` statement. Here is how the three parts work together:
* **`when`**: Filters and selects the comparable conversations (e.g., "same size and same drink").
* **`if`**: Defines the condition or change between the two conversations (e.g., "conversation 0 has more toppings than conversation 1").
* **`then`**: Asserts the expected outcome (e.g., "conversation 0 should cost more").
