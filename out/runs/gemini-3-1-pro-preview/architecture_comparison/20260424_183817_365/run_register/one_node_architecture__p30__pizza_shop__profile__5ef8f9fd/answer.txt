Here is a profile tailored exactly to your needs! 🍕 

I've set up the user to be quite impatient and rude using the `role` and `context` fields. I also included 4 goals with 4 variables (`pizza_type`, `size`, `drink`, and `payment_method`). As requested, `pizza_type` and `size` use the `pairwise()` function, and the conversation `number` is set to `combinations` so Sensei will automatically calculate the matrix and run the exact number of conversations needed to cover all pairs! 🚀

```yaml
test_name: "rude_fast_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a very rude and impatient customer ordering from a pizza shop.
    You want your food immediately, you hate waiting, and you demand quick answers.
  context:
    - "You are in a rush and have zero patience."
    - "You speak abruptly and don't use polite words like 'please' or 'thank you'."
  goals:
    - "I want a {{size}} {{pizza_type}} pizza and make it quick!"
    - "Give me a {{drink}} to go with it."
    - "I'm paying with {{payment_method}}, so have it ready."
    - "Tell me exactly how long this is going to take."
    - pizza_type:
        function: pairwise()
        type: string
        data: [Pepperoni, Meat Lovers, Hawaiian, Supreme]
    - size:
        function: pairwise()
        type: string
        data: [large, extra large, family size]
    - drink:
        function: random()
        type: string
        data: [Coke, Diet Coke, Sprite]
    - payment_method:
        function: random()
        type: string
        data: [cash, credit card]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't catch that. Could you repeat your order?"
  output:
    - total_price:
        type: currency
        description: "The total price of the order."
    - estimated_time:
        type: time("hh:mm")
        description: "The estimated time for the order to be ready."
    - order_summary:
        type: string
        description: "A summary of the pizza and drink ordered."

conversation:
  number: combinations
  goal_style:
    all_answered:
      export: true
      limit: 15
  interaction_style:
    - single question
```

### A quick tip 👀:
Because `pizza_type` has 4 options and `size` has 3 options, the `pairwise()` function combined with `number: combinations` will generate exactly 12 conversations to ensure every size is tested with every pizza type at least once.
