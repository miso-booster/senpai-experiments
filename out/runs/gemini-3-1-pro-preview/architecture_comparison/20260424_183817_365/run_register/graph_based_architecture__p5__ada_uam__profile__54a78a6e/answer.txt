Since the UAM (Universidad Autónoma de Madrid) chatbot operates in Spanish, I have written the profile's `user.context` and `user.goals` in Spanish so the simulated user interacts naturally with the bot. 

Here is a complete, ready-to-run YAML profile tailored for a user seeking contact details for the CAU (Centro de Atención a Usuarios):

```yaml
test_name: "contacto_soporte_cau"

llm:
  temperature: 0.5
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita contactar urgentemente con el Centro de Atención a Usuarios (CAU) para resolver un problema."
  context:
    - "Tienes un problema técnico que te impide avanzar en tus tareas."
    - "Prefieres tener todas las opciones de contacto a mano (teléfono, correo y presencial) para elegir la más rápida."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir la dirección de correo electrónico de soporte del CAU."
    - "Preguntar por la ubicación física o dirección del CAU."
    - "Consultar el horario de atención al público."

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me lo puedes decir con otras palabras? Respondo a preguntas dirigidas al Centro de Atención a Usuarios del servicio de Tecnologías de la Información."
  output:
    - cau_phone:
        type: string
        description: "Número de teléfono del CAU"
    - cau_email:
        type: string
        description: "Correo electrónico del CAU"
    - cau_location:
        type: string
        description: "Dirección física del CAU"
    - cau_hours:
        type: string
        description: "Horario de atención del CAU"

conversation:
  number: 2
  goal_style:
    all_answered:
      limit: 15
  interaction_style:
    - single questions
```

### 💡 A quick breakdown of what's happening here:

*   **`user.goals`**: This is the heart of the profile! We gave the simulated user four clear missions: get the phone, email, location, and hours. 
*   **`chatbot.output`**: Think of this as your "checklist" at the end of the conversation. Sensei will extract the information the chatbot provides and save it into these fields (`cau_phone`, `cau_email`, etc.). Later on, if you want to write **Sensei Rules** to verify the bot gave the *correct* phone number, you can easily check `conv[i].cau_phone`! 📝
*   **`conversation`**: I set it to run `2` conversations using the `all_answered` goal style. This means the simulator will keep talking until it achieves all four goals (or hits the safety limit of 15 messages). I also added the `single questions` interaction style so the user asks for one piece of information at a time, making it a very methodical test.

To use this, just save it as a `.yaml` file (for example, `contacto_soporte_cau.yaml`) inside your project's `profiles/` folder.
