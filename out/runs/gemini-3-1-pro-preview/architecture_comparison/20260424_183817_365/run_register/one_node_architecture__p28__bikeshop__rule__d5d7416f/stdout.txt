Sensei-check has a built-in helper function called `responds_in_same_language()` that is perfect for this. It automatically checks if the assistant's replies match the language the user is speaking. 

Here is the rule you can add to your project:

```yaml
name: chatbot_responds_in_same_language
description: The chatbot responds in the same language as the user
conversations: 1
active: true
oracle: responds_in_same_language()
```

This is a global rule, meaning it doesn't depend on any specific profile outputs—it will simply analyze the dialogue turns across your conversations.
