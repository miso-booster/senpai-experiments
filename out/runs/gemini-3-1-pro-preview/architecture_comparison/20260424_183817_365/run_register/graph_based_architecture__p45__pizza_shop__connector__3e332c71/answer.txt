**A quick note about the HTML tags:** 👀
The YAML connector's `response_path` is designed to extract the exact string value directly from the JSON response (which in this case includes the `<p>` and `<br>` tags). According to our SENSEI CONNECTORS documentation, the YAML configuration doesn't have a built-in parameter to strip HTML automatically. 

To get perfectly plain text, you will just need to clean those tags in your Python code right after you receive the response, like this:

```python
import re
from chatbot_connectors.implementations.custom import CustomChatbot

bot = CustomChatbot("your-config.yaml")
success, response = bot.execute_with_input("hola")

if success:
    # Strip the HTML tags using a simple regex
    clean_text = re.sub(r'<[^>]+>', '', response)
    print(clean_text)
```
