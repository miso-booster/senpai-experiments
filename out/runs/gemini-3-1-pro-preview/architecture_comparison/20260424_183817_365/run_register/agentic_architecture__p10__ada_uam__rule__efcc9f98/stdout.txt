### 1. Metamorphic Rule: Consistent Welcome Day Info
Since the "Welcome Day" is a specific university event, its date and location shouldn't change depending on which degree (`grados`) or course (`cursos`) the user asks about. This rule compares two conversations to ensure the bot gives consistent event details.

```yaml

conversations: 2
```

### 2. Single-Conversation Rule: Valid Application Fee
Your profile extracts an `application_fee` of type `money`. This rule ensures that whenever the bot mentions the fee, it is a valid positive number (or zero). We use the built-in `extract_float` helper to parse the money value.

```yaml
name: valid_application_fee
description: The application fee must be a positive amount or zero.
conversations: 1
active: true
when: application_fee is not None
oracle: extract_float(application_fee) >= 0
```

```yaml
name: responds_in_same_language
```

### 4. Global Rule: No Empty Links
Because your profile expects the bot to provide several URLs (e.g., `admission_to_grados_link`, `waitlist_info_link`, `welcome_day_link`), it's a good idea to check that the bot isn't returning broken or empty link placeholders.

```yaml
name: non_empty_links
description: The chatbot should not return empty links when providing URLs for admissions or events.
conversations: 1
active: true
oracle: not chatbot_returns("LINK: <empty>")
```
