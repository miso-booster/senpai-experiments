Para comprobar si el asistente confirma que ha añadido la bebida durante la conversación, podemos crear una **regla general** utilizando la función `utterance_index`. Esta función busca semánticamente en qué turno de la conversación ocurre una acción específica.

Aquí tienes la regla en formato YAML. Esta regla verifica que el usuario primero pide una bebida y, posteriormente, el asistente confirma que la ha añadido:

```yaml
name: assistant_confirms_drink
description: El asistente confirma que añadió la bebida después de que el usuario la pide
conversations: 1
active: true
oracle: utterance_index('user', 'ordering a drink') < utterance_index('assistant', 'confirms adding the drink')
```

### ¿Cómo funciona esta regla?
- **`conversations: 1`**: Es una regla de oráculo simple que evalúa cada conversación de forma individual.
- **`utterance_index('user', 'ordering a drink')`**: Encuentra el número de turno donde el usuario pide la bebida.
- **`utterance_index('assistant', 'confirms adding the drink')`**: Encuentra el número de turno donde el asistente confirma que la ha añadido.
- **`oracle`**: Al usar el operador `<`, nos aseguramos de que la confirmación del asistente ocurre *después* de que el usuario hace la petición. Si solo te interesa saber si el asistente lo confirma en algún momento (sin importar el orden), podrías cambiar el oráculo a: `oracle: utterance_index('assistant', 'confirms adding the drink') > 0`.
