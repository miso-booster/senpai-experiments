Based on the SENSEI rules documentation (specifically `sensei-check-doc.md` and `rules-examples.md`), there is a built-in helper function called `responds_in_same_language()` designed exactly for this purpose. 

Because this rule only relies on the general conversation text and not on specific data extracted by a chatbot profile, it is **profile-agnostic**. This means you can use it globally across your project without needing to tie it to specific `chatbot.output` fields.

Here is the YAML rule you can use:

```yaml
name: chatbot_responds_in_same_language
description: The chatbot responds in the same language as the user
conversations: 1
active: true
oracle: responds_in_same_language()
yields: f"The chatbot does not respond in the same language"
```

### How it works:
* **`conversations: 1`**: This is a single-conversation oracle check, meaning it evaluates each conversation individually.
* **`oracle: responds_in_same_language()`**: This calls the built-in, LLM-backed helper that checks if the assistant's replies match the language the user is speaking.
* **`yields`**: If the rule fails, it will output the helpful error message provided.

You can save this as a `.yaml` file in your `rules` directory, and it will automatically check language consistency for your conversations! Let me know if you need help creating any other rules.
