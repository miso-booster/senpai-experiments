Para comprobar esto, vamos a crear una **regla de una sola conversación** (lo que en Sensei llamamos un oráculo tradicional). Esta regla verificará que el campo `eco_friendly_toys` haya sido extraído correctamente y contenga al menos un elemento al final de la interacción.

Aquí tienes el código YAML listo para tu regla:

```yaml
name: eco_friendly_toys_returned
description: Verifica que el chatbot haya devuelto una lista de juguetes eco-friendly durante la conversación.
conversations: 1
oracle: eco_friendly_toys is not None and len(eco_friendly_toys) > 0
```

💡 **El consejo de Senpai (Conexión con el Perfil):**
Recuerda que las reglas de Sensei-check están directamente conectadas con los perfiles de SENSEI Chat. Para que esta regla funcione a la perfección, tu perfil debe exponer exactamente ese mismo nombre en su sección `chatbot.output`. 

Debería verse algo así en tu archivo del perfil:

```yaml
test_name: "eco_friendly_toys_search"

user:
  language: Spanish
  role: "Eres un cliente buscando juguetes ecológicos para niños."
  goals:
    - "Preguntar por juguetes respetuosos con el medio ambiente."

chatbot:
  fallback: "Lo siento, no he entendido. ¿Puedes repetirlo?"
  output:
    - eco_friendly_toys:
        type: list[string]
        description: Lista de juguetes respetuosos con el medio ambiente sugeridos por el asistente.

conversation:
  number: 1
  goal_style:
    steps: 3
```

De esta manera, cuando Sensei evalúe la conversación, sabrá exactamente dónde buscar esa lista de juguetes y la regla podrá comprobar su longitud.
