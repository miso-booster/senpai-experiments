```yaml
test_name: pizza_and_drinks_information_seeker
llm:
  format:

  model: gpt-4o-mini
  temperature: 0.3
user:
  language: English
  role: 'A customer seeking information about pizza types, prices, available drinks, and shop hours before potentially placing an order.'
  context:
    - 'personality: personalities/skeptical-user'

  goals:

    - "Ask about the shop's operating hours."
    - "Ask if they deliver."
chatbot:
  is_starter: false
  fallback: "I'm sorry, I did not get what you said. I can help you ordering predefined or custom pizzas, and then drinks.`\nFor troubleshooting, visit: https://python.langchain.com/docs/troubleshooting/errors/OUTPUT_PARSING_FAILURE"
  output:

```

### 💡 A quick breakdown of what we added:
*   **`is_starter: false`**: This means the simulated user will send the first message, not the chatbot.
*   **`fallback`**: This is the actual message your bot sends when it gets confused. Providing this helps Sensei avoid getting stuck in endless "I don't understand" loops!
*   **`output`**: Notice how each item here (`pizza_types`, `margarita_price`, etc.) perfectly matches the questions your user is asking in the `goals` section? At the end of the conversation, Sensei will extract these values so you can easily verify if the chatbot gave the right answers. 👀
