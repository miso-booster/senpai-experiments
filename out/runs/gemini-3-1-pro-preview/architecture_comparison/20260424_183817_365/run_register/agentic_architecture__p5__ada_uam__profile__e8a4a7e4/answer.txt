Here is the SENSEI profile tailored for testing the UAM chatbot regarding the CAU (User Support Center). 

I have designed it based on the `sensei-chat-guide.md` documentation. The simulated user will try to obtain the phone number, email, location, and opening hours. It uses the `all_answered` goal style so the conversation will naturally conclude once the chatbot provides all the requested information.

```yaml
test_name: "uam_cau_support"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a student or staff member at UAM (Universidad Autónoma de Madrid) seeking support from the CAU (User Support Center).
    You want to know how to contact them and when they are available.
  context:
    - "You need accurate contact details to resolve an IT issue."
  goals:
    - "Ask for the CAU's phone number."
    - "Ask for the CAU's email address."
    - "Ask for the CAU's physical location."
    - "Ask for the CAU's opening hours."

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand. Could you please rephrase?"
  output:
    - cau_phone_number:
        type: string
        description: "The phone number of the CAU"
    - cau_email:
        type: string
        description: "The email address of the CAU"
    - cau_location:
        type: string
        description: "The physical location or office of the CAU"
    - cau_opening_hours:
        type: string
        description: "The opening hours of the CAU"

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - default
```

### 📝 Summary of the Profile
* **User Persona (`user.role` & `user.context`)**: Represents a UAM member who needs IT support and is looking for the CAU's contact and location details.
* **Goals (`user.goals`)**: Explicitly lists the four pieces of information the user wants to obtain (phone, email, location, hours).
* **Conversation Flow (`conversation`)**: It will run 3 conversations. The `all_answered` goal style ensures that the simulator will keep asking questions until all 4 goals are met (up to a safety limit of 20 turns).
* **Extracted Outputs (`chatbot.output`)**: At the end of the conversation, Sensei will extract the following fields so you can validate them later with Sensei Rules:
  * `cau_phone_number`
  * `cau_email`
  * `cau_location`
  * `cau_opening_hours`
