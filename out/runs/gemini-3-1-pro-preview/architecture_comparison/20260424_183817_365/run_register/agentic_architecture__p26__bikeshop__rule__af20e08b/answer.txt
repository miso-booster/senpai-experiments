Based on the SENSEI RULES documentation (`sensei-check-doc.md`), the rule you provided is incorrect for a few reasons. 

Since you are just checking a specific value in a single conversation, this should be a **single-conversation oracle rule**, rather than a metamorphic rule (which compares multiple conversations). 

Here is the corrected YAML:

```yaml
name: check_tune_up_price
description: Checks if the tune-up price is equal to $50.
conversations: 1
oracle: extract_float(tune_up_price) == 50
```

### What I changed and why:

1. **`conversations: 1` instead of `2`**: Your rule was set to `2`, which tells SENSEI to look for pairs of conversations to compare (metamorphic testing). Since you only want to verify the price in a single chat, it should be `1`.
2. **Removed `conv[0].` prefix**: In single-conversation rules, you don't need to specify the conversation index. You can just use the field name directly (e.g., `tune_up_price`).
3. **Replaced `when`, `if`, and `then` with `oracle`**: 
   - `when` is used to filter conversations in metamorphic rules.
   - `then` must be a Python boolean expression (like `x > y`), not a string like `"The tune-up price is $50."`.
   - For a straightforward true/false check on a single conversation, using `oracle:` is the correct and cleanest approach.
4. **Added `extract_float()`**: Chatbot outputs are often extracted as strings (like `"$50.00"`). Wrapping the variable in the built-in `extract_float()` helper ensures SENSEI safely parses the number before comparing it to `50`.

*(Optional tip: If you also want to strictly check that the currency is in US Dollars, you can update the oracle to: `oracle: extract_float(tune_up_price) == 50 and currency(tune_up_price) == 'USD'`)* 😊
