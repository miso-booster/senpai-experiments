To check that a small pizza costs exactly $10, we can create a single-conversation rule. We'll use the `when` clause to filter only the conversations where the user ordered a small pizza, and the `oracle` clause to verify the extracted `price`.

Here is the YAML for your rule:

```yaml
name: small_pizza_price_exact
description: Checks that the price of a small pizza is exactly $10.
conversations: 1
when: size == 'small'
oracle: extract_float(price) == 10 and currency(price) == 'USD'
```

### How it works:
* **`conversations: 1`**: This tells Sensei-check that we are evaluating one conversation at a time (a traditional oracle).
* **`when: size == 'small'`**: This acts as a filter so the rule only runs if the `size` slot extracted from the conversation is 'small'.
* **`oracle: ...`**: This is the condition that must pass. We use the built-in `extract_float()` helper to grab the number from the `price` output, and `currency()` to ensure it's in USD. 

*Note: Make sure your SENSEI Chat profile actually extracts fields named `size` and `price` in its `chatbot.output` section for this rule to work perfectly! (Looking at your project, profiles like `pizza_order_test_predefined` already extract `price`, so you're on the right track!)* 🍕
