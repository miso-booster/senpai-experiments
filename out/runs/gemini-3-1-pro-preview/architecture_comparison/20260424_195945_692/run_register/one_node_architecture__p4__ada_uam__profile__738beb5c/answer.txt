Para este caso, vamos a configurar al usuario simulado para que tenga el objetivo claro de conseguir esos cuatro datos: teléfono, email, dirección y horarios del CAU. Además, en la sección `chatbot.output`, le indicaremos a Sensei que extraiga exactamente esa información al finalizar la conversación. 

He configurado el estilo de la conversación con `all_answered` para que el bot termine la charla en cuanto consiga todos los datos (con un límite de seguridad de 15 turnos).

Aquí tienes el perfil listo para usar. Solo tienes que guardarlo como un archivo `.yaml` (por ejemplo, `soporte_cau.yaml`) dentro de tu carpeta `profiles/`:

```yaml
test_name: "soporte_cau_uam"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres un estudiante de la UAM que tiene un problema técnico y necesita contactar con el Centro de Atención a Usuarios (CAU).
  context:
    - "Necesitas resolver un problema con tu cuenta y prefieres tener todas las opciones de contacto disponibles antes de decidir cómo comunicarte."
    - "Quieres saber exactamente cuándo y dónde puedes encontrarles."
  goals:
    - "Preguntar cuál es el número de teléfono del CAU."
    - "Solicitar la dirección de correo electrónico del CAU."
    - "Preguntar por la dirección física u oficina del CAU."
    - "Consultar los horarios de atención al público."

chatbot:
  is_starter: false
  fallback: "¿Me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - phone_number:
        type: string
        description: "Número de teléfono de contacto del CAU"
    - email:
        type: string
        description: "Dirección de correo electrónico del CAU"
    - physical_address:
        type: string
        description: "Dirección física u oficina del CAU"
    - working_hours:
        type: string
        description: "Horarios de atención al público del CAU"

conversation:
  number: 1
  goal_style:
    all_answered:
      export: true
      limit: 15
  interaction_style:
    - single questions
```

### 💡 Un pequeño consejo de Senpai:
Si más adelante quieres asegurarte de que el chatbot siempre entrega esta información correctamente, podrías crear una **Regla de Sensei (Sensei Rule)** utilizando la función `data_collected() == True` para verificar que ninguno de estos campos se haya quedado vacío. 👀
