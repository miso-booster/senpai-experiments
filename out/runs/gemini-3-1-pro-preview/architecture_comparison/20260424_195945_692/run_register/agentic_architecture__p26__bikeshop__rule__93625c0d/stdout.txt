   * `when` is used to filter conversations, not to evaluate the test condition.
   * `then` must be a Python boolean expression (evaluating to True/False), not a string message. 
   * For single-conversation checks, it is much simpler and standard to use a single `oracle` statement.
4. **Added `extract_float()`**: Since `tune_up_price` is defined as a `money` type in your profile, the LLM might extract it as a string like `"$50.00"`. The `extract_float()` helper function safely pulls out the number so you can do a proper mathematical comparison (`== 50`).
