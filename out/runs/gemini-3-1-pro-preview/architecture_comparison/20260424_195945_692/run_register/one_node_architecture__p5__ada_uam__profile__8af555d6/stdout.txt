¡Hola! Claro que sí 😊. Aquí tienes un perfil de SENSEI Chat diseñado específicamente para simular a un usuario que necesita contactar con el Centro de Atención a Usuarios (CAU) de la UAM. 

Este perfil guiará al simulador para que pregunte por el teléfono, el correo electrónico, la ubicación física y los horarios de atención, y luego extraerá esa información en la sección `chatbot.output` para que puedas validarla fácilmente.

Aquí tienes el código YAML listo para usar:

```yaml
test_name: "cau_support_info_request"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita contactar urgentemente con el Centro de Atención a Usuarios (CAU) para resolver un problema técnico."
  context:
    - "Tienes un problema técnico que te impide acceder a tus servicios universitarios."
    - "Necesitas recopilar todas las formas posibles de contactar al CAU para pedir ayuda."
  goals:
    - "Preguntar cuál es el número de teléfono del CAU."
    - "Solicitar la dirección de correo electrónico del CAU."
    - "Preguntar por la ubicación física o dirección de las oficinas del CAU."
    - "Consultar cuáles son los horarios de atención al público del CAU."

chatbot:
  is_starter: false
  fallback: "¿Puedes preguntármelo de otra forma? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - cau_phone:
        type: string
        description: "Número de teléfono del CAU"
    - cau_email:
        type: string
        description: "Correo electrónico de contacto del CAU"
    - cau_location:
        type: string
        description: "Dirección física o ubicación de las oficinas del CAU"
    - cau_hours:
        type: string
        description: "Horarios de atención o apertura del CAU"

conversation:
  number: 2
  goal_style:
    steps: 8
  interaction_style:
    - single questions
```

**💡 Un pequeño consejo:** He configurado el `interaction_style` como `single questions` para que el usuario simulado haga las preguntas de una en una. Esto suele ser muy útil para evaluar cómo el chatbot maneja preguntas específicas de contacto.
