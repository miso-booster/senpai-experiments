To check if the chatbot successfully provided an `order_id`, we can create a simple single-conversation rule (also known as an oracle). This rule will look at the extracted outputs at the end of the conversation and verify that the `order_id` field is present.

Here is the YAML rule you can use:

```yaml
name: order_id_provided
description: The chatbot must return an order ID at the end of the conversation.
conversations: 1
active: true
oracle: 'order_id' in data_output
```

**How it works:**
This rule uses `data_output`, which is a special dictionary containing all the fields extracted by your Sensei profile's `chatbot.output` schema. By checking `'order_id' in data_output`, we ensure that the LLM successfully found and extracted that specific piece of information. If the chatbot forgets to give the user their order ID, this rule will catch it and fail! 🕵️‍♂️
