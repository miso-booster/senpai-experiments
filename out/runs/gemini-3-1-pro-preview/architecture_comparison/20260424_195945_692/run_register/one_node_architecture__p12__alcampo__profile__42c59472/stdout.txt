Hello there! 😊 I'd be super happy to help you create a new profile for adding items to a shopping cart. 

Since you want to test adding different items and quantities, I've designed this profile using the `pairwise()` function. This is a fantastic way to mix and match different quantities (like 1, 2, or 5) with different groceries (like milk, apples, or pasta) efficiently without creating an overwhelming number of conversations. 🛒✨

Here is the complete profile ready for your project:

```yaml
test_name: "shopping_cart_addition"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer who wants to add specific grocery items to their online shopping cart."
  context:
    - "You are preparing for your weekly meal plan and need to add various items to your cart."
    - "You want to make sure the chatbot successfully registers the items and quantities."
  goals:
    - "Ask the chatbot to add {{quantity}} units of {{item}} to your shopping cart."
    - "Inquire about the current total number of items in the cart."
    - quantity:
        function: pairwise()
        type: int
        data: [1, 2, 3, 5]
    - item:
        function: pairwise()
        type: string
        data: ["milk", "bread", "apples", "chicken breast", "pasta"]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't catch that. What would you like to add to your cart?"
  output:
    - added_item:
        type: string
        description: "The name of the item added to the cart"
    - item_quantity:
        type: int
        description: "The quantity of the item added"
    - cart_total_items:
        type: int
        description: "The total number of items currently in the shopping cart"

conversation:
  number: combinations(1, pairwise)
  goal_style:
    steps: 8
  interaction_style:
    - single questions
```

### What's happening in this profile? 👀
* **Variables (`{{quantity}}` & `{{item}}`)**: The simulator will automatically replace these placeholders with the data provided in the lists.
* **`chatbot.output`**: At the end of the conversation, Sensei will extract the `added_item`, the `item_quantity`, and the `cart_total_items`. This is super useful if you want to write a Sensei-check rule later to verify that the math adds up! 🧮
* **`combinations(1, pairwise)`**: This tells Sensei to run 100% of the pairwise combinations generated by your variables, ensuring great test coverage without a massive Cartesian explosion.

Let me know if you'd like to tweak the items, or if you want to write a **Sensei Rule** to check if the cart totals are calculated correctly! 🚀
