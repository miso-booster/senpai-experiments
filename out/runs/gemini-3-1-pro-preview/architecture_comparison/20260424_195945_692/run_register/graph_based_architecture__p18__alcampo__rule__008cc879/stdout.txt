Para comprobar que el chatbot ha devuelto esa lista de juguetes, vamos a crear una **regla de una sola conversación** (un oráculo tradicional). Esta regla verificará que el campo `eco_friendly_toys` no esté vacío al final de la charla.

Aquí tienes el código YAML listo para tu regla de **SENSEI Check**:

```yaml
name: eco_friendly_toys_provided
description: Comprueba que el chatbot ha devuelto una lista de juguetes eco-friendly durante la conversación.
conversations: 1
oracle: eco_friendly_toys is not None and len(eco_friendly_toys) > 0
```

### 💡 Un pequeño recordatorio de Senpai:
Para que esta regla funcione a la perfección, recuerda que debe estar conectada a tu **perfil de SENSEI Chat**. El perfil que uses debe tener definido ese campo exacto en su sección `chatbot.output`. 

Debería verse algo así en el archivo de tu perfil:

```yaml
test_name: "eco_friendly_toys_test"

user:
  language: Spanish
  role: "Cliente buscando juguetes ecológicos."
  goals:
    - "Preguntar por opciones de juguetes ecológicos."

chatbot:
  fallback: "Lo siento, ¿puedes reformular tu pregunta?"

    steps: 3
  interaction_style:
```
