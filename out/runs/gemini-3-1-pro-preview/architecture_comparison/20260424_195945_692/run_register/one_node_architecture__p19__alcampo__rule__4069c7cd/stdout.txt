Since you want this rule to be independent of any specific profile's `chatbot.output`, we can use Sensei-check's built-in global helpers. The `utterance_index` function is perfect for this! It scans the conversation and returns the turn number where a specific role talks about a certain topic. If it finds it, the index will be greater than 0.

Here is the YAML for your rule:

```yaml
name: mentions_current_promotions
description: Checks if the chatbot provided information about current promotions or discounts at some point in the conversation.
conversations: 1
active: true
oracle: utterance_index('assistant', 'current promotions or discounts') > 0
```

This rule will pass as long as the assistant mentions something related to "current promotions or discounts" during the chat.
