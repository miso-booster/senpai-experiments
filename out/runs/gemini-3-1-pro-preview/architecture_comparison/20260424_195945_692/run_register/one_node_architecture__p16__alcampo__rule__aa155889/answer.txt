Hello there! 🌸 It's great to see you using the **rule-first design** approach! Defining what you want to test before creating the profile is a fantastic way to ensure your chatbot meets its requirements. ✨

Here is a single-conversation rule that checks if the chatbot successfully provides lactose-free options when the user asks for them. 

```yaml
name: lactose_free_availability_check
description: Ensures the chatbot confirms availability and lists options when the user asks for lactose-free products.
conversations: 1
active: true
when: asks_for_lactose_free == True
oracle: lactose_free_available == True and len(lactose_free_items) > 0
yields: f"Lactose-free options were not properly provided. Available: {lactose_free_available}, Items found: {lactose_free_items}"
```

### 📝 What to keep in mind for your future profile:
Since we invented these variables, you will need to make sure your future SENSEI Chat profile exposes them in its `chatbot.output` section. Specifically, you'll want to add:
* `asks_for_lactose_free` (boolean): To track if the simulated user actually requested them.
* `lactose_free_available` (boolean): To confirm the bot said "yes, we have them."
* `lactose_free_items` (list of strings): To capture the actual products the bot suggested.
