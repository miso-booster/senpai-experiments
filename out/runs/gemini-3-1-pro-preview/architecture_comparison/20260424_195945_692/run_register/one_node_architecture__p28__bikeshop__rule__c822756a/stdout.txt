To make sure your chatbot matches the user's language, we can create a simple single-conversation rule. Sensei has a built-in helper function called `responds_in_same_language()` specifically designed for this! 

Here is the YAML rule you can add to your project:

```yaml
name: chatbot_responds_in_same_language
description: The chatbot responds in the same language as the user
conversations: 1
active: true
oracle: responds_in_same_language()
on-error: "The chatbot did not respond in the same language."
```

### How it works:
* **`conversations: 1`**: It evaluates each conversation individually.
* **`oracle: responds_in_same_language()`**: This uses an LLM-backed check under the hood to verify that the assistant's replies match the language the simulated user is speaking.
* **`on-error`**: If the chatbot suddenly switches to a different language, Sensei-check will flag it and return this helpful message.

Just save this as a `.yaml` file in your `rules/` folder, and you'll be good to go! Let me know if you need help with anything else. 🚀
