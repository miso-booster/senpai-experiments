In **Sensei-check**, we have a handy built-in helper function made exactly for this called `responds_in_same_language()`. Because it checks the conversation's general behavior, this is considered a **global rule**—meaning you don't even need to tie it to specific `chatbot.output` fields from your SENSEI Chat profiles! 

Here is the YAML rule you can copy and paste right into your project:

```yaml
name: user_language_matching
description: The assistant must reply in the same language that the user is speaking.
conversations: 1
oracle: responds_in_same_language() is True
```

### How it works:
* **`conversations: 1`**: This tells Sensei-check to evaluate this rule on each conversation individually.
* **`oracle: responds_in_same_language() is True`**: This uses our LLM-backed helper to analyze the dialogue and verify that the assistant's replies match the user's language.
