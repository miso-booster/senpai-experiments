You are definitely on the right track, but the rule needs a few adjustments to work correctly. Since you want to check an absolute value (that the price is exactly $50) rather than comparing how the price changes between two different conversations, we should use a **single-conversation oracle** instead of a metamorphic rule.

Here is the corrected version of your rule:

```yaml
name: check_tune_up_price
description: Checks if the tune-up price is equal to $50.
conversations: 1
oracle: extract_float(tune_up_price) == 50 and currency(tune_up_price) == 'USD'
```

### 🛠️ What I changed and why:

1. **Changed `conversations: 2` to `conversations: 1`**: Your original rule was set up for metamorphic testing (comparing two conversations). Since we just want to verify a static price in a single chat, `conversations: 1` is the way to go! Because of this, we also drop the `conv[0].` prefix and just use the field name directly.
2. **Removed the `when` filter**: In your original rule, `when: conv[0].tune_up_price == 50` acted as a filter. This meant Sensei-check would *only* evaluate conversations where the price was already 50, completely ignoring the ones where the chatbot made a mistake! 
3. **Replaced `if/then` with `oracle`**: The `then` clause expects a Python expression that evaluates to `True` or `False`, but you had a text string (`"The tune-up price is $50."`). For a simple 1-conversation check, using a single `oracle` line is much cleaner.
4. **Used `extract_float()` and `currency()` helpers**: Chatbots often output prices as strings like `"$50.00"` or `"50 USD"`. By using the built-in `extract_float(tune_up_price) == 50` and `currency(tune_up_price) == 'USD'`, we safely extract the number and ensure the currency is actually in dollars! 💵

**One quick Senpai reminder:** 👀 
Make sure that `tune_up_price` is exactly how the field is named in your SENSEI Chat profile's `chatbot.output`. If your profile calls it something else (like `price` or `total_cost`), you'll need to update the variable name in the rule to match!
