Here is the SENSEI profile to test the UAM chatbot for the CAU (User Support Center) scenario. I have based this on the `sensei-chat-guide.md` documentation.

This profile simulates a user who wants to gather all the contact and location details for the CAU. It sets up the goals as simple questions and defines the extracted fields in the `chatbot.output` section so that you can later validate if the chatbot successfully provided the information.

```yaml
test_name: "uam_cau_support_info"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a student or staff member at UAM (Universidad Autónoma de Madrid) seeking support from the CAU (Centro de Atención a Usuarios).
  context:
    - "You need to contact the CAU for a technical issue."
    - "You want to gather all their contact and location details before reaching out."
  goals:
    - "Ask for the CAU's phone number."
    - "Ask for the CAU's email address."
    - "Ask for the CAU's physical location."
    - "Ask for the CAU's opening hours."

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand. Can you rephrase?"
  output:
    - phone_number:
        type: string
        description: "The phone number of the CAU provided by the chatbot"
    - email_address:
        type: string
        description: "The email address of the CAU provided by the chatbot"
    - physical_location:
        type: string
        description: "The physical location or address of the CAU provided by the chatbot"
    - opening_hours:
        type: string
        description: "The opening hours of the CAU provided by the chatbot"

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 15
  interaction_style:
    - random:
      - single questions
      - all questions
      - default
```

### 📝 Summary of the Profile

* **User & Goals:** The simulated user will ask the chatbot for the four specific pieces of information you requested (phone, email, location, and hours).
* **Conversation Controls:** 
  * `number: 3` means it will run 3 conversations to test different interaction flows.
  * `goal_style: all_answered` ensures the conversation continues until all goals are met (up to a safety limit of 15 turns).
  * `interaction_style` uses a random mix of asking one question at a time (`single questions`), asking everything at once (`all questions`), or a natural flow (`default`).
* **`chatbot.output` Fields:** At the end of the conversation, SENSEI will extract the following fields, which you can later use in SENSEI RULES to validate the chatbot's answers:
  * `phone_number`
  * `email_address`
  * `physical_location`
  * `opening_hours`
