Here is a rule to check that the ADA UAM chatbot successfully extracted all the CAU contact details! 

Since we want to verify that the chatbot provided the email, phone, and physical address in a single conversation, we can write a straightforward oracle that checks if these specific fields are not `None`. 

Here is the YAML for your rule:

```yaml
name: cau_contact_info_provided
description: Checks that the chatbot provided the email, phone, and physical address of the CAU.
conversations: 1
active: true
oracle: contact_email is not None and contact_phone is not None and physical_address is not None
yields: f"Missing CAU contact info! Email: {contact_email}, Phone: {contact_phone}, Address: {physical_address}"
```

### How it works:
* **`conversations: 1`**: This is a standard single-conversation rule (not metamorphic), as it just checks the output of each individual chat.
* **`oracle`**: It directly evaluates the fields defined in your profile's `chatbot.output`. If any of them are missing (`None`), the rule will fail.
* **`yields`**: If the rule fails, it will print out exactly which fields were captured and which ones were left blank, making it super easy to debug! 🕵️‍♂️
