Para comprobar si el asistente confirma la bebida que el usuario ha pedido, la mejor herramienta que tenemos en Sensei-check es la función `utterance_index(who, what)`. Esta función impulsada por LLM busca en qué turno de la conversación un rol específico (usuario o asistente) menciona un tema.

Lo ideal en este caso es comprobar no solo que el asistente lo confirma, sino que lo hace *después* de que el usuario lo haya pedido. Aquí tienes la regla lista para usar:

```yaml
name: assistant_confirms_drink
description: The assistant confirms the drink order after the user requests it
conversations: 1
active: true
oracle: utterance_index('user', 'ordering a drink') < utterance_index('assistant', 'confirms drink order')
```

**¿Cómo funciona?** 👀
La regla verifica que el número de turno donde el usuario pide la bebida es menor (es decir, ocurre antes) que el turno donde el asistente confirma el pedido de la bebida. 

Si solo quisieras comprobar que el asistente lo menciona en algún momento sin importar el orden, podrías usar simplemente `utterance_index('assistant', 'confirms drink order') > 0`.
