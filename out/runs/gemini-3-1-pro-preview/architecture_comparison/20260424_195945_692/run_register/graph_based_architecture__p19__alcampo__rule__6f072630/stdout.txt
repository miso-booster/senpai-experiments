Since you want a general rule that isn't tied to a specific SENSEI Chat profile (meaning we aren't looking at extracted variables like `conv[0].price` or `conv[0].discount`), we can use one of our awesome built-in helpers to analyze the conversation text directly. 🕵️‍♂️

The perfect tool for this is the `utterance_index(who, what)` helper. It uses a bit of LLM magic under the hood to check if a specific role (like the `'assistant'`) mentioned a certain topic (like `'current promotions'`). If it finds it, it returns the turn number where it happened (which will be greater than 0).

Here is the YAML for your rule. You can copy and paste this right into your project:

```yaml
name: provided_promotions_info
description: Checks if the assistant mentioned current promotions during the conversation.
conversations: 1
oracle: utterance_index('assistant', 'current promotions') > 0
```

### 🧠 How it works:
* **`conversations: 1`**: This tells Sensei-check that we are evaluating each conversation individually (a traditional oracle), rather than comparing multiple conversations together.
* **`oracle: utterance_index(...) > 0`**: This is the heart of the rule! It asks, *"Did the assistant talk about 'current promotions' at any point?"* If the topic is found, the index is greater than 0, and the rule passes! ✅

If you ever decide to create a profile later that extracts a variable like `promotions_offered`, we could easily update this rule to check that variable instead.
