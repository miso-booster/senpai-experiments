Here is a complete SENSEI profile that simulates a user asking the chatbot to add items to their shopping cart. 

I've designed it using the guidelines from the `sensei-chat-guide.md` documentation. It uses variables to randomly select the item and quantity, and it extracts the added items and the total cart count at the end of the conversation.

```yaml
test_name: "shopping_cart_addition"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a customer who wants to add specific items to your online shopping cart.
    You will ask the chatbot to add the items and then confirm the total number of items in your cart.
  context:
    - "You are preparing for a weekly grocery run."
    - "You want to make sure the items are successfully added to your cart."
  goals:
    - "Add {{quantity}} units of {{item}} to my shopping cart"
    - "Ask for the total number of items currently in the cart"
    - quantity:
        function: random()
        type: int
        data:
          min: 1
          max: 5
          step: 1
    - item:
        function: another()
        type: string
        data: [milk, bread, eggs, apples, chicken breast, pasta, cereal]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Could you please rephrase?"
  output:
    - added_items:
        type: list[string]
        description: "The list of items successfully added to the cart"
    - total_items_count:
        type: int
        description: "The total number of items currently in the cart"

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 15
  interaction_style:
    - default
```

### 🛒 How this profile works:
* **Goals & Variables:** The user has two main goals. The first goal uses the `{{quantity}}` and `{{item}}` variables. 
  * `quantity` uses the `random()` function to pick a number between 1 and 5.
  * `item` uses the `another()` function to pick a unique grocery item from the list without repeating it across conversations until the list is exhausted.
* **Chatbot Output:** At the end of the conversation, the extractor will pull two fields:
  * `added_items` (a list of strings) to verify what was actually placed in the cart.
  * `total_items_count` (an integer) to verify the cart's total size.
* **Conversation Controls:** It will run `3` conversations. The `goal_style` is set to `all_answered`, meaning the conversation will naturally stop once the user has successfully added the items and asked for the total count (with a safety limit of 15 messages).
