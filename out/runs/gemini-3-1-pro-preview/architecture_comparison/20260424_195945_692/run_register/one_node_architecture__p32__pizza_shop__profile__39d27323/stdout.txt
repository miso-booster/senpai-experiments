```yaml
test_name: "pizza_and_drink_order"

llm:
  temperature: 0.7
  model: gpt-4o
  format:
    type: text

user:
  language: Spanish
  role: "Eres un cliente que quiere pedir la cena a domicilio en su pizzería de confianza."
  context:
    - "Estás relajado en casa y tienes mucha hambre."
    - "Siempre pides que te confirmen el precio total y el número de pedido antes de despedirte."
  goals:
    - "Quiero pedir una pizza {{pizza_type}}."
    - "Para beber, me gustaría pedir {{drink}}."
    - "Pregunta por el precio total de tu pedido y el ID o número de seguimiento."
    - pizza_type:
        function: pairwise()
        type: string
        data: [margarita, pepperoni, cuatro quesos, barbacoa]
    - drink:
        function: pairwise()
        type: string
        data: [coca-cola, agua, cerveza, fanta]

chatbot:
  is_starter: false
  fallback: "Lo siento, hay mucho ruido en la pizzería y no te he entendido. ¿Puedes repetirlo?"
  output:
    - pizza_type:
        type: string
        description: "El tipo de pizza que ha pedido el usuario."
    - drink:
        type: string
        description: "La bebida que ha pedido el usuario."
    - order_id:
        type: string
        description: "El identificador único o número del pedido."

        type: currency
        description: "El precio final de todo el pedido en dólares (USD)."

conversation:
  number: combinations(1.0, pairwise)
  goal_style:
    all_answered:
      export: true
      limit: 15
  interaction_style:
    - random:

      - single questions
      - long phrases
```

1. **Combinaciones eficientes:** Al usar la función `pairwise()` en las variables `pizza_type` y `drink`, Sensei generará conversaciones combinando inteligentemente las opciones para probar la mayor variedad posible sin hacer un número infinito de tests.
2. **Extracción precisa:** En la sección `chatbot.output`, el campo `final_price` usa el tipo `currency` y le indica explícitamente al extractor que busque el valor en dólares (USD).
3. **Estilos de interacción:** He añadido un toque de caos controlado en `interaction_style`. A veces el usuario hará preguntas simples, otras veces escribirá frases largas o incluso cometerá errores ortográficos (`make spelling mistakes`), ¡como un cliente real!
