The issue with your rule is that it uses a `then:` statement but is missing its partner, the `if:` statement! 

In Sensei-check, when you want to express a metamorphic relation (like "If X changes this way, then Y should change that way"), you need to use **both** `if` and `then`. Right now, your rule knows what to check at the end (that one price is greater than the other), but it doesn't know what condition triggers that check (that one pizza has more toppings than the other).

Here is the fixed version of your rule with the missing `if:` clause added:

```yaml
name: more_toppings_cost_more
description: Adding more toppings to a custom pizza costs more
active: true
conversations: 2
when: conv[0].size == conv[1].size and conv[0].drink == conv[1].drink
if: len(conv[0].toppings) > len(conv[1].toppings)
then: extract_float(conv[0].price) > extract_float(conv[1].price)
```

### A quick tip 👀
Just make sure that the profile you are testing this against actually extracts `size`, `drink`, `toppings`, and `price` in its `chatbot.output` section. If those fields aren't being extracted by the profile, the rule won't have any data to compare!
