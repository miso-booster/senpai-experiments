In the world of **SENSEI RULES** (specifically Sensei-check), an **oracle** is basically the condition or test expression that decides whether a chatbot's response is correct or not. Think of it as the ultimate judge ⚖️!

When you write a rule to test your chatbot, the oracle is the Python-like expression that must evaluate to `True` for the test to pass. 

You will typically use the `oracle:` keyword in your YAML files for two main scenarios:

**1. Traditional Oracles (Single Conversation)**
This checks an absolute truth within a single conversation. For example, if you want to ensure that the chatbot always charges at least $10 for a small pizza, your oracle would look like this:
```yaml
name: small_base_price_floor
conversations: 1
when: size == 'small'
oracle: extract_float(price) >= 10 and currency(price) == 'USD'
```

**2. Global Oracles (All Conversations)**
You can also use an oracle to check a condition across your entire dataset of conversations. For example, making sure every single order gets a unique ID:
```yaml
name: unique_order_ids
conversations: all
oracle: is_unique('order_id')
```

*(Note: When we write **metamorphic rules** that compare two or more conversations against each other, we often use `if:` and `then:` instead of a single `oracle:` keyword. It does the same job of evaluating the test, but reads much more clearly like a cause-and-effect rule! 🍕➡️💰)*
