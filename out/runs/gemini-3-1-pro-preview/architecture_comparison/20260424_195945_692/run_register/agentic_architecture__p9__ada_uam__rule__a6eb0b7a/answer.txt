Para comprobar que el horario de la biblioteca es de 9 a 20, podemos crear una regla de **una sola conversación** (un oráculo tradicional). Como el perfil extrae la información del horario en el campo `library_hours` (dentro de `chatbot.output`), podemos usar la función de ayuda `semantic_content` de SENSEI. Esta función utiliza el LLM para verificar si el contenido extraído coincide semánticamente con la descripción que le pasemos (en este caso, "de 9 a 20").

Aquí tienes la regla en formato YAML:

```yaml
name: horario_biblioteca
description: Comprueba que el horario de la biblioteca indicado por el chatbot es de 9 a 20.
conversations: 1
active: true
oracle: semantic_content(library_hours, 'de 9 a 20')
```

### 📝 Resumen de lo que hace esta regla:
* **`conversations: 1`**: Se evalúa de forma individual para cada conversación generada con este perfil.
* **`oracle`**: Es la condición que debe cumplirse. 
* **`semantic_content(library_hours, 'de 9 a 20')`**: Toma el valor que el chatbot haya guardado en la variable `library_hours` (definida en tu perfil) y comprueba semánticamente si significa que el horario es de 9:00 a 20:00.

¡Puedes guardar este bloque de código en un archivo `.yaml` dentro de tu carpeta de reglas y SENSEI se encargará de validarlo! ¿Te gustaría crear alguna otra regla para los préstamos de laptops o el acceso a la VPN?
