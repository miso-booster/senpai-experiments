### A quick breakdown of what's happening here 👀:
* **`pairwise()` magic:** Because `pizza_size` has 3 options and `pizza_type` has 4 options, a full Cartesian grid would be 12 conversations. Pairwise will intelligently reduce this number while ensuring every size is paired with every type at least once!
* **`combinations(1.0, pairwise)`:** This tells Sensei to run 100% of the conversations generated by that pairwise matrix.
* **`chatbot.output`:** At the end of the grumpy user's conversation, Sensei will extract the `total_price`, `estimated_time`, and `order_summary` so you can validate them later with Sensei Rules.
