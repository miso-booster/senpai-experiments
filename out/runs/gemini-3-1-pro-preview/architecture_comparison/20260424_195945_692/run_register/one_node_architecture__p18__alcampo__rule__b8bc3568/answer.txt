```yaml
name: eco_friendly_toys_provided
description: Comprueba que el chatbot ha devuelto una lista de juguetes eco-friendly durante la conversación.
conversations: 1
active: true
```

**¿Cómo funciona esta regla?** 👀
* **`conversations: 1`**: Indica que la regla se evalúa de forma individual para cada conversación generada por ese perfil.
* **`oracle: eco_friendly_toys is not None`**: Verifica que el extractor haya podido capturar la información y guardarla en la variable `eco_friendly_toys`. Si el chatbot no menciona los juguetes, el valor será nulo (`None`) y la regla fallará, avisándote del problema.
