Como ambos chatbots utilizan la misma tecnología base de 1millionbot, la estructura es prácticamente idéntica. Solo tenemos que actualizar el token de autorización, los identificadores de la conversación y el bot en el `payload_template`, y añadir las cabeceras `Origin` y `Referer` por si el servidor las requiere por seguridad.

El `response_path` se mantiene igual (`response.0.text`), ya que la respuesta JSON sigue teniendo el texto del bot en esa misma ruta.

Aquí tienes el archivo YAML listo para usar:

```yaml
name: "Ayuntamiento Morón de la Frontera"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "65ca19e7dbbb4e26cbeadf28"
    Origin: "https://www.morondelafrontera.es"
    Referer: "https://www.morondelafrontera.es/"
  payload_template:
    conversation: "67ea76f4e213b2dcbc146e2b"
    sender_type: "User"
    sender: "67ea76f40643a3dd27e59411"
    bot: "65ca19e7dbbb4e26cbeadf24"
    language: "es"
    url: "https://www.morondelafrontera.es/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

Guarda este código en un archivo (por ejemplo, `moron-frontera.yml`) dentro de tu carpeta de conectores y ya podrás empezar a probarlo. ¡Si necesitas ayuda con algo más, aquí estoy! 👀✨
