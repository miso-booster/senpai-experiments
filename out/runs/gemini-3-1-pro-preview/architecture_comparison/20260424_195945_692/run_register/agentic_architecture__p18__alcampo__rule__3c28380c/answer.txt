Para comprobar que el chatbot ha devuelto una lista de juguetes y basándonos en el campo `eco_friendly_toys`, podemos crear una regla de **una sola conversación** (un oráculo tradicional) que verifique que ese campo no esté vacío.

Aquí tienes el YAML de la regla:

```yaml
name: eco_friendly_toys_returned
description: Comprueba que el chatbot ha devuelto una lista de juguetes eco-friendly durante la conversación.
conversations: 1
active: true
oracle: eco_friendly_toys is not None and len(eco_friendly_toys) > 0
on-error: "El chatbot no devolvió ninguna lista de juguetes eco-friendly."
```

### 🔗 Conexión con tu Perfil (SENSEI Chat)

Para que esta regla funcione correctamente, el perfil que utilices para generar las conversaciones **debe** exponer este campo en su sección `chatbot.output`. Debería verse algo así:

```yaml
chatbot:
  # ... otras configuraciones ...
  output:
    - eco_friendly_toys:
        type: list[string]
        description: "Lista de juguetes eco-friendly recomendados o devueltos por el chatbot"
```

**¿Qué hace esta regla exactamente?**
1. Toma **1** conversación (`conversations: 1`).
2. Evalúa la condición en `oracle`: verifica que la variable `eco_friendly_toys` (extraída gracias a tu perfil) exista (`is not None`) y que contenga al menos un elemento (`len(...) > 0`).
