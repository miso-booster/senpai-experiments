Since we are checking a condition within a single conversation (rather than comparing multiple conversations), we'll use a **single-conversation rule** (also known as a traditional oracle). 

Here is the YAML code for your rule. You can save this in your `rules` folder (for example, as `small_pizza_price.yaml`):

```yaml
name: small_pizza_price
description: The price of a small pizza must be exactly $10.
conversations: 1
when: size == 'small'
oracle: extract_float(price) == 10
```

### 🍕 How it works:
* **`conversations: 1`**: Tells Sensei-check to evaluate this rule on one conversation at a time.
* **`when: size == 'small'`**: This acts as a filter. The rule will only run if the simulated user ordered a 'small' pizza.
* **`oracle: extract_float(price) == 10`**: This is the actual test! We use the handy `extract_float()` helper function to pull the number out of the price string (so it handles things like "$10.00" or "10 USD" gracefully) and checks if it equals 10.

*(Optional pro-tip: If you also want to make sure the currency is correct, you could update the oracle to something like `oracle: extract_float(price) == 10 and currency(price) == 'USD'`!)*

### ⚠️ Quick Reminder:
For this rule to work perfectly, make sure your **SENSEI Chat profile** exposes both `size` and `price` in its `chatbot.output` section. Sensei-check needs those fields to know what to evaluate!
