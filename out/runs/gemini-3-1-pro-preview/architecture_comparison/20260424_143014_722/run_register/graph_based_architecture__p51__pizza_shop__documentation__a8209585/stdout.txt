Hello there! 😊 

Connectors are super handy tools in Sensei! They act as a bridge that allows you to connect Sensei to any chatbot API **without writing a single line of code**. You simply create a YAML configuration file that describes exactly how Sensei should communicate with your chatbot's API, and Sensei handles the rest! 🚀

Here are the fields you can use to configure a Custom YAML Connector, along with what they do:

*   **`name`** *(Optional)*: A friendly name for your chatbot (e.g., "My Awesome Bot").
*   **`base_url`** *(Required)*: The main web address of your chatbot's API (e.g., `https://api.mychatbot.com`).
*   **`send_message.path`** *(Required)*: The specific API endpoint path that gets added to the base URL (e.g., `/chat/send`).
*   **`send_message.method`** *(Optional)*: The HTTP method to use, such as `POST`, `GET`, `PUT`, or `DELETE`. If you leave this out, it defaults to `POST`.
*   **`send_message.headers`** *(Optional)*: Any custom headers your API needs to work, like `Authorization: Bearer your-api-key` or `Content-Type: application/json`.
*   **`send_message.payload_template`** *(Required)*: The JSON structure of the message you are sending to the bot. This is crucial because it **must** include the `{user_msg}` placeholder. That's how Sensei knows exactly where to inject the simulated user's text!
*   **`response_path`** *(Required)*: A dot-separated path that tells Sensei exactly where to find the bot's reply in the JSON response. For example, if the bot replies with `{"data": {"text": "Hello!"}}`, your response path would be `data.text`.
