To ensure the chatbot matches the user's language, we can use a built-in helper function called `responds_in_same_language()`. This is a fantastic "global rule," meaning it doesn't depend on specific profile outputs and can be applied to any conversation to check for language consistency.

Here is the YAML rule you need:

```yaml
name: chatbot_responds_in_same_language
description: The chatbot responds in the same language as the user
conversations: 1
active: true
oracle: responds_in_same_language() is True
```

**How it works:**
* **`conversations: 1`**: It evaluates each conversation individually.
* **`oracle`**: It uses the LLM-backed `responds_in_same_language()` helper to analyze the dialogue. If the assistant replies in a different language than the user's prompts, the rule will fail and flag the conversation for you.

Just save this as a `.yaml` file in your `rules/` folder, and Sensei-check will take care of the rest. Let me know if you need help creating any other rules! 🚀
