Based on the SENSEI Profiles documentation (`sensei-chat-guide.md`), here are the fields that are explicitly **optional** or not mandatory when creating a profile:

### 1. The entire `llm` block
You do not have to define the `llm` section at all. If you omit it, SENSEI will automatically apply default settings (like a default model and temperature) and assume the format is text.

### 2. Cost limits (`max_cost`)
Cost caps are completely optional but highly recommended for safety:
*   **`conversation.max_cost`**: Caps the maximum spend for the *entire run*.
*   **`conversation.goal_style.max_cost`**: Caps the maximum spend *per conversation*.

### 3. `all_answered` limits and exports
If you use `all_answered` as your `goal_style`, its sub-parameters are optional:
*   **`limit`**: A safety stop for the maximum number of turns. If omitted, it defaults to `30`.
*   **`export`**: A boolean (`true`/`false`). If set to true, it exports a verification dataframe (.csv) showing which outputs were satisfied.

### 4. Personalities in `user.context`
Inside the `user.context` list, referencing a pre-written personality file (e.g., `- personality: personalities/calm-user.yml`) is optional. You can just use freeform text to describe the user's constraints and preferences instead.

### 5. `interaction_style`
While you usually define an interaction style, if you don't want anything specific, SENSEI will default to a natural conversation style. 

***

**A quick tip:** While `chatbot.output` isn't strictly required just to make the simulator chat, it is practically mandatory if you plan to use **SENSEI Rules** later, as rules rely on the fields extracted in the output schema! 😊
