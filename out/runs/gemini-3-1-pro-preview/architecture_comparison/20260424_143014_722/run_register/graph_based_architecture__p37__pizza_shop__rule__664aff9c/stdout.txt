Para comprobar si un evento ocurre después de otro en una misma conversación (como que el usuario pida una bebida y el asistente lo confirme), podemos usar la función **`utterance_index(who, what)`**. Esta función impulsada por LLM busca en qué turno de la conversación un rol específico (usuario o asistente) mencionó cierto tema.

Aquí tienes el código YAML listo para tu regla. He utilizado una estructura `if/then` para que la regla solo se evalúe si el usuario efectivamente pidió una bebida:

```yaml
name: assistant_confirms_drink
description: El asistente confirma que añadió la bebida después de que el usuario la pide.
conversations: 1
if: utterance_index('user', 'ordering a drink') > 0
then: utterance_index('user', 'ordering a drink') < utterance_index('assistant', 'confirms adding the drink')
```

### 🤓 ¿Cómo funciona esta regla?
1. **`conversations: 1`**: Es una regla de oráculo tradicional, ya que solo necesitamos analizar una conversación a la vez.
2. **`if`**: Primero verificamos si el usuario pidió una bebida (`utterance_index > 0`). Si no lo hizo, la regla simplemente se ignora y no falla.
3. **`then`**: Comprobamos que el turno en el que el usuario pide la bebida sea **menor** (es decir, que ocurra antes) que el turno en el que el asistente confirma que la añadió.

Puedes guardar este bloque de código en un archivo llamado `assistant_confirms_drink.yaml` dentro de tu carpeta de reglas.
