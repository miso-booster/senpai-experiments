In a Sensei Profile, you have a lot of flexibility! While things like the `user.role`, `user.goals`, and `chatbot.output` are essential to define what the simulator does, there are several fields that are **completely optional**:

1. **The `llm` block**: You actually don't have to define the `llm` section at all! If you omit it, Sensei will simply apply its default settings (like a default model, temperature, and text format). You only need to add it if you want to override those defaults or use `speech` mode.
2. **Cost limits (`max_cost`)**: Both `conversation.max_cost` (which caps the spend for the *entire run*) and `goal_style.max_cost` (which caps the spend *per conversation*) are optional safety features. 
3. **Personalities (`user.context.personality`)**: You don't have to link to a separate YAML file in the `personalities/` folder. You can just write freeform text directly in the `context` list if you prefer!
4. **Variables in `user.goals`**: If your simulated user has a very simple, static goal, you can just write plain strings (e.g., `"Order a large pizza"`). You only need to define variable dictionaries (with `data`, `type`, and `function`) if you are using `{{variables}}` in your goal strings.
5. **`export` and `limit` in `goal_style`**: If you are using the `all_answered` goal style, the `export: true` (to export a verification dataframe) and `limit: <int>` (a safety stop) fields are optional. If you omit `limit`, it defaults to 30 steps.

If you ever want to start with a minimal profile and build up from there, you can skip these fields entirely! Let me know if you need help putting together a specific profile. 🥋✨
