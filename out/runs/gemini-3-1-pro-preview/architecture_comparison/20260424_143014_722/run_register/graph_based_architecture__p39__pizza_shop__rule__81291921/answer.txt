To check that adding a drink costs exactly $2 extra, we need to compare **two** conversations. We'll use the `when` filter to make sure that everything else about the order (like the pizza size, toppings, and quantity) stays exactly the same. That way, we know the price difference is *only* because of the drink! 🥤

Here is the YAML rule you can use. You can save this as a `.yaml` file in your `rules/` folder:

```yaml
name: drink_costs_two_dollars_extra
description: Adding a drink to an order costs exactly 2 dollars extra, assuming all other factors are equal.
conversations: 2
when: conv[0].size == conv[1].size and conv[0].toppings == conv[1].toppings and conv[0].number == conv[1].number
if: not conv[0].drink and conv[1].drink
then: extract_float(conv[1].price) == extract_float(conv[0].price) + 2
```

### 👀 How it works:
* **`conversations: 2`**: This tells Sensei-check we are doing metamorphic testing by comparing a pair of conversations.
* **`when`**: This ensures we are comparing apples to apples 🍎 (or in this case, identical pizzas!). We lock in the `size`, `toppings`, and `number` so they match in both conversations.
* **`if`**: This is our trigger! It looks for a pair where the first conversation (`conv[0]`) does *not* have a drink, and the second conversation (`conv[1]`) *does* have a drink. *(Note: `not conv[0].drink` works great if your SENSEI Chat profile outputs `None`, `False`, or an empty string for no drink).*
* **`then`**: This is the actual check. We use the handy `extract_float()` helper to grab the numeric price from both conversations and assert that the second one is exactly $2 more than the first one. 💸

Make sure your SENSEI Chat profile's `chatbot.output` actually exposes the fields `size`, `toppings`, `number`, `drink`, and `price` for this to work perfectly!
