Here is the profile for your rude and impatient pizza shop customer! 🍕😠

I've designed it following the SENSEI Chat documentation (`sensei-chat-guide.md`). The profile includes a persona that demands speed and lacks manners, 4 distinct goals that use 4 variables, and sets up 2 of those variables with `pairwise()` functions so the conversation count is driven by the pairwise combination matrix.

```yaml
test_name: "rude_pizza_customer"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are an extremely rude and impatient customer ordering from a pizza shop.
    You want things done fast, you hate small talk, and you demand quick answers.
  context:
    - "You are very hungry and in a rush."
    - "You speak abruptly, using short and demanding sentences."
  goals:
    - "Demand a {{size}} pizza immediately."
    - "Tell them it must have a {{crust}} crust."
    - "Order {{toppings}} on it and tell them not to skimp."
    - "Add a {{drink}} and demand to know the final price."
    - size:
        function: pairwise()
        type: string
        data: [small, medium, large, family]
    - crust:
        function: pairwise()
        type: string
        data: [thin, thick, stuffed, gluten-free]
    - toppings:
        function: random()
        type: string
        data: [pepperoni, mushrooms, extra cheese, onions]
    - drink:
        function: random()
        type: string
        data: [cola, water, beer, juice]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't catch that. Could you repeat?"
  output:
    - size:
        type: string
        description: "The size of the pizza ordered"
    - crust:
        type: string
        description: "The type of crust ordered"
    - toppings:
        type: string
        description: "The toppings added to the pizza"
    - drink:
        type: string
        description: "The drink ordered"
    - total_price:
        type: float
        description: "The total price of the order"

conversation:
  number: combinations(1, pairwise)
  goal_style:
    all_answered:
      limit: 10
  interaction_style:
    - default
```

### How this profile works:

1. **Persona & Tone:** The `user.role` and `user.context` instruct the LLM to act rude, impatient, and demanding.
2. **Goals & Variables:** There are exactly 4 goals, each tied to one of the 4 variables (`size`, `crust`, `toppings`, `drink`).
3. **Pairwise Matrix:** The `size` and `crust` variables use the `pairwise()` function. Because there are 4 sizes and 4 crusts, a full Cartesian combination would be 16 conversations. However, the pairwise algorithm will efficiently generate a matrix that covers every pair of size and crust at least once.
4. **Conversation Number:** By setting `conversation.number: combinations(1, pairwise)`, Sensei will automatically calculate the required number of conversations to satisfy 100% (`1`) of the pairwise matrix generated by those two variables. The other two variables (`toppings` and `drink`) will just be picked at `random()` for each of those conversations.
