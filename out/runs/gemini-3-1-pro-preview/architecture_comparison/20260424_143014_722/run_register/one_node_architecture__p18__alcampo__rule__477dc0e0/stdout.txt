Para comprobar que el chatbot efectivamente ha devuelto esa información durante la conversación, podemos crear una regla de una sola conversación (un oráculo tradicional) que verifique que ese campo se haya extraído correctamente y no esté vacío.

Aquí tienes la regla lista para usar:

```yaml
name: eco_friendly_toys_returned
description: Verifica que el chatbot haya devuelto una lista de juguetes ecológicos durante la conversación.
conversations: 1
active: true
oracle: eco_friendly_toys is not None and len(eco_friendly_toys) > 0
on-error: "El chatbot no devolvió la lista de juguetes ecológicos esperada."
```

**¿Cómo funciona esta regla?** 👀
* **`conversations: 1`**: Le dice a Sensei-check que evalúe las conversaciones de una en una.
* **`oracle`**: Es la condición que debe cumplirse. Comprueba que la variable `eco_friendly_toys` (que viene directamente del `chatbot.output` de tu perfil) no sea nula y tenga algún contenido (`len > 0`).
* **`on-error`**: Es un mensaje de ayuda que aparecerá si la regla falla, para que sepas exactamente qué salió mal.

Puedes guardar este código en un archivo dentro de tu carpeta `rules/`, por ejemplo, `rules/eco_friendly_toys.yaml`.
