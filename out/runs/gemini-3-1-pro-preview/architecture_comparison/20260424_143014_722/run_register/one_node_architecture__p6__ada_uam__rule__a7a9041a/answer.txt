Since you want to make sure the chatbot successfully provides those three specific pieces of contact information in a single conversation, we can write a **single-conversation oracle**. This rule will check that the variables `contact_email`, `contact_phone`, and `physical_address` (which come directly from your profile's `chatbot.output`) were successfully extracted and are not empty (`None`).

Here is the rule you can add to your project:

```yaml
name: cau_contact_info_complete
description: Verifies that the chatbot provided the CAU's phone number, email, and physical address.
conversations: 1
active: true
oracle: contact_email is not None and contact_phone is not None and physical_address is not None
yields: f"Missing CAU contact info! Email: {contact_email}, Phone: {contact_phone}, Address: {physical_address}"
```

### How it works:
* **`conversations: 1`**: This tells Sensei-check to evaluate the rule on each conversation individually.
* **`oracle`**: This is the condition that must be true. It checks that all three fields were successfully filled by the extractor.
* **`yields`**: If the rule fails (meaning the bot missed one or more pieces of info), this helpful error message will show you exactly which fields were captured and which ones were left as `None`.

Just save this as a `.yaml` file inside your `rules/` folder, and you'll be good to go! Let me know if you need help with anything else. 🚀
