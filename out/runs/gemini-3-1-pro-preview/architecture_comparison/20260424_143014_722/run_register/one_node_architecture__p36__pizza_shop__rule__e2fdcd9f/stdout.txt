The reason your rule isn't working is that it's missing the **`if`** clause! 

In Sensei-check, when you write a metamorphic rule using `then`, it must always be paired with an `if` statement. The `if` acts as the precondition (the change in the input), and the `then` is the expected outcome (the change in the output). 

Since your description says *"Adding more toppings to a custom pizza costs more"*, we need to add an `if` condition that checks if one conversation has more toppings than the other. 

Here is the fixed and fully working version of your rule:

```yaml
name: more_toppings_cost_more
description: Adding more toppings to a custom pizza costs more
active: True
conversations: 2
when: conv[0].size == conv[1].size and conv[0].drink == conv[1].drink
if: len(conv[0].toppings) > len(conv[1].toppings)
then: extract_float(conv[0].price) > extract_float(conv[1].price)
```
