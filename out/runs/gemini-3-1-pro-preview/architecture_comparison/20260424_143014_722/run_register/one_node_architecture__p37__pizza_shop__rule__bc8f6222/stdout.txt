Para comprobar que el asistente confirma la bebida que el usuario ha pedido, podemos usar la función `utterance_index`. Esta función busca en qué turno de la conversación se habla de un tema específico. 

Podemos crear una regla que verifique que el turno donde el asistente "confirma el pedido de la bebida" ocurre *después* del turno donde el usuario "pide una bebida".

Aquí tienes la regla lista para usar:

```yaml
name: assistant_confirms_drink
description: El asistente confirma el pedido de la bebida después de que el usuario la solicita.
conversations: 1
active: true
oracle: utterance_index('user', 'ordering a drink') < utterance_index('assistant', 'confirms the drink order')
```

**¿Cómo funciona?**
* `utterance_index('user', 'ordering a drink')` encuentra el número de turno en el que el usuario pide la bebida.
* `utterance_index('assistant', 'confirms the drink order')` encuentra el turno en el que el asistente lo confirma.
* Al usar el operador `<`, nos aseguramos de que la confirmación del asistente suceda estrictamente después de la petición del usuario.
