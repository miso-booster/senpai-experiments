To check that adding a drink costs exactly $2 extra, we need to compare two conversations (`conversations: 2`). We will look for a pair where the pizza details are identical, but one order has no drink and the other does. Then, we check if the price difference is exactly 2.

Here is the rule ready for your project:

```yaml
name: drink_adds_two_dollars
description: Adding a drink to an otherwise identical order increases the total price by exactly 2 dollars.
conversations: 2
when: conv[0].size == conv[1].size and conv[0].pizza_type == conv[1].pizza_type
if: conv[0].drink is None and conv[1].drink is not None
then: extract_float(conv[1].price) == extract_float(conv[0].price) + 2
```

### 👀 How it works:
* **`when`**: This acts as our filter. It ensures we are comparing "apples to apples" (e.g., both orders have the same `size` and `pizza_type`). *Note: Feel free to adjust these field names if your profile uses different ones for the pizza details!*
* **`if`**: This sets up the scenario. We look for a pair where the first conversation (`conv[0]`) didn't include a drink, but the second one (`conv[1]`) did.
* **`then`**: This is the actual check! It extracts the numeric value from the `price` output and verifies that the second conversation costs exactly $2 more than the first one.
