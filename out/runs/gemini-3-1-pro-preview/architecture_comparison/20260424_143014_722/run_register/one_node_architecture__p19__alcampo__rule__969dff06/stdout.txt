Since you want a rule that isn't tied to a specific profile's output fields, we can use one of Sensei-check's built-in helpers. The `utterance_index` function is perfect for this! It scans the conversation turns and checks if a specific role (like the 'assistant') talked about a certain topic. 

Here is a profile-agnostic rule you can use:

```yaml
name: chatbot_provides_promotions
description: Checks if the assistant mentioned current promotions or offers during the conversation.
conversations: 1
active: true
oracle: utterance_index('assistant', 'current promotions, discounts, or special offers') > 0
```

This rule will pass as long as the chatbot mentions something about promotions or discounts at some point in the conversation. Let me know if you need any tweaks or if you'd like to see how to do this using extracted variables instead! 😊
