Since you want to verify that a specific field (`order_id`) was successfully extracted during a single conversation, we can write a simple single-conversation oracle. We just need to check if `'order_id'` is present in the `data_output` dictionary, which is where Sensei stores all the extracted fields from the profile's `chatbot.output`.

Here is the rule you need:

```yaml
name: order_id_provided
description: The chatbot must provide an order ID at the end of the conversation
conversations: 1
active: true
oracle: "'order_id' in data_output"
```

### How it works:
* **`conversations: 1`**: This tells Sensei-check that it only needs to look at one conversation at a time (it's a traditional oracle, not a metamorphic one).
* **`oracle: "'order_id' in data_output"`**: This is the condition that must be true. If the chatbot successfully provided the order ID and the extractor caught it, it will be inside `data_output`, and the rule will pass! ✨
