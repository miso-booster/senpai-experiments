Looking at your goal—checking if the tune-up price is exactly $50—you are actually looking to write a **single-conversation oracle** rather than a metamorphic rule. 

Your current draft has a few little hiccups:
1. **`conversations: 2`** is used for metamorphic testing (comparing two different conversations). Since we just want to check a static value in one conversation, it should be `1`.
2. **`when: conv[0].tune_up_price == 50`** acts as a *filter*. If you put your condition here, Sensei-check will only evaluate conversations where the price is already 50, which defeats the purpose of the test! 😅
3. **`then: "The tune-up price is $50."`** needs to be a Python expression that evaluates to `True` or `False`, rather than a text string.
4. When using `conversations: 1`, you don't need the `conv[0].` prefix. You can just use the variable name directly!

Here is the corrected and much more robust version of your rule:

```yaml
name: check_tune_up_price
description: Checks if the tune-up price is equal to $50.
conversations: 1
oracle: extract_float(tune_up_price) == 50 and currency(tune_up_price) == 'USD'
```

### 🛠️ What I changed and why:
* **`conversations: 1`**: Changed from 2 to 1, because we are just validating a single output, not comparing multiple conversations.
* **Removed `when` and `if/then`**: For simple, absolute checks like this, using a single `oracle` is the cleanest and most standard approach in Sensei-check.
* **Added `extract_float()` and `currency()` helpers**: Chatbots can be a bit unpredictable with how they format text (e.g., "$50", "50.00 USD", "fifty bucks"). Using `extract_float(tune_up_price) == 50` safely pulls the number out, and `currency(tune_up_price) == 'USD'` ensures the currency is correct! 

**One quick reminder!** 👀 
Make sure that `tune_up_price` is exactly how the field is named in your SENSEI Chat profile's `chatbot.output`. If your profile calls it something else (like `price` or `total_cost`), you'll need to update the variable name in the rule to match.
