Since we are checking a specific condition within individual conversations, this will be a **single-conversation rule** (also known as a traditional oracle). 

Here is the YAML code for your rule. You can save this as a `.yaml` file in your project's `rules` folder:

```yaml
name: small_pizza_price
description: The price of a small pizza must be exactly $10.
conversations: 1
when: size == 'small'
oracle: extract_float(price) == 10 and currency(price) == 'USD'
```

### 🧐 Let's break down what's happening here:
* **`conversations: 1`**: This tells Sensei-check that we only need to look at one conversation at a time, rather than comparing multiple conversations together.
* **`when: size == 'small'`**: This is our filter! It ensures the rule only runs on conversations where the user ordered a small pizza.
* **`oracle: extract_float(price) == 10 and currency(price) == 'USD'`**: This is where the magic happens ✨. We use the built-in `extract_float()` helper to pull the number out of the price string and check if it equals 10. We also use the `currency()` helper to make sure the chatbot is charging in US Dollars!

**💡 A quick Senpai tip:** 
Make sure that `size` and `price` match the exact field names defined in your SENSEI Chat profile's `chatbot.output`. If your profile uses something like `total_price` instead of `price`, just update the rule to match!
