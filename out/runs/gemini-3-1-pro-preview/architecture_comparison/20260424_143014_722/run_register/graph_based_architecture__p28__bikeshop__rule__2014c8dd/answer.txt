Hey there! 😊 That is a fantastic idea. Making sure your chatbot speaks the user's language is key to a smooth and welcoming user experience! 

In **Sensei-check**, creating a rule for this is super easy because we have a built-in helper function made exactly for this scenario called `responds_in_same_language()`. 

Since this rule applies to the general flow of the chat and doesn't rely on specific extracted data (like a price or an order ID), it is considered a **global rule**. This means you don't even need to worry about linking it to specific `chatbot.output` fields in your SENSEI Chat profiles!

Here is the ready-to-use YAML code for your rule:

```yaml
name: user_language_consistency
description: The assistant should always reply in the same language as the user.
conversations: 1
oracle: responds_in_same_language() is True
```

### How it works:
* **`conversations: 1`**: This tells Sensei-check to evaluate this rule on a single conversation at a time.
* **`oracle: responds_in_same_language() is True`**: This uses our LLM-backed helper to automatically analyze the dialogue and verify that the assistant's replies match the language the simulated user is speaking. 

Just save this as a `.yaml` file in your rules folder, and Sensei-check will handle the rest! ✨
