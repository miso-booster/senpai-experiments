```yaml
name: spanish_language_consistency
description: The chatbot must respond in Spanish, matching the user's language.
```

### 2. Topic Scope Guardrail (General)
Sometimes chatbots hallucinate or get distracted by user prompts. This rule ensures the chatbot stays strictly within the domain of university admissions and doesn't talk about unrelated topics.

```yaml
name: admission_topic_scope
description: The chatbot should not drift from university admissions, degrees, and welcome day.
conversations: 1
active: true
oracle: only_talks_about('university admissions, degrees, courses, and welcome day events')
```

### 3. Application Fee Sanity Check (Profile-Bound)
In your profile's `chatbot.output`, you have a field called `application_fee` of type `money`. This rule checks that if the bot mentions a fee, it is a valid positive number and is quoted in Euros (EUR), which makes sense for UAM.

```yaml
name: application_fee_sanity
description: The application fee should be a valid positive amount in Euros (EUR).
conversations: 1
active: true
when: application_fee is not None
oracle: extract_float(application_fee) >= 0 and currency(application_fee) == 'EUR'
```

### 4. Welcome Day Consistency (Metamorphic Rule)
Metamorphic rules compare multiple conversations. Since the Welcome Day is a specific university event, its date and location shouldn't change depending on whether the user asks about "Biología" or "Arquitectura". This rule compares **two** conversations and ensures the extracted `welcome_day_date` and `event_location` are identical in both.

```yaml
name: consistent_welcome_day
description: The Welcome Day date and location should be consistent across all inquiries.
conversations: 2
active: true
if: conv[0].welcome_day_date is not None and conv[1].welcome_day_date is not None
then: conv[0].welcome_day_date == conv[1].welcome_day_date and conv[0].event_location == conv[1].event_location
```
