¡Hola! Qué buena iniciativa lo de los juguetes eco-friendly 🌍💚. ¡Claro que sí! Como tu Senpai en el Chatbot Dojo, estoy encantado de ayudarte a crear esta regla.

Para este caso, necesitamos una **regla de una sola conversación** (lo que en SENSEI llamamos un oráculo tradicional). Esta regla se encargará de mirar el resultado de la conversación y comprobar que la lista de juguetes se ha llenado correctamente.

Aquí tienes el código YAML listo para tu regla:

```yaml
name: eco_friendly_toys_returned
description: Verifica que el chatbot haya devuelto una lista de juguetes eco-friendly durante la conversación.
conversations: 1
oracle: eco_friendly_toys is not None and len(eco_friendly_toys) > 0
```

### 🧠 ¿Cómo se conecta esto con tu Perfil de SENSEI Chat?

Como bien has intuido, para que esta regla funcione, **es súper importante** que el perfil de tu chatbot exponga exactamente ese mismo campo en su sección de `chatbot.output`. 

Para que todo encaje a la perfección, asegúrate de que el perfil (SENSEI Profile) que estás evaluando tenga algo como esto:

```yaml
test_name: "eco_toys_profile"

user:
  language: Spanish
  role: "Un usuario interesado en comprar juguetes ecológicos."
  goals:
    - "Preguntar por recomendaciones de juguetes ecológicos."

chatbot:
  fallback: "Lo siento, no entiendo. ¿Podrías reformularlo?"
  output:
    - eco_friendly_toys:
        type: list[string]
        description: Lista de juguetes respetuosos con el medio ambiente recomendados al usuario.

conversation:
  number: 1
  goal_style:
    steps: 5
  interaction_style:
    - default
```

De esta manera, cuando SENSEI Chat genere la conversación, extraerá los juguetes y los guardará en la variable `eco_friendly_toys`. Luego, SENSEI Check leerá esa variable y nuestra regla comprobará que la lista existe (`is not None`) y que tiene al menos un juguete (`len > 0`). ¡Magia pura! ✨
