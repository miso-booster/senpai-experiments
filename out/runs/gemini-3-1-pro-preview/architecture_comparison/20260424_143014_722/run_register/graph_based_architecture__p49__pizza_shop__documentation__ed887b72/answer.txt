The `pairwise()` function is a super handy tool used in the `user.goals` section of your **SENSEI Profiles**. It helps you test different combinations of variables without running into a massive, time-consuming number of conversations!

Here is how it works in a nutshell:

When you have multiple variables in your chatbot tests (for example, pizza `size`, `crust_type`, and `drink`), testing *every single possible combination* can result in hundreds or thousands of conversations. This is called a "Cartesian explosion." 💥

Instead of testing every single combination, the `pairwise()` function uses a smart mathematical approach: it ensures that **every possible pair of values between your variables is tested together at least once**. This drastically reduces the total number of conversations you need to run, while still catching the vast majority of bugs (since most bugs are caused by the interaction of just two specific factors).

### How to use it:
To use it, you simply set `function: pairwise()` on the variables you want to combine. 

**Important Rule:** You must assign `pairwise()` to **at least two variables** in your goals for it to work! 

Here is a quick example of how it looks inside a profile:

```yaml
user:
  goals:
    - "I want a {{size}} pizza with {{toppings}}."
    - size:
        function: pairwise()
        type: string
        data: [small, medium, large]
    - toppings:
        function: pairwise()
        type: string
        data: [cheese, pepperoni, mushrooms]
```

### Pro-Tip 💡
If you want Sensei to automatically calculate the right number of conversations to cover all these pairs, you can set your `conversation.number` at the bottom of your profile like this:

```yaml
conversation:
  number: combinations
  # Or, if you only want to run a fraction of them (e.g., 50%):
  # number: combinations(0.5, pairwise)
```
