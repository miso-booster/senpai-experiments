Since checking if the chatbot matches the user's language is a universal concept, this will be a **general rule**. It doesn't depend on any specific outputs from a SENSEI Chat profile, so it will work across all your conversations.

SENSEI provides a built-in helper function called `responds_in_same_language()` specifically for this purpose. 

Here is the YAML rule you can use:

```yaml
name: chatbot_responds_in_same_language
description: The chatbot responds in the same language as the user
conversations: 1
active: true
oracle: responds_in_same_language()
on-error: f"The chatbot did not respond in the same language as the user."
```

### How it works:
* **`conversations: 1`**: This is a single-conversation oracle rule, meaning it evaluates each conversation individually rather than comparing multiple conversations.
* **`oracle: responds_in_same_language()`**: This uses the built-in LLM-backed helper to automatically detect the language of the user's messages and verify that the assistant's replies match it.
* **`on-error`**: If the rule fails (i.e., the chatbot switches to a different language), SENSEI will output this helpful error message.

You can save this as a `.yml` file in your `rules` directory, and it will automatically apply to your tests! Let me know if you need help creating any other rules.
