Since we only need to look at one chat at a time to see if the `order_id` was successfully extracted, this will be a **single-conversation rule** (also known as a traditional oracle). 

Based on the Sensei-check documentation, all the fields extracted from your SENSEI Chat profile's `chatbot.output` are stored in a dictionary called `data_output`. We can simply check if `'order_id'` is inside it!

Here is the YAML code you can use:

```yaml
name: order_id_provided
description: The chatbot must successfully provide an order ID.
conversations: 1
oracle: "'order_id' in data_output"
```

### 🧠 A quick breakdown of how it works:
* **`conversations: 1`**: Tells Sensei-check to evaluate this rule on each conversation individually, rather than comparing multiple conversations together.
* **`oracle`**: This is the condition that must be `True` for the test to pass. We are just asking Python, *"Hey, is 'order_id' inside the data_output dictionary?"*

**💡 Senpai Tip:** 
If you ever want to check if *multiple* required slots were missed, you can also use the built-in `missing_slots()` helper! For example, `oracle: "'order_id' not in missing_slots()"` would also work perfectly. 

You can save this as a new `.yaml` file (for example, `order_id_provided.yaml`) in your project's rules folder (`/home/ivan/miso/automatizacion/graph/sensei_projects/pizza_shop/rules/`).
