Connectors are super handy tools in Sensei. Think of them as a bridge or a universal translator between Sensei and the specific chatbot you want to test. 🌉🤖 

Their main purpose is to allow you to connect to **any chatbot API without writing a single line of code**. You simply create a YAML configuration file that tells Sensei exactly how to send messages to your bot and where to find the bot's replies. 

Here are the fields you can use to build a Custom YAML Connector:

*   **`name`** *(Optional)*: A friendly name for your chatbot (e.g., "My Awesome Bot").
*   **`base_url`** *(Required)*: The main web address of your chatbot's API (e.g., `https://api.mychatbot.com`).
*   **`send_message.path`** *(Required)*: The specific endpoint path that gets added to the base URL (e.g., `/chat/send`).
*   **`send_message.method`** *(Optional)*: The HTTP method used to send the message, like `POST`, `GET`, `PUT`, or `DELETE`. If you leave it out, it defaults to `POST`.
*   **`send_message.headers`** *(Optional)*: Any custom headers you might need to get past the bouncer, like an `Authorization` token or `Content-Type`.
*   **`send_message.payload_template`** *(Required)*: The JSON structure of the message you're sending. This is where you put the magic **`{user_msg}`** placeholder so Sensei knows exactly where to inject the simulated user's text! ✨
*   **`response_path`** *(Required)*: Think of this as a little treasure map! 🗺️ It's a dot-separated path that tells Sensei exactly where to extract the bot's reply from the JSON response. For example, if the bot replies with `{"data": {"text": "Hello!"}}`, your path would be `data.text`.
