Here is a metamorphic rule that checks if adding a drink increases the total price by exactly $2! 🍕🥤

This rule compares two conversations where the pizza size and toppings are identical. It assumes that your `drink` output is an integer representing the quantity of drinks. 

```yaml
name: drink_adds_two_dollars
description: Adding exactly one drink increases the total price by $2 (assuming same pizza size and toppings).
conversations: 2
when: conv[0].size == conv[1].size and conv[0].toppings == conv[1].toppings
if: conv[1].drink == conv[0].drink + 1
then: extract_float(conv[1].price) == extract_float(conv[0].price) + 2
```

**A quick tip:** 👀 
If your `drink` output is actually a **list** of strings (e.g., `["Coke", "Sprite"]`) rather than a number, you can easily adapt the `if` condition to check the length of the list instead, like this: `len(conv[1].drink) == len(conv[0].drink) + 1`.
