```yaml
name: drink_costs_2_dollars_extra
description: Adding a drink to an order increases the total price by exactly 2 dollars.
conversations: 2
when: conv[0].size == conv[1].size and conv[0].pizza_type == conv[1].pizza_type
if: conv[0].drink is None and conv[1].drink is not None
then: extract_float(conv[1].price) == extract_float(conv[0].price) + 2
```

### How this works:
* **`conversations: 2`**: This tells SENSEI-check to compare pairs of conversations (metamorphic testing).
* **`when`**: This acts as a filter to ensure we are comparing apples to apples. It holds the base order equal (e.g., same `size` and `pizza_type`). *Note: You should adjust these field names to match whatever base items your actual profile uses!*
* **`if`**: This is the trigger condition. It looks for a pair where the first conversation has no drink (`None`) and the second conversation does have a drink.
* **`then`**: This asserts the relationship. It uses the built-in `extract_float()` helper (as documented in `sensei-check-doc.md`) to pull the numeric value from the `price` field and checks that the second conversation is exactly $2 more than the first.
