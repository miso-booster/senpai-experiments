### 1. The missing `if` clause
In Sensei-check, when you use a `then` statement to check a metamorphic relation between two conversations, you **must** include an `if` statement. The `if` clause acts as the precondition (what changes between the conversations), while the `then` clause is the expected outcome. 

Since your rule is checking if adding *more toppings* increases the price, we need to add an `if` condition that compares the length of the toppings!

Here is the corrected rule:

```yaml
name: more_toppings_cost_more
description: Adding more toppings to a custom pizza costs more
active: true
conversations: 2
when: conv[0].size == conv[1].size and conv[0].drink == conv[1].drink
if: len(conv[0].toppings) > len(conv[1].toppings)
then: extract_float(conv[0].price) > extract_float(conv[1].price)
```
