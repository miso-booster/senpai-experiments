Hello there! 😊 I'd be happy to help you create a rule for that. 

Sensei-check has a handy built-in helper function called `responds_in_same_language()` that makes this super easy. It automatically checks if the assistant's replies match the language used by the simulated user. Because it's a global rule, it doesn't depend on any specific fields in your profile's `chatbot.output`.

Here is the YAML rule you can use:

```yaml
name: chatbot_responds_in_same_language
description: The chatbot responds in the same language as the user
conversations: 1
active: true
oracle: responds_in_same_language()
yields: f"The chatbot does not respond in the same language"
```

You can just save this as a `.yaml` file in your `rules/` folder. Let me know if you need help with anything else! 👀
