2. **Missing `type` in outputs**: Every item in `chatbot.output` needs a `type`. Your `seat_price` and `care_bike` were missing theirs!
3. **`str` vs `string`**: The correct default type for text in Sensei is `string`, not `str`. 
4. **`money` type**: `money` isn't a default type. Unless you have a custom `money.yml` file in your `types/` folder, it's safer to use the built-in `currency` type.
5. **Missing `goal_style`**: The `conversation` section needs a `goal_style` (like `steps: 5` or `all_answered`) so Sensei knows when to finish the chat.
