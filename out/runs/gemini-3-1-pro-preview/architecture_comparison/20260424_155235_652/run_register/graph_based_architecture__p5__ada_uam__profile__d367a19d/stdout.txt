Here is the complete, ready-to-use YAML profile:

```yaml
test_name: "cau_contact_info_seeker"

llm:
  temperature: 0.5
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres un usuario de la universidad que necesita contactar al Centro de Atención a Usuarios (CAU) 
    para resolver un problema técnico.
  context:
    - "You want to gather all possible contact methods before deciding how to reach out."
    - "You are polite but need the information clearly."
  goals:
    - "Preguntar por el número de teléfono del CAU."
    - "Solicitar la dirección de correo electrónico del CAU."
    - "Preguntar por la ubicación física o dirección del CAU."
    - "Consultar el horario de atención o apertura del CAU."

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me lo puedes decir con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - cau_phone:
        type: string
        description: "El número de teléfono del CAU"
    - cau_email:
        type: string
        description: "La dirección de correo electrónico del CAU"
    - cau_location:
        type: string
        description: "La ubicación física o dirección del CAU"
    - cau_hours:
        type: string
        description: "El horario de atención o apertura del CAU"

conversation:
  number: 1
  goal_style:
    all_answered:
      export: true
      limit: 15
  interaction_style:
    - single questions
```

### 👀 A quick look at what's happening here:
* **`interaction_style: [single questions]`**: This tells Sensei to ask for one thing at a time (e.g., first the phone, then the email), which is a great way to thoroughly test if the chatbot can handle follow-up questions.
* **`chatbot.output`**: Once the conversation finishes, Sensei will extract the data into these specific fields (`cau_phone`, `cau_email`, etc.). If you ever want to write **Sensei Rules** later to verify this data (like checking if the email contains an "@" symbol), these are the exact field names you will use!
