Here is the SENSEI profile for the rude, impatient pizza shop customer. 

I have configured the profile with exactly 4 goals and 4 variables. Two of the variables (`size` and `crust`) use the `pairwise()` function. By setting `conversation.number: combinations(1, pairwise)`, Sensei will automatically calculate the minimum number of conversations needed to test every combination of `size` and `crust` at least once, rather than running a full Cartesian explosion.

```yaml
test_name: "rude_fast_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a very rude and impatient customer ordering a pizza. 
    You want things done as fast as possible, you have no time for pleasantries, 
    and you get easily annoyed if the chatbot asks too many questions or is slow.
  context:
    - "You are in a huge hurry."
    - "You are blunt and demanding."
  goals:
    - "Order a {{size}} pizza."
    - "Make sure the crust is {{crust}}, don't mess it up."
    - "Put {{toppings}} on it."
    - "Deliver it immediately to {{address}}."
    - size:
        function: pairwise()
        type: string
        data: [small, medium, large, extra large]
    - crust:
        function: pairwise()
        type: string
        data: [thin, thick, stuffed, gluten-free]
    - toppings:
        function: random()
        type: string
        data: [pepperoni, mushrooms, extra cheese, onions, sausage]
    - address:
        function: random()
        type: string
        data: [123 Main St, 456 Elm St, 789 Oak Ave]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't catch that. Could you repeat?"
  output:
    - pizza_size:
        type: string
        description: "The size of the pizza ordered"
    - pizza_crust:
        type: string
        description: "The type of crust"
    - pizza_toppings:
        type: string
        description: "The toppings added"
    - delivery_address:
        type: string
        description: "The delivery address"

conversation:
  number: combinations(1, pairwise)
  goal_style:
    all_answered:
      export: true
      limit: 15
  interaction_style:
    - default
```

### How this profile works:
1. **Persona**: The `user.role` and `user.context` instruct the LLM to act rude, blunt, and impatient.
2. **Goals & Variables**: There are 4 goals mapped to 4 variables (`size`, `crust`, `toppings`, `address`).
3. **Pairwise Matrix**: `size` and `crust` both use the `pairwise()` function. Because we set `conversation.number: combinations(1, pairwise)`, Sensei will generate a pairwise matrix of these two variables. This ensures every size is tested with every crust at least once across the generated conversations, efficiently covering the test space.
4. **Random Variables**: `toppings` and `address` use `random()`, meaning they will just pick a random option from their lists for each conversation generated by the pairwise matrix.
5. **Output**: The `chatbot.output` defines the schema (size, crust, toppings, address) that will be extracted at the end of each conversation, which you can later validate using Sensei-check rules.
