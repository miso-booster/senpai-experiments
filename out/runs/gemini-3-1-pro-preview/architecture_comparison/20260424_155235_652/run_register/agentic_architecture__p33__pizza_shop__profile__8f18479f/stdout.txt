Based on the SENSEI Profiles documentation (`sensei-chat-guide.md`), the `chatbot` field is crucial because it defines the contract between the simulated user and the chatbot. It tells SENSEI who starts the conversation, how to handle fallbacks, and most importantly, what data to extract at the end of the conversation (which is very useful if you want to write validation rules later!).

Here is what you typically add to the `chatbot` section:
1. **`is_starter`**: `true` or `false`. Determines if the chatbot sends the first message.
2. **`fallback`**: The exact fallback message your real chatbot uses (e.g., "I'm sorry, I didn't understand"). This prevents SENSEI from getting stuck in an endless loop if the bot fails.
3. **`output`**: A list of fields you want SENSEI to extract from the conversation once it finishes. Since your user is asking about pizza types, prices, drinks, hours, and delivery, we can define a schema to capture all those answers!
