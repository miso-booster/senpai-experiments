To check that adding a drink costs exactly $2 extra, we need to compare **two conversations** where everything about the pizza (like the size and toppings) is exactly the same, but one order includes a drink and the other doesn't. 

Here is the YAML code for your new rule. You can save this as a new file in your project's rules folder (for example, `drink_costs_two_dollars_extra.yaml`):

```yaml
name: drink_costs_two_dollars_extra
description: Adding a drink costs exactly 2 dollars extra when the pizza size and toppings are identical.
conversations: 2
when: conv[0].size == conv[1].size and conv[0].toppings == conv[1].toppings
if: conv[0].drink and not conv[1].drink
then: extract_float(conv[0].price) == extract_float(conv[1].price) + 2.0
```

### 🧠 How this works under the hood:
* **`conversations: 2`**: Tells Sensei-check that this is a metamorphic rule comparing a pair of conversations.
* **`when`**: This is our filter! It ensures we are only comparing apples to apples 🍎 (or in this case, identical pizzas!). We make sure the `size` and `toppings` are exactly the same in both conversations.
* **`if`**: This is our trigger condition. It looks for a pair where the first conversation (`conv[0]`) has a `drink`, and the second conversation (`conv[1]`) does *not* have a drink.
* **`then`**: This is the magic math! ✨ We use the handy `extract_float()` helper to pull the numeric value out of the `price` string, and assert that the first order's price is exactly $2.0 greater than the second order's price.
