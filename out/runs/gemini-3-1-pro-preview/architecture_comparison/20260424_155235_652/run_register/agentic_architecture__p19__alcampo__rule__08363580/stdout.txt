Here is a SENSEI rule that checks if the chatbot provided information about current promotions. 

Since you mentioned this is not based on an existing profile, I have designed it using a custom variable named `provided_promotions`. 

```yaml
name: provided_promotions_info
description: Checks if the chatbot provided information about current promotions to the user.
conversations: 1
active: true
oracle: provided_promotions == True
on-error: "The chatbot failed to provide information about current promotions."
```

### How this works:
- **`conversations: 1`**: This is a single-conversation rule (an oracle) that evaluates each conversation individually.
- **`oracle: provided_promotions == True`**: This is the condition that must be met. It assumes that during the conversation, we extract a boolean value indicating whether promotions were discussed.

### ⚠️ Important Note for the Future Profile
Because rules in SENSEI-check read the outputs defined by SENSEI Chat profiles, **any future profile you create for this rule MUST expose this exact variable in its `chatbot.output`**. 

When you build the profile, its output section should look something like this:

```yaml
chatbot:
  output:
    - provided_promotions:
        type: boolean
        description: True if the chatbot mentioned or explained current promotions, False otherwise.
```
