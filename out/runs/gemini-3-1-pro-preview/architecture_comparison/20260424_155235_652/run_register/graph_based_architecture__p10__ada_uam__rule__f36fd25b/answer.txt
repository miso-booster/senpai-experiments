You have a fantastic SENSEI Chat profile here for prospective students. Since your chatbot extracts a lot of great information—like dates, fees, and links—we can write some really useful **SENSEI RULES** to verify that your chatbot is giving consistent and correct answers.

In Sensei-check, rules look at the fields you defined in your `chatbot.output`. Here are a few rule suggestions ranging from simple checks to metamorphic (multi-conversation) relations. You can copy and paste these directly into your project! 😊

### 1. Language Consistency Check
Since your user is speaking Spanish (`language: Spanish`), the chatbot should definitely reply in Spanish. This is a great, simple rule to ensure the bot doesn't accidentally switch languages.

```yaml
name: spanish_language_consistency
description: The chatbot should always respond in Spanish to the prospective student.
conversations: 1
oracle: language(chatbot_phrases) == 'ESP'
```

### 2. Welcome Day Consistency (Metamorphic Rule)
This is where metamorphic testing shines! ✨ Even if one student asks about "Arquitectura" and another asks about "Biología", the **Welcome Day date and time** should be exactly the same, right? This rule compares two different conversations to ensure that consistency.

```yaml
name: welcome_day_consistency
description: The Welcome Day date and time should be the same regardless of the degree asked about.
conversations: 2
when: conv[0].grados != conv[1].grados
oracle: conv[0].welcome_day_date == conv[1].welcome_day_date and conv[0].welcome_day_time == conv[1].welcome_day_time
```

### 3. Application Fee Sanity Check
You have an `application_fee` output of type `money`. We can write a rule to ensure that whenever the bot mentions the fee, it's a valid, non-negative number. We use the handy `extract_float()` helper for this!

```yaml
name: valid_application_fee
description: The application fee must be a valid positive amount or zero.
conversations: 1
oracle: extract_float(application_fee) >= 0
```

### 4. Essential Links Provided
Your user's goals explicitly ask for admission details and Welcome Day info. We can write a rule to check that the chatbot actually provided those specific links in the output.

```yaml
name: essential_links_provided
description: The chatbot must successfully provide the admission and welcome day links.
conversations: 1
oracle: admission_to_grados_link is not None and welcome_day_link is not None
```

### How to use these:
Just save each of these blocks as a `.yaml` file inside your rules folder (for example, `rules/welcome_day_consistency.yaml`). When you run Sensei-check, it will evaluate these rules against the 6 conversations generated by your profile! 🚀
