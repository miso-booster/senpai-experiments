Here is a rule you can use to check that ADA UAM provided all the necessary contact information for the CAU! 😊

Since we are checking the outcome of a single conversation to ensure specific fields were extracted, we can write a single-conversation oracle. It will verify that `contact_email`, `contact_phone`, and `physical_address` are not empty (`None`).

```yaml
name: cau_contact_info_complete
description: The chatbot must provide the email, phone number, and physical address of the CAU.
conversations: 1
active: true
oracle: contact_email is not None and contact_phone is not None and physical_address is not None
yields: f"Missing CAU contact info! Email: {contact_email}, Phone: {contact_phone}, Address: {physical_address}"
```

### How it works:
* **`conversations: 1`**: This tells Sensei-check to evaluate the rule on each conversation individually.
* **`oracle`**: This is the condition that must be met. It simply checks that the LLM successfully extracted a value for all three of those fields defined in your `chatbot.output`.
* **`yields`**: If the rule fails (meaning one or more of those fields were missing), it will output a helpful error message showing exactly what was captured so you can easily spot what ADA UAM forgot to mention! 👀

Let me know if you'd like to add any other conditions to this rule! 🚀
