In **Sensei-check**, we actually have a built-in helper function designed exactly for this purpose called `responds_in_same_language()`. Because this rule checks the general conversational behavior rather than specific extracted data, it is considered a "global" or profile-agnostic rule.

Here is the YAML rule you can use:

```yaml
name: language_matching
description: The assistant always replies in the same language that the user speaks.
conversations: 1
oracle: responds_in_same_language() is True
```

### How it works:
* **`conversations: 1`**: This tells Sensei-check to evaluate this rule on each conversation individually (it's a single-conversation oracle).
* **`oracle: responds_in_same_language() is True`**: This uses our LLM-backed helper function to automatically analyze the dialogue turns and verify that the assistant's language matches the user's language. 

You can just drop this rule into your project, and Sensei-check will flag any conversations where the chatbot accidentally switches languages! 🌍💬
