¡Hola! Claro que sí 😊. Para comprobar que el asistente confirma la bebida después de que el usuario la pide, podemos usar la función `utterance_index`. 

Esta función analiza la conversación y nos devuelve el número de turno en el que alguien habla de un tema específico. Así que la lógica es sencilla: solo tenemos que asegurarnos de que el turno donde el usuario pide la bebida ocurre *antes* (es decir, su índice es menor) que el turno donde el asistente confirma el pedido de la bebida.

Aquí tienes la regla lista para añadir a tu proyecto:

```yaml
name: assistant_confirms_drink_order
description: The assistant confirms the drink order after the user orders a drink
conversations: 1
active: true
oracle: utterance_index('user', 'ordering a drink') < utterance_index('assistant', 'confirms drink order')
```

**💡 Un pequeño consejo:** Esta regla sigue la misma estructura que ya tienes en tu archivo `ordering_conversation_turns_assistant.yaml` para las pizzas, ¡así que encajará perfectamente en tu proyecto!
