Testing how a chatbot handles dates and times is super important, especially for booking appointments. To do this efficiently, we can use **variables** for the days and times, and apply the `pairwise()` function. This will mix and match different days and times to ensure your chatbot understands various formats (like "tomorrow", specific dates, "10:00 AM", or "noon") without having to write dozens of separate profiles.

Here is a complete, ready-to-run profile for your bike shop:

```yaml
test_name: "wheel_change_appointment"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a cyclist who needs to get your bike's wheels changed. 
    You want to schedule an appointment at the local bike shop to have them installed.
  context:
    - "Your current wheels are worn out. You just need the shop to install new ones."
    - "You have a busy schedule, so you need to confirm the exact day and time."
  goals:
    - "Hi, I need to get my bike wheels changed."
    - "Can I schedule an appointment for {{day}} at {{time}}?"
    - day:
        function: pairwise()
        type: string
        data: 
          - "tomorrow"
          - "next Monday"
          - "Friday"
          - "November 15th"
    - time:
        function: pairwise()
        type: string
        data: 
          - "10:00 AM"
          - "14:30"
          - "noon"
          - "4:00 PM"

chatbot:
  is_starter: false
  fallback: "I'm sorry, it's a little loud in the shop right now. Could you repeat that?"
  output:
    - confirmed_day:
        type: string
        description: "The day confirmed by the chatbot for the wheel change appointment."
    - confirmed_time:
        type: time("hh:mm")
        description: "The time confirmed by the chatbot for the appointment."
    - service_type:
        type: string
        description: "The specific service confirmed by the bot (e.g., wheel change or installation)."

conversation:
  number: combinations(1, pairwise)
  goal_style:
    all_answered:
      export: true
      limit: 15
  interaction_style:
    - default
```

### 🛠️ Why we built it this way:

1. **Variables & `pairwise()`**: In the `user.goals` section, we defined `{{day}}` and `{{time}}`. By using `function: pairwise()` on both, Sensei will automatically generate a smart matrix of combinations (e.g., "tomorrow at 14:30", "Friday at noon"). This gives you great test coverage without running every single possible combination!
2. **`conversation.number`**: We set this to `combinations(1, pairwise)`. This tells Sensei to run exactly 100% (the `1`) of the pairwise combinations generated by your variables.
3. **`chatbot.output`**: At the end of the conversation, Sensei will extract the `confirmed_day` and `confirmed_time`. Notice how we used `type: time("hh:mm")` for the time? This normalizes the output, making it super easy to write **Sensei Rules** later to verify if the bot booked the correct slot! 🕒
4. **`goal_style.all_answered`**: We set `export: true` so that after the run, Sensei will generate a handy CSV dataframe showing you exactly which goals were satisfied during the tests.

If you want to make it even trickier for the chatbot, we could add `change your mind` to the `interaction_style` so the user asks for Monday, but then suddenly switches to Friday! 👀
