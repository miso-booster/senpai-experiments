Based on the SENSEI rules documentation (`sensei-check-doc.md` and `rules-examples.md`), checking if the chatbot matches the user's language is a **general rule**. This means it is profile-agnostic and doesn't depend on specific outputs from your chatbot; instead, it uses a built-in helper function called `responds_in_same_language()`.

Here is the YAML for the rule:

```yaml
name: chatbot_responds_in_same_language
description: The chatbot responds in the same language as the user
conversations: 1
active: true
oracle: responds_in_same_language()
on-error: f"The chatbot did not respond in the same language as the user."
```

### How this rule works:
* **`conversations: 1`**: This is a single-conversation check (an oracle). It evaluates each conversation individually.
* **`oracle: responds_in_same_language()`**: This uses SENSEI's built-in LLM-backed helper to analyze the dialogue and verify that the assistant's replies match the language the simulated user is speaking.
* **`on-error`**: If the rule fails, this provides a helpful error message indicating the language mismatch.

You can save this as a `.yaml` file in your `rules` directory, and it will automatically apply to your conversations to ensure language consistency! Let me know if you need help creating any other rules.
