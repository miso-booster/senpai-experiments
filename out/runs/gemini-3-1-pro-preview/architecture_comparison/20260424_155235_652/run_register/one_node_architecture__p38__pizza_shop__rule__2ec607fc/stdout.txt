Since you want to verify that a specific field (`order_id`) was successfully extracted by the end of the conversation, we just need a simple single-conversation rule (also known as an oracle). 

Here is the YAML for the rule. It checks the `data_output` dictionary to ensure the `order_id` was captured:

```yaml
name: order_id_provided
description: The chatbot must return an order ID by the end of the conversation.
conversations: 1
active: true
oracle: "'order_id' in data_output"
```

Alternatively, you can also write the oracle to directly check if the variable is not empty, like this: `oracle: order_id is not None`. Both work perfectly!

Just remember that for this rule to work, your target SENSEI Profile must have `order_id` defined in its `chatbot.output` section so the extractor knows to look for it.
