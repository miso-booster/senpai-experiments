¡Hola! Claro que sí, ¡puedo ayudarte con eso! 😊

Como ambos chatbots utilizan la misma plataforma (1millionbot), la estructura es prácticamente idéntica. Solo necesitamos actualizar los identificadores de la conversación, el bot, el token de autorización y añadir las cabeceras de `Origin` y `Referer` que aparecen en tu petición para asegurarnos de que el servidor no bloquee la conexión.

El `response_path` se mantiene igual (`response.0.text`), ya que la estructura de la respuesta JSON es la misma.

Aquí tienes tu nuevo conector listo para usar:

```yaml
name: "Morón de la Frontera"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "65ca19e7dbbb4e26cbeadf28"
    Origin: "https://www.morondelafrontera.es"
    Referer: "https://www.morondelafrontera.es/"
  payload_template:
    conversation: "67ea76f4e213b2dcbc146e2b"
    sender_type: "User"
    sender: "67ea76f40643a3dd27e59411"
    bot: "65ca19e7dbbb4e26cbeadf24"
    language: "es"
    url: "https://www.morondelafrontera.es/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

Guarda este contenido en un archivo (por ejemplo, `moron-frontera.yml`) dentro de tu carpeta de conectores y ya podrás empezar a probarlo. ¡Espero que el Gallo de Morón responda perfectamente a todas las pruebas! 🐓✨
