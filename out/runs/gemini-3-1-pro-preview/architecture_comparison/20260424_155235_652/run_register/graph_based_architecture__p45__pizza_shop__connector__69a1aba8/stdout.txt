### A quick note about removing HTML tags 👀
You mentioned wanting the assistant response to return plain text with the HTML tags removed. Based on the SENSEI CONNECTORS documentation, the YAML connector is designed to extract the exact value located at the `response_path` (which in your case is `response.0.text`). 

Currently, the YAML configuration doesn't have a built-in feature to automatically strip HTML tags from the extracted string. It will return the raw string exactly as the API sends it (e.g., `"<p>¡Buenos días!<br><br>¿En qué puedo ayudarte?</p>"`). 

To get plain text, you will just need to strip those HTML tags in your Python code right after the connector fetches the response, like this:

```python
import re
from chatbot_connectors.implementations.custom import CustomChatbot

bot = CustomChatbot("your-malaga-config.yml")
success, response = bot.execute_with_input("hola")

if success:
    # Remove HTML tags using a simple regex in your code! ✨
    clean_text = re.sub(r'<[^>]+>', '', response)
    print(clean_text)
```
