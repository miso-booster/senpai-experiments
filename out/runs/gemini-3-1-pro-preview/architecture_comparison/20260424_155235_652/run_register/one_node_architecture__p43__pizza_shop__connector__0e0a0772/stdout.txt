Si el conector te está fallando en la práctica, lo más probable es que se deba a un pequeño problema de indentación (los espacios son muy estrictos en YAML) o a que la API requiera algún token de seguridad que no está en los `headers`.

```yaml
name: "Test Connector 2"
base_url: "https://api.anotherexample.com"
send_message:
  path: "/api/chat"
  method: "POST"
  headers:
    Content-Type: "application/json"
    # Authorization: "Bearer tu-token-aqui" # Descomenta esta línea si tu API requiere autenticación
  payload_template:
    message:
      text: "{user_msg}"
response_path: "response.text"
```

**💡 Un par de consejos extra:**
1. Asegúrate de que la URL completa (`https://api.anotherexample.com/api/chat`) sea correcta y accesible desde donde estás ejecutando SENSEI.
2. Si tu API requiere algún tipo de llave, token o header adicional (como `Origin` o `User-Agent`), no olvides agregarlo en la sección de `headers`.
