While a profile needs core sections like `user`, `chatbot`, and `conversation` to know how to behave, there are several fields that are completely **optional**. If you leave them out, Sensei will either ignore them or use handy default values. 

Here are the non-mandatory fields in a profile:

*   **The entire `llm` block:** You actually don't have to define this at all! If you omit it, Sensei will automatically apply its default settings (like a default model, temperature, and text format). 🤖
*   **`user.context.personality`:** When setting up the user's context, linking to a specific personality file (e.g., `personalities/calm-user.yml`) is optional. You can just write freeform text constraints and facts instead!
*   **`conversation.max_cost`:** This is an optional safety cap (in $) for the *entire* run. It's super useful to prevent you from spending too much on LLM tokens, but you don't have to include it. 💸
*   **`conversation.goal_style.max_cost`:** Similar to the one above, but this optionally caps the spend *per conversation*.
*   **`conversation.goal_style.all_answered.export` and `limit`:** If you choose the `all_answered` goal style, you don't have to specify these. `export` defaults to false, and `limit` (a safety stop for the number of turns) defaults to 30.
*   **`chatbot.fallback`:** While highly recommended so your bot doesn't get stuck in endless loops, it's technically optional depending on how your target chatbot handles errors.

**In short:** You can keep your profile super minimal, or you can add these extra fields for more control and safety!
