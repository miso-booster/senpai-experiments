Since we are checking a condition within a single conversation rather than comparing multiple conversations, we'll use a **single-conversation oracle** rule. 

Here is the YAML code for your rule. You can save this in your `rules` folder (for example, as `small_pizza_price.yaml`):

```yaml
name: small_pizza_price_10
description: A small pizza should cost exactly $10.
conversations: 1
when: size == 'small'
oracle: extract_float(price) == 10 and currency(price) == 'USD'
```

### 📝 A quick breakdown of how this works:
* **`conversations: 1`**: Tells Sensei-check that we are evaluating one conversation at a time.
* **`when: size == 'small'`**: This acts as a filter. The rule will only run on conversations where the simulated user ordered a 'small' pizza.
* **`oracle: ...`**: This is the test itself! We use the handy `extract_float()` helper to pull the number out of the price string (just in case the bot replies with something like "$10.00"), and we use `currency()` to make sure it's in USD.

**A quick Senpai tip 👀:** Remember that for this rule to work perfectly, your **SENSEI Chat profile** needs to expose `size` and `price` in its `chatbot.output` schema.
