Aquí tienes el YAML listo para usar:

```yaml
name: "Ayuntamiento de Morón de la Frontera"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "65ca19e7dbbb4e26cbeadf28"
    Origin: "https://www.morondelafrontera.es"
    Referer: "https://www.morondelafrontera.es/"
  payload_template:
    conversation: "67ea76f4e213b2dcbc146e2b"
    sender_type: "User"
    sender: "67ea76f40643a3dd27e59411"
    bot: "65ca19e7dbbb4e26cbeadf24"
    language: "es"
    url: "https://www.morondelafrontera.es/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

### 📝 Resumen de los cambios:
1. **Autorización (`Authorization`)**: Actualizada al token del nuevo bot (`65ca19e7dbbb4e26cbeadf28`).
2. **Cabeceras adicionales (`Headers`)**: He añadido `Origin` y `Referer` apuntando a la web del ayuntamiento, ya que a veces las APIs de 1millionbot las requieren por seguridad (CORS).
3. **Payload (`payload_template`)**:
   - Se han actualizado los IDs de `conversation`, `sender` y `bot` con los valores de tu petición.
   - La `url` ahora apunta a `https://www.morondelafrontera.es/`.
4. **Ruta de respuesta (`response_path`)**: Se mantiene como `response.0.text` porque la estructura del JSON de respuesta es idéntica a la de Ada UAM (el texto del bot viene dentro del primer elemento del array `response`).
