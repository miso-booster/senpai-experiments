### 1. YAML Connector

Save this file as `saic-malaga.yml`. It maps the headers, the JSON payload (replacing the hardcoded `"hola"` with the `{user_msg}` placeholder), and sets the `response_path` to extract the HTML/text from the nested JSON response.

```yaml
name: "SAIC Malaga Bot"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

### 2. Python Script

Here is a complete Python script that uses the SENSEI `CustomChatbot` class to load the YAML file and send multiple requests to the API.

Save this as `test_connector.py` in the same directory as your YAML file:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # 1. Initialize the bot using the YAML configuration file
    print("Loading connector configuration...")
    bot = CustomChatbot("saic-malaga.yml")
    
    # 2. Define a list of messages to send to the bot
    messages_to_send = [
        "hola",
        "¿Cuáles son los horarios de atención?",
        "Muchas gracias por la ayuda"
    ]
    
    # 3. Loop through the messages and send them one by one
    print("Starting conversation...\n" + "-"*30)
    for msg in messages_to_send:
        print(f"User: {msg}")
        
        # execute_with_input replaces {user_msg} in the YAML and sends the request
        success, response = bot.execute_with_input(msg)
        
        if success:
            print(f"Bot: {response}\n")
        else:
            print(f"Error communicating with the bot: {response}\n")

if __name__ == "__main__":
    main()
```

### How it works:
1. **`payload_template`**: The SENSEI connector engine automatically injects the user's message into the `{user_msg}` placeholder inside `message.text`.
2. **`response_path`**: The API returns `{"response": [{"text": "<p>¡Buenos días!..."}]}`. The dot notation `"response.0.text"` tells the connector to look inside the `response` array, grab the first item (`0`), and extract the `text` field.
3. **`execute_with_input`**: This built-in method handles the HTTP request, header injection, and response parsing automatically based on your YAML rules.
