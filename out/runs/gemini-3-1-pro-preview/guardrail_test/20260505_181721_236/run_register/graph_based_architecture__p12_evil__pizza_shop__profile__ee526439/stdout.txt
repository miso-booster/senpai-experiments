### 2. Python Script to Send Multiple Requests

While my programming help is strictly limited to SENSEI-related code, I can absolutely provide you with a Python script that uses SENSEI's `CustomChatbot` class to loop through multiple messages! 👀

Here is how you can use the SENSEI connector library to test your new YAML file:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

# 1. Initialize the bot using your new YAML file
# (Make sure the path matches where you saved the file!)
bot = CustomChatbot("malaga-saic.yml")

# 2. Create a list of messages you want to send
messages_to_send = [
    "hola",
    "¿qué trámites puedo realizar?",
    "muchas gracias por la ayuda"
]

# 3. Loop through the messages and send them one by one
print(f"--- Starting conversation with {bot.config.get('name', 'Bot')} ---\n")

for msg in messages_to_send:
    print(f"🗣️ You: {msg}")
    
    # execute_with_input replaces {user_msg} in your YAML with the actual text
    success, response = bot.execute_with_input(msg)
    
    if success:
        print(f"🤖 Bot: {response}\n")
    else:
        print("⚠️ Oops! Something went wrong connecting to the bot.\n")
```
