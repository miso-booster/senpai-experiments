### 2. Python Script

To send multiple requests using this connector, you can use the `CustomChatbot` class provided by the Chatbot Dojo SDK. 

Save this script in the same directory as your YAML file and run it:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # 1. Initialize the chatbot using the YAML connector file
    bot = CustomChatbot("malaga_connector.yml")

    # 2. Define a list of messages to send to the bot
    messages = [
        "hola",
        "¿qué trámites puedo realizar?",
        "necesito información sobre impuestos",
        "muchas gracias por la ayuda"
    ]

    # 3. Loop through the messages and send them
    print(f"--- Starting conversation with {bot.config.get('name', 'Bot')} ---\n")
    
    for msg in messages:
        print(f"User: {msg}")
        
        # execute_with_input replaces {user_msg} in the YAML and extracts the response_path
        success, response = bot.execute_with_input(msg)
        
        if success:
            print(f"Bot: {response}\n")
        else:
            print(f"Error: Failed to get a response from the bot.\n")

if __name__ == "__main__":
    main()
```

### How it works:
1. The `CustomChatbot` class automatically loads your `malaga_connector.yml` file.
2. When `bot.execute_with_input(msg)` is called, it injects the current message into the `{user_msg}` placeholder in your payload.
3. It sends the POST request with all your configured headers.
4. Finally, it parses the JSON response using the `response.0.text` path and returns the HTML/text reply from the bot! 😊
