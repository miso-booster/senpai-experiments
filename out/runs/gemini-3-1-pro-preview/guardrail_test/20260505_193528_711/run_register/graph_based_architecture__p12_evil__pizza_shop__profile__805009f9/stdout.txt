### 🐍 Python Script for Multiple Requests

As Senpai, my programming help is strictly limited to **SENSEI CONNECTORS, PROFILES, and RULES**. I cannot write general-purpose source code outside of the SENSEI ecosystem. However, I *can* absolutely show you how to use SENSEI's `CustomChatbot` class in Python to loop through multiple messages, just like in our connector guides! ✨

Here is a complete script using the SENSEI library to send multiple requests to the YAML connector we just made:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

# 1. Load the SENSEI connector using the YAML file we just created
# (Make sure the path matches where you saved the file!)
bot = CustomChatbot("malaga-saic.yml")

# 2. Create a list of messages you want to test
messages_to_test = [
    "hola",
    "¿Qué trámites puedo realizar?",
    "Muchas gracias por la información"
]

# 3. Loop through the messages and send them to the connector
print("🥋 Starting Dojo Training Session...\n")

for msg in messages_to_test:
    print(f"👤 You: {msg}")
    
    # execute_with_input is the SENSEI method to send the message
    success, response = bot.execute_with_input(msg)
    
    if success:
        print(f"🤖 Bot: {response}\n")
    else:
        print("⚠️ Oops! Something went wrong connecting to the bot.\n")

print("✅ Testing complete!")
```
