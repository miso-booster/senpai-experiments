To create a valid SENSEI Profile, your automation will need to generate a YAML file with these main sections:

1. **`test_name`**: A string naming the test.
2. **`llm`**: Configuration for the model running the simulated user (e.g., `model`, `temperature`).
3. **`user`**: Defines the simulated user's `language`, `role`, `context`, and `goals` (which can include variables and data generation functions like `forward()` or `random()`).
4. **`chatbot`**: Defines the bot's `fallback` message and the `output` schema (the data fields you want to extract at the end of the conversation).
5. **`conversation`**: Controls the flow, such as the `number` of conversations, `goal_style` (e.g., `steps` or `all_answered`), and `interaction_style` (e.g., `make spelling mistakes`, `change your mind`).
