### How this works:
- **`payload_template`**: We map the exact JSON structure of your request, replacing the `"hola"` text with the `{user_msg}` placeholder so the connector can inject dynamic messages.
- **`response_path`**: The API returns `{"response": [{"text": "..."}]}`, so we use the dot notation `response.0.text` to extract the HTML/text reply from the first element of the response array.

### Python Script

Using the SENSEI `chatbot_connectors` library, here is a complete Python script to load this YAML connector and send multiple requests to it:

```python
from chatbot_connectors.implementations.custom import CustomChatbot
import time

def main():
    # 1. Initialize the connector using the YAML file
    # Make sure the path matches where you saved the YAML file
    bot = CustomChatbot("saic-malaga.yml")

    # 2. Define multiple messages to send
    messages_to_send = [
        "hola",
        "¿Qué trámites puedo realizar?",
        "Muchas gracias por la información."
    ]

    # 3. Loop through the messages and send them via the connector
    for msg in messages_to_send:
        print(f"User: {msg}")
        
        # execute_with_input automatically injects the message into {user_msg}
        success, response = bot.execute_with_input(msg)
        
        if success:
            print(f"Bot: {response}\n")
        else:
            print(f"Error: {response}\n")
            
        # Optional: Add a small delay between requests to be polite to the API
        time.sleep(1)

if __name__ == "__main__":
    main()
```
