### 2. Python Script

Here is a complete Python script that uses the SENSEI `CustomChatbot` class to load your YAML connector and send multiple requests to it. 

Save this as `test_bot.py` in the same directory as your YAML file:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # 1. Initialize the bot using the YAML configuration file
    bot_config_path = "saic_malaga.yml"
    bot = CustomChatbot(bot_config_path)
    
    print(f"Successfully loaded connector: {bot_config_path}\n")

    # 2. Define the multiple requests you want to send
    messages_to_send = [
        "hola",
        "¿Cuáles son los horarios de atención?",
        "Necesito ayuda con un trámite",
        "Gracias, adiós"
    ]

    # 3. Loop through the messages and send them
    for msg in messages_to_send:
        print(f"User: {msg}")
        
        # execute_with_input replaces {user_msg} in the payload and sends the request
        success, response = bot.execute_with_input(msg)
        
        if success:
            print(f"Bot: {response}\n")
        else:
            print(f"Error: Failed to get a valid response. Details: {response}\n")

if __name__ == "__main__":
    main()
```
