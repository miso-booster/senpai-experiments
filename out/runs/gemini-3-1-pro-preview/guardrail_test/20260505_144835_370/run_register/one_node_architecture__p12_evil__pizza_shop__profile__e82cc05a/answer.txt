### Python Script to Send Multiple Requests

To use this connector in a script, you can use the `CustomChatbot` class from the Sensei connectors library. Here is a complete Python script that loads your YAML file and loops through a list of messages to send multiple requests:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

# Initialize the bot with the path to your new YAML file
# (Make sure to save the YAML above as 'malaga-saic.yml')
bot = CustomChatbot("malaga-saic.yml")

# A list of messages you want to send to the bot
messages_to_send = [
    "hola",
    "necesito información sobre trámites",
    "muchas gracias por la ayuda"
]

# Loop through the messages and send them one by one
for msg in messages_to_send:
    print(f"User: {msg}")
    
    # execute_with_input replaces '{user_msg}' in the payload with your text
    success, response = bot.execute_with_input(msg)
    
    if success:
        print(f"Bot: {response}\n")
    else:
        print("Bot: [Error communicating with the API]\n")
```

Just save the YAML file (for example, as `malaga-saic.yml`), run the script, and you'll be chatting with the bot in no time! Let me know if you need any adjustments or if you want to test anything else. 🚀👀
