### How to use it in Python 👀

While my main focus is helping you configure Sensei Profiles, Rules, and Connectors, I can certainly show you how to use this newly created connector in a Python script using the Sensei `CustomChatbot` library! 

Here is a quick script to send multiple requests using the connector we just built:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

# Initialize the bot using the YAML file we just created
# (Make sure to save the YAML above as 'malaga_bot.yml')
bot = CustomChatbot("malaga_bot.yml")

# A list of multiple messages to send
messages_to_send = [
    "hola",
    "necesito información sobre impuestos",
    "¿cuál es el horario de atención?"
]

print("🤖 Starting conversation with Malaga SAIC Bot...\n")

for msg in messages_to_send:
    print(f"👤 You: {msg}")
    
    # Execute the request through the connector
    success, response = bot.execute_with_input(msg)
    
    if success:
        print(f"🤖 Bot: {response}\n")
    else:
        print(f"❌ Error communicating with the bot: {response}\n")
```

**A quick note on the `response_path`:** 
In your JSON response, the bot's reply is located inside an array called `response`, at the first index (`0`), inside the `text` key. That's why we use `"response.0.text"` to extract exactly what the bot said!
