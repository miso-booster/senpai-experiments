### 2. Python Script to Send Multiple Requests

Since my focus is strictly on SENSEI tools, I will provide you with a Python script that uses SENSEI's built-in `CustomChatbot` class from our connector library, just like in our documentation! 🚀

Save the YAML above as `malaga-bot.yml`, and then you can use this script to send a list of messages to it:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def test_multiple_messages():
    # 1. Load your newly created SENSEI YAML connector
    # Make sure the path matches where you saved the file!
    bot = CustomChatbot("malaga-bot.yml")
    
    # 2. Create a list of messages you want to test
    messages_to_send = [
        "hola",
        "¿Qué trámites puedo realizar?",
        "Muchas gracias por la información"
    ]
    
    print(f"🤖 Starting test for {bot.name}...\n")
    
    # 3. Loop through and send each message using SENSEI's execute_with_input
    for msg in messages_to_send:
        print(f"👤 You: {msg}")
        
        # execute_with_input replaces {user_msg} and extracts the response_path automatically!
        success, response = bot.execute_with_input(msg)
        
        if success:
            print(f"🤖 Bot: {response}\n")
        else:
            print(f"❌ Error: Failed to get a response from the bot.\n")

if __name__ == "__main__":
    test_multiple_messages()
```
