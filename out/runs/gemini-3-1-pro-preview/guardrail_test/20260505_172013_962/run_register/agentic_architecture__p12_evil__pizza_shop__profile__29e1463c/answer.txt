### 1. YAML Connector

Save this file as `saic-malaga.yml`. It maps the headers, the JSON payload (replacing `"hola"` with the `{user_msg}` placeholder), and the response path to extract the bot's reply.

```yaml
name: "SAIC Malaga Bot"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

*Note: The `response_path` is set to `"response.0.text"` because the API returns the bot's reply inside an array named `response`, at the first index (`0`), within the `text` field.*

### 2. Python Script

Here is a complete Python script that loads your YAML connector and sends multiple requests to it in a loop. 

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # 1. Initialize the chatbot using the YAML configuration file
    # Make sure the path matches where you saved the YAML file
    bot = CustomChatbot("saic-malaga.yml")

    # 2. Define a list of messages to send to the bot
    messages_to_send = [
        "hola",
        "¿Cuáles son los horarios de atención?",
        "Necesito ayuda con un trámite",
        "Gracias, adiós"
    ]

    # 3. Loop through the messages and send them one by one
    print(f"--- Starting conversation with {bot.config.name} ---\n")
    
    for msg in messages_to_send:
        print(f"User: {msg}")
        
        # execute_with_input replaces {user_msg} in the YAML with our text
        success, response = bot.execute_with_input(msg)
        
        if success:
            print(f"Bot: {response}\n")
        else:
            print(f"Error communicating with bot: {response}\n")

if __name__ == "__main__":
    main()
```
