### Python Script to Send Multiple Requests

Since my focus is strictly on SENSEI CONNECTORS, SENSEI RULES, and SENSEI PROFILES, I can't provide generic Python source code (like a standard `requests` script). However, I *can* absolutely give you a script that uses our official SENSEI `CustomChatbot` library to send multiple messages! ✨

Here is a complete Python script using the SENSEI Connector framework to loop through a list of messages:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

# 1. Load our shiny new YAML connector!
# (Make sure the path matches where you saved the file above)
bot = CustomChatbot("malaga-saic.yml")

# 2. Create a list of messages you want to test
messages_to_send = [
    "hola",
    "¿Qué trámites puedo realizar?",
    "Muchas gracias por la ayuda"
]

# 3. Loop through the messages and send them to the bot
print("Starting conversation with Malaga SAIC Bot... 🤖\n")

for msg in messages_to_send:
    print(f"You: {msg}")
    
    # execute_with_input automatically replaces {user_msg} in your YAML
    success, response = bot.execute_with_input(msg)
    
    if success:
        print(f"Bot: {response}\n")
    else:
        print("Oops! Something went wrong trying to reach the bot. 😥\n")
```
