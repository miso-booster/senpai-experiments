Here is a complete Python automation script that uses OpenAI's LLM to generate valid SENSEI profiles. 

Based on the SENSEI documentation, a valid profile requires specific top-level keys (`test_name`, `llm`, `user`, `chatbot`, `conversation`), strict variable mapping in `user.goals`, and a clear extraction schema in `chatbot.output`. The script below embeds these rules into a strong **System Prompt** so the LLM knows exactly how to format the YAML.

### Prerequisites
You will need the `openai` and `pyyaml` packages. You can install them via pip:
```bash
pip install openai pyyaml
```
You also need to set your OpenAI API key as an environment variable:
```bash
export OPENAI_API_KEY="your-api-key-here"
```

### Python Automation Script (`generate_profile.py`)

```python
import os
import yaml
from openai import OpenAI

# Initialize OpenAI client
client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

# This system prompt embeds the SENSEI Profile schema rules
SENSEI_PROFILE_SYSTEM_PROMPT = """
You are an expert in creating SENSEI profiles for chatbot testing.
A SENSEI profile is a YAML file that defines a simulated user's behavior, goals, and the expected chatbot outputs.

Follow these strict rules for the YAML structure:
1. Top-level keys: `test_name`, `llm`, `user`, `chatbot`, `conversation`.
2. `llm`: Should specify `temperature`, `model` (e.g., gpt-4o), `model_prov` (e.g., openai), and `format` (type: text).
3. `user`:
   - `language`: e.g., English, Spanish.
   - `role`: A prompt describing the simulated user.
   - `context`: A list of strings with constraints, preferences, etc.
   - `goals`: A list containing strings with `{{variables}}` AND mappings for those variables.
     - Variable mappings must have: `function` (e.g., random(), default(), forward(), pairwise(), another()), `type` (string, int, float), and `data` (a list of values or min/max/step).
     - Variables in strings must EXACTLY match the mapping names.
4. `chatbot`:
   - `is_starter`: true or false.
   - `fallback`: The bot's real fallback message.
   - `output`: A list of dictionaries defining fields to extract. Each field needs a `type` (e.g., string, int, currency, time("hh:mm")) and `description`.
5. `conversation`:
   - `number`: An integer or `combinations(0.5, pairwise)` if using pairwise/forward.
   - `goal_style`: e.g., `steps: 5` or `all_answered: {export: true}`.
   - `interaction_style`: A list of styles (e.g., `long phrases`, `make spelling mistakes`, `single questions`, `change language: [Spanish]`, or `random: [...]`).

Output ONLY valid YAML inside a ```yaml block. Do not include any other text or explanations.
"""

def generate_sensei_profile(description: str, output_filename: str):
    print(f"Generating SENSEI profile for scenario: '{description}'...")
    
    # Call the LLM
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[
            {"role": "system", "content": SENSEI_PROFILE_SYSTEM_PROMPT},
            {"role": "user", "content": f"Create a SENSEI profile for the following scenario:\n{description}"}
        ],
        temperature=0.2 # Low temperature for more deterministic, structured output
    )
    
    content = response.choices[0].message.content.strip()
    
    # Clean up the markdown formatting to extract just the YAML
    if content.startswith("```yaml"):
        content = content[7:]
    elif content.startswith("```"):
        content = content[3:]
        
    if content.endswith("```"):
        content = content[:-3]
        
    content = content.strip()
    
    # Validate that the output is actually valid YAML
    try:
        parsed_yaml = yaml.safe_load(content)
        print("✅ Generated YAML is syntactically valid.")
    except yaml.YAMLError as e:
        print(f"❌ Error parsing generated YAML: {e}")
        print("Raw output was:\n", content)
        return None
        
    # Ensure the target directory exists
    os.makedirs(os.path.dirname(output_filename) or ".", exist_ok=True)
    
    # Save the profile
    with open(output_filename, "w", encoding="utf-8") as f:
        f.write(content)
        
    print(f"🎉 Successfully saved profile to {output_filename}")
    return content

# --- Example Usage ---
if __name__ == "__main__":
    # Describe the chatbot testing scenario you want to automate
    scenario = """
    A user trying to book a table at an Italian restaurant for a group of friends. 
    They want to know if there are vegan options and need to specify the date, time, and party size.
    They might make spelling mistakes and change their mind.
    """
    
    # Generate and save the profile
    generate_sensei_profile(
        description=scenario, 
        output_filename="profiles/restaurant_booking.yml"
    )
```

### How this automation works:
1. **System Prompt Engineering**: The script feeds the LLM a highly condensed version of the SENSEI documentation. It explicitly tells the LLM how to format `user.goals` (with `{{variables}}` and data functions like `random()` or `pairwise()`) and `chatbot.output` (which acts as the contract for SENSEI-check rules later).
2. **Low Temperature**: We set `temperature=0.2` to prevent the LLM from hallucinating unsupported YAML fields and to keep it strictly adhering to the schema.
3. **Validation**: Before saving, the script uses `yaml.safe_load()` to ensure the LLM didn't break the YAML syntax. 
4. **File Generation**: It automatically strips out the markdown code blocks (` ```yaml `) and saves the raw YAML directly into your `profiles/` directory, ready to be executed by Sensei! 😊
