### 2. Python Script (`test_connector.py`)

Here is a complete Python script that loads the YAML connector and sends multiple requests to the chatbot in a loop.

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # 1. Initialize the chatbot using the YAML connector file
    # Make sure the path matches where you saved the YAML file
    bot = CustomChatbot("malaga_saic.yml")

    # 2. Define a list of messages to send
    messages_to_send = [
        "hola",
        "¿Cuáles son los horarios de atención?",
        "Necesito información sobre trámites",
        "Gracias, adiós"
    ]

    print(f"--- Starting conversation with {bot.config.name} ---\n")

    # 3. Loop through the messages and send them
    for msg in messages_to_send:
        print(f"User: {msg}")
        
        # execute_with_input replaces '{user_msg}' in the payload and sends the request
        success, response = bot.execute_with_input(msg)
        
        if success:
            print(f"Bot: {response}\n")
        else:
            print(f"Error: Failed to get a response for message: '{msg}'\n")

if __name__ == "__main__":
    main()
```

### How it works:
- **`payload_template`**: The `message.text` field is set to `"{user_msg}"`. The `CustomChatbot` class will automatically replace this placeholder with the actual string you pass to `execute_with_input()`.
- **`response_path`**: The API returns `{"response": [{"text": "<p>¡Buenos días!..."}]}`. The dot notation `"response.0.text"` tells the connector to look inside the `response` array, grab the first item (`0`), and extract the `text` field.
