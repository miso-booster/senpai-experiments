Since my expertise is focused on Sensei Connectors, Profiles, and Rules, I can show you exactly how to write a Python script that uses the Sensei `CustomChatbot` class to send multiple requests using the YAML file we just created!

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def test_malaga_bot():
    # 1. Initialize the bot using your new YAML connector
    # Make sure the path matches where you saved the file!
    bot = CustomChatbot("malaga-saic.yml")

    # 2. Create a list of messages you want to send
    messages_to_send = [
        "hola",
        "¿Cómo puedo empadronarme?",
        "Muchas gracias por la ayuda"
    ]

    # 3. Loop through the messages and send them
    for msg in messages_to_send:
        print(f"🗣️ Sending: {msg}")
        
        # execute_with_input replaces '{user_msg}' with your text
        success, response = bot.execute_with_input(msg)
        
        if success:
            print(f"🤖 Bot replied: {response}\n")
        else:
            print(f"❌ Error: {response}\n")

if __name__ == "__main__":
    test_malaga_bot()
```
