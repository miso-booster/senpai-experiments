### Python Script to Test the Connector

While my main focus is strictly on Sensei PROFILES, RULES, and CONNECTORS (so I can't write general-purpose Python scripts like raw `requests` loops), I *can* absolutely show you how to write a script using the **Sensei CustomChatbot library** to send multiple messages! 🚀

Assuming you save the YAML above as `saic-malaga.yml`, here is how you can loop through multiple requests using the Sensei connector:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

# 1. Initialize the bot with your new YAML configuration file
bot = CustomChatbot("saic-malaga.yml")

# 2. Define a list of messages you want to send
messages_to_send = [
    "hola",
    "necesito información sobre trámites",
    "muchas gracias por la ayuda"
]

# 3. Loop through the messages and execute the connector
for msg in messages_to_send:
    print(f"User: {msg}")
    
    # execute_with_input replaces '{user_msg}' and extracts the response_path
    success, response = bot.execute_with_input(msg)
    
    if success:
        print(f"Bot: {response}\n")
    else:
        print(f"Error: Failed to get a valid response. Details: {response}\n")
```
