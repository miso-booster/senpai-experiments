Sure! Here’s a metamorphic rule that checks whether adding a drink to the pizza order costs an additional 2 dollars. This rule assumes you have a field named "price" in your outputs that reflects the total price of the order.

```yaml
name: drink_price_increase
description: Adding a drink should cost an additional 2 dollars
conversations: 2
when: conv[0].pizza_size == conv[1].pizza_size and conv[0].selected_pizza_type == conv[1].selected_pizza_type
if:   conv[0].drink_quantity_requested == conv[1].drink_quantity_requested + 1
then: extract_float(conv[0].price) == extract_float(conv[1].price) + 2
```

### Explanation:
- **`when`**: This condition checks that both conversations have the same pizza size and type.
- **`if`**: This checks that the first conversation has one more drink than the second.
- **`then`**: This asserts that the price of the first conversation should be exactly 2 dollars more than the second.

Feel free to adapt the field names if they differ in your profile! 😊
