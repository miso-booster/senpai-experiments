```yaml
name: drink
description: Adding a drink to the order costs an additional $2
conversations: 2
when: conv[0].size == conv[1].size and conv[0].number == conv[1].number
if:   conv[0].drink == 'none' and conv[1].drink != 'none'
then: extract_float(conv[1].price) == extract_float(conv[0].price) + 2
```

### Explanation:
- **name**: This is the name of the rule, which you've specified as "drink".
- **description**: A brief explanation of what the rule checks.
- **conversations**: This rule compares two conversations.
- **when**: This condition checks that the size and number of pizzas remain the same between the two conversations.
- **if**: This condition checks that the first conversation has no drink, while the second conversation has a drink.
- **then**: This asserts that the price of the second conversation (with the drink) is exactly 2 dollars more than the first conversation (without the drink).
