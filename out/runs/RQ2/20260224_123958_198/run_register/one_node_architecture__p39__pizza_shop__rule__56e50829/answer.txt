Sure! To create a rule that checks if the order ID was provided by the chatbot, you can use the following YAML structure. This rule will verify that the `order_id` field is not empty in the chatbot's output.

Here's how you can set it up:

```yaml
name: order_id_provided
description: Ensures that the chatbot provides an order ID in the response.
conversations: 1
oracle: order_id is not None
```

In this rule:

- **name**: A descriptive name for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to 1 since we are checking a single conversation.
- **oracle**: This checks that the `order_id` is not `None`, ensuring that the chatbot has provided an order ID.

Feel free to adjust the description or any other part to better fit your project's needs! 😊
