Connectors are used to facilitate communication between your chatbot and external APIs. They allow your chatbot to send messages, receive responses, and interact with various services seamlessly. This is particularly useful for integrating functionalities like ordering, booking, or retrieving information from different platforms.

### Key Fields in a Connector Configuration:

1. **name**: A friendly name for your chatbot connector. This helps identify it easily.

2. **base_url**: The base URL of the chatbot API. This is the starting point for all API requests.

3. **send_message**: This section contains details about how to send a message to the chatbot API:
   - **path**: The specific endpoint path that will be appended to the base URL for sending messages.
   - **method**: The HTTP method to use (e.g., POST, GET). If not specified, POST is the default.
   - **headers**: Any custom headers that need to be included in the request (e.g., for authentication).
   - **payload_template**: The structure of the message being sent, often including a placeholder for the user's message (e.g., `{user_msg}`).

4. **response_path**: This field specifies how to extract the bot's reply from the JSON response received from the API. It uses dot notation to navigate through the response structure.

### Example of a Simple Connector Configuration:

```yaml
name: "My Custom Bot"
base_url: "https://api.mychatbot.com"
send_message:
  path: "/chat"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

This configuration allows your chatbot to send messages to the specified API and extract the response text for further processing. If you have any more questions or need further clarification, feel free to ask! 😊
