In the context of Sensei-check, an **oracle** is a mechanism used to verify the correctness of the outputs generated by your chatbot during testing. It acts as a reference or a standard against which the chatbot's responses can be evaluated.

There are two main types of oracles in Sensei-check:

1. **Single-conversation oracles**: These check the correctness of a single conversation's output. For example, you might want to ensure that a specific response contains certain expected information.

2. **Metamorphic oracles**: These are used for comparing multiple conversations. They help verify that certain relationships or properties hold true across different outputs. For instance, if two conversations have the same input conditions, the oracle might assert that one output should be greater than the other based on specific criteria.

In summary, oracles help ensure that your chatbot behaves as expected by providing a way to validate its responses against defined criteria. If you have more specific questions about how to implement or use oracles in your Sensei project, feel free to ask! 😊
