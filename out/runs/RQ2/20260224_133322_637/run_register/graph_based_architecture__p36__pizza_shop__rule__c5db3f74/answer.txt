Sure! To create a rule that checks if the price of a small pizza is $10, you can follow the structure of a single-conversation oracle in Sensei-check. Here’s how you can write it in YAML format:

```yaml
name: small_pizza_price_check
description: Small pizzas should cost exactly $10
conversations: 1
when: size == 'small'
oracle: extract_float(price) == 10 and currency(price) == 'USD'
```

### Breakdown:
- **name**: A unique identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to 1 because this is a single-conversation oracle.
- **when**: This condition checks if the pizza size is 'small'.
- **oracle**: This checks that the extracted price is exactly $10 and that the currency is USD.
