¡Claro! Aquí tienes un perfil de ejemplo para probar el chatbot de una pizzería. Este perfil incluye los campos de salida que mencionaste: tipo de pizza, bebida, ID del pedido y precio final en dólares. Puedes copiarlo y ajustarlo según tus necesidades 😊.

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer ordering pizza and drinks."
  context:
    - "You want to order a pizza and a drink for delivery."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Select a {{drink_type}} to go with the pizza."
    - "Ask for the total price."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Vegetarian, BBQ Chicken]
    - drink_type:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Can you please repeat?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink_type:
        type: string
        description: "The type of drink ordered."
    - order_id:
        type: string
        description: "The unique identifier for the order."
    - total_price:
        type: currency
        description: "The final price of the order in dollars."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 10
  interaction_style:
    - random:
      - long phrases
      - single questions
```

Este perfil simula a un cliente que quiere pedir una pizza y una bebida, y el chatbot debe responder con el tipo de pizza, la bebida seleccionada, el ID del pedido y el precio total. ¡Espero que te sea útil! Si necesitas más ajustes o detalles, no dudes en decírmelo. 🍕🥤
