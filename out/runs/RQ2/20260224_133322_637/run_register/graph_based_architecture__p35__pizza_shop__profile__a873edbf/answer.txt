```yaml
test_name: "custom_to_predefined_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer who initially wants a custom pizza but changes their mind."
  context:
    - "You are planning a pizza night with friends and want to customize your pizza."
    - "Halfway through, you decide to go for a predefined pizza instead."
  goals:
    - "I would like to order a custom pizza with {{custom_toppings}}."
    - "Actually, can I get a {{predefined_pizza}} instead?"
    - custom_toppings:
        function: random()
        type: string
        data: [pepperoni, mushrooms, olives, extra cheese, bell peppers]
    - predefined_pizza:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, BBQ Chicken, Vegetarian]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't quite catch that. Can you please repeat?"
  output:
    - order_confirmation:
        type: string
        description: "Confirmation of the pizza order, whether custom or predefined."

conversation:
  number: 2
  goal_style:
    all_answered:
      export: true
      limit: 10
  interaction_style:
    - change your mind
    - long phrases
```

### Explanation:
- **User Role & Context**: The user is a customer who starts with a custom pizza request and then changes their mind.
- **Goals**: The user has two main goals: to order a custom pizza and then switch to a predefined pizza.
- **Custom Toppings & Predefined Pizza**: These are defined with random selections to add variability.
- **Chatbot Output**: The chatbot will confirm the order based on the user's final choice.
- **Conversation Control**: The interaction style includes the ability to change their mind, which is key to your scenario!
