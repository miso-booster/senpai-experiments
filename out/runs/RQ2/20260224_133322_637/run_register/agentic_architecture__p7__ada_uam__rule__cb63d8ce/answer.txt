### Rule Overview
The rule will check if the chatbot's outputs for the contact email, phone number, and physical address match the expected values.

### Expected Outputs
- **Contact Email**: cau@uam.es
- **Contact Phone**: 91 497 4029
- **Physical Address**: Higher Polytechnic School, C/ Francisco Tomás y Valiente nº 11, Building B, first floor, office TI-107

### Proposed YAML for the Rule
Here's how the rule could look in YAML format:

```yaml
name: check_cau_information
description: Checks that the chatbot provides the correct information about the CAU
conversations: 1
oracle: |
  conv[0].contact_email == 'cau@uam.es' and
  conv[0].contact_phone == '91 497 4029' and
  conv[0].physical_address == 'Higher Polytechnic School, C/ Francisco Tomás y Valiente nº 11, Building B, first floor, office TI-107'
```

### Explanation
- **name**: A unique identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to `1` since we are checking a single conversation.
- **oracle**: This is the condition that must be true for the rule to pass. It checks if the outputs match the expected values.
