Let's create a profile for the UAM chatbot that represents a user seeking support related to the CAU (User Support Center). This profile will include the necessary fields to extract the CAU's phone number, email address, physical location, and opening hours.

### Profile Structure

Here's how the profile will be structured:

- **Test Name**: A descriptive name for the profile.
- **User Information**: Language, role, context, and goals.
- **Chatbot Output**: Fields to extract the required information.
- **Conversation Controls**: How the conversation will be structured.

### YAML Profile

Here's the YAML representation of the profile:

```yaml
test_name: "CAU Support User"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "User seeking support from the CAU."
  context:
    - "The user wants to know the CAU's contact details."
  goals:
    - "Obtain the CAU's phone number."
    - "Obtain the CAU's email address."
    - "Obtain the CAU's physical location."
    - "Obtain the CAU's opening hours."

chatbot:
  is_starter: false
  fallback: "Lo siento, no pude encontrar esa información."
  output:
    - phone_number:
        type: string
        description: "Número de teléfono del CAU."
    - email_address:
        type: string
        description: "Dirección de correo electrónico del CAU."
    - physical_location:
        type: string
        description: "Ubicación física del CAU."
    - opening_hours:
        type: string
        description: "Horas de apertura del CAU."

conversation:
  number: 1
  goal_style:
    steps: 4
  interaction_style:
    - random:
      - single questions
      - long phrases
```

### Summary

- **Profile Name**: `CAU Support User`
- **Outputs**: Includes fields for phone number, email address, physical location, and opening hours.
- **Language**: Set to Spanish, as the user is likely to communicate in that language.
