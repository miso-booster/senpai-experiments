Great question! 😊 In the context of Sensei, a **metamorphic rule** is a specific type of rule used in **Sensei-check** to verify the correctness of conversations generated by your chatbot. 

Here's a simple breakdown:

1. **Definition**: A metamorphic rule states a condition that checks how outputs should change (or remain the same) when inputs change across pairs or tuples of conversations. This helps in alleviating the oracle problem by focusing on relationships between outputs rather than just absolute answers.

2. **Types of Checks**: Metamorphic rules can target:
   - A **single conversation** (traditional checks).
   - **Several conversations** (the essence of metamorphic testing).
   - **All conversations** (global checks).

3. **How It Works**:
   - You start by generating conversations with your chatbot using Sensei.
   - Then, you write rules in YAML format specifying how many conversations to check, any filters for selecting conversations, and the relationships to verify.
   - Sensei-check evaluates these rules and reports any failures.

For example, a metamorphic rule might check that if two pizzas have the same size and drink, the one with more toppings should cost more. This kind of rule helps ensure that your chatbot behaves consistently and correctly across different scenarios! 🍕✨
