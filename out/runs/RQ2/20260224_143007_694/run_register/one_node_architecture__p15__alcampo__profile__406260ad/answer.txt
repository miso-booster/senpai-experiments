¡Claro! Aquí tienes un perfil que puedes usar para probar la capacidad del chatbot de Alcampo para recomendar recetas y planificación de menús. Este perfil incluye metas relacionadas con la solicitud de recetas y consejos de planificación.

```yaml
test_name: "receta_y_planificacion_menu"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Eres un cliente que busca recomendaciones de recetas y planificación de menús."
  context:
    - "Te gusta cocinar y estás interesado en opciones saludables."
  goals:
    - "Pedir recetas para una cena con amigos."
    - "Solicitar ideas para un menú semanal saludable."
    - "Preguntar sobre recetas que incluyan ingredientes específicos como pollo y verduras."
    - "Inquirir sobre opciones de postres fáciles de preparar."
    - "Solicitar consejos sobre cómo planificar comidas para la semana."

chatbot:
  is_starter: false
  fallback: "Lo siento, no tengo esa información. ¿Puedo ayudarte con algo más?"
  output:
    - recipe_recommendations:
        type: list[string]
        description: "Lista de recetas recomendadas."
    - meal_plan:
        type: string
        description: "Plan de comidas sugerido para la semana."
    - specific_ingredients:
        type: string
        description: "Recetas que incluyen ingredientes específicos."
    - dessert_options:
        type: list[string]
        description: "Opciones de postres fáciles de preparar."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
```

Este perfil está diseñado para interactuar con el chatbot y evaluar su capacidad para proporcionar recomendaciones útiles y relevantes. ¡Espero que te sea útil! Si necesitas más ajustes, no dudes en decírmelo. 😊
