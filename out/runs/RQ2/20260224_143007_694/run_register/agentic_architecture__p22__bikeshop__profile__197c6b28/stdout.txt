### Profile Structure Overview
Here's a quick breakdown of the key sections we'll include in the profile:

- **test_name**: A name for the profile.
- **llm**: Configuration for the language model (optional).
- **user**: Defines the user's language, role, context, and goals.
- **chatbot**: Specifies the chatbot's behavior and the outputs we want to extract.
- **conversation**: Controls the flow of the conversation, including the number of interactions and styles.
