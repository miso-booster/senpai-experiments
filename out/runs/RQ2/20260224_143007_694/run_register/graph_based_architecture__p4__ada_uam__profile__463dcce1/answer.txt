¡Claro! Estoy aquí para ayudarte a crear un perfil para tu chatbot de la UAM. Vamos a estructurarlo para que el usuario pueda obtener soporte sobre el CAU y conseguir la información que necesitas.

Aquí tienes un ejemplo de cómo podría verse tu perfil en formato YAML:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita soporte del Centro de Atención a Usuarios (CAU)."
  context:
    - "Buscas información sobre cómo contactar al CAU para resolver dudas."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico de contacto del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar sobre los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU."
    - contact_email:
        type: string
        description: "Correo electrónico de contacto del CAU."
    - physical_address:
        type: string
        description: "Dirección física del CAU."
    - service_hours:
        type: string
        description: "Horarios de atención del CAU."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

### Desglose del perfil:
- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje, como la temperatura y el modelo.
- **user**: Define el rol del usuario y sus metas.
- **chatbot**: Incluye la respuesta de fallback y los campos de salida que deseas extraer.
- **conversation**: Controla el número de interacciones y el estilo de interacción.

Puedes ajustar los detalles según sea necesario, pero este es un buen punto de partida. ¡Espero que te ayude! Si necesitas más cambios o tienes preguntas, ¡dímelo! 😊
