A metamorphic rule in the context of Sensei is a type of rule that helps ensure the consistency and correctness of chatbot behavior by defining relationships between different outputs or states. These rules are particularly useful for validating that the chatbot maintains certain properties across different interactions or contexts.

### Key Features of Metamorphic Rules:
- **Consistency Checks**: They verify that if certain inputs lead to specific outputs, then related inputs should lead to related outputs.
- **State Relationships**: They can define how changes in one part of the conversation affect other parts, ensuring that the chatbot behaves logically and coherently.
- **Validation**: Metamorphic rules can be used to test the chatbot's responses against expected outcomes, helping to identify inconsistencies or errors in the logic.

For example, if a chatbot is designed to handle order processing, a metamorphic rule might state that if an order is confirmed, the status should not revert to "pending" without a valid reason.
