```yaml
test_name: "Soporte CAU UAM"

  is_starter: false
  fallback: "Lo siento, no pude encontrar esa información. ¿Puedes reformular tu pregunta?"
  output:
    - contact_email:
        type: string
        description: "Correo electrónico del CAU"
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string

  goal_style:
    steps: 4
  interaction_style:

    - single questions
```

### Explicación del perfil:
- **test_name**: Nombre del perfil para identificarlo.
- **llm**: Configuración del modelo de lenguaje que se utilizará.
- **user**: Describe el rol del usuario y sus objetivos.
- **chatbot**: Define la salida que se espera del chatbot, incluyendo los campos que se quieren extraer.
- **conversation**: Controla el número de conversaciones y el estilo de interacción.
