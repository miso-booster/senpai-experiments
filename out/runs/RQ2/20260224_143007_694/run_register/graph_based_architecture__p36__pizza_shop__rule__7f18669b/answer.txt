Sure! To create a rule that checks if the price of a small pizza is $10, we can define it using the Sensei-check format. Here's how it would look:

```yaml
name: small_pizza_price_check
description: Small pizzas should cost exactly $10
conversations: 1
when: size == 'small'
oracle: extract_float(price) == 10 and currency(price) == 'USD'
```

### Breakdown:
- **name**: A unique identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: This rule checks a single conversation.
- **when**: This condition specifies that the rule applies when the pizza size is 'small'.
- **oracle**: This checks that the extracted price is exactly $10 in USD.
