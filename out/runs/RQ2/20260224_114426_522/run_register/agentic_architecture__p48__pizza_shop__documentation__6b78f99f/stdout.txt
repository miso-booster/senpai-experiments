A metamorphic rule in the context of Sensei is a type of rule that allows you to define conditions and actions based on the outputs of the chatbot. These rules are particularly useful for ensuring that the chatbot behaves consistently across different interactions and scenarios.

### Key Features of Metamorphic Rules:
- **Dynamic Conditions**: They can evaluate the current state or outputs of the chatbot and adjust the behavior accordingly.
- **Context Awareness**: Metamorphic rules can take into account previous interactions or specific user inputs to modify the chatbot's responses.
- **Flexibility**: They allow for complex logic that can adapt to various situations, making the chatbot more intelligent and responsive.

### Example Use Case:
For instance, if a user asks about a product, a metamorphic rule could check if the user has previously shown interest in similar products and tailor the response to highlight those products.
