Great! I've loaded the relevant documentation for creating a profile from the `sensei-chat-guide.md`. Now, let's create a profile that asks the chatbot for items to add to the user's shopping cart.

### Profile Structure
Here's a basic outline of what the profile will include:
- **Test Name**: A descriptive name for the profile.
- **User Role**: Defines the simulated user's behavior and context.
- **Goals**: Specifies what the user will ask for, such as items to add to the shopping cart.
- **Chatbot Output**: Defines what information we want to extract after the conversation.

### Proposed YAML Profile
Here's a sample YAML profile based on the structure outlined above:

```yaml
test_name: "shopping_cart_profile"

llm:
  temperature: 0.7
  model: "gpt-4o"
  model_prov: "openai"
  format:
    type: text

user:
  language: English
  role: "You are a customer looking to add items to your shopping cart."
  context:
    - "You can ask for various items like fruits, vegetables, or electronics."
  goals:
    - "Add {{item}} to my shopping cart."
    - item:
        function: random()
        type: string
        data: [apples, bananas, carrots, laptops, headphones]

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you please specify the item you want to add?"
  output:
    - cart_items:
        type: list[string]
        description: "List of items currently in the shopping cart."

conversation:
  number: 5
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Explanation
- **Test Name**: "shopping_cart_profile" gives a clear indication of the profile's purpose.
- **User Role**: Describes the simulated user as a customer wanting to add items to their cart.
- **Goals**: The user can ask to add various items, which are randomly selected from a predefined list.
- **Chatbot Output**: The output field `cart_items` will capture the list of items in the shopping cart.
