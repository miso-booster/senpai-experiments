¡Hola! 😊 Para crear una regla que compruebe si el asistente confirma que añadió la bebida que el usuario pidió, podemos usar la estructura de las reglas de Sensei-check. 

Aquí tienes un ejemplo de cómo podría verse esa regla:

```yaml
name: confirm_drink_added
description: El asistente debe confirmar que ha añadido la bebida solicitada por el usuario.
conversations: 1
if: utterance_index('user', 'quiero una bebida') >= 0
then: utterance_index('assistant', 'he añadido tu bebida') > 0
```

### Explicación:
- **name**: Un nombre descriptivo para la regla.
- **description**: Explica lo que se está comprobando.
- **conversations**: Indica que se está evaluando una sola conversación.
- **if**: Verifica si el usuario ha mencionado que quiere una bebida.
- **then**: Comprueba que el asistente confirme que ha añadido la bebida.

Recuerda ajustar las frases en `if` y `then` según las respuestas específicas que tu asistente utiliza. Si necesitas más ayuda o ajustes, ¡no dudes en decírmelo! 😊
