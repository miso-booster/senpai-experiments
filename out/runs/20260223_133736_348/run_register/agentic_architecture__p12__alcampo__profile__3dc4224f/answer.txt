Great! I've loaded the documentation related to SENSEI profiles from the `sensei-chat-guide.md`. Now, let's create a profile that allows the chatbot to ask the user for items to add to their shopping cart.

### Profile Structure

Here's a basic outline of what the profile will include:

- **Test Name**: A descriptive name for the profile.
- **User Role**: Describes the simulated user and their context.
- **Goals**: Defines what the user wants to achieve (e.g., adding items to the cart).
- **Chatbot Output**: Specifies what information should be extracted after the conversation.

### Proposed YAML Profile

Here's a sample YAML profile based on the structure we discussed:

```yaml
test_name: "shopping_cart_profile"

llm:
  temperature: 0.7
  model: "gpt-4o"
  model_prov: "openai"
  format:
    type: text

user:
  language: English
  role: "You are a customer shopping online. Ask for items to add to your cart."
  context:
    - "You are looking for groceries and household items."
  goals:
    - "Add {{item}} to my shopping cart."
    - item:
        function: random()
        type: string
        data: [milk, bread, eggs, detergent, shampoo]

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you please specify the item?"
  output:
    - cart_items:
        type: list[string]
        description: "List of items added to the shopping cart."

conversation:
  number: 5
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - single questions
      - long phrases
```

### Explanation of the Profile

- **Test Name**: "shopping_cart_profile" identifies the purpose of this profile.
- **User Role**: Sets the context for the simulated user as a customer shopping online.
- **Goals**: The user aims to add items to their cart, with the `item` variable randomly chosen from a predefined list.
- **Chatbot Output**: The `cart_items` field will capture the list of items added to the cart.
- **Conversation Control**: The chatbot will engage in 5 interactions, asking for items to add to the cart.
