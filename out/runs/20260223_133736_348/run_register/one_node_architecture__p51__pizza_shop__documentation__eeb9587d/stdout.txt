In the context of Sensei and conversational testing, an **oracle** is a mechanism or rule that helps determine whether the output of a chatbot is correct or meets certain expectations. It acts like a reference point or a standard against which the chatbot's responses can be evaluated.

In Sensei-check, oracles can be defined in two main ways:

1. **Single-conversation oracles**: These check the correctness of a response within a single conversation. For example, you might have a rule that states a pizza order must return a price that is greater than or equal to a certain amount.

2. **Metamorphic oracles**: These compare outputs across multiple conversations to check for consistency or expected relationships. For instance, if two orders have the same size and drink, the one with more toppings should cost more.

Oracles help ensure that the chatbot behaves as expected and can catch errors or inconsistencies in its responses. They are essential for validating the quality and reliability of the chatbot's performance. 😊
