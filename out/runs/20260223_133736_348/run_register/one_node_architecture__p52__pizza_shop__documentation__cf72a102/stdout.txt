Connectors are used to facilitate communication between your chatbot and external APIs. They help your chatbot send messages to and receive responses from various services, allowing for a seamless interaction experience. 

Here are the key fields typically included in a connector configuration:

| Field                     | Description                                                  | Required |
|---------------------------|--------------------------------------------------------------|----------|
| `name`                    | A friendly name for your chatbot.                           | No       |
| `base_url`               | The base URL of the chatbot API.                           | Yes      |
| `send_message.path`      | The API endpoint path (appended to `base_url`).            | Yes      |
| `send_message.method`    | The HTTP method (e.g., POST, GET, PUT, DELETE).            | No (default: POST) |
| `send_message.headers`    | Custom headers (e.g., Authorization).                       | No       |
| `send_message.payload_template` | The JSON structure with a placeholder for the user's message (e.g., `{user_msg}`). | Yes      |
| `response_path`          | A dot-separated path to extract the bot's reply from the JSON response. | Yes      |

These fields allow you to define how your chatbot interacts with external services, ensuring that it can send user messages and properly handle responses. If you have any specific questions about creating or configuring connectors, feel free to ask! 😊
