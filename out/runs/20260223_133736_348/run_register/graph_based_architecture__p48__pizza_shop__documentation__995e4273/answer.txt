A metamorphic rule in Sensei is a condition that you set to check the correctness of conversations generated by your chatbot. Unlike traditional testing methods that focus on absolute answers, metamorphic testing looks at the relationships between pairs or groups of conversations. 

Here's a simple breakdown of how it works:

1. **Generate Conversations**: First, you create conversations using Sensei-chat, which are stored along with their inputs (like pizza size) and outputs (like price).

2. **Write Rules**: You then write metamorphic rules in YAML format. Each rule specifies:
   - How many conversations it needs to check.
   - Any filters to select specific conversations (like comparing only those with the same pizza size).
   - The relationship that should hold true between the outputs of these conversations.

3. **Evaluate Rules**: When you run the rules, Sensei-check evaluates them against the generated conversations and reports any failures.

For example, a metamorphic rule might state that if two pizzas have the same size and drink, the one with more toppings should cost more. This helps ensure that your chatbot behaves consistently and correctly across different scenarios! 😊
