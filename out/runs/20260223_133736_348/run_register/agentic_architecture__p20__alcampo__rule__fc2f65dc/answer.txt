Let's create a rule to check if the chatbot provides information about current promotions. Since this rule is not based on any specific profile, we'll use general variables. Here's the YAML for the rule:

```yaml
name: check_promotions_info
description: The chatbot provides information about current promotions.
conversations: 1
oracle: |
  'promotions' in chatbot_phrases
```

### Explanation:
- **name**: A unique identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to 1, as this rule checks a single conversation.
- **oracle**: This checks if the word "promotions" is present in the chatbot's responses.

This rule is profile-agnostic and uses a simple check to see if the chatbot mentions promotions in its responses. If you need any modifications or additional features, feel free to ask! 😊
