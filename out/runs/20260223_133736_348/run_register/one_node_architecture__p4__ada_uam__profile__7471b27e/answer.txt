¡Claro! Estoy aquí para ayudarte a crear un perfil para testear el chatbot de la UAM y obtener la información que necesitas sobre el CAU. Aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Eres un usuario que busca información sobre el Centro de Atención a Usuarios (CAU)."
  context:
    - "Necesitas obtener el número de teléfono, correo electrónico, dirección física y horarios de atención del CAU."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico de contacto del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar sobre los horarios de atención del CAU."

chatbot:
  is_starter: true
  fallback: "Lo siento, no puedo ayudarte con eso."
  output:
    - contact_email:
        type: string
        description: "Correo electrónico del CAU"
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horas de servicio del CAU"

conversation:
  number: 1
  goal_style:
    steps: 4
  interaction_style:
    - long phrases
```

### Desglose del perfil:

- **test_name**: Nombre del perfil para identificarlo.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario y el contexto de la conversación.
- **goals**: Lista de objetivos que el usuario quiere alcanzar durante la conversación.
- **chatbot**: Define cómo el chatbot debe responder y qué información debe extraer.
- **conversation**: Controla el número de interacciones y el estilo de interacción.

Puedes ajustar los detalles según sea necesario. ¡Espero que esto te ayude a empezar! Si necesitas más cambios o detalles, no dudes en decírmelo 😊.
