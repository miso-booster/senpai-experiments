¡Claro! Aquí tienes un perfil para probar el chatbot de una pizzería. Este perfil incluye los campos que necesitas en el output: tipo de pizza, bebida, ID del pedido y precio final en dólares. Espero que te sirva 😊.

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza."
  context:
    - "You want to know about the available pizzas and drinks."
  goals:
    - "Order a pizza and a drink."
    - "Ask for the total price."
    - "Request the order ID."

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you repeat that?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink:
        type: string
        description: "The drink ordered."
    - order_id:
        type: string
        description: "The unique identifier for the order."
    - final_price:
        type: currency
        description: "The total price of the order in dollars."

conversation:
  number: 2
  goal_style:
    steps: 5
  interaction_style:
    - long phrases
    - make spelling mistakes
```

Si necesitas hacer algún ajuste o agregar más detalles, ¡no dudes en decírmelo! 🍕✨
