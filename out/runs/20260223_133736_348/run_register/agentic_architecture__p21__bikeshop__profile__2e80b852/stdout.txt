Great! I've loaded the relevant documentation for profiles from the `sensei-chat-guide.md`. Now, let's create a profile for a user who wants to set an appointment at a bike shop to have their wheels changed. This profile will include various variables to test different days and times.

### Profile Structure

Here's a proposed structure for the profile:

- **Test Name**: A descriptive name for the test.
- **User Role**: Describes the simulated user.
- **Goals**: Includes variables for the appointment date and time.
- **Chatbot Output**: Defines what information we want to extract after the conversation.

### Proposed YAML Profile

```yaml
test_name: "bike_shop_appointment"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer wanting to set an appointment to change bike wheels."
  context:
    - "The user is flexible with dates and times."
  goals:
    - "Schedule an appointment on {{appointment_date}} at {{appointment_time}}."
    - appointment_date:
        function: random()
        type: string
        data:
          - any(3 dates within the next 30 days)
    - appointment_time:
        function: random()
        type: string
        data:
          - "10:00 AM"
          - "1:00 PM"
          - "3:00 PM"

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you provide more details?"
  output:
    - appointment_confirmation:
        type: string
        description: "Confirmation of the scheduled appointment."

conversation:
  number: combinations(0.5, pairwise)
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Explanation

- **Test Name**: "bike_shop_appointment" for easy identification.
- **User Role**: Clearly states the user's intent.
- **Goals**: 
  - The first goal is to schedule an appointment with variables for date and time.
  - The `appointment_date` uses a random function to select dates within the next 30 days.
  - The `appointment_time` includes a few fixed options to test different times.
- **Chatbot Output**: We want to extract a confirmation message after the conversation.
- **Conversation Controls**: Allows for a combination of interactions to test various scenarios.
