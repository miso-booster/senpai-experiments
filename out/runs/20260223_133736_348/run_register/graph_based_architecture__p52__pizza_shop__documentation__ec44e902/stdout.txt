Connectors are used to facilitate communication between your chatbot and external APIs or services. They allow your chatbot to send messages to and receive responses from these services, enabling a wide range of functionalities, such as retrieving data, processing user requests, or integrating with other systems.

### Key Fields in a Connector

Here are the main fields typically found in a connector configuration:

1. **name**: A friendly name for your chatbot connector. This helps identify the connector in your project.

2. **base_url**: The base URL of the chatbot API. This is the root address that will be used to send requests.

3. **send_message**: This section defines how to send messages to the chatbot API. It includes:
   - **path**: The specific endpoint path that will be appended to the base URL for sending messages.
   - **method**: The HTTP method to use (e.g., POST, GET). If omitted, POST is usually the default.
   - **headers**: Any custom headers that need to be included in the request, such as authentication tokens.
   - **payload_template**: The structure of the JSON payload that will be sent in the request. It often includes a placeholder for the user's message (e.g., `{user_msg}`).

4. **response_path**: This field specifies how to extract the bot's reply from the JSON response received from the API. It uses dot notation to navigate through the response structure.

### Example of a Connector Configuration

Here's a simple example of what a connector configuration might look like:

```yaml
name: "My Custom Bot"
base_url: "https://api.mychatbot.com"
send_message:
  path: "/chat"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

In this example:
- The connector is named "My Custom Bot."
- It communicates with the API at `https://api.mychatbot.com/chat` using the POST method.
- The message sent to the bot will be structured with the user's message in the `message` field.
- The bot's response will be extracted from the `response.text` field in the JSON response.

Connectors are essential for integrating your chatbot with various services, enhancing its capabilities and providing a better user experience! If you have any more questions about connectors or anything else, feel free to ask! 😊
