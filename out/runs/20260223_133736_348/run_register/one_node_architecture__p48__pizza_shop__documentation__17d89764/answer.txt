Great question! 😊 In the context of Sensei, a **metamorphic rule** is a specific type of rule used in testing that states a condition to check over generated conversations. These rules are particularly useful because they allow you to compare pairs or tuples of conversations to see how outputs should change (or not) when inputs change.

Here's a simple breakdown of how it works:

1. **Generate Conversations**: First, you create conversations using Sensei-chat, which are stored with input selections and extracted outputs.

2. **Write Metamorphic Rules**: You then write these rules in YAML format. Each rule specifies:
   - How many conversations it needs to compare.
   - An optional filter to select eligible conversations.
   - The relationship you want to check between the outputs of those conversations.

3. **Evaluate the Rules**: Sensei-check evaluates these rules and reports any failing cases, helping you ensure that your chatbot behaves as expected across different scenarios.

For example, a metamorphic rule might state that if two pizza orders have the same size and drink, the order with more toppings should cost more. This way, you're checking the relationship between the inputs and outputs rather than just looking for absolute answers.

It's a powerful way to ensure your chatbot's responses are consistent and logical! If you need help writing a specific metamorphic rule, feel free to ask! 🍕✨
