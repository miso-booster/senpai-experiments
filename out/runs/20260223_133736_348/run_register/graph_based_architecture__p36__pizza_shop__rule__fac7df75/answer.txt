Sure! To create a rule that checks if the price of a small pizza is at least $10, you can use the following YAML structure:

```yaml
name: small_pizza_price_floor
description: Small pizzas should cost at least $10
conversations: 1
when: size == 'small'
oracle: extract_float(price) >= 10 and currency(price) == 'USD'
```

### Explanation:
- **name**: This is a unique identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to `1` because this is a single-conversation check.
- **when**: This condition checks if the pizza size is 'small'.
- **oracle**: This checks that the extracted price is at least $10 and that the currency is in USD.
