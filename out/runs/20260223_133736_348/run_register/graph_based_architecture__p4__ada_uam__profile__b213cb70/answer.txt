¡Claro! Estoy aquí para ayudarte a crear un perfil para probar el chatbot de la UAM y obtener soporte sobre el CAU. Vamos a estructurarlo de manera que cumpla con tus necesidades. Aquí tienes un ejemplo de perfil en YAML:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita información sobre el CAU."
  context:
    - "Buscas obtener detalles de contacto del Centro de Atención a Usuarios."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico de contacto del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar sobre los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "¿Me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico de contacto del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

### Explicación de cada sección:

- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje que se utilizará.
- **user**: Define el usuario simulado, su rol y contexto.
- **goals**: Las preguntas que el usuario hará al chatbot para obtener la información deseada.
- **chatbot**: Configuración del chatbot, incluyendo el mensaje de fallback y los campos de salida que se desean extraer.
- **conversation**: Controla la cantidad de interacciones y el estilo de la conversación.

Puedes ajustar los detalles según tus necesidades específicas. ¡Espero que esto te ayude a comenzar! Si necesitas más cambios o detalles, no dudes en decírmelo 😊.
