That sounds like a great profile to create! 😊 Let's outline a profile for a user who needs to visit the bike shop to customize their new bike by changing the seat and handlebar grips. Here’s a sample YAML profile you can use as a starting point:

```yaml
test_name: "bike_setup_customization"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer who recently bought a new bike and wants to customize it."
  context:
    - "You want to make your bike more comfortable by changing the seat and handlebar grips."
    - "You are unsure about the options available for seats and grips."
  goals:
    - "Ask about the available seat options for customization."
    - "Inquire about the handlebar grips available for my bike."
    - "Request information on the costs associated with changing the seat and grips."
    - "Ask for recommendations on the best seat and grips for comfort."
    - seat_options:
        function: default()
        type: string
        data: ["standard seat", "gel seat", "racing seat", "padded seat"]
    - grip_options:
        function: default()
        type: string
        data: ["foam grips", "rubber grips", "ergonomic grips", "cork grips"]

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you repeat that?"
  output:
    - seat_options_available:
        type: string
        description: "List of available seat options for customization."
    - grip_options_available:
        type: string
        description: "List of available handlebar grip options."
    - customization_cost:
        type: money
        description: "Total cost for changing the seat and grips."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 5
  interaction_style:
    - all questions
```

### Explanation of the Profile:
- **Role and Context**: The user is a customer looking to customize their new bike. The context provides background on their needs and uncertainties.
- **Goals**: The goals outline what the user wants to ask about, including seat and grip options, costs, and recommendations.
- **Chatbot Output**: This section defines what information the chatbot should provide in response to the user's inquiries.
- **Conversation Control**: The conversation is set to allow for a few interactions, focusing on single questions to keep things clear and concise.
