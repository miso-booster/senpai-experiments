¡Hola! 😊 He revisado la documentación sobre perfiles y estoy listo para ayudarte a crear un perfil para el chatbot de la UAM que proporcione soporte sobre el CAU (Centro de Atención a Usuarios). 

### Estructura del Perfil

El perfil debe incluir los siguientes elementos en la sección `chatbot.output` para capturar la información que deseas: número de teléfono, email, dirección física y horarios. Aquí tienes un ejemplo de cómo podría verse el perfil:

```yaml
test_name: "UAM_CAU_Support"

llm:
  temperature: 0.7
  model: "gpt-4o"
  model_prov: "openai"
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca soporte sobre el CAU de la UAM."
  context:
    - "El usuario necesita información sobre contacto y horarios del CAU."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Cuál es el email del CAU?"
    - "¿Dónde se encuentra físicamente el CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: true
  fallback: "Lo siento, no pude encontrar esa información."
  output:
    - telefono:
        type: string
        description: "Número de teléfono del CAU"
    - email:
        type: string
        description: "Email de contacto del CAU"
    - direccion:
        type: string
        description: "Dirección física del CAU"
    - horarios:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 1
  goal_style:
    steps: 4
  interaction_style:
    - default
```

### Desglose del Perfil

- **test_name**: Nombre del perfil para identificarlo.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el contexto y los objetivos del usuario.
- **chatbot**: 
  - `is_starter`: Si el chatbot inicia la conversación.
  - `fallback`: Mensaje de fallback en caso de no poder responder.
  - `output`: Campos que se extraerán al final de la conversación.
- **conversation**: Controla el número de interacciones y el estilo de interacción.

### Siguientes Pasos

1. **Revisar el perfil**: Asegúrate de que todos los campos y descripciones sean correctos.
2. **Crear el archivo**: Guarda este contenido en un archivo YAML en la carpeta de perfiles de tu proyecto.
3. **Ejecutar pruebas**: Usa el perfil para probar el chatbot y validar que responde correctamente a las consultas sobre el CAU.
