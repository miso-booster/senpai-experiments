In the context of Sensei, a metamorphic rule is a type of rule that allows you to define relationships between different outputs or states of a chatbot. These rules are designed to ensure that the chatbot behaves consistently and logically across various interactions. 

### Key Features of Metamorphic Rules:
- **Conditional Logic**: They often use conditions to determine when certain outputs should occur based on previous interactions or outputs.
- **State Management**: Metamorphic rules can help manage the state of a conversation, ensuring that the chatbot responds appropriately based on the context established by earlier exchanges.
- **Output Relationships**: They can specify how different outputs relate to each other, ensuring coherence in the chatbot's responses.

### Example Use Case:
For instance, if a user is ordering a pizza, a metamorphic rule might ensure that if the user has selected "extra cheese," the chatbot should not suggest "no cheese" in subsequent messages.
