¡Claro! Aquí tienes un perfil de ejemplo para probar el chatbot de una pizzería. Este perfil incluye el output que mencionaste: tipo de pizza, bebida, ID del pedido y precio final en dólares. Puedes ajustar los detalles según tus necesidades 😊.

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer ordering pizza and drinks."
  context:
    - "You want to order a pizza and a drink for delivery."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Select a drink: {{drink_type}}."
    - "Confirm the order."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Vegetarian, BBQ Chicken]
    - drink_type:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Can you please rephrase?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink_type:
        type: string
        description: "The drink selected."
    - order_id:
        type: string
        description: "A unique identifier for the order."
    - total_price:
        type: currency
        description: "Final price in dollars."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 10
  interaction_style:
    - random:
      - long phrases
      - single questions
```

Este perfil está diseñado para simular una conversación en la que el usuario pide una pizza y una bebida, y al final, extrae la información necesaria. ¡Espero que te sea útil! Si necesitas más ajustes o detalles, no dudes en decírmelo. 🍕🥤
