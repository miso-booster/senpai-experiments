Sure! To create a rule that checks if the order ID is provided by the chatbot, you can use a single-conversation oracle. Here's how you can structure it in YAML:

```yaml
name: order_id_provided
description: The chatbot must return an order ID in the response.
conversations: 1
oracle: "'order_id' in data_output"
```

### Breakdown:
- **name**: This is a unique identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to 1, since this rule is checking a single conversation.
- **oracle**: This checks if the `order_id` field is present in the chatbot's output.
