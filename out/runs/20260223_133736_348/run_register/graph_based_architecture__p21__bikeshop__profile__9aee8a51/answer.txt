Sure! Let's create a profile for a user who wants to set an appointment to have their wheels changed at a bike shop. This profile will include variables for different dates and times to thoroughly test how the chatbot manages appointments. Here’s a sample YAML profile for you:

```yaml
test_name: "wheel_change_appointment"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer looking to set an appointment for changing bike wheels."
  context:
    - "You want to ensure your bike is ready for the upcoming season."
    - "You have a flexible schedule and can choose from various dates and times."
  goals:
    - "Schedule an appointment for wheel change on {{appointment_date}} at {{appointment_time}}."
    - appointment_date:
        function: random()
        type: string
        data: [tomorrow, 'November 6th, 2024', 'next Monday', 'next Saturday', 'in two days']
    - appointment_time:
        function: random()
        type: string
        data: ['10:00 AM', '2:00 PM', '3:30 PM', '11:30 AM', '1:00 PM']

chatbot:
  is_starter: true
  fallback: "I'm sorry, it's a little loud in my shop, can you say that again?"
  output:
    - confirmed_date:
        type: date
        description: "The confirmed date for the appointment."
    - confirmed_time:
        type: string
        description: "The confirmed time for the appointment."
    - appointment_confirmation:
        type: string
        description: "Confirmation message for the scheduled appointment."

conversation:
  number: 5
  goal_style:
    all_answered:
      export: true
      limit: 5
  interaction_style:
    - default
```

### Breakdown of the Profile:
- **Test Name**: A descriptive name for the profile.
- **User Role**: Describes the user as someone looking to set an appointment for a wheel change.
- **Goals**: Includes a goal to schedule an appointment with variables for the date and time.
- **Variables**:
  - `appointment_date`: Randomly selects from a list of potential dates.
  - `appointment_time`: Randomly selects from a list of potential times.
- **Chatbot Output**: Specifies what the chatbot should confirm after the appointment is scheduled.
- **Conversation Controls**: Sets the number of conversations and how the goals should be handled.
