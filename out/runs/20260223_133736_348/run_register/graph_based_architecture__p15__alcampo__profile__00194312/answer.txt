¡Claro! Aquí tienes un perfil que puedes usar para probar la capacidad del chatbot de Alcampo en recomendar recetas y planificación de menús. Este perfil está diseñado para simular un usuario que busca ideas de recetas y ayuda con la planificación de comidas:

```yaml
test_name: "Recetas y Planificación de Menús"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A user looking for recipe recommendations and meal planning assistance."
  context:
    - "You are interested in healthy and easy-to-make recipes."
    - "You want to incorporate seasonal ingredients into your meals."
    - "You are looking for tips on meal prep and planning for the week."
  goals:
    - "Suggest a recipe for a healthy dinner using {{seasonal_ingredient}}."
    - "Provide a meal plan for the week that includes breakfast, lunch, and dinner."
    - "Recommend some quick snacks for busy days."
    - "Ask for tips on how to meal prep effectively."
    - seasonal_ingredient:
        function: random()
        type: string
        data: [carrots, spinach, tomatoes, zucchini, bell peppers]

chatbot:
  is_starter: false
  fallback: "Lo siento, no entendí tu pregunta. ¿Puedes reformularla? Estoy aquí para ayudarte con recetas y planificación de menús."
  output:
    - recipe:
        type: string
        description: "Recipe suggestion based on the user's request."
    - meal_plan:
        type: string
        description: "Weekly meal plan including all meals."
    - snack_recommendations:
        type: string
        description: "Suggestions for quick snacks."
    - meal_prep_tips:
        type: string
        description: "Tips for effective meal preparation."

conversation:
  number: 3
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```

### Explicación de los componentes:
- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje que se utilizará.
- **user**: Define el rol del usuario, su contexto y los objetivos que quiere lograr.
- **chatbot**: Define cómo debe comportarse el chatbot, incluyendo su mensaje de fallback y los tipos de salida que se esperan.
- **conversation**: Controla el número de interacciones y el estilo de interacción.

Puedes ajustar los ingredientes estacionales y las metas según tus necesidades específicas. ¡Espero que esto te ayude a probar el chatbot de Alcampo! Si necesitas más ajustes o tienes alguna otra pregunta, ¡no dudes en decírmelo! 😊
