A metamorphic rule in the context of Sensei is a type of validation logic that checks relationships or properties across multiple conversations rather than just within a single conversation. These rules are useful for ensuring consistency and correctness in the behavior of a chatbot over a series of interactions.

### Key Features of Metamorphic Rules:
- **Cross-Conversation Validation**: Unlike standard rules that focus on individual conversations, metamorphic rules assess how outputs or behaviors relate across different conversation instances.
- **Implication Logic**: They often use an implication structure (if/then) to define conditions that should hold true across multiple conversations.
- **Use of Extracted Outputs**: Metamorphic rules can reference outputs extracted from conversations, allowing for checks on consistency, completeness, or other properties that span multiple interactions.

### Example Use Cases:
- Ensuring that if a user asks for the same information in different conversations, the chatbot provides consistent answers.
- Validating that certain user intents lead to expected changes in the chatbot's behavior across multiple sessions.

These rules help maintain the integrity and reliability of chatbot interactions over time, making them an essential part of the validation framework in Sensei.
