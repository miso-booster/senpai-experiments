¡Claro! Aquí tienes un perfil de ejemplo para probar el chatbot de una pizzería. Este perfil incluye los campos que mencionaste: tipo de pizza, bebida, ID del pedido y precio final en dólares. Puedes copiar y pegar esto en un archivo YAML en la carpeta `profiles/` de tu proyecto.

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza and drinks from a pizzeria."
  context:
    - "You want to order a pizza and a drink for delivery."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Select a {{drink_type}}."
    - "Ask for the total price."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Vegetarian, Hawaiian, BBQ Chicken]
    - drink_type:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: true
  fallback: "I'm sorry, I didn't understand that. Can you please repeat?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink_type:
        type: string
        description: "The type of drink ordered."
    - order_id:
        type: string
        description: "Unique identifier for the order."
    - total_price:
        type: currency
        description: "Final price of the order in dollars."

conversation:
  number: 1
  goal_style:
    steps: 3
  interaction_style:
    - long phrases
```

### Explicación de los campos:
- **test_name**: Nombre del perfil para identificarlo fácilmente.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario y sus objetivos, incluyendo la selección aleatoria de tipos de pizza y bebida.
- **chatbot**: Define la salida esperada del chatbot, incluyendo el tipo de pizza, bebida, ID del pedido y precio total.
- **conversation**: Controla el número de interacciones y el estilo de conversación.
