¡Hola! 😊 Vamos a crear algunas reglas para probar tu perfil "Usuarios Nuevos y Admisiones". Este perfil está diseñado para simular a un estudiante potencial que busca información sobre el proceso de admisión y recursos disponibles. Aquí tienes algunas sugerencias de reglas que podrías implementar:

### 1. Regla de Compleción de Campos
**Descripción:** Verifica que todos los campos de salida del chatbot estén llenos después de una conversación.

```yaml
name: chatbot_fills_all_slots
description: Todos los campos de salida del chatbot deben estar llenos.
conversations: 1
active: true
oracle: data_collected() == True
yields: |
  f"Campos faltantes: {missing_slots()}"
```

### 2. Regla de Respuesta en el Mismo Idioma
**Descripción:** Asegura que el chatbot responda en español, ya que el usuario simulado tiene el idioma configurado en español.

```yaml
name: chatbot_responds_in_same_language
description: El chatbot responde en el mismo idioma que el usuario.
conversations: 1
active: true
oracle: responds_in_same_language()
yields: f"El chatbot no responde en el mismo idioma."
```

### 3. Regla de Información de Admisión
**Descripción:** Verifica que el chatbot proporcione información relevante sobre los grados disponibles cuando se le pregunte.

```yaml
name: admission_info_provided
description: El chatbot debe proporcionar información sobre los grados disponibles.
conversations: 1
active: true
oracle: conv[0].grados_available is not None
```

Estas reglas están diseñadas para validar que tu chatbot funcione correctamente y proporcione la información necesaria a los estudiantes potenciales. Puedes ajustar las descripciones y los nombres según sea necesario.
