Connectors in the Sensei framework are used to facilitate communication between your chatbot and external APIs. They define how to send messages to the chatbot and how to interpret the responses received. This is super helpful for testing and validating your chatbot's performance against real-world scenarios! 🌍

### Key Fields in a Connector

Here are the main fields you typically find in a connector configuration:

1. **name**: A friendly name for your connector. This helps you identify it easily.

2. **base_url**: The base URL of the chatbot API you are connecting to. This is the starting point for all API requests.

3. **send_message**: This section contains details about how to send a message to the chatbot:
   - **path**: The specific endpoint path that will be appended to the base URL for sending messages.
   - **method**: The HTTP method to use (e.g., POST, GET, etc.). The default is usually POST.
   - **headers**: Any custom headers that need to be included in the request (e.g., for authentication).
   - **payload_template**: The structure of the message you are sending, often including placeholders like `{user_msg}` for the user's input.

4. **response_path**: This defines how to extract the chatbot's reply from the JSON response you receive. It uses dot notation to navigate through the JSON structure.

### Example of a Connector

Here's a simple example to illustrate:

```yaml
name: "Echo Bot"
base_url: "https://postman-echo.com"
send_message:
  path: "/post"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "json.message"
```

In this example:
- The connector is named "Echo Bot."
- It connects to the Postman Echo API.
- It sends a message using the POST method and expects to receive the same message back in the response.
