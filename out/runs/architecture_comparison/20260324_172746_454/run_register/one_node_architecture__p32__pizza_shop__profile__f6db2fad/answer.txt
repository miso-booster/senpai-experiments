¡Claro! Aquí tienes un perfil de ejemplo para probar el chatbot de una pizzería. Este perfil incluye los campos que mencionaste en el `chatbot.output`. ¡Vamos a ello! 🍕✨

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  format:
    type: text

user:
  language: English
  role: "A customer ordering pizza and drinks."
  context:
    - "You are ordering a pizza for delivery."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Select a drink: {{drink}}."
    - "Confirm the order."

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Can you repeat your order?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink:
        type: string
        description: "The drink selected."
    - order_id:
        type: string
        description: "The unique identifier for the order."
    - final_price:
        type: currency
        description: "The total price of the order in dollars."

conversation:
  number: 1
  goal_style:
    steps: 3
  interaction_style:
    - long phrases
```

Este perfil está diseñado para simular una conversación donde el usuario ordena una pizza y una bebida, y el chatbot devuelve el tipo de pizza, la bebida, el ID del pedido y el precio final. ¡Espero que te sirva! Si necesitas más ajustes, no dudes en decírmelo. 😊
