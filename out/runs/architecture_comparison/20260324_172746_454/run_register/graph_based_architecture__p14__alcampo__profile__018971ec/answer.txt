¡Hola! 😊 Para crear un perfil que pruebe la capacidad del chatbot de Alcampo para recomendar recetas y planificación de menús, podemos basarnos en la estructura de un perfil de Sensei. Aquí tienes un ejemplo que podrías utilizar y ajustar según tus necesidades:

```yaml
test_name: "Recipe Recommendations and Menu Planning"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A user looking for recipe recommendations and assistance with meal planning."
  context:
    - "You are interested in healthy meals and seasonal ingredients."
    - "You want to explore new recipes that fit your dietary preferences."
  goals:
    - "Ask for recipe recommendations based on seasonal ingredients."
    - "Request a meal plan for a week that includes breakfast, lunch, and dinner."
    - "Inquire about healthy snack options."
    - "Ask for tips on meal prepping for the week."
    - "Request information on how to incorporate more vegetables into your meals."

chatbot:
  is_starter: false
  fallback: "Lo siento, no entendí tu pregunta. ¿Puedes reformularla? Estoy aquí para ayudarte con recetas y planificación de menús."
  output:
    - recipe_recommendations:
        type: string
        description: "Suggested recipes based on user preferences."
    - meal_plan:
        type: string
        description: "Weekly meal plan including breakfast, lunch, and dinner."
    - healthy_snacks:
        type: string
        description: "List of healthy snack options."
    - meal_prepping_tips:
        type: string
        description: "Tips for effective meal prepping."
    - vegetable_incorporation_tips:
        type: string
        description: "Suggestions for adding more vegetables to meals."

conversation:
  number: 5
  goal_style:
    steps: 20
  interaction_style:
    - single questions
```

### Desglose del perfil:
- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario y el contexto para guiar al chatbot.
- **goals**: Lista de objetivos que el usuario quiere lograr durante la conversación.
- **chatbot**: Configuración del chatbot, incluyendo un mensaje de fallback y los campos de salida que se quieren extraer.
- **conversation**: Controla el número de interacciones y el estilo de la conversación.

Puedes ajustar los detalles según tus preferencias y necesidades específicas. ¡Espero que esto te ayude a crear un perfil efectivo! Si necesitas más ajustes o detalles, ¡no dudes en decírmelo! 😊
