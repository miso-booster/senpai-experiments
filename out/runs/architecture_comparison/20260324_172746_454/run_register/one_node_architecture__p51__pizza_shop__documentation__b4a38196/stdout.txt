Connectors in Sensei are used to facilitate communication between your chatbot and external APIs. They define how to send messages to the chatbot and how to interpret the responses received. This is super helpful for testing and validating your chatbot's interactions with real-world services! 😊

### Key Fields in Connectors

Here are the main fields you typically find in a connector configuration:

1. **name**: A friendly name for your chatbot connector (e.g., "Ada UAM").

2. **base_url**: The base URL of the chatbot API you want to connect to.

3. **send_message**: This section describes how to send messages to the API:
   - **path**: The specific endpoint path (appended to the base URL).
   - **method**: The HTTP method to use (e.g., POST, GET).
   - **headers**: Any custom headers required for the request (like authorization).
   - **payload_template**: The structure of the message you send, often including placeholders like `{user_msg}` for the user's input.

4. **response_path**: A dot-separated path to extract the chatbot's reply from the JSON response. This tells the connector where to find the relevant information in the API's response.

### Example Structure

Here's a simple example of what a connector might look like:

```yaml
name: "My Custom Bot"
base_url: "https://api.mychatbot.com"
send_message:
  path: "/chat"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

This structure allows you to easily configure how your chatbot interacts with different APIs, making it flexible and adaptable for various testing scenarios! If you have any specific connectors in mind or need help with a particular configuration, feel free to ask! 😊
