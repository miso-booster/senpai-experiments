¡Claro! Para crear una regla que verifique si el asistente confirma que ha añadido la bebida que el usuario pidió, podemos utilizar la estructura de una regla de Sensei-check. Aquí te dejo un ejemplo de cómo podría ser esta regla:

```yaml
name: confirm_drink_added
description: El asistente debe confirmar que ha añadido la bebida solicitada por el usuario.
conversations: 1
if: utterance_index('user', 'quiero una bebida') >= 0
then: utterance_index('assistant', 'he añadido la bebida') > 0
```

### Explicación:
- **name**: Un nombre descriptivo para la regla.
- **description**: Una breve descripción de lo que comprueba la regla.
- **conversations**: Se establece en 1 porque estamos verificando una sola conversación.
- **if**: Comprueba si el usuario ha solicitado una bebida en algún momento de la conversación.
- **then**: Verifica que el asistente confirme que ha añadido la bebida después de que el usuario lo haya solicitado.

Recuerda adaptar las frases en `utterance_index` según las respuestas específicas que tu asistente utiliza. ¡Espero que esto te ayude! Si necesitas más ajustes o ejemplos, ¡no dudes en preguntar! 😊
