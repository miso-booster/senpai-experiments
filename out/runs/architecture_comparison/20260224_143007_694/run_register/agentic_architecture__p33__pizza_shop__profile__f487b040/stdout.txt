### Perfil para el Chatbot de Pizzería

Aquí tienes un ejemplo de cómo podría verse el perfil en YAML, incluyendo los campos que mencionaste: tipo de pizza, bebida, ID del pedido y precio final en dólares.

```yaml
test_name: "pizza_order_profile"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza."
  context:
    - "You want to order a pizza with a drink."
  goals:
    - "Order a {{pizza_type}} pizza with a {{drink}}."
    - "Ask for the total price."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Veggie, Hawaiian]
    - drink:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: false
  fallback: "Sorry, could you repeat that?"
  output:
    - pizza_type:
        type: string
        description: "Type of pizza ordered"
    - drink:
        type: string
        description: "Drink ordered"
    - order_id:
        type: string
        description: "Unique ID for the order"
    - total_price:
        type: currency
        description: "Final price in dollars"

conversation:
  number: combinations(0.5, pairwise)
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Descripción de los Campos

- **pizza_type**: El tipo de pizza que el usuario desea pedir.
- **drink**: La bebida que el usuario quiere con su pedido.
- **order_id**: Un identificador único para el pedido.
- **total_price**: El precio final del pedido en dólares.

Este perfil está diseñado para interactuar con el chatbot y extraer la información necesaria al final de la conversación.
