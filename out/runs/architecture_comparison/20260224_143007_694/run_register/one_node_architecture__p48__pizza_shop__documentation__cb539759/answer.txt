Great question! 😊 In the context of Sensei, a **metamorphic rule** is a specific type of rule used in **Sensei-check** that helps verify the correctness of conversations generated by your chatbot. 

Here's a simple breakdown:

1. **Definition**: A metamorphic rule states a condition to check over sets of conversations. It can target:
   - A **single** conversation (like traditional checks).
   - **Several** conversations (which is where metamorphic testing shines).
   - **All** conversations (for global checks).

2. **Purpose**: The main goal of metamorphic rules is to compare pairs or tuples of conversations that meet certain criteria. This allows you to assert how outputs should change (or remain the same) when inputs are modified. This approach helps alleviate the oracle problem, which is the challenge of determining the correctness of a system's output.

3. **How it Works**:
   - You first generate conversations using Sensei-chat.
   - Then, you write rules in YAML format that specify how many conversations are needed, any filters for selecting eligible conversations, and the relationships you want to check.
   - Finally, Sensei-check evaluates these rules and reports any failures.

For example, you might have a rule that states if two pizza orders have the same size and drink, the one with more toppings should cost more. This kind of testing helps ensure that your chatbot behaves as expected under different scenarios! 🍕✨
