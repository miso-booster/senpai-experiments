This rule ensures that all necessary outputs are generated after a conversation.

```yaml
name: check_required_outputs
description: Ensure all required outputs are provided after the conversation
conversations: 1
oracle: data_collected() == True
yields: f"Missing outputs: {missing_slots()}"
```

### 2. Validate Admission Links
This rule checks that the admission link is provided when a user asks about the admission process.

```yaml
name: validate_admission_link
description: Admission link should be provided when asking about admission processes
conversations: 1

oracle: admission_to_grados_link != ""
```
