In the context of Sensei-check, an **oracle** is a mechanism that helps verify the correctness of the outputs generated by your chatbot during testing. It acts as a reference or a standard against which the chatbot's responses can be compared.

Oracles can be used in two main ways:

1. **Single-conversation oracles**: These check the correctness of a response based on the input of a single conversation. For example, you might specify that a certain output must include a specific keyword or value.

2. **Metamorphic oracles**: These compare outputs from multiple conversations to ensure that they maintain expected relationships. For example, if two conversations have the same input conditions, the oracle might assert that one output should be greater than the other based on certain criteria.

In essence, oracles help ensure that your chatbot behaves as expected and provides accurate, reliable responses! If you have more specific questions or need help with writing oracles, feel free to ask! 😊
