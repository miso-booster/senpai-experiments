### Profile Structure

Here's a basic outline of what the profile will include:

- **Test Name**: A descriptive name for the profile.
- **LLM Settings**: Configuration for the language model.
- **User Role**: Description of the simulated user's role and context.
- **Goals**: Specific goals for the user, including asking for items to add to the shopping cart.
- **Chatbot Output**: Fields that will be extracted after the conversation.

### Proposed YAML Profile

Here’s a sample YAML profile for your shopping cart scenario:

```yaml
test_name: "shopping_cart_profile"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer looking to add items to your shopping cart."
  context:
    - "You can ask for various items like fruits, vegetables, and household products."
  goals:
    - "Add {{item}} to my shopping cart."
    - item:
        function: random()
        type: string
        data: [apples, bananas, milk, bread, eggs]

chatbot:
  is_starter: true
  fallback: "I'm sorry, I didn't understand that. Could you please specify an item?"
  output:
    - added_item:
        type: string
        description: "The item that was added to the shopping cart."
    - cart_total:
        type: float
        description: "Total cost of the items in the shopping cart."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Explanation

- **Goals**: The user will randomly ask to add items like apples, bananas, etc., to their shopping cart.
- **Chatbot Output**: The profile captures the added item and the total cost of the cart.
- **Interaction Style**: The user can interact in various ways, such as using long phrases or single questions.
