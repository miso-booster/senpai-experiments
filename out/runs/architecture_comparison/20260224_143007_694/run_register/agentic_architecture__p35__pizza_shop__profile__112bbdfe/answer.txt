I've successfully loaded the relevant documentation for profiles from the `sensei-chat-guide.md`. Now, let's outline the profile for your pizza ordering scenario where the user can change their mind during the conversation.

### Profile Structure
Here's a basic outline of how the profile will be structured:

1. **Test Name**: A descriptive name for the profile.
2. **User**:
   - **Language**: The language the user will communicate in.
   - **Role**: A description of the user's intention (e.g., ordering pizza).
   - **Context**: Any specific context or personality traits.
   - **Goals**: The different goals the user might have during the conversation, including ordering a custom pizza and switching to a predefined one.
3. **Chatbot**:
   - **Output**: The fields that will be extracted at the end of the conversation (e.g., order details).
4. **Conversation**:
   - **Number**: How many interactions will occur.
   - **Goal Style**: How the conversation will progress.
   - **Interaction Style**: The style of interaction, including the ability to change opinions.

### Drafting the Profile YAML
Now, let’s create the YAML for this profile! Here’s a draft:

```yaml
test_name: "Pizza Order Change of Mind"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer who wants to order a pizza. You start by asking for a custom pizza but may change your mind to a predefined option."
  context:
    - "You enjoy trying different pizzas."
  goals:
    - "Order a custom pizza with {{toppings}} and {{size}}."
    - "Switch to a predefined pizza: {{predefined_pizza}}."
    - toppings:
        function: random()
        type: string
        data: [pepperoni, mushrooms, onions, sausage, bacon, extra cheese]
    - size:
        function: random()
        type: string
        data: [small, medium, large]
    - predefined_pizza:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Veggie]

chatbot:
  is_starter: true
  fallback: "Sorry, could you clarify your order?"
  output:
    - order_details:
        type: string
        description: "Details of the pizza order including size and toppings."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - change your mind
```

### Summary of the Profile
- **Test Name**: "Pizza Order Change of Mind"
- **User Goals**: The user can request a custom pizza and has the option to switch to a predefined pizza.
- **Chatbot Output**: The order details will be extracted at the end of the conversation.
