He cargado la documentación sobre perfiles, que se encuentra en el archivo `sensei-chat-guide.md`. Esta guía proporciona información sobre cómo estructurar un perfil para definir el comportamiento del chatbot y qué campos incluir en la sección `chatbot.output`.

### Estructura del Perfil
Para crear un perfil que permita al chatbot de Alcampo recomendar recetas y planificar menús, aquí hay un esquema básico que podemos seguir:

```yaml
test_name: "Alcampo Recipe Recommendation"

llm:
  temperature: 0.7
  model: "gpt-4o"
  model_prov: "openai"
  format:
    type: text

user:
  language: Spanish
  role: "Eres un usuario que busca recomendaciones de recetas y planificación de menús."
  context:
    - "Prefieres recetas saludables y rápidas."
  goals:
    - "Recomiéndame una receta con {{ingredient}}."
    - "Ayúdame a planificar un menú para {{days}} días."
    - ingredient:
        function: random()
        type: string
        data: [pollo, pescado, verduras, pasta]
    - days:
        function: random()
        type: int
        data:
          min: 1
          max: 7

chatbot:
  is_starter: true
  fallback: "Lo siento, no entiendo. ¿Puedes reformular tu pregunta?"
  output:
    - recipe_name:
        type: string
        description: "Nombre de la receta recomendada."
    - cooking_time:
        type: string
        description: "Tiempo de cocción estimado."
    - ingredients_list:
        type: list[string]
        description: "Lista de ingredientes necesarios."

conversation:
  number: combinations(0.5, pairwise)
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - make spelling mistakes
```

### Desglose del perfil
- **`test_name`**: Un nombre descriptivo para el perfil.
- **`llm`**: Configuración del modelo de lenguaje.
- **`user`**: Define el lenguaje, el rol del usuario y sus metas.
- **`chatbot`**: Especifica el comportamiento del chatbot y los campos de salida que se extraerán.
- **`conversation`**: Controla el número de interacciones y el estilo de interacción.
