That sounds like a fun scenario to test! Here’s a profile that captures a user who starts by asking for a custom pizza but then changes their mind and opts for a predefined pizza instead. 😊

```yaml
test_name: "custom_to_predefined_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer trying to order a pizza. Initially, you want a custom pizza but change your mind and ask for a predefined pizza."
  context:
    - "You like a variety of toppings but are unsure about what to choose."
  goals:
    - "Ask for a custom pizza with toppings like {{toppings}}."
    - "Change your mind and ask for a predefined pizza like {{predefined_pizza}}."
    - toppings:
        function: random()
        type: string
        data: [pepperoni, mushrooms, onions, sausage, bacon, extra cheese]
    - predefined_pizza:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Veggie]

chatbot:
  is_starter: false
  fallback: "Sorry, could you rephrase that?"
  output:
    - order_confirmation:
        type: string
        description: "Confirmation of the pizza order."

conversation:
  number: 2
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - change your mind
```

This profile sets up a scenario where the user expresses a desire for a custom pizza but then switches to a predefined option. You can adjust the toppings and predefined pizza options as needed! Happy testing! 🍕
