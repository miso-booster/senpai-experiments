test_name: "Recetas y Planificación de Menús"

  model: gpt-4o-mini
  format:

  language: English

    - main_ingredient:
        function: random()
        type: string

        function: random()
        type: string
        data: [vegetarian, gluten-free, low-carb, high-protein]

chatbot:
  is_starter: false
  fallback: "Lo siento, no entendí eso. ¿Puedes reformular tu pregunta sobre recetas o planificación de menús?"

    - recipe_suggestion:
        type: string
        description: "A suggested recipe based on the main ingredient."

### Explicación del perfil:
- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario, el contexto y los objetivos que busca alcanzar.
- **chatbot**: Define cómo el chatbot debe responder y qué información debe extraer.
- **conversation**: Controla el número de interacciones y el estilo de interacción.
