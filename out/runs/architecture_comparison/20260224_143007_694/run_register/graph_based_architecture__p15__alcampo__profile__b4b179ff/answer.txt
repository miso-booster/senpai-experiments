¡Claro! Aquí tienes un perfil que puedes usar para probar la capacidad del chatbot de Alcampo para recomendar recetas y ayudar en la planificación de menús. Este perfil está diseñado para simular a un usuario que busca ideas de recetas y consejos de planificación de comidas.

```yaml
test_name: "Recetas y Planificación de Menús"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A user looking for recipe recommendations and meal planning assistance."
  context:
    - "You are interested in healthy and easy-to-make recipes."
    - "You want to plan meals for the week, considering dietary preferences."
    - "You enjoy exploring seasonal ingredients and local produce."
  goals:
    - "Suggest a healthy recipe for dinner that includes {{main_ingredient}}."
    - "Provide a weekly meal plan that incorporates {{dietary_preference}}."
    - "Recommend seasonal fruits and vegetables for this week's meals."
    - "Give tips on how to efficiently meal prep for the week."
    - main_ingredient:
        function: random()
        type: string
        data: [chicken, quinoa, spinach, lentils, salmon]
    - dietary_preference:
        function: random()
        type: string
        data: [vegetarian, gluten-free, low-carb, high-protein]

chatbot:
  is_starter: false
  fallback: "Lo siento, no entendí eso. ¿Puedes reformular tu pregunta sobre recetas o planificación de menús?"
  output:
    - recipe_suggestion:
        type: string
        description: "A suggested recipe based on the main ingredient."
    - weekly_meal_plan:
        type: string
        description: "A proposed meal plan for the week."
    - seasonal_produce:
        type: string
        description: "List of seasonal fruits and vegetables."
    - meal_prep_tips:
        type: string
        description: "Tips for efficient meal preparation."

conversation:
  number: 5
  goal_style:
    steps: 10
  interaction_style:
    - random:
      - single questions
      - long phrases
```

### Explicación del perfil:
- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario, el contexto y los objetivos que busca alcanzar.
- **chatbot**: Define cómo el chatbot debe responder y qué información debe extraer.
- **conversation**: Controla el número de interacciones y el estilo de interacción.

Puedes ajustar los ingredientes y preferencias dietéticas según lo que desees probar. ¡Espero que esto te ayude a evaluar la capacidad del chatbot de Alcampo! Si necesitas más ajustes o información, no dudes en decírmelo. 😊
