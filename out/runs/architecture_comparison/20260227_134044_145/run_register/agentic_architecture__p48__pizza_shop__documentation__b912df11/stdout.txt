A metamorphic rule in the context of Sensei is a type of validation logic that checks the consistency and correctness of chatbot interactions across multiple conversations rather than just a single conversation. These rules help ensure that certain properties hold true when comparing different conversation sets.

### Key Features of Metamorphic Rules:
- **Cross-Conversation Validation**: Unlike standard rules that validate a single conversation, metamorphic rules analyze relationships between multiple conversations.
- **Consistency Checks**: They can verify that responses remain consistent across similar inputs or that certain outputs change predictably when inputs are varied.
- **Use of Implications**: Metamorphic rules often use implications (if/then statements) to express how one conversation's output should relate to another's.

### Example Use Cases:
- Ensuring that if a user asks for a specific product in one conversation, the chatbot should consistently provide similar information in subsequent conversations.
- Validating that changing a user's query slightly leads to a logically consistent change in the chatbot's response.

These rules are particularly useful for testing the robustness and reliability of chatbots in handling various user interactions.
