He cargado la documentación sobre perfiles desde el archivo `sensei-chat-guide.md`. Ahora, vamos a crear un perfil para el soporte del CAU de la UAM. Este perfil debe permitir obtener el número de teléfono, correo electrónico, dirección física y horarios.

### Estructura del Perfil

Vamos a definir los siguientes campos en el perfil:

1. **test_name**: Nombre del perfil.
2. **llm**: Configuración del modelo (opcional).
3. **user**: Definición del usuario simulado, incluyendo su lenguaje, rol y objetivos.
4. **chatbot**: Detalles sobre el chatbot, incluyendo los campos de salida que queremos extraer.
5. **conversation**: Control de la conversación, como el número de interacciones y el estilo de interacción.

### Propuesta de Perfil

Aquí tienes un ejemplo de cómo podría verse el perfil:

```yaml
test_name: "CAU_Support_Profile"

llm:
  temperature: 0.7
  model: "gpt-4"
  model_prov: "openai"
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca soporte del CAU de la UAM."
  context:
    - "El usuario necesita información sobre el CAU."
  goals:
    - "Obtener el número de teléfono del CAU."
    - "Obtener el correo electrónico del CAU."
    - "Obtener la dirección física del CAU."
    - "Obtener los horarios de atención del CAU."

chatbot:
  is_starter: true
  fallback: "Lo siento, no pude encontrar esa información."
  output:
    - telefono:
        type: string
        description: "Número de teléfono del CAU."
    - email:
        type: string
        description: "Correo electrónico del CAU."
    - direccion:
        type: string
        description: "Dirección física del CAU."
    - horarios:
        type: string
        description: "Horarios de atención del CAU."

conversation:
  number: 1
  goal_style:
    steps: 4
  interaction_style:
    - random:
      - single questions
      - long phrases
```

### Resumen

- **Nombre del perfil**: CAU_Support_Profile
- **Objetivos**: Obtener información específica del CAU.
- **Campos de salida**: Número de teléfono, correo electrónico, dirección y horarios.
