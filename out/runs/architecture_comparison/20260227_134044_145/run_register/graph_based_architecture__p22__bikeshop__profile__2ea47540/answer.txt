That sounds like a great profile to create! 😊 Let's outline a profile for a user who wants to get their new bike set up with specific adjustments. Here's a basic structure you can use as a starting point:

```yaml
test_name: "bike_setup_request"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer who has recently purchased a new bike and wants to customize it."
  context:
    - "You want to adjust the seat height and change the handlebar grips to your preference."
    - "You are looking for advice on the best options for comfort and performance."
  goals:
    - "Ask about adjusting the seat height."
    - "Inquire about changing the handlebar grips."
    - "Request recommendations for comfortable grips."
    - "Ask if there are any additional adjustments that can enhance the riding experience."
    - {seat_adjustment: {data: [higher, lower], function: random(), type: string}}
    - {grip_type: {data: [foam, rubber, gel], function: random(), type: string}}

chatbot:
  is_starter: false
  fallback: "I'm sorry, could you repeat that?"
  output:
    - seat_adjustment_confirmation:
        type: string
        description: "Confirmation of the seat adjustment request."
    - grip_recommendation:
        type: string
        description: "Recommendations for handlebar grips."
    - additional_adjustments:
        type: string
        description: "Any other adjustments suggested by the shop."

conversation:
  number: 4
  goal_style:
    all_answered:
      export: true
      limit: 4
  interaction_style:
    - random:
        - single questions
        - long phrases
```

### Breakdown of the Profile:
- **Test Name**: A clear identifier for the profile.
- **User Role**: Describes the user's situation and intentions.
- **Context**: Provides background information about the user's needs and preferences.
- **Goals**: Lists the specific questions or requests the user will make during the conversation.
- **Chatbot Output**: Specifies what information should be extracted from the chatbot's responses.
- **Conversation Controls**: Defines how many interactions will occur and the style of interaction.
