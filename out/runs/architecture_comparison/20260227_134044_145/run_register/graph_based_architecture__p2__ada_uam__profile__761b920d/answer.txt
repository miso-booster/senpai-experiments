Creating a profile for an Erasmus user who needs help setting up their Moodle and Sigma accounts sounds like a great idea! Let's structure a simple profile that captures the essence of their needs while ensuring we have the necessary outputs for validation. Here’s a sample profile you can use:

```yaml
test_name: "Erasmus User Setup Assistance"

llm:
  temperature: 0.8
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Erasmus student who has just arrived and needs help setting up Moodle and Sigma."
  context:
    - "You are unfamiliar with the university's digital platforms and need guidance."
    - "You want to ensure you can access all necessary resources for your studies."
  goals:
    - "Solicitar ayuda para configurar mi cuenta de Moodle."
    - "Pedir instrucciones sobre cómo acceder a Sigma."
    - "Consultar sobre los requisitos para acceder a los recursos digitales de la universidad."

chatbot:
  is_starter: false
  fallback: "¿Me puedes repetir la pregunta con otras palabras? O, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - moodle_setup_info:
        type: string
        description: "Instrucciones para configurar la cuenta de Moodle."
    - sigma_access_info:
        type: string
        description: "Instrucciones para acceder a Sigma."
    - digital_resources_info:
        type: string
        description: "Requisitos para acceder a los recursos digitales de la universidad."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

### Explanation:
- **Test Name**: Clearly indicates the purpose of the profile.
- **User Section**: Defines the Erasmus student’s role and context, emphasizing their need for guidance.
- **Goals**: Lists specific requests the user might make regarding Moodle and Sigma.
- **Chatbot Outputs**: Specifies what information should be extracted after the conversation, ensuring you can validate that the chatbot provides the necessary support.
- **Conversation Controls**: Sets the number of interactions and the style of interaction.
