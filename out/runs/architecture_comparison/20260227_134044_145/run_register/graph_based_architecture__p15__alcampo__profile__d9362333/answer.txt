¡Claro! Aquí tienes un perfil que puedes usar para probar la capacidad del chatbot de Alcampo en recomendar recetas y planificación de menús. Este perfil está diseñado para simular un usuario que busca ideas de recetas y consejos para planificar sus comidas. 

```yaml
test_name: "Recetas y Planificación de Menús"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "User looking for recipe recommendations and meal planning assistance."
  context:
    - "You are interested in exploring healthy recipes that fit your dietary preferences."
    - "You want to learn how to plan meals for the week efficiently."
  goals:
    - "Suggest healthy recipes for dinner that include seasonal ingredients."
    - "Provide tips for meal prepping for the week."
    - "Recommend recipes that are quick to prepare for busy weekdays."
    - "Inquire about vegetarian options for meal planning."
    - "Ask for ideas on how to incorporate more fruits and vegetables into meals."

chatbot:
  is_starter: false
  fallback: "Lo siento, no entendí eso. ¿Puedes reformular tu pregunta sobre recetas o planificación de menús?"
  output:
    - recipe_suggestions:
        type: string
        description: "List of suggested recipes based on user preferences."
    - meal_prepping_tips:
        type: string
        description: "Tips for effective meal prepping."
    - quick_recipes:
        type: string
        description: "Recommendations for quick-to-prepare recipes."
    - vegetarian_options:
        type: string
        description: "List of vegetarian recipes for meal planning."
    - fruit_vegetable_incorporation:
        type: string
        description: "Ideas for adding more fruits and vegetables to meals."

conversation:
  number: 5
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```

Este perfil simula un usuario que busca recetas y consejos de planificación de menús, y está estructurado para extraer información útil del chatbot de Alcampo. ¡Espero que te sea útil! Si necesitas más ajustes o detalles, no dudes en decírmelo 😊.
