Sure! Here’s a profile for a pizza shop where the user is rude and wants things done quickly. I've included 4 goals with 4 variables, and two of those variables use pairwise functions to ensure the conversation number can be determined by the pairwise matrix. 

Feel free to tweak any details as needed! 😊

```yaml
test_name: "rude_fast_pizza_order"

llm:
  temperature: 0.5
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "You are a rude customer who wants to order pizza quickly without any nonsense."
  context:
    - "You expect fast responses and don't tolerate delays."
    - "You want to get your order done without small talk."
  goals:
    - "What kinds of pizzas do you have?"
    - "I want a {{pizza_type}} pizza."
    - "Make it {{pizza_size}} and add {{toppings}}."
    - "How long until it's ready?"

    - pizza_type:
        function: pairwise()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, BBQ Chicken]
    - pizza_size:
        function: pairwise()
        type: string
        data: [small, medium, large]
    - toppings:
        function: random(2)
        type: string
        data: [cheese, mushrooms, pepperoni, olives, onions]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't catch that. Just let me know what you want."
  output:
    - available_pizza_types:
        type: string
        description: "List of available pizza types."
    - order_confirmation:
        type: string
        description: "Confirmation of the pizza order."
    - estimated_time:
        type: time("hh:mm:ss")
        description: "Estimated time for the pizza to be ready."

conversation:
  number: combinations(0.5, pairwise) # This will use the pairwise functions to determine conversation number
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - single questions
```

This profile sets the stage for a lively interaction where the user is direct and expects quick answers. Let me know if you need any adjustments or further assistance! 🍕✨
