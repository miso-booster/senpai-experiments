¡Claro! Aquí tienes un perfil de ejemplo para probar el chatbot de una pizzería. Este perfil incluye los campos que mencionaste: tipo de pizza, bebida, ID del pedido y precio final en dólares. Puedes copiar y pegar este código en un archivo YAML en tu carpeta de perfiles.

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza and drinks."
  context:
    - "You want to know the available pizza options and place an order."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Select a {{drink_type}}."
    - "Ask for the total price."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Vegetarian, BBQ Chicken]
    - drink_type:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Can you please rephrase?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink_type:
        type: string
        description: "The drink selected."
    - order_id:
        type: string
        description: "A unique identifier for the order."
    - total_price:
        type: currency
        description: "The final price of the order in dollars."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - single questions
```

### Explicación de las secciones:

- **test_name**: Nombre del perfil para identificarlo.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario y sus objetivos, incluyendo las variables para el tipo de pizza y bebida.
- **chatbot**: Especifica la salida que se espera del chatbot, incluyendo el tipo de pizza, bebida, ID del pedido y precio total.
- **conversation**: Controla el número de interacciones y el estilo de la conversación.
