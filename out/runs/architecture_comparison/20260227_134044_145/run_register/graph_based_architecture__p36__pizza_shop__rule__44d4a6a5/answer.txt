Sure! To create a rule that checks if the price of a small pizza is $10, you'll want to follow the structure of a Sensei-check rule. Here’s how you can write it in YAML format:

```yaml
name: small_pizza_price_check
description: Small pizzas should cost exactly $10
conversations: 1
when: size == 'small'
oracle: extract_float(price) == 10
```

### Breakdown of the Rule:
- **name**: A unique identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to 1 since it's a single-conversation oracle.
- **when**: Specifies the condition that the size must be 'small'.
- **oracle**: Checks that the extracted price is exactly $10.
