Sure! Here’s a profile you can use to test the UAM chatbot for a user seeking support related to the CAU (User Support Center). This profile will focus on obtaining the CAU’s phone number, email address, physical location, and opening hours.

```yaml
test_name: "CAU Support Inquiry"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca información sobre el Centro de Atención a Usuarios (CAU)."
  context:
    - "Necesitas asistencia para resolver dudas sobre los servicios del CAU."
    - "Te gustaría obtener información de contacto para comunicarte con el CAU."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Cuál es el correo electrónico de contacto del CAU?"
    - "¿Dónde se encuentra físicamente el CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - phone_contact:
        type: string
        description: "Número de teléfono del CAU"
    - email_contact:
        type: string
        description: "Correo electrónico de contacto del CAU"
    - physical_location:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

Feel free to adjust any details as needed! This profile will help simulate a user who is looking for specific information from the CAU. Happy testing! 😊
