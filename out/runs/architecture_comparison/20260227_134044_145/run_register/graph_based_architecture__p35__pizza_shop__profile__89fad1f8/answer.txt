That sounds like a fun scenario to test! 😊 You can create a profile that captures this behavior by using the `change your mind` interaction style. Here’s a sample profile that you can use as a template:

```yaml
test_name: "custom_to_predefined_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer who initially wants to order a custom pizza but changes their mind halfway through."
  context:
    - "You are looking to order a pizza for a casual get-together."
    - "You want to explore options but are unsure about what to choose."
  goals:
    - "I would like to order a custom pizza with {{custom_toppings}}."
    - "Actually, can I get a {{predefined_pizza}} pizza instead?"
    - custom_toppings:
        function: random()
        type: string
        data: [pepperoni, mushrooms, olives, bell peppers, onions]
    - predefined_pizza:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, BBQ Chicken]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't quite catch that. Could you please repeat?"
  output:
    - order_confirmation:
        type: string
        description: "Confirmation of the pizza order"

conversation:
  number: 2
  goal_style:
    steps: 3
  interaction_style:
    - change your mind
    - long phrases
```

### Breakdown of the Profile:
- **Role and Context**: The user is a customer looking to order pizza for a casual get-together and is unsure about their choice.
- **Goals**: The user first expresses a desire for a custom pizza with specific toppings and then changes their mind to request a predefined pizza.
- **Interaction Style**: The `change your mind` style allows the user to switch their request during the conversation.
- **Output**: The chatbot will confirm the order based on the final request.

Feel free to adjust the toppings and predefined pizza options as needed! Happy testing! 🍕✨
