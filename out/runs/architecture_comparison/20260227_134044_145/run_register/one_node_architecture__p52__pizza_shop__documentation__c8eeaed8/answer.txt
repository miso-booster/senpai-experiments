Connectors in Sensei are used to facilitate communication between your chatbot and external APIs. They define how to send messages to the chatbot and how to handle responses. This allows you to integrate your chatbot with various platforms or services seamlessly.

### Key Fields in Connectors:

1. **name**: A friendly name for your chatbot connector.
2. **base_url**: The base URL of the chatbot's API endpoint.
3. **send_message**: This section contains details about how to send a message to the chatbot, including:
   - **path**: The specific endpoint path (appended to the base URL).
   - **method**: The HTTP method to use (e.g., POST, GET).
   - **headers**: Any custom headers required for the request (e.g., authentication).
   - **payload_template**: The structure of the message being sent, with placeholders for dynamic content (like user messages).
4. **response_path**: A dot-separated path to extract the bot's reply from the JSON response received from the API.

These fields help you configure how your chatbot interacts with external services, ensuring smooth communication and data exchange. If you need help creating or modifying a specific connector, feel free to ask! 😊
