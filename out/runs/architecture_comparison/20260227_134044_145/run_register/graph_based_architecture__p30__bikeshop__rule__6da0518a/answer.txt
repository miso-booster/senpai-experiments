Here's a sample rule you can use:

```yaml
name: appointment_confirmation_check
description: Check if the chatbot confirms the appointment when a user requests to schedule a bike service.
conversations: 1
when: 'conv[0].confirmed_service is not None and conv[0].confirmed_date is not None and conv[0].confirmed_time is not None'
oracle: |
  'confirmed_service' in data_output and 'confirmed_date' in data_output and 'confirmed_time' in data_output
```

### Explanation:
- **name**: A unique identifier for your rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to 1, as we are checking a single conversation.
- **when**: This condition checks if the `confirmed_service`, `confirmed_date`, and `confirmed_time` fields are not `None`, indicating that the user has requested an appointment.
- **oracle**: This checks if the output includes confirmation of the appointment details.
