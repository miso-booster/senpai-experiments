### Perfil de prueba para el chatbot de la pizzería

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Cliente que desea hacer un pedido de pizza."
  context:
    - "El cliente prefiere opciones vegetarianas."
  goals:
    - "Quiero pedir una pizza de {{tipo_pizza}} y una bebida {{bebida}}."
    - "El precio total es {{precio_final}} dólares."
    - "Mi ID de pedido es {{id_pedido}}."
    - tipo_pizza:
        function: random()
        type: string
        data: [margarita, pepperoni, cuatro quesos, vegetariana]
    - bebida:
        function: random()
        type: string
        data: [cola, agua, limonada]
    - precio_final:
        function: random()
        type: float
        data: [10.99, 12.50, 15.00, 8.75]
    - id_pedido:
        function: random()
        type: string
        data: [any(5 alphanumeric characters)]

chatbot:
  is_starter: true
  fallback: "Lo siento, no entendí eso. ¿Puedes repetirlo?"
  output:
    - tipo_pizza:
        type: string
        description: "Tipo de pizza seleccionada."
    - bebida:
        type: string
        description: "Bebida seleccionada."
    - id_pedido:
        type: string
        description: "ID del pedido."
    - precio_final:
        type: currency
        description: "Precio total del pedido en dólares."

conversation:
  number: 5
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - long phrases
      - make spelling mistakes
```

### Resumen del perfil
- **Campos de salida**: `tipo_pizza`, `bebida`, `id_pedido`, `precio_final`.
- **Interacción**: El usuario puede hacer pedidos de pizza y recibir un ID y un precio.
- **Estilo de conversación**: Se permite un estilo de interacción variado, incluyendo errores tipográficos.

Este perfil está diseñado para simular un cliente que hace un pedido en una pizzería. Si necesitas ajustes o más detalles, ¡házmelo saber! 😊
