He revisado la documentación sobre perfiles en el archivo `sensei-chat-guide.md`. Ahora puedo ayudarte a crear un perfil que pruebe la capacidad del chatbot de Alcampo para recomendar recetas y planificar menús.

### Estructura del Perfil

Aquí tienes un ejemplo de cómo podría ser el perfil en YAML:

```yaml
test_name: "Alcampo Recipe and Menu Planning"

llm:
  temperature: 0.7
  model: "gpt-4"
  model_prov: "openai"
  format:
    type: text

user:
  language: Spanish
  role: "Eres un cliente que busca recomendaciones de recetas y planificación de menús."
  context:
    - "Te gusta cocinar y buscas opciones saludables."
    - "Prefieres recetas que se pueden hacer en menos de 30 minutos."
  goals:
    - "Recomiéndame una receta con {{ingredientes}}."
    - "Ayúdame a planificar un menú para {{número_días}} días."
    - ingredientes:
        function: random()
        type: string
        data: [pollo, pescado, verduras, pasta, arroz]
    - número_días:
        function: random()
        type: int
        data:
          min: 1
          max: 7

chatbot:
  is_starter: true
  fallback: "Lo siento, no puedo ayudarte con eso."
  output:
    - receta:
        type: string
        description: "La receta recomendada."
    - menú:
        type: list[string]
        description: "El menú planificado."

conversation:
  number: combinations(0.5, pairwise)
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Descripción del Perfil

- **Nombre de prueba**: Define el nombre del perfil.
- **Configuración del LLM**: Establece el modelo y la temperatura.
- **Usuario**: Describe el rol del usuario y sus objetivos.
- **Chatbot**: Define el comportamiento del chatbot, incluyendo los campos de salida que se extraerán.
- **Conversación**: Controla el número de interacciones y el estilo de interacción.
