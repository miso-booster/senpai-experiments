Connectors in the Sensei framework are used to facilitate communication between your chatbot and external APIs. They allow you to send user messages to the chatbot and receive responses, making it possible to test and validate the chatbot's behavior in real-world scenarios.

### Key Fields in Connectors

1. **name**: A friendly name for your chatbot connector. This helps identify the connector easily.

2. **base_url**: The base URL of the chatbot API that you want to connect to. This is the starting point for all API requests.

3. **send_message**: This section defines how to send messages to the chatbot. It includes:
   - **path**: The specific endpoint path that will be appended to the base URL for sending messages.
   - **method**: The HTTP method to use (e.g., POST, GET). The default is usually POST.
   - **headers**: Any custom headers required for the API request, such as authentication tokens.
   - **payload_template**: The structure of the JSON payload that will be sent with the user message. This often includes a placeholder for the user's message (e.g., `{user_msg}`).

4. **response_path**: This field specifies how to extract the chatbot's reply from the JSON response received from the API. It uses dot notation to navigate through the JSON structure.

### Example of a Connector

Here’s a simple example of what a connector might look like:

```yaml
name: "My Custom Bot"
base_url: "https://api.mychatbot.com"
send_message:
  path: "/chat"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

In this example:
- The connector is named "My Custom Bot."
- It connects to an API at `https://api.mychatbot.com`.
- It sends messages to the `/chat` endpoint using a POST request.
- The response is expected to be found at `response.text` in the JSON returned by the API.
