Great! I've loaded the relevant documentation on profiles from `sensei-chat-guide.md`. Now, let's create a profile for a user who starts by asking for a custom pizza but changes their mind halfway through and opts for a predefined pizza instead.

### Profile Structure
Here's how we can structure the profile:

1. **Test Name**: A descriptive name for the profile.
2. **User Role**: Describes the simulated user's behavior.
3. **Goals**: Includes the initial request for a custom pizza and the later request for a predefined pizza.
4. **Chatbot Output**: Defines what information we want to extract at the end of the conversation.
5. **Conversation Controls**: Specifies how many conversations to run and the interaction style.

### Example Profile YAML
Here’s a draft of the profile based on your requirements:

```yaml
test_name: "custom_to_predefined_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer who initially wants to create a custom pizza but changes their mind to order a predefined pizza."
  goals:
    - "I would like to order a custom pizza with {{custom_toppings}}."
    - "Actually, can I just get a {{predefined_pizza}} instead?"
    - custom_toppings:
        function: random()
        type: string
        data: [pepperoni, mushrooms, onions, olives, extra cheese]
    - predefined_pizza:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, BBQ Chicken]

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you clarify that?"
  output:
    - order_confirmation:
        type: string
        description: "Confirmation of the pizza order"

conversation:
  number: 2
  goal_style:
    steps: 3
  interaction_style:
    - change your mind
```

### Explanation of Key Sections
- **Goals**: The user first expresses a desire for a custom pizza and then changes their mind to a predefined option.
- **Chatbot Output**: We want to extract the order confirmation at the end of the conversation.
- **Interaction Style**: The user is expected to change their mind during the conversation.
