Great! I've loaded the documentation on profiles from `sensei-chat-guide.md`. Now, let's create a profile for a user who is trying to set up eduroam on their device but is facing difficulties. 

### Profile Structure

The profile will include:
- **User Role**: Describing the user trying to set up eduroam.
- **Goals**: Different ways the user could attempt to set it up, such as checking settings, using a setup guide, or contacting support.
- **Chatbot Output**: Fields to extract relevant information after the conversation.

### Proposed YAML Profile

Here's a draft of the profile:

```yaml
test_name: "eduroam_setup_assistance"

llm:
  temperature: 0.7
  model: "gpt-4o"
  model_prov: "openai"
  format:
    type: text

user:
  language: English
  role: "A user trying to set up eduroam on their device but unable to do so."
  context:
    - "The user is a student or staff member at a university."
  goals:
    - "Check if the Wi-Fi settings are correct."
    - "Follow the setup guide provided by the university."
    - "Contact IT support for assistance."
    - "Try resetting the network settings on the device."
    - "Ask about common issues with eduroam setup."

chatbot:
  is_starter: true
  fallback: "I'm sorry, I didn't quite catch that. Can you please rephrase?"
  output:
    - setup_status:
        type: string
        description: "Status of the eduroam setup attempt."
    - troubleshooting_steps:
        type: list[string]
        description: "List of troubleshooting steps taken by the user."
    - support_contacted:
        type: boolean
        description: "Indicates if the user contacted IT support."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - change language: [Spanish, French]
```

### Summary of the Profile
- **Test Name**: `eduroam_setup_assistance`
- **User Role**: A user trying to set up eduroam.
- **Goals**: Various methods the user might try to resolve their issue.
- **Chatbot Output**: Fields to capture the setup status, troubleshooting steps, and whether support was contacted.
