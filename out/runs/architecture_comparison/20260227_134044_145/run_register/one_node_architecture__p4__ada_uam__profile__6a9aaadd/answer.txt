¡Claro! Vamos a crear un perfil para el chatbot de la UAM que se enfoque en obtener soporte sobre el CAU. Este perfil incluirá los objetivos que mencionaste, así como los campos de salida necesarios para extraer la información.

Aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca información sobre el Centro de Atención a Usuarios (CAU)."
  context:
    - "El usuario necesita obtener información de contacto y horarios del CAU."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar por los horarios de atención del CAU."

chatbot:
  is_starter: true
  fallback: "Lo siento, no puedo ayudar con eso."
  output:
    - contact_email:
        type: string
        description: "Correo electrónico del CAU"
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horas de servicio del CAU"

conversation:
  number: 1
  goal_style:
    steps: 4
  interaction_style:
    - long phrases
    - make spelling mistakes
```

### Desglose del perfil:
- **test_name**: Nombre del perfil para identificarlo.
- **llm**: Configuración del modelo de lenguaje que se utilizará.
- **user**: Define el rol del usuario y los objetivos que tiene al interactuar con el chatbot.
- **chatbot**: Define el comportamiento del chatbot y los campos de salida que se esperan.
- **conversation**: Controla el número de interacciones y el estilo de la conversación.

Puedes ajustar los detalles según sea necesario. ¡Espero que esto te ayude a empezar! Si necesitas más cambios o detalles, ¡dímelo! 😊
