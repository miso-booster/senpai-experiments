¡Claro! Vamos a crear un perfil para que puedas testear el chatbot de la UAM en el contexto de soporte del CAU. Aquí tienes un ejemplo de cómo podría verse tu perfil en formato YAML:

```yaml
test_name: "Soporte CAU - Información de Contacto"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca información sobre el Centro de Atención a Usuarios (CAU)."
  context:
    - "Necesitas obtener información de contacto para resolver dudas."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico de contacto del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar sobre los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "¿Puedes repetir la pregunta de otra forma? O, si lo prefieres, consulta nuestro catálogo de servicios."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico de contacto del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

### Desglose del perfil:

- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el contexto y los objetivos del usuario que busca soporte.
- **chatbot**: Incluye el mensaje de fallback y los campos de salida que deseas extraer (teléfono, email, dirección y horarios).
- **conversation**: Especifica el número de interacciones y el estilo de interacción.

Puedes ajustar cualquier parte de este perfil según tus necesidades. ¡Espero que esto te ayude a comenzar! Si necesitas más cambios o detalles, ¡no dudes en decírmelo! 😊
