In the context of Sensei and testing, an **oracle** is a mechanism or method used to determine whether the output of a system (like a chatbot) is correct or not. It acts as a reference point to validate the responses generated by the chatbot during testing.

In Sensei-check, oracles can be defined as conditions that the outputs must satisfy. For example, an oracle might check if a price returned by a chatbot is greater than zero or if a specific field is present in the output. 

In simpler terms, think of an oracle as a set of rules or expectations that help you verify if your chatbot is performing as intended! 😊
