Connectors are used to facilitate communication between your chatbot and external APIs. They define how to send messages to the chatbot and how to interpret the responses received. This is especially useful for integrating your chatbot with various services, allowing it to perform tasks like fetching data, processing requests, or interacting with users across different platforms.

### Key Fields in a Connector

Here are the main fields typically found in a connector configuration:

1. **name**: A friendly name for your chatbot connector.

2. **base_url**: The base URL of the chatbot API you are connecting to.

3. **send_message**: This section contains details about how to send messages to the chatbot API:
   - **path**: The specific endpoint path that will be appended to the base URL.
   - **method**: The HTTP method to use (e.g., POST, GET). If not specified, POST is often the default.
   - **headers**: Any custom headers required for the API request (e.g., Authorization).
   - **payload_template**: The structure of the JSON payload that will be sent to the API, often containing a placeholder for the user's message (e.g., `{user_msg}`).

4. **response_path**: A dot-separated path that specifies how to extract the bot's reply from the JSON response received from the API.

These fields allow you to configure how your chatbot interacts with external services, ensuring that messages are sent and received correctly. If you have any specific connectors in mind or need help with a particular configuration, feel free to ask! 😊
