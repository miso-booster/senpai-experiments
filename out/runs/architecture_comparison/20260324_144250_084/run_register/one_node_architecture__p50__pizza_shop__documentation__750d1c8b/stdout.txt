In the context of Sensei and testing, an **oracle** is a mechanism used to determine whether the output of a system (like a chatbot) is correct or not. It acts as a reference point to validate the results produced during testing.

In Sensei-check, oracles can be defined in rules to specify the expected behavior or output for a given input. For example, if you're testing a pizza ordering chatbot, an oracle might check that the total price returned is greater than zero when a valid order is placed.

Oracles can be simple conditions (like checking if a value is not null) or more complex expressions that compare multiple outputs or states. They help ensure that the chatbot behaves as expected across different scenarios. 😊
