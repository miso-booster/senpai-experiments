¡Hola! 😊 He revisado la documentación sobre perfiles y estoy listo para ayudarte a crear un perfil para probar el chatbot de una pizzería. Este perfil incluirá los campos que mencionaste: tipo de pizza, bebida, ID del pedido y precio final en dólares.

Aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Cliente que desea hacer un pedido de pizza."
  context:
    - "El cliente quiere pedir una pizza y una bebida."
  goals:
    - "Quiero una pizza de {{tipo_pizza}} y una bebida {{bebida}}."
    - tipo_pizza:
        function: random()
        type: string
        data: [pepperoni, vegetariana, cuatro quesos, hawaiana]
    - bebida:
        function: random()
        type: string
        data: [Coca-Cola, Fanta, agua, cerveza]
    
chatbot:
  is_starter: true
  fallback: "Lo siento, no entendí eso. ¿Puedes repetirlo?"
  output:
    - tipo_pizza:
        type: string
        description: "Tipo de pizza pedido."
    - bebida:
        type: string
        description: "Bebida seleccionada."
    - order_id:
        type: string
        description: "ID del pedido."
    - total_price:
        type: currency
        description: "Precio final del pedido en dólares."

conversation:
  number: 1
  goal_style:
    steps: 3
  interaction_style:
    - long phrases
```

### Resumen del perfil:
- **Nombre de prueba**: `pizza_order_test`
- **Lenguaje**: Español
- **Rol del usuario**: Cliente que desea hacer un pedido de pizza.
- **Objetivos**: Incluye variables para el tipo de pizza y bebida, que se seleccionan aleatoriamente.
- **Salida del chatbot**: Define los campos que se extraerán al final de la conversación.
