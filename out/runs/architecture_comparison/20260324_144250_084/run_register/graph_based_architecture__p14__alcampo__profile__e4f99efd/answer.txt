¡Claro! Aquí tienes un perfil que puedes usar para probar la capacidad del chatbot de Alcampo en recomendar recetas y ayudar con la planificación de menús. Este perfil está diseñado para simular un usuario que busca recetas y consejos de cocina.

```yaml
test_name: "Recipe Recommendations and Menu Planning"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A user looking for recipe recommendations and menu planning assistance."
  context:
    - "You are interested in exploring new recipes for healthy meals."
    - "You want to plan a week's worth of dinners that are easy to prepare."
    - "You are looking for seasonal ingredients to incorporate into your meals."
  goals:
    - "Suggest a recipe for a healthy dinner using seasonal vegetables."
    - "Help me plan a week's worth of dinners with a variety of cuisines."
    - "Provide tips for meal prep to save time during the week."
    - "Recommend a recipe for a quick lunch that I can take to work."
    - "Inquire about any special dietary options available for recipes."

chatbot:
  is_starter: false
  fallback: "Lo siento, no entendí tu pregunta. 😊 ¿Podrías reformularla? Estoy aquí para ayudarte con recetas y planificación de menús."
  output:
    - recipe_suggestion:
        type: string
        description: "A suggested recipe based on user preferences."
    - meal_plan:
        type: string
        description: "A proposed meal plan for the week."
    - meal_prep_tips:
        type: string
        description: "Tips for efficient meal preparation."
    - quick_lunch_recipe:
        type: string
        description: "A recipe for a quick and easy lunch."
    - dietary_options:
        type: string
        description: "Information about dietary options for recipes."

conversation:
  number: 5
  goal_style:
    steps: 10
  interaction_style:
    - random:
      - long phrases
      - single questions
      - change language:
        - Spanish
```

Este perfil simula un usuario que busca recetas y planificación de menús, y permite al chatbot interactuar de manera efectiva. Puedes ajustarlo según tus necesidades específicas. ¡Espero que te sea útil! 😊
