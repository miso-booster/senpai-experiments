¡Claro! Estoy aquí para ayudarte a crear un perfil para testear el chatbot de la UAM sobre el CAU. Vamos a estructurarlo para que obtengas la información que necesitas: número de teléfono, email, dirección física y horarios. Aquí tienes un ejemplo de cómo podría verse tu perfil en formato YAML:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita soporte del CAU."
  context:
    - "Buscas información sobre cómo contactar al CAU para resolver dudas."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico de contacto del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar sobre los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "¿Puedes reformular tu pregunta? O consulta nuestro catálogo de servicios."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU."
    - contact_email:
        type: string
        description: "Correo electrónico del CAU."
    - physical_address:
        type: string
        description: "Dirección física del CAU."
    - service_hours:
        type: string
        description: "Horarios de atención del CAU."

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

### Explicación de las secciones:
- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el usuario simulado, su rol y los objetivos que tiene.
- **chatbot**: Describe cómo debe comportarse el chatbot y qué información debe extraer.
- **conversation**: Controla el número de interacciones y el estilo de la conversación.

Puedes ajustar cualquier parte de este perfil según tus necesidades. ¡Espero que esto te ayude a empezar! Si necesitas más cambios o detalles, no dudes en decírmelo 😊.
