It looks like your rule is almost there, but it’s missing the `if` condition that specifies the relationship you want to check. In metamorphic rules, you need both `if` and `then` to establish the condition properly. 

Here's the corrected version of your rule:

```yaml
name: more_toppings_cost_more
description: Adding more toppings to a custom pizza costs more
active: true
conversations: 2
when: conv[0].size == conv[1].size and conv[0].drink == conv[1].drink
if: len(conv[0].toppings) > len(conv[1].toppings)
then: extract_float(conv[0].price) > extract_float(conv[1].price)
```

### Changes Made:
1. Added the `if` condition to check if the first conversation has more toppings than the second one.

Now, this rule will check if two pizzas of the same size and drink have different numbers of toppings, and it will assert that the pizza with more toppings costs more.
