### Estructura del Perfil

El perfil que vamos a crear incluirá:

- **Nombre de la prueba**: Un identificador para el perfil.
- **Configuración del LLM**: Opcional, pero podemos incluir temperatura y modelo.
- **Usuario**: Definiremos el lenguaje, rol y objetivos del usuario.
- **Chatbot**: Especificaremos que el chatbot es el iniciador y definiremos los campos de salida que deseas.
- **Conversación**: Controlaremos el número de interacciones y el estilo de interacción.

### Campos de salida requeridos

Los campos de salida que mencionaste son:
- Tipo de pizza
- Bebida
- ID del pedido
- Precio final en dólares

### Perfil Propuesto

Aquí tienes el perfil en YAML:

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: "gpt-4"
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza."
  goals:
    - "Order a {{pizza_type}} pizza with a {{drink}} and get the total price."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Veggie, BBQ Chicken]
    - drink:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: true
  fallback: "Sorry, could you repeat that?"
  output:
    - pizza_type:
        type: string
        description: "Type of pizza ordered"
    - drink:
        type: string
        description: "Drink selected"
    - order_id:
        type: string
        description: "Unique order identifier"
    - total_price:
        type: currency
        description: "Final price in dollars"

conversation:
  number: 5
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Resumen

- **Nombre del perfil**: `pizza_order_test`
- **Campos de salida**: Incluye el tipo de pizza, bebida, ID del pedido y precio final.
- **Estilo de interacción**: Permite frases largas y preguntas individuales.
