¡Claro! Aquí tienes un perfil de ejemplo para probar el chatbot de una pizzería. Este perfil incluye los campos que mencionaste: tipo de pizza, bebida, ID del pedido y precio final en dólares. Puedes ajustarlo según tus necesidades.

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer ordering a pizza and drinks."
  context:
    - "You are looking for a delicious pizza and a refreshing drink."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Select a {{drink_type}} to go with the pizza."
    - "Ask for the total price in dollars."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Vegetarian, BBQ Chicken]
    - drink_type:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Can you please repeat?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink_type:
        type: string
        description: "The type of drink ordered."
    - order_id:
        type: string
        description: "A unique identifier for the order."
    - total_price:
        type: currency
        description: "The final price of the order in dollars."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - random:
        - long phrases
        - single questions
```

Este perfil define un cliente que quiere hacer un pedido de pizza y bebida. El output incluye los campos necesarios para validar la conversación. ¡Espero que te sirva! Si necesitas más ajustes, no dudes en decírmelo 😊.
