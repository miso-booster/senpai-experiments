He revisado la documentación sobre perfiles en Sensei, que se encuentra en el archivo `sensei-chat-guide.md`. Ahora puedo ayudarte a crear un perfil que pruebe la capacidad del chatbot de Alcampo para recomendar recetas y planificar menús.

### Estructura del Perfil

Aquí tienes un ejemplo de cómo podría ser el perfil:

```yaml
test_name: "Alcampo_Recetas_y_Planificación"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Eres un cliente que busca recomendaciones de recetas y planificación de menús."
  context:
    - "Te gusta la comida saludable y buscas opciones rápidas."
  goals:
    - "Recomiéndame una receta con {{ingredientes}}."
    - "Ayúdame a planificar un menú para {{número_de_días}} días."
    - ingredientes:
        function: random()
        type: string
        data: [pollo, pescado, verduras, pasta, arroz]
    - número_de_días:
        function: random()
        type: int
        data:
          min: 1
          max: 7

chatbot:
  is_starter: true
  fallback: "Lo siento, no entendí eso. ¿Podrías reformularlo?"
  output:
    - receta:
        type: string
        description: "La receta recomendada."
    - menú:
        type: string
        description: "El menú planificado."

conversation:
  number: combinations(0.5, pairwise)
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Descripción del Perfil

- **test_name**: Nombre del perfil.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el comportamiento del usuario simulado, incluyendo su rol y metas.
- **chatbot**: Especifica cómo interactúa el chatbot, incluyendo los campos de salida que se extraerán.
- **conversation**: Controla el número de conversaciones y el estilo de interacción.
