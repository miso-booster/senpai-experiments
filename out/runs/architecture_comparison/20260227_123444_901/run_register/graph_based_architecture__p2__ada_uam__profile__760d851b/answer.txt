Creating a profile for an Erasmus user who needs help setting up their Moodle and Sigma accounts sounds like a great idea! Let's keep it simple and focused on the essentials. Here’s a draft profile you can use as a starting point:

```yaml
test_name: "Erasmus User Setup Assistance"

llm:
  temperature: 0.8
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Erasmus student needing help with account setups."
  context:
    - "Eres un estudiante Erasmus recién llegado y no sabes cómo configurar tus cuentas en Moodle y Sigma."
  goals:
    - "Solicitar ayuda para configurar mi cuenta de Moodle."
    - "Pedir instrucciones sobre cómo acceder a Sigma."
    - "Consultar sobre los requisitos necesarios para acceder a ambos sistemas."

chatbot:
  is_starter: false
  fallback: "¿Puedes repetir la pregunta de otra forma? O consulta nuestro catálogo de servicios."
  output:
    - moodle_setup_info:
        type: string
        description: "Instrucciones para configurar la cuenta de Moodle."
    - sigma_access_info:
        type: string
        description: "Instrucciones para acceder a Sigma."
    - account_requirements:
        type: string
        description: "Requisitos necesarios para acceder a Moodle y Sigma."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

### Explanation of the Profile:

- **Test Name**: Clearly states the purpose of the profile.
- **LLM Settings**: Adjusts the model and temperature for more conversational responses.
- **User Section**: Defines the user’s role and context, making it clear they are a new Erasmus student needing assistance.
- **Goals**: Lists the specific requests the user will make regarding Moodle and Sigma.
- **Chatbot Outputs**: Specifies what information needs to be extracted for validation, ensuring that the chatbot provides the necessary support.
- **Conversation Controls**: Sets the number of conversations and interaction style to keep it straightforward.
