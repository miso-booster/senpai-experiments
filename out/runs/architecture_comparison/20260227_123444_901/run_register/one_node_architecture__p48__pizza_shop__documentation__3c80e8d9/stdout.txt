Great question! 😊 In the context of Sensei, a **metamorphic rule** is a specific type of rule used in testing that states a condition to check over generated conversations. These rules are particularly useful because they allow you to compare pairs or tuples of conversations, asserting how outputs should change (or not) when inputs change. This helps address the oracle problem by checking relationships between outputs rather than relying on absolute answers.

Here's a quick breakdown:

1. **Single vs. Multiple Conversations**: Metamorphic rules can target a single conversation (like traditional oracles), several conversations, or even all conversations within a dataset.

2. **Comparative Checking**: They focus on comparing outputs from different conversations that meet certain selection criteria, which you define using filters (like `when` conditions).

3. **Example Use Case**: For instance, if you have two pizza orders with the same size and drink, a metamorphic rule could check that if one order has more toppings, it must cost more than the other.

This approach is super helpful for ensuring that your chatbot behaves consistently and correctly across various scenarios! If you have more questions or need examples, feel free to ask! 🍕✨
