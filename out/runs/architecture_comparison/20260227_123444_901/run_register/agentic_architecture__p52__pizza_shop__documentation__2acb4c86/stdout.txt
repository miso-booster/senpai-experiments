Connectors in the SENSEI framework are used to connect to external chatbot APIs without the need for coding. By creating a YAML configuration file, you can specify how to communicate with your chatbot's API. Here's a summary of their purpose and the fields they contain:

### Purpose of Connectors
- **Connect to Chatbot APIs**: They allow you to send and receive messages from external chatbots.
- **Configuration**: You define how to interact with the API, including endpoints, methods, and data formats.

### Configuration Fields
Here are the key fields in a connector configuration:

| Field                       | Description                                                        | Required            |
|-----------------------------|--------------------------------------------------------------------|---------------------|
| `name`                      | Friendly name for your chatbot                                      | No                  |
| `base_url`                 | Base URL of the chatbot API                                        | Yes                 |
| `send_message.path`        | API endpoint path (appended to `base_url`)                        | Yes                 |
| `send_message.method`      | HTTP method (POST, GET, PUT, DELETE)                              | No (default: POST)  |
| `send_message.headers`     | Custom headers (e.g., Authorization)                               | No                  |
| `send_message.payload_template` | JSON structure with `{user_msg}` placeholder                  | Yes                 |
| `response_path`            | Dot-separated path to extract the bot's reply from the JSON response | Yes                 |

### Example Configuration
Here's a simple example of a connector configuration:

```yaml
name: "My Custom Bot"
base_url: "https://api.mychatbot.com"
send_message:
  path: "/chat"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

### Tips for Using Connectors
- Use `{user_msg}` as a placeholder for the user's message in your payload.
- Check your API documentation for the exact response structure to set the correct `response_path`.
- Add authentication headers in the `headers` section if required.

This information is based on the **Custom YAML Connector Guide** and **Connector Examples** documentation. If you have any specific questions or need help with a particular connector, feel free to ask! 😊
