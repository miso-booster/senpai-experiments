Based on the provided request details and the connector documentation, here’s the YAML configuration for the custom connector to connect to the Alcampo chatbot API.

### YAML Connector Configuration

```yaml
name: "Alcampo Chatbot"
base_url: "https://alcampo.botslovers.com"
send_message:
  path: "/bot/web"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Accept: "*/*"
    Accept-Language: "en-US,en;q=0.9"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
    Referer: "https://alcampo.botslovers.com/Admin/Widget?mobile=0&user=0&lang=es"
  payload_template:
    data:
      id_user: "{id_user}"
      idweb_user: "{idweb_user}"
      session: "{session}"
      message:
        message:
          message:
            text: "{user_msg}"
        iduser: "{id_user}"
        session: "{session}"
        channel: "web"
      widget_form: "TRUE"
      contexto_extra: []
      lang: "es"
      accion: "response_bot"
response_path: "messages.0.0.message.text"
```

### Explanation of the Configuration

- **name**: A friendly name for the connector.
- **base_url**: The base URL of the Alcampo chatbot API.
- **send_message**:
  - **path**: The specific endpoint to send messages.
  - **method**: The HTTP method used for the request (POST).
  - **headers**: Custom headers required for the API request.
  - **payload_template**: The structure of the JSON payload sent to the API, with placeholders for dynamic values like `id_user`, `idweb_user`, `session`, and `user_msg`.
- **response_path**: The path to extract the chatbot's reply from the JSON response.
