Sure! Since you want to create a rule that checks if the chatbot provided information about current promotions without being tied to a specific profile, we can use a global rule approach. Here’s a sample rule you can use:

```yaml
name: promotions_information_check
description: Ensure the chatbot provides information about current promotions.
conversations: 1
oracle: |
  'current_promotions' in chatbot.output
```

### Explanation:
- **name**: This is the identifier for your rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to 1, as this rule applies to a single conversation.
- **oracle**: This checks if the `current_promotions` field is present in the chatbot's output, ensuring that the chatbot provides the necessary information.
