```yaml

llm:

  model: gpt-4o

    - "Pedir el correo electrónico del CAU."

    - "Preguntar por los horarios de atención del CAU."

  is_starter: true
  fallback: "Lo siento, no pude encontrar esa información."
  output:
    - contact_email:
        type: string
        description: "Correo electrónico del CAU"
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - physical_address:
        type: string

    - service_hours:
        type: string
        description: "Horas de servicio del CAU"

  number: 1
  goal_style:
    steps: 4
```

### Desglose del perfil:
- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario y los objetivos que quiere alcanzar.
- **chatbot**: Define la salida que se espera del chatbot, incluyendo los campos que se van a extraer.
- **conversation**: Controla el número de conversaciones y los pasos que se deben seguir.
