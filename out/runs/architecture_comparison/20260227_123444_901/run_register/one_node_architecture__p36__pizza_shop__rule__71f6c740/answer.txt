Sure! Here’s a Sensei rule that checks if the price of a small pizza is at least $10. This rule assumes you have a `price` field in your `chatbot.output` for the pizza order profile.

```yaml
name: small_pizza_price_check
description: Small pizzas should cost at least $10
conversations: 1
when: size == 'small'
oracle: extract_float(price) >= 10 and currency(price) == 'USD'
```

Feel free to adjust the `currency` check if your output uses a different currency format! Let me know if you need any more help! 😊
