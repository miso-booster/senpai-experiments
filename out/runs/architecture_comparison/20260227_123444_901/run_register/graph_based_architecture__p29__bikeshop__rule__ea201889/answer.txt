```yaml
name: language_consistency
description: Assistant responds in the same language as the user
conversations: 2
when: conv[0].user_language == conv[1].user_language
oracle: responds_in_same_language() is True
```

### Explanation:
- **name**: This is the name of the rule.
- **description**: A brief description of what the rule checks.
- **conversations**: We are checking two conversations to ensure consistency.
- **when**: This condition checks that the user language in both conversations is the same.
- **oracle**: This checks that the assistant responds in the same language as the user.
