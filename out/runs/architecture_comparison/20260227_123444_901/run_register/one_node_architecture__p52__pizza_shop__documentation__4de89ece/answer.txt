Connectors in the Sensei framework are used to establish communication between your chatbot and external APIs. They define how to send messages to the chatbot and how to handle the responses. This allows you to integrate various chatbot services seamlessly, enabling testing and validation of your chatbot's interactions.

### Key Fields in Connectors

Here are the main fields you typically find in a connector configuration:

1. **name**: A friendly name for your chatbot connector.
2. **base_url**: The base URL of the chatbot API you are connecting to.
3. **send_message**: This section defines how to send messages to the chatbot:
   - **path**: The endpoint path appended to the base URL.
   - **method**: The HTTP method to use (e.g., POST, GET).
   - **headers**: Any custom headers required for the API request (e.g., authorization tokens).
   - **payload_template**: The structure of the message being sent, often including placeholders for dynamic content (e.g., `{user_msg}`).
4. **response_path**: A dot-separated path to extract the bot's reply from the JSON response.

These fields allow you to customize how your chatbot interacts with the API, ensuring that messages are formatted correctly and responses are parsed accurately.
