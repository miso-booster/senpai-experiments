Sure! Here’s a profile that represents a user seeking support related to the CAU (Centro de Atención a Usuarios). This profile will help you test the UAM chatbot effectively. 

```yaml
test_name: "CAU Support Inquiry"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca información sobre el Centro de Atención a Usuarios (CAU)."
  context:
    - "Necesito obtener información de contacto del CAU, incluyendo el número de teléfono, correo electrónico, ubicación física y horarios de atención."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir la dirección de correo electrónico del CAU."
    - "Consultar la ubicación física del CAU."
    - "Preguntar sobre los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - phone_contact:
        type: string
        description: "Número de teléfono de contacto del CAU"
    - email_contact:
        type: string
        description: "Correo electrónico de contacto del CAU"
    - physical_location:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

### Breakdown of the Profile:
- **Test Name**: A clear title for the profile.
- **LLM Configuration**: Specifies the model and temperature for the chatbot interaction.
- **User Section**: Defines the user’s language, role, context, and goals. The context provides background on the user's needs, while the goals outline specific inquiries.
- **Chatbot Section**: Describes the chatbot's fallback message and the expected output fields that should be extracted after the conversation.
- **Conversation Controls**: Specifies the number of interactions and the style of interaction.
