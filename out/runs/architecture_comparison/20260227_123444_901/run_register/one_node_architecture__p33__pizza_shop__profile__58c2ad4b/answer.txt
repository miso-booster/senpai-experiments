¡Claro! Aquí tienes un perfil para probar el chatbot de una pizzería. Este perfil incluye los campos que mencionaste en el `chatbot.output`.

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza."
  context:
    - "You want to know about pizza types and drinks."
  goals:
    - "Ask about the available pizza types."
    - "Order a pizza and a drink."
    - "Request the final price of the order."

chatbot:
  is_starter: true
  fallback: "Sorry, I didn't understand that."
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink:
        type: string
        description: "The drink ordered."
    - order_id:
        type: string
        description: "The unique identifier for the order."
    - final_price:
        type: currency
        description: "The final price of the order in dollars."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - long phrases
    - make spelling mistakes
```
