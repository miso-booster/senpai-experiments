Great question! 😊 In the context of Sensei, a **metamorphic rule** is a specific type of rule used in testing conversational agents. It helps ensure that the chatbot behaves correctly by checking the relationships between different conversations rather than just looking for absolute correctness.

Here's a simple breakdown:

1. **Definition**: A metamorphic rule states a condition that must hold true across multiple conversations. It compares pairs or tuples of conversations to assert how outputs should change (or remain the same) when certain inputs change.

2. **Purpose**: The main goal is to alleviate the "oracle problem," which is the challenge of determining the correct output for every possible input. Instead of needing to know the exact answer, you can check if the relationships between inputs and outputs are consistent.

3. **Structure**: In Sensei-check, you write these rules in YAML format. Each rule specifies:
   - How many conversations it needs to evaluate.
   - An optional filter to select which conversations to compare.
   - The relationship that should hold true between the selected conversations.

For example, you might have a rule that states if two pizza orders have the same size and drink, then the order with more toppings should cost more. This checks the relationship between the number of toppings and the price, ensuring consistency in the chatbot's pricing logic.
