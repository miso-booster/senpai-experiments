¡Claro! Vamos a crear un perfil para que puedas testear el chatbot de la UAM y obtener la información que necesitas sobre el CAU. Aquí tienes un ejemplo de cómo podría verse tu perfil en YAML:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca soporte sobre el CAU."
  context:
    - "Necesito información sobre cómo contactar al CAU."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Cuál es el correo electrónico de contacto del CAU?"
    - "¿Cuál es la dirección física del CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: false
  fallback: "¿Me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - phone_contact:
        type: string
        description: "Número de teléfono del CAU"
    - email_contact:
        type: string
        description: "Correo electrónico de contacto del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

### Explicación de cada sección:

- **test_name**: El nombre del perfil que estás creando.
- **llm**: Configuración del modelo de lenguaje que usarás.
- **user**: Define el usuario simulado, su rol y el contexto de la conversación.
- **goals**: Las preguntas que el usuario hará para obtener la información deseada.
- **chatbot**: Aquí defines cómo se comportará el chatbot, incluyendo su mensaje de fallback y la información que se espera extraer.
- **conversation**: Controla el número de interacciones y el estilo de interacción.

Puedes ajustar los detalles según tus necesidades. ¡Espero que esto te ayude a comenzar! Si necesitas más cambios o detalles, no dudes en decírmelo 😊.
