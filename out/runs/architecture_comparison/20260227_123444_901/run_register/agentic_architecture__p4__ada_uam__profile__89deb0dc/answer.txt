¡Hola! 😊 Vamos a crear un perfil para testear el chatbot de la UAM que permita a un usuario obtener soporte sobre el CAU (Centro de Atención a Usuarios). Este perfil incluirá la obtención de información como el número de teléfono, email, dirección física y horarios.

### Estructura del perfil

Aquí tienes un ejemplo de cómo podría ser el perfil en YAML:

```yaml
test_name: "UAM_CAU_Support"

llm:
  temperature: 0.7
  model: "gpt-4o"
  model_prov: "openai"
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca soporte del Centro de Atención a Usuarios (CAU) de la UAM."
  context:
    - "El usuario necesita información sobre contacto y horarios del CAU."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Cuál es el email del CAU?"
    - "¿Dónde se encuentra la dirección física del CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: true
  fallback: "Lo siento, no pude entender tu solicitud. ¿Puedes reformularla?"
  output:
    - telefono:
        type: string
        description: "Número de teléfono del CAU"
    - email:
        type: string
        description: "Email del CAU"
    - direccion:
        type: string
        description: "Dirección física del CAU"
    - horarios:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Explicación de la estructura

- **test_name**: Nombre del perfil para identificarlo fácilmente.
- **llm**: Configuraciones del modelo de lenguaje que se utilizará.
- **user**: Define el lenguaje, rol y contexto del usuario simulado, así como los objetivos que busca alcanzar.
- **chatbot**: Especifica si el chatbot inicia la conversación, un mensaje de fallback y los campos de salida que se extraerán al final de la conversación.
- **conversation**: Controla el número de conversaciones y el estilo de interacción.

### Siguientes pasos

1. **Revisar el perfil**: Asegúrate de que todos los campos y descripciones sean correctos.
2. **Guardar el perfil**: Puedes guardarlo en un archivo YAML en la carpeta de perfiles de tu proyecto.
3. **Ejecutar pruebas**: Una vez guardado, podrás usarlo para probar el chatbot y validar que responde correctamente a las consultas sobre el CAU.
