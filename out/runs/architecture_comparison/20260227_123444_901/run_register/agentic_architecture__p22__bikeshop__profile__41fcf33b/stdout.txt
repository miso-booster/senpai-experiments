### Profile Structure

Here's a breakdown of what we'll include in the profile:

- **Test Name**: A descriptive name for the profile.
- **User Details**:
  - **Language**: The language the user will communicate in.
  - **Role**: A description of the user's situation and intent.
  - **Context**: Any specific preferences or constraints.
  - **Goals**: The actions the user wants to achieve during the conversation.
- **Chatbot Details**:
  - **Is Starter**: Indicates if the user starts the conversation.
  - **Fallback Message**: A message the chatbot can use if it doesn't understand.
  - **Output Fields**: What we want to extract from the conversation.
- **Conversation Controls**: How many conversations to simulate and interaction styles.
