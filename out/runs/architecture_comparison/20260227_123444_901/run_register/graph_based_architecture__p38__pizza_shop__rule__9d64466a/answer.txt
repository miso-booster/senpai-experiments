¡Claro! Para crear una regla que verifique si el asistente confirma que ha añadido la bebida que el usuario pidió, podemos usar una estructura similar a las reglas que ya tienes.

Aquí tienes un ejemplo de cómo podría ser la regla en YAML:

```yaml
name: confirm_drink_added
description: El asistente debe confirmar que ha añadido la bebida solicitada por el usuario.
conversations: 1
if: utterance_index('user', 'ordenar bebida') >= 0  # Verifica si el usuario ha mencionado que quiere ordenar una bebida
then: utterance_index('assistant', 'confirmar bebida') > 0  # Verifica que el asistente confirme que la bebida ha sido añadida
```

### Explicación:
- **`if`**: Verificamos si el usuario ha mencionado que quiere ordenar una bebida.
- **`then`**: Comprobamos que el asistente haya confirmado que la bebida ha sido añadida.

Recuerda ajustar las frases en `utterance_index` según las respuestas específicas que tu asistente utiliza. Si necesitas más ayuda o ajustes, ¡no dudes en decírmelo! 😊
