Sure! Here’s a profile for a pizza shop where the user is rude and wants things done quickly. I've included four goals with four variables, two of which use pairwise functions to help determine the conversation number. Let’s dive in! 🍕✨

```yaml
test_name: "rude_fast_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "You are a rude customer who wants to place a pizza order quickly without any nonsense."
  context:
    - "You expect fast responses and don't tolerate delays."
  goals:
    - "Get me a {{pizza_type}} pizza."
    - "Make it {{pizza_size}} and add {{toppings}}."
    - "I want {{number_of_drinks}} {{drink_type}}."
    - "How long until it's ready?"

    - pizza_type:
        function: pairwise()
        type: string
        data: [Margherita, Pepperoni, Vegetarian, BBQ Chicken]
    - pizza_size:
        function: pairwise()
        type: string
        data: [small, medium, large]
    - toppings:
        function: random()
        type: string
        data: [extra cheese, mushrooms, olives, peppers]
    - number_of_drinks:
        function: forward()
        type: int
        data:
          min: 1
          max: 5
    - drink_type:
        function: pairwise()
        type: string
        data: [Fountain Drink, Bottled Soda, Juice]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't catch that. Just tell me what you want!"
  output:
    - order_confirmation:
        type: string
        description: "Confirmation of the pizza order details."
    - estimated_time:
        type: time("hh:mm")
        description: "Estimated time for the order to be ready."

conversation:
  number: combinations(0.5, pairwise)  # Using pairwise for pizza_type and pizza_size
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - single questions
```

### Breakdown:
- **User Role**: The user is rude and expects quick responses.
- **Goals**: Four goals are set to get the pizza order done fast, with variables that include pairwise functions for `pizza_type` and `pizza_size`.
- **Conversation Number**: The conversation number is determined by the combinations of the pairwise functions.
