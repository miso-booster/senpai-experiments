Sure! Here’s a simple profile that asks the chatbot for items to add to the user's shopping cart. You can customize it further based on your specific needs! 😊

```yaml
test_name: "Shopping Cart Addition"

llm:
  temperature: 0.7
  model: gpt-4o
  format:
    type: text

user:
  language: English
  role: "A customer looking to add items to their shopping cart."
  context:
    - "You are preparing for a family gathering and want to ensure you have all the necessary ingredients."
    - "You prefer to shop for fresh produce and snacks."
  goals:
    - "Ask the chatbot for recommendations on fresh fruits to add to the cart."
    - "Request suggestions for snacks suitable for a family gathering."
    - "Inquire about any current promotions on grocery items."
    - "Ask for a list of essential ingredients for a popular recipe."

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't quite catch that. Could you please specify what you're looking for?"
  output:
    - fresh_fruits:
        type: string
        description: "List of recommended fresh fruits to add to the shopping cart."
    - snack_options:
        type: string
        description: "Suggestions for snacks suitable for a family gathering."
    - promotions:
        type: string
        description: "Current promotions on grocery items."
    - recipe_ingredients:
        type: string
        description: "Essential ingredients for a popular recipe."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

Feel free to adjust the `goals` or any other sections to better fit your requirements! Happy testing! 🛒✨
