In the context of Sensei-check, an **oracle** refers to a condition or rule that defines what the expected outcome should be for a given conversation or set of conversations. It acts like a reference point to determine whether the chatbot's responses are correct or not.

For example, if you have a rule that checks if the price of a pizza is greater than zero, the oracle would specify that the expected condition is true (i.e., the price should indeed be greater than zero). If the chatbot's response meets this condition, it passes the check; if not, it fails.

Oracles can be used for both single conversations (traditional checks) and for multiple conversations (metamorphic testing), where they help ensure that the chatbot behaves as intended across different scenarios.
