```yaml
test_name: "custom_to_predefined_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "You are a customer who initially wants to order a custom pizza but changes your mind halfway through."
  context:
    - "You are looking for a delicious pizza for a casual gathering."
  goals:
    - "I would like to order a custom pizza with {{custom_toppings}}."
    - "Actually, can I get a {{predefined_pizza}} instead?"
    - custom_toppings:
        function: random()
        type: string
        data: [pepperoni, mushrooms, onions, olives, extra cheese]
    - predefined_pizza:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Can you please clarify?"
  output:
    - order_confirmation:
        type: string
        description: "Confirmation of the pizza order, including type and toppings."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - change your mind
    - single questions
```

### Key Elements:
- **Role**: The user is defined as someone who initially wants a custom pizza but changes their mind.
- **Goals**: The user has two main goals: to order a custom pizza and then to switch to a predefined pizza.
- **Interaction Style**: The `change your mind` style allows for the user to alter their request during the conversation.
