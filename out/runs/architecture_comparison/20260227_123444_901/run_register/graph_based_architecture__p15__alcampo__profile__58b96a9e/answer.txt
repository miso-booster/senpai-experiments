¡Claro! Aquí tienes un perfil que puedes usar para probar la capacidad del chatbot de Alcampo en recomendar recetas y planificación de menús. Este perfil está diseñado para simular un usuario que busca ayuda en la cocina y en la planificación de comidas. Puedes ajustarlo según tus necesidades.

```yaml
test_name: "Recetas y Planificación de Menús"

llm:
  temperature: 0.7
  model: gpt-4o
  format:
    type: text

user:
  language: English
  role: "You are a user looking for recipe recommendations and meal planning assistance."
  context:
    - "You want to explore healthy recipes that incorporate seasonal ingredients."
    - "You are interested in meal prep ideas to save time during the week."
  goals:
    - "Ask for healthy recipe suggestions using seasonal vegetables."
    - "Request a weekly meal plan that includes breakfast, lunch, and dinner."
    - "Inquire about quick recipes for busy weekdays."
    - "Ask for tips on meal prepping for the week."
    - "Request ideas for vegetarian meals."

chatbot:
  is_starter: false
  fallback: "Lo siento, no entendí tu pregunta. 😊 ¿Cómo puedo ayudarte con recetas o planificación de menús?"
  output:
    - recipe_suggestions:
        type: string
        description: "Recommendations for healthy recipes."
    - meal_plan:
        type: string
        description: "A weekly meal plan including breakfast, lunch, and dinner."
    - quick_recipes:
        type: string
        description: "Quick recipes for busy weekdays."
    - meal_prepping_tips:
        type: string
        description: "Tips for effective meal prepping."
    - vegetarian_meals:
        type: string
        description: "Ideas for vegetarian meals."

conversation:
  number: 5
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```

Este perfil simula un usuario que busca recetas y planificación de menús, lo que debería ayudarte a evaluar cómo el chatbot de Alcampo responde a esas solicitudes. ¡Espero que te sea útil! Si necesitas más ajustes o información, ¡no dudes en decírmelo! 😊
