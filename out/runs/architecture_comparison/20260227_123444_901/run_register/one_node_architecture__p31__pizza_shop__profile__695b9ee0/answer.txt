Sure! Here’s a profile for a pizza shop where the user is rude and wants things done quickly. I've included four goals with four variables, and two of them use pairwise functions to help determine the conversation number.

```yaml
test_name: "rude_fast_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a rude customer who demands quick service."
  context:
    - "You don't have time for chit-chat."
  goals:
    - "I want a {{size}} pizza with {{toppings}}. Make it quick!"
    - "I also need {{cans}} cans of {{drink}}. Hurry up!"
    - "What's the total cost? I need it now!"
    - "When will it be ready? Don't keep me waiting!"

inputs:
  - name: size
    type: string
    data: ['small', 'medium', 'large', 'extra large']
    function: pairwise()
  - name: toppings
    type: string
    data: ['cheese', 'mushrooms', 'pepperoni', 'olives']
    function: pairwise()
  - name: cans
    type: int
    data: {'min': 1, 'max': 5, 'step': 1}
    function: forward()
  - name: drink
    type: string
    data: ['sprite', 'coke', 'orange fanta']
    function: forward()

chatbot:
  is_starter: true
  fallback: "What do you want?"
  output:
    - price:
        type: currency
        description: "The total price of the pizza order"
    - time:
        type: time(hh:mm:ss)
        description: "Estimated time for the order to be ready"
    - order_id:
        type: string
        description: "Your order ID"

conversation:
  number: combinations(0.5, pairwise)
  goal_style:
    steps: 4
  interaction_style:
    - long phrases
```
