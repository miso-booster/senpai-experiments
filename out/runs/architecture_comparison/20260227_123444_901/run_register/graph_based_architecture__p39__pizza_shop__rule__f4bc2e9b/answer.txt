Sure! To create a rule that checks if the order ID was provided by the chatbot, you can use a simple single-conversation oracle. Here’s how it would look in YAML format:

```yaml
name: order_id_provided
description: The chatbot must return an order ID in the response.
conversations: 1
oracle: "'order_id' in chatbot.output"
```

### Explanation:
- **name**: This is the identifier for the rule, which is "order_id_provided."
- **description**: A brief explanation of what the rule checks for, which is that the chatbot must return an order ID.
- **conversations**: Set to 1, as this rule checks a single conversation.
- **oracle**: This expression checks if the `order_id` is present in the chatbot's output.
