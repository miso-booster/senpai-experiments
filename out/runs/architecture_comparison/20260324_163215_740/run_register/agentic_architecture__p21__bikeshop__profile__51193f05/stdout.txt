### Proposed Profile Structure

```yaml
test_name: "bikeshop_customization"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer who recently bought a new bike and wants to customize it."
  context:
    - "The customer wants to change the seat and handlebar grips."
  goals:
    - "Request to change the seat and handlebar grips for the bike."
    - "Ask about the available options for seat and grips."
    - "Inquire about the cost of customization."
    - "Confirm the appointment for the customization."

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you repeat that?"
  output:
    - customization_options:
        type: list[string]
        description: "List of available customization options."
    - total_cost:
        type: currency
        description: "Total cost for the customization."
    - appointment_confirmation:
        type: string
        description: "Confirmation of the appointment for customization."

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Explanation of the Profile
- **test_name**: A descriptive name for the profile.
- **llm**: Settings for the language model, including temperature and model type.
- **user**: Defines the user's language, role, context, and goals.
  - The goals outline what the user wants to achieve in the conversation.
- **chatbot**: Specifies whether the chatbot starts the conversation, provides a fallback message, and outlines the output fields to be extracted.
- **conversation**: Controls how many conversations to simulate and the interaction style.
