¡Claro! Aquí tienes un perfil que puedes usar para probar la capacidad del chatbot de Alcampo en recomendar recetas y ayudar con la planificación de menús. Este perfil está diseñado para simular a un usuario que busca inspiración y asistencia en la cocina. 😊

```yaml
test_name: "Recipe Management and Menu Planning"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A user looking for recipe recommendations and menu planning assistance."
  context:
    - "You are excited to explore new recipes and meal ideas to enhance your cooking skills."
    - "You want to focus on seasonal ingredients and healthy meal options."
    - "You're interested in finding recipes that cater to specific dietary preferences."
  goals:
    - "Ask for recipes that include seasonal vegetables."
    - "Request meal planning ideas for a week."
    - "Inquire about healthy recipes for family dinners."
    - "Ask for tips on how to incorporate more plant-based meals into your diet."
    - "Request a list of ingredients needed for a selected recipe."

chatbot:
  is_starter: false
  fallback: "Parece que tu mensaje no es claro o no es una pregunta relacionada con recetas. 😊 ¿En qué puedo ayudarte hoy? Estoy aquí para ayudarte a encontrar recetas deliciosas y saludables."
  output:
    - seasonal_recipes:
        type: string
        description: "List of recipes that include seasonal vegetables."
    - meal_planning_ideas:
        type: string
        description: "Suggestions for meal planning for a week."
    - healthy_dinner_recipes:
        type: string
        description: "Healthy recipes suitable for family dinners."
    - plant_based_meals:
        type: string
        description: "Tips for incorporating more plant-based meals."
    - recipe_ingredients:
        type: string
        description: "List of ingredients needed for a selected recipe."

conversation:
  number: 5
  max_cost: 0.5
  goal_style:
    steps: 20
  interaction_style:
    - single questions
```

¡Espero que este perfil te ayude a probar la funcionalidad del chatbot de Alcampo! Si necesitas más ajustes o tienes alguna otra pregunta, no dudes en decírmelo. ¡Feliz prueba! 🍽️✨
