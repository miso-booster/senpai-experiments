Sure! Here’s a profile you can use to test a bike shop chatbot for a user who wants to set an appointment to have their wheels changed. This profile includes different variables to test various days and times for the appointment. Feel free to adjust any details as needed! 😊

```yaml
test_name: "wheel_change_appointment"

llm:
  temperature: 0.5
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer looking to schedule an appointment to have their wheels changed."
  context:
    - "You need to get your bike's wheels changed and want to ensure you can find a suitable time."
    - "You prefer to have the appointment as soon as possible."
  goals:
    - "Schedule an appointment for wheel change on {{appointment_date}} at {{appointment_time}}."
    - appointment_date:
        function: random()
        type: string
        data: [tomorrow, 'November 6th, 2024', 'November 7th, 2024', 'November 8th, 2024']
    - appointment_time:
        function: random()
        type: string
        data: ['10:00 AM', '1:00 PM', '3:00 PM', '5:00 PM']

chatbot:
  is_starter: true
  fallback: "I'm sorry, it's a little loud in my shop, can you say that again?"
  output:
    - confirmed_date:
        type: date
        description: "The date of the appointment confirmed by the assistant."
    - confirmed_time:
        type: str
        description: "The hour of the appointment confirmed by the assistant."
    - appointment_confirmation:
        type: string
        description: "Confirmation message of the scheduled appointment."

conversation:
  number: 4
  goal_style:
    all_answered:
      export: true
      limit: 5
  interaction_style:
    - default
```

### Explanation:
- **Goals**: The user will schedule an appointment for wheel change, specifying both the date and time.
- **Variables**: 
  - `appointment_date` includes different days to test the chatbot's handling of scheduling.
  - `appointment_time` includes various times for the appointment.
- **Chatbot Output**: The profile specifies what the chatbot should confirm after the appointment is scheduled.
