Let's create a profile for a pizza shop where the user is rude and wants things done fast. We'll include four goals with variables, two of which will utilize pairwise functions to determine the conversation number through a pairwise matrix.

Here's the profile YAML:

```yaml
test_name: "pizza_shop_rude_customer"

llm:
  temperature: 0.5
  model: gpt-4
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a rude customer who wants fast service."
  context:
    - "You often complain about waiting times."
  goals:
    - "Order a {{size}} pizza with {{toppings}} quickly."
    - "I need it ready by {{time}}."
    - "How much will it cost for {{quantity}} pizzas?"
    - "Make sure it's delivered to {{address}}."
    - size:
        function: random()
        type: string
        data: [small, medium, large]
    - toppings:
        function: pairwise()
        type: string
        data: [pepperoni, mushrooms, onions, olives]
    - time:
        function: random()
        type: string
        data: [ASAP, in 10 minutes, in 15 minutes]
    - quantity:
        function: pairwise()
        type: int
        data:
          min: 1
          max: 5
    - address:
        function: random()
        type: string
        data: ["123 Pizza St", "456 Fast Lane", "789 Quick Rd"]

chatbot:
  is_starter: true
  fallback: "What do you want?"
  output:
    - total_price:
        type: currency
        description: "Total cost of the order"
    - delivery_time:
        type: time("hh:mm")
        description: "Estimated delivery time"
    - order_id:
        type: string
        description: "Order confirmation ID"

conversation:
  number: combinations(0.5, pairwise)  # Two pairwise functions declared
  goal_style:
    steps: 5
  interaction_style:
    - long phrases
    - make spelling mistakes
```

- **User Role**: A rude customer wanting fast service.
- **Goals**:

  - Specifying a delivery time.
  - Asking for the cost of multiple pizzas.
  - Providing a delivery address.
- **Variables**: 
  - `size` (random selection).
  - `toppings` (pairwise combinations).
  - `time` (random selection).
  - `quantity` (pairwise combinations).
  - `address` (random selection).
- **Chatbot Output**: Includes total price, estimated delivery time, and order ID.
- **Conversation Control**: Uses a combination of pairwise functions to determine the conversation number.
