¡Claro! Vamos a crear un perfil para tu chatbot de la UAM que se enfoque en obtener soporte sobre el CAU. Aquí tienes un ejemplo de cómo podría verse el perfil en formato YAML:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita soporte del CAU."
  context:
    - "Buscas obtener información sobre cómo contactar al CAU."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico de contacto del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar sobre los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "¿Puedes reformular tu pregunta? O consulta nuestro catálogo de servicios."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU."
    - contact_email:
        type: string
        description: "Correo electrónico de contacto del CAU."
    - physical_address:
        type: string
        description: "Dirección física del CAU."
    - service_hours:
        type: string
        description: "Horarios de atención del CAU."

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

### Desglose del perfil:

- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje, puedes ajustar la temperatura según lo necesites.
- **user**: Define el rol del usuario y el contexto de su búsqueda.
- **goals**: Aquí se especifican las preguntas que el usuario hará para obtener la información deseada.
- **chatbot**: Incluye la respuesta de respaldo y los campos de salida que quieres extraer.
- **conversation**: Define el número de interacciones y el estilo de interacción.

Puedes ajustar cualquier parte de este perfil según tus necesidades. ¡Espero que esto te ayude a comenzar! Si necesitas más ajustes o detalles, no dudes en decirme. 😊
