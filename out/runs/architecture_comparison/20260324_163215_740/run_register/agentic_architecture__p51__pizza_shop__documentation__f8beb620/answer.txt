Connectors in the SENSEI framework are used to integrate with external chatbot APIs without requiring any coding. You create a YAML configuration file that specifies how to communicate with the chatbot's API. Here's a breakdown of the key components and fields involved in a connector:

### Purpose of Connectors
- **Integration**: Connectors allow your chatbot to send and receive messages from external APIs.
- **Configuration**: You can easily configure the connection settings in a structured YAML format.

### Key Fields in a Connector
Here are the main fields you would typically include in a connector configuration:

| Field                       | Description                                                       | Required         |
|-----------------------------|-------------------------------------------------------------------|------------------|
| `name`                      | Friendly name for your chatbot                                     | No               |
| `base_url`                 | Base URL of the chatbot API                                       | Yes              |
| `send_message.path`        | API endpoint path (appended to `base_url`)                       | Yes              |
| `send_message.method`      | HTTP method (e.g., POST, GET, PUT, DELETE)                       | No (default: POST) |
| `send_message.headers`     | Custom headers (e.g., Authorization)                              | No               |
| `send_message.payload_template` | JSON structure with a placeholder for the user's message `{user_msg}` | Yes              |
| `response_path`            | Dot-separated path to extract the bot's reply from the JSON response | Yes              |

### Example Connector Configuration
Here's a simple example of a connector configuration:

```yaml
name: "My Custom Bot"
base_url: "https://api.mychatbot.com"
send_message:
  path: "/chat"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

### Additional Notes
- The `response_path` field is crucial as it defines how to navigate through the JSON response to extract the chatbot's reply.
- You can include authentication headers in the `send_message.headers` section if required by the API.
