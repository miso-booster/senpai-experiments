Connectors in the Sensei framework are used to define how your chatbot interacts with various APIs. They allow you to send messages to a chatbot and receive responses, facilitating the testing and validation of your chatbot's behavior in different scenarios.

### Key Fields in a Connector

Here are the main fields you typically find in a connector configuration:

1. **name**: A friendly name for your chatbot connector. This helps identify the connector in your project.

2. **base_url**: The base URL of the chatbot API you are connecting to. This is the starting point for all API requests.

3. **send_message**: This section defines how to send messages to the chatbot. It includes:
   - **path**: The specific endpoint path that gets appended to the base URL for sending messages.
   - **method**: The HTTP method to use (e.g., POST, GET). The default is usually POST.
   - **headers**: Any custom headers required for the API request, such as authentication tokens.
   - **payload_template**: The structure of the message you send to the chatbot, often including placeholders (like `{user_msg}`) for dynamic content.

4. **response_path**: This defines how to extract the chatbot's reply from the JSON response. It uses dot notation to navigate through the response structure.

### Example Connector Configuration

Here's a simple example to illustrate these fields:

```yaml
name: "Echo Bot"
base_url: "https://postman-echo.com"
send_message:
  path: "/post"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "json.message"
```

In this example:
- The connector is named "Echo Bot".
- It connects to the Postman Echo API.
- It sends a POST request to the `/post` endpoint with a message.
- The response is extracted from the `json.message` path in the response.
