¡Claro! Vamos a crear un perfil para que un usuario obtenga soporte sobre el CAU de la UAM. Este perfil incluirá los detalles que mencionaste: número de teléfono, email, dirección física y horarios.

Aquí tienes un ejemplo de cómo podría ser el perfil en YAML:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita soporte del CAU."
  context:
    - "Buscas información sobre cómo contactar al Centro de Atención a Usuarios."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico de contacto del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar sobre los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - phone_contact:
        type: string
        description: "Número de teléfono del CAU."
    - email_contact:
        type: string
        description: "Correo electrónico de contacto del CAU."
    - physical_address:
        type: string
        description: "Dirección física del CAU."
    - operational_hours:
        type: string
        description: "Horarios de atención del CAU."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

Este perfil está diseñado para que el usuario pueda hacer preguntas específicas sobre el CAU y obtener la información necesaria. Puedes ajustarlo según tus necesidades o agregar más detalles si lo deseas. ¡Espero que te sirva! 😊
