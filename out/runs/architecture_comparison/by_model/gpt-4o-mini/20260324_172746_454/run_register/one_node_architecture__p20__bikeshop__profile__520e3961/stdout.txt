Sure! Here’s a profile for a user who wants to set an appointment to have their wheels changed at a bike shop. This profile includes variables for different days and times to test how the chatbot manages appointments. Let’s dive in! 🚴‍♂️

```yaml
test_name: "wheel_change_appointment"

llm:
  temperature: 0.5
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer looking to set an appointment to change their bike wheels."
  context:
    - "You need to change your bike wheels soon."
    - "You want to ensure the appointment is at a convenient time."
  goals:
    - "Schedule an appointment for changing my bike wheels on {{appointment_date}} at {{appointment_time}}."
    - appointment_date:
        function: random()
        type: string
        data: [tomorrow, "November 6th, 2024", "next Monday", "this weekend"]
    - appointment_time:
        function: random()
        type: string
        data: ["10:00 AM", "2:00 PM", "3:30 PM", "4:00 PM"]

chatbot:
  is_starter: true
  fallback: "I'm sorry, it's a little loud in my shop, can you say that again?"
  output:
    - confirmed_date:
        description: "The date of the appointment confirmed by the assistant."
        type: date
    - confirmed_time:
        description: "The time of the appointment confirmed by the assistant."
        type: string
    - appointment_confirmation:
        description: "Confirmation message of the scheduled appointment."
        type: string

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 5
  interaction_style:
    - default
```

This profile sets up a user who is looking to schedule an appointment for changing bike wheels, with variables for different dates and times to test the chatbot's handling of these inputs. Feel free to modify any part of it to better suit your needs! 😊
