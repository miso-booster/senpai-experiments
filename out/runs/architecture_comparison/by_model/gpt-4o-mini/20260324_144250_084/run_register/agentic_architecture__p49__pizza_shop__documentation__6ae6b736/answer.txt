The **pairwise function** in the context of SENSEI-check rules is part of the **metamorphic testing** approach. Here's how it works:

### Overview of Pairwise Function in Metamorphic Testing

1. **Purpose**: The pairwise function is used to compare **pairs of conversations** that meet specific selection criteria. This helps in validating how outputs should change (or remain the same) when inputs are varied.

2. **Key Components**:
   - **Conversations**: It operates on two or more conversations generated by the SENSEI Chat simulator.
   - **Selection Filter**: You can define a filter using the `when` clause to select which conversations to compare. For example, you might want to compare conversations where the size of the pizza is the same.
   - **Assertions**: The rules assert relationships between outputs of these conversations. For instance, if one conversation has more toppings than another, the price should also be higher.

3. **Example Structure**:
   A typical metamorphic rule using the pairwise function might look like this:

   ```yaml
   name: toppings_monotonicity
   description: More toppings should increase the price
   conversations: 2
   when: conv[0].size == conv[1].size
   if: len(conv[0].toppings) > len(conv[1].toppings)
   then: extract_float(conv[0].price) > extract_float(conv[1].price)
   ```

   - **`when`**: This condition filters pairs of conversations based on the size of the pizza.
   - **`if`**: This checks if the first conversation has more toppings than the second.
   - **`then`**: This asserts that the price of the first conversation should be greater than that of the second.

### Benefits of Using Pairwise Testing
- **Reduces Oracle Problem**: Instead of checking for absolute correctness, it checks for relationships, which can be more manageable and insightful.
- **Increases Coverage**: By comparing pairs, you can cover more scenarios and edge cases that might not be evident when testing single conversations.

### Conclusion
The pairwise function is a powerful tool in SENSEI-check for ensuring that your chatbot behaves consistently and correctly across different scenarios by validating relationships between conversation outputs.
