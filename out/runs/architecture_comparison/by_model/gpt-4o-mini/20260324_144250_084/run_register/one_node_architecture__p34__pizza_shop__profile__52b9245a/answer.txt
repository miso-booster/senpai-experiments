That sounds like a fun scenario to test! Here's a profile that captures a user who initially asks for a custom pizza but then changes their mind and requests a predefined pizza instead. 

Feel free to modify any details to better fit your needs!

```yaml
test_name: "custom_to_predefined_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer trying to order a pizza. You start by asking for a custom pizza but change your mind halfway through."
  context:
    - "You are ordering for a casual gathering with friends."
  goals:
    - "I would like to order a custom pizza with {{custom_toppings}}."
    - "Actually, can I get a {{predefined_pizza}} instead?"
    - custom_toppings:
        function: random()
        type: string
        data: [pepperoni, mushrooms, olives, extra cheese, bell peppers]
    - predefined_pizza:
        function: random()
        type: string
        data: [Margherita, Hawaiian, Pepperoni, Vegetarian, BBQ Chicken]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't quite catch that. Can you repeat your order?"
  output:
    - order_confirmation:
        type: string
        description: "Confirmation of the pizza order, including type and toppings."
    - estimated_time:
        type: time("hh:mm")
        description: "Estimated time for the pizza to be ready."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - change your mind
    - long phrases
```
