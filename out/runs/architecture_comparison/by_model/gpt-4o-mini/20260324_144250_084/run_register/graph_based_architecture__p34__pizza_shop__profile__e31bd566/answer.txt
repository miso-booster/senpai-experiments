That sounds like a fun scenario to test! 😊 You can create a profile that captures this behavior by defining the user goals and including the interaction style that allows for changing opinions. Here’s a sample profile you can use as a template:

```yaml
test_name: "custom_to_predefined_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer who initially wants to order a custom pizza but changes their mind halfway."
  context:
    - "You are planning a pizza night and want to explore options."
    - "You start by asking for a custom pizza but then decide to go with a predefined option."
  goals:
    - "I would like to order a custom pizza with {{custom_toppings}}."
    - "Actually, can I get a {{predefined_pizza}} pizza instead?"
    - custom_toppings:
        function: random()
        type: string
        data: [pepperoni, mushrooms, olives, extra cheese, bell peppers]
    - predefined_pizza:
        function: random()
        type: string
        data: [Margherita, Hawaiian, Pepperoni, Vegetarian, BBQ Chicken]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't quite catch that. Could you repeat your order?"
  output:
    - order_confirmation:
        type: string
        description: "Confirmation of the pizza order."
    - order_id:
        type: string
        description: "Your order ID for tracking."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - change your mind
    - long phrases

```

### Explanation:
- **Goals**: The user starts by asking for a custom pizza and then changes their mind to a predefined pizza.
- **Interaction Style**: The `change your mind` style allows the user to express a change in their request during the conversation.
- **Output**: The chatbot will provide confirmation and an order ID for tracking.

Feel free to modify the toppings and pizza types as per your needs! Happy testing! 🍕😊
