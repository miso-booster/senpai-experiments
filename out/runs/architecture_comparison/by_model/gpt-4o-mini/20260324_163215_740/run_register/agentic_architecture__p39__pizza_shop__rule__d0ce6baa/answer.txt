To create a metamorphic rule that checks if adding a drink costs an extra $2, we need to ensure that the rule references the appropriate output field from the profile. The output field you specified is "drink." 

Here's how the rule will be structured:

### Metamorphic Rule Structure
- **Name**: A descriptive name for the rule.
- **Description**: What the rule is checking.
- **Conversations**: This will be set to 2, as we need to compare two conversations.
- **When**: This will filter the conversations to ensure they are comparable (e.g., same pizza size and number).
- **If/Then**: This will check that the price of the conversation with the drink is $2 more than the one without.

### Proposed YAML for the Rule
```yaml
name: drink_price_check
description: Adding a drink to the order costs an extra $2
conversations: 2
when: conv[0].size == conv[1].size and conv[0].number == conv[1].number
if:   conv[0].drink is None and conv[1].drink is not None
then: extract_float(conv[1].price) == extract_float(conv[0].price) + 2
```

### Explanation
- **Name**: `drink_price_check` — This clearly indicates what the rule is about.
- **Description**: It explains that the rule checks if adding a drink increases the price by $2.
- **Conversations**: Set to `2` to compare two conversations.
- **When**: Ensures that both conversations are for the same size and quantity of pizzas.
- **If**: Checks that the first conversation does not have a drink while the second does.
- **Then**: Asserts that the price of the second conversation (with the drink) is exactly $2 more than the first (without the drink).

This rule assumes that the profile used exposes the `size`, `number`, `drink`, and `price` fields in its `chatbot.output`.
