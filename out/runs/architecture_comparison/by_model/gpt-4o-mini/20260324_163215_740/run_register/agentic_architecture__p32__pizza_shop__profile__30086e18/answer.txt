¡Vamos a crear un perfil para probar el chatbot de una pizzería! Este perfil incluirá los campos que mencionaste: tipo de pizza, bebida, ID del pedido y precio final en dólares.

Aquí tienes el YAML del perfil:

```yaml
test_name: "pizzeria_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Cliente que desea hacer un pedido de pizza."
  context:
    - "El cliente prefiere opciones vegetarianas."
  goals:
    - "Quiero pedir una pizza de {{tipo_pizza}} con {{bebida}}."
    - tipo_pizza:
        function: random()
        type: string
        data: [margarita, pepperoni, cuatro quesos, vegetariana]
    - bebida:
        function: random()
        type: string
        data: [agua, refresco, cerveza]
    
chatbot:
  is_starter: true
  fallback: "Lo siento, no entendí eso. ¿Puedes repetirlo?"
  output:
    - tipo_pizza:
        type: string
        description: "Tipo de pizza seleccionada."
    - bebida:
        type: string
        description: "Bebida seleccionada."
    - order_id:
        type: string
        description: "ID del pedido."
    - total_price:
        type: currency
        description: "Precio final del pedido en dólares."

conversation:
  number: 1
  goal_style:
    steps: 2
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Resumen del perfil:
- **Nombre de prueba**: `pizzeria_order_test`
- **Salida del chatbot**:
  - `tipo_pizza`: Tipo de pizza seleccionada.
  - `bebida`: Bebida seleccionada.
  - `order_id`: ID del pedido.
  - `total_price`: Precio final del pedido en dólares.

Este perfil está diseñado para simular un cliente que hace un pedido en una pizzería. Si necesitas hacer ajustes o agregar más detalles, ¡házmelo saber! 😊
