¡Hola! 😊 He revisado la documentación sobre perfiles y ahora puedo ayudarte a crear un perfil para probar el chatbot de una pizzería. Este perfil incluirá los campos que mencionaste: tipo de pizza, bebida, ID del pedido y precio final en dólares.

Aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza."
  context:
    - "You want to order a pizza with a drink."
  goals:
    - "Order a {{pizza_type}} pizza with a {{drink}}."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, BBQ Chicken, Veggie]
    - drink:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you repeat that?"
  output:
    - pizza_type:
        type: string
        description: "Type of pizza ordered"
    - drink:
        type: string
        description: "Drink ordered"
    - order_id:
        type: string
        description: "Unique identifier for the order"
    - total_price:
        type: currency
        description: "Final price in dollars"

conversation:
  number: 1
  goal_style:
    steps: 2
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Resumen de la estructura:
- **test_name**: Nombre del test.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario y sus metas, incluyendo las variables para el tipo de pizza y la bebida.
- **chatbot**: Especifica cómo se debe comportar el chatbot y qué datos se deben extraer al final de la conversación.
- **conversation**: Controla el número de interacciones y el estilo de interacción.
