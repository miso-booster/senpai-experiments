In the context of Sensei and chatbot testing, an **oracle** is a mechanism or rule used to determine whether the output of a chatbot is correct or not. It acts as a reference point to validate the responses generated by the chatbot during testing.

For example, an oracle might specify that the chatbot should return a certain value when given a specific input. If the chatbot's output matches the expected value defined by the oracle, then the test is considered successful. If it doesn't match, the test fails.

In Sensei-check, oracles can be used in single-conversation checks or as part of metamorphic rules, where they help verify the relationships between different outputs based on varying inputs. This way, oracles help ensure that the chatbot behaves as intended and maintains conversational correctness. 😊
