### Profile Structure
Here’s a proposed structure for the profile:

- **Test Name**: A descriptive name for the profile.
- **LLM Settings**: Configuration for the language model.
- **User Role**: Describes the simulated user and their context.
- **Goals**: Specific goals the user wants to achieve, including asking for advice on adjustments or services.
- **Chatbot Output**: Fields to extract relevant information from the conversation.
- **Conversation Controls**: Defines how many conversations to run and the interaction style.

```yaml
test_name: "Bike Discomfort Inquiry"

  temperature: 0.7

  format:
    type: text

  language: English
  role: >
```
