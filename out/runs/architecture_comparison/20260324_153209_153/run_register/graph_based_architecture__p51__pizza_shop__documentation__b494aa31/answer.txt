Connectors are super useful in the Sensei framework! They allow you to connect your chatbot to various APIs, enabling seamless communication between your chatbot and external services. This means that your chatbot can send messages, receive responses, and interact with different platforms or systems.

### Key Fields in Connectors

Here are the main fields you typically find in a connector configuration:

1. **name**: A friendly name for your chatbot connector. This helps identify it easily.

2. **base_url**: The base URL of the chatbot API you want to connect to. This is the starting point for all your API requests.

3. **send_message**: This section contains details about how to send messages to the chatbot API:
   - **path**: The specific endpoint path that will be appended to the base URL for sending messages.
   - **method**: The HTTP method to use (like POST, GET, etc.). POST is commonly used for sending messages.
   - **headers**: Any custom headers needed for the API request (like authorization tokens).
   - **payload_template**: The structure of the message you want to send, often including placeholders like `{user_msg}` for dynamic content.

4. **response_path**: This field specifies how to extract the chatbot's reply from the JSON response. It uses dot notation to navigate through the response structure.

### Example Connector

Here’s a quick example of what a connector might look like:

```yaml
name: "My Custom Bot"
base_url: "https://api.mychatbot.com"
send_message:
  path: "/chat"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

In this example, the connector is set up to send messages to a chatbot API, and it specifies how to extract the response.
