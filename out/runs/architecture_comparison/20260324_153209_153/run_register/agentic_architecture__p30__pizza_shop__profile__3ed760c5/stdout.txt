Let's create a profile for a pizza shop where the user is rude and wants things done quickly. This profile will include four goals, with two of them utilizing pairwise functions to determine the conversation number. Here's the structure we'll follow:

### Profile Structure

1. **Test Name**: A descriptive name for the profile.
2. **LLM Settings**: Configuration for the language model.
3. **User Definition**:
   - **Language**: English
   - **Role**: Describes the rude user.
   - **Context**: Any additional personality traits or constraints.
   - **Goals**: Four goals with variables, including pairwise functions.
4. **Chatbot Output**: Fields to extract after the conversation.
5. **Conversation Controls**: Number of conversations and interaction styles.

### YAML Profile

Here's the YAML representation of the profile:

```yaml
test_name: "Pizza Shop Rude User"

llm:
  temperature: 0.5
  model: "gpt-4"
  model_prov: "openai"
  format:
    type: text

user:
  language: English
  role: "You are a rude customer who demands fast service."
  context:
    - "You want your pizza quickly and don't tolerate delays."
  goals:
    - "Order a {{size}} pizza with {{toppings}}."
    - "Request the total price in {{currency}}."
    - "Ask for a delivery time of {{delivery_time}}."
    - "Demand to speak to a manager if not satisfied."
    - size:
        function: random()
        type: string
        data: [small, medium, large]
    - toppings:
        function: pairwise()
        type: string
        data: [pepperoni, mushrooms, onions, olives]
    - currency:
        function: random()
        type: string
        data: [USD, EUR, GBP]
    - delivery_time:
        function: pairwise()
        type: string
        data: [15 minutes, 30 minutes, 45 minutes]

chatbot:
  is_starter: true
  fallback: "I'm sorry, can you repeat that?"
  output:
    - total_price:
        type: currency
        description: "Final price for the pizza order"
    - estimated_delivery:
        type: string
        description: "Estimated delivery time"

conversation:
  number: combinations(0.5, pairwise)
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - make spelling mistakes
```

### Summary of the Profile
- **Test Name**: "Pizza Shop Rude User"
- **User Role**: Rude customer wanting fast service.
- **Goals**: Includes ordering pizza, asking for prices, and demanding quick delivery.
- **Pairwise Functions**: Used for toppings and delivery time to generate combinations.
- **Conversation Control**: Uses a pairwise matrix to determine conversation numbers.

This profile should effectively simulate a rude customer in a pizza shop scenario! If you need any adjustments or additional features, just let me know! 😊
