¡Claro! Vamos a crear un perfil para tu chatbot de la UAM que permita a un usuario obtener soporte sobre el CAU. Este perfil incluirá los detalles que mencionaste: número de teléfono, email, dirección física y horarios.

Aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita soporte del Centro de Atención a Usuarios (CAU)."
  context:
    - "Buscas obtener información sobre cómo contactar al CAU para resolver tus dudas."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico de contacto del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar sobre los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - phone_contact:
        type: string
        description: "Número de teléfono del CAU."
    - email_contact:
        type: string
        description: "Correo electrónico de contacto del CAU."
    - physical_address:
        type: string
        description: "Dirección física del CAU."
    - service_hours:
        type: string
        description: "Horarios de atención del CAU."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

### Explicación del perfil:
- **test_name**: Nombre del perfil para identificarlo.
- **llm**: Configuración del modelo que se utilizará.
- **user**: Define el rol del usuario y los objetivos que busca alcanzar.
- **chatbot**: Incluye la información que se espera que el chatbot devuelva, como el número de teléfono, email, dirección y horarios.
- **conversation**: Define cuántas interacciones se realizarán y el estilo de interacción.

Puedes ajustar los detalles según tus necesidades específicas. ¡Espero que esto te ayude a comenzar! Si necesitas más cambios o ajustes, no dudes en decírmelo 😊.
