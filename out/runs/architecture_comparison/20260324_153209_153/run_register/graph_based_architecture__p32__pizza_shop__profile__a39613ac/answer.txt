¡Claro! Aquí tienes un perfil de ejemplo para probar el chatbot de una pizzería. Este perfil incluye el output que mencionaste: tipo de pizza, bebida, ID del pedido y precio final en dólares. Puedes copiarlo y ajustarlo según tus necesidades 😊.

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer looking to order a pizza and drink."
  context:
    - "You are excited to try a new pizza place."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Select a {{drink_type}} to go with the pizza."
    - "Ask for the total price."
    - "Request the order ID."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian]
    - drink_type:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: true
  fallback: "I'm sorry, I didn't understand that. Can you please rephrase?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink_type:
        type: string
        description: "The type of drink ordered."
    - order_id:
        type: string
        description: "The unique identifier for the order."
    - total_price:
        type: currency
        description: "The final price of the order in dollars."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - random:
        - long phrases
        - single questions
```

Este perfil está diseñado para simular un cliente que quiere hacer un pedido en la pizzería. ¡Espero que te sea útil! Si necesitas más ajustes o detalles, no dudes en decírmelo. 🍕🥤
