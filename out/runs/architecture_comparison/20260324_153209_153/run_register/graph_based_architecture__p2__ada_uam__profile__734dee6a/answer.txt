Creating a profile for an Erasmus user who needs help setting up their Moodle and Sigma accounts sounds like a great idea! Let's put together a simple profile that captures this scenario. 

Here’s a basic outline for your profile:

```yaml
test_name: "Erasmus User Setup Assistance"

llm:
  temperature: 0.8
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Erasmus student who needs help setting up Moodle and Sigma."
  context:
    - "Como estudiante Erasmus, necesito ayuda para configurar mis cuentas en Moodle y Sigma."
  goals:
    - "Solicitar instrucciones para acceder a Moodle."
    - "Pedir ayuda para configurar mi cuenta en Sigma."
    - "Consultar sobre los requisitos necesarios para acceder a los recursos académicos."
  
chatbot:
  is_starter: false
  fallback: "¿Me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - moodle_access_info:
        type: string
        description: "Instrucciones para acceder a Moodle."
    - sigma_setup_info:
        type: string
        description: "Pasos para configurar la cuenta en Sigma."
    - academic_resources_info:
        type: string
        description: "Requisitos para acceder a los recursos académicos."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

### Breakdown of the Profile:
- **Test Name**: Clearly states the purpose of the profile.
- **LLM Settings**: Specifies the model and temperature for the conversation.
- **User Section**: Defines the user role and context, focusing on the needs of an Erasmus student.
- **Goals**: Lists the specific requests the user will make during the conversation.
- **Chatbot Outputs**: Defines what information we expect to extract from the chatbot, ensuring we can validate the support received.
- **Conversation Controls**: Sets the number of interactions and the style of questions.
