```yaml
name: "Test Connector 2"
base_url: "https://api.anotherexample.com"
send_message:
  path: "/api/chat"
  method: "POST"
  headers:
    Content-Type: "application/json"
  payload_template:
    message: "{user_msg}"  # Cambié esto para que solo envíe el texto directamente
response_path: "response.response.text"  # Cambié esto para acceder correctamente al texto
```

### Cambios realizados:
1. **Payload Template**: Cambié `message: { text: "{user_msg}" }` a `message: "{user_msg}"` para que el mensaje se envíe correctamente.
2. **Response Path**: Cambié `response_path` a `"response.response.text"` para acceder correctamente al texto en la respuesta.
