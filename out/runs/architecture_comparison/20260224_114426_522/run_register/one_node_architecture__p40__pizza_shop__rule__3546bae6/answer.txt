Sure! To create a metamorphic rule that checks if adding a drink costs an extra $2, we can set it up to compare two conversations where one includes a drink and the other does not, while keeping the pizza size and type the same. Here’s how you can structure that rule:

```yaml
name: drink_cost_increase
description: Adding a drink to the order should cost an extra $2
conversations: 2
when: conv[0].size == conv[1].size and conv[0].pizza_type == conv[1].pizza_type
if:   conv[0].drink_quantity == conv[1].drink_quantity + 1
then: extract_float(conv[0].price) == extract_float(conv[1].price) + 2
```

### Explanation:
- **`conversations: 2`**: This rule compares two conversations.
- **`when`**: It checks that both conversations have the same pizza size and type.
- **`if`**: It checks that the first conversation has one more drink than the second.
- **`then`**: It asserts that the price of the first conversation (with the drink) is $2 more than the second (without the drink).
