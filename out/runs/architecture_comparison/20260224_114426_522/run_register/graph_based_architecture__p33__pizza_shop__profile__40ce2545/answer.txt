¡Claro! Aquí tienes un perfil de ejemplo para probar el chatbot de una pizzería. Este perfil está diseñado para que el output muestre el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares. Puedes ajustarlo según tus necesidades:

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer ordering a pizza and drink."
  context:
    - "You want to order a pizza with a drink for delivery."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Select a drink: {{drink_type}}."
    - "Ask for the total price."
    - "Request the order ID."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Vegetarian, BBQ Chicken]
    - drink_type:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Can you please repeat?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink_type:
        type: string
        description: "The type of drink ordered."
    - order_id:
        type: string
        description: "The unique identifier for the order."
    - total_price:
        type: currency
        description: "The final price of the order in dollars."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - random:
        - single questions
        - long phrases
```

### Explicación de los campos:
- **test_name**: El nombre del perfil de prueba.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario y sus metas, incluyendo la selección de pizza y bebida.
- **chatbot**: Define la salida esperada, que incluye el tipo de pizza, bebida, ID del pedido y precio total.
- **conversation**: Controla el número de interacciones y el estilo de la conversación.

¡Espero que esto te ayude! Si necesitas más ajustes o tienes alguna otra pregunta, no dudes en decírmelo 😊.
