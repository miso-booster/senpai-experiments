¡Claro! Vamos a crear un perfil para que puedas testear el chatbot de la UAM y obtener la información que necesitas sobre el CAU. Aquí tienes un ejemplo de cómo podría verse tu perfil en YAML:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca soporte sobre el Centro de Atención a Usuarios (CAU)."
  context:
    - "El usuario quiere información sobre contacto y horarios del CAU."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar por los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "Lo siento, no tengo esa información. ¿Puedo ayudarte con algo más?"
  output:
    - contact_email:
        type: string
        description: "Correo electrónico del CAU"
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horas de servicio del CAU"

conversation:
  number: 1
  goal_style:
    steps: 4
  interaction_style:
    - long phrases
```

### Desglose del perfil:
- **test_name**: Nombre del perfil para identificarlo fácilmente.
- **llm**: Configuración del modelo de lenguaje que se utilizará.
- **user**: Define el rol del usuario y sus objetivos.
- **chatbot**: Especifica qué información debe extraer el chatbot al final de la conversación.
- **conversation**: Controla el número de interacciones y el estilo de la conversación.

Puedes ajustar los detalles según tus necesidades. ¡Espero que esto te ayude a empezar! Si necesitas más cambios o detalles, no dudes en decírmelo 😊.
