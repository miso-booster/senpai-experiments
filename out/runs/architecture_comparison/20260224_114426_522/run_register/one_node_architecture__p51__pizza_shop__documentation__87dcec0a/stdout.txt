In the context of Sensei-check, an **oracle** is a condition or rule that defines what the expected outcome should be for a given conversation or set of conversations. Essentially, it acts as a reference point to verify whether the chatbot's responses are correct or meet certain criteria.

When you create rules in Sensei-check, you can specify an oracle to check if the outputs of your chatbot align with the expected results. This helps in validating the conversational correctness of the chatbot by ensuring that it behaves as intended under various scenarios.

For example, if you have a rule that checks if the price of a pizza is greater than a certain amount, the oracle would define that condition, and the Sensei-check would verify if the chatbot's response meets this expectation.

In summary, oracles are crucial for testing and validating the performance of chatbots by providing a benchmark against which their outputs can be measured. If you have any specific questions about how to implement or use oracles in your rules, feel free to ask! 😊
