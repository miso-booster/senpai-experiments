¡Claro! Aquí tienes un ejemplo de perfil que puedes usar para probar la capacidad del chatbot de Alcampo para recomendar recetas y ayudar con la planificación de menús. Puedes ajustarlo según tus necesidades específicas:

```yaml
test_name: "Recetas y Planificación de Menús"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A user looking for recipe recommendations and meal planning assistance."
  context:
    - "You want to explore healthy recipes that fit your dietary preferences."
    - "You're interested in seasonal ingredients and quick meal solutions."
  goals:
    - "Suggest a recipe for a healthy dinner using {{main_ingredient}}."
    - "Provide a weekly meal plan that includes {{dietary_preference}} options."
    - "Recommend side dishes that pair well with {{main_dish}}."
    - "List ingredients needed for the recipe of {{recipe_name}}."
    - main_ingredient:
        function: random()
        type: string
        data: [chicken, quinoa, broccoli, salmon, lentils]
    - dietary_preference:
        function: random()
        type: string
        data: [vegetarian, gluten-free, low-carb, high-protein]
    - main_dish:
        function: random()
        type: string
        data: [grilled chicken, quinoa salad, baked salmon, vegetable stir-fry]
    - recipe_name:
        function: random()
        type: string
        data: [Mediterranean quinoa salad, chicken stir-fry, lentil soup, baked salmon with vegetables]

chatbot:
  is_starter: false
  fallback: "Lo siento, no entendí eso. ¿Puedes reformular tu pregunta sobre recetas o planificación de menús?"
  output:
    - recipe:
        type: string
        description: "Recipe details including ingredients and instructions."
    - meal_plan:
        type: string
        description: "Weekly meal plan including breakfast, lunch, and dinner."
    - side_dishes:
        type: string
        description: "Recommended side dishes for the main dish."
    - ingredients_list:
        type: string
        description: "List of ingredients needed for the specified recipe."

conversation:
  number: 5
  goal_style:
    steps: 10
  interaction_style:
    - random:
      - single questions
      - long phrases
```

Este perfil está diseñado para interactuar con el chatbot de Alcampo y evaluar su capacidad para proporcionar recetas y ayudar con la planificación de menús. Puedes ejecutarlo y ver cómo responde el chatbot a las diferentes solicitudes. ¡Espero que te sirva! 😊
