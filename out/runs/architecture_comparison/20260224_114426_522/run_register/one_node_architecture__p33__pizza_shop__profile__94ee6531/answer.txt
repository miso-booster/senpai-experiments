¡Claro! Aquí tienes un perfil para probar el chatbot de una pizzería. Este perfil está diseñado para extraer el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares. 

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza."
  context:
    - "You want to know about pizza types and drinks."
  goals:
    - "Order a {{pizza_type}} pizza with a {{drink}}."
    - "Ask for the total price."
    - "Request the order ID."

chatbot:
  is_starter: true
  fallback: "Sorry, I didn't understand that."
  output:
    - pizza_type:
        type: string
        description: "Type of pizza ordered."
    - drink:
        type: string
        description: "Beverage ordered."
    - order_id:
        type: string
        description: "Unique identifier for the order."
    - total_price:
        type: currency
        description: "Final price for the order in dollars."

conversation:
  number: 1
  goal_style:
    steps: 3
  interaction_style:
    - long phrases
```

Este perfil define cómo interactuar con el chatbot y qué información extraer al final de la conversación. ¡Espero que te sirva! Si necesitas más ajustes, no dudes en decírmelo 😊.
