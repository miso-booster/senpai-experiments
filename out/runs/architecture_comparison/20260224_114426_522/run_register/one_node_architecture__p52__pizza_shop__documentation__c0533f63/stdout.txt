Connectors are used to facilitate communication between your chatbot and external APIs. They allow you to send user messages to the chatbot and receive responses, enabling integration with various services and platforms. This is especially useful for testing chatbots in different environments or with different backend systems.

### Key Fields in Connectors

Here are the primary fields you typically find in a connector configuration:

1. **name**: A friendly name for your chatbot connector.
2. **base_url**: The base URL of the chatbot API you want to connect to.
3. **send_message**: This section contains details about how to send messages to the chatbot.
   - **path**: The specific API endpoint path that will be appended to the base URL.
   - **method**: The HTTP method to use (e.g., POST, GET, PUT, DELETE). The default is usually POST.
   - **headers**: Any custom headers required for the API request (e.g., authorization tokens).
   - **payload_template**: The structure of the message you are sending, often including placeholders for dynamic content (like `{user_msg}`).
4. **response_path**: A dot-separated path to extract the chatbot's reply from the JSON response returned by the API.

These fields allow you to configure how your chatbot interacts with external systems, making it easier to test and validate its functionality in various scenarios. If you have any specific questions about creating or using connectors, feel free to ask! 😊
