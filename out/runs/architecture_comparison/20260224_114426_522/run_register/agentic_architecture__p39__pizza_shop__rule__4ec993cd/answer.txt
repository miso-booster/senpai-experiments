To create a rule that checks if the `order_id` was provided by the chatbot, we can define a simple metamorphic rule. This rule will ensure that the `order_id` field is not empty in the conversation output.

Here's how the rule would look in YAML format:

```yaml
name: order_id_provided
description: Checks if the order ID is provided by the chatbot
conversations: 1
oracle: conv[0].order_id is not None
```

### Explanation:
- **name**: This is the identifier for the rule, which is `order_id_provided`.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to `1`, indicating that this rule applies to a single conversation.
- **oracle**: This condition checks if the `order_id` is not `None`, meaning it must be provided.

### Important Note:
Make sure that the `order_id` field is defined in the `chatbot.output` of the relevant profile. If it is not defined, this rule will not work as intended.
