Great question! 😊 In the context of Sensei, a **metamorphic rule** is a specific type of rule used in **Sensei-check** to verify the correctness of conversations generated by Sensei-chat. 

Here's a simple breakdown:

1. **Purpose**: Metamorphic rules help check how outputs should change (or remain the same) when inputs change across different conversations. This is particularly useful because it alleviates the oracle problem, which is the challenge of determining the correctness of outputs in conversational AI.

2. **Comparison**: These rules compare pairs or tuples of conversations that meet certain criteria. For example, if two conversations have the same pizza size and drink, a metamorphic rule could assert that adding more toppings should result in a higher price.

3. **Structure**: A metamorphic rule typically includes:
   - A **filter** (`when`) that selects eligible conversations based on certain conditions.
   - A condition to check (`if`) that specifies when the rule should apply.
   - An expected outcome (`then`) that describes how the outputs should relate to each other.

4. **Example**: For instance, if you have two conversations where the pizza size is the same, and one has more toppings than the other, the rule could state that the price of the pizza with more toppings should be greater than the other.

By using metamorphic rules, you can ensure that your chatbot behaves consistently and correctly across various scenarios! If you have more questions or need examples, feel free to ask! 🍕✨
