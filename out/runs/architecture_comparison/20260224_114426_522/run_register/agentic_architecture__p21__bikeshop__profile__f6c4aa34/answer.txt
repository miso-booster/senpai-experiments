I've loaded the relevant documentation for SENSEI profiles from the file `sensei-chat-guide.md`. Now, let's create a profile for a user who wants to set an appointment at a bike shop to have their wheels changed. This profile will include various variables to test different days and times for the appointment.

### Profile Structure
Here's a proposed structure for the profile:

- **User Role**: A customer looking to set an appointment for wheel changes.
- **Goals**: Include variables for different dates and times.
- **Chatbot Output**: Define the expected output fields for the appointment.

### Proposed YAML Profile
```yaml
test_name: "bike_shop_appointment"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer looking to set an appointment to change bike wheels."
  context:
    - "The user prefers morning appointments."
  goals:
    - "Set an appointment for wheel change on {{appointment_date}} at {{appointment_time}}."
    - appointment_date:
        function: random()
        type: string
        data:
          - any(3 dates within the next 30 days)
    - appointment_time:
        function: random()
        type: string
        data:
          - "09:00 AM"
          - "10:00 AM"
          - "11:00 AM"
          - "02:00 PM"
          - "03:00 PM"

chatbot:
  is_starter: false
  fallback: "I'm sorry, could you provide that information again?"
  output:
    - appointment_confirmation:
        type: string
        description: "Confirmation message for the appointment."
    - appointment_id:
        type: string
        description: "Unique identifier for the appointment."

conversation:
  number: combinations(0.5, pairwise)
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Summary
- **Profile Name**: `bike_shop_appointment`
- **User Goals**: Setting an appointment with random dates and specified times.
- **Chatbot Output**: Includes confirmation and appointment ID.
