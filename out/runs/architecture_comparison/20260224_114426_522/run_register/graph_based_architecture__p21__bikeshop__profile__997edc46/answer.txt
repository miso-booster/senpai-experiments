Sure! Let's create a profile for a user who wants to set an appointment to have their wheels changed at a bike shop. This profile will include variables for different days and times to thoroughly test how the chatbot handles scheduling. Here’s a sample YAML profile for you:

```yaml
test_name: "wheel_change_appointment"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer looking to schedule an appointment to change their bike wheels."
  context:
    - "You need to change your bike wheels and want to set an appointment."
    - "You have specific days and times in mind for the appointment."
  goals:
    - "Schedule an appointment for wheel change on {{appointment_date}} at {{appointment_time}}."
    - "If that date is not available, ask for the next available date."
    - appointment_date:
        function: random()
        type: string
        data: [tomorrow, "November 6th, 2024", "November 7th, 2024", "November 8th, 2024"]
    - appointment_time:
        function: random()
        type: string
        data: ["10:00 AM", "2:00 PM", "3:30 PM", "4:00 PM"]

chatbot:
  is_starter: false
  fallback: "I'm sorry, it's a little loud in my shop, can you say that again?"
  output:
    - appointment_confirmation:
        type: string
        description: "Confirmation of the scheduled appointment for wheel change, including date and time."
    - alternative_date_response:
        type: string
        description: "Response from the chatbot if the requested date is not available, suggesting another date."

conversation:
  number: 5
  goal_style:
    all_answered:
      export: true
      limit: 5
  interaction_style:
    - single questions
```

### Breakdown of the Profile:
- **Test Name**: Clearly identifies the purpose of the profile.
- **User Role**: Describes the simulated user as someone looking to schedule an appointment.
- **Goals**: Includes a primary goal to set the appointment and a follow-up to ask for alternative dates if necessary.
- **Variables**:
  - **appointment_date**: Randomly selects from a list of potential dates.
  - **appointment_time**: Randomly selects from a list of possible times.
- **Chatbot Output**: Specifies what the chatbot should confirm back to the user.
- **Conversation Controls**: Sets the number of interactions and specifies that the conversation should focus on single questions.

Feel free to adjust any of the variables or descriptions to better fit your testing needs! Happy testing! 🚴‍♂️😊
