Let's create a rule to check if the chatbot provided information about current promotions. Since this rule is not based on any specific profile, we will use general variables.

Here's the YAML for the rule:

```yaml
name: check_promotions_info
description: Verify that the chatbot provides information about current promotions.
conversations: 1
active: true
oracle: |
  'promotions' in chatbot_phrases
```

### Explanation:
- **name**: A unique identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to 1, as this rule checks a single conversation.
- **active**: Indicates that the rule is currently active.
- **oracle**: Checks if the term 'promotions' is included in the chatbot's responses.

This rule is designed to ensure that the chatbot mentions promotions when relevant. If you need any adjustments or further details, feel free to ask! 😊
