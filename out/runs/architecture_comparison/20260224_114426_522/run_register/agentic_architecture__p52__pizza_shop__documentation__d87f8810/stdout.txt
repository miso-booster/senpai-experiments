Connectors in SENSEI are used to connect your chatbot to external APIs without needing to write code. You create a YAML configuration file that describes how to communicate with your chatbot's API. Here’s a breakdown of the key fields and their purposes:

### Key Fields in a Connector

| Field                        | Description                                                   | Required          |
|------------------------------|---------------------------------------------------------------|-------------------|
| `name`                       | Friendly name for your chatbot                                | No                |
| `base_url`                  | Base URL of the chatbot API                                   | Yes               |
| `send_message.path`         | API endpoint path (appended to `base_url`)                   | Yes               |
| `send_message.method`       | HTTP method (POST, GET, PUT, DELETE)                         | No (default: POST)|
| `send_message.headers`      | Custom headers (e.g., Authorization)                          | No                |
| `send_message.payload_template` | JSON structure with `{user_msg}` placeholder               | Yes               |
| `response_path`             | Dot-separated path to extract the bot's reply from JSON response | Yes               |

### Example Configuration

Here’s a simple example of a connector configuration:

```yaml
name: "My Custom Bot"
base_url: "https://api.mychatbot.com"
send_message:
  path: "/chat"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

### Usage Tips
- Use `{user_msg}` as a placeholder for the user's message in your payload.
- Ensure the `response_path` correctly navigates through the JSON response based on your API's structure.
- Add authentication headers in the `headers` section if required.

For more detailed examples and configurations, you can refer to the documentation files: `custom-connector-guide.md` and `connector-examples.md`. 😊
