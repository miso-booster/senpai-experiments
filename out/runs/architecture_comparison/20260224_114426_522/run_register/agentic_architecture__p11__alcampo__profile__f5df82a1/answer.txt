### Profile Structure
Here’s a basic outline of the profile we will create:

- **test_name**: A descriptive name for the profile.
- **llm**: Configuration for the language model (optional).
- **user**: 
  - **language**: Language of the interaction.
  - **role**: Description of the simulated user.
  - **context**: Any additional context or constraints.
  - **goals**: Goals related to subscription services.
- **chatbot**: 
  - **is_starter**: Indicates if the chatbot starts the conversation.
  - **fallback**: Fallback message for the chatbot.
  - **output**: This section will be empty since we won't add variables.
- **conversation**: Controls for the conversation flow.

### Proposed YAML Profile
Here’s the YAML structure for the new profile:

```yaml
test_name: "subscription_services_inquiry"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer interested in subscription services. Ask about available plans, benefits, and any promotional offers."
  context:
    - "You are looking for information on various subscription options."
  goals:
    - "Inquire about the different subscription plans available."
    - "Ask about the benefits of each subscription plan."
    - "Request information on any ongoing promotions or discounts."

chatbot:
  is_starter: false
  fallback: "I'm sorry, could you please provide more details?"

conversation:
  number: 5
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - long phrases
      - single questions
```
