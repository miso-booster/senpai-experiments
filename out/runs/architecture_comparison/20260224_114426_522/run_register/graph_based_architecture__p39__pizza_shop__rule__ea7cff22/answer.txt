Sure! To create a rule that checks whether the order ID was provided by the chatbot, you can use a simple single-conversation oracle rule. Here’s how it would look in YAML format:

```yaml
name: order_id_provided
description: The chatbot must return an order ID in the response.
conversations: 1
oracle: |
  'order_id' in data_output
```

### Explanation:
- **name**: This is the identifier for your rule, and I've named it `order_id_provided`.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to `1`, indicating this rule is for a single conversation.
- **oracle**: This checks if the `order_id` is present in the `data_output` of the chatbot's response.
