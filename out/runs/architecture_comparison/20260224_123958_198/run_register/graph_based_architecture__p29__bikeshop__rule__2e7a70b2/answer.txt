Absolutely! Ensuring that the chatbot responds in the same language as the user is a great way to enhance the user experience. Here's a simple metamorphic rule you can use to check for language consistency:

```yaml
name: language_consistency
description: Assistant responds in the same language as the user
conversations: 2
when: conv[0].language == conv[1].language
oracle: responds_in_same_language() is True
```

### Explanation:
- **name**: This is the name of your rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: This rule checks two conversations to ensure they are comparable.
- **when**: This condition checks if the language of both conversations is the same.
- **oracle**: This asserts that the assistant should respond in the same language as the user.
