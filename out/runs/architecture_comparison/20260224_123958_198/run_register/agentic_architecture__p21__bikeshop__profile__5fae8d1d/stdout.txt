### Profile Structure
1. **Test Name**: A descriptive name for the profile.
2. **User Information**:
   - **Language**: The language the user will communicate in.
   - **Role**: Describes the user’s intent (e.g., setting an appointment for wheel changes).
   - **Context**: Any additional context about the user.
   - **Goals**: Specific goals that include variables for testing different days and times.
3. **Chatbot Output**: Fields that will be extracted after the conversation, such as appointment date and time.
4. **Conversation Controls**: Defines how many conversations to run and the interaction style.

### Proposed Profile YAML
Here's a draft for the bike shop appointment profile:

```yaml
test_name: "bike_shop_appointment_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer wanting to set an appointment to change bike wheels."
  context:
    - "The customer is flexible with dates and times."
  goals:
    - "Schedule an appointment on {{appointment_date}} at {{appointment_time}}."
    - appointment_date:
        function: random()
        type: string
        data: 
          - any(3 dates within the next 30 days)
    - appointment_time:
        function: random()
        type: string
        data:
          - "10:00 AM"
          - "2:00 PM"
          - "4:00 PM"

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you please provide that information again?"
  output:
    - appointment_confirmation:
        type: string
        description: "Confirmation of the scheduled appointment."
    - appointment_date:
        type: date("mm/dd/yyyy")
        description: "The date of the appointment."
    - appointment_time:
        type: time("hh:mm")
        description: "The time of the appointment."

conversation:
  number: combinations(0.5, pairwise)
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
```
