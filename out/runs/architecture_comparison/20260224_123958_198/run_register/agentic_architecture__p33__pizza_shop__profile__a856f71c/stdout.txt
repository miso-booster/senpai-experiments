¡Hola! 😊 He revisado la documentación sobre perfiles y ahora puedo ayudarte a crear un perfil para probar el chatbot de una pizzería. Este perfil incluirá los campos que mencionaste: tipo de pizza, bebida, ID del pedido y precio final en dólares.

Aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "pizza_order_profile"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza."
  context:
    - "You prefer a variety of pizzas and drinks."
  goals:
    - "Order a {{pizza_type}} pizza with {{drink}}."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Veggie, BBQ Chicken]
    - drink:
        function: random()
        type: string
        data: [Coke, Sprite, Water]

chatbot:
  is_starter: false
  fallback: "Sorry, could you rephrase that?"
  output:
    - pizza_type:
        type: string
        description: "Type of pizza ordered"
    - drink:
        type: string
        description: "Drink ordered"
    - order_id:
        type: string
        description: "Unique order identifier"
    - total_price:
        type: currency
        description: "Final price in dollars"
        
conversation:
  number: 1
  goal_style:
    steps: 2
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Resumen del perfil:
- **Nombre del perfil**: `pizza_order_profile`
- **Campos de salida**:
  - `pizza_type`: Tipo de pizza ordenada.
  - `drink`: Bebida seleccionada.
  - `order_id`: ID único del pedido.
  - `total_price`: Precio total en dólares.

Este perfil está diseñado para simular un cliente que ordena una pizza y una bebida, y extraerá los datos relevantes al final de la conversación.
