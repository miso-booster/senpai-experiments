¡Claro! Aquí tienes un perfil para probar el chatbot de una pizzería que incluye los campos que necesitas en el output. Este perfil está diseñado para extraer el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares.

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza."
  context:
    - "You want to know about pizza types and beverages."
  goals:
    - "Ask for the available pizza types."
    - "Ask for the available drinks."
    - "Place an order for a pizza and a drink."
    - "Request the order ID and the final price."

chatbot:
  is_starter: true
  fallback: "I'm sorry, I didn't understand that."
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink:
        type: string
        description: "The drink ordered."
    - order_id:
        type: string
        description: "The unique identifier for the order."
    - final_price:
        type: currency
        description: "The final price of the order in dollars."

conversation:
  number: 2
  goal_style:
    steps: 5
  interaction_style:
    - long phrases
    - make spelling mistakes
```

Este perfil te permitirá probar el chatbot de la pizzería y asegurarte de que pueda manejar las consultas relacionadas con los tipos de pizza, las bebidas, el ID del pedido y el precio final. ¡Espero que te sea útil! 🍕😊
