¡Claro! Aquí tienes un perfil de ejemplo para probar el chatbot de una pizzería. Este perfil está diseñado para que el output incluya el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares. Puedes copiarlo y ajustarlo según tus necesidades:

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza and drinks from a pizzeria."
  context:
    - "You want to know the available pizza types and drink options."
  goals:
    - "Order a {{pizza_type}} pizza with {{toppings}}."
    - "Select {{drink_quantity}} {{drink_type}}."
    - "Ask for the total price in dollars."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Vegetarian, BBQ Chicken]
    - toppings:
        function: random()
        type: string
        data: [cheese, mushrooms, pepperoni, olives]
    - drink_quantity:
        function: random(2)
        type: int
        data: {min: 1, max: 5}
    - drink_type:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Fanta]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Can you please rephrase?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink_type:
        type: string
        description: "The type of drink ordered."
    - order_id:
        type: string
        description: "A unique identifier for the order."
    - total_price:
        type: currency
        description: "The final price of the order in dollars."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - random:
      - long phrases
      - single questions
```

Este perfil define un cliente que quiere ordenar una pizza y una bebida, y el output incluye todos los campos que mencionaste. ¡Espero que te sea útil! Si necesitas más ajustes o tienes alguna otra pregunta, ¡no dudes en decírmelo! 🍕😊
