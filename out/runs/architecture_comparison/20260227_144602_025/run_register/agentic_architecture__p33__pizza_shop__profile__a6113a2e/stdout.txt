¡Vamos a crear un perfil para probar el chatbot de la pizzería! Basado en la documentación, aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Cliente que quiere pedir una pizza."
  context:
    - "El cliente está buscando una pizza y una bebida."
  goals:
    - "Quiero una pizza de {{tipo_pizza}} y una bebida {{bebida}}."
    - tipo_pizza:
        function: random()
        type: string
        data: [margarita, pepperoni, cuatro quesos, vegetariana]
    - bebida:
        function: random()
        type: string
        data: [Coca-Cola, Fanta, agua, cerveza]
    
chatbot:
  is_starter: true
  fallback: "Lo siento, no entendí eso."
  output:
    - tipo_pizza:
        type: string
        description: "Tipo de pizza pedido"
    - bebida:
        type: string
        description: "Bebida seleccionada"
    - order_id:
        type: string
        description: "ID del pedido"
    - total_price:
        type: currency
        description: "Precio final en dólares"

conversation:
  number: 5
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Desglose del perfil:
- **test_name**: Nombre del test que se está realizando.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el comportamiento del usuario simulado, incluyendo el lenguaje y el rol.
- **goals**: Aquí se especifican los objetivos del usuario, incluyendo las variables para el tipo de pizza y la bebida.
- **chatbot.output**: Define los campos que se extraerán al final de la conversación, como el tipo de pizza, la bebida, el ID del pedido y el precio total.
- **conversation**: Controla el número de interacciones y el estilo de interacción.
