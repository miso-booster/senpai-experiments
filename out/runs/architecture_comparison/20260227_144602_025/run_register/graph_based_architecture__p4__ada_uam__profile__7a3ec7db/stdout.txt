¡Claro! 😊 Vamos a crear un perfil para que puedas testear el chatbot de la UAM, específicamente para obtener soporte sobre el CAU. Aquí tienes un ejemplo de cómo podría verse tu perfil en YAML:

```yaml
test_name: "Soporte CAU - Información de Contacto"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita información sobre el Centro de Atención a Usuarios (CAU)."
  context:
    - "Buscas obtener detalles de contacto y horarios del CAU."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico de contacto del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar sobre los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me puedes decirlo de otra forma? O, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 1
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

### Desglose del perfil:

- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje que se utilizará.
- **user**: Define el rol del usuario y sus objetivos.
- **chatbot**: Contiene la información que se espera obtener del chatbot, como el número de teléfono, correo electrónico, dirección y horarios.
- **conversation**: Configura la cantidad de interacciones y el estilo de las preguntas.
