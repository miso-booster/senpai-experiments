Connectors are used to integrate with external chatbot APIs without the need for coding. They allow you to define how to communicate with a chatbot's API through a simple YAML configuration file.

### Key Fields in a Connector

Here are the essential fields you can include in a connector configuration:

| Field                        | Description                                                        | Required                |
|------------------------------|--------------------------------------------------------------------|-------------------------|
| `name`                       | Friendly name for your chatbot                                     | No                      |
| `base_url`                  | Base URL of the chatbot API                                        | Yes                     |
| `send_message.path`         | API endpoint path (appended to `base_url`)                        | Yes                     |
| `send_message.method`       | HTTP method (POST, GET, PUT, DELETE)                              | No (default: POST)      |
| `send_message.headers`      | Custom headers (e.g., Authorization)                               | No                      |
| `send_message.payload_template` | JSON structure with a placeholder for the user's message (`{user_msg}`) | Yes                     |
| `response_path`             | Dot-separated path to extract the bot's reply from the JSON response | Yes                     |

### Example Configuration

Here's a simple example of a connector configuration:

```yaml
name: "My Custom Bot"
base_url: "https://api.mychatbot.com"
send_message:
  path: "/chat"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

### How It Works

- **`base_url`**: This is the main URL of the chatbot API you are connecting to.
- **`send_message`**: This section defines how to send messages to the chatbot, including the endpoint path, HTTP method, headers, and the payload structure.
- **`response_path`**: This specifies how to navigate through the JSON response to extract the chatbot's reply.

For more detailed examples and configurations, you can refer to the documentation files: `custom-connector-guide.md` and `connector-examples.md`. If you have any specific questions or need help with a particular connector, feel free to ask! 😊
