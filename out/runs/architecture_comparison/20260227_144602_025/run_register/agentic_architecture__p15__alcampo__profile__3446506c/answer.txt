He revisado la documentación sobre los perfiles de SENSEI (en `sensei-chat-guide.md`). Vamos a crear un perfil que pruebe la capacidad del chatbot de Alcampo para recomendar recetas y planificar menús. Aquí hay un esquema básico que podemos usar:

### Esquema del Perfil

```yaml
test_name: "Alcampo Recipe and Menu Planner"

llm:
  temperature: 0.7
  model: "gpt-4"
  model_prov: "openai"
  format:
    type: text

user:
  language: Spanish
  role: "Eres un cliente que busca recomendaciones de recetas y planificación de menús."
  context:
    - "Te gusta la cocina mediterránea y prefieres platos vegetarianos."
  goals:
    - "Recomiéndame una receta con {{ingredient}}."
    - "Planifica un menú para {{number}} personas con {{cuisine}}."
    - ingredient:
        function: random()
        type: string
        data: [tomate, espinaca, garbanzos, berenjena]
    - number:
        function: random()
        type: int
        data:
          min: 2
          max: 6
    - cuisine:
        function: random()
        type: string
        data: [mediterránea, italiana, mexicana]

chatbot:
  is_starter: true
  fallback: "Lo siento, no entiendo. ¿Puedes reformular tu pregunta?"
  output:
    - recipe_name:
        type: string
        description: "Nombre de la receta recomendada."
    - menu_plan:
        type: string
        description: "Descripción del menú planificado."

conversation:
  number: 5
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Descripción del Perfil
- **test_name**: Nombre del perfil para identificarlo.
- **llm**: Configuración del modelo de lenguaje que se utilizará.
- **user**: Define el comportamiento del usuario simulado, incluyendo su rol, contexto y objetivos.
- **chatbot**: Especifica si el chatbot inicia la conversación, su mensaje de fallback y los campos de salida que se quieren extraer.
- **conversation**: Controla el número de conversaciones y el estilo de interacción.
