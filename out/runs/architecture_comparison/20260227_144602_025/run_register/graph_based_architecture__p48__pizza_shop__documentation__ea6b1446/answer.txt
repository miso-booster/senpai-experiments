Great question! 😊 In the context of Sensei, a **metamorphic rule** is a condition that you define to check the correctness of conversations generated by the Sensei-chat. Instead of looking for absolute answers, these rules focus on the relationships between different conversations.

Here’s a simple breakdown:

1. **Purpose**: Metamorphic rules help verify that if certain inputs change, the outputs should change in a specific way. This is particularly useful for testing chatbots, as it allows you to check the consistency and correctness of their responses across multiple scenarios.

2. **Types of Checks**: You can create rules that apply to:
   - A **single conversation** (traditional oracle).
   - **Several conversations** (this is where metamorphic testing shines).
   - **All conversations** (global checks).

3. **Structure**: Each rule typically includes:
   - A condition to filter conversations (using `when`).
   - A relationship to check (using `if` and `then`).

For example, you might have a rule that states if two pizza orders have the same size and drink, then the order with more toppings should cost more. This helps ensure that the pricing logic of your chatbot is working correctly!

In summary, metamorphic rules are a powerful way to ensure your chatbot behaves as expected across various interactions. If you have any specific examples or need help writing one, feel free to ask! 😊
