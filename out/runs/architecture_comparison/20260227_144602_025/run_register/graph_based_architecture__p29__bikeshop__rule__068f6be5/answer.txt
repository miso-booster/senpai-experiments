```yaml
name: language_consistency
description: Ensure the assistant responds in the same language as the user.
conversations: 2
when: conv[0].language == conv[1].language
oracle: responds_in_same_language() is True
```

### Breakdown of the Rule:
- **name**: A unique identifier for the rule.
- **description**: A brief explanation of what the rule does.
- **conversations**: We check across two conversations to ensure consistency.
- **when**: This condition checks if the language of both conversations is the same.
- **oracle**: This asserts that the assistant must respond in the same language as the user.
