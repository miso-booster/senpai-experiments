¡Hola! 😊 Vamos a crear un perfil para testear el chatbot del CAU de la UAM. Este perfil permitirá simular un usuario que busca soporte y necesita obtener información como el número de teléfono, email, dirección física y horarios.

### Estructura del Perfil

Aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "UAM_CAU_Support_Profile"

llm:
  temperature: 0.7
  model: "gpt-4"
  model_prov: "openai"
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca soporte del Centro de Atención a Usuarios (CAU) de la UAM."
  context:
    - "El usuario necesita información sobre contacto y horarios."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Cuál es el email del CAU?"
    - "¿Cuál es la dirección física del CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: true
  fallback: "Lo siento, no tengo esa información. ¿Puedes reformular tu pregunta?"
  output:
    - telefono:
        type: string
        description: "Número de teléfono del CAU"
    - email:
        type: string
        description: "Email del CAU"
    - direccion:
        type: string
        description: "Dirección física del CAU"
    - horarios:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - random:
      - single questions
      - long phrases
```

### Desglose del Perfil

- **test_name**: Nombre del perfil para identificarlo.
- **llm**: Configuración del modelo de lenguaje, donde puedes ajustar la temperatura y el modelo utilizado.
- **user**: Define el comportamiento del usuario simulado, incluyendo su lenguaje, rol y objetivos.
- **chatbot**: Especifica cómo se comporta el chatbot, incluyendo el mensaje de fallback y los campos de salida que se quieren extraer.
- **conversation**: Controla el número de interacciones y el estilo de interacción.

### Siguientes Pasos

1. **Revisar el perfil**: Asegúrate de que cumple con tus expectativas y necesidades.
2. **Guardar el perfil**: Este YAML debe guardarse en un archivo dentro de la carpeta `profiles/` de tu proyecto.
3. **Ejecutar pruebas**: Utiliza este perfil para interactuar con el chatbot y validar que la información se extrae correctamente.

Si necesitas hacer ajustes o tienes más preguntas, ¡déjamelo saber! 😊
