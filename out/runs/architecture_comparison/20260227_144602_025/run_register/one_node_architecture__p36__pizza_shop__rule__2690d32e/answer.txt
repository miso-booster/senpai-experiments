Sure! Here’s a Sensei rule that checks if the price of a small pizza is at least $10. This rule assumes that your profile has a field for the pizza size and the price in the `chatbot.output`.

```yaml
name: small_pizza_price_check
description: Small pizzas should cost at least $10
conversations: 1
when: size == 'small'
oracle: extract_float(price) >= 10 and currency(price) == 'USD'
```

Feel free to adjust the `currency(price)` check if you're using a different currency! Let me know if you need any more help! 😊
