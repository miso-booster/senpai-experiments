Connectors in Sensei are used to facilitate communication between your chatbot and external APIs. They allow you to send user messages to the chatbot and receive responses, enabling seamless interaction during testing. Essentially, they act as the bridge that connects your testing framework with the chatbot's backend.

### Key Fields in Connectors

1. **name**: A friendly name for your chatbot connector.
2. **base_url**: The base URL of the chatbot API, which will be used to construct the full API endpoint.
3. **send_message**: This section defines how to send messages to the chatbot. It includes:
   - **path**: The specific endpoint path for sending messages (appended to the base URL).
   - **method**: The HTTP method used for the request (e.g., POST, GET).
   - **headers**: Any custom headers required for the request (like authorization).
   - **payload_template**: The structure of the message being sent, often including a placeholder for the user message (e.g., `{user_msg}`).

4. **response_path**: This field specifies how to extract the chatbot's reply from the JSON response received from the API. It uses dot notation to navigate through the response structure.

These fields help define how the connector interacts with the chatbot API, ensuring that messages are sent and responses are correctly parsed for further use in testing. If you have any specific questions about creating or using connectors, feel free to ask! 😊
