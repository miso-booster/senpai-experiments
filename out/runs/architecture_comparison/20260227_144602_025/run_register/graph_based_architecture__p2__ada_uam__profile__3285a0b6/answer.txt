Creating a profile for an Erasmus user who needs assistance with setting up Moodle and Sigma is a great idea! Let's keep it simple and focused on the essential outputs you need for validation. Here’s a sample profile you can use as a starting point:

```yaml
test_name: "Erasmus User Setup Assistance"

llm:
  temperature: 0.8
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Erasmus student who needs help setting up Moodle and Sigma."
  context:
    - "Eres un estudiante Erasmus recién llegado y no sabes cómo configurar tus cuentas en Moodle y Sigma."
  goals:
    - "Solicitar ayuda para configurar mi cuenta de Moodle."
    - "Pedir instrucciones sobre cómo acceder a Sigma."
    - "Consultar sobre los requisitos para acceder a los recursos digitales de la universidad."

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - moodle_setup_info:
        type: string
        description: "Instrucciones para configurar la cuenta de Moodle."
    - sigma_access_info:
        type: string
        description: "Instrucciones para acceder a Sigma."
    - digital_resources_info:
        type: string
        description: "Requisitos para acceder a los recursos digitales."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

### Breakdown of the Profile:

- **Test Name**: Clearly identifies the purpose of the profile.
- **User Role**: Describes the user as an Erasmus student needing help.
- **Context**: Provides background on the user's situation.
- **Goals**: Lists specific requests the user might make.
- **Chatbot Outputs**: Defines what information you want to extract after the conversation, ensuring you can validate that the chatbot provides proper support.
- **Conversation Controls**: Sets the number of interactions and the style of interaction.
