I found the relevant documentation on profiles in the `sensei-chat-guide.md`. Now, let's create a profile where the user can ask for a custom pizza but changes their mind halfway through the conversation to request a predefined pizza instead. 

### Profile Structure
Here's a breakdown of how we can structure this profile:

- **Test Name**: A descriptive name for the profile.
- **User**:
  - **Language**: Specify the language (e.g., English).
  - **Role**: Describe the user's role (e.g., a customer ordering pizza).
  - **Goals**: Define the goals, including asking for a custom pizza and then switching to a predefined pizza.
- **Chatbot**:
  - **Is Starter**: Indicate if the chatbot starts the conversation.
  - **Fallback**: A fallback message if the chatbot doesn't understand.
  - **Output**: Define the fields to extract, such as the final order details.
- **Conversation**:
  - **Number**: Define how many conversations to simulate.
  - **Interaction Style**: Include styles that allow for changing opinions.

### Proposed YAML Profile
Here’s a draft of the profile based on the above structure:

```yaml
test_name: "custom_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer who wants to order pizza."
  context:
    - "The user is indecisive and may change their mind."
  goals:
    - "I would like to order a custom pizza with {{custom_toppings}}."
    - "Actually, can I get a {{predefined_pizza}} instead?"
    - custom_toppings:
        function: random()
        type: string
        data: [pepperoni, mushrooms, onions, olives, extra cheese]
    - predefined_pizza:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, BBQ Chicken]

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you clarify your order?"
  output:
    - final_order:
        type: string
        description: "The final pizza order confirmed by the user."

conversation:
  number: 2
  goal_style:
    steps: 3
  interaction_style:
    - change your mind
```

### Summary
- **Profile Name**: `custom_pizza_order`
- **User Goals**: Includes both custom and predefined pizza requests.
- **Interaction Style**: Allows for changing opinions.
