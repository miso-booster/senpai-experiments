That sounds like a great use case for a Sensei profile! Let’s create a profile for a user who needs to visit the bike shop to have their new bike set up. This user will want to customize their bike by changing the seat and handlebar grips. Here’s a sample profile you can use as a starting point:

```yaml
test_name: "bike_setup_request"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer who has recently purchased a new bike and wants to customize it."
  context:
    - "You want to ensure your bike is comfortable and tailored to your preferences."
    - "You are particularly interested in changing the seat and handlebar grips."
  goals:
    - "Ask if the shop can help customize your bike."
    - "Inquire about different seat options available, specifically {{seat_type}}."
    - "Ask about the types of handlebar grips they offer, such as {{grip_type}}."
    - "Request a quote for the customization service."
    - seat_type:
        function: forward()
        type: string
        data: [racing, comfort, gel, leather]
    - grip_type:
        function: forward()
        type: string
        data: [foam, rubber, gel, leather]

chatbot:
  is_starter: false
  fallback: "I'm sorry, it's a little loud in my shop, can you say that again?"
  output:
    - customization_confirmation:
        type: string
        description: "Confirmation from the chatbot regarding whether they can customize the bike."
    - seat_options:
        type: string
        description: "Details about the available seat options."
    - grip_options:
        type: string
        description: "Information about the handlebar grips available."
    - customization_quote:
        type: money
        description: "The estimated cost for the customization service."

conversation:
  number: 4
  goal_style:
    all_answered:
      export: true
      limit: 4
  interaction_style:
    - default
```

### Explanation:
- **test_name**: A clear name for the profile.
- **llm**: Specifies the model and temperature for the language model.
- **user**: Defines the user’s role, context, and goals. The goals include inquiries about customization and specific options for the seat and grips.
- **chatbot**: Describes the expected outputs from the chatbot, such as confirmation of customization and details about options and costs.
- **conversation**: Sets the number of interactions and how the conversation will flow.
