The `pairwise` function is a powerful tool used in Sensei profiles to generate combinations of input values for testing. It helps ensure that all pairs of input variables are covered without having to create every possible combination, which can be overwhelming and inefficient!

### How It Works:

1. **Input Variables**: When you define your input variables in the profile, you can specify the `function: pairwise()` for any of them. This tells Sensei to create combinations that cover all possible pairs of the specified variables.

2. **Combination Generation**: For example, if you have two input variables, `size` (with values like `small`, `medium`, `large`) and `toppings` (with values like `cheese`, `pepperoni`), using `pairwise()` will generate combinations that ensure each size is tested with each topping at least once.

3. **Efficiency**: This method significantly reduces the number of tests needed while still providing good coverage. Instead of testing every possible combination of sizes and toppings, it focuses on pairs, making it much more manageable.

### Example:

If you have the following inputs:

```yaml
inputs:
  - name: size
    type: string
    data: ['small', 'medium', 'large']
    function: pairwise()
  - name: toppings
    type: string
    data: ['cheese', 'pepperoni']
    function: pairwise()
```

Using `pairwise()` will generate combinations like:

- small + cheese
- small + pepperoni
- medium + cheese
- medium + pepperoni
- large + cheese
- large + pepperoni

This way, you ensure that all sizes are tested with all toppings without creating an exhaustive list of every possible combination.
