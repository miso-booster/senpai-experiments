A metamorphic rule in Sensei is a condition that you define to check the correctness of conversations generated by the Sensei-chat. Unlike traditional testing methods that look for absolute answers, metamorphic rules focus on the relationships between pairs or tuples of conversations. This means they help verify how outputs should change (or not) when inputs change, which is super helpful in alleviating the oracle problem!

Here's a quick breakdown of how it works:

1. **Generate Conversations**: First, you create conversations using Sensei-chat, which includes inputs and outputs.

2. **Write Metamorphic Rules**: You then write rules in YAML format that specify:
   - How many conversations the rule needs to evaluate.
   - Any selection filters to determine which conversations to compare.
   - The expected relationship between the outputs of those conversations.

3. **Evaluate the Rules**: Sensei-check evaluates these rules against the generated conversations and reports any failures.

For example, you might have a rule that states if two pizza orders are the same size and drink, the one with more toppings should cost more. This helps ensure that the chatbot behaves correctly under various scenarios! 🍕✨
