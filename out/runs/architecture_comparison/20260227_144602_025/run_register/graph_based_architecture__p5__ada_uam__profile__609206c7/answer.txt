Sure! Here’s a sample profile you can use to test the UAM chatbot for a user seeking support related to the CAU (User Support Center). This profile will focus on obtaining the CAU’s phone number, email address, physical location, and opening hours.

```yaml
test_name: "Support Inquiry for CAU"

llm:
  temperature: 0.8
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita información sobre el Centro de Atención a Usuarios (CAU)."
  context:
    - "Como estudiante, necesito obtener información de contacto y horarios del CAU para resolver mis dudas."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Cuál es el correo electrónico de contacto del CAU?"
    - "¿Dónde se encuentra físicamente el CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me puedes decir eso de otra forma? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - phone_contact:
        type: string
        description: "Número de teléfono del CAU"
    - email_contact:
        type: string
        description: "Correo electrónico de contacto del CAU"
    - physical_location:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

Feel free to adjust any part of the profile to better fit your testing needs! Happy testing! 😊
