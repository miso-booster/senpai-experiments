Let's create a profile for your chatbot that asks the user for items to add to their shopping cart. This profile will define the user's goals, the chatbot's output, and how the conversation will flow.

### Profile Structure

Here's a basic outline of what the profile will include:

- **Test Name**: A descriptive name for the profile.
- **User Role**: Describes the simulated user's context and behavior.
- **Goals**: The specific items the user wants to add to the shopping cart.
- **Chatbot Output**: Fields to extract after the conversation.
- **Conversation Controls**: How many interactions and the style of interaction.

### YAML Profile Example

Here's a YAML representation of the profile:

```yaml
test_name: "shopping_cart_addition"

llm:
  temperature: 0.7
  model: "gpt-4o"
  model_prov: "openai"
  format:
    type: text

user:
  language: English
  role: "You are a customer looking to add items to your shopping cart."
  context:
    - "You can specify multiple items and their quantities."
  goals:
    - "Add {{quantity}} of {{item}} to my shopping cart."
    - item:
        function: random()
        type: string
        data: ["apples", "bananas", "milk", "bread", "eggs"]
    - quantity:
        function: random(3)
        type: int
        data:
          min: 1
          max: 5

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you please repeat that?"
  output:
    - items_added:
        type: list[string]
        description: "List of items added to the shopping cart."
    - total_items:
        type: int
        description: "Total number of items in the shopping cart."

conversation:
  number: 5
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Summary of the Profile

- **Test Name**: "shopping_cart_addition" - This identifies the profile.
- **User Role**: The user is a customer adding items to their cart.
- **Goals**: The user can specify items and quantities to add.
- **Chatbot Output**: The profile extracts a list of added items and the total count.
- **Conversation Controls**: The conversation allows for 5 interactions with a mix of styles.
