In the context of Sensei-check, an **oracle** refers to a rule or condition that defines what the expected outcome should be for a conversation or a set of conversations. Essentially, it's a way to verify if the chatbot's responses are correct based on certain criteria.

For example, in a metamorphic rule, you might have an oracle that checks if a certain output (like a price or a confirmation message) meets specific conditions. If the chatbot's response aligns with the oracle's expectations, it passes the test; if not, it fails.

Oracles can be used for both single conversations (traditional oracles) and multiple conversations (metamorphic testing), helping to ensure that the chatbot behaves as intended across different scenarios. They play a crucial role in validating the correctness and reliability of the chatbot's responses! 😊
