```yaml
test_name: "bike_wheel_change_appointment"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer looking to set an appointment to change your bike wheels."
  context:
    - "You want to know the available dates and times for the appointment."

    - appointment_date:
        function: random()
        type: string
        data:
          - "Monday"
          - "Tuesday"
          - "Wednesday"
          - "Thursday"
          - "Friday"
          - "Saturday"
    - appointment_time:
        function: random()
        type: string
        data:
          - "10:00 AM"
          - "1:00 PM"
          - "3:00 PM"
          - "5:00 PM"

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Can you please rephrase?"
  output:
    - appointment_confirmation:
        type: string
        description: "Confirmation of the appointment date and time."
    - available_dates:
        type: list[string]
        description: "List of available dates for appointments."
    - available_times:
        type: list[string]
        description: "List of available times for appointments."

conversation:
  number: 5
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Explanation:
- **Goals**: The user wants to schedule an appointment, and the variables `appointment_date` and `appointment_time` allow for testing different combinations of dates and times.
- **Outputs**: The chatbot should confirm the appointment and provide lists of available dates and times.
- **Interaction Style**: This includes a mix of long phrases and single questions to simulate different user interactions.
