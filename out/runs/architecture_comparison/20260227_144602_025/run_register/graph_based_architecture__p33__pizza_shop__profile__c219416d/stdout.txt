¡Claro! Aquí tienes un perfil de ejemplo para probar el chatbot de una pizzería. Este perfil está diseñado para que el output muestre el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares. Puedes copiarlo y ajustarlo según tus necesidades:

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza and drinks."
  context:
    - "You want to place an order for a pizza and a drink."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Select a {{drink_type}}."
    - "Confirm the order."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Vegetarian, BBQ Chicken]
    - drink_type:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: true
  fallback: "I'm sorry, I didn't understand that. Can you please repeat?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink_type:
        type: string
        description: "The type of drink ordered."
    - order_id:
        type: string
        description: "A unique identifier for the order."
    - total_price:
        type: currency
        description: "The final price of the order in dollars."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Desglose del perfil:
- **test_name**: Nombre del perfil para identificarlo.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario y los objetivos de la conversación.
- **chatbot**: Especifica la salida que se espera del chatbot, incluyendo el tipo de pizza, bebida, ID del pedido y precio total.
- **conversation**: Controla el número de interacciones y el estilo de la conversación.
