To create a rule that checks if the price of a small pizza is $10, we need to ensure that we reference the correct fields from the relevant profile's `chatbot.output`. Based on the documentation retrieved, it seems we can create a rule that checks the price of a small pizza.

Here's how the rule will look:

```yaml
name: small_pizza_price_check
description: Checks that the price of a small pizza is exactly $10.
active: true
conversations: 1
when: size == 'small'
oracle: extract_float(price) == 10 and currency(price) == 'USD'
```

### Explanation:
- **name**: This is the identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **active**: Set to true to ensure the rule is evaluated.
- **conversations**: Set to 1 since this is a single-conversation check.
- **when**: This condition checks if the size of the pizza is 'small'.
- **oracle**: This checks that the extracted price is exactly $10 and that the currency is USD.

This rule assumes that the profile being used has the fields `size` and `price` defined in its `chatbot.output`. If you need to confirm the profile or make adjustments, please let me know!
