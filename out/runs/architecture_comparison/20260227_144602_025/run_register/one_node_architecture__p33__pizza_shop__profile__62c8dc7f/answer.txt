¡Claro! Aquí tienes un perfil para probar el chatbot de una pizzería. Este perfil está diseñado para extraer el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares. Espero que te sea útil 😊.

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza."
  context:
    - "You want to know about pizza options and place an order."
  goals:
    - "What types of pizza do you have?"
    - "I would like a {{pizza_type}} pizza."
    - "What drinks do you offer?"
    - "I want a {{drink}}."
    - "Please confirm my order."

    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Veggie]

    - drink:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: true
  fallback: "I'm sorry, I didn't understand that."
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink:
        type: string
        description: "The drink ordered."
    - order_id:
        type: string
        description: "The unique ID for the order."
    - total_price:
        type: currency
        description: "Final price of the order in dollars."

conversation:
  number: 1
  goal_style:
    steps: 5
  interaction_style:
    - long phrases
```

Este perfil define las interacciones del usuario y los datos que se extraerán al final de la conversación. Si necesitas hacer ajustes o añadir más detalles, ¡no dudes en decírmelo! 🍕
