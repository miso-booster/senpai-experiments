¡Claro! Aquí tienes un perfil de ejemplo que puedes usar para probar la capacidad del chatbot de Alcampo en recomendar recetas y planificación de menús. Puedes ajustarlo según tus necesidades específicas:

```yaml
test_name: "Recetas y Planificación de Menús"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A user looking for recipe recommendations and meal planning assistance."
  context:
    - "You are interested in exploring healthy recipes that fit your dietary preferences."
    - "You want to plan meals for the week to ensure variety and nutrition."
  goals:
    - "Ask for healthy dinner recipes that include chicken."
    - "Request a meal plan for a week that incorporates seasonal vegetables."
    - "Inquire about quick lunch ideas for busy weekdays."
    - "Ask for dessert recipes that are low in sugar."
    - "Request tips on meal prepping for the week."

chatbot:
  is_starter: false
  fallback: "Lo siento, no entendí tu solicitud. 😊 ¿Puedes reformular tu pregunta sobre recetas o planificación de menús?"
  output:
    - dinner_recipes:
        type: string
        description: "Healthy dinner recipes that include chicken."
    - meal_plan:
        type: string
        description: "A meal plan for a week with seasonal vegetables."
    - lunch_ideas:
        type: string
        description: "Quick lunch ideas for busy weekdays."
    - dessert_recipes:
        type: string
        description: "Low sugar dessert recipes."
    - meal_prepping_tips:
        type: string
        description: "Tips on meal prepping for the week."

conversation:
  number: 5
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```

Este perfil está diseñado para interactuar con el chatbot y obtener recomendaciones sobre recetas y planificación de menús. Puedes ejecutarlo y ver cómo responde el chatbot a cada una de las solicitudes. ¡Espero que te sea útil! Si necesitas más ayuda, ¡no dudes en preguntar! 😊
