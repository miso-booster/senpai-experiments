Para crear una regla que verifique que el chatbot ha devuelto una lista de juguetes eco-friendly, primero asegurémonos de que el `chatbot.output` en tu perfil tenga un campo llamado `eco_friendly_toys`. Luego, podemos escribir una regla que compruebe si este campo está presente y tiene contenido.

Aquí tienes un ejemplo de cómo podría verse la regla en YAML:

```yaml
name: eco_friendly_toys_check
description: Verifica que el chatbot devuelva una lista de juguetes eco-friendly
conversations: 1
oracle: eco_friendly_toys is not None and len(eco_friendly_toys) > 0
```

Esta regla asegura que el campo `eco_friendly_toys` no sea `None` y que contenga al menos un elemento en la lista. Si necesitas algo más específico o diferente, ¡házmelo saber! 😊
