¡Claro! 😊 Aquí tienes un ejemplo de perfil que puedes usar para probar la capacidad del chatbot de Alcampo en recomendar recetas y planificación de menús. Puedes ajustarlo según tus necesidades específicas:

```yaml
test_name: "Recetas y Planificación de Menús"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A user looking for recipe recommendations and meal planning assistance."
  context:
    - "You are interested in healthy and seasonal recipes."
    - "You want to explore new meal ideas for the week."
  goals:
    - "Suggest a recipe for a healthy dinner."
    - "Provide a weekly meal plan including breakfast, lunch, and dinner."
    - "Recommend seasonal ingredients to include in the meal plan."
    - "Ask for tips on meal prepping for the week."
    - "Inquire about any special dietary considerations for the recipes."

chatbot:
  is_starter: false
  fallback: "Lo siento, no entendí tu pregunta. ¿Cómo puedo ayudarte con recetas y planificación de menús?"
  output:
    - recipe_suggestion:
        type: string
        description: "Recommended recipe for a healthy dinner."
    - weekly_meal_plan:
        type: string
        description: "Weekly meal plan including breakfast, lunch, and dinner."
    - seasonal_ingredients:
        type: string
        description: "List of seasonal ingredients to include."
    - meal_prepping_tips:
        type: string
        description: "Tips for meal prepping for the week."
    - dietary_considerations:
        type: string
        description: "Special dietary considerations for the recipes."

conversation:
  number: 5
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```

Este perfil está diseñado para interactuar con el chatbot y evaluar su capacidad para proporcionar recomendaciones de recetas y planificación de menús. Puedes ejecutarlo en tu entorno de prueba de Sensei. ¡Espero que te sea útil! Si necesitas más ajustes o ayuda, ¡no dudes en decírmelo! 🍽️✨
