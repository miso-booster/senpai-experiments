¡Claro! Vamos a crear un perfil para que el usuario obtenga soporte sobre el CAU de la UAM. Este perfil incluirá las metas que mencionaste: obtener el número de teléfono, correo electrónico, dirección física y horarios de servicio.

Aquí tienes un ejemplo de cómo podría ser el perfil en YAML:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca información sobre el Centro de Atención a Usuarios (CAU)."
  context:
    - "El usuario necesita asistencia sobre cómo contactar al CAU."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar sobre los horarios de servicio del CAU."

chatbot:
  is_starter: false
  fallback: "Lo siento, no puedo ayudar con eso."
  output:
    - contact_email:
        type: string
        description: "Correo electrónico del CAU"
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horas de servicio del CAU"

conversation:
  number: 5
  goal_style:
    steps: 4
  interaction_style:
    - long phrases
    - make spelling mistakes
```

### Explicación del perfil:
- **test_name**: Nombre del perfil para identificarlo.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario y el contexto de la conversación.
- **goals**: Las metas específicas que el usuario quiere alcanzar durante la conversación.
- **chatbot**: Define la salida esperada del chatbot, que incluye el correo electrónico, número de teléfono, dirección física y horarios de servicio.
- **conversation**: Controla el número de interacciones y el estilo de interacción.
