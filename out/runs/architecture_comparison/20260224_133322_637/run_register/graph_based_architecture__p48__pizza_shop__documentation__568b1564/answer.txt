Great question! 😊 In the context of Sensei, a **metamorphic rule** is a specific type of rule used in **Sensei-check** to verify the correctness of conversations generated by Sensei-chat. 

Here's a simple breakdown:

1. **Definition**: A metamorphic rule states a condition that checks how outputs should change (or remain the same) when inputs change across pairs or tuples of conversations. This helps in alleviating the oracle problem by focusing on the relationships between outputs rather than just absolute answers.

2. **Types of Checks**: Metamorphic rules can target:
   - A **single conversation** (traditional oracle checks).
   - **Several conversations** (this is where metamorphic testing comes into play).
   - **All conversations** (global checks).

3. **How It Works**:
   - You generate conversations using Sensei-chat, which includes inputs and outputs.
   - You write rules in YAML format that specify how many conversations are needed, any filters for selection, and the relations to check.
   - Sensei-check evaluates these rules and reports any failing cases.

For example, a metamorphic rule might check that if two pizzas have the same size and drink, the one with more toppings should cost more. This kind of rule helps ensure that the chatbot behaves consistently and correctly across different scenarios.
