¡Claro! Vamos a crear un perfil para probar la capacidad del chatbot de Alcampo en recomendar recetas y ayudar con la planificación de menús. Aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "Recetas y Planificación de Menús"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "User looking for recipe recommendations and meal planning assistance."
  context:
    - "You are interested in healthy meals and seasonal ingredients."
    - "You want to explore new recipes that fit your dietary preferences."
  goals:
    - "Ask for recipe suggestions based on seasonal ingredients."
    - "Request a weekly meal plan that includes breakfast, lunch, and dinner."
    - "Inquire about healthy snack options."
    - "Ask for tips on meal prepping for the week."
    - "Request information on how to incorporate more vegetables into your meals."

chatbot:
  is_starter: false
  fallback: "Lo siento, no entiendo tu solicitud. ¿Puedes reformularla? Estoy aquí para ayudarte con recetas y planificación de menús."
  output:
    - recipe_suggestions:
        type: string
        description: "Recommendations for recipes based on seasonal ingredients."
    - weekly_meal_plan:
        type: string
        description: "A suggested meal plan for the week."
    - healthy_snack_options:
        type: string
        description: "List of healthy snack options."
    - meal_prepping_tips:
        type: string
        description: "Tips for meal prepping effectively."
    - vegetable_incorporation_tips:
        type: string
        description: "Suggestions for adding more vegetables to meals."

conversation:
  number: 5
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```

Este perfil define un usuario que busca recomendaciones de recetas y ayuda con la planificación de menús. Incluye varios objetivos que el chatbot debe cumplir y especifica qué tipo de información se espera que devuelva. Puedes ajustarlo según tus necesidades específicas.
