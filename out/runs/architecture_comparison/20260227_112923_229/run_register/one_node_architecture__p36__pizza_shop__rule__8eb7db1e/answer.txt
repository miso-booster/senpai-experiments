Sure! Here’s a Sensei rule that checks if the price of a small pizza is at least $10. This rule will ensure that the price is correctly validated for small pizzas.

```yaml
name: small_pizza_price_check
description: Small pizzas should cost at least $10
conversations: 1
when: pizza_size == 'small'
oracle: extract_float(price) >= 10 and currency(price) == 'USD'
```

Feel free to adjust the `currency` check if your project uses a different currency! Let me know if you need any more help! 😊
