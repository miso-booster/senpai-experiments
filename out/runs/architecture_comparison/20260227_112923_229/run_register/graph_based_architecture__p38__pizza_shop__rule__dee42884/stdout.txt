¡Hola! 😊 Para crear una regla que verifique si el asistente confirma que ha añadido la bebida que el usuario pidió, podemos utilizar la estructura de una regla de Sensei-check. 

Aquí te dejo un ejemplo de cómo podría verse esta regla:

```yaml
name: confirm_drink_added
description: El asistente debe confirmar que se ha añadido la bebida solicitada por el usuario.
conversations: 1
if: utterance_index('user', 'quiero una bebida') < utterance_index('assistant', 'he añadido la bebida')
then: utterance_index('assistant', 'he añadido la bebida') > 0
```

### Explicación:
- **`name`**: Este es el nombre de la regla.
- **`description`**: Una breve descripción de lo que verifica la regla.
- **`conversations`**: Aquí se establece que se está evaluando una sola conversación.
- **`if`**: Esta condición comprueba si el índice de la conversación donde el usuario menciona que quiere una bebida es menor que el índice donde el asistente confirma que ha añadido la bebida.
- **`then`**: Esta parte asegura que la respuesta del asistente confirmando la adición de la bebida se produjo en la conversación.
