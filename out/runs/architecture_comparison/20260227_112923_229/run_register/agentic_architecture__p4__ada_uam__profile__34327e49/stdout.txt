He revisado la documentación sobre perfiles en el archivo `sensei-chat-guide.md`. Ahora puedo ayudarte a crear un perfil para el chatbot de la UAM que permita a los usuarios obtener soporte sobre el CAU (Centro de Atención a Usuarios). Este perfil incluirá la recolección de datos como el número de teléfono, correo electrónico, dirección física y horarios.

### Estructura del Perfil

Aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "CAU_Support_Profile"

llm:
  temperature: 0.7
  model: "gpt-4o"
  model_prov: "openai"
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca soporte del CAU"
  context:
    - "El usuario necesita información sobre el CAU."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Cuál es el correo electrónico del CAU?"
    - "¿Dónde se encuentra la dirección física del CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: true
  fallback: "Lo siento, no pude encontrar esa información. ¿Podrías reformular tu pregunta?"
  output:
    - telefono:
        type: string
        description: "Número de teléfono del CAU"
    - email:
        type: string
        description: "Correo electrónico del CAU"
    - direccion:
        type: string
        description: "Dirección física del CAU"
    - horarios:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Desglose del Perfil

- **test_name**: Nombre del perfil para identificarlo.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el lenguaje, el rol del usuario y los objetivos que busca alcanzar.
- **chatbot**: Indica si el chatbot inicia la conversación, el mensaje de respaldo y los campos de salida que se extraerán.
- **conversation**: Controla el número de interacciones y el estilo de interacción.
