### YAML Connector

```yaml
name: "Alcampo Bot"
base_url: "https://alcampo.botslovers.com/bot/web"
send_message:
  path: "/bot/web"
  method: "POST"
  headers:
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
    Accept: "*/*"
    Accept-Language: "en-US,en;q=0.9"
    Accept-Encoding: "gzip, deflate, br, zstd"
    Content-Type: "application/json"
    Origin: "https://alcampo.botslovers.com"
    Connection: "keep-alive"
  payload_template:
    data:
      id_user: "{user_id}"
      idweb_user: "{web_user_id}"
      session: "{session_id}"
      message:
        message:
          message:
            text: "{user_msg}"
        iduser: "{user_id}"
        session: "{session_id}"
        channel: "web"
      widget_form: "TRUE"
      contexto_extra: []
      lang: "es"
      accion: "response_bot"
response_path: "messages.0.0.message.text"
```

### Explanation
- **name**: A friendly name for your connector.
- **base_url**: The base URL of the chatbot API.
- **send_message**: Configuration for sending messages, including:
  - **path**: The endpoint for sending messages.
  - **method**: The HTTP method used (POST).
  - **headers**: Custom headers required for the request.
  - **payload_template**: The structure of the JSON payload, with placeholders for dynamic values (like user ID and message).
- **response_path**: The path to extract the bot's reply from the JSON response.

This connector is set up to send a message to the Alcampo bot and extract the response text. If you need any modifications or additional features, just let me know! 😊
