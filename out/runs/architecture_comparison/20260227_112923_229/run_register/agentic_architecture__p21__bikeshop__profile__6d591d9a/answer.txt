Great! I've loaded the relevant documentation for profiles from `sensei-chat-guide.md`. Now, let's create a profile for a user who wants to set an appointment at a bike shop to have their wheels changed, including different variables for testing various days and times.

### Profile Structure

Here's how the profile will be structured:

- **Test Name**: A descriptive name for the profile.
- **User Details**: Language, role, context, and goals.
- **Chatbot Output**: Fields that will be extracted after the conversation.
- **Conversation Controls**: Number of conversations, goal style, and interaction style.

### Proposed Profile YAML

```yaml
test_name: "bike_shop_appointment"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer wanting to set an appointment to change bike wheels."
  context:
    - "The customer prefers morning appointments."
  goals:
    - "Schedule an appointment for wheel change on {{appointment_date}} at {{appointment_time}}."
    - appointment_date:
        function: random()
        type: string
        data:
          - any(3 dates within the next 30 days)
    - appointment_time:
        function: random()
        type: string
        data:
          - "09:00 AM"
          - "10:00 AM"
          - "11:00 AM"
          - "01:00 PM"
          - "02:00 PM"

chatbot:
  is_starter: true
  fallback: "I'm sorry, I didn't quite understand that. Could you please rephrase?"
  output:
    - confirmation_message:
        type: string
        description: "Confirmation message for the appointment."
    - appointment_id:
        type: string
        description: "Unique identifier for the appointment."

conversation:
  number: combinations(0.5, pairwise)  # Using pairwise combinations for varied testing
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Summary of the Profile

- **Test Name**: `bike_shop_appointment` — This identifies the profile for testing.
- **User Role**: The simulated user is a customer looking to set an appointment.
- **Goals**: The profile includes variables for the appointment date and time, allowing for testing of different scenarios.
- **Chatbot Output**: The profile specifies fields like `confirmation_message` and `appointment_id` to be extracted after the conversation.
- **Conversation Controls**: It uses combinations for varied testing and includes different interaction styles.
