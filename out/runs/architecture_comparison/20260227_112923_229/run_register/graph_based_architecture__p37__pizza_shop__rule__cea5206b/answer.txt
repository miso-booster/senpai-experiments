It looks like your rule is almost there, but it seems to be missing the `if` condition, which is essential for defining the precondition before asserting the relationship in the `then` clause. 

In your case, you want to check if the number of toppings in `conv[0]` is greater than in `conv[1]` before asserting that the price of `conv[0]` should be greater than the price of `conv[1]`. 

Here’s the corrected version of your rule:

```yaml
name: more_toppings_cost_more
description: Adding more toppings to a custom pizza costs more
active: true
conversations: 2
when: conv[0].size == conv[1].size and conv[0].drink == conv[1].drink
if: len(conv[0].toppings) > len(conv[1].toppings)
then: extract_float(conv[0].price) > extract_float(conv[1].price)
```

Now, this rule will check that if the first conversation has more toppings than the second, and both pizzas are the same size and drink, then the price of the first pizza should indeed be greater than the second.
