Sure! To create a rule that checks if the order ID was provided by the chatbot, you can use the following YAML structure. This rule will ensure that the `order_id` field is not empty in the chatbot's output.

Here's how you can write the rule:

```yaml
name: order_id_provided
description: Ensure that the chatbot provides an order ID in the response
conversations: 1
oracle: order_id is not None
```

In this rule:

- **name**: This is the identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: This indicates that the rule applies to a single conversation.
- **oracle**: This checks that the `order_id` field is not `None`, meaning it should be provided by the chatbot.
