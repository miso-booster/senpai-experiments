### Profile Structure
Here's a breakdown of what we need for the profile:
- **Test Name**: A descriptive name for the profile.
- **User Role**: Describe the simulated user (e.g., a customer at a bike shop).
- **User Goals**: Specify what the user wants to achieve (e.g., changing the seat and handlebar grips).
- **Chatbot Output**: Define what information we want to extract after the conversation.

### Proposed Profile YAML
Here's a draft of the profile based on your requirements:

```yaml
test_name: "bike_shop_customization"

llm:
  temperature: 0.7
  model: "gpt-4o"
  model_prov: "openai"
  format:
    type: text

user:
  language: English
  role: "A customer who recently bought a new bike and wants to customize it."
  context:
    - "The user is looking for a comfortable seat and better handlebar grips."
  goals:
    - "Request to change the seat to a more comfortable one."
    - "Ask for options on handlebar grips."
    - "Inquire about the cost for these customizations."

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you clarify that?"
  output:
    - seat_type:
        type: string
        description: "Type of seat chosen."
    - grip_type:
        type: string
        description: "Type of handlebar grips chosen."
    - total_cost:
        type: currency
        description: "Total cost for the customizations."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
```
