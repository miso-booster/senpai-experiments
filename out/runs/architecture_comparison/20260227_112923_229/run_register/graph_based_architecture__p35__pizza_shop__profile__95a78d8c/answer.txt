That sounds like a fun scenario to create! 😊 Let's put together a profile where the user starts by asking for a custom pizza but then changes their mind and opts for a predefined pizza instead. Here’s a sample profile you can use:

```yaml
test_name: "custom_to_predefined_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer looking to order a pizza."
  context:
    - "You initially want to customize your pizza with specific toppings."
    - "Halfway through, you decide to go for a predefined pizza instead."
  goals:
    - "I would like to order a custom pizza with {{custom_toppings}}."
    - "Actually, can I get a {{predefined_pizza}} pizza instead?"
    - custom_toppings:
        function: random()
        type: string
        data: [pepperoni, mushrooms, olives, onions, extra cheese]
    - predefined_pizza:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, BBQ Chicken]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Can you please clarify?"
  output:
    - order_confirmation:
        type: string
        description: "Confirmation of the pizza order."
    - pizza_type:
        type: string
        description: "Type of pizza ordered."
    - toppings:
        type: string
        description: "Toppings on the custom pizza."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - change your mind
    - long phrases
```

### Explanation:
- **User Role and Context**: The user is set up as a customer who starts with a custom pizza request but changes their mind.
- **Goals**: The goals include asking for custom toppings and then switching to a predefined pizza.
- **Chatbot Output**: The chatbot is expected to confirm the order and provide details about the pizza type and toppings.
- **Conversation Controls**: The interaction style includes the ability to change their mind, which is key to this profile.
