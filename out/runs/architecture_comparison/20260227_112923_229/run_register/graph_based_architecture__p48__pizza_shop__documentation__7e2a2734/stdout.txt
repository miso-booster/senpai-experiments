Great question! 😊 In the context of Sensei, a **metamorphic rule** is a condition that you define to check the correctness of conversations generated by your chatbot. These rules help ensure that the chatbot behaves as expected when certain inputs change.

Here’s a simple breakdown:

1. **Purpose**: Metamorphic rules are used to verify how outputs should change (or remain the same) when you modify the inputs. This helps in alleviating the oracle problem, where you might not always know the correct answer but can still check relationships between different outputs.

2. **Types of Checks**: These rules can target:
   - A **single conversation** (traditional oracle).
   - **Several conversations** (this is where metamorphic testing shines!).
   - **All conversations** (global checks).

3. **How It Works**: You write these rules in a format called YAML, specifying:
   - How many conversations you want to compare.
   - Any filters for selecting eligible conversations.
   - The relationship you want to check (like if one output should be greater than another).

For example, if you have two pizza orders of the same size and drink, a metamorphic rule might state that if one order has more toppings, it should cost more than the other. 

This way, you can ensure your chatbot maintains consistent and logical behavior across different scenarios! 🍕✨ If you have more questions about writing these rules or how they connect to profiles, feel free to ask!
