¡Listo! He revisado la documentación sobre perfiles en el archivo `sensei-chat-guide.md`. Ahora puedo ayudarte a crear un perfil para probar el chatbot de una pizzería. Aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "pizzeria_order_test"

llm:
  temperature: 0.7
  model: "gpt-4o"
  model_prov: "openai"
  format:
    type: text

user:
  language: Spanish
  role: "Eres un cliente que quiere hacer un pedido en una pizzería."
  context:
    - "Prefieres pizza vegetariana."
  goals:
    - "Quiero pedir una {{tipo_pizza}} y una {{bebida}}."
    - "¿Cuál es el precio final?"
    - tipo_pizza:
        function: random()
        type: string
        data: [\"margarita\", \"pepperoni\", \"vegetariana\", \"cuatro quesos\"]
    - bebida:
        function: random()
        type: string
        data: [\"Coca-Cola\", \"Fanta\", \"agua\", \"cerveza\"]
  
chatbot:
  is_starter: true
  fallback: "Lo siento, no entendí eso."
  output:
    - tipo_pizza:
        type: string
        description: "Tipo de pizza que se ha pedido."
    - bebida:
        type: string
        description: "Bebida que se ha pedido."
    - order_id:
        type: string
        description: "ID del pedido."
    - total_price:
        type: currency
        description: "Precio final del pedido en dólares."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Resumen del perfil:
- **Nombre de prueba**: `pizzeria_order_test`
- **Salida del chatbot**: incluye el tipo de pizza, la bebida, el ID del pedido y el precio total.
- **Interacción**: el usuario simula un cliente que pide pizza y bebida, y pregunta por el precio.
