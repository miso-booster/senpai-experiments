I've loaded the relevant documentation on profiles from `sensei-chat-guide.md`. Now, let's create a profile for a user who initially asks for a custom pizza but changes their mind halfway through the conversation and opts for a predefined pizza instead.

### Profile Structure

Here’s a breakdown of the profile we'll create:

- **Test Name**: A descriptive name for the test.
- **User**:
  - **Language**: English (or Spanish, depending on your preference).
  - **Role**: Describes the user's intention to order a pizza.
  - **Goals**: 
    - Initially ask for a custom pizza with specific toppings.
    - Change the request to a predefined pizza.
- **Chatbot**:
  - **Is Starter**: Indicates if the chatbot starts the conversation.
  - **Fallback Message**: A message the chatbot uses if it doesn't understand.
  - **Output**: Fields to extract, such as the final order details.
- **Conversation Controls**: Number of conversations and interaction style.

### Proposed Profile YAML

Here's the YAML for the profile:

```yaml
test_name: "custom_to_predefined_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer who wants to order a pizza."
  context:
    - "The user is flexible but tends to change their mind."
  goals:
    - "I would like a custom pizza with {{toppings}}."
    - "Actually, can I have a {{predefined_pizza}} instead?"
    - toppings:
        function: random()
        type: string
        data: [pepperoni, mushrooms, onions, sausage, bacon, extra cheese]
    - predefined_pizza:
        function: random()
        type: string
        data: [Margherita, Pepperoni, BBQ Chicken, Hawaiian]

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you repeat that?"
  output:
    - order_details:
        type: string
        description: "Details of the final pizza order."

conversation:
  number: 2
  goal_style:
    steps: 5
  interaction_style:
    - change your mind
```

### Explanation

- **Goals**: The user starts by requesting a custom pizza and then changes their mind to ask for a predefined pizza.
- **Interaction Style**: The `change your mind` style is included to reflect the user's behavior of switching preferences.
- **Output**: The `order_details` field will capture the final pizza order details for validation.
