Absolutely! To ensure that your chatbot responds in the same language as the user, we can create a metamorphic rule using the `responds_in_same_language()` helper. This will check if the chatbot's responses match the user's language.

Here’s a sample rule you can use:

```yaml
name: language_consistency
description: Ensure the chatbot responds in the same language as the user.
conversations: 2
when: conv[0].language == conv[1].language
oracle: responds_in_same_language()
```

### Explanation:
- **name**: This is a descriptive name for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: We are checking pairs of conversations (2).
- **when**: This condition ensures that we only compare conversations where the user's language is the same.
- **oracle**: This checks that the chatbot's responses are in the same language as the user.
