```yaml
  headers:
    Content-Type: "application/json"

      text: "{user_msg}"

```

### Explanation of the Configuration

- **name**: A friendly name for the connector.
- **base_url**: The base URL for the API.
- **send_message**: 
  - **path**: The endpoint for sending messages.
  - **method**: The HTTP method used (POST).
  - **headers**: Custom headers required for the request, including `Content-Type` and `Authorization`.
  - **payload_template**: The JSON structure to send, with placeholders for dynamic values (`{conversation_id}`, `{sender_id}`, `{bot_id}`, and `{user_msg}`).
- **response_path**: Specifies how to extract the bot's reply from the JSON response.
