To create a rule that checks if the chatbot provided all the correct information about the CAU, we will follow the structure outlined in the documentation. The rule will verify that the chatbot outputs match the expected values for the contact email, phone number, and physical address.

### Rule Structure

Here’s how the rule will be structured based on the provided outputs:

- **Name**: A descriptive name for the rule.
- **Description**: A brief explanation of what the rule checks.
- **Conversations**: This will be set to 1 since we are checking a single conversation.
- **When**: This will check if the outputs are not empty.
- **Oracle**: This will check if the outputs match the expected values.

### Expected Outputs
- **contact_email**: `cau@uam.es`
- **contact_phone**: `91 497 4029`
- **physical_address**: `Higher Polytechnic School, C/ Francisco Tomás y Valiente nº 11, Building B, first floor, office TI-107`

### Proposed YAML Rule

Here’s the YAML for the rule:

```yaml
name: check_cau_information
description: Verifies that the CAU information provided by the chatbot is correct.
conversations: 1
oracle: |
  conv[0].contact_email == 'cau@uam.es' and
  conv[0].contact_phone == '91 497 4029' and
  conv[0].physical_address == 'Higher Polytechnic School, C/ Francisco Tomás y Valiente nº 11, Building B, first floor, office TI-107'
```

### Summary
- This rule checks if the chatbot's outputs for the CAU information are correct based on the specified values.
- It uses a single conversation to verify the outputs.
