Let's create a profile for a user who is trying to set up eduroam on their device but is facing difficulties. The profile will include various methods they might attempt to set it up as variables.

### Profile Structure

Here's how the profile will be structured:

- **Test Name**: A descriptive name for the profile.
- **User Information**: Language, role, context, and goals.
- **Chatbot Output**: Fields to extract after the conversation.
- **Conversation Controls**: How many conversations and interaction style.

### Proposed Profile YAML

```yaml
test_name: "eduroam_setup_assistance"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A user trying to set up eduroam on their device."
  context:
    - "The user is a student or staff member at an educational institution."
    - "They are using a laptop or mobile device."
  goals:
    - "Help me set up eduroam using {{setup_method}}."
    - setup_method:
        function: random()
        type: string
        data: [\"manual configuration\", \"using the eduroam CAT tool\", \"connecting via QR code\", \"assistance from IT support\", \"using a different device\"]

chatbot:
  is_starter: true
  fallback: "I'm sorry, I couldn't help with that. Can you try again?"
  output:
    - setup_status:
        type: string
        description: "Status of the setup attempt (success or failure)"
    - error_message:
        type: string
        description: "Any error messages encountered during setup"

conversation:
  number: 5
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - long phrases
      - single questions
      - make spelling mistakes
```

### Explanation of Key Sections

- **Goals**: The `setup_method` variable includes different ways the user might attempt to set up eduroam, such as manual configuration or using the eduroam CAT tool.
- **Chatbot Output**: The profile extracts the `setup_status` and `error_message` to validate the outcome of the setup attempts.
- **Conversation Controls**: The user will have multiple interactions, allowing for a variety of responses and scenarios.
