Connectors in Sensei are used to facilitate communication between the Sensei user simulator and your chatbot's API. They define how to send messages to the chatbot and how to extract responses from it. This allows you to test and validate your chatbot's behavior effectively.

### Key Fields in a Connector

Here are the main fields typically found in a connector configuration:

1. **name**: A friendly name for your chatbot connector.
2. **base_url**: The base URL of the chatbot API. This is the starting point for all API requests.
3. **send_message**: This section contains details about how to send messages to the chatbot:
   - **path**: The specific endpoint path that will be appended to the base URL.
   - **method**: The HTTP method to be used (e.g., POST, GET).
   - **headers**: Any custom headers required for the API request (e.g., authentication tokens).
   - **payload_template**: The structure of the JSON payload that will be sent to the chatbot, including placeholders for dynamic content (like user messages).
4. **response_path**: A dot-separated path to extract the chatbot's reply from the JSON response. This tells the connector where to find the relevant response data.

### Example Connector

Here’s a simple example of what a connector might look like:

```yaml
name: "My Custom Bot"
base_url: "https://api.mychatbot.com"
send_message:
  path: "/chat"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

In this example:
- The connector is named "My Custom Bot".
- It sends a POST request to the `/chat` endpoint of the specified base URL.
- The payload includes a message field that will be populated with the user's message.
- The response path indicates where to find the chatbot's reply in the JSON response.
