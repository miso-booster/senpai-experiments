That sounds like a great profile to create! 😊 Let's put together a Sensei profile for a user who needs to get their new bike set up with a tailored seat and handlebar grips. Here’s a basic structure you can use as a template:

```yaml
test_name: "bike_setup_request"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer who recently bought a new bike and wants to customize it."
  context:
    - "You want to change the seat to one that is more comfortable."
    - "You prefer handlebar grips that provide better grip and comfort."
  goals:
    - "Inquire about options for changing the seat."
    - "Ask about available handlebar grips."
    - "Request a quote for the customization services."
    - "Ask how long the setup will take."
    - "Specify that you want a {{seat_type}} seat."
    - "Specify that you want {{grip_type}} handlebar grips."
    - seat_type:
        function: forward()
        type: string
        data: [comfort, racing, gel, ergonomic]
    - grip_type:
        function: forward()
        type: string
        data: [rubber, foam, leather, gel]

chatbot:
  is_starter: false
  fallback: "I'm sorry, could you repeat that?"
  output:
    - seat_options:
        type: string
        description: "Information about available seat options."
    - grip_options:
        type: string
        description: "Information about available handlebar grip options."
    - setup_cost:
        type: money
        description: "The cost for the customization services."
    - setup_time:
        type: string
        description: "Estimated time for the setup."

conversation:
  number: 5
  goal_style:
    all_answered:
      export: true
      limit: 5
  interaction_style:
    - single questions
```

### Explanation of the Profile:
- **test_name**: A descriptive name for the test.
- **llm**: Specifies the language model and its settings.
- **user**: Defines the user’s role, context, and goals. The goals include inquiries about the seat and handlebar grips, as well as a request for cost and time estimates.
- **chatbot**: Specifies the chatbot's responses and what outputs to extract.
- **conversation**: Defines the number of interactions and how the conversation will flow.

Feel free to modify any part of this profile to better fit your testing needs! If you have any specific requirements or additional details you'd like to include, just let me know! 😊
