Sure! Since you want a rule that checks if the chatbot provided information about current promotions and it's not based on any specific profile, we can create a global rule using the `chatbot_returns` helper. Here’s how it could look:

```yaml
name: check_promotions_info
description: Ensure the chatbot provides information about current promotions.
conversations: 1
oracle: chatbot_returns('current_promotions') > 0
```

In this rule:

- **name**: A unique identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to 1 since we're checking a single conversation.
- **oracle**: This checks that the chatbot returns information related to `current_promotions`.

Feel free to adjust the field name in the `chatbot_returns` function if you have a specific term in mind for promotions! 😊
