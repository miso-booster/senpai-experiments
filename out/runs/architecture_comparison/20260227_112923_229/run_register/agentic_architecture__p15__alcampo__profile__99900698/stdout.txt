He revisado la documentación sobre perfiles en el archivo `sensei-chat-guide.md`. Ahora puedo ayudarte a crear un perfil que pruebe la capacidad del chatbot de Alcampo para recomendar recetas y planificar menús. 

### Estructura del Perfil

Aquí tienes un ejemplo de cómo podría ser el perfil:

```yaml
test_name: "recetas_y_planificacion_menu"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Eres un usuario que busca recomendaciones de recetas y planificación de menús."
  context:
    - "Te gusta la cocina mediterránea y prefieres recetas saludables."
  goals:
    - "Recomiéndame una receta para {{plato}}."
    - "Ayúdame a planificar un menú para {{num_dias}} días."
    - plato:
        function: random()
        type: string
        data: [ensalada, pasta, pollo, pescado]
    - num_dias:
        function: random()
        type: int
        data:
          min: 1
          max: 7

chatbot:
  is_starter: true
  fallback: "Lo siento, no puedo ayudar con eso."
  output:
    - receta:
        type: string
        description: "Receta recomendada."
    - menu:
        type: list[string]
        description: "Menú planificado."

conversation:
  number: combinations(0.5, pairwise)
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Descripción del Perfil

- **test_name**: Nombre del perfil para identificarlo.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el comportamiento del usuario simulado, incluyendo su rol y contexto.
- **goals**: Objetivos del usuario, como pedir recetas y planificar menús, con variables para personalizar las solicitudes.
- **chatbot**: Define cómo se comporta el chatbot, incluyendo los campos de salida que se extraerán.
- **conversation**: Controla el número de conversaciones y el estilo de interacción.
