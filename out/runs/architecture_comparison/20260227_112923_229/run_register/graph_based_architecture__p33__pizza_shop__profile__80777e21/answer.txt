¡Claro! Aquí tienes un perfil de ejemplo para probar el chatbot de una pizzería. Este perfil está diseñado para que el output muestre el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares. Puedes copiarlo y ajustarlo según tus necesidades:

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza and drinks from a pizzeria."
  context:
    - "You want to know the available pizza types and drinks."
  goals:
    - "Order a {{pizza_type}} pizza and a {{drink}}."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Vegetarian, BBQ Chicken]
    - drink:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Can you please rephrase?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink:
        type: string
        description: "The drink ordered."
    - order_id:
        type: string
        description: "A unique identifier for the order."
    - total_price:
        type: currency
        description: "The final price of the order in dollars."

conversation:
  number: 1
  goal_style:
    all_answered:
      export: true
      limit: 1
  interaction_style:
    - single questions
```

### Desglose del perfil:
- **test_name**: Nombre del perfil de prueba.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario y sus objetivos.
- **chatbot**: Define la respuesta del chatbot y los campos que se quieren extraer.
- **conversation**: Controla el número de interacciones y el estilo de la conversación.

¡Espero que esto te ayude a probar tu chatbot de pizzería! Si necesitas más ajustes o ayuda, no dudes en decírmelo 😊.
