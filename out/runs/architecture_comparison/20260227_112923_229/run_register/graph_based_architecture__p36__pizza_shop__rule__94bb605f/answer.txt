Sure! To create a rule that checks if the price of a small pizza is $10, you can use the following YAML structure. This rule will ensure that whenever the size of the pizza is 'small', the price must be at least $10.

Here's how you can write it:

```yaml
name: small_pizza_price_check
description: Small pizzas should cost at least $10
conversations: 1
when: size == 'small'
oracle: extract_float(price) >= 10 and currency(price) == 'USD'
```

### Explanation:
- **name**: A unique identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to 1 since this is a single-conversation check.
- **when**: This condition checks if the pizza size is 'small'.
- **oracle**: This checks that the extracted price is at least $10 and that the currency is USD.
