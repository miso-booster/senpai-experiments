I've loaded the relevant documentation for creating profiles from `sensei-chat-guide.md`. Now, let's create a profile that asks the chatbot for items to add to the user's shopping cart.

### Profile Structure

Here's a proposed structure for the profile:

- **Test Name**: A descriptive name for the profile.
- **User Role**: Describes the simulated user's behavior and context.
- **Goals**: Specifies what the user wants to achieve, including asking for items to add to the cart.
- **Chatbot Output**: Defines what information should be extracted after the conversation.
- **Conversation Controls**: Specifies how many conversations to run and interaction styles.

### Example Profile YAML

Here's an example YAML for the profile:

```yaml
test_name: "shopping_cart_addition"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer trying to add items to your shopping cart. Ask for different items and their prices."
  goals:
    - "I want to add {{item}} to my shopping cart."
    - item:
        function: random()
        type: string
        data: [apples, bread, milk, eggs, cheese]

chatbot:
  is_starter: true
  fallback: "Sorry, I didn't understand that. Can you please specify an item?"
  output:
    - item_added:
        type: string
        description: "The item that was added to the cart."
    - item_price:
        type: currency
        description: "The price of the item added to the cart."

conversation:
  number: 5
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Summary

- **Profile Name**: `shopping_cart_addition`
- **User Role**: Simulates a customer adding items to a shopping cart.
- **Goals**: Includes asking to add a random item from a predefined list.
- **Chatbot Output**: Extracts the item added and its price.
- **Conversation Controls**: Runs 5 conversations with a maximum of 3 steps each.
