Sure! Here’s a profile for a pizza shop where the user is rude and wants things done quickly. I've included 4 goals with 4 variables, and I've set up 2 of the variables to use pairwise functions to help determine the conversation number. Let's dive in! 🍕✨

```yaml
test_name: "rude_fast_pizza_order"

llm:
  temperature: 0.5
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "You are a rude customer who wants to place a pizza order quickly."
  context:
    - "You expect fast responses and don't tolerate delays."
    - "You're impatient and want to get your order sorted without any fuss."
  goals:
    - "What kinds of pizzas do you have?"
    - "I want a {{pizza_type}} pizza."
    - "Make it {{size}} and add {{toppings}}."
    - "Get me {{number_of_drinks}} {{drink_type}} drinks!"

    - pizza_type:
        function: forward()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian]
    - size:
        function: pairwise()
        type: string
        data: [small, medium, large]
    - toppings:
        function: pairwise()
        type: string
        data: [extra cheese, mushrooms, olives, peppers]
    - drink_type:
        function: forward()
        type: string
        data: [Coke, Sprite, Water, Lemonade]
    - number_of_drinks:
        function: random(2)
        type: int
        data: {min: 1, max: 5}

chatbot:
  is_starter: false
  fallback: "I'm sorry, could you repeat that?"
  output:
    - pizza_options:
        type: string
        description: "List of available pizza types."
    - order_confirmation:
        type: string
        description: "Confirmation of the pizza order."
    - drink_options:
        type: string
        description: "List of available drink options."
    - total_cost:
        type: currency
        description: "Total cost of the order."

conversation:
  number: combinations(0.5, pairwise) # Using pairwise functions for conversation number
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - single questions
```

This profile sets the stage for a rude customer who wants to get their pizza order done quickly! The use of pairwise functions for the `size` and `toppings` variables will help create a variety of combinations for testing. If you have any adjustments or need more details, just let me know! 😊🍕
