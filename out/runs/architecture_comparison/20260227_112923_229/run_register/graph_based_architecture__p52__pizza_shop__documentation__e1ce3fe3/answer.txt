Connectors are super handy tools that allow you to connect your chatbot to various APIs without needing to write any code! They help facilitate communication between your chatbot and external services, enabling it to send and receive messages seamlessly.

### Key Fields in Connectors

Here are the main fields you typically find in a connector configuration:

1. **name**: A friendly name for your chatbot connector, making it easy to identify.

2. **base_url**: The base URL of the chatbot API you want to connect to. This is the starting point for all API requests.

3. **send_message**: This section defines how to send messages to the chatbot API. It includes:
   - **path**: The specific endpoint path that will be appended to the base URL.
   - **method**: The HTTP method to use (e.g., POST, GET). If not specified, POST is the default.
   - **headers**: Any custom headers you need to include in your request (like authentication tokens).
   - **payload_template**: The structure of the message you want to send, often including placeholders like `{user_msg}` for dynamic content.

4. **response_path**: This is a dot-separated path that tells the connector how to extract the bot's reply from the JSON response it receives. It helps navigate through the response structure to find the relevant information.

### Example

Here’s a simple example of a connector configuration:

```yaml
name: "My Custom Bot"
base_url: "https://api.mychatbot.com"
send_message:
  path: "/chat"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

In this example:
- The connector is named "My Custom Bot".
- It connects to the API at `https://api.mychatbot.com/chat`.
- It sends a POST request with a message payload.
- The bot's response is extracted from the `response.text` field in the JSON response.
