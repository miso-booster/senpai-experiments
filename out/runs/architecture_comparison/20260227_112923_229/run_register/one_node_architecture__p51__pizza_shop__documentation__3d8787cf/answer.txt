In the context of Sensei and testing, an **oracle** is a mechanism or method used to determine whether the output of a system (like a chatbot) is correct or not. It acts as a reference point to validate the responses generated by the chatbot during testing.

In Sensei-check, oracles can be defined in your rules to specify the expected outcomes based on certain inputs. For example, if you have a rule that checks if a pizza order's price is correct, the oracle would state the condition that must be met for the output to be considered valid.

Here's a simple example of an oracle in a rule:

```yaml
name: price_check
description: Check that the price for a small pizza is at least $10
conversations: 1
oracle: extract_float(price) >= 10 and currency(price) == 'USD'
```

In this case, the oracle checks that the extracted price is greater than or equal to $10 and that the currency is USD. If the output meets these conditions, it passes the test! 🎉
