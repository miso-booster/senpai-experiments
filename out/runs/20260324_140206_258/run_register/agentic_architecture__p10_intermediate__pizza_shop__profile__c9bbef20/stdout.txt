Here are the details of the connectors that use **1millionbot** and a comparison with a **non-1millionbot** connector:

### 1millionbot Connectors

1. **Ada UAM**
   - **Base URL:** `https://api.1millionbot.com`
   - **Send Message Endpoint:**
     - **Path:** `/api/public/messages`
     - **Method:** `POST`
     - **Headers:**
       - `Content-Type: application/json`
       - `Authorization: 60a3bee2e3987316fed3218f`
     - **Payload Template:**
       ```json
       {
         "conversation": "682ce1ce271ce860cffde0fd",
         "sender_type": "User",
         "sender": "682ce1cefe831160cee700ed",
         "bot": "60a3be81f9a6b98f7659a6f9",
         "language": "es",
         "url": "https://www.uam.es/uam/tecnologias-informacion/servicios-ti/acceso-remoto-red",
         "message": {
           "text": "{user_msg}"
         }
       }
       ```
   - **Response Path:** `response.0.text`

### Non-1millionbot Connector

2. **Postman Echo**
   - **Base URL:** `https://postman-echo.com`
   - **Send Message Endpoint:**
     - **Path:** `/post`
     - **Method:** `POST`
     - **Payload Template:**
       ```json
       {
         "message": "{user_msg}"
       }
       ```
   - **Response Path:** `json.message`

### Comparison and Differences

- **Base URL:**
  - **Ada UAM:** Uses `https://api.1millionbot.com`
  - **Postman Echo:** Uses `https://postman-echo.com`

- **Send Message Endpoint:**
  - **Ada UAM:**
    - Path: `/api/public/messages`
    - Requires specific headers including `Authorization`.
    - Has a more complex payload with multiple fields including `conversation`, `sender_type`, `sender`, `bot`, `language`, and `url`.
  - **Postman Echo:**
    - Path: `/post`
    - No special headers required.
    - Simpler payload with just a single field for the message.

- **Response Path:**
  - **Ada UAM:** `response.0.text`
  - **Postman Echo:** `json.message`

### Summary of Differences
- The **Ada UAM** connector is more complex, requiring specific headers and a detailed payload structure, while the **Postman Echo** connector is simpler and does not require additional headers. The response paths are also different, reflecting the structure of the respective APIs.
