### Profile Structure
The profile will include:
- **User role**: Describing the user's situation and goals.
- **Goals**: Different methods the user could try to set up eduroam.
- **Chatbot output**: Fields to extract relevant information after the conversation.

### Proposed Profile YAML

Here's a draft of the profile:

```yaml
test_name: "eduroam_setup_user"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A user trying to set up eduroam on their device but facing difficulties."
  context:
    - "The user has a laptop and a smartphone."
    - "The user has tried multiple methods to connect."
  goals:
    - "Try setting up eduroam using the university's guide."
    - "Attempt to configure the network settings manually."
    - "Check if the device's Wi-Fi is enabled."
    - "Reach out to the IT support for assistance."
    - "Use the eduroam app for configuration."
    - "Look for troubleshooting tips online."

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you clarify that?"
  output:
    - setup_method:
        type: string
        description: "The method the user chooses to try for setting up eduroam."
    - success:
        type: boolean
        description: "Whether the user successfully connected to eduroam."
    - feedback:
        type: string
        description: "User's feedback on the setup process."

conversation:
  number: combinations(0.5, pairwise)
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - make spelling mistakes
      - single questions
```

- **Profile Name**: `eduroam_setup_user`
- **Goals**: Various methods the user can attempt to set up eduroam.
