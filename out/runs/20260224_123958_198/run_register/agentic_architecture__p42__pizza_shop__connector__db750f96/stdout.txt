I've loaded the relevant documentation for creating a custom connector. Here’s a summary of the key points from the `custom-connector-guide.md` and `connector-examples.md` files:

### Key Configuration Fields
- **name**: Friendly name for your chatbot (optional).
- **base_url**: The base URL of the chatbot API (required).
- **send_message.path**: The API endpoint path (required).
- **send_message.method**: HTTP method (default is POST).
- **send_message.headers**: Custom headers (optional).
- **send_message.payload_template**: JSON structure with a placeholder for the user's message (required).
- **response_path**: Path to extract the bot's reply from the JSON response (required).

### Example Structure
Here’s a basic example structure based on the documentation:

```yaml
name: "My Custom Bot"
base_url: "https://api.mychatbot.com"
send_message:
  path: "/chat"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

### Creating Your Connector
Based on your request, here's how the YAML connector would look for your specific API:

```yaml
name: "Alcampo Bot"
base_url: "https://alcampo.botslovers.com/bot/web"
send_message:
  path: "/"
  method: "POST"

    Content-Type: "application/json"

  payload_template:
    data:
      id_user: "{id_user}"
      idweb_user: "{idweb_user}"
      session: "{session}"
      message:
        message:
          text: "{user_msg}"
        iduser: "{id_user}"
        session: "{session}"
        channel: "web"
      widget_form: "TRUE"
      contexto_extra: []
      lang: "es"
      accion: "response_bot"
response_path: "messages.0.0.message.text"
```

### Explanation
- **name**: Set to "Alcampo Bot" for easy identification.
- **base_url**: Points to the API endpoint.
- **send_message.path**: The path for sending messages.
- **headers**: Includes necessary headers for the request.
- **payload_template**: Uses placeholders for dynamic values (like user ID and session).
- **response_path**: Specifies how to navigate the JSON response to get the bot's reply.
