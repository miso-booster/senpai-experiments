¡Claro! Aquí tienes un perfil que puedes usar para probar la capacidad del chatbot de Alcampo en recomendar recetas y ayudar con la planificación de menús. Este perfil está diseñado para simular un usuario que busca recetas saludables y opciones de planificación de comidas.

```yaml
test_name: "Recetas y Planificación de Menús"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A user looking for healthy recipes and meal planning assistance."
  context:
    - "You are interested in incorporating more vegetables and whole foods into your meals."
    - "You want to explore seasonal ingredients and easy-to-follow recipes."
  goals:
    - "Ask for healthy dinner recipes that include seasonal vegetables."
    - "Request a weekly meal plan that incorporates a variety of food groups."
    - "Inquire about quick and easy lunch ideas for busy weekdays."
    - "Ask for tips on meal prepping to save time during the week."
    - "Request information on how to create balanced meals."

chatbot:
  is_starter: false
  fallback: "Lo siento, no entendí tu pregunta. 😊 ¿Puedes reformularla? Estoy aquí para ayudarte con recetas y planificación de menús."
  output:
    - healthy_recipes:
        type: string
        description: "List of healthy recipes including seasonal vegetables."
    - meal_plan:
        type: string
        description: "Weekly meal plan incorporating a variety of food groups."
    - quick_lunch_ideas:
        type: string
        description: "Ideas for quick and easy lunches."
    - meal_prepping_tips:
        type: string
        description: "Tips on how to meal prep effectively."
    - balanced_meal_guidelines:
        type: string
        description: "Guidelines for creating balanced meals."

conversation:
  number: 5
  goal_style:
    steps: 10
  interaction_style:
    - random:
        - single questions
        - long phrases
```

### Explicación del perfil:
- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario y su contexto, así como los objetivos de la conversación.
- **chatbot**: Define el comportamiento del chatbot, incluyendo mensajes de retroalimentación y los datos que se espera extraer.
- **conversation**: Controla el número de interacciones y el estilo de interacción.

Puedes ajustar cualquier parte del perfil según tus necesidades específicas. ¡Espero que esto te ayude a probar el chatbot de Alcampo! Si necesitas más ajustes o tienes alguna otra pregunta, ¡no dudes en decírmelo! 😊
