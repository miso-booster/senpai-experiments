In the context of Sensei-check, an **oracle** is a condition or rule that defines what the expected outcome should be for a given conversation. It acts as a reference point to determine if the chatbot's responses are correct or not.

Oracles can be used in two main ways:

1. **Single-conversation oracles**: These check the correctness of a single conversation based on specific criteria. For example, you might have an oracle that verifies if the price returned by the chatbot is greater than a certain amount.

2. **Metamorphic oracles**: These compare outputs from multiple conversations to ensure that certain relationships hold true. For instance, if two conversations have the same input conditions, the oracle might assert that if one conversation has more toppings, it should also have a higher price.

In summary, oracles help validate the performance of your chatbot by defining what correct behavior looks like! 😊 If you have any specific examples or need help with oracles in your Sensei project, feel free to ask!
