I've loaded the documentation for SENSEI profiles from the file `sensei-chat-guide.md`. This guide provides a comprehensive overview of how to create user profiles, including the necessary sections and how they interact with the chatbot's outputs.

### Profile Structure Overview
Here's a brief outline of the key sections we need to include in the profile for the bike shop user:

1. **test_name**: A string to identify the profile.
2. **llm**: Configuration for the language model (optional).
3. **user**:
   - **language**: The language the user will communicate in.
   - **role**: A description of the user's context and behavior.
   - **context**: Any additional constraints or preferences.
   - **goals**: The specific objectives the user wants to achieve.
4. **chatbot**:
   - **is_starter**: Indicates if the chatbot starts the conversation.
   - **fallback**: A fallback message if the chatbot doesn't understand.
   - **output**: Fields that will be extracted after the conversation.
5. **conversation**: Controls how the conversation is structured.

### Proposed Profile for the Bike Shop User
Based on your description, here's a draft of the profile:

```yaml
test_name: "bike_shop_setup"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer who recently bought a new bike and wants to customize it."
  context:
    - "The user wants to change the seat and handlebar grips."
  goals:
    - "Request to have the bike set up with a new seat and handlebar grips."
    - "Ask for recommendations on seat types and grip materials."

chatbot:
  is_starter: true
  fallback: "Sorry, could you rephrase that?"
  output:
    - seat_type:
        type: string
        description: "Type of seat chosen for the bike."
    - grip_material:
        type: string
        description: "Material of the handlebar grips."
    - total_price:
        type: currency
        description: "Final price for the setup service."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Summary of the Profile
- **Purpose**: This profile simulates a user who wants to customize their new bike by changing the seat and handlebar grips.
- **Outputs**: It includes fields for the type of seat, grip material, and total price, which can be used in subsequent rules for validation.
