### Estructura del Perfil

El perfil que vamos a crear incluirá los siguientes campos en `chatbot.output` para obtener el número de teléfono, email, dirección física y horarios. Aquí tienes un ejemplo de cómo podría verse:

```yaml
test_name: "UAM_CAU_Support"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca soporte sobre el CAU de la UAM."
  context:
    - "El usuario necesita información sobre contacto y horarios."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Cuál es el email del CAU?"
    - "¿Dónde se encuentra el CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: true
  fallback: "Lo siento, no tengo esa información."
  output:
    - telefono:
        type: string
        description: "Número de teléfono del CAU."
    - email:
        type: string
        description: "Email del CAU."
    - direccion:
        type: string
        description: "Dirección física del CAU."
    - horarios:
        type: string
        description: "Horarios de atención del CAU."

conversation:
  number: 1
  goal_style:
    steps: 4
  interaction_style:
    - long phrases
    - single questions
```

### Descripción de los Campos

- **test_name**: Nombre del perfil para identificarlo.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el contexto y los objetivos del usuario.
- **chatbot**: Define cómo el chatbot debe comportarse y qué información debe extraer.
- **conversation**: Controla el número de interacciones y el estilo de interacción.
