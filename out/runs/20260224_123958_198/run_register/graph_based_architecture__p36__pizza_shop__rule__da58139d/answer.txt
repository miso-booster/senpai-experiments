Sure! To create a rule that checks if the price of a small pizza is $10, you'll want to follow the structure of a single-conversation oracle in Sensei-check. Here's how you can write that rule in YAML format:

```yaml
name: small_pizza_price_check
description: Small pizzas should cost exactly $10
conversations: 1
when: size == 'small'
oracle: extract_float(price) == 10 and currency(price) == 'USD'
```

### Breakdown of the Rule:
- **name**: A unique identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to 1 since this is a single-conversation check.
- **when**: This condition specifies that the rule applies when the size of the pizza is 'small'.
- **oracle**: This checks that the extracted price is exactly $10 and that the currency is USD.
