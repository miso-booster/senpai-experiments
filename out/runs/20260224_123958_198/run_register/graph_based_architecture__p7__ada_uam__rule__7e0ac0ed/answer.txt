```yaml
name: check_cau_information
description: Verifies that the CAU provides correct contact information
conversations: 1
if:   conv[0].contact_email == 'cau@uam.es' and
      conv[0].contact_phone == '91 497 4029' and
```

- **name**: A unique identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to 1 since we're checking a single conversation.
- **if**: This condition checks if the chatbot's outputs match the expected values for the email, phone number, and physical address.
- **then**: If the condition is met, it returns `True`, indicating that the information is correct.
