### Rule Overview: Same Number of Toppings Cost the Same

The rule **"same_number_of_toppings_cost_the_same"** checks if two pizzas with the same number of toppings and size cost the same. Here's how it works:

- **When**: The drinks of both orders are the same.
- **If**: The sizes of both pizzas are the same and they have the same number of toppings.
- **Then**: The prices of both pizzas should be equal.
