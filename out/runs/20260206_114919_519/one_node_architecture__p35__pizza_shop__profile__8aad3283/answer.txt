That sounds like a fun scenario to create! Here’s a profile that captures a user who starts by asking for a custom pizza but then changes their mind and requests a predefined pizza instead. 😊

```yaml
test_name: "custom_to_predefined_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer trying to order a pizza. Start by asking for a custom pizza, then change your mind and ask for a predefined pizza."
  context:
    - "You enjoy a variety of toppings but are unsure what to choose."
  goals:
    - "I would like to order a custom pizza with {{custom_toppings}}."
    - "Actually, can I get a {{predefined_pizza}} instead?"
    - custom_toppings:
        function: random()
        type: string
        data: [pepperoni, mushrooms, olives, bell peppers, onions]
    - predefined_pizza:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian]

chatbot:
  is_starter: false
  fallback: "Sorry, could you rephrase that?"
  output:
    - order_confirmation:
        type: string
        description: "Confirmation of the pizza order."

conversation:
  number: 2
  goal_style:
    steps: 5
  interaction_style:
    - long phrases
    - change your mind
```

This profile sets up a conversation where the user starts by expressing a desire for a custom pizza and then changes their mind to a predefined option. Feel free to modify the toppings or predefined pizzas as needed! 🍕
