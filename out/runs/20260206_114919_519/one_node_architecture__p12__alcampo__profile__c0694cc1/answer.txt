Sure! Here’s a profile that asks the chatbot for items to add to the user's shopping cart. You can customize the details as needed:

```yaml
test_name: "shopping_cart_addition"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer looking to add items to your shopping cart."
  context:
    - "You are shopping for groceries and want to add specific items."
  goals:
    - "Add {{item}} to my shopping cart."
    - "Can you suggest some {{category}} items to add?"
    - "What are the available options for {{item}}?"
    - "Please add {{quantity}} of {{item}} to my cart."
    - item:
        function: random()
        type: string
        data: [milk, bread, eggs, cheese, fruits, vegetables, snacks]
    - category:
        function: random()
        type: string
        data: [dairy, bakery, produce, snacks]
    - quantity:
        function: random(3)
        type: int
        data: [1, 2, 3, 4, 5]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Can you please repeat?"
  output:
    - added_items:
        type: list[string]
        description: "List of items added to the shopping cart"
    - total_items:
        type: int
        description: "Total number of items in the shopping cart"
    - confirmation_message:
        type: string
        description: "Confirmation message for added items"

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
```

Feel free to tweak the items, categories, and other details to better suit your project! 😊
