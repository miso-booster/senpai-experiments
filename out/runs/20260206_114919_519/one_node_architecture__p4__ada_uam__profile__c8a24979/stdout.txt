Aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "Soporte CAU UAM"

llm:

  model: gpt-4o
  model_prov: openai
  format:

    - "Consultar la dirección física del CAU."
    - "Preguntar por los horarios de atención del CAU."

  is_starter: true
  fallback: "Lo siento, no entendí tu solicitud. ¿Puedes reformularla?"
  output:
    - contact_email:
        type: string
        description: "Correo electrónico del CAU"
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"

    steps: 4
  interaction_style:
```

### Desglose del perfil:
- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario y los objetivos que quiere alcanzar.
- **chatbot**: Define la estructura de salida que se espera del chatbot, incluyendo los campos que se van a extraer.
- **conversation**: Controla el número de conversaciones y el estilo de interacción.
