In the context of Sensei-check and conversational testing, an **oracle** is a mechanism or rule that helps verify whether the output of a chatbot is correct based on certain conditions. It acts like a reference point to determine if the chatbot's responses meet the expected criteria.

For example, in a Sensei-check rule, an oracle might specify that if a user asks about the price of a pizza, the response should include a price that is greater than zero. If the chatbot's response meets this condition, it passes the oracle check; if not, it fails.

Oracles can be used in different ways:

1. **Single Conversation Oracle**: Checks the correctness of a single conversation.
2. **Metamorphic Oracle**: Compares multiple conversations to ensure that certain relationships hold true (like price monotonicity when adding toppings).

In summary, oracles are essential for validating the performance and accuracy of chatbots by providing a standard against which their outputs can be measured. If you have more specific questions about how to implement or use oracles in your Sensei project, feel free to ask! 😊
