¡Claro! Aquí tienes un perfil que puedes usar para probar la capacidad del chatbot de Alcampo en recomendar recetas y planificación de menús. Este perfil incluye metas específicas relacionadas con recetas y planificación de menús, así como los campos de salida que podrías necesitar.

```yaml
test_name: "recetas_y_planificacion_de_menus"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Español
  role: "Eres un cliente que busca recomendaciones de recetas y planificación de menús."
  context:
    - "Te gustan las recetas saludables y fáciles de preparar."
    - "Buscas ideas para cenas familiares y comidas rápidas."
  goals:
    - "Recomiéndame una receta para una cena saludable."
    - "¿Cuáles son los ingredientes necesarios para preparar un plato de pasta?"
    - "Ayúdame a planificar un menú para una semana."
    - "Sugiéreme recetas que incluyan pollo y verduras."
    - "¿Qué recetas son ideales para una cena rápida?"

chatbot:
  is_starter: false
  fallback: "Lo siento, no tengo esa información en este momento."
  output:
    - recipe_name:
        type: string
        description: "Nombre de la receta recomendada"
    - ingredients:
        type: list[string]
        description: "Lista de ingredientes necesarios"
    - preparation_steps:
        type: string
        description: "Instrucciones para preparar la receta"
    - menu_plan:
        type: string
        description: "Planificación del menú para la semana"

conversation:
  number: combinations(0.5, pairwise) # Usar combinaciones para cubrir diferentes interacciones
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - make spelling mistakes
```

Este perfil está diseñado para interactuar con el chatbot de Alcampo y probar su capacidad para ofrecer recomendaciones de recetas y planificación de menús. Puedes ajustarlo según tus necesidades específicas. ¡Espero que te sea útil! 😊
