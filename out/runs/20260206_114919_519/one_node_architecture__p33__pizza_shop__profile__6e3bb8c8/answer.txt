¡Claro! Aquí tienes un perfil para probar el chatbot de una pizzería. Este perfil está diseñado para extraer el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares. Espero que te sea útil 😊.

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza. Ask about available pizzas, drinks, and prices."
  goals:
    - "What types of pizza do you have?"
    - "What drinks are available?"
    - "Can I get the price for a pizza?"
    - "What is the final price for my order?"

chatbot:
  is_starter: true
  fallback: "Sorry, I didn't understand that."
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink:
        type: string
        description: "The drink chosen."
    - order_id:
        type: string
        description: "The unique identifier for the order."
    - final_price:
        type: currency
        description: "The final price of the order in dollars."

conversation:
  number: 2
  goal_style:
    steps: 4
  interaction_style:
    - long phrases
```

Si necesitas hacer algún ajuste o agregar más detalles, ¡házmelo saber! 🍕
