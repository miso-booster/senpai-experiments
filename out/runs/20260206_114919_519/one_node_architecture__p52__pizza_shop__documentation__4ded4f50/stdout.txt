Connectors are used to facilitate communication between your chatbot and external APIs. They allow your chatbot to send messages, receive responses, and interact with different services seamlessly. This is especially useful for integrating various functionalities, like retrieving data or processing user requests through different platforms.

### Key Fields in a Connector Configuration:

1. **name**: A friendly name for your chatbot connector (optional).
2. **base_url**: The base URL of the chatbot API (required).
3. **send_message**:
   - **path**: The specific endpoint path that will be appended to the base URL (required).
   - **method**: The HTTP method to use (e.g., POST, GET, PUT, DELETE) — defaults to POST if not specified.
   - **headers**: Any custom headers needed for the request (optional).
   - **payload_template**: The JSON structure that includes placeholders (like `{user_msg}`) for dynamic content (required).
4. **response_path**: A dot-separated path to extract the bot's reply from the JSON response (required).

These fields help define how your chatbot interacts with external services, ensuring smooth communication and data exchange. If you have any specific questions about creating or using connectors, feel free to ask! 😊
