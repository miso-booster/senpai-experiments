### Profile Structure
Here's a simple structure for the profile:

- **Test Name**: A descriptive name for the profile.
- **User Role**: Describes the simulated user.
- **Goals**: Specific objectives the user wants to achieve.

  language: English

  is_starter: true

        type: list[string]
        description: "List of benefits for each subscription."
    - pricing:
        type: currency
        description: "Pricing details for subscriptions."
    - cancellation_policy:
        type: string
        description: "Cancellation policies for subscriptions."
    - promotions:
        type: list[string]
        description: "Available promotional offers or discounts."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - random:
