¡Hola! 😊 He revisado la documentación sobre perfiles y estoy listo para crear el perfil que necesitas para probar el chatbot de la pizzería. Este perfil incluirá los campos que mencionaste: tipo de pizza, bebida, ID del pedido y precio final en dólares.

Aquí tienes el perfil propuesto:

```yaml
test_name: "pizza_order_profile"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza."
  goals:
    - "Order a {{pizza_type}} pizza with {{drink}} and get the total price."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Veggie, BBQ Chicken]
    - drink:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: true
  fallback: "Sorry, could you repeat that?"
  output:
    - pizza_type:
        type: string
        description: "Type of pizza ordered"
    - drink:
        type: string
        description: "Drink ordered"
    - order_id:
        type: string
        description: "Unique order identifier"
    - total_price:
        type: currency
        description: "Final price in dollars"
        
conversation:
  number: 5
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Resumen del perfil:
- **Nombre del perfil**: `pizza_order_profile`
- **Campos de salida**:
  - `pizza_type`: Tipo de pizza ordenada.
  - `drink`: Bebida ordenada.
  - `order_id`: Identificador único del pedido.
  - `total_price`: Precio final en dólares.
