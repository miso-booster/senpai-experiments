I've loaded the relevant documentation for SENSEI profiles from the `sensei-chat-guide.md`. Now, I can create a profile that captures the scenario where a user starts by asking for a custom pizza but then changes their mind and opts for a predefined pizza instead.

### Profile Structure
Here's a brief outline of how the profile will be structured:

- **Test Name**: A descriptive name for the profile.
- **User**: Defines the user's language, role, context, and goals.
- **Chatbot**: Specifies the chatbot's behavior, fallback messages, and output fields.
- **Conversation**: Controls the number of interactions and styles.

### Drafting the Profile
I'll create a profile that includes:
- A goal for asking for a custom pizza.
- A goal for switching to a predefined pizza.
- Outputs that capture the final decision and any relevant details.

Let's draft the YAML profile! 😊

```yaml
test_name: "pizza_order_profile"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza. You initially want to customize your pizza but may change your mind."
  context:
    - "You enjoy various toppings and have specific preferences."
  goals:
    - "Order a custom pizza with {{custom_toppings}}"
    - "Change to a predefined pizza: {{predefined_pizza}}"
    - custom_toppings:
        function: random()
        type: string
        data: [pepperoni, mushrooms, onions, sausage, bacon, extra cheese]
    - predefined_pizza:
        function: random()
        type: string
        data: [Margherita, Pepperoni, BBQ Chicken, Veggie]

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you clarify your order?"
  output:
    - final_order:
        type: string
        description: "The final pizza order chosen by the user"

conversation:
  number: combinations(0.5, pairwise)
  goal_style:
    steps: 5
  interaction_style:
    - change your mind
```

### Summary
- **Profile Name**: `pizza_order_profile`
- **User Goals**: Includes both custom and predefined pizza options.
- **Chatbot Output**: Captures the final order.
- **Interaction Style**: Allows the user to change their mind during the conversation.
