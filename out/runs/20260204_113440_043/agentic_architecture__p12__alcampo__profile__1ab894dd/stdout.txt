I've loaded the relevant documentation for SENSEI profiles from the `sensei-chat-guide.md`. Now, let's create a profile that asks the chatbot for items to add to the user's shopping cart. 

### Profile Structure
Here's a proposed structure for the profile:

- **Test Name**: A descriptive name for the profile.
- **User Role**: Describes the simulated user and their behavior.
- **Goals**: Specifies the items to be added to the shopping cart.
- **Chatbot Output**: Defines what information we want to extract after the conversation.

### Proposed YAML Profile
Here's the YAML content for the profile:

```yaml
test_name: "shopping_cart_profile"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer looking to add items to your shopping cart."
  context:
    - "You can add multiple items and specify quantities."
  goals:
    - "Add {{item}} to my shopping cart."
    - item:
        function: random()
        type: string
        data: [apples, bananas, bread, milk, eggs]

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you repeat that?"
  output:
    - cart_items:
        type: list[string]
        description: "List of items added to the shopping cart."

conversation:
  number: 5
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Summary of the Profile
- **Test Name**: `shopping_cart_profile` - identifies the purpose of the profile.
- **User Role**: Simulates a customer adding items to their cart.
- **Goals**: The user can add random items from a predefined list to the shopping cart.
- **Chatbot Output**: The profile specifies that the chatbot should return a list of items added to the cart.
