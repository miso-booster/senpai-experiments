### Reglas Sugeridas

Aquí hay algunas reglas que podrían ser útiles para tu perfil:

1. **Verificación de Salidas Requeridas**:
   - Asegúrate de que el chatbot devuelva todos los campos de información necesarios después de una conversación.

   ```yaml
   name: chatbot_fills_all_slots
   description: Todos los slots de conversación deben estar llenos con información relevante.
   conversations: 1
   oracle: data_collected() == True
   yields: "Faltan los siguientes slots: {missing_slots()}"
   ```

2. **Consistencia del Idioma**:
   - Verifica que el chatbot responda en español, ya que el usuario está configurado para comunicarse en ese idioma.

   ```yaml
   name: chatbot_responds_in_same_language
   description: El chatbot debe responder en español.
   conversations: 1
   oracle: responds_in_same_language()
   yields: "El chatbot no responde en el mismo idioma."
   ```

3. **Disponibilidad de Información sobre el Evento**:
   - Comprueba si el chatbot proporciona información sobre el evento Welcome Day.

   ```yaml
   name: welcome_day_info_available
   description: El chatbot debe proporcionar detalles sobre el evento Welcome Day.
   conversations: 1
   oracle: welcome_day_link is not None
   yields: "La información sobre el Welcome Day no está disponible."
   ```

4. **Requisitos de Admisión Proporcionados**:
   - Asegúrate de que el chatbot proporcione los requisitos de admisión cuando se le pregunte.

   ```yaml
   name: admission_requirements_info
   description: El chatbot debe proporcionar los requisitos de admisión para los grados.
   conversations: 1
   oracle: admission_requirements is not None
   yields: "Los requisitos de admisión no están proporcionados."
   ```
