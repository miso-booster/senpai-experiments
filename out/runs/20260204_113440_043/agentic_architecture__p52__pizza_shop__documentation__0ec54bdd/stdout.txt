Connectors in SENSEI are used to establish communication between your chatbot and external APIs without needing to write code. They allow you to define how your chatbot interacts with these APIs through a YAML configuration file.

### Key Fields in a Connector

Here are the essential fields you can include in a connector configuration:

| Field                          | Description                                                        | Required |
|--------------------------------|--------------------------------------------------------------------|----------|
| `name`                         | Friendly name for your chatbot                                     | No       |
| `base_url`                    | Base URL of the chatbot API                                       | Yes      |
| `send_message.path`           | API endpoint path (appended to `base_url`)                       | Yes      |
| `send_message.method`         | HTTP method (e.g., POST, GET, PUT, DELETE)                       | No (default: POST) |
| `send_message.headers`        | Custom headers (e.g., Authorization)                              | No       |
| `send_message.payload_template`| JSON structure with `{user_msg}` placeholder                     | Yes      |
| `response_path`               | Dot-separated path to extract the bot's reply from the JSON response | Yes      |

### Example of a Connector Configuration

Here's a simple example of a connector configuration for an echo bot:

```yaml
name: "Echo Bot"
base_url: "https://postman-echo.com"
send_message:
  path: "/post"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "json.message"
```

### Additional Notes
- The `response_path` field is crucial as it defines how to navigate through the JSON response to extract the bot's reply.
- You can customize headers for authentication if needed.

For more detailed examples and usage, you can refer to the documentation files: `custom-connector-guide.md` and `connector-examples.md`. If you have specific use cases in mind, feel free to ask! 😊
