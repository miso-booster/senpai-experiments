¡Hola! 😊 He revisado la documentación sobre perfiles y ahora puedo ayudarte a crear un perfil para el chatbot de la UAM que proporcione soporte sobre el CAU (Centro de Atención a Usuarios). Este perfil incluirá los campos necesarios para obtener el número de teléfono, email, dirección física y horarios.

### Estructura del Perfil

Aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "UAM_CAU_Support"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca soporte sobre el CAU."
  context:
    - "El usuario necesita información sobre el CAU."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Cuál es el email del CAU?"
    - "¿Dónde se encuentra físicamente el CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: false
  fallback: "Lo siento, no puedo ayudar con eso."
  output:
    - telefono:
        type: string
        description: "Número de teléfono del CAU."
    - email:
        type: string
        description: "Email del CAU."
    - direccion:
        type: string
        description: "Dirección física del CAU."
    - horarios:
        type: string
        description: "Horarios de atención del CAU."

conversation:
  number: 1
  goal_style:
    steps: 4
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Descripción del Perfil

- **test_name**: Nombre del perfil para identificarlo.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el lenguaje, rol y contexto del usuario.
- **goals**: Lista de preguntas que el usuario puede hacer sobre el CAU.
- **chatbot.output**: Campos que se extraerán al final de la conversación, como el número de teléfono, email, dirección y horarios.
- **conversation**: Define el número de interacciones y el estilo de interacción.
