¡Claro! Vamos a crear un perfil para que puedas testear el chatbot de la UAM en el contexto de soporte del CAU. Aquí tienes un ejemplo de cómo podría verse tu perfil en YAML:

```yaml
test_name: "Soporte CAU - Información de Contacto"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca información sobre el CAU y necesita detalles de contacto."
  context:
    - "Como usuario, necesito obtener información sobre cómo contactar al CAU."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico de contacto del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar sobre los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "¿Puedes repetir la pregunta de otra forma? O, si lo prefieres, consulta nuestro catálogo de servicios."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU."
    - contact_email:
        type: string
        description: "Correo electrónico del CAU."
    - physical_address:
        type: string
        description: "Dirección física del CAU."
    - service_hours:
        type: string
        description: "Horarios de atención del CAU."

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

### Desglose del perfil:
- **test_name**: Un nombre descriptivo para tu perfil.
- **llm**: Configuración del modelo de lenguaje que se usará.
- **user**: Define el rol del usuario y el contexto de la conversación.
- **goals**: Las preguntas específicas que el usuario hará al chatbot.
- **chatbot**: Define el comportamiento del chatbot, incluyendo su mensaje de fallback y los datos que se quieren extraer.
- **conversation**: Controla el número de interacciones y el estilo de la conversación.

Puedes ajustar los detalles según tus necesidades. ¡Espero que esto te ayude a empezar! Si necesitas más cambios o detalles, ¡dímelo! 😊
