¡Claro! Aquí tienes un perfil de ejemplo para probar el chatbot de una pizzería. Este perfil incluye los campos de salida que solicitaste: tipo de pizza, bebida, ID del pedido y precio final en dólares. Puedes copiarlo y ajustarlo según tus necesidades:

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza."
  context:
    - "You prefer vegetarian options."
  goals:
    - "Order a {{pizza_type}} pizza with {{toppings}}."
    - "I would like a {{drink}}."
    - "How much will it cost?"
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Veggie, Hawaiian]
    - toppings:
        function: random(2)
        type: list
        data: [mushrooms, olives, bell peppers, onions]
    - drink:
        function: random()
        type: string
        data: [Coke, Sprite, Water]

chatbot:
  is_starter: false
  fallback: "I'm sorry, could you repeat that?"
  output:
    - pizza_type:
        type: string
        description: "Type of pizza ordered"
    - drink:
        type: string
        description: "Beverage ordered"
    - order_id:
        type: string
        description: "Order identifier"
    - total_price:
        type: currency
        description: "Final price in dollars"

conversation:
  number: 2
  goal_style:
    steps: 3
  interaction_style:
    - long phrases
    - make spelling mistakes
```

### Explicación de los campos:
- **test_name**: Nombre del perfil de prueba.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario y sus objetivos al interactuar con el chatbot.
- **chatbot**: Configura el comportamiento del chatbot y los datos que se desean extraer al final de la conversación.
- **conversation**: Establece el número de interacciones y el estilo de interacción.

¡Espero que esto te ayude a comenzar! Si necesitas más ajustes o detalles, no dudes en decírmelo 😊.
