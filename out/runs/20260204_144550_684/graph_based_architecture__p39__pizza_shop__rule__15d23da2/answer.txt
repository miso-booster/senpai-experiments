Sure! To create a rule that checks if the order ID was provided by the chatbot, you can define a simple oracle rule. Here’s how it would look in YAML format:

```yaml
name: order_id_provided
description: The chatbot must return an order ID
conversations: 1
oracle: 'order_id' in chatbot.output'
```

### Explanation:
- **name**: This is a unique identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: This rule checks a single conversation.
- **oracle**: This checks if the `order_id` field is present in the chatbot's output.
