Absolutely! To ensure that your chatbot responds in the same language as the user, you can create a metamorphic rule that checks the language consistency across conversations. 

Here's a sample rule you can use:

```yaml
name: language_consistency
description: Assistant responds in the same language as the user
conversations: 2
when: conv[0].language == conv[1].language
oracle: language(conv[0].chatbot_phrases) == conv[0].language and language(conv[1].chatbot_phrases) == conv[1].language
```

### Explanation:
- **name**: This is the name of your rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: This rule checks pairs of conversations (2).
- **when**: This condition ensures that both conversations are in the same language.
- **oracle**: This checks that the assistant's responses in both conversations are in the same language as specified.

Make sure to adapt the `language` checks according to your specific implementation. If you have any questions or need further adjustments, feel free to ask! 😊
