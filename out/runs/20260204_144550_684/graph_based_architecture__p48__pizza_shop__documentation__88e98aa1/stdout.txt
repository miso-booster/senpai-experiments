Great question! 😊 In the context of Sensei, a **metamorphic rule** is a specific type of rule used in **Sensei-check** that helps verify the correctness of conversations generated by your chatbot. 

Here's a simple breakdown:

1. **Definition**: A metamorphic rule states a condition to check over sets of conversations. It allows you to compare pairs or tuples of conversations to see how outputs should change (or not) when inputs change.

2. **Purpose**: The main goal is to alleviate the oracle problem, which is the challenge of determining whether the outputs of a chatbot are correct. Instead of checking for absolute answers, metamorphic rules focus on checking relationships between outputs based on specific input conditions.

3. **How It Works**:
   - You generate conversations using Sensei-chat.
   - You write rules in YAML format that specify how many conversations to compare, any filters to select eligible conversations, and the relationships you want to check.
   - Sensei-check evaluates these rules and reports any failing cases.

For example, you might have a rule that checks if adding more toppings to a pizza should always increase the price, given that other factors (like size and drink) remain the same.

This approach helps ensure that your chatbot behaves consistently and correctly across different scenarios! If you have more questions or need examples, feel free to ask! 😊
