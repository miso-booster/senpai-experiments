Absolutely! Let's create a profile for a user who wants to set an appointment to have their wheels changed at the bike shop. We'll include variables to test different dates and times to see how well the chatbot manages these requests. Here’s a sample profile for you:

```yaml
test_name: "wheel_change_appointment"

llm:
  temperature: 0.5
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "You are a customer looking to set an appointment to have your bike wheels changed."
  context:
    - "You want to know the available dates and times for the appointment."
  goals:
    - "I would like to set an appointment for wheel change on {{appointment_date}} at {{appointment_time}}."
    - appointment_date:
        function: random()
        type: string
        data: [tomorrow, "November 6th, 2024", "November 7th, 2024", "November 8th, 2024"]
    - appointment_time:
        function: random()
        type: string
        data: ["10:00 AM", "1:00 PM", "3:00 PM", "5:30 PM"]

chatbot:
  is_starter: true
  fallback: "I'm sorry, I didn't catch that. Could you please repeat?"
  output:
    - confirmed_date:
        type: date
        description: "The date of the appointment confirmed by the assistant."
    - confirmed_time:
        type: string
        description: "The time of the appointment confirmed by the assistant."
    - confirmed_service:
        type: string
        description: "The service to be performed during the appointment."

conversation:
  number: 4
  goal_style:
    all_answered:
      export: true
      limit: 5
  interaction_style:
    - default
```

### Breakdown of the Profile:
- **Test Name**: This is a unique identifier for your test.
- **LLM Configuration**: Sets the model and temperature for the chatbot's responses.
- **User Role**: Describes the user's intent and context.
- **Goals**: Includes a main goal for setting an appointment with variables for the appointment date and time.
- **Chatbot Output**: Defines what the chatbot should confirm at the end of the interaction.
- **Conversation Controls**: Specifies the number of conversations and how the goals should be structured.

Feel free to modify any part of this profile to better fit your needs! Happy testing! 🚴‍♂️✨
