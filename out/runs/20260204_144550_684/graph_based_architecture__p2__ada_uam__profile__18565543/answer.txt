Creating a profile for an Erasmus user who needs help setting up their Moodle and Sigma accounts sounds like a great idea! Let's structure a simple profile that captures the essence of their needs while ensuring we have the necessary outputs for validation. Here’s a basic example you can use:

```yaml
test_name: "Erasmus User Setup Assistance"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Erasmus student needing help with account setups."
  context:
    - "You are new to the university and need guidance on how to set up your Moodle and Sigma accounts."
    - "You might also have questions about accessing other digital services."
  goals:
    - "Solicitar ayuda para configurar mi cuenta de Moodle."
    - "Pedir instrucciones para acceder a Sigma."
    - "Consultar sobre otros servicios digitales disponibles."

chatbot:
  is_starter: false
  fallback: "¿Puedes repetir la pregunta de otra forma? O, si lo prefieres, consulta nuestro catálogo de servicios."
  output:
    - moodle_setup_info:
        type: string
        description: "Instrucciones para configurar la cuenta de Moodle."
    - sigma_access_info:
        type: string
        description: "Pasos para acceder a Sigma."
    - digital_services_info:
        type: string
        description: "Información sobre otros servicios digitales disponibles."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

### Breakdown of the Profile:
- **Test Name**: A clear title for your test scenario.
- **LLM Settings**: Specifies the model and temperature for the conversation.
- **User Section**: Defines the user’s language, role, context, and goals. The goals are specific to the assistance they need.
- **Chatbot Section**: Contains the fallback message and defines the outputs you want to validate after the conversation.
- **Conversation Controls**: Sets the number of interactions and the style of questions.
