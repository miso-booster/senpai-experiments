Now, let's create a complete Python script that uses this connector to send multiple requests. Here’s a simple example using the `requests` library:

```python
import requests
import json

# Define the connector configuration
connector_config = {
    "base_url": "https://api.1millionbot.com",
    "path": "/api/public/messages",
    "headers": {
        "Content-Type": "application/json",
        "Authorization": "64e5d1af081211d24e2cfecd",
        "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/201001101 Firefox/147.0",
        "Accept": "*/*",
        "Accept-Language": "en-US,en;q=0.9",
        "Accept-Encoding": "gzip, deflate, br, zstd",
        "Referer": "https://saic.malaga.eu/",
        "Origin": "https://saic.malaga.eu",
        "Sec-GPC": "1",
        "Connection": "keep-alive",
        "Sec-Fetch-Dest": "empty",
        "Sec-Fetch-Mode": "cors",
        "Sec-Fetch-Site": "cross-site",
        "Priority": "u=4",
        "Pragma": "no-cache",
        "Cache-Control": "no-cache"
    }
}

# Function to send a message
def send_message(user_msg):
    payload = {
        "conversation": "6977595c744ccf01954b8797",
        "sender_type": "User",
        "sender": "6977595c3e4824018e496b0c",
        "bot": "64e5d1af081211d24e2cfec8",
        "language": "es",
        "url": "https://saic.malaga.eu/",
        "message": {
            "text": user_msg
        }
    }

    response = requests.post(
        f"{connector_config['base_url']}{connector_config['path']}",
        headers=connector_config['headers'],
        data=json.dumps(payload)
    )

    return response.json()

# Sending multiple requests
messages = ["hola", "¿cómo estás?", "¿qué tal?"]
for msg in messages:
    response = send_message(msg)
    print(f"Response for '{msg}': {response}")
```

### Explanation:
1. **YAML Connector**: This defines how to communicate with the API, including headers and the payload structure.
2. **Python Script**: 
   - It uses the `requests` library to send POST requests to the API.
   - The `send_message` function constructs the payload and sends the request.
   - It loops through a list of messages, sending each one and printing the response.
