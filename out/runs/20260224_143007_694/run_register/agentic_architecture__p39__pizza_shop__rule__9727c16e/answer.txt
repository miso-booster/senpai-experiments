To create a rule that checks if the `order_id` was provided by the chatbot, we can define a metamorphic rule in YAML format. This rule will verify that the `order_id` field is present in the chatbot's output.

Here's how the rule would look:

```yaml
name: order_id_provided
description: Checks if the chatbot provides an order ID in the order summary.
conversations: 1
oracle: order_id is not None
```

### Explanation:
- **name**: A unique identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Specifies that this rule applies to a single conversation.
- **oracle**: The condition being checked, which in this case verifies that the `order_id` is not `None`.

### Relation to Profile:
This rule is designed to work with the `pizza_and_drink_order_placement.yaml` profile, which includes the `order_id` in its `chatbot.output`. The rule ensures that when the chatbot processes an order, it must provide an `order_id` as part of the output.
