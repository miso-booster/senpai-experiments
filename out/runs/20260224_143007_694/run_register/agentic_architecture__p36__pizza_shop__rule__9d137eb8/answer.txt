To create a rule that checks if the price of a small pizza is $10, we need to ensure that the rule aligns with the outputs defined in the relevant SENSEI Chat profile. 

### Key Points from the Documentation:
1. **Rule Structure**: The rule must specify conditions and actions based on the profile's `chatbot.output` fields.
2. **Profile Outputs**: The rule should reference existing fields in the profile's output, such as `size` and `price`.

### Proposed Rule
Based on the documentation, here's a rule that checks if the price of a small pizza is at least $10:

```yaml
name: small_pizza_price_check
description: Checks that the price of a small pizza is at least $10.
active: true
conversations: 1
when: size == 'small'
oracle: extract_float(price) >= 10 and currency(price) == 'USD'
```

### Explanation:
- **name**: A unique identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **active**: Indicates whether the rule is currently active.
- **conversations**: Specifies that this rule applies to a single conversation.
- **when**: The condition that checks if the pizza size is 'small'.
- **oracle**: The condition that checks if the extracted price is at least $10 and is in USD.
