¡Hola! 😊 He revisado la documentación sobre perfiles, y ahora puedo ayudarte a crear un perfil para el chatbot de la UAM que permita a los usuarios obtener soporte sobre el CAU (Centro de Atención a Usuarios). 

### Estructura del Perfil

El perfil incluirá los siguientes elementos en `chatbot.output`:
- **número de teléfono**
- **email**
- **dirección física**
- **horarios**

### Propuesta de Perfil

Aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "UAM_CAU_Support"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca soporte del CAU de la UAM."
  context:
    - "El usuario necesita información sobre contacto y horarios del CAU."
  goals:
    - "Obtener el número de teléfono del CAU."
    - "Obtener el email del CAU."
    - "Obtener la dirección física del CAU."
    - "Obtener los horarios de atención del CAU."

chatbot:
  is_starter: true
  fallback: "Lo siento, no pude encontrar esa información."
  output:
    - telefono:
        type: string
        description: "Número de teléfono del CAU."
    - email:
        type: string
        description: "Email de contacto del CAU."
    - direccion:
        type: string
        description: "Dirección física del CAU."
    - horarios:
        type: string
        description: "Horarios de atención del CAU."

conversation:
  number: 1
  goal_style:
    steps: 4
  interaction_style:
    - long phrases
```

### Explicación

- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el contexto y los objetivos del usuario.
- **chatbot.output**: Define los campos que se extraerán al final de la conversación.
- **conversation**: Controla el número de interacciones y el estilo de interacción.
