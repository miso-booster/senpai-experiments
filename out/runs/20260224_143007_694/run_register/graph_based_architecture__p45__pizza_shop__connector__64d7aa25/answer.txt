¡Claro! Aquí tienes el nuevo conector adaptado para el chatbot del Ayuntamiento de Morón de la Frontera, siguiendo la estructura que proporcionaste para Ada UAM. Solo he cambiado los valores necesarios para que se ajusten a la nueva API:

```yaml
name: "Ayuntamiento Morón de la Frontera"
description: "Connector for Ayuntamiento Morón de la Frontera"
conversations: 1
oracle: "response.0.text is not None"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "65ca19e7dbbb4e26cbeadf28"  # Cambia esto si es necesario
  payload_template:
    conversation: "67ea76f4e213b2dcbc146e2b"  # ID de conversación
    sender_type: "User"
    sender: "67ea76f40643a3dd27e59411"  # ID del usuario
    bot: "65ca19e7dbbb4e26cbeadf24"  # ID del bot
    language: "es"
    url: "https://www.morondelafrontera.es/"
    message:
      text: "{user_msg}"
```

### Notas:
- Asegúrate de que los IDs de conversación, usuario y bot sean correctos y estén actualizados.
- Revisa que la URL y el token de autorización sean válidos y tengan los permisos necesarios para interactuar con la API.
- Puedes probar este conector para asegurarte de que funcione correctamente con el chatbot del Ayuntamiento.
