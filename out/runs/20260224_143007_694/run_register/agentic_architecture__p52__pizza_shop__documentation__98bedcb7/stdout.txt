Connectors in SENSEI are used to integrate chatbots with external APIs without the need for coding. You create a YAML configuration file that specifies how to communicate with the chatbot's API. Here’s a breakdown of the key aspects and fields of connectors:

### Purpose of Connectors
- **Integration**: Connectors allow chatbots to send and receive messages from external APIs.
- **Configuration**: They provide a structured way to define the API endpoints, methods, and payloads.

### Key Configuration Fields
Here are the main fields you can include in a connector's YAML configuration:

| Field                       | Description                                                  | Required          |
|-----------------------------|--------------------------------------------------------------|-------------------|
| `name`                      | Friendly name for your chatbot                               | No                |
| `base_url`                 | Base URL of the chatbot API                                  | Yes               |
| `send_message.path`        | API endpoint path (appended to base_url)                    | Yes               |
| `send_message.method`      | HTTP method (POST, GET, PUT, DELETE)                        | No (default: POST)|
| `send_message.headers`     | Custom headers (e.g., Authorization)                         | No                |
| `send_message.payload_template` | JSON structure with `{user_msg}` placeholder           | Yes               |
| `response_path`            | Dot-separated path to extract the bot's reply from JSON response | Yes            |

### Example Connector Configuration
Here’s a simple example of a connector configuration:

```yaml
name: "My Custom Bot"
base_url: "https://api.mychatbot.com"
send_message:
  path: "/chat"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

### How `response_path` Works
The `response_path` field is used to navigate through the JSON response from the API. For example:
- `"message"` → `response["message"]`
- `"data.text"` → `response["data"]["text"]`
