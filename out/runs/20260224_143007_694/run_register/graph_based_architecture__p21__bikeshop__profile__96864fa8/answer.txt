Sure thing! Here’s a profile you can use to test a bike shop chatbot for a user who wants to set an appointment to have their wheels changed. This profile includes different variables for testing various days and times. Feel free to tweak it as needed! 🚴‍♂️✨

```yaml
test_name: "wheel_change_appointment"

llm:
  temperature: 0.5
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer looking to set an appointment to have their wheels changed."
  context:
    - "You want to ensure your bike is ready for the upcoming season."
    - "You prefer to schedule the appointment for a convenient time."
  goals:
    - "Schedule an appointment to change my wheels on {{appointment_date}} at {{appointment_time}}."
    - appointment_date:
        function: random()
        type: string
        data: [tomorrow, "next Monday", "next Wednesday", "next Friday"]
    - appointment_time:
        function: random()
        type: string
        data: ["10:00 AM", "1:00 PM", "3:00 PM", "5:30 PM"]

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you repeat that?"
  output:
    - appointment_confirmation:
        type: string
        description: "Confirmation of the scheduled appointment, including date and time."

conversation:
  number: 4
  goal_style:
    all_answered:
      export: true
      limit: 5
  interaction_style:
    - default
```

### Breakdown of the Profile:
- **Test Name**: Clearly identifies the purpose of the profile.
- **User Role & Context**: Sets the scenario for the user who wants to schedule an appointment.
- **Goals**: Specifies the main goal of scheduling an appointment with variables for different dates and times.
- **Chatbot Output**: Defines what the chatbot should confirm after the appointment is scheduled.
- **Conversation Controls**: Ensures multiple interactions are tested, with an export option for the results.

This should give you a solid foundation for testing how well the chatbot handles appointment scheduling! If you need any more adjustments or additional features, just let me know! 😊
