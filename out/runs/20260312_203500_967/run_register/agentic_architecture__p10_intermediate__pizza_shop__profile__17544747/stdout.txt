Here are the connectors that use **1millionbot** and their respective endpoints, along with a comparison against a non-1millionbot connector:

### 1millionbot Connectors

1. **Ada UAM**
   - **Base URL:** `https://api.1millionbot.com`
   - **Send Message Endpoint:**
     - **Path:** `/api/public/messages`
     - **Method:** `POST`
     - **Headers:**
       - `Content-Type: application/json`
       - `Authorization: 60a3bee2e3987316fed3218f`
     - **Payload Template:**
       ```json
       {
         "conversation": "682ce1ce271ce860cffde0fd",
         "sender_type": "User",
         "sender": "682ce1cefe831160cee700ed",
         "bot": "60a3be81f9a6b98f7659a6f9",
         "language": "es",
         "url": "https://www.uam.es/uam/tecnologias-informacion/servicios-ti/acceso-remoto-red",
         "message": {
           "text": "{user_msg}"
         }
       }
       ```
   - **Response Path:** `response.0.text`

### Non-1millionbot Connector

2. **Echo Bot**
   - **Base URL:** `https://postman-echo.com`
   - **Send Message Endpoint:**
     - **Path:** `/post`
     - **Method:** `POST`
     - **Payload Template:**
       ```json
       {
         "message": "{user_msg}"
       }
       ```
   - **Response Path:** `json.message`

### Comparison of Differences

| Feature                     | Ada UAM (1millionbot)                                | Echo Bot (Non-1millionbot)                     |
|-----------------------------|------------------------------------------------------|------------------------------------------------|
| **Base URL**                | `https://api.1millionbot.com`                        | `https://postman-echo.com`                     |
| **Send Message Path**       | `/api/public/messages`                               | `/post`                                        |
| **Method**                  | `POST`                                               | `POST`                                         |
| **Headers**                 | - `Content-Type: application/json`<br>- `Authorization: <token>` | - No specific headers required                  |
| **Payload Structure**       | Complex structure with multiple fields (e.g., `conversation`, `sender`, `bot`, `language`, `url`) | Simple structure with a single field (`message`) |
| **Response Path**           | `response.0.text`                                   | `json.message`                                 |

### Summary of Differences
- The **Ada UAM** connector has a more complex payload structure with multiple fields, including authorization and conversation details, while the **Echo Bot** has a simpler payload with just a message field.
- The **Ada UAM** connector requires specific headers, including an authorization token, which is not needed for the **Echo Bot**.
- The response paths differ in structure, reflecting the different APIs they interact with.
