Great question! 😊 In the context of Sensei, a **metamorphic rule** is a specific type of rule used in testing conversational AI. It allows you to check the relationships between pairs or tuples of conversations rather than just looking at individual responses. This approach helps to address the oracle problem, which is the challenge of determining whether the output of a system is correct.

Here's a simple breakdown of how it works:

1. **Generate Conversations**: First, you create conversations using Sensei-chat, which includes various inputs and outputs.

2. **Write Metamorphic Rules**: You then define rules in YAML format that specify:
   - How many conversations to compare (usually at least two).
   - Conditions to filter which conversations are relevant for the comparison (using the `when` clause).
   - The expected relationship between the outputs of those conversations (using `if` and `then` clauses).

3. **Evaluation**: Sensei-check evaluates these rules against the generated conversations and reports any failures.

For example, a metamorphic rule might state that if two pizzas have the same size and drink, the one with more toppings should cost more. This way, you can ensure that the pricing logic is consistent across different scenarios! 🍕✨
