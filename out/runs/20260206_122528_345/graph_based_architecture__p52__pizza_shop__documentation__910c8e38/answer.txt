Connectors are super handy tools that allow you to connect your chatbot to various APIs without needing to write any code! They facilitate communication between your chatbot and external services, enabling it to send and receive messages seamlessly.

### Key Fields in Connectors

Here are the main fields you’ll typically find in a connector configuration:

1. **name**: A friendly name for your chatbot. This helps identify the connector easily.

2. **base_url**: The base URL of the chatbot API. This is where all your requests will be sent.

3. **send_message**:
   - **path**: The specific API endpoint path that will be appended to the base URL.
   - **method**: The HTTP method used for the request (e.g., POST, GET). If not specified, it defaults to POST.
   - **headers**: Any custom headers that need to be included in the request (like authorization tokens).
   - **payload_template**: The JSON structure that defines the message being sent, often including a placeholder like `{user_msg}` for the user's input.

4. **response_path**: This field specifies how to navigate through the JSON response from the API to extract the chatbot's reply. It uses dot notation to indicate the path to the desired data.

### Example of a Simple Connector

Here’s a quick example of what a connector might look like:

```yaml
name: "Echo Bot"
base_url: "https://postman-echo.com"
send_message:
  path: "/post"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "json.message"
```

In this example, the connector is set up to send messages to an echo service that simply returns the message it receives.

Connectors make it easy to integrate your chatbot with various services, enhancing its capabilities and allowing for more dynamic interactions! If you have any more questions or need help with a specific connector, feel free to ask! 😊
