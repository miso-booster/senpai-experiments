¡Claro! Vamos a crear un perfil para el chatbot de la UAM que se enfoque en obtener soporte del CAU. Este perfil incluirá las metas que mencionaste: obtener el número de teléfono, email, dirección física y horarios del CAU. Aquí tienes un ejemplo de cómo podría verse el perfil en formato YAML:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca soporte del Centro de Atención a Usuarios (CAU)."
  context:
    - "Necesito información sobre cómo contactar al CAU para resolver mis dudas."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico de contacto del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar sobre los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU."
    - contact_email:
        type: string
        description: "Correo electrónico de contacto del CAU."
    - physical_address:
        type: string
        description: "Dirección física del CAU."
    - service_hours:
        type: string
        description: "Horarios de atención del CAU."

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

### Desglose del perfil:
- **test_name**: Nombre del perfil para identificarlo fácilmente.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el contexto y las metas del usuario.
- **chatbot**: Contiene la información que queremos extraer (número de teléfono, email, dirección y horarios).
- **conversation**: Define el número de interacciones y el estilo de interacción.

Puedes ajustar cualquier parte de este perfil según tus necesidades. ¡Espero que esto te ayude a empezar! Si necesitas más cambios o detalles, no dudes en decírmelo 😊.
