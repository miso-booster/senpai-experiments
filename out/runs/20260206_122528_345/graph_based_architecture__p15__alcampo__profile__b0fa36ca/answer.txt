¡Claro! 😊 Aquí tienes un ejemplo de perfil que puedes usar para probar la capacidad del chatbot de Alcampo para recomendar recetas y ayudar con la planificación de menús. Puedes ajustarlo según tus necesidades específicas:

```yaml
test_name: "Recetas y Planificación de Menús"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A user looking for recipe recommendations and meal planning assistance."
  context:
    - "You are interested in healthy recipes that are easy to prepare."
    - "You want to explore seasonal ingredients and dietary preferences."
  goals:
    - "Ask for recipe suggestions based on seasonal ingredients."
    - "Request a meal plan for a week including breakfast, lunch, and dinner."
    - "Inquire about healthy snacks to include in your meal plan."
    - "Ask for tips on meal prep and storage for the week."
    - "Request information on any special dietary options available."

chatbot:
  is_starter: false
  fallback: "Lo siento, no entendí tu solicitud. ¿Puedes reformularla? Estoy aquí para ayudarte con recetas y planificación de menús."
  output:
    - recipe_suggestions:
        type: string
        description: "Suggestions for recipes based on seasonal ingredients."
    - meal_plan:
        type: string
        description: "A detailed meal plan for the week."
    - healthy_snacks:
        type: string
        description: "List of healthy snacks to include in the meal plan."
    - meal_prep_tips:
        type: string
        description: "Tips for meal preparation and storage."
    - dietary_options:
        type: string
        description: "Information on special dietary options available."

conversation:
  number: 5
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```

Este perfil está diseñado para interactuar con el chatbot y evaluar su capacidad para ofrecer recetas y ayudar en la planificación de menús. Puedes ejecutarlo y ver cómo responde el chatbot a tus consultas. ¡Espero que te sea útil! Si necesitas más ajustes o detalles, no dudes en decírmelo. 🍽️✨
