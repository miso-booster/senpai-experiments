```yaml
test_name: "bike_customization_request"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer who recently purchased a new bike and wants to customize it."
  context:
    - "You want to change the seat and handlebar grips to better suit your preferences."
    - "You are looking for advice on the best options available."
  goals:
    - "Ask about the available seat options for customization."
    - "Inquire about the different handlebar grips that can be installed."
    - "Request recommendations for the best seat and grips based on comfort."
    - "Ask how long the customization process will take."
    - "Confirm the price for the customization service."
    - seat_options:
        function: forward()
        type: string
        data: [standard seat, gel seat, racing seat, comfort seat]
    - grip_options:
        function: forward()
        type: string
        data: [foam grips, rubber grips, ergonomic grips, leather grips]

chatbot:
  is_starter: false
  fallback: "I'm sorry, could you repeat that?"
  output:
    - customization_price:
        type: money
        description: "The total cost for changing the seat and handlebar grips."
    - customization_time:
        type: string
        description: "Estimated time required for the customization."
    - available_seat_options:
        type: string
        description: "List of available seat options for the bike."
    - available_grip_options:
        type: string
        description: "List of available handlebar grip options."

conversation:
  number: 5
  goal_style:
    all_answered:
      export: true
      limit: 5
  interaction_style:
    - single questions
```

### Breakdown:
- **Role and Context**: The user is defined as someone who has recently bought a bike and wants to customize it.
- **Goals**: The goals include asking about seat and grip options, seeking recommendations, and confirming prices and timeframes.
- **Chatbot Output**: The output fields are designed to capture the necessary information about customization options and costs.
