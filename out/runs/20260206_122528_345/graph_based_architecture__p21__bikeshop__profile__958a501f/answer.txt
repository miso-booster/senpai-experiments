Sure! Here's a profile that simulates a user wanting to set an appointment to have their wheels changed at a bike shop. This profile includes variables for different days and times to thoroughly test how the chatbot manages appointments. 

Feel free to customize any part of it to better fit your needs! 😊

```yaml
test_name: "wheel_change_appointment"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer looking to set an appointment for changing bike wheels."
  context:
    - "You want to ensure your bike is ready for your upcoming rides."
    - "You have specific days and times in mind for the appointment."
  goals:
    - "I'd like to schedule an appointment to change my wheels on {{appointment_date}} at {{appointment_time}}."
    - "Can I come in on {{alternative_date}} instead?"
    - "What time do you have available on {{another_date}}?"
    - appointment_date:
        function: random()
        type: string
        data: [tomorrow, "next Monday", "next Wednesday", "this Friday"]
    - appointment_time:
        function: random()
        type: string
        data: ["10:00 AM", "2:00 PM", "3:30 PM", "11:30 AM"]
    - alternative_date:
        function: random()
        type: string
        data: ["next Tuesday", "next Thursday", "this Saturday"]
    - another_date:
        function: random()
        type: string
        data: ["next Monday", "this Sunday", "tomorrow"]

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you repeat that? I didn't quite catch it."
  output:
    - appointment_confirmation:
        type: string
        description: "Confirmation of the scheduled appointment, including date and time."
    - available_times:
        type: string
        description: "List of available times for appointments."
    - reschedule_response:
        type: string
        description: "Response when the user asks to reschedule their appointment."

conversation:
  number: 5
  goal_style:
    all_answered:
      export: true
      limit: 5
  interaction_style:
    - random:
      - single questions
      - long phrases
      - change your mind
```

### Explanation:
- **Goals**: The user has multiple goals to test different appointment dates and times.
- **Variables**: The `appointment_date`, `appointment_time`, `alternative_date`, and `another_date` variables allow for testing various scenarios.
- **Chatbot Outputs**: The profile defines what the chatbot should confirm or provide in response to the user's requests.
