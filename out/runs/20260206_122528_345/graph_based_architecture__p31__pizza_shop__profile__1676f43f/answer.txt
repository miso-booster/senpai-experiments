Sure thing! Here's a profile for a pizza shop where the user is rude and wants things done quickly. I've included four goals with variables, and I've made sure that two of them use pairwise functions to allow for a conversation number determined by the pairwise matrix. Let's dive in! 🍕✨

```yaml
test_name: "rude_fast_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a rude customer who wants to place a pizza order quickly."
  context:
    - "You don't have time to waste and expect fast responses."
    - "You want to get your order done without any nonsense."
  goals:
    - "I want a {{pizza_type}} pizza."
    - "Make it a {{pizza_size}} size."
    - "Add {{number_of_drinks}} {{drink_type}}."
    - "Hurry up with the total cost!"

    - pizza_type:
        function: pairwise()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian]
    - pizza_size:
        function: pairwise()
        type: string
        data: [small, medium, large]
    - number_of_drinks:
        function: forward()
        type: int
        data:
          min: 1
          max: 5
          step: 1
    - drink_type:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Fanta]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't catch that. Can you just order already?"
  output:
    - total_cost:
        type: currency
        description: "The total cost of the pizza and drinks."
    - order_confirmation:
        type: string
        description: "Confirmation of the order details."

conversation:
  number: combinations(0.5, pairwise)  # Using pairwise functions for conversation number
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - single questions
```

Feel free to tweak any of the details to better fit your needs! Happy testing! 😊🍕
