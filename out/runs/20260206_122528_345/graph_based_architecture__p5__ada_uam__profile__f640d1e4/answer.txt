Sure! Here’s a profile you can use to test the UAM chatbot, representing a user seeking support related to the CAU (User Support Center). This profile will focus on obtaining the CAU’s phone number, email address, physical location, and opening hours.

```yaml
test_name: "CAU Support Inquiry"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita información sobre el Centro de Atención a Usuarios (CAU)."
  context:
    - "Buscas obtener información de contacto y horarios del CAU para resolver tus dudas."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Me puedes dar la dirección física del CAU?"
    - "¿Cuál es el correo electrónico de contacto del CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```
