¡Hola! 😊 Vamos a crear un perfil para que los usuarios obtengan soporte sobre el CAU (Centro de Atención a Usuarios) de la UAM. Este perfil incluirá los campos necesarios para obtener el número de teléfono, correo electrónico, dirección física y horarios.

### Estructura del Perfil

Aquí tienes un ejemplo de cómo podría verse el perfil en YAML:

```yaml
test_name: "UAM_CAU_Support"

llm:
  temperature: 0.7
  model: "gpt-4o"
  model_prov: "openai"
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca soporte sobre el CAU de la UAM."
  context:
    - "El usuario necesita información sobre contacto y horarios."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Cuál es el correo electrónico del CAU?"
    - "¿Dónde se encuentra la dirección física del CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: true
  fallback: "Lo siento, no tengo esa información."
  output:
    - telefono:
        type: string
        description: "Número de teléfono del CAU"
    - email:
        type: string
        description: "Correo electrónico del CAU"
    - direccion:
        type: string
        description: "Dirección física del CAU"
    - horarios:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 1
  goal_style:
    steps: 4
  interaction_style:
    - long phrases
```

### Explicación de los Campos

- **test_name**: Nombre del perfil para identificarlo.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el contexto y los objetivos del usuario.
- **chatbot**: Especifica cómo debe responder el chatbot y qué información debe extraer.
- **conversation**: Controla el número de interacciones y el estilo de interacción.

### Próximos Pasos

1. **Revisar el perfil**: Asegúrate de que todos los campos y descripciones sean correctos.
2. **Crear el archivo**: Guarda este YAML en la carpeta de perfiles de tu proyecto.
