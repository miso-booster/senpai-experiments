Based on the documentation I reviewed, here's how to create a rule that checks if the `order_id` was provided by the chatbot. This rule will ensure that the `order_id` field is present in the output of the conversation.

### Rule YAML

```yaml
name: order_id_provided
description: Check that the order ID is provided by the chatbot
conversations: 1
oracle: 'order_id is not None'
```

### Explanation
- **name**: This is the identifier for the rule, which is `order_id_provided`.
- **description**: A brief explanation of what the rule does.
- **conversations**: Set to `1` because we are checking this condition in a single conversation.
- **oracle**: This checks that the `order_id` is not `None`, meaning it must be provided by the chatbot.
