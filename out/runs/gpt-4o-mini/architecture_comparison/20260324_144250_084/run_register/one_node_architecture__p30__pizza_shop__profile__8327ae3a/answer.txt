Sure! Here's a profile for a pizza shop where the user is rude and wants things done quickly. I've included 4 goals with 4 variables, and 2 of them use pairwise functions to help determine the conversation number.

```yaml
test_name: "rude_fast_pizza_order"

llm:
  temperature: 0.5
  model: gpt-4o
  format:
    type: text

user:
  language: English
  role: "You are a rude customer who wants to order pizza quickly."
  context:
    - "You don't have time to waste and expect quick responses."
  goals:
    - "What kinds of pizzas do you have?"
    - "I want a {{pizza_type}} pizza."
    - "Make it {{pizza_size}}."
    - "Get me {{number_of_drinks}} {{drink_type}}."
    - pizza_type:
        function: pairwise()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian]
    - pizza_size:
        function: pairwise()
        type: string
        data: [small, medium, large]
    - number_of_drinks:
        function: forward()
        type: int
        data: {min: 1, max: 5, step: 1}
    - drink_type:
        function: forward()
        type: string
        data: [Coke, Sprite, Water, Fanta]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't catch that. Just tell me what you want."
  output:
    - order_confirmation:
        type: string
        description: "Confirmation of the pizza order and drinks."

conversation:
  number: combinations(0.5, pairwise)  # Using pairwise functions to determine conversation number
  goal_style:
    steps: 4
  interaction_style:
    - long phrases
    - change your mind
```
