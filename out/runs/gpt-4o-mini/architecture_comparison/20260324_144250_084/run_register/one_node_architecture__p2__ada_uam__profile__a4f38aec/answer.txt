Creating a profile for an Erasmus user who needs assistance with setting up platforms like Moodle and Sigma sounds like a great idea! Here's a simple profile that captures the essence of your request, focusing on the user’s need for guidance and ensuring the chatbot outputs relevant support information.

```yaml
test_name: "Erasmus User Setup Assistance"

llm:
  temperature: 0.7
  model: gpt-4o
  format:
    type: text

user:
  language: Spanish
  role: "Erasmus student who has just arrived and needs help setting up Moodle and Sigma."
  context:
    - "You are unfamiliar with the university's digital platforms."
    - "You need clear instructions on how to access and use Moodle and Sigma."
  goals:
    - "Ask for help with setting up my Moodle account."
    - "Request information on how to access Sigma."
    - "Inquire about any other platforms I need to be aware of for my studies."

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - moodle_setup_info:
        type: string
        description: "Instrucciones para configurar la cuenta de Moodle."
    - sigma_access_info:
        type: string
        description: "Información sobre cómo acceder a Sigma."
    - additional_resources:
        type: string
        description: "Otros recursos digitales que el estudiante debe conocer."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

### Explanation:
- **Test Name**: Clearly states the purpose of the profile.
- **User Role**: Describes the user's situation as an Erasmus student needing help.
- **Goals**: Lists specific requests the user might have regarding Moodle and Sigma.
- **Chatbot Outputs**: Defines what information the chatbot should provide to ensure the user receives proper support.
- **Conversation Structure**: Allows for a few interactions to gather necessary information.

Feel free to adjust any part of this profile to better fit your needs! 😊
