¡Claro! Aquí tienes un perfil de ejemplo para probar el chatbot de una pizzería. Este perfil está diseñado para que el output incluya el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares. Espero que te sea útil 😊.

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza and drinks from a pizzeria."
  context:
    - "You want to order a pizza with a drink."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Select a drink: {{drink}}."
    - "Ask for the total price."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian]
    - drink:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Can you please repeat?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink:
        type: string
        description: "The drink selected."
    - order_id:
        type: string
        description: "The unique identifier for the order."
    - total_price:
        type: currency
        description: "The final price of the order in dollars."

conversation:
  number: 1
  goal_style:
    steps: 3
  interaction_style:
    - default
```

Este perfil define un cliente que quiere hacer un pedido de pizza y bebida, y extrae la información necesaria al final de la conversación. Si necesitas hacer ajustes o agregar más detalles, ¡dímelo! 🍕✨
