¡Claro! Aquí tienes un perfil que puedes usar para probar la capacidad del chatbot de Alcampo en recomendar recetas y ayudar con la planificación de menús. Este perfil incluye variables para buscar recetas y gestionar ingredientes.

```yaml
test_name: "Recetas y Planificación de Menús"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "You are a user looking for recipe recommendations and menu planning assistance."
  context:
    - "You want to explore healthy recipes for your meals."
    - "You're interested in seasonal ingredients and easy-to-follow recipes."
  goals:
    - "Ask for recipe recommendations based on seasonal ingredients."
    - "Request a weekly meal plan that includes breakfast, lunch, and dinner."
    - "Inquire about healthy snacks to include in your meal plan."
    - "Ask how to manage ingredients for the recipes provided."

chatbot:
  is_starter: false
  fallback: "Lo siento, no entendí tu pregunta. ¿Cómo puedo ayudarte con recetas y planificación de menús?"
  output:
    - recipe_recommendations:
        type: list[string]
        description: "List of recommended recipes based on seasonal ingredients."
    - meal_plan:
        type: string
        description: "Weekly meal plan including breakfast, lunch, and dinner."
    - snack_options:
        type: list[string]
        description: "Suggestions for healthy snacks."
    - ingredient_management:
        type: string
        description: "Instructions for managing ingredients for the recipes."

conversation:
  number: 3
  goal_style:
    steps: 20
  interaction_style:
    - single questions
```
