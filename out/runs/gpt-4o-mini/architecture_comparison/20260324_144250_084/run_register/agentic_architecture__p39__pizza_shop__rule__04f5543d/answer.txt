To create a metamorphic rule that checks if adding a drink costs an extra 2 dollars, we need to ensure that the rule references the correct output field from the profile. Based on the documentation, the rule will compare the prices of two conversations with the same configuration but differing in whether a drink is included.

Here's how the rule will be structured:

### Metamorphic Rule YAML

```yaml
name: drink_cost_increase
description: Adding a drink to the order costs an additional 2 dollars
conversations: 2
when: conv[0].size == conv[1].size and conv[0].number == conv[1].number and conv[0].drink != conv[1].drink
if:   conv[1].drink is not None
then: extract_float(conv[1].price) == extract_float(conv[0].price) + 2
```

### Explanation
- **name**: The rule is named `drink_cost_increase`.
- **description**: Describes what the rule checks for.
- **conversations**: Specifies that this rule will check two conversations.
- **when**: Ensures that the size and number of items are the same, but the drink differs (one has a drink, the other does not).
- **if**: Checks that the second conversation (with the drink) indeed has a drink.
- **then**: Asserts that the price of the second conversation (with the drink) is exactly 2 dollars more than the first conversation (without the drink).

This rule assumes that the profile being used has the appropriate fields in its `chatbot.output`, specifically `size`, `number`, `drink`, and `price`.
