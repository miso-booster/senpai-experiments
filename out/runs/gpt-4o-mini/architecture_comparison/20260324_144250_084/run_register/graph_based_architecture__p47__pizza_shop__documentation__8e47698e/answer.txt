Great question! 😊 In the context of Sensei, a **metamorphic rule** is a specific type of rule used in **Sensei-check** to verify the correctness of conversations generated by Sensei-chat. 

Here's a simple breakdown:

1. **Purpose**: Metamorphic rules help check how outputs should change (or not) when inputs change across multiple conversations. This is particularly useful because it addresses the "oracle problem," where you might not have a clear expected output for every possible input.

2. **Structure**: A metamorphic rule typically involves:
   - **Conversations**: It can target a single conversation, several conversations, or all conversations.
   - **Conditions**: It checks conditions on pairs of conversations, asserting how outputs should relate to each other based on specific input changes.
   - **Syntax**: These rules are written in YAML format and include sections like `when`, `if`, and `then` to define the conditions and expected relationships.

3. **Example**: For instance, if you have two pizza orders of the same size and drink, a metamorphic rule might state that if one order has more toppings than the other, it should cost more.

This approach allows you to ensure that your chatbot behaves consistently and correctly across various scenarios! If you need help writing a specific metamorphic rule, feel free to ask! 😊
