```yaml
name: reject_duplicate_date
description: Si se menciona la misma fecha dos veces, el asistente debe rechazar la segunda.
conversations: 2
when: conv[0].date == conv[1].date
if:   utterance_index('assistant', 'no válido') > 0

```

- **`when:`** se asegura de que ambas conversaciones tengan la misma fecha.

- **`then:`** asegura que el rechazo ocurra después de que el usuario mencione la fecha.
