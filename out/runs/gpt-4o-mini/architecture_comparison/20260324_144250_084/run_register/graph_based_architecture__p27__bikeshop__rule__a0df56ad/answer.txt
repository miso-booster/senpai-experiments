¡Claro! Para crear una regla que verifique que si se le dice al asistente la misma fecha dos veces, debe rechazar la segunda, podemos usar una regla de metamorfismo en Sensei-check. Aquí tienes un ejemplo de cómo podría verse:

```yaml
name: reject_duplicate_date
description: Si se menciona la misma fecha dos veces, el asistente debe rechazar la segunda.
conversations: 2
when: conv[0].date == conv[1].date
if:   utterance_index('assistant', 'no válido') > 0
then: utterance_index('assistant', 'no válido') > utterance_index('user', conv[1].date)
```

En esta regla:

- **`when:`** se asegura de que ambas conversaciones tengan la misma fecha.
- **`if:`** comprueba que el asistente mencione un rechazo (por ejemplo, "no válido") en respuesta a la segunda mención de la fecha.
- **`then:`** asegura que el rechazo ocurra después de que el usuario mencione la fecha.

Asegúrate de que el asistente esté configurado para responder adecuadamente a la entrada duplicada. Si necesitas más ayuda o ajustes, ¡solo dímelo! 😊
