He cargado la documentación sobre los perfiles de SENSEI, que me ayudará a crear el perfil que necesitas para el chatbot de la UAM. Aquí hay un resumen de lo que se puede incluir en el perfil:

### Estructura del Perfil
Un perfil en SENSEI se define en un archivo YAML y tiene las siguientes secciones clave:

- **test_name**: Nombre del perfil.
- **llm**: Configuración del modelo de lenguaje (opcional).
- **user**: Define el lenguaje, el rol del usuario, el contexto y los objetivos.
- **chatbot**: Define si el chatbot inicia la conversación, el mensaje de fallback y los campos de salida que se extraerán.
- **conversation**: Controla el número de interacciones y el estilo de interacción.

### Campos de Salida
Para tu caso, los campos de salida que deseas extraer son:
- Número de teléfono
- Correo electrónico
- Dirección física
- Horarios

### Propuesta de Perfil
Voy a crear un perfil que refleje estos requisitos. Aquí tienes un ejemplo de cómo podría ser:

```yaml
test_name: "UAM_CAU_Support"

user:
  language: Spanish
  role: "Usuario que busca soporte sobre el CAU de la UAM."
  context:
    - "El usuario quiere obtener información sobre el CAU."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Cuál es el correo electrónico del CAU?"
    - "¿Dónde se encuentra la dirección física del CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: true
  fallback: "Lo siento, no pude encontrar esa información. ¿Puedes reformular tu pregunta?"
  output:
    - telefono:
        type: string
        description: "Número de teléfono del CAU"
    - email:
        type: string
        description: "Correo electrónico del CAU"
    - direccion:
        type: string
        description: "Dirección física del CAU"
    - horarios:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - random:
      - single questions
      - long phrases
```
