Aquí te propongo algunas reglas que podrías implementar para validar las respuestas del chatbot, basadas en los outputs que has definido. Estas reglas te ayudarán a asegurar que la información proporcionada sea correcta y útil.

### Sugerencias de Reglas

1. **Validación de Enlaces de Admisión**
   - **Descripción**: Verifica que el chatbot proporcione un enlace válido para el proceso de admisión.
   - **Condición**: Si se solicita información sobre admisiones, entonces `admission_to_grados_link` debe ser una URL válida.

2. **Información sobre Lista de Espera**
   - **Descripción**: Asegura que se proporcione información sobre los procedimientos de lista de espera.
   - **Condición**: Si se pregunta sobre la lista de espera, entonces `waitlist_info_link` debe ser una URL válida.

3. **Recursos para Futuros Estudiantes**
   - **Descripción**: Comprueba que se ofrezca un enlace a recursos para futuros estudiantes.
   - **Condición**: Si se consulta sobre recursos, entonces `future_students_link` debe ser una URL válida.

4. **Detalles del Evento Welcome Day**
   - **Descripción**: Verifica que se proporcione información sobre el evento Welcome Day.
   - **Condición**: Si se pregunta sobre el Welcome Day, entonces `welcome_day_link`, `welcome_day_date`, y `welcome_day_time` deben estar presentes y ser válidos.

5. **Requisitos de Admisión**
   - **Descripción**: Asegúrate de que se proporcionen los requisitos de admisión.
   - **Condición**: Si se pregunta sobre los requisitos de admisión, entonces `admission_requirements` debe contener información relevante.

### Ejemplo de Regla en YAML

A continuación, te muestro cómo podría verse una de estas reglas en YAML:

```yaml
name: validacion_enlaces_admision
description: Verifica que el chatbot proporcione un enlace válido para el proceso de admisión.
conversations: 1
if: "user.request == 'información sobre admisiones'"
then: "admission_to_grados_link is valid URL"
```
