Sure! Here’s a profile designed for a user who wants to set an appointment to have their wheels changed at a bike shop. This profile includes variables for different days and times to thoroughly test how the chatbot manages appointment scheduling. 

```yaml
test_name: "wheel_change_appointment"

llm:
  temperature: 0.7
  model: gpt-4o
  format:
    type: text

user:
  language: English
  role: "A customer looking to schedule an appointment for a wheel change."
  context:
    - "You need to get your bike's wheels changed soon."
    - "You have a flexible schedule but prefer specific days and times."
  goals:
    - "Set an appointment for a wheel change on {{appointment_date}} at {{appointment_time}}."
    - appointment_date:
        function: random()
        type: string
        data: [tomorrow, "next Monday", "next Wednesday", "this Saturday"]
    - appointment_time:
        function: random()
        type: string
        data: ["10:00 AM", "2:00 PM", "1:00 PM", "3:30 PM"]

chatbot:
  is_starter: true
  fallback: "I'm sorry, I didn't catch that. Could you please repeat?"
  output:
    - appointment_confirmation:
        type: string
        description: "Confirmation of the scheduled appointment, including date and time."

conversation:
  number: 5
  goal_style:
    all_answered:
      export: true
      limit: 5
  interaction_style:
    - default
```

### Explanation:
- **Goals**: The user aims to set an appointment for a wheel change, with variables for the date and time.
- **Variables**: 
  - `appointment_date` includes options for tomorrow, next Monday, next Wednesday, and this Saturday.
  - `appointment_time` includes various times to test how well the chatbot handles different scheduling scenarios.
- **Output**: The chatbot is expected to confirm the appointment details.
