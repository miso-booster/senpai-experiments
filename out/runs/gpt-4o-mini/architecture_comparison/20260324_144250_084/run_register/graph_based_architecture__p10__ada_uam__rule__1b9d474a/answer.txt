### 1. Admission Requirements Rule
This rule checks if the chatbot provides the admission requirements when a user asks for them.

```yaml
name: admission_requirements_check
description: The chatbot should provide admission requirements when asked.
conversations: 1
when: |
  'admission_requirements' in chatbot.output
oracle: admission_requirements is not None
```
