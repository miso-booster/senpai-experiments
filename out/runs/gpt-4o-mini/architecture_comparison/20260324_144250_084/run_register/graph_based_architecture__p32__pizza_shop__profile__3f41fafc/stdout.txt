¡Claro! Aquí tienes un perfil de ejemplo para probar el chatbot de una pizzería. Este perfil está diseñado para que el output muestre el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares. Puedes copiarlo y ajustarlo según tus necesidades:

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering a pizza and a drink."
  context:
    - "You want to order a pizza for delivery."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Select a drink: {{drink_type}}."
    - "Confirm the order."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian]
    - drink_type:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: true
  fallback: "I'm sorry, I didn't understand that. Can you please repeat?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink_type:
        type: string
        description: "The drink selected."
    - order_id:
        type: string
        description: "Unique identifier for the order."
    - total_price:
        type: currency
        description: "Final price of the order in dollars."

conversation:
  number: 3
  goal_style:
    steps: 3
  interaction_style:
    - random:
        - long phrases
        - single questions
```

### Desglose del perfil:
- **test_name**: Nombre del perfil para identificarlo.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el rol del usuario y sus metas.
- **chatbot**: Especifica el comportamiento del chatbot y qué información se debe extraer.
- **conversation**: Controla la cantidad de interacciones y el estilo de conversación.
