¡Claro! Aquí tienes un perfil para probar el chatbot de una pizzería. Este perfil está diseñado para extraer el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares. Puedes copiarlo y pegarlo en un archivo YAML en la carpeta de perfiles de tu proyecto.

```yaml
test_name: "pizza_order_profile"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza."
  context:
    - "You want to know the available pizza types and drinks."
  goals:
    - "Order a {{pizza_type}} pizza and a {{drink}}."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Vegetarian, Hawaiian]
    - drink:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Can you please rephrase?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink:
        type: string
        description: "The drink ordered."
    - order_id:
        type: string
        description: "The unique identifier for the order."
    - total_price:
        type: currency
        description: "The final price of the order in dollars."

conversation:
  number: 1
  goal_style:
    steps: 2
  interaction_style:
    - default
```

Este perfil configura un usuario que puede pedir una pizza y una bebida, y el chatbot debe responder con los detalles del pedido, incluyendo el ID y el precio total. ¡Espero que te sea útil! 🍕😊
