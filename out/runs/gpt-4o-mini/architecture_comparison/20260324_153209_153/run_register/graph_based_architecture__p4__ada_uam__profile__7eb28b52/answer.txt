¡Claro! Vamos a crear un perfil para que puedas testear el chatbot de la UAM y obtener la información que necesitas sobre el CAU. Aquí tienes un ejemplo de cómo podría verse tu perfil en YAML:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca información sobre el Centro de Atención a Usuarios (CAU)."
  context:
    - "Necesito obtener información de contacto y horarios del CAU."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Cuál es el correo electrónico de contacto del CAU?"
    - "¿Cuál es la dirección física del CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

### Desglose del perfil:
- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje que se usará.
- **user**: Define el rol del usuario y sus objetivos.
- **chatbot**: Configura el comportamiento del chatbot y qué información se espera extraer.
- **conversation**: Controla el número de interacciones y el estilo de la conversación.

Puedes ajustar el perfil según tus necesidades específicas. ¡Espero que esto te ayude a testear el chatbot de la UAM! Si necesitas más cambios o tienes alguna otra pregunta, ¡no dudes en decírmelo! 😊
