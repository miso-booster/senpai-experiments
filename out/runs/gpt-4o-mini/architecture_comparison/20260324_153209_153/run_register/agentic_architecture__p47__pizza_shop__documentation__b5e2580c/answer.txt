A metamorphic rule in the context of Sensei refers to a type of validation logic that checks relationships or properties across multiple conversations rather than just within a single conversation. These rules are particularly useful for ensuring consistency and correctness in the behavior of a chatbot over a series of interactions.

### Key Features of Metamorphic Rules:

- **Cross-Conversation Validation**: Unlike standard rules that might validate a single conversation's output, metamorphic rules assess how outputs from different conversations relate to each other.
  
- **Implication Logic**: They often use an implication structure (if/then) to define conditions that must hold true across multiple conversations.

- **Use Cases**: Metamorphic rules can be used to check for consistency in responses, ensure that certain outputs are unique across conversations, or validate that the chatbot maintains a coherent context over time.

### Example:

- If a user asks for the weather in two different cities, a metamorphic rule might check that the responses do not contradict each other (e.g., if City A is sunny, City B should not be reported as rainy at the same time unless specified).

These rules help in enhancing the robustness of chatbot interactions by ensuring that the chatbot behaves consistently across various scenarios.
