I've loaded the relevant documentation for profiles from `sensei-chat-guide.md`. Now, let's create a profile for a user who wants to set an appointment at a bike shop to have their wheels changed. This profile will include various variables to test different days and times for the appointment.

### Proposed Profile Structure

Here's a draft of the profile:

```yaml
test_name: "bike_shop_appointment"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer wanting to set an appointment to change bike wheels."
  context:
    - "The user is flexible with dates and times."
  goals:
    - "Schedule an appointment on {{appointment_date}} at {{appointment_time}}."
    - appointment_date:
        function: random()
        type: string
        data:
          - any(3 dates within the next 30 days)
    - appointment_time:
        function: random()
        type: string
        data:
          - "10:00 AM"
          - "2:00 PM"
          - "4:00 PM"

chatbot:
  is_starter: true
  fallback: "I'm sorry, I didn't understand that. Can you please rephrase?"
  output:
    - appointment_confirmation:
        type: string
        description: "Confirmation of the scheduled appointment."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Key Components Explained

- **test_name**: A descriptive name for the profile.
- **llm**: Configuration for the language model.
- **user**: Defines the simulated user, including their role and goals.
  - **goals**: Includes variables for `appointment_date` and `appointment_time`, with options for different dates and times.
- **chatbot**: Specifies that the chatbot starts the conversation and includes an output field for appointment confirmation.
- **conversation**: Controls the number of conversations and interaction style.
