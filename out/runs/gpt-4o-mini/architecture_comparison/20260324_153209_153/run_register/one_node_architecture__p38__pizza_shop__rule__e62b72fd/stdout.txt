Sure! To create a rule that checks if the order ID was provided by the chatbot, you can use a simple oracle rule. Here’s how it would look:

```yaml
name: order_id_provided
description: The chatbot must provide an order ID in the response.
conversations: 1
oracle: order_id is not None
```

In this rule:

- **name**: A unique identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to 1, as this is a single-conversation check.
- **oracle**: It checks that the `order_id` field is not `None`, meaning it must be provided by the chatbot.

Feel free to adjust any part of it to better fit your project! 😊
