The **pairwise function** in the context of SENSEI-check is used to define **metamorphic rules** that compare pairs of conversations to assert how outputs should change (or remain the same) when certain inputs change. This approach helps alleviate the oracle problem by checking relationships between outputs instead of relying solely on absolute answers.

### Key Aspects of the Pairwise Function:

1. **Purpose**: 
   - The pairwise function allows you to specify conditions that must hold true across pairs of conversations. For example, if two conversations have the same input conditions, you can assert that one output should be greater than the other based on a specified relationship.

2. **Structure**:
   - A metamorphic rule using the pairwise function typically includes:
     - **Conversations**: Specifies how many conversations are involved (usually at least two).
     - **When Condition**: A filter that selects which pairs of conversations to compare.
     - **If/Then Relation**: Specifies what should happen if the condition is met.

3. **Example**:
   Here's a simple example of a pairwise rule that checks if adding more toppings to a pizza increases the price:
   ```yaml
   name: toppings_monotonicity
   description: More toppings increase total price
   conversations: 2
   when: conv[0].size == conv[1].size and conv[0].drink == conv[1].drink
   if:   len(conv[0].toppings) > len(conv[1].toppings)
   then: extract_float(conv[0].price) > extract_float(conv[1].price)
   ```

### How It Works:
- **Generate Conversations**: First, conversations are generated with specific inputs (e.g., pizza size, drink).
- **Write Rules**: You write rules that declare how many conversations are needed, what conditions to check, and the expected relationships.
- **Evaluation**: The SENSEI-check framework evaluates these rules against the generated conversations and reports any failures.

### Benefits:
- **Relational Checking**: Instead of checking for absolute correctness, you can check for expected relationships, which is especially useful in scenarios where outputs may vary slightly due to the nature of conversational AI.
