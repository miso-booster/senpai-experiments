### YAML Connector

```yaml
name: "Alcampo Chatbot"
base_url: "https://alcampo.botslovers.com"
send_message:
  path: "/bot/web"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Accept: "*/*"
    Accept-Language: "en-US,en;q=0.9"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
    Referer: "https://alcampo.botslovers.com/Admin/Widget?mobile=0&user=0&lang=es"
  payload_template:
    data:
      id_user: "{id_user}"
      idweb_user: "{idweb_user}"
      session: "{session}"
      message:
        message:
          text: "{user_msg}"
        iduser: "{id_user}"
        session: "{session}"
        channel: "web"
      widget_form: "TRUE"
      contexto_extra: []
      lang: "es"
      accion: "response_bot"
response_path: "messages.0.0.message.text"
```

### Explanation of the Connector

- **name**: A friendly name for the connector.
- **base_url**: The base URL of the chatbot API.
- **send_message**: This section contains:
  - **path**: The specific endpoint for sending messages.
  - **method**: The HTTP method used for the request (POST).
  - **headers**: Custom headers required for the request.
  - **payload_template**: The JSON structure that includes placeholders for dynamic values (like user ID, session, and user message).
- **response_path**: This specifies how to extract the chatbot's reply from the JSON response.

### Notes
- Make sure to replace the placeholders (e.g., `{id_user}`, `{idweb_user}`, `{session}`, `{user_msg}`) with actual values when making a request.
- The `response_path` is set to navigate through the JSON response to get the text of the message returned by the bot.
