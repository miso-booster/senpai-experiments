¡Claro! Aquí tienes un perfil que puedes usar para probar la capacidad del chatbot de Alcampo en recomendar recetas y ayudar con la planificación de menús. Este perfil está diseñado para simular un usuario que busca asistencia en la cocina y la gestión de recetas.

```yaml
test_name: "Recipe Management and Menu Planning"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A user looking for recipe recommendations and menu planning assistance."
  context:
    - "You are excited to explore new recipes and plan meals for the week."
    - "You want to focus on seasonal ingredients and healthy options."
    - "You are looking for tools that can help streamline your cooking process."
  goals:
    - "Ask for recipe recommendations based on seasonal ingredients."
    - "Inquire about meal planning tips for a balanced diet."
    - "Request information on how to add ingredients from recipes to a shopping list."
    - "Ask for details on any available cooking classes or workshops."
    - "Seek advice on how to prepare a specific dish."

chatbot:
  is_starter: false
  fallback: "Parece que tu mensaje no es claro o no es una pregunta relacionada con recetas. 😊 ¿En qué puedo ayudarte hoy? Estoy aquí para ayudarte con tus dudas sobre recetas y planificación de menús."
  output:
    - recipe_recommendations:
        type: string
        description: "Suggested recipes based on seasonal ingredients."
    - meal_planning_tips:
        type: string
        description: "Tips for planning balanced meals."
    - ingredient_management:
        type: string
        description: "Instructions for adding ingredients to a shopping list."
    - cooking_classes_info:
        type: string
        description: "Information about available cooking classes or workshops."
    - specific_dish_advice:
        type: string
        description: "Advice on preparing a specific dish."

conversation:
  number: 5
  max_cost: 0.5
  goal_style:
    steps: 20
  interaction_style:
    - single questions
```

Este perfil te permitirá probar cómo el chatbot de Alcampo maneja solicitudes relacionadas con recetas y planificación de menús. ¡Espero que te sea útil! Si necesitas más ajustes o detalles, no dudes en decírmelo. 😊
