Connectors in Sensei are used to facilitate communication between your chatbot and external APIs. They define how to send messages to the chatbot and how to interpret the responses received. This allows you to integrate different chatbot systems seamlessly into your testing framework.

### Key Fields in a Connector

1. **name**: A friendly name for your chatbot connector.
2. **base_url**: The base URL of the chatbot API that you'll be interacting with.
3. **send_message**: This section contains details on how to send a message to the chatbot:
   - **path**: The specific endpoint path (appended to the base URL) for sending messages.
   - **method**: The HTTP method to use (e.g., POST, GET). If not specified, POST is the default.
   - **headers**: Any custom headers that need to be included in the request (e.g., Authorization).
   - **payload_template**: The structure of the message you want to send, including placeholders (like `{user_msg}`) for dynamic content.
4. **response_path**: A dot-separated path to extract the chatbot's reply from the JSON response. This tells the connector where to find the relevant information in the response.

These fields allow you to configure how your chatbot interacts with various APIs, making it easier to test and validate different conversational scenarios. If you have any specific connector you want to explore or modify, feel free to ask! 😊
