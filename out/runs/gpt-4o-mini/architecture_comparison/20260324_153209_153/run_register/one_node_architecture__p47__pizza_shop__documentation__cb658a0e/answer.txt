Great question! 😊 In the context of Sensei, a **metamorphic rule** is a condition used to check the correctness of generated conversations by comparing pairs or tuples of conversations. Instead of just looking for absolute answers, metamorphic rules focus on the relationships between outputs when inputs are modified.

Here's a simple breakdown:

1. **Purpose**: They help verify that certain properties hold true across multiple conversations. For example, if you add more toppings to a pizza, the price should increase.

2. **Structure**: Each metamorphic rule specifies:
   - How many conversations it needs to evaluate (usually at least two).
   - An optional filter to select which conversations to compare.
   - A relation that describes how the outputs should change (or remain the same) based on the inputs.

3. **Example**: If you have two conversations where the size of the pizzas is the same, the rule might state that if one pizza has more toppings than the other, its price should be higher.

This approach helps alleviate the oracle problem by ensuring that the system behaves consistently under varying conditions! 🌟 If you have more questions about how to write or use these rules, feel free to ask!
