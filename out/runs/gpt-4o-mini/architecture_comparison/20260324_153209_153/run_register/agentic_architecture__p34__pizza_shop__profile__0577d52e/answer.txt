### Profile Structure
Here's how we can structure the profile:

1. **Test Name**: A descriptive name for the profile.
2. **LLM Settings**: Configuration for the language model.
3. **User Definition**:
   - **Language**: The language the user will communicate in.
   - **Role**: Describes the user's behavior and context.
   - **Goals**: Defines what the user wants to achieve in the conversation.
4. **Chatbot Configuration**:
   - **Is Starter**: Indicates if the chatbot starts the conversation.
   - **Fallback Message**: What the chatbot says if it doesn't understand.
   - **Output Fields**: The data we want to extract at the end of the conversation.
5. **Conversation Controls**: Defines how many conversations to run and interaction styles.

### Proposed Profile YAML
Here’s a draft of the profile based on your requirements:

```yaml
test_name: "custom_pizza_order"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer who initially wants a custom pizza but changes their mind halfway through the conversation."
  context:
    - "The user is indecisive and may ask for predefined options after discussing custom toppings."
  goals:
    - "Order a custom pizza with {{custom_toppings}}."
    - "Change my order to a predefined pizza: {{predefined_pizza}}."
    - custom_toppings:
        function: random()
        type: string
        data: ["pepperoni", "mushrooms", "onions", "extra cheese", "black olives"]
    - predefined_pizza:
        function: random()
        type: string
        data: ["Margherita", "Pepperoni", "BBQ Chicken", "Veggie Delight"]

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you clarify your order?"
  output:
    - order_summary:
        type: string
        description: "Summary of the final pizza order including toppings and type."

conversation:
  number: 2
  goal_style:
    steps: 5
  interaction_style:
    - change your mind
```

### Summary of the Profile
- **Test Name**: `custom_pizza_order` describes the scenario.
- **User Role**: The user starts with a custom order but may switch to a predefined pizza.
- **Goals**: Includes both the custom toppings and the option to change to a predefined pizza.
- **Chatbot Output**: Captures a summary of the order.
