Sure thing! Here’s a profile for a pizza shop where the user is rude and wants things done quickly. I've included 4 goals with 4 variables, and two of them use pairwise functions to help determine the conversation number. Let's dive in! 🍕✨

```yaml
test_name: "rude_fast_pizza_order"

llm:
  temperature: 0.6
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A rude customer who wants their pizza order handled quickly."
  context:
    - "You don't have time for chit-chat and expect fast service."
    - "You want to get your order done without any delays."
  goals:
    - "I want a {{pizza_type}} pizza."
    - "Make it {{size}} and add {{toppings}}."
    - "I need {{number_of_drinks}} {{drink_type}} drinks."
    - "How long until it's ready?"

    - pizza_type:
        function: forward()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian]
    - size:
        function: pairwise()
        type: string
        data: [small, medium, large]
    - toppings:
        function: pairwise()
        type: string
        data: [extra cheese, mushrooms, olives, peppers]
    - number_of_drinks:
        function: forward()
        type: int
        data:
          min: 1
          max: 5
          step: 1
    - drink_type:
        function: forward()
        type: string
        data: [Coke, Sprite, Water, Fanta]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't catch that. Can you just order already?"
  output:
    - order_confirmation:
        type: string
        description: "Confirmation of the order details."
    - estimated_time:
        type: time("hh:mm:ss")
        description: "Estimated time for the order to be ready."
    - total_cost:
        type: currency
        description: "Total cost of the pizza and drinks."

conversation:
  number: combinations(0.5, pairwise) # Using pairwise functions for conversation number
  goal_style:
    all_answered:
      export: true
      limit: 10
  interaction_style:
    - long phrases
    - change your mind
```

This profile sets the stage for a rude customer who wants their pizza order processed quickly. The goals and variables are designed to create a dynamic conversation while ensuring that the conversation number can be determined by the pairwise matrix.
