Sure! To create a rule that checks if the order ID is provided by the chatbot, you can use a simple single-conversation oracle. Here’s how it would look in YAML format:

```yaml
name: order_id_provided
description: The chatbot must return an order ID
conversations: 1
oracle: "'order_id' in data_output"
```

### Explanation:
- **name**: This is the identifier for the rule, which I've set as `order_id_provided`.
- **description**: A brief explanation of what the rule checks.
- **conversations**: This is set to `1` because we are checking a single conversation.
- **oracle**: This checks if the `order_id` is present in the output data from the chatbot.
