Connectors in the SENSEI framework are used to integrate with external chatbot APIs without the need for coding. They allow you to define how to communicate with a chatbot's API through a YAML configuration file.

### Key Fields in a Connector

Here's a breakdown of the main fields you would typically find in a connector configuration:

| Field                        | Description                                                   | Required        |
|------------------------------|---------------------------------------------------------------|------------------|
| `name`                       | Friendly name for your chatbot                                | No               |
| `base_url`                  | Base URL of the chatbot API                                   | Yes              |
| `send_message.path`         | API endpoint path (appended to base_url)                     | Yes              |
| `send_message.method`       | HTTP method (POST, GET, PUT, DELETE)                         | No (default: POST) |
| `send_message.headers`      | Custom headers (e.g., Authorization)                          | No               |
| `send_message.payload_template` | JSON structure with `{user_msg}` placeholder               | Yes              |
| `response_path`             | Dot-separated path to extract the bot's reply from JSON response | Yes              |

### Example Configuration

Here’s a simple example of a connector configuration:

```yaml
name: "My Custom Bot"
base_url: "https://api.mychatbot.com"
send_message:
  path: "/chat"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "response.text"
```

### Usage

- **Creating a Connector**: You create a YAML file that specifies the fields above to define how your chatbot interacts with the API.
- **Sending Messages**: The `send_message` section details how to send user messages to the API, including the HTTP method and any necessary headers.
- **Extracting Responses**: The `response_path` field is used to navigate through the JSON response from the API to get the chatbot's reply.

For more detailed examples and configurations, you can refer to the documentation files: `custom-connector-guide.md` and `connector-examples.md`. If you have any specific questions about how to set up a connector or need help with a particular API, feel free to ask! 😊
