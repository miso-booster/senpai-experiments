Sure! Here’s a profile you can use to test the UAM chatbot for a user seeking support related to the CAU (User Support Center). This profile will focus on obtaining the CAU's phone number, email address, physical location, and opening hours.

```yaml
test_name: "CAU Support Inquiry"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca información sobre el Centro de Atención a Usuarios (CAU)."
  context:
    - "Necesito ayuda para acceder a los servicios del CAU."
    - "Busco obtener información sobre cómo contactar al CAU."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir la dirección física del CAU."
    - "Consultar el correo electrónico de contacto del CAU."
    - "Preguntar sobre el horario de atención del CAU."

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me puedes decir con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - phone_contact:
        type: string
        description: "Número de teléfono del CAU."
    - contact_email:
        type: string
        description: "Correo electrónico del CAU."
    - physical_address:
        type: string
        description: "Dirección física del CAU."
    - service_hours:
        type: string
        description: "Horario de atención del CAU."

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

Feel free to modify any part of this profile to better suit your testing needs! Happy testing! 😊
