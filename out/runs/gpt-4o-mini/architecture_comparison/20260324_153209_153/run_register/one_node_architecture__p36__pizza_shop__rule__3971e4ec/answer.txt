It looks like your rule is missing the `if` condition, which is essential to specify the condition under which the `then` clause should be evaluated. In your case, you want to check if the number of toppings in the first conversation is greater than the number of toppings in the second conversation. 

Here's the corrected version of your rule:

```yaml
name: more_toppings_cost_more
description: Adding more toppings to a custom pizza costs more
active: True
conversations: 2
when: conv[0].size == conv[1].size and conv[0].drink == conv[1].drink
if:   len(conv[0].toppings) > len(conv[1].toppings)
then: extract_float(conv[0].price) > extract_float(conv[1].price)
```

Now, this rule checks that if the first conversation has more toppings than the second conversation, then the price of the first pizza should be greater than the price of the second pizza. Give it a try! 😊
