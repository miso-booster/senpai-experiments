Sure! Here's a profile for a user who wants to set an appointment to have their wheels changed at a bike shop. This profile includes variables for different days and times to thoroughly test how the chatbot manages appointment scheduling. 

```yaml
test_name: "wheel_change_appointment"

llm:
  temperature: 0.5
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer looking to set an appointment for changing bike wheels."
  context:
    - "You want to ensure your bike is ready for the upcoming season."
    - "You have a flexible schedule and can choose from various days and times."
  goals:
    - "Set an appointment for changing the wheels on {{appointment_date}} at {{appointment_time}}."
    - appointment_date:
        function: random()
        type: string
        data: [tomorrow, 'November 6th, 2024', 'next Monday', 'this Saturday']
    - appointment_time:
        function: random()
        type: string
        data: ['10:00 AM', '2:00 PM', '1:00 PM', '3:30 PM']

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you repeat that?"
  output:
    - confirmed_date:
        description: "The date of the appointment confirmed by the assistant."
        type: date
    - confirmed_time:
        description: "The time of the appointment confirmed by the assistant."
        type: string
    - appointment_confirmation:
        description: "Confirmation of the scheduled appointment for wheel change."
        type: string

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 5
  interaction_style:
    - default
```

This profile allows the user to set an appointment for changing bike wheels, testing various dates and times. Feel free to adjust any details as needed! 😊
