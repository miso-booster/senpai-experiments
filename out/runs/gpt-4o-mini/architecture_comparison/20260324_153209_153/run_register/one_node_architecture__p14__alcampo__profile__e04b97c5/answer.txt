¡Claro! Aquí tienes un perfil que puedes usar para probar la capacidad del chatbot de Alcampo para recomendar recetas y ayudarte con la planificación de menús. Este perfil incluye variables para buscar recetas y gestionar ingredientes. 

```yaml
test_name: "Recetas y Planificación de Menús"

llm:
  temperature: 0.7
  model: gpt-4o
  format:
    type: text

user:
  language: English
  role: "A user looking for recipe recommendations and meal planning assistance."
  context:
    - "You want to explore new recipes to enhance your cooking skills."
    - "You're interested in seasonal ingredients and healthy meal options."
  goals:
    - "Ask for recipe recommendations based on seasonal ingredients."
    - "Inquire about meal planning tips for a week."
    - "Request help in creating a shopping list for selected recipes."
    - "Ask for suggestions on how to incorporate leftovers into new meals."
    - "Seek advice on healthy meal prep techniques."

chatbot:
  is_starter: false
  fallback: "I'm here to help you with recipes and meal planning! What do you need?"
  output:
    - recipe_recommendations:
        type: string
        description: "List of recommended recipes based on user preferences."
    - meal_planning_tips:
        type: string
        description: "Tips for effective meal planning."
    - shopping_list:
        type: string
        description: "A shopping list based on selected recipes."
    - leftover_ideas:
        type: string
        description: "Creative ways to use leftovers in new meals."
    - meal_prep_advice:
        type: string
        description: "Advice on healthy meal prep techniques."

conversation:
  number: 5
  goal_style:
    steps: 10
  interaction_style:
    - random:
      - long phrases
      - single questions
```

Este perfil está diseñado para interactuar con el chatbot y obtener recomendaciones útiles sobre recetas y planificación de menús. Puedes ajustarlo según tus necesidades específicas. ¡Espero que te sea útil! 😊
