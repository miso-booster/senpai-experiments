- **Conversations**: This will specify that it applies to a single conversation.

### Proposed YAML Rule
Here’s the YAML for the rule:

```yaml
name: small_pizza_price
description: Checks that the price of a small pizza is at least $10
active: true
conversations: 1
when: size == 'small'
oracle: extract_float(price) >= 10 and currency(price) == 'USD'
```

### Explanation
- **`name`**: Identifies the rule as `small_pizza_price`.
- **`description`**: Clearly states the purpose of the rule.
- **`active`**: Set to `true` so that the rule is evaluated.
- **`conversations`**: Indicates that this rule applies to one conversation.
- **`when`**: Checks if the pizza size is 'small'.
- **`oracle`**: Validates that the extracted price is at least $10 and that the currency is USD.
