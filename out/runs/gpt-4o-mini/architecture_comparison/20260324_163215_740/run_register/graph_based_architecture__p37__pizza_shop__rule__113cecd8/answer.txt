¡Claro! Para crear una regla que verifique si el asistente confirma que añadió la bebida que el usuario pidió, podemos basarnos en la estructura de las reglas de Sensei. Aquí tienes un ejemplo de cómo podría verse esa regla:

```yaml
name: confirm_drink_added
description: El asistente confirma que ha añadido la bebida solicitada por el usuario.
conversations: 1
oracle: utterance_index('user', 'quiero una bebida') < utterance_index('assistant', 'he añadido la bebida')
```

### Explicación:
- **name**: Le damos un nombre descriptivo a la regla.
- **description**: Explicamos qué es lo que estamos verificando.
- **conversations**: Establecemos que esta regla se aplica a una sola conversación.
- **oracle**: Aquí usamos `utterance_index` para comprobar que la frase donde el usuario pide la bebida aparece antes que la frase donde el asistente confirma que la bebida ha sido añadida.

Recuerda adaptar las frases exactas según el lenguaje que utilice tu asistente. Si necesitas más ayuda o ajustes, ¡no dudes en decírmelo! 😊
