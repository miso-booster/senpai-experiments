I've loaded the relevant documentation for profiles from `sensei-chat-guide.md`. Now, let's create a profile for a user wanting to set an appointment at a bike shop to have their wheels changed. This profile will include variables for testing different days and times.

### Proposed Profile Structure

Here's how the profile will be structured:

- **Test Name**: A descriptive name for the profile.
- **User Role**: Describes the simulated user (e.g., a customer at a bike shop).
- **Goals**: Includes variables for appointment dates and times.
- **Chatbot Output**: Defines what we want to extract after the conversation.

### YAML Profile Example

```yaml
test_name: "bike_shop_appointment"

llm:
  temperature: 0.7
  model: "gpt-4o"
  model_prov: "openai"
  format:
    type: text

user:
  language: English
  role: "A customer wanting to set an appointment to have their bike wheels changed."
  context:
    - "The user is flexible with dates and times."
  goals:
    - "Set an appointment for wheel change on {{appointment_date}} at {{appointment_time}}."
    - appointment_date:
        function: random()
        type: string
        data:
          - any(3 dates within the next 30 days)
    - appointment_time:
        function: random()
        type: string
        data:
          - "09:00 AM"
          - "01:00 PM"
          - "03:00 PM"

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you please provide that information again?"
  output:
    - appointment_confirmation:
        type: string
        description: "Confirmation of the appointment date and time."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
```

- **Test Name**: `bike_shop_appointment` - This identifies the profile.
- **User Role**: The user is a customer looking to set an appointment.
- **Goals**: The profile includes variables for `appointment_date` and `appointment_time`, allowing the chatbot to handle various scenarios.
- **Chatbot Output**: The output field `appointment_confirmation` will capture the confirmation message from the chatbot.
