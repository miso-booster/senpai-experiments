That sounds like a great use case for a Sensei profile! Let's create a profile for a user who recently got a new bike and wants to customize it by changing the seat and handlebar grips. Here’s a basic outline you can use to get started:

```yaml
test_name: "bike_setup_request"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer looking to customize their new bike."
  context:
    - "You recently purchased a new bike and want to make it more comfortable."
    - "You are interested in changing the seat and handlebar grips."
  goals:
    - "Ask if the shop can help customize your bike."
    - "Inquire about the available seat options."
    - "Ask about the different types of handlebar grips available."
    - "Request a quote for the customization service."
    - "Specify the seat type as {{seat_type}}."
    - "Specify the grip type as {{grip_type}}."
    - seat_type:
        function: random()
        type: string
        data: [comfort, racing, gel, leather, ergonomic]
    - grip_type:
        function: random()
        type: string
        data: [foam, rubber, gel, leather, ergonomic]

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you repeat that?"
  output:
    - customization_confirmation:
        type: string
        description: "Confirmation from the chatbot that they can customize the bike."
    - seat_options:
        type: string
        description: "Details about available seat options."
    - grip_options:
        type: string
        description: "Details about available handlebar grip options."
    - quote:
        type: money
        description: "The estimated cost for the customization service."

conversation:
  number: 4
  goal_style:
    all_answered:
      export: true
      limit: 5
  interaction_style:
    - random:
      - single questions
      - long phrases
```

### Explanation:
- **test_name**: A descriptive name for your profile.
- **user**: Defines the user's role, context, and goals. Here, the user is looking to customize their new bike.
- **chatbot**: Specifies the chatbot's behavior and the outputs you want to extract after the conversation.
- **conversation**: Controls how many interactions will occur and the style of those interactions.
