¡Claro! Aquí tienes un perfil de ejemplo para probar el chatbot de una pizzería. Este perfil incluye los campos de salida que mencionaste: tipo de pizza, bebida, ID del pedido y precio final en dólares. Puedes copiarlo y pegarlo en un archivo YAML en la carpeta de perfiles de tu proyecto.

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering pizza."
  context:
    - "You want to order a pizza and a drink."
  goals:
    - "Order a {{pizza_type}} pizza with {{toppings}}."
    - "Select a drink: {{drink}}."
    - "Ask for the total price."

    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian]
    - toppings:
        function: random()
        type: string
        data: [None, Extra cheese, Olives, Mushrooms, Peppers]
    - drink:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Can you please repeat?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink:
        type: string
        description: "The drink selected."
    - order_id:
        type: string
        description: "The unique identifier for the order."
    - total_price:
        type: currency
        description: "The final price of the order in dollars."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - random:
      - long phrases
      - single questions
```

Este perfil está diseñado para simular un cliente que pide una pizza y una bebida, y también incluye los campos necesarios para la salida. ¡Espero que te sirva! Si necesitas más ajustes, no dudes en decírmelo. 🍕😊
