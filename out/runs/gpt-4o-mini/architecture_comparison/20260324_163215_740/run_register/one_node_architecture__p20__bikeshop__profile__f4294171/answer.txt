Sure! Here’s a profile for a user looking to set an appointment to have their wheels changed at a bike shop. This profile includes variables to test different days and times for the appointment. Let’s dive right in! 🚴‍♂️

```yaml
test_name: "wheel_change_appointment"

llm:
  temperature: 0.5
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer looking to set an appointment for changing bike wheels."
  context:
    - "You want to ensure your bike is in good condition for your upcoming rides."
    - "You have a flexible schedule and can choose from various days and times."
  goals:
    - "Set an appointment for changing the wheels on {{appointment_date}} at {{appointment_time}}."
    - appointment_date:
        function: random()
        type: string
        data: [tomorrow, "next Monday", "next Wednesday", "next Friday"]
    - appointment_time:
        function: random()
        type: string
        data: ["10:00 AM", "2:00 PM", "4:30 PM", "11:30 AM"]

chatbot:
  is_starter: true
  fallback: "I'm sorry, I didn't catch that. Could you please repeat?"
  output:
    - confirmed_date:
        type: date
        description: "The date of the appointment confirmed by the assistant."
    - confirmed_time:
        type: string
        description: "The time of the appointment confirmed by the assistant."
    - service_type:
        type: string
        description: "The service to be done in the appointment, confirmed by the assistant."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 5
  interaction_style:
    - default
```

### Explanation:
- **User Role**: The user is looking to set an appointment for changing bike wheels.
- **Goals**: The goals include setting an appointment with variables for different dates and times.
- **Variables**: 
  - `appointment_date` has options for tomorrow, next Monday, next Wednesday, and next Friday.
  - `appointment_time` includes various times for the appointment.
- **Chatbot Output**: The chatbot will confirm the date, time, and type of service.
