Great question! 😊 In the context of Sensei, a **metamorphic rule** is a specific type of rule used in testing that helps verify the correctness of conversational outputs by comparing pairs or tuples of conversations. 

Here's a simple breakdown:

1. **Purpose**: Metamorphic rules are designed to check how outputs should change (or not) when inputs change. This helps address the oracle problem, which is the challenge of determining the correctness of outputs in situations where you might not have a clear expected answer.

2. **Targeting Conversations**: These rules can target:
   - A **single conversation** (traditional oracle),
   - **Several conversations** (this is where metamorphic testing shines),
   - Or **all conversations** (global checks).

3. **Structure**: When you write a metamorphic rule, you typically define:
   - How many conversations it needs to evaluate (usually at least two).
   - A condition that filters which conversations to compare (using expressions).
   - The expected relationship between the outputs of those conversations.

For example, you might have a rule that states if two pizza orders have the same size and drink, the one with more toppings should cost more. This would be a metamorphic rule because it checks the relationship between the inputs (size, drink, toppings) and the output (price).

In summary, metamorphic rules are a powerful way to ensure that your chatbot behaves correctly across different scenarios by focusing on the relationships between inputs and outputs! If you have more questions or need examples, feel free to ask! 🍕✨
