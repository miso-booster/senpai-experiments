¡Claro! Aquí tienes un perfil de ejemplo para probar el chatbot de una pizzería. Este perfil incluye los campos que mencionaste en el `output`, como el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares. Puedes copiarlo y ajustarlo según tus necesidades:

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "You are a customer ordering a pizza and a drink."
  context:
    - "You want to enjoy a meal with friends."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Select a {{drink_type}} to go with it."
    - "Ask for the total price."
    - "Request the order ID."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian]
    - drink_type:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Lemonade]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Can you please rephrase?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink_type:
        type: string
        description: "The type of drink ordered."
    - order_id:
        type: string
        description: "The unique identifier for the order."
    - total_price:
        type: currency
        description: "The final price of the order in dollars."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 20
  interaction_style:
    - random:
        - long phrases
        - single questions
```

Este perfil está diseñado para simular un cliente que ordena una pizza y una bebida, y luego solicita el precio total y el ID del pedido. ¡Espero que te sea útil! Si necesitas más ajustes, no dudes en decírmelo 😊.
