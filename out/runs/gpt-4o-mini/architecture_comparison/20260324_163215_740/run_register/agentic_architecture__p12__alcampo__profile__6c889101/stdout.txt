I've loaded the relevant documentation for creating profiles from the `sensei-chat-guide.md`. Now, let's create a profile that asks the chatbot for items to add to the user's shopping cart. 

### Profile Structure
Here's a basic outline of the profile we'll create:

- **Test Name**: A descriptive name for the profile.
- **User**: Defines the language, role, context, and goals.
- **Chatbot**: Specifies if the chatbot starts the conversation, fallback messages, and output fields.
- **Conversation**: Controls the number of conversations and interaction styles.

### Proposed Profile YAML
Here's a sample YAML for the shopping cart profile:

```yaml
test_name: "shopping_cart_profile"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer looking to add items to your shopping cart."
  context:
    - "You may ask for various items like groceries, electronics, or clothing."
  goals:
    - "Add a {{item}} to my shopping cart."
    - item:
        function: random()
        type: string
        data: [apples, milk, laptop, shoes, book]

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you specify what item you'd like to add?"
  output:
    - added_item:
        type: string
        description: "The item that was added to the shopping cart."

conversation:
  number: 5
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - single questions
      - long phrases
```

### Summary
- **Test Name**: "shopping_cart_profile"
- **User Role**: A customer asking to add items to the cart.
- **Goals**: Randomly select items to add to the cart.
- **Chatbot Output**: The item added to the cart.
