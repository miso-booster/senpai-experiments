Let's create a rule to check if the chatbot provides information about current promotions. This rule will utilize general variables and helpers since it is not based on any specific profile.

### Rule Structure
- **Name**: `check_promotions_info`
- **Description**: This rule checks if the chatbot provides information about current promotions.
- **Conversations**: This will be set to 1, as we are examining a single conversation.
- **Oracle**: The condition will verify if the response contains keywords related to promotions.

Here’s the YAML for the rule:

```yaml
name: check_promotions_info
description: Check if the chatbot provides information about current promotions
conversations: 1
oracle: "('promotions' in chatbot_phrases) or ('discount' in chatbot_phrases) or ('offer' in chatbot_phrases)"
```

### Explanation
- **`name`**: This is the identifier for the rule.
- **`description`**: A brief overview of what the rule is checking.
- **`conversations`**: Indicates that the rule applies to a single conversation.
- **`oracle`**: This condition checks if the phrases returned by the chatbot include any mention of "promotions," "discount," or "offer," which indicates that the chatbot has provided information about current promotions.
