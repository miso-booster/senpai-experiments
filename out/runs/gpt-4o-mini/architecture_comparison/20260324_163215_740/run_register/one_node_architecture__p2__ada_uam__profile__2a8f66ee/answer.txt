That sounds like a great idea! Let's create a simple profile for an Erasmus user who needs assistance with setting up their Moodle and Sigma accounts. This profile will include the necessary chatbot outputs to ensure you can check for proper support.

Here's a sample profile you can use:

```yaml
test_name: "Erasmus User Support Profile"

llm:
  temperature: 0.7
  model: gpt-4o
  format:
    type: text

user:
  language: Spanish
  role: "Erasmus student who needs help setting up Moodle and Sigma."
  context:
    - "You have just arrived and are unfamiliar with the digital platforms."
    - "You need clear instructions on how to access and set up your accounts."
  goals:
    - "Ask for help with setting up Moodle."
    - "Request information on how to access Sigma."
    - "Inquire about any necessary credentials or links."

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me puedes repetir la pregunta con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - moodle_setup_info:
        type: string
        description: "Instrucciones para configurar la cuenta de Moodle."
    - sigma_access_info:
        type: string
        description: "Instrucciones para acceder a Sigma."
    - required_credentials:
        type: string
        description: "Credenciales necesarias para acceder a las plataformas."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

### Explanation:
- **test_name**: A descriptive name for the profile.
- **llm**: Specifies the language model settings.
- **user**: Defines the user's role, context, and goals for the conversation.
- **chatbot**: Contains fallback messages and outputs that the chatbot should provide.
- **conversation**: Sets the number of interactions and style for the conversation.
