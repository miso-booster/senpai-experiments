That sounds like a great use case for a bike shop profile! 😊 Here’s a sample profile you can use for a user who wants to get their new bike set up by changing the seat and handlebar grips.

Feel free to adjust the details as needed!

```yaml
test_name: "bike_setup_request"

llm:
  temperature: 0.6
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer who recently bought a new bike and wants it tailored to their preferences."
  context:
    - "You want to change the seat and handlebar grips of your new bike."
    - "You are looking for recommendations on the best options available."
  goals:
    - "Ask about the available seat options for comfort."
    - "Inquire about the types of handlebar grips that can be customized."
    - "Request information on the installation process for the new seat and grips."
    - "Ask for the estimated time to complete the setup."

chatbot:
  is_starter: false
  fallback: "I'm sorry, could you repeat that?"
  output:
    - seat_options:
        type: string
        description: "List of available seat options for the bike."
    - grip_options:
        type: string
        description: "List of available handlebar grip options."
    - installation_process:
        type: string
        description: "Details about the installation process for the new seat and grips."
    - setup_time:
        type: string
        description: "Estimated time to complete the setup."

conversation:
  number: 3
  goal_style:
    all_answered:
      export: true
      limit: 4
  interaction_style:
    - single question
```

This profile sets up a scenario where the user is looking for specific information about customizing their new bike. Let me know if you need any changes or additional details! 🚴‍♂️✨
