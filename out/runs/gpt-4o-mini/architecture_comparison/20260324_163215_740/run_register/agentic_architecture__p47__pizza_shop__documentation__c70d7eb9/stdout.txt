A metamorphic rule in the context of Sensei refers to a type of validation logic that checks the consistency of outputs across multiple conversations rather than just a single conversation. These rules are designed to ensure that certain properties hold true when comparing different interactions with the chatbot.

### Key Characteristics of Metamorphic Rules:
- **Cross-Conversation Validation**: Unlike standard rules that validate a single conversation's output, metamorphic rules assess the relationship between outputs from different conversations.
- **Consistency Checks**: They can check for consistency in responses, ensuring that similar inputs yield similar outputs, or that the outputs maintain certain expected relationships.
- **Use of Variables**: Metamorphic rules often reference extracted fields from multiple conversations, allowing for complex validation scenarios.

### Example Use Cases:
- Ensuring that if a user asks for the same information in different ways, the chatbot provides consistent answers.
- Verifying that the order of responses does not affect the correctness of the information provided.

These rules help enhance the robustness of the chatbot by ensuring it behaves consistently across various interactions.
