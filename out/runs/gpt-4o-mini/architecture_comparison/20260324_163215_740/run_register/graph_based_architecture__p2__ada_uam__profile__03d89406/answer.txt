test_name: "Erasmus User Setup Assistance"

        type: string

- **Test Name**: A clear identifier for the profile.
- **LLM Settings**: Configuration for the language model.
- **User Section**: Defines the user’s role and context, focusing on their needs as an Erasmus student.
- **Goals**: Specific requests for help with Moodle and Sigma.
- **Chatbot Outputs**: Fields to extract information about the setup instructions and requirements for accessing digital resources.
