Sure! To create a rule that checks if the order ID was provided by the chatbot, you can define a simple rule that verifies the presence of the `order_id` output. Here’s how you can structure it:

```yaml
name: order_id_provided
description: The chatbot must provide an order ID in the response
conversations: 1
oracle: order_id is not None
```

In this rule:

- **name**: A unique identifier for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: Set to 1, as this is a single-conversation check.
- **oracle**: This checks that the `order_id` output is not `None`, meaning it must be provided by the chatbot.
