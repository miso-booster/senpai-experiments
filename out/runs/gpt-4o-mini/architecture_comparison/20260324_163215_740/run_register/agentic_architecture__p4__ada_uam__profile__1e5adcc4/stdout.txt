He revisado la documentación sobre perfiles en el archivo `sensei-chat-guide.md`. Ahora puedo ayudarte a crear un perfil para el chatbot de la UAM que permita a los usuarios obtener soporte sobre el CAU (Centro de Atención a Usuarios). 

### Estructura del Perfil

Para este perfil, definiremos los siguientes elementos:

- **test_name**: Un nombre descriptivo para el perfil.
- **user**: Definiremos el lenguaje, el rol del usuario y los objetivos que queremos alcanzar.
- **chatbot**: Especificaremos cómo se comporta el chatbot, incluyendo la salida que queremos extraer.
- **conversation**: Controlaremos el número de interacciones y el estilo de interacción.

### Campos a Extraer

Los campos que deseas extraer son:
- Número de teléfono
- Email
- Dirección física
- Horarios

### Propuesta de YAML

Aquí tienes una propuesta de perfil en YAML:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que busca soporte sobre el CAU de la UAM."
  context:
    - "El usuario necesita información sobre contacto y horarios."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Cuál es el email del CAU?"
    - "¿Cuál es la dirección física del CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: true
  fallback: "Lo siento, no entendí tu pregunta. ¿Puedes reformularla?"
  output:
    - telefono:
        type: string
        description: "Número de teléfono del CAU."
    - email:
        type: string
        description: "Email de contacto del CAU."
    - direccion:
        type: string
        description: "Dirección física del CAU."
    - horarios:
        type: string
        description: "Horarios de atención del CAU."

conversation:
  number: 1
  goal_style:
    steps: 4
  interaction_style:
    - long phrases
```

### Resumen

- **Nombre del perfil**: Soporte CAU UAM.
- **Objetivos**: Obtener información de contacto y horarios del CAU.
- **Salida esperada**: Número de teléfono, email, dirección y horarios.
