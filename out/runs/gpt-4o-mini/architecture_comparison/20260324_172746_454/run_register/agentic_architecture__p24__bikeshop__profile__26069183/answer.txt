Great! I've loaded the relevant documentation for profiles from `sensei-chat-guide.md`. Now, let's create a profile for testing the bike shop's virtual assistant. Here's how the profile will be structured:

### Profile Structure

- **Test Name**: A descriptive name for the profile.
- **LLM Settings**: Configuration for the language model.
- **User Details**: Language, role, context, and goals.
- **Chatbot Output**: Fields to extract after the conversation.
- **Conversation Controls**: Number of interactions and styles.

### Proposed YAML Profile

```yaml
test_name: "bike_shop_virtual_assistant"

llm:
  temperature: 0.7
  model: "gpt-4"
  model_prov: "openai"
  format:
    type: text

user:
  language: English
  role: "A customer seeking general information about the bike shop and its services."
  context:
    - "The user is interested in shop hours, pricing for bike services, and basic bike maintenance advice."
  goals:
    - "What are the opening and closing times of the bike shop?"
    - "How much does a new bike tire cost?"
    - "What is the price for a standard bike tune-up?"
    - "How much for a new bike seat?"
    - "Can you give me some general advice on how to take care of my bike?"

chatbot:
  is_starter: true
  fallback: "I'm sorry, I can't help with that."
  output:
    - opening_hours:
        type: string
        description: "The shop's opening and closing times."
    - tire_price:
        type: currency
        description: "Price of a new bike tire."
    - tune_up_price:
        type: currency
        description: "Price for a standard bike tune-up."
    - seat_price:
        type: currency
        description: "Price for a new bike seat."
    - maintenance_advice:
        type: string
        description: "General advice on bike maintenance."

conversation:
  number: 5
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

### Summary of the Profile
- **Purpose**: This profile simulates a customer asking about the bike shop's services, focusing on shop hours, pricing, and basic maintenance advice.
- **Output Fields**: The output fields are designed to capture the relevant information provided by the chatbot.
