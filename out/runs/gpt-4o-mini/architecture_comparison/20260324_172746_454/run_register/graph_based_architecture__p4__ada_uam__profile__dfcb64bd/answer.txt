¡Claro! Vamos a crear un perfil para que puedas testear el chatbot de la UAM, enfocado en obtener soporte del CAU. Aquí tienes un ejemplo de cómo podría verse tu perfil en formato YAML:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita soporte del CAU."
  context:
    - "Buscas obtener información sobre el Centro de Atención a Usuarios."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico de contacto del CAU."
    - "Consultar la dirección física del CAU."
    - "Preguntar sobre los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "¿Puedes reformular tu pregunta? O consulta nuestro catálogo de servicios."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU."
    - contact_email:
        type: string
        description: "Correo electrónico de contacto del CAU."
    - physical_address:
        type: string
        description: "Dirección física del CAU."
    - operational_hours:
        type: string
        description: "Horarios de atención del CAU."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

### Explicación de cada sección:

- **test_name**: Un nombre descriptivo para el perfil.
- **llm**: Configuración del modelo de lenguaje.
- **user**: Define el usuario simulado, su rol y el contexto.
- **goals**: Las preguntas específicas que el usuario hará al chatbot.
- **chatbot**: Define cómo el chatbot debe responder y qué información debe extraer.
- **conversation**: Controla el número de interacciones y el estilo de interacción.

Puedes ajustar cualquier parte que necesites. ¡Espero que esto te ayude a comenzar! Si necesitas más cambios o ajustes, ¡solo dímelo! 😊
