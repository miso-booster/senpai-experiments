### Estructura del perfil

El perfil que vamos a crear incluirá los siguientes elementos:

- **Nombre de la prueba**: Un título para identificar el perfil.
- **Configuración del LLM**: Opciones como temperatura y modelo.
- **Usuario**: Definición del lenguaje, rol y objetivos del usuario.
- **Chatbot**: Especificaciones sobre el chatbot, incluyendo el output que deseas.
- **Conversación**: Control sobre el número de interacciones y estilo.

### YAML del perfil

Aquí tienes el perfil en formato YAML:

```yaml
test_name: "pizzeria_order_test"

llm:
  temperature: 0.7
  model: "gpt-4"
  model_prov: "openai"
  format:
    type: text

user:
  language: Spanish
  role: "Cliente que desea pedir una pizza y una bebida."
  goals:
    - "Quiero una pizza de {{tipo_pizza}} y una bebida de {{bebida}}."
    - tipo_pizza:
        function: random()
        type: string
        data: [pepperoni, margarita, cuatro quesos, vegetariana]
    - bebida:
        function: random()
        type: string
        data: [Coca-Cola, Fanta, agua, cerveza]

chatbot:
  is_starter: true
  fallback: "Lo siento, no entendí eso. ¿Podrías repetirlo?"
  output:
    - tipo_pizza:
        type: string
        description: "Tipo de pizza solicitada."
    - bebida:
        type: string
        description: "Bebida solicitada."
    - order_id:
        type: string
        description: "ID del pedido."
    - total_price:
        type: currency
        description: "Precio final en dólares."

conversation:
  number: 5
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Resumen

- **Tipo de pizza** y **bebida** se seleccionan aleatoriamente de las opciones proporcionadas.
- El **output** incluye el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares.
- El perfil está configurado para realizar 5 interacciones con un estilo de conversación aleatorio.
