Here's a profile for a pizza shop where the user is rude and demands quick service. This profile includes four goals, with two of them using pairwise functions to determine the conversation number based on a pairwise matrix.

```yaml
test_name: "pizza_shop_rude_customer"

llm:
  temperature: 0.5
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A rude customer who demands quick service."
  context:
    - "The user is impatient and often interrupts."
  goals:
    - "Order a {{size}} pizza with {{toppings}} quickly."
    - "Ask for the total price in {{currency}}."
    - "Request delivery time for the {{size}} pizza."
    - "Demand a discount for the delay."
    - size:
        function: random()
        type: string
        data: [small, medium, large]
    - toppings:
        function: pairwise()
        type: string
        data: [pepperoni, mushrooms, onions, olives]
    - currency:
        function: random()
        type: string
        data: [USD, EUR, GBP]
    - discount:
        function: pairwise()
        type: float
        data: [0, 5, 10, 15]  # Different discount options
  
chatbot:
  is_starter: true
  fallback: "What do you want? Make it quick!"
  output:
    - total_price:
        type: currency
        description: "Final price for the pizza order."
    - delivery_time:
        type: string
        description: "Estimated delivery time."
    - discount:
        type: float
        description: "Discount offered for the delay."

conversation:
  number: combinations(0.5, pairwise) # Two pairwise functions have been declared
  goal_style:
    steps: 5
  interaction_style:
    - make spelling mistakes
    - single questions
```

### Summary of the Profile:
- **Role**: The user is characterized as a rude customer who wants fast service.
- **Goals**: Four goals are defined, with two using pairwise functions to ensure a variety of combinations in the conversation.
- **Chatbot Output**: The profile specifies what outputs to extract after the conversation, including total price, delivery time, and any discounts.
- **Conversation Control**: The conversation number is determined by a combination of pairwise functions, allowing for efficient testing of different scenarios.
