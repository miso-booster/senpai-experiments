Sure! To create a rule that checks if the order ID was provided by the chatbot, you can use a simple oracle rule. Here’s how it would look in YAML format:

```yaml
name: response_contains_order_id
description: The chatbot must return an order ID in the response.
conversations: 1
oracle: |
  'order_id' in data_output
```

### Breakdown of the Rule:
- **name**: A clear name for the rule, indicating what it checks.
- **description**: A brief explanation of what the rule does.
- **conversations**: Set to 1, as this is a single-conversation check.
- **oracle**: This checks if the `order_id` is present in the chatbot's output.
