That sounds like a great profile to create! Let’s set up a user profile for someone who needs to get their new bike tailored to their preferences. Here’s a template you can use, and feel free to adjust any details as needed:

```yaml
test_name: "bike_setup_request"

llm:
  temperature: 0.6
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: "A customer who recently bought a new bike and wants to customize it."
  context:
    - "You want to change the seat and handlebar grips to better suit your preferences."
    - "You are looking for advice on the best options available."
  goals:
    - "Ask if the shop can help customize the bike."
    - "Inquire about different seat options available."
    - "Ask about handlebar grip options."
    - "Request a recommendation for the best seat for comfort."
    - "Ask about the process for getting the bike set up."

    # Variables for customization options
    - seat_type:
        function: random()
        type: string
        data: [comfort, racing, gel, leather]
    - grip_type:
        function: random()
        type: string
        data: [foam, rubber, ergonomic, leather]

chatbot:
  is_starter: false
  fallback: "I'm sorry, could you repeat that?"
  output:
    - customization_confirmation:
        type: string
        description: "Confirmation from the chatbot that they can assist with bike customization."
    - seat_options:
        type: string
        description: "Information about available seat types."
    - grip_options:
        type: string
        description: "Information about available handlebar grips."

conversation:
  number: 5
  goal_style:
    all_answered:
      export: true
      limit: 5
  interaction_style:
    - default
```

### Breakdown of the Profile:
1. **User Role & Context**: This defines who the user is and their needs.
2. **Goals**: These are the specific questions or requests the user will make during the conversation.
3. **Variables**: These allow for random selection of seat and grip types, making the conversation more dynamic.
4. **Chatbot Output**: This specifies the information the chatbot should provide in response to the user’s inquiries.
5. **Conversation Controls**: This sets the number of interactions and how the conversation should flow.
