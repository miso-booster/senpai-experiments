I've loaded the relevant documentation for creating a custom connector from the `custom-connector-guide.md` and `connector-examples.md`. Here’s how we can structure the YAML connector based on your request:

### YAML Connector Structure

```yaml
name: "Alcampo Bot"
base_url: "https://alcampo.botslovers.com/bot/web"
send_message:
  path: "/"
  method: "POST"
  headers:
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
    Accept: "*/*"
    Accept-Language: "en-US,en;q=0.9"
    Accept-Encoding: "gzip, deflate, br, zstd"
    Content-Type: "application/json"
    Origin: "https://alcampo.botslovers.com"
    Connection: "keep-alive"
    Cache-Control: "no-cache"
    Pragma: "no-cache"
  payload_template:
    data:
      id_user: "{id_user}"
      idweb_user: "{idweb_user}"
      session: "{session}"
      message:
        message:
          message:
            text: "{user_msg}"
        iduser: "{id_user}"
        session: "{session}"
        channel: "web"
      widget_form: "TRUE"
      contexto_extra: []
      lang: "es"
      accion: "response_bot"
response_path: "messages.0.0.message.text"
```

### Explanation of the Structure
- **name**: A friendly name for the connector.
- **base_url**: The base URL of the chatbot API.
- **send_message**: 
  - **path**: The endpoint path for sending messages.
  - **method**: The HTTP method used for the request (POST).
  - **headers**: Custom headers that are required for the request.
  - **payload_template**: The JSON structure that includes placeholders for dynamic values like `id_user`, `idweb_user`, `session`, and `user_msg`.
- **response_path**: The path to extract the bot's reply from the JSON response.
