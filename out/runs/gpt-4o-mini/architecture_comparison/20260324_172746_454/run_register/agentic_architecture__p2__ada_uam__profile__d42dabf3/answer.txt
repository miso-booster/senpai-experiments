### Profile Structure

Here's a brief outline of what we'll include in the profile:

- **Test Name**: A descriptive name for the profile.
- **User Language**: The language the user will communicate in.
- **User Role**: A brief description of the user's situation (an Erasmus student needing help).
- **User Goals**: Specific tasks the user wants to accomplish (e.g., setting up Moodle, asking for help with Sigma).
- **Chatbot Output**: Fields that we want to extract after the conversation for validation (e.g., confirmation of setup, links to resources).
- **Conversation Controls**: How many conversations to simulate and the interaction style.

### Proposed Profile YAML

Here's a draft of the profile based on the above structure:

```yaml
test_name: "Erasmus User Support Profile"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "An Erasmus student who has just arrived and needs help setting up Moodle and Sigma."
  context:
    - "The user is unfamiliar with the platforms and needs step-by-step guidance."
  goals:
    - "Help me set up my Moodle account."
    - "Can you guide me on how to access Sigma?"
    - "What resources are available for new students?"

chatbot:
  is_starter: true
  fallback: "I'm sorry, I didn't quite catch that. Can you ask again?"
  output:
    - setup_confirmation:
        type: string
        description: "Confirmation message about the setup process."
    - resource_links:
        type: list[string]
        description: "Links to resources for Moodle and Sigma."
    - additional_support:
        type: string
        description: "Information on further support available."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - random:
      - long phrases
      - single questions
      - make spelling mistakes
```
