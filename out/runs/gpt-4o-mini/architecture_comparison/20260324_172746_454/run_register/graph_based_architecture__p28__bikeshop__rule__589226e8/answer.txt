Absolutely! It's great that you want to ensure language consistency in your chatbot's responses. Here’s a simple rule you can use to check if the chatbot responds in the same language as the user:

```yaml
name: language_consistency
description: Assistant responds in the same language as the user
conversations: 2
when: conv[0].user_language == conv[1].user_language
oracle: responds_in_same_language() is True
```

### Breakdown of the Rule:
- **name**: This is just a title for the rule.
- **description**: A brief explanation of what the rule checks.
- **conversations**: This rule checks two conversations to compare the responses.
- **when**: This condition ensures that both conversations are in the same language.
- **oracle**: This checks that the assistant's responses are in the same language as the user.

Make sure that your SENSEI Chat profile has a field for `user_language` to make this rule work! If you need any adjustments or have more questions, feel free to ask! 😊
