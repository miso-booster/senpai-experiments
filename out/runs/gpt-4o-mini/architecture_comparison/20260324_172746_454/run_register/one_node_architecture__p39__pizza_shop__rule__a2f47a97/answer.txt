```yaml
name: drink_cost_increase
description: Adding a drink to the order should cost an additional 2 dollars
conversations: 2
when: conv[0].pizza_type == conv[1].pizza_type and conv[0].size == conv[1].size
if:   conv[0].drink is not None and conv[1].drink is None

```

- We check that both conversations have the same pizza type and size.
- We ensure that the first conversation includes a drink while the second does not.
- Finally, we assert that the price of the first conversation (with the drink) is exactly 2 dollars more than the price of the second conversation (without the drink).
