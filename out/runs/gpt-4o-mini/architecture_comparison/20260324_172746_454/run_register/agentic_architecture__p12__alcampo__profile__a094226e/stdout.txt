I've loaded the relevant documentation for profiles from `sensei-chat-guide.md`. Now, let's create a profile that asks the chatbot for items to add to the user's shopping cart.

### Profile Structure

Here's a proposed structure for the profile:

- **Test Name**: A descriptive name for the profile.
- **User Role**: Describes the simulated user's behavior and context.
- **Goals**: Specifies what the user will ask the chatbot, including variables for items to add.
- **Chatbot Output**: Defines what information will be extracted after the conversation.

### Example Profile YAML

Here's an example of how the profile could look:

```yaml
test_name: "shopping_cart_addition"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "You are a customer looking to add items to your shopping cart. Ask for various items."
  context:
    - "You prefer to shop for groceries."
  goals:
    - "Add {{item}} to my shopping cart."
    - item:
        function: random()
        type: string
        data: [milk, bread, eggs, cheese, fruits]

chatbot:
  is_starter: true
  fallback: "I'm sorry, could you please specify the item you want to add?"
  output:
    - added_item:
        type: string
        description: "The item that was added to the shopping cart."
    - confirmation_message:
        type: string
        description: "Confirmation that the item has been added."

conversation:
  number: 5
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - long phrases
      - single questions
```

### Summary of the Profile

- **Test Name**: "shopping_cart_addition" indicates the purpose of the profile.
- **User Role**: The user is a customer looking to add items to their shopping cart.
- **Goals**: The user will ask to add random grocery items to the cart.
- **Chatbot Output**: It specifies the fields to be extracted, such as the added item and a confirmation message.
