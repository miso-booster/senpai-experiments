A metamorphic rule in Sensei is a condition used to check the correctness of conversations generated by the Sensei-chat. Unlike traditional testing methods that verify absolute answers, metamorphic rules focus on the relationships between pairs or sets of conversations. This approach helps alleviate the oracle problem by asserting how outputs should change (or remain the same) when inputs are modified.

Here’s a simple breakdown of how it works:

1. **Generate Conversations**: First, you create conversations using Sensei-chat, which includes various inputs and outputs.

2. **Write Metamorphic Rules**: These rules are written in YAML format and specify:
   - How many conversations are needed for the rule (at least two for metamorphic testing).
   - Conditions to filter which conversations to compare (using the `when` clause).
   - The expected relationship between the outputs of these conversations (using `if` and `then` clauses).

3. **Evaluate the Rules**: Sensei-check evaluates these rules against the generated conversations and reports any failures.

For example, a metamorphic rule might state that if two pizzas have the same size and drink, the one with more toppings should cost more. This way, you can ensure that your chatbot behaves consistently and correctly across different scenarios! 🍕✨
