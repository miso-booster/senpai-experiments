### Profile Structure

Here's a breakdown of what we need for the profile:

- **Test Name**: A descriptive name for the profile.
- **User Details**:
  - **Language**: The language the user will communicate in.
  - **Role**: A brief description of the user’s situation.
  - **Context**: Any relevant details about the user’s preferences or constraints.
  - **Goals**: Specific goals the user wants to achieve during the conversation.
- **Chatbot Details**:
  - **Is Starter**: Whether the chatbot starts the conversation.
  - **Fallback Message**: A message the chatbot can use if it doesn't understand.
  - **Output Fields**: Fields we want to extract after the conversation.
- **Conversation Controls**: How many conversations to run and interaction styles.

### Proposed Profile YAML

Here's a proposed YAML structure for the profile:

```yaml
test_name: "Bike Shop Customization"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer who recently bought a new bike and wants to customize it."
  context:
    - "The user wants to change the seat and handlebar grips."
  goals:
    - "Request to change the seat to a more comfortable one."
    - "Ask for options for handlebar grips."
    - "Inquire about the costs for these customizations."

chatbot:
  is_starter: true
  fallback: "I'm sorry, I didn't quite catch that. Could you please repeat?"
  output:
    - seat_type:
        type: string
        description: "Type of seat chosen."
    - grip_type:
        type: string
        description: "Type of handlebar grips chosen."
    - total_cost:
        type: currency
        description: "Total cost for the customizations."

conversation:
  number: 1
  goal_style:
    steps: 3
  interaction_style:
    - random:
      - long phrases
      - single questions
```
