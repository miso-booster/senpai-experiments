Great question! 😊 In the context of Sensei, a **metamorphic rule** is a condition used to check the correctness of conversations generated by your chatbot. Unlike traditional testing methods that look for absolute correctness, metamorphic testing focuses on the relationships between pairs or sets of conversations.

Here’s how it works:

1. **Generate Conversations**: First, you create conversations using Sensei-chat, which simulate user interactions with your chatbot.

2. **Write Metamorphic Rules**: These rules are written in YAML format and specify:
   - How many conversations to compare (usually two or more).
   - Conditions that define when to apply the rule (using filters).
   - The expected relationship between the outputs of the conversations when certain inputs change.

3. **Evaluate the Rules**: Sensei-check evaluates these rules against the generated conversations and reports any failures. This helps identify inconsistencies or unexpected behaviors in your chatbot's responses.

For example, a metamorphic rule could state that if two orders have the same pizza size and drink, the one with more toppings should cost more. This way, you’re not just checking if the price is correct, but also if it follows the expected logical relationship based on the inputs.

This approach helps alleviate the oracle problem by focusing on relational properties rather than absolute correctness, making it a powerful tool for testing conversational AI! 🌟 If you have more questions or need help with specific rules, feel free to ask!
