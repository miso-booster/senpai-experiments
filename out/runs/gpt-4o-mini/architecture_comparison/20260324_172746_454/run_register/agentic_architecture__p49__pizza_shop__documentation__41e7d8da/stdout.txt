The **pairwise function** in the context of SENSEI rules is part of the **metamorphic testing** approach used to validate conversational correctness across multiple conversations. Here's a breakdown of how it works:

### Overview of Pairwise Function
- **Purpose**: The pairwise function allows you to compare pairs (or tuples) of conversations to assert how outputs should change (or remain the same) when inputs change. This helps in alleviating the oracle problem by checking relationships instead of absolute answers.
  
### Key Components
1. **Conversation Generation**: Conversations are generated using SENSEI Chat, which includes inputs (like pizza size) and outputs (like price).
  
2. **Rule Definition**: In SENSEI-check, you define rules in YAML that specify:
   - How many conversations are needed for the check.
   - An optional filter (`when`) to select eligible conversations.
   - The relationship to check between the outputs of the selected conversations.

3. **Evaluation**: The rules are evaluated, and any failing cases are reported. The evaluation checks whether the conditions specified in the rules hold true for the pairs of conversations.

### Example of a Pairwise Rule
Here's a simple example of a metamorphic rule that checks the relationship between the number of toppings and the price of a pizza:

```yaml
name: toppings_monotonicity
description: More toppings increase the price of a pizza (same size and drink)
conversations: 2
when: conv[0].size == conv[1].size and conv[0].drink == conv[1].drink
if:   len(conv[0].toppings) > len(conv[1].toppings)
then: extract_float(conv[0].price) > extract_float(conv[1].price)
```

### Explanation of the Example
- **Conversations**: This rule requires two conversations to be evaluated.
- **When Condition**: It checks that both conversations are for the same size and drink.
- **If Condition**: It asserts that if the first conversation has more toppings than the second, then...
- **Then Condition**: The price of the first pizza should be greater than the price of the second.

### Conclusion
The pairwise function is a powerful tool in SENSEI-check that allows for robust testing of conversational systems by ensuring that relationships between inputs and outputs are maintained across different scenarios. This method helps in identifying inconsistencies and improving the overall quality of the chatbot's responses.
