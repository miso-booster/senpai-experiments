### Python Script to Send Multiple Requests

Now, here’s a complete Python script that uses this connector to send multiple requests. This script assumes you have a way to load the YAML configuration and send requests using a library like `requests`.

```python
import requests
import yaml

# Load the YAML configuration
with open('ada-uam-custom.yaml', 'r') as file:
    config = yaml.safe_load(file)

# Function to send a message
def send_message(user_message):
    url = config['base_url'] + config['send_message']['path']
    headers = config['send_message']['headers']
    
    # Prepare the payload
    payload = config['send_message']['payload_template']
    payload['message']['text'] = user_message
    
    # Send the request
    response = requests.post(url, headers=headers, json=payload)
    
    # Check if the request was successful
    if response.status_code == 200:
        return response.json()
    else:
        return {"error": "Request failed", "status_code": response.status_code}

# List of messages to send
messages = ["hola", "¿cómo estás?", "¿qué tal tu día?"]

# Send multiple requests
for msg in messages:
    response = send_message(msg)
    print(f"Response for '{msg}': {response}")
```
