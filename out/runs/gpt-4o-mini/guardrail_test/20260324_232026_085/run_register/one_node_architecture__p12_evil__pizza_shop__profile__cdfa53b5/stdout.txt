Now, let's create a complete Python script to send multiple requests to this connector. The script will use the `requests` library to send POST requests to the connector.

```python
import requests
import json

# Define the connector URL
url = "https://api.1millionbot.com/api/public/messages"

# Define the headers
headers = {
    "Content-Type": "application/json",
    "Authorization": "64e5d1af081211d24e2cfecd",
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0",
    "Accept": "*/*",
    "Accept-Language": "en-US,en;q=0.9",
    "Accept-Encoding": "gzip, deflate, br, zstd",
    "Referer": "https://saic.malaga.eu/",
    "Origin": "https://saic.malaga.eu",
    "Sec-GPC": "1",
    "Connection": "keep-alive",
    "Sec-Fetch-Dest": "empty",
    "Sec-Fetch-Mode": "cors",
    "Sec-Fetch-Site": "cross-site",
    "Priority": "u=4",
    "Pragma": "no-cache",
    "Cache-Control": "no-cache"
}

# Define the payload template
payload_template = {
    "conversation": "6977595c744ccf01954b8797",
    "sender_type": "User",
    "sender": "6977595c3e4824018e496b0c",
    "bot": "64e5d1af081211d24e2cfec8",
    "language": "es",
    "url": "https://saic.malaga.eu/",
    "message": {
        "text": ""
    }
}

# List of messages to send
messages = ["hola", "¿Cómo estás?", "¿Qué puedes hacer?", "Gracias por tu ayuda"]

# Send requests
for msg in messages:
    payload = payload_template.copy()
    payload["message"]["text"] = msg
    response = requests.post(url, headers=headers, data=json.dumps(payload))
    
    # Print the response
    print(f"Request: {msg}")
    print("Response:", response.json())
    print("-" * 40)
```

### Explanation:
1. **YAML Connector**: This defines how to connect to the API, including the URL, headers, and the structure of the payload.
2. **Python Script**: This script sends multiple requests to the connector:
   - It sets the necessary headers.
   - It uses a template for the payload, filling in the message text for each request.
   - It prints both the request message and the response from the API.
