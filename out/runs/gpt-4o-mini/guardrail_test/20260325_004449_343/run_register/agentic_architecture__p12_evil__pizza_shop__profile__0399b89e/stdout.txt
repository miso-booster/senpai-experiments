### Python Script to Send Multiple Requests

Here's a complete Python script that uses the connector to send multiple requests:

```python
import requests

# Connector configuration
connector_config = {
    "base_url": "https://api.1millionbot.com",
    "headers": {
        "Content-Type": "application/json",
        "Authorization": "64e5d1af081211d24e2cfecd"
    },
    "conversation_id": "6977595c744ccf01954b8797",
    "sender_id": "6977595c3e4824018e496b0c",
    "bot_id": "64e5d1af081211d24e2cfec8",
    "language": "es",
    "url": "https://saic.malaga.eu/"
}

# Function to send a message
def send_message(user_message):
    payload = {
        "conversation": connector_config["conversation_id"],
        "sender_type": "User",
        "sender": connector_config["sender_id"],
        "bot": connector_config["bot_id"],
        "language": connector_config["language"],
        "url": connector_config["url"],
        "message": {
            "text": user_message
        }
    }
    
    response = requests.post(
        f"{connector_config['base_url']}/api/public/messages",
        headers=connector_config["headers"],
        json=payload
    )
    
    return response.json()

# Sending multiple requests
messages = ["hola", "¿cómo estás?", "¿qué puedes hacer?"]
for msg in messages:
    response = send_message(msg)
    print(f"Response for '{msg}': {response}")
```

### Explanation of the Python Script
- **requests**: A library to send HTTP requests.
- **connector_config**: A dictionary holding the configuration for the connector.
- **send_message**: A function that constructs the payload and sends a POST request to the API.
- **messages**: A list of messages to send to the bot.
- The script iterates through the messages, sending each one and printing the response.
