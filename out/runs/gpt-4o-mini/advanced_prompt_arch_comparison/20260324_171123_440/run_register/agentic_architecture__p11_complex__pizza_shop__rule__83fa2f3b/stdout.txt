- **size**: Different sizes of pizza (small, medium, big, extra large).
- **toppings**: List of toppings (cheese, mushrooms, pepperoni).

### Rule 1: More Toppings Cost More
```yaml
name: more_toppings_cost_more
description: Adding more toppings to a custom pizza cost more
active: True
conversations: 2
when: conv[0].size == conv[1].size and conv[0].drink == conv[1].drink
if:   len(conv[0].toppings) > len(conv[1].toppings)
then: extract_float(conv[0].price) > extract_float(conv[1].price)
```

- **Conclusion**: This rule will work correctly with the profile since it uses the `size`, `drink`, and `price` fields defined in the profile's `chatbot.output`.
