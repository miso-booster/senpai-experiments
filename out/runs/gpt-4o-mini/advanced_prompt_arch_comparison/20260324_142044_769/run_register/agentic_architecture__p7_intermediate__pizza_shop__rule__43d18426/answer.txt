### Rule Overview
The rule **`same_number_of_toppings_cost_the_same`** checks if pizzas with the same number of toppings cost the same. Here’s how it works:

- **Condition**: It compares two conversations (let's call them `conv[0]` and `conv[1]`).
- It checks if:
  - Both pizzas are the same size.
  - Both pizzas have the same number of toppings.
- **Action**: If both conditions are true, it verifies that the prices of the two pizzas are equal.

The rule needs the following fields:
- `conv[0].size`
