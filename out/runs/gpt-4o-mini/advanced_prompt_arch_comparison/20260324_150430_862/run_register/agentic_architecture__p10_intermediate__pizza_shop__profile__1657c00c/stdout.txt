Here’s a comparison of the connectors that use **1millionbot** against a non-1millionbot connector:

### 1millionbot Connectors

1. **Ada UAM**
   - **Base URL:** `https://api.1millionbot.com`
   - **Send Message Endpoint:**
     - **Path:** `/api/public/messages`
     - **Method:** `POST`
     - **Headers:**
       - `Content-Type: application/json`
       - `Authorization: 60a3bee2e3987316fed3218f`
     - **Payload Template:**
       - `conversation`: `682ce1ce271ce860cffde0fd`
       - `sender_type`: `User`
       - `sender`: `682ce1cefe831160cee700ed`
       - `bot`: `60a3be81f9a6b98f7659a6f9`
       - `language`: `es`
       - `url`: `https://www.uam.es/uam/tecnologias-informacion/servicios-ti/acceso-remoto-red`
       - `message.text`: `{user_msg}`
   - **Response Path:** `response.0.text`

### Non-1millionbot Connector

2. **Postman Echo**
   - **Base URL:** `https://postman-echo.com`
   - **Send Message Endpoint:**
     - **Path:** `/post`
     - **Method:** `POST`
     - **Payload Template:**
       - `message`: `{user_msg}`
   - **Response Path:** `json.message`

### Differences

| Feature                | Ada UAM (1millionbot)                       | Postman Echo (Non-1millionbot)          |
|-----------------------|---------------------------------------------|------------------------------------------|
| **Base URL**          | `https://api.1millionbot.com`              | `https://postman-echo.com`              |
| **Send Message Path** | `/api/public/messages`                      | `/post`                                   |
| **Method**            | `POST`                                      | `POST`                                    |
| **Headers**           | `Content-Type: application/json` <br> `Authorization: 60a3bee2e3987316fed3218f` | None                                     |
| **Payload Template**  | Multiple fields including `conversation`, `sender`, `bot`, `language`, and `url` | Single field `message`                   |
| **Response Path**     | `response.0.text`                           | `json.message`                           |

### Summary of Differences
- **Base URL** and **Send Message Path** are specific to the 1millionbot API.
- **Headers**: The Ada UAM connector requires specific headers for content type and authorization, while the Postman Echo connector does not require any headers.
- **Payload Structure**: The Ada UAM connector has a more complex payload structure with multiple fields, whereas the Postman Echo connector only requires a single field for the message.
- **Response Path**: The response paths are different, reflecting the structure of the responses from each API.
