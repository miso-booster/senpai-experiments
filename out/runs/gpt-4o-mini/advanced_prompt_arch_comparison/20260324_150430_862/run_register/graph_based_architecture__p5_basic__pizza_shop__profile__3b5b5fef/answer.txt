The connector that uses the 1millionbot API is:

- **Ada UAM**
  - **Base URL:** `https://api.1millionbot.com`
  - **Response Path:** `response.0.text`
  - **Send Message Configuration:** 
    - **Method:** POST
    - **Path:** `/api/public/messages`
    - **Headers:** 
      - `Authorization: 60a3bee2e3987316fed3218f`
      - `Content-Type: application/json`
    - **Payload Template:** 
      - Includes fields like `bot`, `conversation`, `language`, and `message`.
