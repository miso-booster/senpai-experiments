### Rule Summary
The rule **"same_number_of_toppings_cost_the_same"** checks that pizzas with the same number of toppings and size have the same price. Here's how it works:

- **Condition**: It compares two conversations (like two orders).
  - It checks if both orders have the same drink.
  - It checks if both orders have the same size of pizza.
  - It checks if both orders have the same number of toppings.
  
- **Action**: If all those conditions are true, it expects that the prices of both pizzas are the same.
