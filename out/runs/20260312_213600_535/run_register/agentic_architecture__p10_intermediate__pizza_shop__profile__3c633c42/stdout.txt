Here are the details of the connectors that use **1millionbot** and their endpoints, compared against a non-1millionbot connector:

### 1millionbot Connectors

1. **Connector: Ada UAM**
   - **Base URL:** `https://api.1millionbot.com`
   - **Send Message Endpoint:**
     - **Path:** `/api/public/messages`
     - **Method:** `POST`
     - **Headers:**
       - `Content-Type: application/json`
       - `Authorization: 60a3bee2e3987316fed3218f`
     - **Payload Template:**
       ```json
       {
         "conversation": "682ce1ce271ce860cffde0fd",
         "sender_type": "User",
         "sender": "682ce1cefe831160cee700ed",
         "bot": "60a3be81f9a6b98f7659a6f9",
         "language": "es",
         "url": "https://www.uam.es/uam/tecnologias-informacion/servicios-ti/acceso-remoto-red",
         "message": {
           "text": "{user_msg}"
         }
       }
       ```
   - **Response Path:** `response.0.text`

### Non-1millionbot Connector

2. **Connector: Echo Bot**
   - **Base URL:** `https://postman-echo.com`
   - **Send Message Endpoint:**
     - **Path:** `/post`
     - **Method:** `POST`
     - **Payload Template:**
       ```json
       {
         "message": "{user_msg}"
       }
       ```
   - **Response Path:** `json.message`

### Differences

- **Base URL:**
  - **Ada UAM:** Uses `https://api.1millionbot.com`
  - **Echo Bot:** Uses `https://postman-echo.com`

- **Send Message Endpoint:**
  - **Ada UAM:** 
    - **Path:** `/api/public/messages`
    - **Headers:** Includes `Content-Type` and `Authorization`
    - **Payload Template:** More complex, includes conversation ID, sender details, bot ID, language, URL, and message text.
  - **Echo Bot:** 
    - **Path:** `/post`
    - **Headers:** No headers specified.
    - **Payload Template:** Simpler, only includes a single message field.

- **Response Path:**
  - **Ada UAM:** `response.0.text`
  - **Echo Bot:** `json.message`

### Summary
The **1millionbot** connector (Ada UAM) is more complex, requiring specific headers and a detailed payload structure, while the non-1millionbot connector (Echo Bot) is simpler and does not require additional headers.
