¡Perfecto! Aquí tienes la regla para asegurarnos de que el bot de Ada UAM siempre devuelva el email, el teléfono y la dirección física del CAU 😊:

```yaml
name: cau_contact_info_complete
description: El CAU debe proporcionar correo, teléfono y dirección física
conversations: 1
oracle: all(value is not None and isinstance(value, str) and value.strip() != '' for value in [contact_email, contact_phone, physical_address])
on-error: f"Faltan datos de contacto: {[name for name, value in {'contact_email': contact_email, 'contact_phone': contact_phone, 'physical_address': physical_address}.items() if value is None or str(value).strip() == '' ]}"
```

Si necesitas ajustarla a otro perfil o añadir validaciones extra (como patrones de formato para el correo o el teléfono), me dices y lo vemos juntos.
