Here’s a complete `chatbot` section you can drop into your profile:

```yaml
chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't catch that. Could you rephrase your question about our menu or services?"
  output:
    - pizza_options:
        type: list[string]
        description: "Pizza varieties the bot confirms are available."
    - margarita_price:
        type: string
        description: "Price the bot quotes for a Margarita pizza."
    - drink_options:
        type: list[string]
        description: "Drinks the bot lists as available."
    - drink_prices:
        type: list[string]
        description: "Pricing details the bot provides for each drink."
    - operating_hours:
        type: string
        description: "Shop opening and closing hours mentioned by the bot."
    - delivery_available:
        type: string
        description: "Delivery availability information, including any conditions."
```

**Why these fields?** Following the guidance in `sensei-chat-guide.md`, the `chatbot.output` section acts as the contract between this profile and any future rules. Each field corresponds to the information your user wants (pizza variety, prices, drinks, hours, delivery), and I used standard types (`string` / `list[string]`) so you don’t have to rely on custom type files unless you want them later.

Feel free to tweak field names or descriptions to match any rules you plan to write, but this should give you a solid starting point for validating the bot’s answers. If you’d like to collect extra details (e.g., delivery fees), just add more entries under `output`. Let me know if you want help with that too! 😊
