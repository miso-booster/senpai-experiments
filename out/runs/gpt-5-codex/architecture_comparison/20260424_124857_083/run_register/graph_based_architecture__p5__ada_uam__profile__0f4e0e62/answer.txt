¡Hola! 😊 Aquí tienes un perfil Sensei listo para poner a prueba al chatbot de la UAM cuando alguien busca los datos de contacto del CAU. Incluye todas las metas necesarias y los campos de salida para extraer teléfono, correo, dirección y horario de atención.

```yaml
test_name: "Consulta de contacto CAU"

llm:
  model: gpt-4o-mini
  model_prov: openai
  temperature: 0.5
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita contactar al Centro de Atención a Usuarios (CAU) de la UAM."
  context:
    - "Has tenido algunos inconvenientes con tus servicios digitales y necesitas comunicarte directamente con el CAU."
    - "Quieres recopilar toda la información de contacto posible para decidir el mejor canal."
  goals:
    - "Solicitar el número de teléfono del CAU para recibir asistencia."
    - "Pedir la dirección de correo electrónico del CAU para enviar una consulta."
    - "Preguntar por la ubicación física del CAU para acudir en persona."
    - "Preguntar por el horario de atención en el que responde el CAU."

chatbot:
  is_starter: false
  fallback: "¿Podrías reformular tu pregunta? También puedes consultar el catálogo de servicios del CAU."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico de contacto del CAU"
    - physical_location:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horario de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 20
  interaction_style:
    - single questions
  max_cost: 0.4
```

💡 Puedes guardarlo, por ejemplo, en `profiles/consulta_contacto_cau.yaml` dentro de tu proyecto Sensei y ya estará listo para ejecutarse. Si necesitas ajustarlo (otra personalidad, más objetivos, etc.), dime y lo mejoramos juntos.
