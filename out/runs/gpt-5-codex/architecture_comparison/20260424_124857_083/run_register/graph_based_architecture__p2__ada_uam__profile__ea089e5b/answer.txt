¡Listo! Aquí tienes un perfil diseñado para simular a un estudiante Erasmus recién llegado que necesita soporte para poner en marcha Moodle, Sigma y otros servicios clave. Mantiene las entradas sencillas (sin variables) pero incluye un bloque de `chatbot.output` bien nutrido para validar que el bot entregue toda la ayuda necesaria.

```yaml
test_name: "Estudiante Erasmus - Configuración inicial"

llm:
  temperature: 0.6
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are an Erasmus exchange student who just arrived at the university.
    Your Spanish is limited, so you prefer receiving explanations in English.
    You need clear guidance to get all the digital platforms working before classes start.
  context:
    - personality: personalities/curious-user
    - "You have never used the university's systems (ID-UAM, Moodle, Sigma, email, VPN) before."
    - "You are anxious about missing deadlines because you can’t access the platforms yet."
  goals:
    - "Ask for step-by-step instructions to activate my institutional credentials and log into Moodle."
    - "Request guidance on how to access Sigma for course registration and academic records."
    - "Check how to set up the university email and whether it is required before other platforms."
    - "Ask for instructions to connect to the campus Wi-Fi and VPN from my laptop."
    - "Confirm the contact channels for technical support if something fails."

chatbot:
  is_starter: false
  fallback: "Sorry, could you rephrase that? You can also visit our service catalogue."
  output:
    - credential_activation_steps:
        type: string
        description: "Instructions to activate institutional credentials / ID-UAM"
    - moodle_setup_steps:
        type: string
        description: "Steps to access and configure Moodle for the first time"
    - sigma_access_instructions:
        type: string
        description: "Guidance for signing into Sigma and finding enrolment features"
    - email_configuration_info:
        type: string
        description: "How to activate and use the institutional email account"
    - wifi_and_vpn_setup:
        type: string
        description: "Steps for campus Wi-Fi configuration and VPN access from personal devices"
    - multilingual_support_options:
        type: string
        description: "Information about support availability in English or other languages"
    - technical_support_contacts:
        type: list[string]
        description: "Contact channels (email, phone, helpdesk links) for technical assistance"

conversation:
  number: 3
  goal_style:
    steps: 24
  interaction_style:
    - single questions
```

Si quieres ajustarlo (por ejemplo, cambiar el idioma base o añadir alguna variable para rotar entre tipos de dispositivos), dime y lo afinamos sin problema 😊.
