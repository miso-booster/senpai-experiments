¡Perfecto! Aquí tienes un perfil listo para ejecutar pruebas sobre el chatbot de la UAM centrado en la atención del CAU. Espero que te sea útil 😊

```yaml
test_name: "Consulta de contacto del CAU"

llm:
  temperature: 0.6
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Persona que necesita contactar con el Centro de Atención a Usuarios (CAU) de la UAM para resolver dudas técnicas."
  context:
    - personality: personalities/formal-user
    - "Tu objetivo es ponerte en contacto con el CAU para resolver incidencias relacionadas con los servicios digitales de la universidad."
    - "Necesitas confirmar los canales oficiales de contacto antes de llamar o enviar un correo."
  goals:
    - "Solicitar el número de teléfono oficial del CAU."
    - "Pedir la dirección de correo electrónico del CAU para soporte."
    - "Preguntar por la dirección física donde se ubica el CAU."
    - "Solicitar el horario de atención del CAU para saber cuándo contactar."

chatbot:
  is_starter: false
  fallback: "¿Puedes preguntármelo de otra forma? o, si lo prefieres, puedes consultar nuestro catálogo de servicios. Respondo a preguntas dirigidas al Centro de Atención a Usuarios del servicio de Tecnologías de la Información."
  output:
    - cau_phone_number:
        type: string
        description: "Número de teléfono del CAU"
    - cau_email_address:
        type: string
        description: "Correo electrónico del CAU"
    - cau_physical_location:
        type: string
        description: "Dirección física del CAU"
    - cau_opening_hours:
        type: string
        description: "Horario de atención del CAU"

conversation:
  number: 3
  max_cost: 0.4
  goal_style:
    steps: 16
  interaction_style:
    - single questions
```

Si necesitas ajustar algo más (más variables, otro estilo de interacción, etc.), dime y le damos una vuelta juntos 🙌
