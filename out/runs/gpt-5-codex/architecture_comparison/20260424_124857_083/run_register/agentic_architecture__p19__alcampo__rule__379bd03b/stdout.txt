Here you go! This rule is profile-agnostic and just checks the assistant’s messages for common promotion-related keywords, so it can be reused across any profile.

```yaml
name: promotion_info_present
description: Ensures the chatbot mentions current promotions or equivalent deals
conversations: 1
active: true
oracle: |
  bool(chatbot_returns('promotion')) or
  bool(chatbot_returns('deal')) or
  bool(chatbot_returns('offer')) or
  bool(chatbot_returns('discount'))
yields: |
  f"No promotion-related information found in assistant replies: {chatbot_phrases}"
```

**Why this works**

- Relies on the generic `chatbot_returns` helper described in `sensei-check-doc.md`, so no `chatbot.output` fields are needed.
- Mirrors the pattern shown in `rules-examples.md` for checking keyword presence, keeping the rule simple and general-purpose.
