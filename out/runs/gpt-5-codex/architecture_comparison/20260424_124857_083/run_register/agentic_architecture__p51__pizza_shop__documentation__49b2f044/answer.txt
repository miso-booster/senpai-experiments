¡Hola! Los conectores en SENSEI sirven como “puentes” entre el simulador de Chatbot Dojo y el API real de tu bot. Básicamente, describen en un archivo YAML cómo debe realizarse la petición HTTP para enviar cada mensaje del usuario al servicio externo, y dónde encontrar dentro de la respuesta JSON la contestación que debe recibir el simulador. Así puedes probar cualquier chatbot sin escribir código adicional.

Según la documentación (`custom-connector-guide.md` y `connector-examples.md`), los campos clave de un conector son:

1. **`name`** (opcional): un nombre amigable para identificar el bot.
2. **`base_url`** (obligatorio): la URL base del API del chatbot.
3. **`send_message`** (bloque obligatorio) que define cómo se envía cada mensaje:
   - **`path`** (obligatorio): el endpoint que se añade al `base_url`.
   - **`method`** (opcional, por defecto `POST`): el verbo HTTP.
   - **`headers`** (opcional): cabeceras personalizadas, como tokens de autenticación.
   - **`payload_template`** (obligatorio): el cuerpo JSON que se manda en cada request. Debe incluir `{user_msg}` como marcador para el mensaje del usuario.
4. **`response_path`** (obligatorio): una ruta con notación de puntos que indica dónde está el texto de la respuesta dentro del JSON devuelto por el API (por ejemplo, `response.0.text`).

Con ese esquema, cada vez que el simulador necesite hablar con tu chatbot, construirá la petición siguiendo esa plantilla y extraerá la respuesta usando `response_path`. ¡Y listo! 😊
