Here’s a simple Sensei-check rule that verifies the assistant mirrors the user’s language. It uses the built-in `responds_in_same_language()` helper, so it doesn’t depend on any profile-specific outputs.

```yaml
name: same_language_responses
description: Ensures the assistant replies in the same language the user used
conversations: 1
oracle: responds_in_same_language() is True
on-error: "Assistant drifted from the user's language in conversation {conversation_id}."
```

### How it works
- **`conversations: 1`** — evaluates each dialogue individually.
- **`responds_in_same_language()`** — returns `True` when the assistant’s replies match the user’s language throughout the conversation.
- **`on-error`** (optional but handy!) — gives you a friendly hint in the report when the rule fails.

Just drop this YAML file into your Sensei-check rules directory, and you’ll start catching language mismatches right away. Let me know if you’d like to tweak the error message or make it language-specific! 🌍
