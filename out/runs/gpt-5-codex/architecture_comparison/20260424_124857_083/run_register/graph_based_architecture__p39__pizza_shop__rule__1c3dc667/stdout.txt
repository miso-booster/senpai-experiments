Sure thing! Here’s a metamorphic rule named **“drink”** that checks whether adding a drink to an otherwise identical pizza order bumps the price by exactly \$2.

It assumes that the profile uses the string `"none"` in `chatbot.output.drink` when the customer skips drinks. If your profile uses a different marker (like `""`, `"no drink"`, or `null`), just tweak the `if:` condition accordingly.

```yaml
name: drink
description: Adding a drink to the same pizza order should increase the price by exactly $2
conversations: 2
when: conv[0].size == conv[1].size and conv[0].toppings == conv[1].toppings
if: (conv[0].drink == 'none' and conv[1].drink != 'none') or (conv[1].drink == 'none' and conv[0].drink != 'none')
then: abs(extract_float(conv[0].price) - extract_float(conv[1].price)) == 2
```

Feel free to ping me if you’d like to handle other sentinel values for “no drink” or add currency checks too. Happy testing! 🥤🍕
