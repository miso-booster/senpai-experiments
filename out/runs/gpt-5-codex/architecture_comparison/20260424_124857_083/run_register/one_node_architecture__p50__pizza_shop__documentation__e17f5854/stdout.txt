Hey there! 👋 In the Sensei rules world, an **oracle** is simply the condition that determines whether a conversation (or set of conversations) passes the rule you’ve written. It’s the logical statement Sensei-check evaluates using the extracted data from your chat logs.

In practice:

- For **single-conversation rules**, the `oracle:` field holds a boolean expression that must be `True` for the conversation to pass.
- For **metamorphic rules**, you often see the pair `if:` and `then:` instead of a single `oracle:`—but the idea is the same: you’re describing what should hold true given certain conditions across conversations.

Think of the oracle as your mini “truth test” that Sensei runs after each batch of simulated chats. If the oracle fails, Sensei reports the rule as violated.

Hope that clears it up! Let me know if you want to see a concrete example 😊
