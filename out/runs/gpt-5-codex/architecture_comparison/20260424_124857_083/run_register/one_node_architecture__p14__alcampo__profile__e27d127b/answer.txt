¡Claro que sí! Aquí tienes un perfil listo para poner a prueba las recomendaciones de recetas y la planificación de menús del chatbot de Alcampo 😊👇

```yaml
test_name: "recipe_and_menu_planning_support"

llm:
  temperature: 0.6
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres una persona que busca inspiración culinaria y quiere organizar menús semanales equilibrados
    con ayuda del chatbot de Alcampo.
  context:
    - personality: personalities/conversational-user
    - "Has decidido planificar tus comidas de la semana para ahorrar tiempo y comer de forma saludable."
    - "Quieres aprovechar ingredientes frescos y productos disponibles en Alcampo."
    - "Te interesa adaptar las recetas a diferentes preferencias alimentarias."
  goals:
    - "Solicita sugerencias de recetas equilibradas para {{meal_moment}}."
    - "Pide un plan de menú para {{menu_days}} días, incluyendo variedad entre las comidas."
    - "Pregunta por sustituciones recomendadas para una dieta {{dietary_preference}}."
    - "Consulta los ingredientes clave necesarios para preparar platos con {{main_ingredient}}."
    - "Pide consejos para preparar con antelación y conservar los platos durante la semana."
    - meal_moment:
        function: forward()
        type: string
        data:
          - desayuno
          - comida
          - cena
    - menu_days:
        function: forward()
        type: int
        data:
          - 3
          - 5
          - 7
    - dietary_preference:
        function: forward()
        type: string
        data:
          - vegetariana
          - sin gluten
          - baja en carbohidratos
    - main_ingredient:
        function: forward()
        type: string
        data:
          - pollo
          - legumbres
          - verduras de temporada

chatbot:
  is_starter: false
  fallback: "Parece que tu mensaje no está claro o no está relacionado con Alcampo. 😊 ¿En qué puedo ayudarte hoy con tus recetas o menús?"
  output:
    - recommended_recipes:
        type: list[string]
        description: Lista de recetas sugeridas por el chatbot
    - menu_plan_overview:
        type: string
        description: Resumen del plan de menú propuesto
    - shopping_list_items:
        type: list[string]
        description: Ingredientes o productos recomendados para comprar
    - substitution_suggestions:
        type: string
        description: Sugerencias de sustituciones para preferencias dietéticas
    - prep_ahead_tips:
        type: string
        description: Consejos para preparar platos con antelación y conservarlos
    - nutritional_guidance:
        type: string
        description: Orientación nutricional o equilibrio del menú

conversation:
  number: 4
  max_cost: 0.6
  goal_style:
    steps: 26
  interaction_style:
    - long phrases
    - random:
        - make spelling mistakes
        - change language:
            - inglés
            - francés
```
