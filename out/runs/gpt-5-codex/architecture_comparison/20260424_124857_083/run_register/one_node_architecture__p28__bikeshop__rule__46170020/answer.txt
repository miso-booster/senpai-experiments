Absolutely! Here’s a rule you can drop straight into your `rules/` folder to make sure each conversation stays in the user’s language:

```yaml
name: chatbot_responds_in_same_language
description: Ensures the chatbot replies in the same language as the user
conversations: 1
oracle: responds_in_same_language()
```

This global rule uses the built-in `responds_in_same_language()` helper, so it doesn’t rely on any specific profile fields—perfect for covering all your profiles at once. Let me know if you’d like it tweaked (e.g., custom error messaging or activation flags)! 😊
