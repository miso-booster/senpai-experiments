Looks like that bot expects the same structure as the 1millionbot APIs (very similar to the `Ada UAM` example). I’ve adjusted the connector so it sends the required fields and reads the reply from the right spot. Give this version a try:

```yaml
name: "Connector"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

This mirrors the working request you captured (same endpoint, headers, and payload keys) and pulls the assistant’s text from `response[0].text`, which is where the API places it. Let me know if you need to make any of those IDs dynamic!
