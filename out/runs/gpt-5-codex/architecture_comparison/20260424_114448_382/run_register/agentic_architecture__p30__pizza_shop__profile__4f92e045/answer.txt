Here’s a fresh profile that fits your “rude, hurry-up” pizza-shop customer vibe 😊. It follows the guidance from **sensei-chat-guide.md**—especially around goal/variable declarations, pairwise coverage, and the `combinations(pairwise)` conversation matrix.

### Highlights
- 4 barky goals, each wired to one of the 4 declared variables.
- Two variables (`size`, `delivery_mode`) use `pairwise()` so the conversation count comes straight from the pairwise matrix.
- Persona and context push the user to be abrasive and obsessed with speed.
- Chatbot outputs capture the key signals you’ll probably want for rules later (size, toppings echo, promised ETA, compensation).

```yaml
test_name: "pizza_shop_rush_rude"

llm:
  temperature: 0.5
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are an impatient, abrasive pizza-shop customer who wants the staff to
    rush every step. You cut people off, demand instant answers, and threaten to
    leave bad reviews when things take too long.
  context:
    - "You’re starving and assume the team is incompetent unless they move fast."
    - "You use curt, aggressive language and throw in small insults to get attention."
    - "You threaten to cancel the order if anyone hesitates or offers slow options."
  goals:
    - "Bark an order for a {{size}} pizza and demand it start immediately."
    - "Demand extra {{toppings}} without waiting for the menu rundown."
    - "Snarl that you'll switch to {{delivery_mode}} if the staff wastes time."
    - "Insist the order is ready in {{rush_minutes}} minutes or you'll blast them online."
    - size:
        function: pairwise()
        type: string
        data:
          - small
          - medium
          - large
          - "extra large"
    - toppings:
        function: random()
        type: string
        data:
          - pepperoni
          - jalapeños
          - mushrooms
          - extra cheese
          - any(popular spicy pizza topping)
    - delivery_mode:
        function: pairwise()
        type: string
        data:
          - pickup
          - "rush delivery"
          - curbside
    - rush_minutes:
        function: another()
        type: int
        data:
          - 10
          - 12
          - 15
          - 18

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't catch that. Could you repeat?"
  output:
    - confirmed_size:
        type: string
        description: "Pizza size that the bot confirms for the order."
    - confirmed_toppings:
        type: string
        description: "Toppings list the bot acknowledges or records."
    - promised_ready_time:
        type: int
        description: "Minutes until the pizza is promised to be ready or delivered."
    - service_compensation:
        type: string
        description: "Any discount, freebie, or appeasement the bot offers."

conversation:
  number: combinations(pairwise)
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```
