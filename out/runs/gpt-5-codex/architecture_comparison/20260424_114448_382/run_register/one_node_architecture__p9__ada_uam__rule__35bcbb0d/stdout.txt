```yaml
name: biblioteca_horario_9_a_20
description: Verifica que el horario de la biblioteca indique apertura de 9:00 a 20:00 (perfil Préstamos y Recursos de la Biblioteca)
conversations: 1
when: library_hours not in [None, '']
oracle: semantic_content(library_hours, 'La biblioteca abre de 9:00 a 20:00.')
```

Esta regla se aplica cuando el campo `library_hours` existe y no está vacío; luego usa `semantic_content` para asegurarse de que el texto comunique ese horario específico. ¡Listo para que lo añadas a tu suite de reglas! 📚✨
