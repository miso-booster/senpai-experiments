- **Objetivos del usuario**: cada meta fuerza al bot a entregar teléfono, email, dirección y horarios. La variable `relacion_con_uam` (función `another()`) introduce diversidad sin complicar demasiado el set de conversaciones, cumpliendo lo sugerido en la guía sobre variabilidad controlada.
- **`chatbot.output`**: definí los cuatro campos que luego podrás validar con reglas (`conv[i].telefono_cau`, etc.). Están tipados como `string`, tal como permite el doc, aunque puedes migrar a tipos personalizados si luego quieres validar formatos (teléfono, email…).
- **`conversation.goal_style`**: uso `all_answered` para asegurar que la simulación se mantenga hasta que todos los objetivos hayan sido cubiertos (tal y como recomienda la guía cuando necesitamos respuestas completas).
- **`interaction_style`**: añadí `long phrases` y `make spelling mistakes` para estresar un poco al bot. Puedes quitarlos o sumar otros estilos si necesitas pruebas más limpias.
