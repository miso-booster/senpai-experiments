¡Perfecto! Aquí tienes un perfil listo para simular a un usuario que pide al chatbot del CAU la info de contacto clave 📞📧🏢🕒:

```yaml
test_name: "Soporte CAU - Información de Contacto"

llm:
  model: gpt-4o-mini
  temperature: 0.6
  format:
    type: text

user:
  language: Spanish
  role: "Eres un usuario que necesita contactar al Centro de Atención a Usuarios (CAU) de la UAM para resolver dudas técnicas."
  context:
    - "Necesitas confirmar los métodos de contacto disponibles del CAU."
    - "Quieres poder llamar, escribir por correo y acercarte en persona si es necesario."
    - "También deseas conocer el horario oficial de atención para organizar tu consulta."
  goals:
    - "Solicitar el número de teléfono del CAU para comunicar un problema técnico."
    - "Pedir la dirección de correo electrónico del CAU para enviar una consulta."
    - "Preguntar por la dirección física del CAU en caso de necesitar atención presencial."
    - "Solicitar los horarios de atención al público del CAU."

chatbot:
  is_starter: false
  fallback: "¿Puedes reformular tu consulta? También puedes revisar nuestro catálogo de servicios para más información."
  output:
    - cau_phone_number:
        type: string
        description: "Número de teléfono oficial del CAU."
    - cau_email_address:
        type: string
        description: "Correo electrónico de contacto del CAU."
    - cau_physical_address:
        type: string
        description: "Dirección física del CAU."
    - cau_service_hours:
        type: string
        description: "Horarios de atención del CAU."

conversation:
  number: 3
  max_cost: 0.4
  goal_style:
    steps: 20
  interaction_style:
    - single questions
```
