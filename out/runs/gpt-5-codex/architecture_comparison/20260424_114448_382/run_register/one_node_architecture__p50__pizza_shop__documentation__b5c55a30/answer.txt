Great question! In Sensei Rules, an **oracle** is the condition you write inside a rule to express what “should be true” for the conversations that get checked. Think of it as the pass/fail test: if the oracle evaluates to `True`, the rule passes; if it evaluates to `False`, the rule fails and Sensei will report it.

Here’s a simple example from the docs:

```yaml
name: chatbot_fills_all_slots
description: All conversation slots are filled
conversations: 1
oracle: data_collected() == True
```

In this rule, the oracle `data_collected() == True` ensures the chatbot filled every slot we expected. You can also pair an oracle with helper functions, comparisons, or even string checks—anything that returns a boolean.

So whenever you see the `oracle:` field in a rule, that’s the heart of your check 💡.
