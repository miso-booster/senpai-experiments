Sure thing! 😊 Since this profile is all about gathering menu and service info, we’ll want the `chatbot` section to capture:

1. **Whether the bot starts the convo** (`is_starter`)
2. **Its fallback reply** (so Sensei knows how to detect misunderstandings)
3. **Which specific pieces of info we want extracted at the end** (the `output` schema)

Here’s a ready-to-drop-in `chatbot` block that matches your goals:

```yaml
test_name: pizza_and_drinks_information_seeker
llm:
  format:
    type: text
  model: gpt-4o-mini
  temperature: 0.3
user:
  language: English
  role: "A customer seeking information about pizza types, prices, available drinks, and shop hours before potentially placing an order."
  context:
    - "personality: personalities/skeptical-user"
    - "You're planning a casual pizza night at home with friends this weekend and are considering ordering from a local pizzeria."
    - "You want to gather all the necessary information before deciding what to order and whether to pick it up or have it delivered."
    - "You have a variety of preferences among your friends, so you need to find options that cater to different tastes."
  goals:
    - "Ask about the available pizza types."
    - "Ask about the price of a Margarita pizza."
    - "Ask about the available drinks and their prices."
    - "Ask about the shop's operating hours."
    - "Ask if they deliver."
chatbot:
  is_starter: false
  fallback: "I'm sorry, I did not get what you said. I can help you ordering predefined or custom pizzas, and then drinks.\nFor troubleshooting, visit: https://python.langchain.com/docs/troubleshooting/errors/OUTPUT_PARSING_FAILURE"
  output:
    - pizza_types:
        type: string
        description: "A list of the pizza types offered by the shop."
    - margarita_price:
        type: money
        description: "The price of a Margarita pizza. Capture all sizes mentioned."
    - drinks_and_prices:
        type: string
        description: "Available drinks with their corresponding prices."
    - operating_hours:
        type: string
        description: "Opening and closing times of the shop."
    - delivery_availability:
        type: string
        description: "Whether the shop offers delivery or not."
conversation:
  number: 3
  max_cost: 0.5
  goal_style:
    all_answered:
      export: false
      limit: 20
  interaction_style:
    - single questions
```

These output fields line up one-to-one with the questions in `user.goals`, so Sensei will be able to extract the answers cleanly after each conversation. Let me know if you’d like to adjust the types (e.g., use a custom type) or add more fields! 🍕✨
