Hey there! Thanks for sharing your rule 😊. I spotted a couple of little hiccups, so I tweaked things to make it behave exactly the way you described.

### What was wrong
1. **Metamorphic config for no reason** – you set `conversations: 2` but never compare `conv[0]` and `conv[1]`. Since you only want to verify one conversation at a time, `conversations: 1` is better.
2. **`then` needs a boolean expression** – Sensei-check expects an expression that evaluates to `True`/`False`, not a plain string like `"The tune-up price is $50."`.

### Polished version
Here’s the corrected rule:

```yaml
name: check_tune_up_price
description: Verifies the tune-up price is exactly $50 USD.
conversations: 1
if: tune_up_price is not None
then: extract_float(tune_up_price) == 50 and currency(tune_up_price) == 'USD'
```

### What changed
- Switched to a single-conversation rule.
- Replaced the string in `then` with a boolean check using `extract_float` (to read the number) and `currency` (to make sure it’s in USD).
- Dropped the unused `when:` clause since it wasn’t doing anything.

If your `tune_up_price` output is already a plain number (e.g., `50`), you can simplify the `then:` line to just `tune_up_price == 50`. Let me know if you’d like that version instead!
