To make sure the chatbot mirrors the user’s language, you can lean on the built-in helper `responds_in_same_language()`. It works great for profile-agnostic rules and checks that the assistant’s replies match the user’s language within each conversation.

Here’s a ready-to-use Sensei-check rule:

```yaml
name: same_language_reply
description: Assistant should answer in the same language the user uses
conversations: 1
oracle: responds_in_same_language() is True
```

**How it works:**  
- `responds_in_same_language()` compares the detected language of the user turns vs. the assistant turns in that conversation.  
- If any mismatch pops up, the rule fails — super handy for catching accidental language switches!
