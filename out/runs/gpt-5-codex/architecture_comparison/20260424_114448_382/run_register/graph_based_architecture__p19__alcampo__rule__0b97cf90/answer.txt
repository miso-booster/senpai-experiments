Aquí tienes una regla global (sin depender de ningún perfil) que comprueba que, cuando la persona usuaria pregunta por promociones, el chatbot le dé información sobre ellas 😊:

```yaml
name: current_promotions_info
description: Si el usuario pregunta por promociones, el asistente debe mencionar las promociones vigentes.
conversations: 1
if: utterance_index('user','promotion') >= 0 or utterance_index('user','discount') >= 0 or utterance_index('user','deal') >= 0
then: any(len(chatbot_returns(term)) > 0 for term in ['promotion','discount','deal','offer'])
on-error: "El asistente no mencionó promociones tras la solicitud del usuario."
```

**Cómo funciona:**

- `if:` detecta si la persona usuaria preguntó por “promotion”, “discount” o “deal”.
- `then:` exige que el asistente devuelva al menos una respuesta con alguno de esos términos (añadí “offer” como comodín extra).
- `on-error:` ofrece un mensajito útil cuando la condición no se cumple.
