Sure thing! Since your profiles expose an `order_id` field in `chatbot.output`, you can write a simple single-conversation rule that fails whenever that slot is missing or empty. Here’s a ready-to-use example:

```yaml
name: order_id_provided
description: The chatbot must return a non-empty order_id.
conversations: 1
oracle: order_id is not None and len(str(order_id).strip()) > 0
on-error: f"Order ID missing or empty. Current value: {order_id}"
```

This rule becomes applicable in any conversation where that `order_id` slot should be filled. If the chatbot forgets to supply it (or returns only whitespace), the rule will flag it right away. 😊
