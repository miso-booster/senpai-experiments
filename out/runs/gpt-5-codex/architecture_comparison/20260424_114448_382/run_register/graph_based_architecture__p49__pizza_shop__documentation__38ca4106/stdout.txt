The `pairwise()` function in Sensei profiles is all about getting smart coverage of variable combinations without exploding the number of conversations you have to run.

### What `pairwise()` actually does
- When you assign `pairwise()` to **two or more variables** inside `user.goals`, Sensei builds a set of conversations so that **every possible pair of values** across those variables appears at least once.
- It’s much more efficient than generating every single combination (like nested `forward()` would). You still touch every pairing that could reveal a defect, but with far fewer test runs.

### Things to remember
- Make sure you apply `pairwise()` to **at least two variables** in the same goal block—otherwise Sensei can’t build the pairing matrix.
- Once you have two pairwise variables, you can use `conversation.number: combinations` (or a percentage like `combinations(0.6, pairwise)`) to tell Sensei to actually run the pairwise matrix it generated.
- If you mix `pairwise()` with other functions (like `forward()` or `another()`), that’s totally fine, as long as each variable uses the function that best matches the coverage you want.

### Quick, friendly example
Imagine a pizza profile where you want to cover:
- `pizza_type` (`pairwise()`)
- `pizza_size` (`pairwise()`)

Sensei will create conversations so that every `pizza_type/pizza_size` pair appears somewhere, but it won’t repeat unnecessary combos. That keeps the test suite compact and still precise. 🍕
