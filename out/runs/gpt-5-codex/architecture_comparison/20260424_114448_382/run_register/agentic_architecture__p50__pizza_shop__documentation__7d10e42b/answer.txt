Great question! In Sensei-check, an **oracle** is simply the boolean condition that decides whether a conversation (or a set of conversations) passes the rule.

- When you write a rule, the `oracle:` field contains a Python-like expression that must evaluate to `True` for the rule to pass.  
- If you prefer an implication style, you can use the `if:`/`then:` fields instead, but they’re just a more structured way of expressing the same idea—an expected relation that should hold.

So, in practice, the oracle is your “truth test” for the scenario the rule targets. This is described in the Sensei-check rules guide (`sensei-check-doc.md`) where it shows examples like:

```yaml
oracle: extract_float(price) >= 10
```

or, for metamorphic checks over multiple conversations, something like:

```yaml
then: extract_float(conv[0].price) > extract_float(conv[1].price)
```
