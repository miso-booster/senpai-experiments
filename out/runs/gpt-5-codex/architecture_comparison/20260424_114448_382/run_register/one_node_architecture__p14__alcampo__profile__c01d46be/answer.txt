¡Perfecto! Aquí tienes un perfil listo para poner a prueba las recomendaciones de recetas y la planificación de menús del chatbot de Alcampo 😊👇

```yaml
test_name: "Recipe Recommendations and Menu Planning"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres una persona que planifica cuidadosamente sus comidas semanales
    y desea recibir recomendaciones personalizadas de recetas y menús
    equilibrados para toda la semana.
  context:
    - Buscas recetas que se ajusten a un estilo de vida saludable y a tus preferencias alimentarias.
    - Quieres optimizar el tiempo en la cocina sin sacrificar variedad ni sabor.
    - Necesitas sugerencias que se adapten a un presupuesto concreto y que faciliten la lista de la compra.
  goals:
    - "Pide al chatbot sugerencias de recetas que encajen con una alimentación {{diet_preference}}."
    - "Solicita un plan de menú semanal que cubra {{meals_per_day}} comidas al día, incluyendo desayunos, comidas y cenas."
    - "Pregunta por los ingredientes esenciales de cada receta y las posibles sustituciones disponibles."
    - "Solicita una lista de la compra agrupada por secciones del supermercado."
    - "Pide consejos para optimizar el tiempo de preparación y aprovechar restos de comida."
    - "Pregunta por información nutricional relevante y recomendaciones para mantener el equilibrio del menú."
    - diet_preference:
        function: forward()
        type: string
        data: [vegetariana, mediterránea, alta en proteínas]
    - meals_per_day:
        function: forward(diet_preference)
        type: int
        data:
          min: 2
          max: 3
          step: 1

chatbot:
  is_starter: false
  fallback: "Parece que tu mensaje no es claro o no es una pregunta relacionada con Alcampo. 😊 ¿En qué puedo ayudarte hoy? Estoy aquí para resolver tus dudas sobre nuestros productos y servicios."
  output:
    - recipe_recommendations:
        type: list[string]
        description: Lista de recetas sugeridas por el chatbot para la semana
    - menu_plan:
        type: string
        description: Resumen del plan de menú semanal propuesto
    - grocery_list:
        type: list[string]
        description: Lista de la compra organizada por secciones
    - ingredient_substitutions:
        type: string
        description: Sugerencias de sustituciones para ingredientes clave
    - nutritional_guidance:
        type: string
        description: Recomendaciones nutricionales relevantes para el menú
    - prep_strategies:
        type: string
        description: Consejos para optimizar tiempos de preparación y aprovechar sobras
    - estimated_total_budget:
        type: money
        description: Presupuesto estimado para el menú semanal
    - time_saving_tips:
        type: string
        description: Recomendaciones adicionales para ahorrar tiempo en la cocina

conversation:
  number: combinations
  max_cost: 0.6
  goal_style:
    steps: 26
  interaction_style:
    - long phrases
    - change your mind
```
