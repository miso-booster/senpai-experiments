¡Hola! Aquí tienes un perfil listo para ejecutar pruebas con un usuario que busca los datos de contacto del CAU. 😊

```yaml
test_name: "Consulta de contacto del CAU"

llm:
  model: gpt-4o-mini
  temperature: 0.6
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres un miembro de la comunidad universitaria que necesita contactar al Centro
    de Atención a Usuarios (CAU) para resolver dudas urgentes.
  context:
    - "Valoras respuestas claras y concretas sobre cómo ponerte en contacto con el CAU."
    - "Dispones de poco tiempo y necesitas confirmar los canales oficiales de comunicación."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir la dirección de correo electrónico oficial del CAU."
    - "Preguntar por la ubicación física del CAU."
    - "Solicitar los horarios de atención del CAU."
    - "Confirmar si existe alguna recomendación adicional para contactar con el CAU."

chatbot:
  is_starter: false
  fallback: "¿Podrías formular tu pregunta de otra manera? También puedes consultar nuestro catálogo de servicios."
  output:
    - cau_phone_number:
        type: string
        description: "Número de teléfono del CAU"
    - cau_email_address:
        type: string
        description: "Correo electrónico oficial del CAU"
    - cau_physical_location:
        type: string
        description: "Dirección física del CAU"
    - cau_opening_hours:
        type: string
        description: "Horarios de atención al público del CAU"
    - additional_contact_notes:
        type: string
        description: "Recomendaciones adicionales para contactar con el CAU"

conversation:
  number: 3
  goal_style:
    steps: 8
  interaction_style:
    - single questions
  max_cost: 0.4
```
