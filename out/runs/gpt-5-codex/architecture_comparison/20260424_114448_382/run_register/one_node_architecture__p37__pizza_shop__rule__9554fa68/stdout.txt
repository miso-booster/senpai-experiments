¡Claro! Aquí tienes una regla que verifica que, cuando el perfil `pizzaorder_ivan_test` obtiene la confirmación del pedido, el texto incluya la bebida seleccionada. Así podemos detectar si el asistente realmente confirmó que añadió la bebida solicitada. 😊

```yaml
name: drink_confirmation_in_order_summary
description: The assistant confirms that the requested drink was added to the order
conversations: 1
when: selected_drink_type is not None and pizza_order_confirmation
oracle: selected_drink_type.lower() in pizza_order_confirmation.lower()
on-error: >
  f"The assistant did not mention the drink '{selected_drink_type}' in the confirmation: {pizza_order_confirmation}"
```
