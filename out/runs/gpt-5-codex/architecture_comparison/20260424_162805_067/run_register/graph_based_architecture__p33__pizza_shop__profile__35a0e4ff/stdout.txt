For the `chatbot` section you’ll want two things:

1. **`fallback`** – what the simulator assumes the bot will say when it can’t understand the user.  
2. **`output`** – the fields you want Sensei to extract from the conversation transcript. These fields later feed into Sensei-check rules or any post-run analysis.

Since this profile is about gathering menu and service info, here’s a `chatbot` block tailored to those goals:

```yaml
test_name: pizza_and_drinks_information_seeker

llm:
  model: gpt-4o-mini
  temperature: 0.3
  format:
    type: text

user:
  language: English
  role: A customer seeking information about pizza types, prices, drinks, and delivery options before ordering.
  context:
    - You're planning a pizza night with friends and want to explore the menu first.
    - You need details about pricing, operating hours, and whether delivery is available.
  goals:
    - Ask about the available pizza types.
    - Ask for the price of a Margarita pizza.
    - Ask about the available drinks and their prices.
    - Ask about the shop's operating hours.
    - Ask if the shop offers delivery service.

chatbot:
  is_starter: false
  fallback: >
    I'm sorry, I did not get what you said. I can help you ordering predefined or
    custom pizzas, and then drinks.
  output:
    - pizza_types:
        type: string
        description: >
          A list of the pizza types offered by the shop. Look for phrases like "We
          offer [pizza types]" or a list of available pizzas.
    - margarita_price:
        type: money
        description: >
          The price of a Margarita pizza. Extract the price, including currency if
          present. If multiple sizes are mentioned, capture all prices mentioned.
    - drinks_and_prices:
        type: string
        description: >
          A list of available drinks and their prices. Include the drink name and the
          corresponding price.
    - operating_hours:
        type: string
        description: >
          The shop's operating hours, including opening and closing times.
    - delivery_availability:
        type: string
        description: >
          Whether the shop offers delivery. Look for clear statements such as "We deliver"
          or "We do not offer delivery."

conversation:
  number: 3
  max_cost: 0.5
  goal_style:
    all_answered:
      export: false
      limit: 20
  interaction_style:
    - single questions
```

Just drop this under your `chatbot:` key and you’ll be all set. If you’d like to adjust the fallback message or add more output fields later, you can tweak it anytime. Let me know if you’d like help validating the full profile or aligning it with any Sensei-check rules! 🍕✨
