Absolutely! Since this check doesn’t depend on any specific profile outputs, it can be written as a general Sensei-check rule using the built-in `responds_in_same_language()` helper. Drop the YAML below into your `rules/` folder and you’re set 😊

```yaml
name: chatbot_responds_in_same_language
description: Ensures the assistant matches the user’s language in every conversation
conversations: 1
oracle: responds_in_same_language()
on-error: "Assistant reply language mismatch detected."
```
