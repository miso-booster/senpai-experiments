Hey! I noticed the original rule referenced `user_request`, but that field isn’t part of your profile’s `chatbot.output`, so Sensei-check couldn’t evaluate it. Here’s a cleaned-up single-conversation rule that simply verifies the bot fills both contact slots each time 💪

```yaml
name: customer_service_contact_info
description: Ensure the chatbot provides contact options and the customer service number.
conversations: 1
oracle: (
  contact_options is not None and contact_options.strip() != ''
) and (
  customer_service_number is not None and customer_service_number.strip() != ''
)
```
