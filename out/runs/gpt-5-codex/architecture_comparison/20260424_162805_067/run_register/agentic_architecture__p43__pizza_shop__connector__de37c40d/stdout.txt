¡Listo! Tomando como referencia `custom-connector-guide.md` y `connector-examples.md`, ajusté el conector para que coincida exactamente con la request/response que compartiste. Con este YAML, el body enviado será `{"message":{"text":"…"}}` y el bot responderá usando la ruta `response.text`.

```yaml
name: "Test Connector 2"
base_url: "https://api.anotherexample.com"
send_message:
  path: "/api/chat"
  method: "POST"
  headers:
    Content-Type: "application/json"
  payload_template:
    message:
      text: "{user_msg}"
response_path: "response.text"
```

Haz una prueba rápida con `CustomChatbot` y deberías recibir `¡Hola! ¿Cómo puedo ayudarte hoy?`. Si tu API requiere cabeceras adicionales (por ejemplo, autenticación), solo añádelas bajo `headers`. ¡Cuéntame si necesitas algo más! 😊
