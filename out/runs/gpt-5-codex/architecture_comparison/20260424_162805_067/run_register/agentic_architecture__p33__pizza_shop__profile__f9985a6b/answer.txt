Here’s a `chatbot` block you can drop straight into your profile 😊. I designed the outputs so you can later write rules that check every goal you listed—this follows the guidance from `sensei-chat-guide.md` about making `chatbot.output` the contract between the profile and rules.

```yaml
chatbot:
  is_starter: false
  fallback: "Sorry, I didn't catch that—could you rephrase?"
  output:
    - pizza_options:
        type: list[string]
        description: "List of pizza varieties the bot mentions."
    - margherita_price:
        type: currency
        description: "Quoted price for a Margherita pizza."
    - drink_options:
        type: list[string]
        description: "Available drinks together with any prices provided."
    - operating_hours:
        type: string
        description: "Shop opening and closing hours."
    - delivery_details:
        type: string
        description: "Delivery availability and any related conditions or fees."
```

**Why these fields?**
- `pizza_options` captures every pizza type the bot lists, matching your first goal.
- `margherita_price` uses the `currency` type so future rules can parse the amount cleanly.
- `drink_options` lets you store both drink names and their prices as free-form strings.
- `operating_hours` keeps opening/closing times together.
- `delivery_details` records whether delivery is offered plus any extra info.
