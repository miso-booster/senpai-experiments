```yaml
name: customer_service_contact_info
description: Ensures contact options mention the same customer service number surfaced in a dedicated request.
conversations: 2
when: conv[0].user_request == 'contact options' and conv[1].user_request == 'customer service number'
if: str(conv[0].contact_options).strip() not in ['None', ''] and str(conv[1].customer_service_number).strip() not in ['None', '']
then: str(conv[1].customer_service_number) in str(conv[0].contact_options)
on-error: f"Contact options {conv[0].contact_options} do not mention the number {conv[1].customer_service_number}"
```
