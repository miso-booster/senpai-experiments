¡Hola! Para armar bien el perfil necesito un par de detalles:

1. ¿En qué idioma debería hablar el usuario simulado?
2. ¿Qué tipo de artículos quiere agregar al carrito (por ejemplo, comestibles, electrónicos, ropa)?
3. ¿Hay algún campo específico que necesitemos extraer del chatbot al final? (por ejemplo, lista de ítems, total estimado, disponibilidad)
4. ¿Tienes un mensaje de fallback que use tu bot cuando no entiende algo?
5. ¿Algún estilo de interacción preferido (hacer muchas preguntas, cometer errores ortográficos, etc.) o número de conversaciones que quieras generar?

Con eso puedo dejar el perfil bien definido. 😊
