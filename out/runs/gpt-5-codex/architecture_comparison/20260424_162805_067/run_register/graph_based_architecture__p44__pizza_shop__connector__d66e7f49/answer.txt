¡Genial! Ya que el chatbot del Ayuntamiento de Morón de la Frontera usa la misma API de MillionBot, solo necesitamos ajustar los identificadores y encabezados. Aquí tienes el conector listo para usar 🐔✨

```yaml
name: "Morón de la Frontera"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "65ca19e7dbbb4e26cbeadf28"
  payload_template:
    conversation: "67ea76f4e213b2dcbc146e2b"
    sender_type: "User"
    sender: "67ea76f40643a3dd27e59411"
    bot: "65ca19e7dbbb4e26cbeadf24"
    language: "es"
    url: "https://www.morondelafrontera.es/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

### Pasos rápidos para ponerlo en marcha
1. Guarda este YAML (por ejemplo, como `moron-ayuntamiento.yml`) en tu carpeta de conectores.
2. Cárgalo desde la interfaz o añade la ruta al config donde uses tus conectores.
3. ¡Haz una prueba con un mensaje (“hola”, “¿dónde pago el IBI?”…) y comprueba que responde!

Si ves que el bot devuelve su respuesta en otro campo o formato, dime y lo ajustamos al vuelo. Estoy aquí para ayudarte 😄
