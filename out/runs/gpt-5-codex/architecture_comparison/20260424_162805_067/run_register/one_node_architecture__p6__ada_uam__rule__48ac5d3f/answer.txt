¡Genial! Aquí tienes una regla sencilla que asegura que el conector de Ada UAM complete los datos clave del CAU (correo, teléfono y dirección). Solo verifica que los campos no estén vacíos 😊.

```yaml
name: cau_contact_details_complete
description: Verifica que el bot proporcione correo, teléfono y dirección física del CAU
conversations: 1
oracle: |
  contact_email is not None and contact_email.strip() \
  and contact_phone is not None and contact_phone.strip() \
  and physical_address is not None and physical_address.strip()
on-error: |
  f"Faltan datos de contacto del CAU. Email: {contact_email!r}, Teléfono: {contact_phone!r}, Dirección: {physical_address!r}"
```
