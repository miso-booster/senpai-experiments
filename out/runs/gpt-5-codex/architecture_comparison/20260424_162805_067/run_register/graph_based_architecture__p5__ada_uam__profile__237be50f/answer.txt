¡Perfecto! Aquí tienes un perfil Sensei listo para probar al chatbot de la UAM con un usuario que busca los datos de contacto del CAU. Incluí los campos clave que mencionaste (teléfono, correo, ubicación y horario) dentro de `chatbot.output` para que luego puedas validarlos con reglas o inspeccionarlos en los resultados 👀

```yaml
test_name: "Consulta de contacto del CAU"

llm:
  temperature: 0.5
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita obtener los datos de contacto del Centro de Atención a Usuarios (CAU) de la UAM."
  context:
    - "Necesitas comunicarte con el CAU para resolver una incidencia técnica urgente."
    - "Prefieres confirmar todos los canales de contacto disponibles antes de llamar."
    - "Quieres asegurarte de que el horario de atención se ajusta a tu disponibilidad."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir la dirección de correo electrónico del CAU para recibir asistencia."
    - "Preguntar la ubicación física del CAU para acudir en persona si es necesario."
    - "Confirmar el horario de atención del CAU."

chatbot:
  is_starter: false
  fallback: "¿Podrías reformular tu pregunta? También puedes consultar nuestro catálogo de servicios."
  output:
    - cau_phone_number:
        type: string
        description: "Número de teléfono oficial del CAU"
    - cau_email_address:
        type: string
        description: "Correo electrónico de contacto del CAU"
    - cau_physical_location:
        type: string
        description: "Dirección física del CAU"
    - cau_service_hours:
        type: string
        description: "Horario de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 12
  interaction_style:
    - single questions
  max_cost: 0.4
```

Si quieres ajustarlo (por ejemplo, añadir una personalidad específica o ampliar los objetivos), dime y lo adaptamos enseguida 😊
