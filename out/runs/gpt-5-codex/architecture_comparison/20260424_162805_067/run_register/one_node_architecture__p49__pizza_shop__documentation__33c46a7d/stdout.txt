### Pairwise in a nutshell  
The `pairwise()` function lives inside a Sensei profile’s `user.goals` section. Its mission: **generate conversation scenarios that cover every pair of values across selected variables**, without exploding into every possible combination.

Think of it like planning outfits:
- Full Cartesian combos would make you try *every shirt with every pair of pants and every pair of shoes* (huge wardrobe chaos 😅).
- `pairwise()` ensures that **every shirt is tried with every pair of pants at least once, every shirt with every pair of shoes, and every pants-shoes pair**, but you don’t repeat unnecessary mixes. Maximum coverage, minimal fatigue!

### How you use it
1. Pick **two or more goal variables** that you want to mix smartly.
2. Set each variable’s `function: pairwise()`.  
   They must be in the same logical “group” (i.e., declared in the same `goals` list).
3. Sensei then builds a conversations matrix that covers every value pair across those variables **at least once**.

### Example snippet
```yaml
- pizza_size:
    function: pairwise()
    type: string
    data: [small, medium, large]

- crust_type:
    function: pairwise()
    type: string
    data: [thin, regular, deep dish]

- delivery_option:
    function: pairwise()
    type: string
    data: [pickup, delivery]
```
With `pairwise()`, Sensei will schedule enough conversations so that:
- every size pairs with every crust at least once,
- every size pairs with every delivery option,
- every crust pairs with every delivery option.

You might run ~5 or 6 cases instead of 3 × 3 × 2 = 18 😎.

### Bonus tips
- Pairwise needs **at least two variables** using it; otherwise Sensei can’t build meaningful pairs.
- You can mix `pairwise()` with `forward()` or others, but it works best when its variables are aligned (no conflicting dependencies).
- If you set `conversation.number: combinations` or `combinations(<fraction>, pairwise)`, Sensei will base the total run count on the pairwise matrix it generates.

Hope that gives you a feel for how clever `pairwise()` is! Let me know if you want to see the resulting combination table or combine it with other functions.
