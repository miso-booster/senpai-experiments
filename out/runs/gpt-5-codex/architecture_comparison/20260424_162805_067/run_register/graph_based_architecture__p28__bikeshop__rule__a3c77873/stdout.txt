Hey there! 😊 Absolutely, we can catch that with a simple Sensei-check rule using the built-in helper `responds_in_same_language()`. It’s perfect for ensuring the assistant mirrors the user’s language in each dialogue.

Here’s a ready-to-drop YAML snippet:

```yaml
name: same_language_responses
description: Assistant replies in the same language as the user.
conversations: 1
oracle: responds_in_same_language() is True
on-error: "Assistant language drift detected. Please verify the conversation."
```

**How it works:**
- `conversations: 1` tells Sensei-check to inspect each conversation individually.
- `responds_in_same_language()` returns `True` only when every assistant message matches the language of the corresponding user message.
- The optional `on-error` message gives you a friendly heads-up if a conversation fails the rule.

Drop this into your ruleset, and you’ll be alerted anytime your chatbot slips into the wrong language. Let me know if you’d like to extend this for specific locales or add exceptions! 🌍✨
