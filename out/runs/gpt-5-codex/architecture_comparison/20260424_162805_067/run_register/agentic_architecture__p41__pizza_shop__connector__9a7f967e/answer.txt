Aquí tienes el conector listo para usar 😊. Seguí las pautas de `custom-connector-guide.md` y los ejemplos de `connector-examples.md` para estructurarlo con el `payload_template` y el `response_path` correctos.

```yaml
name: "Alcampo Botslovers Connector"
base_url: "https://alcampo.botslovers.com"
send_message:
  path: "/bot/web"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Accept: "*/*"
    Origin: "https://alcampo.botslovers.com"
    Referer: "https://alcampo.botslovers.com/Admin/Widget?mobile=0&user=0&lang=es"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
  payload_template:
    accion: "response_bot"
    data:
      id_user: "377611"
      idweb_user: "ea38fe92-ad92-4610-9d62-ef7fecb1679b"
      session: "729745848fcf76b3a49c2e2c4e6f2d5e"
      message:
        message:
          message:
            text: "{user_msg}"
        iduser: "377611"
        session: "729745848fcf76b3a49c2e2c4e6f2d5e"
        channel: "web"
      widget_form: "TRUE"
      contexto_extra: []
      lang: "es"
response_path: "messages.0.0.message.text"
```

El campo `response_path` toma la primera respuesta del bot (`messages -> 0 -> 0 -> message -> text`), y el `payload_template` conserva todos los parámetros fijos del request original, dejando `{user_msg}` como el punto donde se inyecta el mensaje del usuario. Si necesitas ajustar sesiones o IDs en el futuro, basta con actualizar esos valores en la plantilla. ¡Listo para probarlo! 🚀
