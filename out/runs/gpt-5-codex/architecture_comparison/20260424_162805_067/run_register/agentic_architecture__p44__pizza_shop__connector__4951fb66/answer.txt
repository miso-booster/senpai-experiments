¡Listo! Aquí tienes el conector adaptado para el chatbot del Ayuntamiento de Morón de la Frontera:

```yaml
name: "Gallo Morón"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "65ca19e7dbbb4e26cbeadf28"
  payload_template:
    conversation: "67ea76f4e213b2dcbc146e2b"
    sender_type: "User"
    sender: "67ea76f40643a3dd27e59411"
    bot: "65ca19e7dbbb4e26cbeadf24"
    language: "es"
    url: "https://www.morondelafrontera.es/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

### Resumen
- Partí del conector de ejemplo de MillionBot y actualicé los valores de `Authorization`, `conversation`, `sender`, `bot` y `url` según los datos de la petición que compartiste.
- Mantuve el mismo `response_path` (`response.0.text`), ya que la respuesta del API sigue el mismo formato anidado.
- Referencias utilizadas: `custom-connector-guide.md` y `connector-examples.md`, que confirman la estructura de YAML y el ejemplo original de MillionBot.

Si necesitas añadir más cabeceras opcionales (como `User-Agent` o `Referer`) o ajustar algún identificador en el futuro, dime y te ayudo encantado 😊.
