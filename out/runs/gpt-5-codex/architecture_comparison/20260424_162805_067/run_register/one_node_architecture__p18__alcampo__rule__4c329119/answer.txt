¡Claro! Aquí tienes una regla que comprueba que el campo `eco_friendly_toys` devuelva al menos dos juguetes eco-friendly separados por comas o saltos de línea:

```yaml
name: eco_friendly_toys_list_present
description: Verifica que el campo eco_friendly_toys contenga una lista con al menos dos juguetes eco-friendly.
conversations: 1
when: eco_friendly_toys is not None
oracle: len([item.strip('•- ').strip() for item in eco_friendly_toys.replace(';', ',').replace('\n', ',').split(',') if item.strip('•- ').strip()]) >= 2
on-error: f"No se detectó una lista de juguetes eco-friendly en eco_friendly_toys: {eco_friendly_toys}"
```
