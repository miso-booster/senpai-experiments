Hey there! 😊 In Sensei, a **metamorphic rule** is a check you define in **Sensei-check** (the rule engine) to compare how the chatbot behaves across **multiple conversations at once**. Instead of judging each conversation in isolation, the rule looks at relationships:

- You define how many conversations it needs (e.g., 2, 3, or “all”).
- You optionally filter which conversations to compare using `when:`.
- Then you specify a relation—usually via `if:` / `then:` or a single `oracle:` expression—that must hold between those conversations.

The goal is to capture logical expectations like “if we order the same pizza but add extra toppings, the price shouldn’t go down” or “similar inputs should produce answers in the same language.” This makes it a powerful way to ensure consistency and detect regressions without needing exact expected outputs for every single case.
