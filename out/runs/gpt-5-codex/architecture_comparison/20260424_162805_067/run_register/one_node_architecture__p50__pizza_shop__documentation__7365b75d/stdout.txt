Great question! In Sensei-check rules, an **oracle** is simply the condition that must be true for the rule to pass. Think of it like the “truth detector” for that rule 😊.  

When you write a rule in YAML, the `oracle:` field holds a Python-style expression that gets evaluated over the conversation data (for single-conversation rules) or over multiple conversations (for metamorphic rules). If the oracle expression returns `True`, the rule passes; if it returns `False`, the rule fails.

For example:

```yaml
oracle: data_collected() == True
```

This oracle says, “All required slots must be filled.” If any slot is missing, the oracle evaluates to `False`, and the rule fails.

So, in short: an oracle is the condition that tells Sensei whether the chatbot behaved as expected. It’s the core logic you’re testing!
