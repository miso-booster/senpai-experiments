```yaml
name: small_pizza_price_is_10
description: Small pizzas must cost exactly $10
active: true
conversations: 1
when: size == 'small'
oracle: extract_float(price) == 10 and currency(price) == 'USD'
```

Drop this into a new rule file (for example, `rules/small_pizza_price_is_10.yaml`) and you’re good to go. Let me know if you’d like a variant that allows a tolerance or handles missing currency indicators! 😊
