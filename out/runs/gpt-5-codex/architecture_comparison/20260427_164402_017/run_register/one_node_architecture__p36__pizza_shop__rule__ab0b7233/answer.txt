Hey there! 👋 The rule wasn’t running because `then:` can only be used when it’s paired with an `if:`—otherwise Sensei-check treats the YAML as invalid and skips it. I’ve restored the missing precondition below. Make sure the profile that generates these conversations exposes `size`, `drink`, `toppings`, and `price` in its `chatbot.output`; if any of those fields are absent, the rule still won’t be able to evaluate.

```yaml
name: more_toppings_cost_more
description: Adding more toppings to a custom pizza costs more
active: true
conversations: 2
when: conv[0].size == conv[1].size and conv[0].drink == conv[1].drink
if: len(conv[0].toppings) > len(conv[1].toppings)
then: extract_float(conv[0].price) > extract_float(conv[1].price)
```

Once the profile schema and the rule line up, you should be good to go! 😊
