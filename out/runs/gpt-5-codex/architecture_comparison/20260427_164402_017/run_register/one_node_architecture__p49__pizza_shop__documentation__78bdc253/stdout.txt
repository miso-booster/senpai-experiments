The `pairwise()` function is a clever way to cover lots of combinations in your Sensei profiles without exploding the total number of conversations. Here’s the gist:

### What `pairwise()` does
- When you apply `pairwise()` to two or more variables in the `user.goals` section, Sensei will generate a set of conversations where **every possible pair of variable values appears together at least once**.
- It’s the classic pairwise testing strategy: instead of testing the full Cartesian product (which can be huge), you only test enough combinations to make sure every pair is exercised somewhere.

### Why it’s useful
- Suppose you have three variables, each with 4 values. A full grid would be 4 × 4 × 4 = 64 conversations 😵‍💫.
- With `pairwise()`, you typically get a **dramatic reduction** (often a dozen-ish conversations) while still catching bugs caused by interactions between values.

### How to use it
- Declare `function: pairwise()` on each variable you want included. Sensei will recognize all the variables sharing `pairwise()` and treat them as a group.
- You need at least two variables using `pairwise()` for it to make sense.
- You can mix `pairwise()` with other functions (`forward`, `random`, etc.), but only the variables marked `pairwise()` participate in the coverage matrix.

### Bonus tips
- If you later set `conversation.number: combinations` (or `combinations(p)`), Sensei will automatically use the pairwise matrix created from those variables.
- Perfect when you care about interactions (e.g., pizza size × drink type) but don’t want to run every imaginable scenario.
