Absolutely—this is a great candidate for a general rule that applies to any profile 👍. Sensei-check already ships the helper `responds_in_same_language()`, which looks at each turn pair and verifies the assistant keeps the user’s language. Below is a minimal rule that activates that check per conversation.

```yaml
name: chatbot_responds_in_same_language
description: Ensures the assistant replies in the same language as the user.
conversations: 1
active: true
oracle: responds_in_same_language()
```

### How it works
- `conversations: 1` makes it a single-dialog oracle.
- `responds_in_same_language()` returns `True` only if every assistant reply mirrors the user’s language, so the rule fails whenever the bot drifts.

Feel free to add an `on-error` message if you want more context in failure reports.

**Docs consulted:** I relied on `sensei-check-doc.md` for the rule structure and the catalog of helpers, and `rules-examples.md` for the sample rule that uses the same helper. Let me know if you’d like a profile-specific variant or additional guardrails!
