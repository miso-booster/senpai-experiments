Absolutely! Here’s a Sensei-check rule you can drop into your `rules/` folder to make sure the chatbot replies in the same language the user uses 😊

```yaml
name: chatbot_responds_in_same_language
description: The chatbot should reply in the same language as the user within each conversation.
conversations: 1
active: true
oracle: responds_in_same_language()
on-error: "Mismatch languages detected in conversation {conversation_id}: {responds_in_same_language(details=True)}"
```

This uses the built-in `responds_in_same_language()` helper, so it’s profile-agnostic and works across your entire project. Let me know if you’d like to tweak the error message or make a project-wide (all conversations) version!
