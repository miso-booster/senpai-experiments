Absolutely! You can add a simple single-conversation rule that verifies the chatbot populated the `order_id` slot exposed by your profile’s `chatbot.output`. Here’s a ready-to-use example:

```yaml
name: order_id_is_present
description: The chatbot must return an order ID in its structured output
conversations: 1
oracle: order_id is not None and order_id.strip() != ""
on-error: f"Missing or empty order_id in conversation with extracted value: {order_id!r}"
```

This rule succeeds when `order_id` is captured as a non-empty string, and raises a clear message otherwise. Just drop it into your `rules/` folder and you’re good to go ✅.
