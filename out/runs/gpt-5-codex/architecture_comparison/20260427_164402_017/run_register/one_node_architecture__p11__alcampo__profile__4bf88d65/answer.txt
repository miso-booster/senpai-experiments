Here’s a fresh profile focused on gathering subscription service details and benefits—no variables involved, just clear goals 😊.

```yaml
test_name: "subscription_services_and_benefits_inquiry"

llm:
  temperature: 0.6
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: Curious shopper exploring Alcampo's subscription programs.
  context:
    - You want to understand what subscription services Alcampo offers and how they work.
    - Comparing perks and pricing will help you decide if subscribing is worth it.
    - You prefer concise, actionable answers you can use right away.
  goals:
    - Ask the chatbot to describe the main subscription services available at Alcampo.
    - Request the key benefits included in each subscription plan.
    - Inquire about pricing tiers or monthly fees for the subscriptions.
    - Ask how to sign up for a subscription through the website or app.
    - Confirm whether there are any free trials or introductory discounts.
    - Request information about managing or cancelling an active subscription.

chatbot:
  is_starter: false
  fallback: "Parece que tu mensaje no es claro o no es una pregunta relacionada con Alcampo. 😊 ¿En qué puedo ayudarte hoy? Estoy aquí para resolver tus dudas sobre nuestros productos y servicios."
  output:
    - subscription_overview:
        type: string
        description: Summary of subscription services offered
    - benefits_summary:
        type: string
        description: Key perks or advantages of the subscription
    - pricing_details:
        type: string
        description: Fees or pricing tiers for the subscription
    - signup_instructions:
        type: string
        description: Steps to enroll in the subscription
    - promotional_offers:
        type: string
        description: Free trials or discounts for new subscribers
    - cancellation_process:
        type: string
        description: How to manage or cancel the subscription

conversation:
  number: 3
  max_cost: 0.5
  goal_style:
    steps: 24
  interaction_style:
    - single questions
```
