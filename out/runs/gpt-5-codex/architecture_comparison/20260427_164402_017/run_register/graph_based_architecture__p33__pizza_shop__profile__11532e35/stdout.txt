¿Por qué queda tan bien?  
- `is_starter: false` deja que el bot responda después de la primera intervención del simulador.  
- `fallback` captura el mensaje real que tu bot usa cuando no entiende algo (importantísimo para que la simulación no se quede colgada).  
- Cada entrada de `chatbot.output` refleja exactamente la información que esperas validar al terminar la conversación. Así luego las reglas o revisiones pueden acceder a `conv[i].pizza_types`, `conv[i].margarita_price`, etc.
