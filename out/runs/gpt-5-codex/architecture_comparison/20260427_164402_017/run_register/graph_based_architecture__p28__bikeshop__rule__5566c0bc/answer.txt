To check that the assistant mirrors the user’s language, you can lean on the built-in helper `responds_in_same_language()` from Sensei-check. It looks at each conversation and verifies that the assistant’s replies use the same language detected in the user’s turns — perfect for multilingual coverage.

Here’s a ready-to-use rule you can drop into your Sensei-check ruleset (for example, under `rules/language_consistency.yaml`). This one is profile-agnostic, so it applies to any profile because it doesn’t rely on specific `chatbot.output` fields:

```yaml
name: same_language_reply
description: Assistant replies in the same language as the user
conversations: 1
oracle: responds_in_same_language() is True
```

### How it works
- `conversations: 1` tells Sensei-check to evaluate each conversation independently.
- `responds_in_same_language()` returns `True` only when every assistant message matches the user’s language across that dialogue.
- The rule fails if the bot responds in a different language at any point.

If you’d like variations (e.g., allow English responses to Spanish users in certain cases), you could wrap the helper in an `if/then` to handle exceptions. Just let me know and I’ll help tweak it!
