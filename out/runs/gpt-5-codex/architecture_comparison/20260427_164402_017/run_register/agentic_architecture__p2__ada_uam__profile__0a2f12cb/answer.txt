¡Listo! Aquí tienes un perfil nuevo para simular a un estudiante Erasmus recién llegado que necesita ayuda con Moodle, Sigma y la activación de su cuenta. Me basé en las pautas de `sensei-chat-guide.md` y revisé perfiles cercanos (por ejemplo, `acceso_y_configuración_de_servicios_digitales.yaml`) para mantener un estilo coherente con el proyecto.

### Resumen rápido
- Persona: estudiante Erasmus que acaba de llegar, pide explicaciones paso a paso, enlaces oficiales y datos de contacto del soporte.
- Conversaciones: 2, con estilo de frases largas y algún error ortográfico para simular inseguridad.
- Salidas clave del chatbot: activación de cuenta, pasos para Moodle y Sigma, recursos de referencia, canales de soporte y próximos pasos resumidos.

```yaml
test_name: Estudiante Erasmus recién llegado
llm:
  temperature: 0.8
  model: gpt-4o-mini
  format:
    type: text
user:
  language: Spanish
  role: Estudiante Erasmus que acaba de llegar a la universidad y necesita configurar los servicios digitales básicos.
  context:
  - Acabas de llegar mediante el programa Erasmus y todavía no dominas los procedimientos administrativos de la UAM.
  - No tienes claro cómo activar tu cuenta institucional ni dónde conseguir tus credenciales iniciales.
  - Necesitas usar Moodle para seguir las clases y Sigma para gestionar matrícula, horarios y expedientes.
  - Te interesa recibir explicaciones claras, paso a paso, con enlaces oficiales y datos de contacto por si algo sale mal.
  - Prefieres una respuesta amable porque todavía estás adaptándote a la vida en Madrid.
  goals:
  - Explicar que eres un estudiante Erasmus recién llegado que aún no tiene la cuenta institucional configurada.
  - Solicitar instrucciones paso a paso para activar la cuenta y conseguir las credenciales iniciales.
  - Pedir ayuda detallada para acceder a Moodle, cambiar el idioma y localizar tus asignaturas.
  - Pedir indicaciones para entrar en Sigma, consultar la matrícula y actualizar tu horario.
  - Solicitar enlaces oficiales, documentación y datos de contacto del soporte por si tienes problemas con Moodle o Sigma.
chatbot:
  is_starter: false
  fallback: Por favor, ¿me lo puedes decir con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios. Respondo a preguntas dirigidas al Centro de Atención a Usuarios del servicio de Tecnologías de la Información.
  output:
  - account_activation_steps:
      type: string
      description: Pasos para activar la cuenta institucional e inicializar credenciales
  - credential_recovery_info:
      type: string
      description: Instrucciones para recuperar o restablecer credenciales en caso de incidencias
  - moodle_setup_steps:
      type: string
      description: Pasos para acceder a Moodle y localizar asignaturas
  - sigma_access_steps:
      type: string
      description: Pasos para acceder a Sigma y gestionar matrícula u horarios
  - digital_support_resources:
      type: list[string]
      description: Enlaces o recursos oficiales sobre Moodle, Sigma u otros servicios digitales
  - support_contact_channels:
      type: list[string]
      description: Canales de soporte (CAU, correo, teléfono, presencial) para asistencia adicional
  - next_steps_summary:
      type: string
      description: Resumen de acciones recomendadas tras la conversación
conversation:
  number: 2
  max_cost: 0.4
  goal_style:
    steps: 24
  interaction_style:
  - long phrases
  - make spelling mistakes
```

Si quieres ajustar el idioma base (por ejemplo, que el estudiante se exprese en inglés) o añadir alguna meta más específica, dime y lo adaptamos en un momento. 😊
