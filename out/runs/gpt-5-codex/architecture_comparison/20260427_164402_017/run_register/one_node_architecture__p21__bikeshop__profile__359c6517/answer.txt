Sounds like a great scenario to cover! Here’s a profile you can drop into your `profiles/` folder—maybe call it `bike_setup_customization.yaml`. It walks the bot through confirming fitting services, upgrading the saddle and grips, and wrapping up with an appointment.

```yaml
test_name: bike_setup_customization

llm:
  temperature: 0.5
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: >
    You are a new bike owner who wants the shop to tailor the bike fit—especially the seat
    and handlebar grips—to match your riding style and comfort needs.
  context:
    - You bought a new commuter bike last week and it still feels a bit off compared to your older ride.
    - You rely on comfort for longer rides and want professional advice on the right saddle and grips.
    - You hope to get recommendations, pricing, and an installation appointment before your first long ride.
  goals:
    - Explain that you recently bought a new bike and ask if the shop offers fitting or setup sessions.
    - Mention that the stock seat is uncomfortable and ask for recommendations for a {{seat_preference}}.
    - Ask if the shop can swap the seat and provide pricing for the recommended option.
    - Say the handlebar grips feel wrong and ask about {{grip_material}} options plus installation service.
    - Ask how long the fitting or setup service usually takes.
    - Schedule a setup appointment for {{appointment_day}} at {{appointment_time}}.
    - seat_preference:
        function: forward()
        type: string
        data:
          - comfort touring saddle
          - performance racing saddle
          - endurance saddle with extra padding
    - grip_material:
        function: another()
        type: string
        data:
          - ergonomic foam grips
          - stitched leather wraps
          - gel-padded rubber grips
          - textured silicone grips
    - appointment_day:
        function: another()
        type: string
        data:
          - tomorrow
          - this Saturday
          - next Wednesday
    - appointment_time:
        function: random()
        type: string
        data:
          - 9:30 AM
          - 11:00 AM
          - 1:30 PM
          - 4:15 PM

chatbot:
  is_starter: false
  fallback: "I'm sorry it's a little loud in my shop, can you say that again?"
  output:
    - fitting_service_confirmation:
        type: string
        description: Confirmation that the shop offers bike fitting or setup services for new bikes.
    - seat_adjustment_details:
        type: string
        description: Details on how the seat can be adjusted or replaced to match the rider's preferences.
    - seat_upgrade_price:
        type: money
        description: The quoted price for any recommended seat upgrade or installation.
    - grip_options_information:
        type: string
        description: Information about handlebar grip options available for customization.
    - grip_installation_price:
        type: money
        description: The cost to install the requested handlebar grips.
    - fitting_duration:
        type: string
        description: The estimated time the fitting or setup session will take.
    - appointment_confirmation:
        type: string
        description: Confirmation message of the scheduled setup appointment, including date and time.

conversation:
  number: 4
  max_cost: 0.6
  goal_style:
    all_answered:
      export: false
      limit: 20
  interaction_style:
    - default
```

Let me know if you’d like companion rules to validate the outputs, or tweaks to the persona/interaction style.
