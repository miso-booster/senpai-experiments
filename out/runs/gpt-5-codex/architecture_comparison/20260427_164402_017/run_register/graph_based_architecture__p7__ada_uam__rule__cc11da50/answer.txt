Sure thing! Here's a Sensei-check rule you can plug right into your project to make sure the ada uam chatbot returns the complete and correct CAU contact info:

```yaml
name: cau_contact_details_complete
description: Verifica que el perfil ada_uam proporciona el contacto completo del CAU correctamente.
conversations: 1
oracle: |
  (
    contact_email.lower() == 'cau@uam.es'
    and contact_phone.replace(' ', '').replace('-', '') in ['914974029', '+34914974029']
    and semantic_content(
      physical_address,
      'Higher Polytechnic School, C/ Francisco Tomás y Valiente nº 11, Building B, first floor, office TI-107'
    )
  )
```

This rule does three checks in one go:
- Confirms the email matches exactly `cau@uam.es`.
- Normalizes the phone number by removing spaces and hyphens so it works with formats like `91 497 4029` or `+34 91 497 4029`.
- Uses `semantic_content` to make sure the physical address matches the official one, even if minor wording changes appear.
