Absolutely! Here’s a rule that enforces the $10 price for any conversation where the chatbot reports a small pizza:

```yaml
name: small_pizza_price_is_10_usd
description: Small pizzas should cost exactly $10
conversations: 1
when: size == 'small'
oracle: extract_float(price) == 10 and currency(price) == 'USD'
on-error: f"Expected a $10 USD price for small pizza but got {price}"
```

This rule assumes the target profile exposes both `size` and `price` in its `chatbot.output`. Let me know if you’d like a variant that uses a different price field (e.g., `total_cost`) or currency!
