¡Perfecto! Aquí tienes una regla que comprueba que el campo `eco_friendly_toys` (expuesto por la conversación) contenga una lista con al menos un elemento. Asegúrate de que en el perfil el tipo declarado sea `list[string]` (u otra variante de lista) para que la validación funcione correctamente 😊.

```yaml
name: eco_friendly_toys_list_present
description: Verifica que el chatbot devuelva una lista de juguetes eco-friendly en eco_friendly_toys.
conversations: 1
if: eco_friendly_toys is not None
then: isinstance(eco_friendly_toys, list) and len(eco_friendly_toys) > 0
on-error: |
  f"El campo eco_friendly_toys no contiene una lista válida: {eco_friendly_toys}"
```
