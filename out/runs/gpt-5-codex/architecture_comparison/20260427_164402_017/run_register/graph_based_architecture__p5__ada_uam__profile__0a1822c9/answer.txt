¡Genial! Aquí tienes un perfil listo para Sensei que simula a una persona buscando los datos de contacto del CAU. Puedes guardarlo como, por ejemplo, `profiles/contacto_cau_informacion.yml` dentro de tu proyecto:

```yaml
test_name: "Contacto CAU - Información de Soporte"

llm:
  temperature: 0.5
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita contactar con el Centro de Atención a Usuarios (CAU) para resolver incidencias."
  context:
    - "Te encuentras con un problema y necesitas los datos completos del CAU para recibir asistencia."
    - "Deseas confirmar los canales oficiales de contacto y saber cuándo puedes comunicarte con ellos."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir la dirección de correo electrónico del CAU."
    - "Preguntar la ubicación física del CAU para visitas presenciales."
    - "Solicitar el horario de atención del CAU."

chatbot:
  is_starter: false
  fallback: "¿Puedes reformular tu consulta? También puedes revisar el catálogo de servicios del CAU."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Dirección de correo electrónico del CAU"
    - physical_address:
        type: string
        description: "Ubicación física del CAU"
    - support_hours:
        type: string
        description: "Horario de atención del CAU"

conversation:
  number: 1
  max_cost: 0.4
  goal_style:
    steps: 12
  interaction_style:
    - single questions
```

Este perfil mantiene el foco en los cuatro datos clave que quieres validar y produce campos bien definidos en `chatbot.output` para que luego los puedas usar en tus Sensei rules. Si necesitas extenderlo con más campos o personalizar el tono del usuario (por ejemplo, añadiendo una personalidad), dime y ajustamos lo que haga falta 😊.
