```yaml
name: admissions_links_are_urls
description: Las URLs de admisiones deben tener formato de enlace válido
conversations: 1
oracle: all((not link) or link.startswith('http') for link in [admission_to_grados_link, waitlist_info_link, future_students_link, welcome_day_link])
```

```yaml
name: application_fee_is_non_negative
description: La tasa de solicitud debe ser un importe numérico mayor o igual a cero
conversations: 1
when: application_fee and any(ch.isdigit() for ch in application_fee)
oracle: extract_float(application_fee) is not None and extract_float(application_fee) >= 0
```

```yaml
name: welcome_day_details_are_consistent
```
