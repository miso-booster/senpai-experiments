Sure thing! Here’s a connector that hits the API using only the essential headers, keeps the payload exactly as in your sample, and strips HTML tags from the bot’s reply so you get clean text back.

```yaml
name: "SAIC Málaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
response_filters:
  - strip_html
```

`response_filters: strip_html` ensures any HTML is removed before the text is returned, so “¡Buenos días!” arrives without the `<p>` tags. Let me know if you’d like to parametrize any of those IDs or add optional headers later on!
