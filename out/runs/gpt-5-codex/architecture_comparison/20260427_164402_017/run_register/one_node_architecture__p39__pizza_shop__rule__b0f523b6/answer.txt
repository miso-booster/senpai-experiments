Got it! Here’s a metamorphic rule you can drop into your `rules/` folder. It assumes your target profile exposes both `price` (as a currency string) and a `drink` output that is empty/`none` when no drink is included. Make sure those fields are available in `chatbot.output` before running the rule 😊.

```yaml
name: drink_addon_two_dollars
description: Adding a drink increases the total price by exactly $2 (requires price + drink outputs)
conversations: 2
if: (conv[0].drink in [None, '', 'none']) ^ (conv[1].drink in [None, '', 'none'])
then: abs(abs(extract_float(conv[0].price) - extract_float(conv[1].price)) - 2) <= 0.01
on-error: |
  f"Expected a $2 difference when adding a drink, but got {extract_float(conv[0].price) - extract_float(conv[1].price)} (orders: {conv[0].drink} vs {conv[1].drink})"
```
