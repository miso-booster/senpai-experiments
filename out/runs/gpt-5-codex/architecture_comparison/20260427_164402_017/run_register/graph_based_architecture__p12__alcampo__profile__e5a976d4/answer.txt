¡Listo! Aquí tienes un perfil nuevo llamado `cart_item_recommendations.yaml` pensado específicamente para que el usuario pida al chatbot sugerencias de productos para añadir al carrito de compra. Revísalo y ajústalo si quieres personalizar algún detalle 😊.

```yaml
test_name: Shopping Cart Item Recommendations

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: >
    You are a proactive shopper who already has a few essentials in the Alcampo
    online cart and wants tailored ideas to round out the order. You value practical
    suggestions, availability details, and estimated costs before adding anything new.
  context:
    - personality: personalities/conversational-user
    - You want to streamline the checkout process and make sure every item you add is useful.
    - You love mixing everyday staples with a few exciting finds or time-saving options.
    - You're budget-conscious but willing to consider promotions or bundles that add value.
  goals:
    - "Tell the chatbot what is already in my cart and ask for additional items from the {{product_category}} section."
    - "Ask for complementary products that would round out a {{meal_plan}} meal plan."
    - "Request recommendations for value bundles or current promotions that I can add to the cart."
    - "Ask which healthy or dietary-friendly options could fit my preferences."
    - "Confirm availability and estimated cost for the suggested items before adding them."
    - product_category:
        function: forward()
        type: string
        data:
          - fresh produce
          - pantry staples
          - beverages
          - household essentials
          - frozen meals
    - meal_plan:
        function: forward()
        type: string
        data:
          - weekday dinners
          - weekend brunch
          - family gathering
          - quick lunches

chatbot:
  is_starter: false
  fallback: "Parece que tu mensaje no es claro o no es una pregunta relacionada con Alcampo. 😊 ¿En qué puedo ayudarte hoy? Estoy aquí para resolver tus dudas sobre nuestros productos y servicios."
  output:
    - recommended_items:
        type: list[string]
        description: "List of items the chatbot suggests adding to the cart"
    - category_focus:
        type: string
        description: "Primary product category used for the recommendations"
    - promotion_opportunities:
        type: string
        description: "Promotions or bundle offers tied to the suggested items"
    - availability_status:
        type: string
        description: "Availability details for the recommended items"
    - estimated_cost:
        type: money
        description: "Estimated total cost of the suggested additions"
    - add_to_cart_instructions:
        type: string
        description: "Guidance provided by the chatbot on how to add items to the cart"

conversation:
  number: 4
  max_cost: 0.6
  goal_style:
    steps: 26
  interaction_style:
    - change your mind
    - single questions
```

Si necesitas que ajustemos variables, estilos de interacción o los campos de salida para alinear con futuras reglas, dímelo y lo pulimos juntos 🙌.
