¡Hola! 😊 Los conectores en Chatbot Dojo sirven para enlazar el simulador de SENSEI con un chatbot real a través de su API. En otras palabras, describen cómo enviar el mensaje del usuario al servicio externo y cómo extraer la respuesta de la API sin tener que escribir código personalizado. Esta información está detallada en `custom-connector-guide.md` y respaldada con ejemplos reales en `connector-examples.md`.

### ¿Para qué se usan?
- Para definir la “capa de transporte” entre el simulador y tu bot.
- Permiten especificar la URL base, la ruta del endpoint, el método HTTP, cabeceras opcionales (como tokens), el cuerpo de la petición (incluyendo la variable `{user_msg}` que se reemplaza por el mensaje del simulador) y cómo leer la respuesta JSON para obtener el texto del bot.

### Campos principales de un conector (según `custom-connector-guide.md`)
| Campo | ¿Qué hace? | ¿Es obligatorio? |
|-------|------------|------------------|
| `name` | Nombre descriptivo del bot o integración. | Opcional (pero útil para identificarlo). |
| `base_url` | URL base de la API del chatbot. | Sí. |
| `send_message.path` | Ruta que se añade al `base_url` para llamar al endpoint. | Sí. |
| `send_message.method` | Método HTTP (POST, GET, etc.). Si no lo pones, asume `POST`. | Opcional. |
| `send_message.headers` | Cabeceras HTTP (por ejemplo, `Authorization`, `Content-Type`). | Opcional. |
| `send_message.payload_template` | JSON de la petición con `{user_msg}` donde va el texto del usuario. | Sí. |
| `response_path` | Ruta (con notación de puntos) para extraer la respuesta de la API. | Sí. |

### Ejemplos rápidos (tomados de `connector-examples.md`)
- **Connector “Ada UAM”**: incluye headers con un token, un payload con IDs de conversación y usa `response_path: "response.0.text"`.
- **Connector “Metro Madrid”**: agrega headers de navegador y extrae la respuesta con `response_path: "messages.0.content"`.

Si quieres, puedo ayudarte a crear un conector nuevo o revisar uno existente. Solo dime qué API deseas conectar y vemos cómo configurarlo.
