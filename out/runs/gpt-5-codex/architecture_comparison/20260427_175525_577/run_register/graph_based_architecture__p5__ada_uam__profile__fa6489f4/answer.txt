¡Claro que sí! Aquí tienes un perfil listo para que el simulador de Sensei represente a una persona que necesita la información de contacto del Centro de Atención a Usuarios (CAU). Solo copia este YAML en tu carpeta `profiles/` (por ejemplo, como `contacto_cau.yaml`) y ya podrás ejecutarlo:

```yaml
test_name: "Contacto con el CAU"

llm:
  temperature: 0.6
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: "Persona que necesita asistencia del Centro de Atención a Usuarios (CAU) para resolver un problema tecnológico."
  context:
    - personality: personalities/patient-user
    - "Has encontrado una incidencia técnica y necesitas contactar directamente con el CAU para solucionarla."
    - "Deseas tener toda la información de contacto a mano para elegir el canal que te resulte más conveniente."
  goals:
    - "Solicitar el número de teléfono del CAU para hablar con soporte."
    - "Pedir la dirección de correo electrónico del CAU para enviar mi consulta."
    - "Preguntar por la ubicación física del CAU por si necesito acudir en persona."
    - "Confirmar el horario de atención del CAU para saber cuándo puedo contactarles."

chatbot:
  is_starter: false
  fallback: "¿Puedes preguntármelo de otra forma? o, si lo prefieres, puedes consultar nuestro\ncatálogo de servicios.\nRespondo a preguntas dirigidas al\nCentro de Atención a Usuarios del servicio de Tecnologías de la Información."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horario de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 15
  interaction_style:
    - single questions
  max_cost: 0.4
```

Si necesitas que ajustemos algún detalle —como la personalidad del usuario, el estilo de interacción o el número de conversaciones— solo dime y lo adaptamos juntos 😊. ¡Éxitos con tus pruebas!
