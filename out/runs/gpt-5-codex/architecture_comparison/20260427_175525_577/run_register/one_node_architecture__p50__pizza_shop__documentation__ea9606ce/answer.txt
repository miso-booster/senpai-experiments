In the world of **Sensei Rules (Sensei-check)**, an **oracle** is the condition we evaluate to decide whether a conversation (or set of conversations) passes the rule. Think of it as the “truth test” you set up: if the oracle evaluates to `True`, the rule passes; if it evaluates to `False`, the rule fails.

Here’s how it fits:

- In **single-conversation rules**, the `oracle:` field holds one boolean expression. For example, `"extract_float(price) >= 10"` would ensure the price is at least $10.
- In **metamorphic rules**, you can still use `oracle:` for a single condition that compares multiple conversations (like `conv[0]` vs. `conv[1]`). Alternatively, you can use the `if:`/`then:` form to express “If this happens… then that should be true”, but `oracle:` is the simplest form when one condition is enough.

So, the oracle is basically the logical check Sensei runs to verify whether the chatbot behaved the way you expect. Let me know if you’d like to see a full example!
