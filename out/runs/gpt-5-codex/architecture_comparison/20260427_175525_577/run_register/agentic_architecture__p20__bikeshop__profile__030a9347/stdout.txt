test_name: "bike_wheel_change_appointment"

        type: string

        function: pairwise()
        type: string

        function: another()
        type: string

### Why this setup works

- **Multiple day/time combos**: `preferred_date` and `preferred_time` both use `pairwise()` so Sensei explores a wide matrix of date/time combinations (per `sensei-chat-guide.md`). Alternate slots add even more coverage.
- **Follow-up pressure**: The goals push the bot to confirm availability, propose backups, and acknowledge deadlines/drop-off preferences—perfect for evaluating how the chatbot manages scheduling.
- **Rich extraction targets**: `chatbot.output` captures the confirmed slot, alternates, status, and drop-off instructions, giving future rules plenty to inspect.
