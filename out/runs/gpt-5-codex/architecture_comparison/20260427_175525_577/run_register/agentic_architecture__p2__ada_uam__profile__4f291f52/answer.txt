¡Listo! Aquí tienes una propuesta de perfil que modela a un estudiante Erasmus recién llegado y perdido con Moodle, Sigma y el resto de plataformas. Incluí salidas del chatbot pensadas para que puedas validar si el soporte fue completo. Me basé en las pautas de `sensei-chat-guide.md` para estructurar el YAML y en perfiles existentes similares para mantener coherencia.

```yaml
test_name: Soporte inicial para estudiante Erasmus
llm:
  temperature: 0.8
  model: gpt-4o-mini
  format:
    type: text
user:
  language: English
  role: >
    You are an Erasmus exchange student who just arrived on campus and needs
    help configuring the university’s digital services.
  context:
    - You have not used the university credentials before and need everything explained clearly.
    - You prefer instructions in English but can try simple Spanish words if needed.
    - You must configure Moodle, Sigma, institutional email, and eduroam Wi-Fi to start classes.
  goals:
    - Ask for step-by-step instructions to activate your institutional credentials and set your first password.
    - Request guidance to access and configure Moodle for the first time.
    - Ask for instructions to enter Sigma and review or update your academic data.
    - Request information about other essential services such as institutional email and eduroam Wi-Fi.
    - Ask where to get additional support in English if you still have problems.
chatbot:
  is_starter: false
  fallback: Por favor, ¿me lo puedes decir con otras palabras? o, si lo prefieres, puedes consultar nuestro catálogo de servicios. Respondo a preguntas dirigidas al Centro de Atención a Usuarios del servicio de Tecnologías de la Información.
  output:
    - credential_activation_steps:
        type: string
        description: Steps provided to activate institutional credentials and the initial password
    - moodle_setup_instructions:
        type: string
        description: Guidance for first-time Moodle access and configuration
    - sigma_access_instructions:
        type: string
        description: Steps to access Sigma and manage academic data
    - essential_platform_guidance:
        type: string
        description: Information about other core services such as institutional email or eduroam Wi-Fi
    - support_contact_information:
        type: string
        description: Contact channels or offices offered for extra help
    - language_support_details:
        type: string
        description: Information about support available in English or other languages
    - helpful_links_provided:
        type: list[string]
        description: URLs or resources shared for platform setup
conversation:
  number: 2
  goal_style:
    steps: 8
    max_cost: 0.1
  interaction_style:
    - change language:
        - Spanish
        - English
    - make spelling mistakes
```

### Por qué estas salidas
- **credential_activation_steps**, **moodle_setup_instructions** y **sigma_access_instructions** permiten comprobar si el bot realmente entrega pasos concretos.
- **essential_platform_guidance** cubre otros servicios básicos (email corporativo, eduroam…).
- **support_contact_information** y **language_support_details** sirven para validar que el bot ofrezca vías de ayuda adicional y soporte en inglés.
- **helpful_links_provided** facilita comprobar si ofrece URLs útiles.

Si necesitas ajustar el número de conversaciones, el estilo de interacción o añadir alguna variable mínima (por ejemplo, campus o facultad), dímelo y lo adaptamos 😊.
