Sure thing! Here’s a rule that makes sure the QA profile conversations return the exact values you listed for opening hours and prices 😊

```yaml
name: qa_expected_values
description: QA profile should return fixed opening hours and price points
conversations: 1
when: opening_and_closing is not None
oracle: |
  opening_and_closing.strip().lower() in ['10 to 20', '10:00 to 20:00'] and \
  extract_float(tire) == 20 and \
  extract_float(tune_up) == 50 and \
  extract_float(seat_price) == 20
on-error: |
  f"Got opening_and_closing={opening_and_closing}, tire={tire}, tune_up={tune_up}, seat_price={seat_price}"
```
