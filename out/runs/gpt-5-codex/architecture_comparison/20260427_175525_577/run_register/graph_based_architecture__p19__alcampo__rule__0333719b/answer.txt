¡Claro! Aquí tienes una regla estilo global (sin depender de ningún profile) que verifica si el chatbot ofreció información sobre promociones cuando la persona usuaria lo pidió. Ajusta las palabras clave si en tu dominio usan otros términos (por ejemplo “ofertas flash”, “rebajas”, etc.). 😊

```yaml
name: current_promotions_disclosed
description: When the user asks about current promotions, the assistant shares at least one promotion-related detail.
conversations: 1
if: any(idx >= 0 for idx in [utterance_index('user', kw) for kw in ['promotion', 'promotions', 'deal', 'offer', 'discount']])
then: any(idx >= 0 for idx in [utterance_index('assistant', kw) for kw in ['promotion', 'promotions', 'deal', 'offer', 'discount']])
on-error: "Assistant never mentioned promotions after the user asked about them."
```

**Cómo funciona:**

- **`if:`** detecta si la persona usuaria preguntó por promociones usando varias palabras clave comunes.
- **`then:`** exige que el chatbot mencione al menos una de esas palabras, lo que señaliza que respondió sobre promociones.
- **`on-error`:** te deja un mensaje clarito cuando no se cumple la regla, para que sea fácil rastrear el fallo.

Si necesitas que la respuesta del bot ocurra *después* del turno específico del usuario, o quieres añadir más matices (por ejemplo exigir cierta estructura o detalles concretos), avísame y lo ajustamos junt@s.
