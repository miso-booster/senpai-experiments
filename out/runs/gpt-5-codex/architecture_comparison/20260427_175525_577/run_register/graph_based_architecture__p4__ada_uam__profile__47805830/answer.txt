¡Claro que sí! Vamos a crear un perfil Sensei bonito y directo para que el usuario simulado pida exactamente la información de contacto del CAU (teléfono, correo, dirección y horarios) 😊. Aquí tienes una propuesta lista para colocar dentro de la carpeta `profiles/`:

```yaml
test_name: "Contacto CAU - Información esencial"

llm:
  temperature: 0.6
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Persona que necesita comunicarse con el Centro de Atención a Usuarios (CAU) de la UAM para resolver dudas."
  context:
    - personality: personalities/curious-user
    - "Estás experimentando algunos problemas con tus accesos y necesitas hablar con el CAU cuanto antes."
    - "Quieres asegurarte de guardar todos los datos de contacto oficiales para futuras referencias."
  goals:
    - "Solicitar el número de teléfono oficial del CAU de la Universidad Autónoma de Madrid."
    - "Pedir la dirección de correo electrónico del CAU para enviar consultas."
    - "Preguntar la dirección física del CAU para acudir en persona en caso necesario."
    - "Solicitar el horario de atención del CAU para planificar futuras consultas."

chatbot:
  is_starter: false
  fallback: "¿Podrías reformular la consulta? También puedes revisar nuestro catálogo de servicios. Respondo a preguntas dirigidas al Centro de Atención a Usuarios del servicio de Tecnologías de la Información."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico del CAU"
    - contact_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horario de atención del CAU"

conversation:
  number: 2
  goal_style:
    steps: 12
  interaction_style:
    - single questions
```

### ¿Qué hace este perfil?
- Simula a un usuario curioso y un poquito apurado que quiere todos los datos de contacto del CAU.
- Las metas obligan al chatbot a dar teléfono, email, dirección y horario.
- Al final, Sensei extraerá esos datos en `chatbot.output`, así luego puedes validarlos fácilmente o escribir reglas con Sensei-check 💪.

Si quieres ajustar el tono del usuario o añadir más preguntas (por ejemplo, sobre tiempos de respuesta o canales alternativos), dime y lo afinamos juntos. ¿Te vale así o quieres que añadamos algo más?
