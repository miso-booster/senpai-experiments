To ensure the assistant always answers in the same language as the user, you can use the built-in helper `responds_in_same_language()`. This function checks each conversation and returns `True` only when both sides stick to the same language.

Here’s a ready-to-use Sensei-check rule you can drop into your rules folder:

```yaml
name: consistent_language_pairing
description: Assistant must reply in the same language as the user
conversations: 1
oracle: responds_in_same_language() is True
```

A couple of quick tips:

- This is a **profile-agnostic (global) rule**, so it doesn’t depend on any specific `chatbot.output` fields.
- It works per conversation (`conversations: 1`), making it handy for catching any reply that slips into the wrong language—say, an English answer to a Spanish prompt.

If you’d like to add logging or a custom message for failures, feel free to extend it with `on-error` wording later. Let me know if you want to tailor it for specific languages or combine it with other style checks!
