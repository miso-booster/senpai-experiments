¡Genial! Aquí tienes una regla que comprueba que el campo `eco_friendly_toys` contenga al menos dos juguetes listados por el chatbot, ya sea como lista o como texto separado por comas:

```yaml
name: eco_friendly_toys_list_present
description: Verifica que el bot devuelva una lista de juguetes eco-friendly durante la conversación.
conversations: 1
oracle: |
  eco_friendly_toys not in [None, '', []] and (
    (isinstance(eco_friendly_toys, list) and len([toy for toy in eco_friendly_toys if toy]) >= 2) or
    (isinstance(eco_friendly_toys, str) and len([toy.strip() for toy in eco_friendly_toys.split(',') if toy.strip()]) >= 2)
  )
on-error: |
  f"La respuesta del bot no incluyó una lista válida de juguetes eco-friendly: {eco_friendly_toys}"
```
