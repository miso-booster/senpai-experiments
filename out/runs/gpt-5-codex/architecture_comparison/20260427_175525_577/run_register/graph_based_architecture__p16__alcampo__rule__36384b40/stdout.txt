Sure thing! Here’s a ready-to-drop Sensei-check rule that enforces availability info whenever a product is flagged as lactose-free. Since there’s no profile yet, I picked placeholder field names and documented them right in the description so whoever builds the profile knows what to expose. 😊

```yaml
name: lactose_free_availability_required
description: >
  If the product is marked as lactose-free, the assistant must provide an explicit availability status.
  Assumes the future profile exposes `lactose_free_flag` (bool) and `availability_status` (string).
conversations: 1
if: bool(lactose_free_flag)
then: availability_status not in [null, "", "unknown"]
on-error: >
  f"Lactose-free product lacks availability info: flag={lactose_free_flag}, availability='{availability_status}'"
```

Feel free to tweak the allowed availability values (`in_stock`, `preorder`, etc.) once your profile schema is finalized. Just holler if you need a follow-up rule or help shaping the profile itself! 💪
