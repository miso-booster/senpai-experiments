In Sensei, a **metamorphic rule** (written in **Sensei-check**) is a test that compares two or more conversations to make sure the chatbot’s behavior changes—or stays consistent—in the right way when we tweak the inputs.

Instead of checking a single conversation for “the one correct answer,” metamorphic rules say things like:

- “If both orders have the same size and drink, the one with more toppings should cost more.”
- “If nothing about the order changed, the price shouldn’t suddenly change either.”
- “If the user switches to Spanish, the bot should respond in Spanish too.”

So we write the rule in YAML, declare how many conversations we need, filter them with `when`, and then express the relation we expect with `if`/`then` or an `oracle`. During testing, Sensei-check looks at all the generated chats from your profiles and flags any pairs (or groups) that break that expected relationship.

It’s a powerful way to keep things consistent without hardcoding exact answers ✨
