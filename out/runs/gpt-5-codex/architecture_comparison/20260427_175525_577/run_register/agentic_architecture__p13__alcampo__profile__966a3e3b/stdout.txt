### Qué estaba fallando
Revisando el perfil contra la guía oficial (`sensei-chat-guide.md`), había dos problemas clave:

1. **Bloque `chatbot.output` mal formateado**  
   Cada campo debe ir como una lista de ítems con guion (`- campo:`). Al tener la indentación rota, YAML se rompía y el perfil no podía cargarse.

2. **Referencia a la personalidad**  
   Para aplicar una personalidad debes usar un mapa (`- personality: personalities/...`). En tu YAML aparecía como string con comillas simples, así que Sensei no la interpretaba como personalidad.

Aproveché y añadí `model_prov: openai` para que el modelo `gpt-4o-mini` quede plenamente especificado (opcional, pero recomendado).
