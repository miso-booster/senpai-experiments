Aquí tienes la regla que valida que el chatbot devuelva email, teléfono y dirección física del CAU 🚀:

```yaml
name: cau_contact_channels_present
description: El chatbot debe proporcionar correo, teléfono y dirección del CAU
conversations: 1
active: true
oracle: all(value and value.strip() for value in [contact_email, contact_phone, physical_address])
on-error: >
  f"Algún dato de contacto falta o viene vacío. Email: {contact_email}, Teléfono: {contact_phone}, Dirección: {physical_address}"
```
