¡Hola 😊! Me encanta la idea de crear un perfil específico para un estudiante Erasmus recién llegado que necesita orientación con Moodle, Sigma y otros servicios de la UAM. Aquí tienes una propuesta de perfil Sensei que puedes añadir a tu carpeta `profiles/`. Lo diseñé con metas claras pero sin variables adicionales, tal como pediste, y con un bloque de `chatbot.output` amplio para validar que el bot entregue la ayuda que esperas.

---

### 📁 Archivo sugerido
`profiles/estudiante_erasmus_soporte_onboarding.yaml`

```yaml
test_name: "Erasmus Student Onboarding Support"

llm:
  temperature: 0.6
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres un estudiante Erasmus que acaba de llegar a la UAM. No conoces las herramientas digitales
    y necesitas ayuda para configurarlas.
  context:
    - "Hablas español pero no dominas la terminología técnica de la UAM."
    - "Vienes de un sistema universitario diferente y no sabes qué plataformas necesitas usar."
    - "Tienes dudas sobre cómo acceder a Moodle, Sigma, el correo institucional y la red WiFi."
    - "Quieres saber dónde encontrar soporte si algo falla y si hay recursos disponibles en otros idiomas."
  goals:
    - "Pedir instrucciones paso a paso para configurar el acceso a Moodle."
    - "Solicitar ayuda para entrar a Sigma y saber qué credenciales necesito."
    - "Preguntar cómo activar el correo institucional y usarlo en mi móvil."
    - "Pedir información para conectarme a la WiFi de la universidad desde mi portátil."
    - "Preguntar qué hacer si algo falla y cómo contactar al soporte técnico adecuado."

chatbot:
  is_starter: false
  fallback: "¿Podrías reformularlo, por favor? También puedes consultar nuestro catálogo de servicios."
  output:
    - moodle_setup_instructions:
        type: string
        description: "Pasos concretos para acceder y configurar Moodle."
    - sigma_access_steps:
        type: string
        description: "Instrucciones para entrar a Sigma y gestionar credenciales."
    - institutional_email_guidance:
        type: string
        description: "Guía para activar y usar el correo institucional."
    - wifi_configuration_details:
        type: string
        description: "Pasos y requisitos para conectarse a la WiFi universitaria."
    - multilingual_support_info:
        type: string
        description: "Recursos o asistencia disponibles en otros idiomas."
    - technical_support_contacts:
        type: string
        description: "Datos de contacto del soporte técnico competente."
    - troubleshooting_resources:
        type: string
        description: "Recursos adicionales para resolver incidencias comunes."
    - vpn_or_remote_access_info:
        type: string
        description: "Indicaciones sobre VPN u otras herramientas para uso remoto si aplican."

conversation:
  number: 4
  goal_style:
    steps: 25
  interaction_style:
    - single questions
```

---

### 💡 Notas rápidas

- **Sin variables extra**: todas las metas son frases simples para que el simulador siga un flujo natural sin combinatoria compleja.
- **Outputs centrados en soporte**: cada campo apunta a la información clave que quieres verificar (configuración de Moodle, Sigma, correo, WiFi, soporte, etc.).
- **Interacción directa**: `single questions` hace que el usuario pregunte cada objetivo por separado, ideal para revisar respuestas específicas.

Si necesitas ajustar el tono del usuario (por ejemplo, hacerlo más ansioso o más formal) o agregar algún idioma alternativo en las metas, dímelo y lo adaptamos en un momento. ¡Ánimo con esas pruebas! ✨
