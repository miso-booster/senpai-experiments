Here’s a rule you can drop into your `rules/` folder. It assumes the conversations expose the `size` variable and the `price` output (as in `pizza_order_test_predefined.yml`). 😊

```yaml
name: small_pizza_price_is_ten
description: Small pizzas should cost exactly $10
conversations: 1
when: size[0] == 'small'
oracle: extract_float(price) == 10 and currency(price) == 'USD'
on-error: f"Small pizza should cost $10 USD but got {price}"
```
