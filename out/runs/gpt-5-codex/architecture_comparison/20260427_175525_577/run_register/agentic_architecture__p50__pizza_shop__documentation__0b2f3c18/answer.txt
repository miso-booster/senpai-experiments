Great question! In the SENSEI-check DSL (📄 `sensei-check-doc.md`), an **oracle** is simply the boolean expression inside a rule that decides whether the chatbot’s behaviour passes or fails that rule.

### How it works
- Each rule targets one or more conversations and gathers the data you care about (usually fields exposed by the profile’s `chatbot.output`).
- The `oracle:` line (or the `then:` part of an `if`/`then` rule) evaluates that data.
  - If the expression returns `True`, the rule passes.
  - If it returns `False`, the rule reports a failure.

### Tiny example
```yaml
oracle: data_collected() == True
```
Here, the helper `data_collected()` checks that every required slot was filled; the oracle passes only if that’s true.

So, think of the oracle as the rule’s “verdict formula”—it encodes the requirement you want to enforce on the chatbot’s output.
