¡Perfecto! Aquí tienes una regla sencilla para comprobar que el perfil expone una lista de juguetes eco-friendly mediante el campo `eco_friendly_toys`. Asumo que tu SENSEI Chat profile ya declara ese slot en `chatbot.output`.

```yaml
name: eco_friendly_toys_list_present
description: Verifica que el chatbot devuelve una lista de juguetes eco-friendly en eco_friendly_toys
conversations: 1
oracle: eco_friendly_toys is not None and isinstance(eco_friendly_toys, list) and len(eco_friendly_toys) > 0 and all(isinstance(item, str) and item.strip() for item in eco_friendly_toys)
on-error: >
  Se esperaba que eco_friendly_toys fuera una lista con al menos un juguete eco-friendly, obtenido: {eco_friendly_toys}
```

💡 Guarda esta regla (por ejemplo, como `rules/eco_friendly_toys_list_present.yaml`) y ejecútala una vez que tu perfil publique el campo `eco_friendly_toys`. Si necesitas validar algún criterio adicional (por ejemplo, palabras clave como “eco” o materiales específicos), dime y ajustamos la condición.
