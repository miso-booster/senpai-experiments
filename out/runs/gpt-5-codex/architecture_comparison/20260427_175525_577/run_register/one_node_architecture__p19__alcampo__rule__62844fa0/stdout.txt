Aquí tienes una regla global para asegurarnos de que el asistente responda con información sobre promociones cuando la persona usuaria lo solicita. 😊

```yaml
name: assistant_mentions_current_promotions
description: When the user asks about promotions, the assistant should provide promotional information.
conversations: 1
if: utterance_index('user', 'promotion') >= 0
then: len(chatbot_returns('promotion')) > 0
on-error: >
  f"The assistant never mentioned promotions even though the user asked (user turn index: {utterance_index('user', 'promotion')})."
```
