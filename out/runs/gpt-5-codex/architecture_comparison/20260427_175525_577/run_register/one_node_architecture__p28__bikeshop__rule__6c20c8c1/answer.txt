Absolutely! Here’s a handy global rule that checks every conversation to make sure the assistant sticks to the user’s language. Drop it into your project’s `rules/` folder (for example as `responds_in_same_language.yaml`) and you’re good to go:

```yaml
name: chatbot_responds_in_same_language
description: Ensures the assistant replies in the same language as the user
conversations: 1
oracle: responds_in_same_language()
```

This uses the built-in `responds_in_same_language()` helper, so it works across all your profiles without needing any specific output fields. Let me know if you’d like to add an error message or tailor it to a particular profile! 😊
