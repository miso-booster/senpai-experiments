Here’s a profile-agnostic rule that checks whether the assistant actually mentions current promotions (or confirms there aren’t any) whenever the user brings up promotions, offers, or discounts 😊

```yaml
name: current_promotions_disclosed
description: If the user asks about promotions, the assistant must share current deals or confirm none are available.
conversations: 1
when: "any(idx >= 0 for idx in [utterance_index('user','promotion'), utterance_index('user','promotions'), utterance_index('user','discount'), utterance_index('user','offer'), utterance_index('user','deals')])"
oracle: "any(idx >= 0 for idx in [utterance_index('assistant','current promotion'), utterance_index('assistant','promotion'), utterance_index('assistant','discount'), utterance_index('assistant','special offer'), utterance_index('assistant','deal'), utterance_index('assistant','promo code')]) or utterance_index('assistant','no promotions available') >= 0"
on-error: "The assistant never mentioned current promotions or clarified their availability after the user asked."
```
