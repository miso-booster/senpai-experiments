Sure thing! In Sensei-check, a **metamorphic rule** is a validation that compares **two or more conversations** to make sure the chatbot behaves consistently when certain inputs change. Instead of judging a single dialogue in isolation, you look at how outputs relate across similar cases.

From the `sensei-check-doc.md` guide:

- You set `conversations: N` (with `N ≥ 2`) to tell Sensei-check you’re evaluating multiple dialogues together.
- Optional `when:` filters pick the conversation tuples that should be comparable (e.g., same pizza size and drink).
- Then you express the expected relation using either:
  - a single boolean `oracle:` expression, or
  - an `if:` / `then:` pair (great for “if toppings increase, price must increase” kinds of checks).
- Inside those expressions you refer to each conversation as `conv[0]`, `conv[1]`, etc., and use the fields exposed by the profile’s `chatbot.output`.

Think of it as writing “laws” about how the chatbot should respond when you tweak inputs—perfect for catching regressions like price monotonicity, language consistency, or SLA guarantees across comparable conversations.
