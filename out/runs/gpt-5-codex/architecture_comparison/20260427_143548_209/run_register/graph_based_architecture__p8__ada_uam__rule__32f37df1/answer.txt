### ✅ What’s going well
The intention of your rule is totally clear: you want to make sure the CAU always returns the official contact details. Love the precision! 💪

### ⚠️ What needs tweaking
There are two small issues:

1. **Using `conv[0]` in a single-conversation rule** – When `conversations: 1`, Sensei-check already assumes you’re talking about the only conversation available, so you should reference the fields directly (e.g., `contact_email`) instead of `conv[0].contact_email`.

2. **Redundant `when` clause** – Since the `when` condition is identical to the `oracle`, it doesn’t filter anything—it just repeats the check. You can safely remove it and keep the assertion in the `oracle`.

- Refer to fields directly in single-conversation rules.
- Use `oracle` for the actual check; only add a `when` if you need a filter.
