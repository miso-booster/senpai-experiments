Hey there! Thanks for sharing your rule 😊. I took a close look, and there were a few things to tighten up so it really checks that the tune-up price is $50:

### What I changed
1. **Rule type**: You only need one conversation for this check, so I changed `conversations: 2` to `conversations: 1`.
2. **Condition format**: The `then` field should evaluate to a boolean expression, not a string message. I replaced it with a direct check.
3. **Simplified structure**: Since we just need to assert the price, there's no need for `when`/`if`—a simple `oracle` does the job.
4. **Robust comparison**: I used `extract_float` so the rule works whether `tune_up_price` is a number or a string like `"50 USD"`.

### Updated rule
```yaml
name: check_tune_up_price
description: Checks that the tune-up price is exactly $50.
conversations: 1
oracle: tune_up_price is not None and extract_float(tune_up_price) == 50
```
