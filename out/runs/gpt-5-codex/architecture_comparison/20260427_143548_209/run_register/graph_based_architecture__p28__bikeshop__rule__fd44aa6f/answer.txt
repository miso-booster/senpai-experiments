Absolutely! To make sure every conversation sticks to the user’s language, you can rely on Sensei-check’s built-in `responds_in_same_language()` helper. It scans each dialog and verifies that the assistant mirrors whatever language the user used—super handy for multilingual bots 🌍.

Here’s a ready-to-use rule:

```yaml
name: same_language_as_user
description: Assistant replies in the same language detected in each conversation
conversations: 1
oracle: responds_in_same_language()
```

Drop this into your Sensei-check ruleset, and each conversation will be checked individually. If any assistant response slips into the wrong language, the rule will flag it so you can investigate.
