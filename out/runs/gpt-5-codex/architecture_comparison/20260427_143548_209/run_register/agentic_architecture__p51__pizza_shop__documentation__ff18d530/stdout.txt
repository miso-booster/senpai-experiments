¡Hola! 😊 Los conectores en Chatbot Dojo sirven como el “puente” que conecta el simulador de SENSEI con el chatbot real que quieres probar. En lugar de escribir código a mano, describes en YAML cómo enviar mensajes al API de tu bot y cómo leer la respuesta. Así el sistema sabe exactamente a qué endpoint llamar, qué payload enviar y dónde encontrar la respuesta en el JSON devuelto.

Según la documentación (`custom-connector-guide.md` y `connector-examples.md`), estos son los campos principales que puede tener un conector:

- **`name`** *(opcional)*: un nombre amigable para reconocer el bot.
- **`base_url`** *(obligatorio)*: la URL base del API de tu chatbot.
- **`send_message`** *(obligatorio)*: define cómo se envía cada mensaje. Dentro de este bloque:
  - **`path`** *(obligatorio)*: el endpoint que se añade al `base_url`.
  - **`method`** *(opcional, por defecto `POST`)*: verbo HTTP que se usará.
  - **`headers`** *(opcional)*: cabeceras adicionales, por ejemplo para autenticación o tipo de contenido.
  - **`payload_template`** *(obligatorio)*: el cuerpo JSON que se manda en cada solicitud. Debe incluir el marcador `{user_msg}`, que se sustituirá por el mensaje real del simulador.
- **`response_path`** *(obligatorio)*: una ruta en notación de puntos para indicar en qué parte del JSON de respuesta está el texto del chatbot (por ejemplo `response.text` o `data.messages.0.content`).

Con esa info el simulador puede hacer las llamadas al API, enviar mensajes de prueba y extraer las respuestas sin que tengas que programar nada extra. Si necesitas más detalles o quieres ver un ejemplo completo, dime y te ayudo encantado.
