Claro que podemos adaptar el conector de Ada UAM para el chatbot del Ayuntamiento de Morón de la Frontera. Como ambos usan la misma API de MillionBot, solo necesitamos reemplazar los identificadores específicos (conversation, sender, bot, etc.) con los que nos compartiste.

Aquí tienes el YAML listo para usar:

```yaml
name: "Morón de la Frontera"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "65ca19e7dbbb4e26cbeadf28"
  payload_template:
    conversation: "67ea76f4e213b2dcbc146e2b"
    sender_type: "User"
    sender: "67ea76f40643a3dd27e59411"
    bot: "65ca19e7dbbb4e26cbeadf24"
    language: "es"
    url: "https://www.morondelafrontera.es/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

👉 Solo recuerda guardar el archivo dentro de tu carpeta de conectores (`connectors`) con un nombre descriptivo, por ejemplo `moron-ayuntamiento.yml`, y ya estarías listo para probarlo.

Si necesitas ajustar algo más (por ejemplo, personalizar el `user_agent` en los headers o cambiar el `response_path` si el JSON llegara a variar), dímelo sin problema. ¡Estoy aquí para ayudarte! 💪
