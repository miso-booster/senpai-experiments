Happy to help! Here’s a ready-to-use Sensei rule that checks whether the assistant replies in the same language as the user 🎯. Just drop it into your `rules/` folder.

```yaml
name: chatbot_responds_in_user_language
description: Ensures the assistant answers in the same language the user speaks.
conversations: 1
oracle: responds_in_same_language()
on-error: "Assistant language mismatch detected: {responds_in_same_language()}"
```
