2. **Missing `if:` guard**  
   In `sensei-check`, when you want to use a `then:` clause you’re expected to pair it with an `if:` precondition (`sensei-check-doc.md`, section “Syntax snapshot”). The version from `rules-examples.md` shows the intended structure:

   ```yaml
   name: more_toppings_cost_more
   description: Adding more toppings to a custom pizza cost more
   active: True
   conversations: 2
   when: conv[0].size == conv[1].size and conv[0].drink == conv[1].drink
   if:   len(conv[0].toppings) > len(conv[1].toppings)
   then: extract_float(conv[0].price) > extract_float(conv[1].price)
   ```

   Without that `if:`, `then:` isn’t evaluated properly.
