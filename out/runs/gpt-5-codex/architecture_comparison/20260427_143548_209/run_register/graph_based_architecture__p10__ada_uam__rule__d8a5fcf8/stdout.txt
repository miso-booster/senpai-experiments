### 1. Todos los enlaces deben ser URLs válidas  
Como expones cuatro campos tipo link, esta regla revisa que el bot no devuelva textos tipo “consulta con soporte”, sino URLs reales.

```yaml
name: admission_links_are_urls
description: Todos los enlaces de admisiones y recursos deben lucir como URLs
conversations: 1
oracle: |
  all(
    link.startswith('http')
    for link in [
      admission_to_grados_link,
      waitlist_info_link,
      future_students_link,
      welcome_day_link
    ]
    if link
  )
```

### 2. Consistencia en la información del Welcome Day  
Si la respuesta menciona fecha u hora, debería entregar ambos datos y el lugar. Así evitamos respuestas a medias.

```yaml
name: welcome_day_complete_info
description: Si se menciona el Welcome Day, deben aparecer fecha, hora y lugar

```

### 3. Listas de espera: procedimientos + enlace
