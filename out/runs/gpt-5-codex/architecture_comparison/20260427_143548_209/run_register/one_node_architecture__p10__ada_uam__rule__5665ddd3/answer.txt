¡Hola! Me encanta que quieras empezar a validar este perfil 🙌. Aquí tienes tres reglas sencillas que podrías ejecutar de entrada: una para asegurarte de que el bot contesta en español, otra para comprobar que la respuesta incluye un coste de solicitud válido, y una tercera para verificar que siempre ofrece algún contacto de admisiones. Puedes pegarlas directamente en tu carpeta `rules/`.

```yaml
name: respuestas_en_espanol
description: Las conversaciones generadas para Usuarios Nuevos y Admisiones deben estar en español
conversations: 1
oracle: language(chatbot_phrases) == 'ESP'
```

```yaml
name: cuota_de_solicitud_valida
description: La tarifa de solicitud debe incluir un importe numérico y una moneda reconocible
conversations: 1
oracle: extract_float(application_fee) > 0 and currency(application_fee) is not None
```

```yaml
name: contacto_de_admisiones_presente
description: Cuando se pide información sobre admisiones, el bot debe proporcionar algún dato de contacto
conversations: 1
oracle: contact_admissions not in [None, '', 'N/A']
```

Si necesitas algo más específico (por ejemplo, reglas metamórficas comparando distintos grados o cursos), dime y lo diseñamos juntos 😊.
