Aquí tienes el conector listo 😊:

```yaml
name: "SAIC Málaga Bot"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_template: "{{ response.0.text | strip_html }}"
```

**Resumen rápido**
- Siguiendo la guía de `custom-connector-guide.md`, definí `base_url`, `path`, el `payload_template` con el marcador `{user_msg}` y mantuve únicamente los encabezados imprescindibles (`Content-Type` y `Authorization`).
- Para cumplir el requisito de devolver texto plano, uso un `response_template` con el filtro `strip_html`, que elimina las etiquetas HTML del campo `response.0.text`. Si tu instancia no tuviera disponible ese filtro, dímelo y te propongo otra alternativa.
