¡Gracias por los detalles! 😊 Aquí tienes un perfil Sensei pensado para un/a estudiante Erasmus que acaba de llegar y necesita ayuda paso a paso con Moodle, Sigma y otros accesos digitales. Mantiene la sección de objetivos sin variables complicadas, pero amplía el `chatbot.output` para validar que el bot ofrece toda la asistencia necesaria.

```yaml
test_name: "Erasmus Digital Onboarding"

llm:
  temperature: 0.6
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres un estudiante Erasmus recién llegado a la UAM. Necesitas ayuda para
    poner en marcha tus accesos digitales (Moodle, Sigma, correo, VPN)
    porque no estás familiarizado con los procedimientos locales.
  context:
    - "Acabas de aterrizar en Madrid y aún no dominas todos los trámites tecnológicos."
    - "Necesitas instrucciones muy claras y enlaces directos para evitar retrasos académicos."
    - "Todavía estás adaptándote al idioma, así que agradeces pautas sencillas y, si es posible, recursos en inglés."
  goals:
    - "Solicitar instrucciones paso a paso para activar mi ID-UAM y acceder a Moodle por primera vez."
    - "Pedir ayuda para configurar mi acceso a Sigma y revisar mi matrícula."
    - "Preguntar cómo vincular mi cuenta institucional al correo y otros servicios digitales."
    - "Solicitar información sobre cómo conectarme a la VPN o Wi-Fi de la universidad desde mi portátil personal."
    - "Pedir los datos de contacto del soporte técnico por si necesito asistencia en inglés."

chatbot:
  is_starter: false
  fallback: "¿Podrías reformular tu consulta? También puedes revisar nuestro catálogo de servicios. Respondo a preguntas dirigidas al Centro de Atención a Usuarios de TI."
  output:
    - moodle_setup_steps:
        type: string
        description: "Instrucciones detalladas para activar ID-UAM y acceder a Moodle."
    - sigma_access_instructions:
        type: string
        description: "Pasos para entrar a Sigma y revisar la matrícula."
    - institutional_email_setup:
        type: string
        description: "Guía para configurar el correo institucional y servicios vinculados."
    - wifi_vpn_guidance:
        type: string
        description: "Pasos para conectarse a la Wi-Fi o VPN de la UAM."
    - multilingual_support_options:
        type: string
        description: "Opciones de soporte disponibles en otros idiomas (por ejemplo, inglés)."
    - support_contact_email:
        type: string
        description: "Correo de contacto del CAU o soporte TIC."
    - support_contact_phone:
        type: string
        description: "Teléfono de contacto del CAU o soporte TIC."
    - support_service_hours:
        type: string
        description: "Horario de atención del servicio de soporte."
    - helpdesk_ticket_link:
        type: string
        description: "Enlace para abrir un ticket de asistencia."
    - onboarding_resources_link:
        type: string
        description: "URL con recursos para nuevos estudiantes Erasmus."
    - estimated_response_time:
        type: string
        description: "Tiempo estimado de respuesta del soporte."
    - required_credentials_summary:
        type: string
        description: "Lista de credenciales o requisitos previos (ID-UAM, NIA, etc.)."

conversation:
  number: 3
  max_cost: 0.6
  goal_style:
    steps: 25
  interaction_style:
    - single questions
```

🔍 **Cómo usarlo**

- Guarda el archivo, por ejemplo, como `profiles/erasmus_digital_onboarding.yaml`.
- Ejecútalo con tu conector habitual y revisa los campos de `chatbot.output` para verificar que tu bot proporciona todo el soporte clave.
- Puedes ajustar el `language` o la personalidad si deseas que la simulación mezcle inglés y español, pero así ya cubre un escenario claro con solicitudes en español.
