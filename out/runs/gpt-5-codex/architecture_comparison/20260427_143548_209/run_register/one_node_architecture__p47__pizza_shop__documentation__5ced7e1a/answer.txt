Hey there! 👋 In Sensei, a **metamorphic rule** (used in *Sensei-check*) is a test that looks at relationships between multiple conversations instead of judging a single dialogue in isolation.  

Think of it this way: rather than saying “this response is right or wrong,” a metamorphic rule says, “when I change the inputs in a specific way, the chatbot’s outputs should change (or stay the same) accordingly.” For example, if two simulated orders have the same drink and size but different numbers of toppings, the rule might assert that the one with more toppings must cost more.  

These rules are super helpful when there isn’t one “correct” answer, but the responses should still behave consistently across variations.
