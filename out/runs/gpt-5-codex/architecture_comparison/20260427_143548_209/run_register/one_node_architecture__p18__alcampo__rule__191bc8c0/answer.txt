¡Claro! Aquí tienes una regla que valida que `eco_friendly_toys` contenga al menos dos juguetes (asumiendo que el perfil expone ese campo como una lista separada por comas). Si el campo está vacío o solo trae un elemento, la regla marcará el fallo.

```yaml
name: eco_friendly_toys_list_present
description: Verifica que el perfil Pet Products Inquiry devuelva una lista de juguetes eco-friendly.
conversations: 1
oracle: eco_friendly_toys not in [None, ''] and len([item.strip() for item in eco_friendly_toys.split(',') if item.strip()]) >= 2
on-error: f"eco_friendly_toys='{eco_friendly_toys}' no contiene al menos dos juguetes eco-friendly."
```

Si la lista no utiliza comas para separar los elementos, avísame y ajustamos la lógica para adaptarla al formato real 😊.
