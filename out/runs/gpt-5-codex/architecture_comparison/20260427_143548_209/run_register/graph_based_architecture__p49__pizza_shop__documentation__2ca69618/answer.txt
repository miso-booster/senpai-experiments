Hey there! 😊 Great question — the `pairwise()` function is one of those little gems in Sensei profiles that saves you tons of time when you're juggling lots of variables.

### What `pairwise()` does (in plain words)

When you have **two or more variables** in your profile (like pizza type, size, drink, etc.) and you want to make sure every pair of variables is tested together at least once, `pairwise()` steps in. Instead of creating every possible combination (which can explode quickly!), it builds a **pairwise coverage matrix** — meaning it ensures that each possible pairing of variable values shows up in at least one conversation.

### Why it’s awesome
- ✅ It drastically reduces the total number of conversations.
- ✅ You still get excellent test coverage across variable combinations.
- ✅ It’s perfect when you care about how two things interact, but don’t need every possible scenario.

### How to use it
Just set `function: pairwise()` for each variable you want included in that pairwise matrix. You’ll need **at least two variables** using `pairwise()` for it to work. Sensei will automatically handle the smart sampling behind the scenes.

```yaml
- pizza_type:
    function: pairwise()
    type: string
    data: [Margherita, Pepperoni, Vegetarian]

- drink_type:
    function: pairwise()
    type: string
    data: [Soda, Juice, Water]

- pizza_size:
    function: pairwise()
    type: string
    data: [Small, Medium, Large]
```

Combined with `conversation.number: combinations` (or something like `combinations(0.6, pairwise)`), the profile will run just enough conversations to cover all the essential pairs (like every pizza type combined with every size or drink at least once) without going overboard.

If you need more than pairwise coverage (like three-way combinations), Sensei doesn’t have a built-in function for that yet, but pairwise is usually a solid sweet spot 💫.
