Aquí tienes un perfil listo para probar el chatbot de la UAM enfocado en soporte del CAU. ¡Avísame si quieres ajustar algo! 😊

```yaml
test_name: "Soporte CAU - Información de Contacto"

llm:
  temperature: 0.6
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Usuario que necesita contactar con el Centro de Atención a Usuarios (CAU)
    de la Universidad Autónoma de Madrid para resolver dudas urgentes.
  context:
    - personality: personalities/formal-user
    - "Has intentado resolver tus dudas a través del portal web pero no has encontrado los datos de contacto completos."
    - "Necesitas comunicarte con el CAU cuanto antes para resolver incidencias relacionadas con tus servicios digitales."
  goals:
    - "Solicitar el número de teléfono del Centro de Atención a Usuarios (CAU)."
    - "Preguntar cuál es el correo electrónico oficial para contactar con el CAU."
    - "Pedir la dirección física a la que se puede acudir para recibir atención en persona."
    - "Solicitar el horario de apertura y cierre del CAU para planificar una visita."

chatbot:
  is_starter: false
  fallback: "¿Podrías decirlo con otras palabras? También puedes consultar nuestro catálogo de servicios si lo prefieres."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU."
    - contact_email:
        type: string
        description: "Correo electrónico del CAU."
    - physical_address:
        type: string
        description: "Dirección física del CAU."
    - service_hours:
        type: string
        description: "Horario de atención del CAU."

conversation:
  number: 3
  max_cost: 0.4
  goal_style:
    steps: 12
  interaction_style:
    - single questions
```
