Great question! In the context of Sensei Rules (the Sensei-check DSL), an **oracle** is the boolean expression a rule evaluates to decide whether a conversation—or a set of conversations—meets the expected behavior.

Think of it as the rule’s “final verdict”. For single-conversation checks you’ll often just see:

```yaml
oracle: data_collected() is True
```

Here, the rule passes only if the oracle expression is true (i.e., all slots were collected).  

For metamorphic rules, you can either use a single `oracle:` expression or the more readable `if:`/`then:` pair. Whatever path you choose, the oracle is what actually gets evaluated when Sensei-check runs, and a failure simply means the oracle expression turned out `False`.

So in short: **the oracle is the condition the rule expects to hold**—your specification of “what should always be true” for the conversations under that rule.
