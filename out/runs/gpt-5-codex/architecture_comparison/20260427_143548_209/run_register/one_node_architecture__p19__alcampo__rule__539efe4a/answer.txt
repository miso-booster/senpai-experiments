Claro 😊 Aquí tienes una regla global que verifica si el asistente menciona promociones cuando la persona usuaria lo solicita:

```yaml
name: promotions_request_answered
description: Ensures the assistant mentions current promotions or offers when the user asks about them
conversations: 1
if: (utterance_index('user', 'promotion') >= 0) or (utterance_index('user', 'offer') >= 0)
then: (utterance_index('assistant', 'promotion') >= 0) or (utterance_index('assistant', 'offer') >= 0)
on-error: "Assistant did not reference promotions or offers after the user asked about them."
```
