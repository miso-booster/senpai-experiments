To make sure your chatbot always mirrors the user’s language, you can rely on Sensei-check’s built-in helper `responds_in_same_language()`. That helper compares the language of the user and assistant turns within each conversation.

Here’s a ready-to-use rule you can drop into your ruleset:

```yaml
name: responds_in_same_language
description: The assistant should answer in the same language as the user.
conversations: 1
oracle: responds_in_same_language() is True
```

### How it works
- **`conversations: 1`** makes this a single-conversation check — it evaluates each dialogue on its own.
- **`responds_in_same_language()`** returns `True` when every assistant reply stays in the user’s language. If there’s a mismatch (say, user speaks Spanish but the assistant replies in English), the rule fails.
