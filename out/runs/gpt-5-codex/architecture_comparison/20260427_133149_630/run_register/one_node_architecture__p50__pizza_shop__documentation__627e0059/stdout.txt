Hey there! 😊 In the world of SENSEI Rules, an **oracle** is simply the condition a rule uses to decide whether a conversation passes or fails.

In a rule, the `oracle:` field holds a boolean expression—if it evaluates to `True`, the conversation satisfies the rule; if it’s `False`, the rule fails. For example, you might write:

```yaml
oracle: data_collected() == True
```

That tells Sensei-check to mark the conversation as passing only when every expected output slot is filled. So, think of the oracle as the rule’s “final verdict” based on the data extracted from a conversation.
