¡Perfecto! Vamos a armar un perfil Sensei centrado en pedir la información clave del CAU. Puedes guardarlo como `profiles/soporte_contacto_cau.yaml` (o el nombre que prefieras). Aquí tienes la propuesta completa:

```yaml
test_name: "Soporte del CAU - Información de Contacto"

llm:
  temperature: 0.4
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: >
    Usuario que necesita contactar al Centro de Atención a Usuarios (CAU) de la UAM
    para resolver incidencias tecnológicas.
  context:
    - personality: personalities/neutral-user
    - "Tienes problemas con tu cuenta y necesitas comunicarte con el CAU lo antes posible."
    - "Prefieres conocer todas las vías de contacto (teléfono, correo, oficina) y sus horarios antes de llamar."
  goals:
    - "Solicitar el número de teléfono del CAU para soporte técnico."
    - "Pedir el correo electrónico de contacto del CAU."
    - "Preguntar por la dirección física del CAU para acudir en persona."
    - "Solicitar el horario de atención del CAU o sus horarios operativos."

chatbot:
  is_starter: false
  fallback: "¿Podrías reformular tu consulta? También puedes revisar nuestro catálogo de servicios disponibles."
  output:
    - cau_phone:
        type: string
        description: "Número de teléfono oficial del CAU."
    - cau_email:
        type: string
        description: "Dirección de correo electrónico del CAU."
    - cau_address:
        type: string
        description: "Dirección física del CAU."
    - cau_service_hours:
        type: string
        description: "Horarios de atención del CAU."

conversation:
  number: 3
  goal_style:
    steps: 20
  interaction_style:
    - single questions
```

### ¿Por qué funciona este perfil?

- **Objetivo claro:** cada meta está alineada con los datos de contacto que quieres validar.
- **Salida estructurada:** los campos de `chatbot.output` permiten que tus reglas sensei-check verifiquen fácilmente la respuesta del bot.
- **Configuración conservadora:** conversación breve (hasta 20 turnos) y modo de preguntas individuales para mantener las interacciones enfocadas.

Si necesitas añadir más detalles (por ejemplo, recuperar el catálogo de servicios del CAU o instrucciones de ticketing), dime y lo expandimos con gusto 😊.
