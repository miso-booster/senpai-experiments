¡Claro! Aquí tienes una regla que comprueba que la salida `eco_friendly_toys` contenga al menos dos elementos (se asume que la lista viene separada por comas o saltos de línea):

```yaml
name: eco_friendly_toys_list_present
description: Verifica que el chatbot proporcione una lista de juguetes eco-friendly
conversations: 1
oracle: eco_friendly_toys is not None and len([item.strip() for item in eco_friendly_toys.replace('\n', ',').split(',') if item.strip()]) >= 2
on-error: f"No se detectó una lista válida de juguetes eco-friendly: {eco_friendly_toys}"
```
