¡Perfecto! Aquí tienes un perfil Sensei listo para poner a prueba la capacidad del chatbot de Alcampo en recomendaciones de recetas y planificación de menús 🥗✨. Incluye un usuario que pide un menú semanal, recetas concretas, ayuda para generar la lista de la compra y alternativas saludables. Además, le pide al bot recursos digitales para organizarse mejor.

```yaml
test_name: Menu Planning and Recipe Guidance

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: >-
    Persona usuaria de Alcampo que busca inspiración culinaria y organización de menús semanales.
  context:
    - personality: personalities/conversational-user
    - Cocinas en casa para tu familia y quieres integrar recetas equilibradas y fáciles de preparar.
    - Necesitas ayuda para transformar las recomendaciones en una lista de la compra dentro del ecosistema Alcampo.
    - Te interesa aprovechar herramientas digitales para planificar menús y recordar preparaciones.
  goals:
    - "Pide al chatbot un plan de menú semanal equilibrado para {{household_size}} personas con énfasis en {{diet_focus}}."
    - "Solicita tres recetas diferentes para el almuerzo que utilicen ingredientes disponibles en Alcampo."
    - "Pregunta cómo convertir las recetas recomendadas en una lista de la compra online."
    - "Consulta opciones de sustituciones saludables para ingredientes que puedan no gustar o no estén disponibles."
    - "Pregunta por herramientas o recursos de Alcampo que faciliten la planificación de menús (calendario, recordatorios, etc.)."
    - household_size:
        function: forward()
        type: int
        data: [1, 2, 4]
    - diet_focus:
        function: another()
        type: string
        data:
          - alimentación equilibrada
          - opciones vegetarianas
          - sin gluten
          - alta en proteínas

chatbot:
  is_starter: false
  fallback: "Parece que tu mensaje no es claro o no es una pregunta relacionada con Alcampo. 😊 ¿En qué puedo ayudarte hoy?"
  output:
    - weekly_menu_plan:
        type: string
        description: "Resumen del menú semanal sugerido por el chatbot."
    - lunch_recipes:
        type: list[string]
        description: "Recopilación de recetas propuestas para el almuerzo."
    - shopping_list_instructions:
        type: string
        description: "Pasos para añadir ingredientes a la lista de la compra."
    - healthy_substitutions:
        type: string
        description: "Alternativas sugeridas para sustituir ingredientes."
    - planning_tools:
        type: string
        description: "Herramientas o recursos digitales para planificar menús."
    - ingredient_highlights:
        type: string
        description: "Ingredientes clave mencionados en las recetas recomendadas."

conversation:
  number: 3
  goal_style:
    steps: 8
  interaction_style:
    - long phrases
    - random:
        - make spelling mistakes
        - change language:
            - Spanish
            - English
```

👉 Tip: si quieres ampliar la cobertura de casos, puedes añadir más variables (por ejemplo, tipo de comida del día o restricciones adicionales) y ajustar `conversation.number` a `combinations` para generar más combinaciones automáticamente.
