Hey! Thanks for sharing the rule 😊 I spotted a few hiccups:

* It was declared as a 2-conversation rule, but only `conv[0]` was referenced—so it should really be a single-conversation check.
* The `when:` filter already required the price to be 50, which meant the rule never evaluated the “wrong” cases (it would just skip them).
* `then:` must be a boolean expression, not a literal string.

Here’s a corrected version that directly enforces the $50 expectation:

```yaml
name: check_tune_up_price
description: Ensures the tune-up price is exactly $50.
conversations: 1
oracle: tune_up_price is not None and extract_float(tune_up_price) == 50
```

✏️ Changes made:
1. Switched to `conversations: 1` since we only need one dialog.
2. Removed the `when:` clause so the rule evaluates every conversation.
3. Replaced the string in `then:` with a proper boolean condition via `oracle:`.

This assumes `tune_up_price` comes from the profile’s `chatbot.output`. If that field contains a plain number (not text), you can drop `extract_float()` and use `tune_up_price == 50` instead. Let me know if you’d like that version!
