Absolutely! Here's a rule you can drop into your `rules/` folder to make sure the assistant mirrors the user’s language every time 🗣️💬

```yaml
name: chatbot_responds_in_user_language
description: Ensures the chatbot replies in the same language as the user.
conversations: 1
oracle: responds_in_same_language()
yields: "Assistant replies in a different language: {responds_in_same_language()}"
```

This uses the built-in `responds_in_same_language()` helper, so it works across all your profiles without needing any schema-specific fields. Let me know if you’d like a stricter version (e.g., only for certain languages) or if you want it to run on paired conversations instead!
