Absolutely! 😊 Here’s a fresh profile you can drop into your project to simulate a user who wants the chatbot’s help building a shopping cart:

```yaml
test_name: Shopping Cart Item Selection

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: >
    You are planning a weekly grocery run and want guided help from the chatbot to
    build a well-balanced shopping cart.
  context:
    - personality: personalities/conversational-user
    - You prefer mixing fresh produce with pantry staples to cover weekday meals.
    - You're mindful of budget but open to recommended add-ons that make cooking easier.
    - You want reassurance that items are in stock before confirming the cart.
  goals:
    - "Ask the chatbot to suggest must-have {{category_choice}} items for my cart."
    - "Confirm the availability and price of {{specific_item}} before adding it."
    - "Request a complementary item idea for my {{meal_plan}} meal plan."
    - "Ask for alternatives if any suggested product is unavailable."
    - "Review the current cart items and total before proceeding to checkout."
    - category_choice:
        function: forward()
        type: string
        data:
          - fresh produce
          - pantry staples
          - beverages
          - household essentials
    - specific_item:
        function: random()
        type: string
        data:
          - organic avocado pack
          - wholegrain pasta
          - almond milk 1L
          - eco-friendly cleaning wipes
          - Mediterranean salad kit
    - meal_plan:
        function: random()
        type: string
        data:
          - quick weekday dinners
          - family brunch
          - vegetarian meal prep
          - cozy soup night

chatbot:
  is_starter: false
  fallback: >
    Parece que tu mensaje no es claro o no es una pregunta relacionada con Alcampo. 😊
    ¿En qué puedo ayudarte hoy? Estoy aquí para resolver tus dudas sobre nuestros productos y servicios.
  output:
    - cart_items:
        type: list[string]
        description: Items the chatbot confirms adding to the cart
    - cart_total:
        type: currency
        description: Total estimated cost of the cart
    - item_availability:
        type: string
        description: Availability status for requested products
    - recommended_alternatives:
        type: string
        description: Suggested alternatives when an item is unavailable
    - complementary_item:
        type: string
        description: Complementary item recommended for the user’s meal plan
    - delivery_window:
        type: string
        description: Suggested delivery or pickup window

conversation:
  number: 4
  max_cost: 0.6
  goal_style:
    steps: 9
  interaction_style:
    - random:
        - long phrases
        - make spelling mistakes
        - change your mind
```

Let me know if you’d like this tailored for a different persona or tied to specific rules afterwards! 🛒✨
