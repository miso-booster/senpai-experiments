Absolutely! Here’s a Sensei-check rule that locks in those expected values for the QA profile 😊👇

```yaml
name: qa_expected_prices_and_hours
description: Ensure the QA profile returns the expected shop hours and baseline prices.
conversations: 1
oracle: |
  opening_and_closing.strip() == '10 to 20' and
  abs(extract_float(tire) - 20) < 1e-3 and
  abs(extract_float(tune_up) - 50) < 1e-3 and
  abs(extract_float(seat_price) - 20) < 1e-3
on-error: |
  f"Got opening_and_closing={opening_and_closing}, tire={tire}, tune_up={tune_up}, seat_price={seat_price}"
```
