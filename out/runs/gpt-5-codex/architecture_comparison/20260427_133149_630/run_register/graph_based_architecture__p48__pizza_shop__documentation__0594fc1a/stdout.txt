Hey there! Great question. Sensei profiles look pretty full-featured at first glance, but a bunch of those sections are actually optional. Here’s a friendly rundown so you can keep your YAMLs lean and focused 😊

---

### ✅ Optional (nice-to-have) sections

| Section / Field | Why it’s optional |
|-----------------|-------------------|
| **`llm` block** | You don’t have to declare the LLM model, temperature, or output format. Sensei falls back to its defaults automatically. (See the FAQ in the guide: “Do I have to define `llm`? No.”) |
| **`user.context`** | Context items and personality snippets are purely optional flavor. You can skip the entire list if you don’t need extra constraints or persona prompts. |
| **Personality references** | Since `context` is optional, referencing `personalities/<file>.yml` is also optional. Only include them when you want that extra spice. |
| **`conversation.goal_style` tweaks** | The whole `goal_style` block can be omitted. If you do include it, sub-fields such as `steps`, `random steps`, `all_answered.limit`, or `max_cost` are optional knobs. |
| **`conversation.max_cost`** | Global budget caps for the profile run are nice safeguards, but you can leave them out. |
| **`interaction_style`** | Totally optional. If you omit it, Sensei uses its default “natural” behavior. |
| **`chatbot.fallback`** | Highly recommended to avoid loops, yet not mandatory. If you don’t set it, Sensei just uses a generic fallback. |
| **Extra metadata** | Friendly names, descriptions, and other explanatory strings (like the descriptive text inside `chatbot.output`) aren’t required for execution—they’re there to help humans or downstream tooling. |

---

### ⚠️ Core pieces you **should** keep

To avoid surprises, make sure your profile still includes:

- **`test_name`** (gives your run a recognizable label)
- **`user` block** with at least `language`, `role`, and your goal prompts/variables
- **`chatbot.output`** fields if you plan to validate anything later (Sensei-check rules rely on them)
- **`conversation.number`** so Sensei knows how many runs to generate (even a simple `number: 1` works)

As long as those essentials are covered, you can safely drop the optional bits when you don’t need them. If you ever want to grow the profile later—add richer personas, interaction styles, or cost guards—it’s just a matter of popping those sections back in.
