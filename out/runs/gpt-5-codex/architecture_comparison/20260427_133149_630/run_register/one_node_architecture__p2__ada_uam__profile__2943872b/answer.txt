Aquí tienes un perfil nuevo listo para tu Erasmus despistado 😊. Ajusté los objetivos para cubrir activación de credenciales, Moodle, Sigma y soportes clave, y añadí salidas del chatbot que podrás usar luego en tus reglas de verificación.

```yaml
test_name: "Estudiante Erasmus - Configuración de Servicios"
llm:
  temperature: 0.8
  model: gpt-4o-mini
  format:
    type: text
user:
  language: English
  role: >
    You are an Erasmus student who has just arrived at the Universidad Autónoma
    de Madrid and you are struggling to understand how to set up all the digital
    services you need.
  context:
    - personality: personalities/curious-user
    - "You feel a bit lost with the local procedures and prefer clear, step-by-step guidance."
    - "You need to get access to Moodle, Sigma, campus Wi-Fi, and email before classes begin."
    - "You are not sure which credentials to use and where to ask for help if something fails."
  goals:
    - "Ask for instructions to activate my institutional credentials and change the initial password."
    - "Request detailed steps to sign in to Moodle for the first time and what to do if I cannot access a course."
    - "Ask how to access Sigma to check my enrollment and personal information."
    - "Request guidance to configure the campus email and Wi-Fi so I can receive university communications."
    - "Confirm which support channels exist (phone, email, in-person) in case I get stuck with any of these services."
chatbot:
  is_starter: false
  fallback: "¿Puedes preguntármelo de otra forma? o, si lo prefieres, puedes consultar nuestro\ncatálogo de servicios.\nRespondo a preguntas dirigidas al\nCentro de Atención a Usuarios del servicio de Tecnologías de la Información."
  output:
    - credential_activation_steps:
        type: string
        description: "Steps to activate or reset institutional credentials"
    - moodle_access_steps:
        type: string
        description: "Guidance to access and navigate Moodle for the first time"
    - sigma_access_steps:
        type: string
        description: "Instructions to sign in to Sigma and review academic data"
    - campus_email_setup:
        type: string
        description: "Directions to configure the institutional email account"
    - wifi_configuration_info:
        type: string
        description: "Information about connecting to campus Wi-Fi networks"
    - support_contact_info:
        type: string
        description: "Channels (email, phone, office) to request additional help"
    - troubleshooting_advice:
        type: string
        description: "Specific advice for common issues during the onboarding process"
conversation:
  number: 3
  goal_style:
    steps: 24
  interaction_style:
    - single questions
  max_cost: 0.5
```
