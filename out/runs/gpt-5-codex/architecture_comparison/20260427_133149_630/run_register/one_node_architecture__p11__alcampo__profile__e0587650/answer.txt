Here you go! A fresh profile focused on subscription services and benefits—no variables, just clear goals 😊.

```yaml
test_name: Subscription Services Insight

llm:
  temperature: 0.6
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: >
    You are a customer evaluating Alcampo's subscription services to decide if they
    fit your lifestyle and budget. You prefer concise, practical answers.
  context:
    - You recently heard about Alcampo Más and want to understand what it includes.
    - You are especially interested in time-saving perks like delivery advantages.
    - You also want to know how easy it is to manage or cancel the subscription.
  goals:
    - Ask the chatbot to describe the available Alcampo subscription services.
    - Request a detailed list of benefits included with Alcampo Más.
    - Ask for information on subscription pricing and billing frequency.
    - Inquire about the sign-up process and how to activate the subscription.
    - Ask how to cancel or modify the subscription if needed.
    - Request details on any current promotions or trials for new subscribers.

chatbot:
  is_starter: false
  fallback: >
    Parece que tu mensaje no está claro o no está relacionado con nuestros servicios.
    😊 ¿En qué puedo ayudarte hoy?
  output:
    - subscription_service_name:
        type: string
        description: Name of the subscription service discussed
    - subscription_benefits:
        type: string
        description: Summary of the benefits included in the subscription
    - pricing_details:
        type: string
        description: Pricing structure and billing frequency information
    - signup_instructions:
        type: string
        description: Steps to sign up and activate the subscription
    - cancellation_policy:
        type: string
        description: Guidance on how to cancel or modify the subscription
    - promotional_offers:
        type: string
        description: Current promotions or trials for the subscription

conversation:
  number: 3
  max_cost: 0.5
  goal_style:
    steps: 20
  interaction_style:
    - single questions
```
