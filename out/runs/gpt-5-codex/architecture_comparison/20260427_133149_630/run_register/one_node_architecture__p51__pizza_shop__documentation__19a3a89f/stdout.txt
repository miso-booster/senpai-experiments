Hey there! 😊 Connectors are Sensei’s way of talking directly to your chatbot. Think of them as little instruction sheets that explain *how* to send a user message to your bot’s API and *where* to grab the bot’s reply. You describe the API call once in YAML, and Sensei reuses it for every simulated conversation.

Here are the key fields you’ll define:

- **`name`** *(optional)* – Just a friendly label so you can recognize the connector.
- **`base_url`** *(required)* – The root URL for the chatbot API.
- **`send_message`** *(required)* – A block describing the HTTP request:
  - `path` *(required)* – Endpoint appended to `base_url`.
  - `method` *(optional, defaults to POST)* – HTTP verb (POST, GET, etc.).
  - `headers` *(optional)* – Any headers you need, like `Content-Type` or auth tokens.
  - `payload_template` *(required)* – JSON body with a `{user_msg}` placeholder where Sensei injects the simulated user’s message.
- **`response_path`** *(required)* – Dot-notated path to the chatbot’s reply in the JSON response (for example, `"response.0.text"`).

Once you fill those in, Sensei can send messages, receive replies, and keep the whole conversation flowing automatically. Pretty neat, right? Let me know if you’d like to sketch one together! 🚀
