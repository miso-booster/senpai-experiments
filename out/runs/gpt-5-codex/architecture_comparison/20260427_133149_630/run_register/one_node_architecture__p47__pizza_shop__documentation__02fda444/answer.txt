In Sensei, a **metamorphic rule** is a special kind of validation you write in **Sensei-check** to compare multiple conversations and ensure the chatbot’s behaviour changes (or stays the same) in a consistent way when the inputs change. Instead of judging a single answer in isolation, you describe a relationship that should hold **across two or more conversations**.

For example, you might write a rule saying: “If two pizza orders have the same size and drink, but one has more toppings, its price must be higher.” Sensei-check then looks at all generated conversations, finds pairs that match the “same size and drink” condition, and checks whether the price relation holds.

Key ingredients of a metamorphic rule:
- `conversations: N` (with N ≥ 2, or even `all` for global checks).
- An optional `when:` clause to select comparable conversations.
- Either an `oracle:` boolean expression or an `if:`/`then:` implication describing the expected relation.
- Field references like `conv[0].price` come from the profile’s `chatbot.output`.

They’re super handy when you can’t hard-code a “correct” answer but you still know how outputs should behave relative to each other 🧠✨
