Great question! In Sensei-check rules, an **oracle** is the boolean expression that actually decides whether the rule passes or fails. As described in `sensei-check-doc.md`, you put that expression under the `oracle:` key, and the rule evaluates it after selecting the relevant conversation(s). If the expression returns `True`, the rule passes; if it returns `False`, the rule fails.

A few handy details from the docs:

- Oracles can work on a single conversation (e.g., `extract_float(price) >= 10`) or on multiple conversations using `conv[i]` references (e.g., comparing `conv[0].price` and `conv[1].price`).
- For implication-style checks, you can split the logic into `if:` and `then:` instead of a single `oracle:`—still the same idea, just clearer wording.

So, think of the oracle as the rule’s “truth test”: once your `when` filter picks the conversations, the oracle is the condition that must hold for the rule to pass.
