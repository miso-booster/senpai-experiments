In Sensei-check, a **metamorphic rule** is a validation rule that compares **multiple conversations at once** to make sure the chatbot behaves consistently when inputs change in controlled ways. Instead of judging each conversation in isolation, the rule says something like: “If two scenarios only differ in X, then their outputs should relate in Y way.” For example, you might check that when everything else is equal, the conversation where the user orders more items should produce a higher total price.

Key traits of metamorphic rules (from `sensei-check-doc.md`):

- They set `conversations:` to a number ≥ 2 (or `all`) so the rule engine knows to group conversations.
- A `when:` filter can select comparable pairs/tuples (same pizza size, same itinerary, etc.).
- The relationship itself is expressed with `oracle:` (single boolean) or with an `if`/`then` implication that spells out the expected behavior across the selected conversations.
- They typically reference profile outputs as `conv[0].field_name`, `conv[1].field_name`, etc., so they depend on what the associated Sensei Chat profile exposes in `chatbot.output`.

Think of them as “consistency checks across variations” that help catch subtle regressions that single-conversation checks might miss.
