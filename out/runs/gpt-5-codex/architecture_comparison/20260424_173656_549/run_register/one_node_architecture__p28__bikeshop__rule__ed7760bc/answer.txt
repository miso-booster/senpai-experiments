Absolutely! Here’s a handy global rule you can drop into your `rules/` folder to make sure the assistant mirrors the user’s language every time:

```yaml
name: responds_in_same_language
description: The chatbot replies in the same language the user used.
conversations: 1
active: true
oracle: responds_in_same_language()
on-error: "Assistant language mismatch detected in conversation {conversation_id}"
```

This one doesn’t rely on any specific `chatbot.output` fields—perfect for enforcing a universal language consistency check across all your profiles. Let me know if you’d like to add extra logging or pair it with other style rules 😊
