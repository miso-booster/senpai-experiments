A metamorphic rule in Sensei-check is a validation that looks at **relationships across multiple conversations**, rather than judging a single dialogue in isolation. According to `sensei-check-doc.md`, these rules:

- **Select comparable conversations** (with `conversations: <number>` ≥ 2) and an optional `when:` filter so you’re comparing apples to apples—e.g., same pizza size or identical user inputs.
- **State the expected relation** using either a single `oracle:` expression or an `if:/then:` pair. For instance, “if one order has more toppings than another, then its price must be higher.”
- **Reference profile outputs via `conv[i].field`**, relying on whatever slots the linked Sensei Chat profile exposes in its `chatbot.output`.

In short, metamorphic rules help you assert invariants like monotonicity, consistency, or language adherence across a batch of generated conversations. They’re super handy when there’s no single “correct” answer, but you still expect certain behaviors to remain stable 😊.
