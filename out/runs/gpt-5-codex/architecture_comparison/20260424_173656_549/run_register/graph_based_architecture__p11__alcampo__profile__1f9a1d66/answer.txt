¡Claro! Aquí tienes un perfil listo para que Sensei simule a una persona que quiere informarse sobre los servicios de suscripción y sus beneficios. No incluye variables, tal como pediste 😊

```yaml
test_name: Subscription Services Information

llm:
  temperature: 0.6
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: Customer exploring Alcampo’s subscription services to decide if it’s worth joining.
  context:
    - You are considering signing up for an Alcampo subscription to simplify your grocery routine.
    - You want to understand what benefits and perks are included before committing.
    - You’re also comparing the subscription with other convenience services like delivery passes.
  goals:
    - Ask the chatbot to explain what subscription services Alcampo offers.
    - Request a detailed overview of the benefits included in those subscription services.
    - Inquire about the cost of subscribing and whether fees vary by location or store.
    - Ask if there are current promotions or introductory offers for new subscribers.
    - Request clarification on product substitutions and delivery guarantees included with the subscription.
    - Ask about cancellation policies and how to manage the subscription if plans change.

chatbot:
  is_starter: false
  fallback: Parece que tu mensaje no es claro o no es una pregunta relacionada con Alcampo. 😊 ¿En qué puedo ayudarte hoy? Estoy aquí para resolver tus dudas sobre nuestros productos y servicios.
  output:
    - subscription_services_overview:
        type: string
        description: Summary of subscription services offered by Alcampo
    - subscription_benefits:
        type: string
        description: Detailed list of benefits included in the subscription
    - subscription_cost_details:
        type: string
        description: Pricing and fee structure for the subscription service
    - promotional_offers:
        type: string
        description: Current promotions or introductory offers for new subscribers
    - substitution_and_delivery_policy:
        type: string
        description: Information about product substitutions and delivery guarantees
    - cancellation_policy:
        type: string
        description: Steps to cancel or manage the subscription

conversation:
  number: 3
  max_cost: 0.5
  goal_style:
    steps: 24
  interaction_style:
    - single questions
```

Si necesitas ajustar el tono del usuario, la cantidad de conversaciones o el esquema de `chatbot.output`, dime y lo adaptamos juntos.
