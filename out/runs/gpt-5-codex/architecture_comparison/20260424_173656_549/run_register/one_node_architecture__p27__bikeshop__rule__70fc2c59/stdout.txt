¡Vamos a blindar esas agendas! 😊 Aquí tienes una regla metamórfica lista para tu proyecto. Comprueba que nunca se confirmen dos citas para la misma fecha y hora (si la segunda se acepta, la regla fallará).

```yaml
name: rechaza_fecha_duplicada
description: Evita confirmar dos citas iguales (mismo día y hora) en el perfil appointment.
conversations: 2
when: conv[0].confirmed_date is not None and conv[1].confirmed_date is not None and conv[0].confirmed_time is not None and conv[1].confirmed_time is not None
oracle: (conv[0].confirmed_date, conv[0].confirmed_time) != (conv[1].confirmed_date, conv[1].confirmed_time)
on-error: f"Se confirmó dos veces la cita del {conv[0].confirmed_date} a las {conv[0].confirmed_time}."
```

Guárdala en tu carpeta de reglas y estarás validando que, si se intenta reservar la misma fecha dos veces, el asistente rechace la segunda vez como debe ser. Si necesitas ajustar algo (por ejemplo, considerar también el servicio), dime y lo adaptamos. 💪
