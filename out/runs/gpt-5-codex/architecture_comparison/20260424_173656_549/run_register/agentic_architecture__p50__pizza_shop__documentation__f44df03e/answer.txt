In Sensei-check rules, an **oracle** is the boolean expression that actually evaluates whether the conversations pass or fail the rule. You place it under the `oracle:` key in the YAML, and it should resolve to `True` when everything is correct and `False` when there’s a problem. For single-conversation rules the oracle typically inspects the slots extracted from that dialogue (for example, `data_collected() == True` to ensure all fields are filled). In multi-conversation or global rules, the oracle can compare values across conversations using helpers like `language(...)`, `extract_float(...)`, or dataset-level checks such as `is_unique('order_id')`.  

If you need more structure—especially for metamorphic tests—you can swap `oracle:` for an `if:` / `then:` pair, but at the end of the day the idea is the same: describe the condition that must hold.  

This behaviour is spelled out in **`sensei-check-doc.md`**, and you can see concrete examples in **`rules-examples.md`** (e.g., the `chatbot_fills_all_slots` rule whose oracle calls `data_collected()`).
