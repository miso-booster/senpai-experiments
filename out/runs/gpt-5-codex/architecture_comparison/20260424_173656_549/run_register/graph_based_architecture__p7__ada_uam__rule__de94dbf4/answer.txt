¡Listo! Aquí tienes una regla de Sensei-check que verifica que el perfil “ada uam” devuelva todos los datos oficiales del CAU. Usa igualdad estricta para el correo, normaliza el teléfono quitando espacios y compara la dirección con `semantic_content` para tolerar ligeras variaciones en la redacción.

```yaml
name: cau_contact_details_complete
description: Verifica que el perfil ada_uam entregue correo, teléfono y dirección oficiales del CAU.
conversations: 1
oracle: |
  (
    contact_email.strip().lower() == 'cau@uam.es'
    and ''.join(contact_phone.split()) == '914974029'
    and semantic_content(
      physical_address,
      'Higher Polytechnic School, C/ Francisco Tomás y Valiente nº 11, Building B, first floor, office TI-107'
    )
  )
on-error: >
  Datos CAU incompletos o incorrectos -> email: {contact_email}; teléfono: {contact_phone}; dirección: {physical_address}
```

Si necesitas ajustar tolerancias (por ejemplo, permitir distintos formatos de teléfono) me dices y lo retocamos sin problema 😊.
