- **Clear user intent:** The context and goals spell out the customer’s focus on customizing seat and grips.

- **Outputs aligned with checks:** Fields like `seat_adjustment_details` and `fitting_service_price` make it easy to write Sensei-check rules later (e.g., validating that the bot confirms the service and prices it).
