Great question! In Sensei-check rules, an **oracle** is simply the condition that must be true for the rule to pass ✅. You write it as a Python-like expression under the `oracle:` key inside your YAML rule. When Sensei runs your conversations, it evaluates that expression—if it returns `True`, the rule passes; if it’s `False`, the rule fails.

Here’s a tiny example:

```yaml
name: chatbot_fills_all_slots
description: All conversation slots are filled
conversations: 1
oracle: data_collected() is True
```

In this case, the oracle is `data_collected() is True`, which checks that every slot exposed by the profile’s `chatbot.output` was filled. Metamorphic rules can also use `if:`/`then:` instead of a single oracle, but for straightforward checks, `oracle:` is the go-to field 💡
