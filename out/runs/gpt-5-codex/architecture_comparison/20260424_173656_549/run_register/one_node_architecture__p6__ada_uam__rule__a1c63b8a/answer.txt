¡Listo! Aquí tienes la regla que confirma que el chatbot de Ada UAM devuelve todos los datos de contacto del CAU 😊.

```yaml
name: cau_contact_info_complete
description: Verifica que el chatbot entregue correo, teléfono y dirección del CAU
conversations: 1
oracle: all(value not in [None, '', 'N/A'] for value in [contact_email, contact_phone, physical_address])
on-error: f"Faltan datos de contacto del CAU: email={contact_email}, teléfono={contact_phone}, dirección={physical_address}"
```
