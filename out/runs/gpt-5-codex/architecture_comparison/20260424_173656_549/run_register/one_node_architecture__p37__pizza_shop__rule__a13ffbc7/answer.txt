¡Claro! Aquí tienes una regla que valida, para el perfil `pizzaorder_ivan_test`, que el asistente confirme la bebida solicitada (mencionando el tipo y la cantidad en la confirmación del pedido):

```yaml
name: assistant_confirms_requested_drink
description: Verifica que la confirmación del pedido mencione la bebida y cantidad solicitadas.
conversations: 1
active: true
when: pizza_order_confirmation is not None and selected_drink_type is not None
if: drink_quantity_requested is not None and drink_quantity_requested > 0
then: semantic_content(pizza_order_confirmation, f"{drink_quantity_requested} {selected_drink_type}") is True
on-error: >
  f"La confirmación del pedido no menciona la bebida solicitada. Confirmación: {pizza_order_confirmation};
  bebida pedida: {drink_quantity_requested} {selected_drink_type}"
```
