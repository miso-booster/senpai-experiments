To enforce “same language in, same language out,” Sensei-check already gives us a handy helper called `responds_in_same_language()`. It scans the whole conversation and makes sure every assistant message matches the user’s language. Because it doesn’t depend on any profile-specific outputs, it works as a global/style rule.

Here’s a ready-to-use rule you can drop into your rules folder (each document should live in its own YAML file):

```yaml
name: mirror_user_language
description: Assistant replies in the same language as the user throughout the conversation
conversations: 1
oracle: responds_in_same_language() is True
```

A couple of tips:

- `conversations: 1` means the rule runs separately on each generated conversation.
- If you ever need to narrow it down (for example, only Spanish dialogs), you can add a `when` filter like `when: language(user_phrases) == 'ESP'`.
- The helper already handles multi-turn exchanges, so you don’t need extra logic for partial language switches.

Let me know if you’d like to combine this with other style checks or tailor it to a specific language!
