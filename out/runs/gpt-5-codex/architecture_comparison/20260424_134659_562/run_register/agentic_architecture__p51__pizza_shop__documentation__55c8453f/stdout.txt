¡Hola! 😊 Los conectores sirven para que el Chatbot Dojo pueda hablar con un chatbot externo sin necesidad de escribir código adicional. Básicamente, son archivos YAML que describen cómo enviar el mensaje del simulador al API de tu bot y cómo extraer la respuesta. Así, el perfil del simulador genera las conversaciones, el conector realiza las llamadas HTTP y las reglas pueden validar los resultados.

Según la documentación (`custom-connector-guide.md` y los ejemplos en `connector-examples.md`), los campos principales son:

- **`name`** *(opcional)*: un nombre amistoso para identificar el conector.
- **`base_url`** *(obligatorio)*: la URL base del API del chatbot.
- **`send_message`** *(obligatorio)*: bloque que define cómo enviar la petición.
  - `path` *(obligatorio)*: endpoint que se adjunta a `base_url`.
  - `method` *(opcional, por defecto `POST`)*: método HTTP (POST, GET, etc.).
  - `headers` *(opcional)*: cabeceras para autenticación u otros requisitos.
  - `payload_template` *(obligatorio)*: el cuerpo JSON; aquí colocas `{user_msg}` donde quieras que se inserte el mensaje del usuario.
- **`response_path`** *(obligatorio)*: ruta en notación de puntos para encontrar el texto de respuesta dentro del JSON devuelto (por ejemplo, `response.0.text`).

Con eso, el conector sabe exactamente cómo construir la solicitud y dónde buscar la respuesta. Si necesitas ver un ejemplo concreto, los archivos de ejemplo muestran cómo añadir cabeceras de autenticación o cómo manejar respuestas anidadas. ¿Te gustaría que revisemos un conector existente o creemos uno nuevo?
