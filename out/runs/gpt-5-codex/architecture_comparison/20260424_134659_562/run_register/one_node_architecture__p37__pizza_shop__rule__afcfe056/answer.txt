¡Claro! Aquí tienes una regla que verifica que, cuando el usuario pide una bebida, la confirmación del asistente mencione ese mismo tipo de bebida. 😊

```yaml
name: assistant_confirms_requested_drink
description: Cuando el usuario solicita una bebida, la confirmación del asistente debe mencionar esa misma bebida.
active: true
conversations: 1
when: conv[0].selected_drink_type not in [None, ''] and conv[0].pizza_order_confirmation not in [None, '']
oracle: conv[0].selected_drink_type.lower() in conv[0].pizza_order_confirmation.lower()
```
