Here’s a single-conversation Sensei-check rule that verifies the bike shop assistant returns the exact opening hours and prices you mentioned. Drop this into your rules folder (one YAML document per file or block):

```yaml
name: bike_shop_expected_info
description: Checks that the bike shop assistant returns the agreed hours and prices
conversations: 1
oracle: |
  (
    '10' in opening_and_closing
    and '20' in opening_and_closing
    and extract_float(tire) == 20
    and extract_float(tune_up) == 50
    and extract_float(seat_price) == 20
  )
```

### Why it works
- Ensures the `opening_and_closing` field mentions both “10” and “20” (matching the 10–20 schedule).
- Confirms the parsed numeric values for tire, tune-up, and seat prices match 20, 50, and 20 respectively.
- `extract_float` handles values like `$50` or `50 USD`, so you’re covered even if the assistant includes a currency symbol.
