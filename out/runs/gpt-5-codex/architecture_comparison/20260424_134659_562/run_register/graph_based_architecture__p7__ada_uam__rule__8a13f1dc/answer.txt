¡Claro! Aquí tienes una regla lista para confirmar que el perfil de **ada uam** rellena correctamente toda la información del CAU.  
La validación comprueba que el email coincida exactamente y usa `semantic_content` para tolerar pequeños cambios de formato en el teléfono y la dirección física.

```yaml
name: cau_contact_details_correct
description: Verifica que ada uam devuelve todos los datos de contacto oficiales del CAU
conversations: 1
oracle: data_collected() \
  and contact_email is not None and contact_email.lower() == 'cau@uam.es' \
  and semantic_content(contact_phone, '91 497 4029') \
  and semantic_content(physical_address, 'Higher Polytechnic School, C/ Francisco Tomás y Valiente nº 11, Building B, first floor, office TI-107')
```

Con esto podrás detectar cualquier respuesta incompleta o incorrecta respecto a esos campos clave. Si necesitas ajustar la tolerancia (por ejemplo, exigir un formato exacto para el teléfono), me dices y lo afinamos juntos 😊.
