Here you go! This profile steers the simulator through a custom pizza request, then pivots mid-chat to a predefined option 😊👇

```yaml
test_name: custom_to_predefined_switch

llm:
  temperature: 0.6
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: >
    You are a hungry customer who initially wants a fully custom pizza but
    later decides a predefined option is quicker.
  context:
    - You're planning a casual dinner and feel indecisive about the pizza details.
    - You start by insisting on a custom pizza, then realize you'd prefer a predefined pizza instead.
    - Mention that you still want a drink to accompany the order.
  goals:
    - "I want to build a {{initial_size}} custom pizza with {{initial_toppings}} and have it with a {{initial_drink}}."
    - "Ask how much that custom pizza would cost."
    - "Change your mind, cancel the custom idea, and ask what predefined pizzas are available."
    - "Choose the {{predefined_pizza}} pizza in a {{predefined_size}} size instead."
    - "Confirm the final order details, including the drink, and ask for the total price."
    - initial_size:
        function: pairwise()
        type: string
        data: [small, medium, large]
    - initial_toppings:
        function: pairwise()
        type: string
        data:
          - pepperoni and mushrooms
          - spinach and feta
          - bbq chicken and onions
    - initial_drink:
        function: forward()
        type: string
        data: [Coke, Sparkling Water, Lemonade]
    - predefined_pizza:
        function: forward()
        type: string
        data: [Margherita, Pepperoni, Vegetarian, Four cheese]
    - predefined_size:
        function: forward(predefined_pizza)
        type: string
        data: [small, medium, large]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I did not get what you said. I can help you ordering predefined or custom pizzas, and then drinks."
  output:
    - size:
        type: string
        description: "Final pizza size confirmed by the chatbot."
    - pizza_type:
        type: string
        description: "Final pizza type (custom or predefined) confirmed by the chatbot."
    - toppings:
        type: list[string]
        description: "Toppings listed for the final pizza."
    - drink:
        type: string
        description: "Drink confirmed for the order."
    - price:
        type: currency
        description: "Total price quoted for the final order."
    - order_summary:
        type: string
        description: "Chatbot's summary of the finalized order."

conversation:
  number: 6
  max_cost: 1.0
  goal_style:
    all_answered:
      export: false
      limit: 20
  interaction_style:
    - change your mind
    - long phrases
```

Let me know if you’d like variations (different languages, extra drink options, etc.) and we’ll tweak it together!
