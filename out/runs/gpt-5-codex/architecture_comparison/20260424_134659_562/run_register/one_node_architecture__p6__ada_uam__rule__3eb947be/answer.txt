¡Claro! Aquí tienes una regla para asegurarte de que el perfil **Consultante de servicios y asistencia del CAU** devuelve los tres datos de contacto imprescindibles 👇

```yaml
name: cau_contact_details_complete
description: Verifica que el perfil "Consultante de servicios y asistencia del CAU" entrega email, teléfono y dirección del CAU.
conversations: 1
active: true
oracle: all(field is not None and str(field).strip() for field in [contact_email, contact_phone, physical_address])
on-error: f"Información incompleta del CAU → email: {contact_email}, teléfono: {contact_phone}, dirección: {physical_address}"
```
