Sure thing! Since your profiles expose an `order_id` field in `chatbot.output`, you can add a simple single-conversation rule that verifies the assistant actually returns a non-empty value there. Here’s a ready-to-use Sensei-check rule:

```yaml
name: order_id_provided
description: Chatbot must return a non-empty order ID
conversations: 1
oracle: order_id is not None and str(order_id).strip() != ''
on-error: f"Missing or empty order_id in conversation: {order_id}"
```

This rule will flag any dialogue where the extracted `order_id` is missing, `None`, or just an empty string. Just drop it into your `rules/` folder, and you’re set! 😊
