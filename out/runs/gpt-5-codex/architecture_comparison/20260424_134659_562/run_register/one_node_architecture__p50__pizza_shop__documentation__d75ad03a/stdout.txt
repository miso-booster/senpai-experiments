Hey there! 😊 In the Sensei-check world, an **oracle** is just the condition that must be true for a conversation (or set of conversations) to pass a rule.

Think of it as your “truth test.” If the oracle expression evaluates to `True`, then the rule passes; if it’s `False`, the rule fails and you get a report.

For example, in a single-conversation rule you might say:

```yaml
oracle: extract_float(price) >= 10
```

That little expression is the oracle—Sensei-check runs it after each conversation to verify the chatbot behaved the way you expect.

So anytime you see `oracle:` (or the `if:`/`then:` combo in metamorphic rules), that’s the part defining the expected behavior you’re enforcing. Let me know if you’d like to see more examples!
