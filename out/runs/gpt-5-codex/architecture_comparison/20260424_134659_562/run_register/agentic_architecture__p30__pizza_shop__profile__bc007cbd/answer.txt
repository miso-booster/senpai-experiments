Here’s a profile tailor-made for that rude, speed-obsessed pizza customer:

**What’s inside**
- Four aggressive goals wired to four variables, with `pizza_size` and `toppings` using `pairwise()` so the conversation count comes straight from the pairwise matrix (`conversation.number: combinations(pairwise)`).
- Context and role dial up the impatience and rudeness, keeping the user on-brand.
- `chatbot.output` fields capture the essentials you’ll probably want later: size, toppings, promised ready time, fulfillment option, and total price.

I followed the structure and function guidance from `sensei-chat-guide.md`.

```yaml
test_name: "pizza_shop_rush_stress_test"

llm:
  temperature: 0.4
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are an impatient, rude customer ordering from a neighborhood pizza shop. You swear under your breath, interrupt constantly, and make it crystal clear that speed matters more than politeness.
  context:
    - "You are starving after a double shift and expect instant service."
    - "You threaten to blast the shop online if anything slows you down."
  goals:
    - "Bark an order for a {{pizza_size}} pizza overloaded with {{toppings}} and demand it immediately."
    - "Snarl that the order must be ready in {{ready_time}} minutes or you'll trash their reputation."
    - "Force them to arrange {{speed_option}} so you don't waste a second waiting."
    - "Remind them again that the {{pizza_size}} better be correct when you storm in."
    - pizza_size:
        function: pairwise()
        type: string
        data: [small, medium, large, extra-large]
    - toppings:
        function: pairwise()
        type: string
        data:
          - double pepperoni
          - spicy sausage
          - roasted veggie mix
          - black olive & feta
    - ready_time:
        function: forward()
        type: int
        data:
          min: 10
          max: 25
          step: 5
    - speed_option:
        function: random()
        type: string
        data:
          - express pickup counter
          - curbside handoff
          - priority delivery driver
          - in-kitchen fast-track

chatbot:
  is_starter: false
  fallback: "Apologies, could you repeat that request?"
  output:
    - promised_pizza_size:
        type: string
        description: "Pizza size the bot confirms it will prepare."
    - promised_toppings:
        type: string
        description: "Toppings combination the bot commits to."
    - quoted_ready_time:
        type: int
        description: "Minutes until the order is ready according to the bot."
    - fulfillment_option:
        type: string
        description: "Pickup or delivery speed arrangement offered."
    - total_price:
        type: currency
        description: "Quoted total price including rush handling."

conversation:
  number: combinations(pairwise)
  goal_style:
    steps: 4
  interaction_style:
    - all questions
```
