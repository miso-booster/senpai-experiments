To enforce that the assistant replies in the same language the user speaks, you can use the built-in helper `responds_in_same_language()` in a Sensei-check rule. This helper compares each user turn with the corresponding assistant reply and makes sure the language matches.

Here’s a ready-to-use rule you can drop into your Sensei-check ruleset:

```yaml
name: same_language_reply
description: Assistant should answer in the same language the user uses
conversations: 1
oracle: responds_in_same_language() is True
```

### How it works
- `responds_in_same_language()` returns `True` only if every assistant response matches the user’s language throughout the conversation.  
- If the bot slips into a different language at any point, the rule will fail and you’ll know alignment needs improvement.

Feel free to tweak the `description` if you want to reference a specific profile or testing scenario. Let me know if you’d like to combine this with other style checks or run it as part of a batch!
