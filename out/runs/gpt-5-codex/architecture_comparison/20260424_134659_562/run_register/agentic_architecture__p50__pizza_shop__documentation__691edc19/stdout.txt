Great question! In Sensei-check (the DSL for validation rules), an **oracle** is the boolean expression that actually evaluates whether the rule passes or fails for the conversations you selected. According to `sensei-check-doc.md`, you use either:

- `oracle: <python-style boolean expression>` for a direct check, or  
- an `if:` / `then:` pair, where the implication “if condition holds, then expected relation must also hold” acts as the oracle.

This expression can reference fields from the conversations (like `conv[0].price`) and call helper functions (`extract_float`, `language`, etc.). If the oracle evaluates to `True`, the rule passes; if it’s `False`, the rule fails. So, think of the oracle as the truth test the rule enforces over the selected dialogue data.
