Absolutely! Here's a Sensei-check rule you can drop into your project to ensure any conversation where the user orders a small pizza reports a $10 price in USD 😊

```yaml
name: small_pizza_price_is_10_usd
description: Small pizzas should cost exactly $10 USD (targets profiles exposing size + price)
active: true
conversations: 1
when: size[0] == 'small'
oracle: extract_float(price) == 10 and currency(price) == 'USD'
```
