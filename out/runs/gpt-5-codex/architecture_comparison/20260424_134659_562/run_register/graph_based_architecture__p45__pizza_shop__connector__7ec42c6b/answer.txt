Here you go! Based on the request/response you shared, this YAML connector keeps the headers to the essentials (`Content-Type` and `Authorization`) and pulls out the assistant reply. I’ve added a `response_filters` section with `strip_html` so the returned text comes back nice and clean—no tags 🎉. If your connector runtime doesn’t yet recognize `response_filters`, you’ll need to strip the HTML downstream, but give this a try first:

```yaml
name: "SAIC Málaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
response_filters:
  - strip_html
```
