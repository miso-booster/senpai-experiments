¡Perfecto! Aquí tienes un perfil Sensei listo para poner a prueba al chatbot de la UAM con un usuario que busca datos de contacto del CAU. Incluye las metas concretas, el tono del usuario y los campos que queremos extraer del bot. Solo copia este YAML dentro de tu carpeta `profiles/` y ajústalo si necesitas algún matiz adicional 😊

```yaml
test_name: "Consulta de contacto del CAU"

llm:
  model: gpt-4o-mini
  temperature: 0.5
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita información de contacto del Centro de Atención a Usuarios (CAU) de la UAM."
  context:
    - "Te han pedido que gestiones un incidente con el soporte técnico universitario y necesitas comunicarte con el CAU cuanto antes."
    - "Eres organizado y prefieres anotar todos los datos de contacto relevantes en un mismo lugar."
  goals:
    - "Solicitar el número de teléfono del CAU para soporte técnico."
    - "Pedir la dirección de correo electrónico del CAU."
    - "Preguntar la ubicación física de las oficinas del CAU."
    - "Confirmar el horario de atención del CAU."

chatbot:
  is_starter: false
  fallback: "¿Puedes preguntármelo de otra forma? o, si lo prefieres, puedes consultar nuestro catálogo de servicios. Respondo a preguntas dirigidas al Centro de Atención a Usuarios del servicio de Tecnologías de la Información."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono oficial del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico de contacto del CAU"
    - physical_address:
        type: string
        description: "Dirección física de las oficinas del CAU"
    - support_hours:
        type: string
        description: "Horario de atención oficial del CAU"

conversation:
  number: 3
  goal_style:
    steps: 12
  interaction_style:
    - single questions
  max_cost: 0.4
```

Si quieres cubrir más variaciones (por ejemplo, diferentes tonos de usuario o idiomas), podemos extenderlo en un momento. ¿Te gustaría añadir algo más?
