Hey there! 👋 Connectors are Sensei’s way of talking to your real chatbot without writing any Python. You drop a YAML file in `connectors/`, and it tells Sensei exactly how to call your bot’s API—what URL to hit, which headers to send, how the payload should look, and where to find the bot’s reply in the JSON response.

Here are the key fields you’ll see in a connector file:

- **`name`** *(optional)* – a friendly label so you remember which bot this file targets.
- **`base_url`** *(required)* – the root URL for your chatbot API, e.g. `https://api.mybot.com`.
- **`send_message`** *(required block)* – describes how to send the user’s input.
  - **`path`** *(required)* – endpoint appended to the base URL (like `/chat` or `/api/messages`).
  - **`method`** – HTTP method; defaults to `POST` if you skip it.
  - **`headers`** – any custom headers (authorization tokens, content type, etc.).
  - **`payload_template`** *(required)* – JSON body sent to your bot. Use `{user_msg}` anywhere you want Sensei to drop in the simulated user’s message.
- **`response_path`** *(required)* – the dot notation path telling Sensei where to extract the chatbot’s reply from the JSON response (e.g. `data.answer.text` or `response.0.message`).

Once that’s set, Sensei injects the profile-generated user messages into your connector, captures the bot’s responses via `response_path`, and feeds them back into the conversation and rule checks. Super handy for testing production APIs without custom code! Let me know if you want help drafting or debugging a connector YAML 😊
