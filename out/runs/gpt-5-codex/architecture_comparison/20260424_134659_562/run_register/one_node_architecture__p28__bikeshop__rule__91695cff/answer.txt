Absolutely, happy to help! Here’s a ready-to-use Sensei-check rule that verifies the assistant replies in the same language as the user. You can drop it into your project’s `rules/` folder.

```yaml
name: responds_in_user_language
description: Ensures the chatbot answers in the same language as the user
conversations: 1
oracle: responds_in_same_language()
on-error: "Assistant language mismatch detected in conversation {{conv_id}}."
```
