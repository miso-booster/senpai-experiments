¡Claro! Aquí tienes una regla sencilla para validar que el chatbot entregue una lista de juguetes eco-friendly (por ejemplo, la expuesta en el perfil **Pet Products Inquiry**) usando el campo `eco_friendly_toys`:

```yaml
name: eco_friendly_toys_listed
description: Verifica que el chatbot devuelva una lista de juguetes eco-friendly en el perfil de productos para mascotas.
conversations: 1
oracle: eco_friendly_toys is not None and len(eco_friendly_toys) > 0
on-error: f"No se extrajo ninguna lista de juguetes eco-friendly: {eco_friendly_toys}"
```

Esta regla se activa con una sola conversación y confirma que el campo `eco_friendly_toys` no esté vacío. Si necesitas validar también que el campo sea realmente una lista (por ejemplo, cambiando el tipo a `list[string]` en el perfil), avísame y lo ajustamos 😊
