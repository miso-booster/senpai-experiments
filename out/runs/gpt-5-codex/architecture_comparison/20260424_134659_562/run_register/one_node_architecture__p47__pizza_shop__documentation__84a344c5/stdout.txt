Hey there! 😊 In Sensei (specifically the Sensei-check module), a **metamorphic rule** is a test that compares two or more conversations to verify how the chatbot’s behavior should change—or stay the same—when user inputs vary in controlled ways. Instead of checking a single dialogue in isolation, you define a relationship between multiple conversations that meet a filter and assert the expected outcome.

For example, a metamorphic rule might say: *“If two pizza orders have the same size and drink, but one has more toppings, then it should cost more.”* Sensei-check evaluates real conversations generated by your Sensei profiles and flags any that violate that relationship.

So, think of metamorphic rules as your way to express “if input changes like this, output should react like that” across conversations—super handy for catching logical inconsistencies. Let me know if you’d like to see a concrete YAML example!
