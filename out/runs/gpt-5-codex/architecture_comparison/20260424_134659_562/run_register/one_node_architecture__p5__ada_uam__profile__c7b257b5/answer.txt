¡Aquí tienes un nuevo perfil listo para poner a prueba al chatbot de la UAM con consultas sobre el CAU! 😊

```yaml
test_name: "Consulta de Contacto del CAU"

llm:
  temperature: 0.6
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres un usuario que necesita contactar con el Centro de Atención a Usuarios (CAU) de la UAM.
    Buscas obtener sus datos de contacto para resolver dudas urgentes.
  context:
    - personality: personalities/formal-user
    - "Necesitas asegurarte de tener a mano todos los medios oficiales de contacto del CAU."
    - "Quieres verificar que los datos estén actualizados antes de realizar la llamada o enviar un correo."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir la dirección de correo electrónico oficial del CAU."
    - "Preguntar por la dirección física donde se encuentra el CAU."
    - "Solicitar el horario de atención del CAU, incluyendo días y horas."

chatbot:
  is_starter: false
  fallback: "¿Podrías reformular tu consulta? También puedes revisar nuestro catálogo de servicios. Respondo a preguntas relacionadas con el Centro de Atención a Usuarios."
  output:
    - cau_phone_number:
        type: string
        description: "Número de teléfono del CAU"
    - cau_email_address:
        type: string
        description: "Correo electrónico del CAU"
    - cau_physical_address:
        type: string
        description: "Dirección física del CAU"
    - cau_opening_hours:
        type: string
        description: "Horario de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 20
  interaction_style:
    - single questions
  max_cost: 0.5
```
