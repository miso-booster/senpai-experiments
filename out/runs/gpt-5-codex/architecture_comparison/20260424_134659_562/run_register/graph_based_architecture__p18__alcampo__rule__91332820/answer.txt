¡Claro! Aquí tienes una regla Sensei-check para asegurarte de que el chatbot devuelve una lista de juguetes eco-friendly a través del campo `eco_friendly_toys` del `chatbot.output`. Comprueba que sea una lista, que tenga al menos un elemento y que los nombres parezcan relacionados con productos ecológicos. 😊

```yaml
name: eco_friendly_toys_list_present
description: El chatbot debe devolver una lista de juguetes eco-friendly mediante el campo eco_friendly_toys.
conversations: 1
oracle: isinstance(eco_friendly_toys, list) and len(eco_friendly_toys) > 0 and all(any(keyword in toy.lower() for keyword in ['eco', 'sosten', 'recicl', 'madera']) for toy in eco_friendly_toys)
on-error: "No se encontró una lista válida de juguetes eco-friendly: eco_friendly_toys={eco_friendly_toys}"
```

> 📝 Asegúrate de que tu perfil de Sensei Chat exponga este campo en `chatbot.output` con el nombre `eco_friendly_toys`, idealmente como una lista de cadenas.  
> Si prefieres otro criterio (por ejemplo, solo verificar que la lista no esté vacía), dímelo y lo ajustamos sin problema.
