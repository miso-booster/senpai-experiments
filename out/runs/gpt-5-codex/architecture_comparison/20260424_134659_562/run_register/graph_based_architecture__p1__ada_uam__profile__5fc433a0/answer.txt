¡Listo! Aquí tienes un perfil Sensei completito para simular a un usuario que está intentando configurar eduroam sin éxito. Usé variables para representar las distintas vías de configuración que va probando, tal como pediste 😊. Siéntete libre de ajustar los textos o añadir más métodos si lo necesitas.

```yaml
test_name: "Configuración frustrada de eduroam"

llm:
  temperature: 0.6
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Usuario universitario que necesita conectar su dispositivo personal a la red eduroam
    pero no consigue completar la configuración correctamente.
  context:
    - personality: personalities/impatient-user
    - "Dependes de la red Wi-Fi para entregar trabajos y asistir a clases híbridas."
    - "Has leído la documentación oficial, pero los pasos no coinciden con lo que ves en tu dispositivo."
    - "Te preocupa que algún certificado o ajuste de seguridad esté impidiendo la conexión."
  goals:
    - "Explicar que he intentado configurar eduroam en mi {{device_type}} usando {{primary_method}}, pero nunca llega a conectar."
    - "Solicitar una guía paso a paso para repetir el proceso con {{secondary_method}}."
    - "Pedir enlaces o archivos necesarios para {{primary_method}} y {{secondary_method}}, incluyendo certificados digitales."
    - "Preguntar si existen recomendaciones avanzadas al probar {{tertiary_method}}, por ejemplo ajustes de seguridad o eliminación de perfiles previos."
    - "Solicitar consejos de diagnóstico para los errores de autenticación que aparecen tras intentar {{primary_method}}."
    - device_type:
        function: another()
        type: string
        data:
          - "smartphone Android"
          - "portátil Windows 11"
          - "MacBook con macOS Sonoma"
          - "iPhone con iOS 17"
          - "portátil con Linux (Ubuntu 22.04)"
    - primary_method:
        function: pairwise()
        type: string
        data:
          - "la aplicación Eduroam CAT desde Google Play"
          - "el instalador Eduroam CAT para Windows 11"
          - "el perfil móvil .mobileconfig para iOS obtenido en el portal UAM"
          - "la configuración manual de 802.1X en Android"
          - "el asistente de redes de macOS con perfil descargado"
          - "el gestor de conexiones NetworkManager en Linux"
    - secondary_method:
        function: pairwise()
        type: string
        data:
          - "la aplicación Eduroam CAT desde Google Play"
          - "el instalador Eduroam CAT para Windows 11"
          - "el perfil móvil .mobileconfig para iOS obtenido en el portal UAM"
          - "la configuración manual de 802.1X en Android"
          - "el asistente de redes de macOS con perfil descargado"
          - "el gestor de conexiones NetworkManager en Linux"
    - tertiary_method:
        function: random()
        type: string
        data:
          - "reinstalar la aplicación Eduroam CAT y borrar perfiles previos"
          - "configurar manualmente certificados y protocolos EAP-TTLS/PAP"
          - "usar el asistente del portal UAM para generar un nuevo perfil"
          - "solicitar ayuda presencial en el CAU para revisar certificados"
          - "crear un perfil de red temporal con credenciales provisionales"

chatbot:
  is_starter: false
  fallback: "¿Podrías reformular tu consulta, por favor? También puedes revisar nuestro catálogo de servicios para ver más opciones."
  output:
    - eduroam_prerequisites:
        type: string
        description: "Requisitos previos para conectarse (credenciales, certificados, etc.)"
    - step_by_step_primary_method:
        type: string
        description: "Pasos detallados para el método principal mencionado por el usuario"
    - step_by_step_secondary_method:
        type: string
        description: "Pasos detallados para el método alternativo sugerido"
    - troubleshooting_suggestions:
        type: string
        description: "Consejos de diagnóstico y resolución de errores de autenticación"
    - certificate_download_links:
        type: string
        description: "Enlaces a instaladores, perfiles o certificados necesarios"
    - device_specific_notes:
        type: string
        description: "Indicaciones particulares según el tipo de dispositivo"
    - support_contact_info:
        type: string
        description: "Información de contacto del CAU o servicio técnico"

conversation:
  number: combinations(0.6, pairwise)
  goal_style:
    steps: 24
    max_cost: 0.6
  interaction_style:
    - change your mind
    - make spelling mistakes
```

Si necesitas adaptar la temperatura, los estilos de interacción o ampliar la lista de métodos de configuración, dime y lo ajustamos juntos ✨
