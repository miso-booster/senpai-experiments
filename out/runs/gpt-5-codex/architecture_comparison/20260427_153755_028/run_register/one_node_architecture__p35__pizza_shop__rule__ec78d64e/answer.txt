Sure thing! Here’s a Sensei-check rule you can drop into your project. It assumes the profile you’re validating exposes `size` and `price` in `chatbot.output` (the same schema used by your existing `more_toppings_cost_more` rule):

```yaml
name: small_pizza_price_floor
description: Small pizzas must cost exactly $10
conversations: 1
when: size == 'small'
oracle: extract_float(price) == 10 and currency(price) == 'USD'
```
