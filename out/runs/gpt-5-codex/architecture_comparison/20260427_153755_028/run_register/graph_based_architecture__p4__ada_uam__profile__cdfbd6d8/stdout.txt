¡Perfecto! Aquí tienes un perfil de Sensei diseñado especialmente para simular a un usuario que busca información de contacto del CAU (Centro de Atención a Usuarios) de la UAM. Puedes copiarlo dentro de `profiles/consulta_contacto_cau.yaml` (o el nombre que prefieras).

```yaml
test_name: "Consulta de Contacto del CAU"

llm:
  temperature: 0.4
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: "Usuario que necesita obtener los datos de contacto del Centro de Atención a Usuarios (CAU) de la UAM."
  context:
    - "Necesitas comunicarte con el CAU para resolver dudas urgentes sobre servicios tecnológicos."
    - "Deseas confirmar que tienes la información correcta antes de ponerte en contacto."
    - personality: personalities/patient-user
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir el correo electrónico de contacto del CAU."
    - "Preguntar por la dirección física del CAU."
    - "Solicitar los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "¿Podrías reformular tu consulta? También puedes revisar nuestro catálogo de servicios."
  output:
    - cau_phone_number:
        type: string
        description: "Número de teléfono oficial del CAU."
    - cau_email_address:
        type: string
        description: "Correo electrónico de contacto del CAU."
    - cau_physical_address:
        type: string
        description: "Dirección física del CAU."
    - cau_service_hours:
        type: string
        description: "Horarios de atención del CAU."
    - additional_contact_options:
        type: string
        description: "Cualquier otro canal o recomendación de contacto proporcionado por el bot."

conversation:
  number: 3
  goal_style:
    steps: 8
  interaction_style:
    - single questions
  max_cost: 0.4
```

### Cositas a tener en cuenta 😊
- **Personalidad:** ajusta `personalities/patient-user` si aún no tienes esa personalidad; puedes quitar esa línea o cambiarla por otra que exista.
- **Outputs:** añadí un campo opcional (`additional_contact_options`) por si el bot ofrece canales alternativos (formulario, ticket, etc.). Si no lo necesitas, lo eliminas sin problema.
- **conversation.number & steps:** configúralos según el presupuesto y la duración que quieras. Aquí dejé 3 conversaciones de máximo 8 turnos.

Si necesitas validarlo rápido, recuerda el comando:
```bash
python validation_check.py --profile path/al/archivo.yml --output path/al/output
```
