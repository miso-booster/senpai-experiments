Sure thing! Here’s a simple global rule that ensures the assistant actually talks about promotions. It looks for common keywords like “promotion”, “offer”, or “discount” in the assistant’s replies. If none of those show up, the rule will flag it. 😊

```yaml
name: mentions_current_promotions
description: Ensures the assistant shares information about current promotions or offers
conversations: 1
oracle: |
  len(chatbot_returns("promotion")) > 0
  or len(chatbot_returns("offer")) > 0
  or len(chatbot_returns("discount")) > 0
yields: |
  f"No mention of promotions or relevant offers. Assistant replies: {chatbot_returns('promotion')} {chatbot_returns('offer')} {chatbot_returns('discount')}"
```
