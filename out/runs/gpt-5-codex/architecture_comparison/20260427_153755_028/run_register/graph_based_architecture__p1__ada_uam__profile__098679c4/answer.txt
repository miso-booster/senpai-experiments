¡Hola! 😊 Aquí tienes un perfil Sensei listo para un usuario que está intentando (sin éxito) configurar eduroam y quiere explorar distintos métodos para lograrlo. El variable `setup_method` recorre cada una de las formas habituales de configuración, para que puedas generar conversaciones específicas con cada intento.

```yaml
test_name: "Asistencia para configuración de eduroam"

llm:
  temperature: 0.6
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Usuario universitario que no logra conectar su dispositivo a eduroam y busca
    soporte detallado para completar la configuración.
  context:
    - personality: personalities/frustrated-user
    - "Necesitas conexión Wi-Fi urgente para tus clases y trámites en línea."
    - "Has probado varias veces sin éxito y quieres instrucciones claras y enlaces fiables."
    - "Deseas confirmar si tus credenciales y certificados están en regla."
  goals:
    - "Explicar que no he podido conectar mi dispositivo a eduroam y necesito asistencia paso a paso."
    - "Pedir ayuda específica para configurar eduroam utilizando {{setup_method}}."
    - "Solicitar indicaciones para verificar certificados, credenciales y posibles errores con {{setup_method}}."
    - "Preguntar por alternativas o soluciones temporales en caso de que {{setup_method}} siga fallando."
    - setup_method:
        function: forward()
        type: string
        data:
          - "el asistente oficial eduroam CAT"
          - "la configuración manual en Windows 11"
          - "el perfil .mobileconfig para dispositivos iOS"
          - "la configuración manual en Android"
          - "el script de configuración para macOS"

chatbot:
  is_starter: false
  fallback: "¿Podrías reformular tu pregunta? También puedes consultar el catálogo de servicios del CAU."
  output:
    - step_by_step_instructions:
        type: string
        description: "Instrucciones detalladas para configurar eduroam según el método solicitado"
    - download_resources:
        type: string
        description: "Enlaces a instaladores, perfiles o guías oficiales de eduroam"
    - troubleshooting_tips:
        type: string
        description: "Consejos para resolver errores frecuentes durante la configuración"
    - credential_requirements:
        type: string
        description: "Requisitos sobre credenciales, certificados y formatos necesarios"
    - alternative_access_options:
        type: string
        description: "Opciones temporales de conexión mientras se resuelve el problema"
    - support_contact_info:
        type: string
        description: "Datos de contacto del CAU para escalado o asistencia adicional"
    - device_specific_notes:
        type: string
        description: "Consideraciones particulares del dispositivo o sistema operativo"

conversation:
  number: 5
  max_cost: 0.6
  goal_style:
    steps: 26
  interaction_style:
    - single questions
```

Si necesitas ajustar el tono, añadir más variables (por ejemplo, tipo de dispositivo) o ampliar los campos de `chatbot.output`, dime y lo hacemos juntos. ✨
