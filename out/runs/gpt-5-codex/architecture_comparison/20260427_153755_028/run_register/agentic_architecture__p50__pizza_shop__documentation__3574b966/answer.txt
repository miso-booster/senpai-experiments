Hey there! 😊 In Sensei-check (the rules DSL), an **oracle** is the boolean test that decides whether a rule passes or fails for the conversations it’s evaluating. As described in `sensei-check-doc.md`, each rule needs some condition to verify across the selected conversation(s); you can write that condition either as:

- a single `oracle:` expression (e.g., `oracle: extract_float(price) >= 10`), or  
- an `if:` / `then:` implication when you want to state “if this precondition holds, then that result must hold.”

When the oracle expression evaluates to `True`, the rule passes; if it evaluates to `False`, the rule fails and Sensei-check reports the issue (optionally with a custom message). So, think of the oracle as the actual “truth test” embedded inside each rule.
