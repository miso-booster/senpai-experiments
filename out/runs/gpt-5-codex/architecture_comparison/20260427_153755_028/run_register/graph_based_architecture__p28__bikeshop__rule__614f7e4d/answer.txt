To enforce language mirroring, you can add a **global Sensei-check rule** that relies on the built-in helper `responds_in_same_language()`. This helper checks every conversation and confirms the assistant replies in the same language the user used.

Here’s a ready-to-use YAML rule:

```yaml
name: mirrors_user_language
description: Assistant should answer in the same language the user speaks
conversations: 1
oracle: responds_in_same_language() is True
```

### Why this works
- **Scope:** `conversations: 1` means it evaluates each conversation individually.
- **oracle:** `responds_in_same_language()` returns `True` only when the bot consistently mirrors the user’s language, so the rule fails whenever it detects a mismatch.
