Hey there! 👋 In Sensei, a **metamorphic rule** is a check you write in Sensei-check to validate how your chatbot behaves **across multiple conversations at once**, rather than just judging a single dialogue in isolation.

Instead of asking “Is this answer correct?”, metamorphic rules ask things like:

- “If two users choose the same pizza size but one adds more toppings, does the price go up accordingly?”
- “When we keep the inputs the same, does the bot stay in the same language each time?”

Here’s the idea in a nutshell:

1. **Sensei-chat** generates many conversations using your profiles.
2. **Metamorphic rules** (written in YAML) select pairs or groups of those conversations—using filters like `when: conv[0].size == conv[1].size`.
3. They then state the expected *relationship* between their outputs—for example:
   ```yaml
   if:   len(conv[0].toppings) > len(conv[1].toppings)
   then: extract_float(conv[0].price) > extract_float(conv[1].price)
   ```
4. Sensei-check runs these rules and flags any conversations that break the expected relationship.

It’s a powerful way to catch inconsistencies or regressions without needing a single “correct” answer for every input. Let me know if you want an example tailored to your pizza project! 🍕
