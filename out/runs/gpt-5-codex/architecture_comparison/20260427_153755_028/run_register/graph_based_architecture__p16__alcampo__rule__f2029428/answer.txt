Sure thing! Since there isn’t a profile yet, here’s a **rule-first** Sensei-check rule you can start with. It assumes the future profile will expose three fields in `chatbot.output`: `product_name`, `dietary_labels`, and `availability_status`. Feel free to rename them later—just remember to update the rule accordingly 😊

```yaml
name: lactose_free_availability
description: Lactose-free products must have an explicit non-negative availability status.
conversations: 1
if: any(label.lower() in ['lactose-free', 'lactose free'] for label in dietary_labels)
then: availability_status and availability_status.lower() in ['available', 'in stock', 'limited stock']
on-error: f"The lactose-free product '{product_name}' did not report a valid availability status (got {availability_status})."
```

Once you create the profile, make sure those fields (or your preferred names) are present in its `chatbot.output`, and this rule will be ready to go ✅ Let me know if you’d like a companion profile stub or tweaks to the availability logic!
