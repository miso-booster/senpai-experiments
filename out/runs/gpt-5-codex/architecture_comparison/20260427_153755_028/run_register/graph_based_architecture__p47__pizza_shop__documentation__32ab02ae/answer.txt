Great question! In Sensei—specifically within **Sensei-check**—a *metamorphic rule* is a testing rule that compares **two or more conversations** to verify how the chatbot’s output should change (or stay the same) when we tweak the simulated user inputs.

Instead of checking just one conversation in isolation, a metamorphic rule says something like:

> “If these inputs are similar in this way, or differ only in that aspect, then the chatbot responses should follow this predictable relation.”

For example, if two simulated orders have the same size and drink but one has more toppings, a metamorphic rule can insist that the price with more toppings must be higher. Sensei-check expresses these rules in YAML using `conv[0]`, `conv[1]`, etc., to access each conversation’s extracted outputs from the corresponding Sensei Chat profile.

They’re powerful because they let you validate your bot’s behaviour **without needing a ‘correct’ answer** for every input—just a reliable relationship between comparable scenarios.
