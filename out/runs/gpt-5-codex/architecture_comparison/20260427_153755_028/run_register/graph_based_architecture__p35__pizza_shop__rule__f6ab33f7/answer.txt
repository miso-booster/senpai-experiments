Sure thing! Here’s a Sensei-check rule you can drop into your project to ensure that every small pizza is priced at exactly $10. 🍕

```yaml
name: small_pizza_price_is_10
description: Small pizzas must cost exactly $10
conversations: 1
when: size == 'small'
oracle: extract_float(price) == 10
```

**Where to save it:**  
Place this in a new file such as `rules/small_pizza_price_is_10.yaml` (or whatever naming pattern you’re using).

If you’d also like to enforce the currency (say, USD), you can tighten the oracle like this:

```yaml
name: price_equals_10_usd
description: The price must be exactly 10 USD
conversations: 1
oracle: extract_float(price) == 10 and currency(price) == 'USD'
```
