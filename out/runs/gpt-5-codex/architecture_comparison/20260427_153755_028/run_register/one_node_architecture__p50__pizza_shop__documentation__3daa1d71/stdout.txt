Hey there! 😊 In the context of SENSEI Rules, an **oracle** is simply the condition that must be true for a rule to pass. You write it as a Python-style expression in the `oracle:` field, and Sensei-check evaluates that expression after each conversation (or set of conversations, for metamorphic rules).

For example:

```yaml
oracle: extract_float(price) >= 10 and currency(price) == 'USD'
```

This oracle says: “the parsed price must be at least 10, and the currency must be USD.” If the condition evaluates to `True`, the rule passes; if it’s `False`, Sensei flags a failure and (optionally) shows your `on-error` message.

So, in short: the oracle is your truth test—the logic that decides whether the chatbot behaved as expected 🌟.
