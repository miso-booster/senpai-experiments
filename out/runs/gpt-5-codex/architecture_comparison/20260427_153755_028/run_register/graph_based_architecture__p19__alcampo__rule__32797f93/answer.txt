Hey there! 👋 Here’s a tidy little Sensei-check rule you can drop into your project to verify that the assistant actually talks about current promotions. Since you asked for a profile-agnostic check, I leaned on the `semantic_content` helper—it lets Sensei judge whether the assistant’s replies really convey details about ongoing deals.

```yaml
name: current_promotions_shared
description: Ensures the assistant mentions the promotions or discounts currently available.
conversations: 1
oracle: semantic_content(chatbot_phrases, 'describes the current promotions or discounts available right now')
```

**How it works (in plain words):**

- **`conversations: 1`** keeps it simple—each dialog is evaluated on its own.
- **`semantic_content(...)`** is our LLM-powered helper that checks whether the assistant’s messages (bundled as `chatbot_phrases`) genuinely talk about current promos/discounts.
- If the assistant stays silent about current deals, the rule will flag the conversation.

Feel free to tweak the description text inside `semantic_content` if you want it to require more specific details (e.g., “includes promotion name and expiration date”). Let me know if you’d like variations or companion rules! 😊
