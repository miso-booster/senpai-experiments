### What needed fixing
1. **Number of conversations** – you only need to inspect one conversation, so `conversations` should be `1`, not `2`.
2. **Condition structure** – the original `when` clause both filtered and asserted equality, which isn’t ideal here. We can handle missing values with an `if`.
3. **Then-expression** – `then` must be a boolean expression, not a plain string. We should actually check the numeric value.

### Updated rule
Here’s the corrected version:

```yaml
name: check_tune_up_price
description: The tune-up price must be exactly $50.
conversations: 1
if: tune_up_price is not None
then: extract_float(tune_up_price) == 50
```

This version:
- Only runs when the `tune_up_price` field is present.
- Confirms the numeric value equals 50 using `extract_float`, so it works whether the profile outputs `"50"`, `"50 USD"`, or similar.
