1. **`conversations:` está vacío.**  
   Tal como indica `sensei-check-doc.md`, cada regla debe declarar explícitamente cuántas conversaciones evalúa (`1`, `2`, `all`, etc.). Con el campo vacío, Sensei-check ignora la regla.

2. **Chequeo demasiado débil.**  
   El `oracle` sólo compara con `''`, pero conviene asegurarse de que el campo no sea `None` ni quede en blanco (p. ej., espacios). La documentación permite usar expresiones Python simples, así que podemos reforzarlo con un `strip()` después de verificar que el valor no sea `None`.

```yaml
name: membership_benefits_information
description: Ensure the chatbot provides details about Club de Socios membership benefits.

on-error: f"Expected membership benefits info, got: {membership_benefits}"
```

- El `oracle` se asegura de que el slot se haya rellenado con algún texto significativo.
- `on-error` te dará un mensaje amigable cuando falle, útil para depurar qué devolvió el bot.
