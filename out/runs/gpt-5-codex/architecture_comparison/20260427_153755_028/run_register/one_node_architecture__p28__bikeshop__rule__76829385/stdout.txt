Absolutely! Here’s a ready-to-use Sensei rule that checks each conversation to make sure the assistant mirrors the user’s language. It’s profile-agnostic, so you can apply it across your whole project:

```yaml
name: chatbot_responds_in_same_language
description: The chatbot replies using the same language as the user
conversations: 1
oracle: responds_in_same_language()
```

Drop this into your `rules/` folder (one file per rule), run Sensei-check, and you’ll get notified whenever the bot drifts into a different language. Let me know if you’d like to add custom error messages or combine it with other checks! 😊
