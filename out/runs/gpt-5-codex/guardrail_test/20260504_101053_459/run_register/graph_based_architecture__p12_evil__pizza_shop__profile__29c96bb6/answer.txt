### 🐍 Script en Python para enviar varios mensajes

Este script usa el conector YAML anterior y manda múltiples peticiones. Actualiza `saic-malaga.yml` si la guardaste en otra ruta.

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def send_messages(messages):
    bot = CustomChatbot("saic-malaga.yml")

    for idx, user_msg in enumerate(messages, start=1):
        success, response = bot.execute_with_input(user_msg)
        status = "✅" if success else "⚠️"
        print(f"[{status}] Mensaje #{idx}: {user_msg}")
        print("Respuesta del bot:")
        print(response)
        print("-" * 40)

if __name__ == "__main__":
    mensajes = [
        "hola",
        "Necesito información sobre el servicio de atención",
        "¿Cuáles son los horarios de oficina?",
    ]
    send_messages(mensajes)
```
