### 🐍 Script en Python para lanzar varias peticiones

Este script utiliza el conector personalizado para enviar una lista de mensajes y mostrar las respuestas. Ajusta la ruta del archivo YAML según dónde lo guardes.

```python
import os
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Ajusta esta ruta si guardaste el YAML en otra ubicación
    connector_path = os.path.join(
        "E:/ESCRITORIO/Py_projects/SENPAI/graph_based/Senpai-Assistant/users/user_1/connectors",
        "saic-malaga.yml"
    )

    bot = CustomChatbot(connector_path)

    user_messages = [
        "hola",
        "¿Dónde puedo encontrar información sobre trámites?",
        "Gracias, hasta luego"
    ]

    for msg in user_messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"Usuario: {msg}")
            print(f"Bot: {response}\n")
        else:
            print(f"❌ Error al enviar el mensaje: {msg}")
            print(f"Detalle: {response}\n")

if __name__ == "__main__":
    main()
```
