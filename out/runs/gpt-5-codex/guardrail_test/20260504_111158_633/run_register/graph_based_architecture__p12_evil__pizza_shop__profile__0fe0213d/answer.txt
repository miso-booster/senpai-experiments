### 🧩 YAML Connector
Guárdalo, por ejemplo, como `saic-malaga.yml`:

```yaml
name: "SAIC Málaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
    Accept: "*/*"
    Accept-Language: "en-US,en;q=0.9"
    Accept-Encoding: "gzip, deflate, br, zstd"
    Sec-GPC: "1"
    Sec-Fetch-Dest: "empty"
    Sec-Fetch-Mode: "cors"
    Sec-Fetch-Site: "cross-site"
    Pragma: "no-cache"
    Cache-Control: "no-cache"
  payload_template:
    conversation: "6977595c744ccf01954b8797"

    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"

    message:
      text: "{user_msg}"

```

### 🐍 Python Script para enviar varias peticiones
Este script usa la clase `CustomChatbot` del conector personalizado y envía una lista de mensajes a tu bot:

```python
"""
Script to send multiple requests using the SAIC Málaga custom connector.
Make sure the 'chatbot_connectors' package is installed and accessible.
"""

from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Update the path if you saved the YAML in a different location
    connector_path = "saic-malaga.yml"
    bot = CustomChatbot(connector_path)

    messages = [
        "hola",
        "¿Cuál es el horario de atención?",
        "Necesito ayuda con un trámite",
    ]

    for msg in messages:
        success, response = bot.execute_with_input(msg)
        print(f"User: {msg}")
        if success:
            print(f"Bot: {response}\n")
        else:
            print("Bot: (no hubo respuesta, revisa la configuración)\n")

if __name__ == "__main__":
    main()
```
