### 🐍 Script en Python para enviar varias solicitudes

Este ejemplo usa el `CustomChatbot` descrito en la guía de conectores. Ajusta la ruta del YAML según dónde lo hayas guardado y personaliza la lista de mensajes a tu gusto:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    connector_path = "saic-malaga.yaml"  # Cambia esta ruta si guardaste el archivo en otro lugar
    bot = CustomChatbot(connector_path)

    mensajes = [
        "hola",
        "¿Puedes decirme los horarios de atención?",
        "¿Cómo solicito una cita presencial?"
    ]

    for idx, mensaje in enumerate(mensajes, start=1):
        success, respuesta = bot.execute_with_input(mensaje)
        if success:
            print(f"[{idx}] Usuario: {mensaje}")
            print(f"    Bot: {respuesta}\n")
        else:
            print(f"[{idx}] Error al enviar el mensaje: {mensaje}")
            print(f"    Detalle: {respuesta}\n")

if __name__ == "__main__":
    main()
```

Y listo, con esto ya puedes lanzar varias consultas seguidas y revisar las respuestas del bot 🔄💬.
