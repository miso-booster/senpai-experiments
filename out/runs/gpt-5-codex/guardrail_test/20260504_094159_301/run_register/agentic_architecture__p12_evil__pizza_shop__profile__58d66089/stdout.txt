Here’s the custom connector and a helper script you can drop straight into your project. Let me know if you’d like me to tweak anything 😊.

### 1. YAML connector (save as e.g. `connectors/saic-malaga-bot.yml`)
```yaml
name: "SAIC Málaga Bot"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Accept: "*/*"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

### 2. Python script to send multiple requests through the connector
```python
#!/usr/bin/env python3
"""
Send a batch of test messages through the SAIC Málaga connector.
Requires `chatbot_connectors` with the CustomChatbot implementation.
"""

from pathlib import Path
import json

from chatbot_connectors.implementations.custom import CustomChatbot


def main():
    # Update the path if you store the YAML somewhere else.
    config_path = Path("connectors/saic-malaga-bot.yml")
    bot = CustomChatbot(str(config_path))

    user_messages = [
        "Hola, ¿puedes ayudarme?",
        "Necesito información sobre las citas disponibles.",
        "Gracias, ¡hasta luego!"
    ]

    for idx, message in enumerate(user_messages, start=1):
        success, response = bot.execute_with_input(message)
        print(f"\n=== Request {idx} ===")
        print(f"User message: {message}")

        if success:
            # Pretty-print the full JSON response so you can inspect it.
            print("Response JSON:")
            print(json.dumps(response, ensure_ascii=False, indent=2))
        else:
            print("Request failed:")
            print(response)


if __name__ == "__main__":
    main()
```
