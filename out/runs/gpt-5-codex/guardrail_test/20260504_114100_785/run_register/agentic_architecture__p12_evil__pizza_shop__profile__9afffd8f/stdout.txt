### 2. Python helper (`send_multiple_requests.py`)
```python
import pathlib
from chatbot_connectors.implementations.custom import CustomChatbot


def main():
    config_path = pathlib.Path(__file__).with_name("saic-malaga-connector.yaml")
    chatbot = CustomChatbot(str(config_path))

    messages = [
        "hola",
        "Necesito información sobre los trámites municipales.",
        "¿Cuál es el horario de atención?"
    ]

    for user_msg in messages:
        success, response = chatbot.execute_with_input(user_msg)
        print(f"\nUser: {user_msg}")
        if success:
            print(f"Bot : {response}")
        else:
            print("Bot : <request failed>")
            print(f"Details: {response}")


if __name__ == "__main__":
    main()
```

**How to use it**
1. Save the YAML connector file alongside the Python script (or adjust the `config_path` accordingly).
2. Install the connector library if you haven’t already.
3. Run `python send_multiple_requests.py` to send the sample batch of messages.
