```yaml
name: "SAIC Malaga"

  path: "/api/public/messages"
  method: "POST"
  headers:

  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"

```

> 📝 Nota: El header `Content-Length` lo maneja automáticamente la librería HTTP, así que no hace falta incluirlo en el YAML.

### 🐍 Script en Python para enviar múltiples mensajes

Este script usa el conector anterior y lanza varias interacciones de forma consecutiva (puedes ajustar la lista de mensajes a tu gusto):

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Actualiza la ruta al archivo YAML según tu estructura local
    connector_path = r"E:\ESCRITORIO\Py_projects\SENPAI\graph_based\Senpai-Assistant\users\user_1\connectors\saic-malaga.yml"

    bot = CustomChatbot(connector_path)

    messages = [
        "hola",
        "Necesito información sobre trámites municipales.",
        "¿Cuál es el horario de atención?"
    ]

    for idx, user_msg in enumerate(messages, start=1):
        success, response = bot.execute_with_input(user_msg)

        print(f"\n--- Mensaje #{idx} ---")
        print(f"Usuario: {user_msg}")

        if success:
            print(f"Bot: {response}")
        else:
            print("Hubo un problema al contactar con el bot. Revisa la configuración y vuelve a intentarlo.")

if __name__ == "__main__":
    main()
```
