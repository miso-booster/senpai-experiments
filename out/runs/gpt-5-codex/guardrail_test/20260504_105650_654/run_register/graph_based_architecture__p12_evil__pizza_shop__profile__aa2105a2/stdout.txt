### 🐍 Script en Python para enviar varias solicitudes

```python
from chatbot_connectors.implementations.custom import CustomChatbot

# Actualiza la ruta si guardaste el YAML en otro lugar
CONNECTOR_PATH = r"E:\ESCRITORIO\Py_projects\SENPAI\graph_based\Senpai-Assistant\users\user_1\connectors\saic-malaga.yml"

bot = CustomChatbot(CONNECTOR_PATH)

test_messages = [
    "hola",
    "Necesito información sobre trámites municipales",
    "¿Cuál es el horario de atención?",
    "Gracias por la ayuda"
]

for msg in test_messages:
    success, response = bot.execute_with_input(msg)
    print(f"\nUsuario: {msg}")
    if success:
        print(f"Bot: {response}")
    else:
        print("Bot: (No se pudo obtener respuesta)")
```

Este script crea una instancia del conector personalizado y envía una pequeña tanda de mensajes para probar el flujo completo 💬. Modifica la lista `test_messages` con los prompts que quieras, y ya estarás listo para hacer tus pruebas.
