Guárdalo, por ejemplo, como `saic-malaga.yml` dentro de tu carpeta de conectores.

```yaml
name: "SAIC Málaga"

  path: "/api/public/messages"

    Priority: "u=4"

    Cache-Control: "no-cache"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"

      text: "{user_msg}"

```

> **Tip:** `{user_msg}` se reemplaza automáticamente por el mensaje real que envies desde tus pruebas.

### 🐍 Script en Python para lanzar varias peticiones

Actualiza la ruta del archivo YAML (`CONFIG_PATH`) para que apunte a la ubicación real donde lo guardes. Luego ejecuta este script para enviar varios mensajes de prueba:

```python
import os
from chatbot_connectors.implementations.custom import CustomChatbot

# Cambia esta ruta por la ubicación real de tu archivo YAML
CONFIG_PATH = r"E:\ESCRITORIO\Py_projects\SENPAI\graph_based\Senpai-Assistant\users\user_1\connectors\saic-malaga.yml"

def main():
    if not os.path.exists(CONFIG_PATH):
        raise FileNotFoundError(f"No se encontró el archivo de configuración: {CONFIG_PATH}")

    bot = CustomChatbot(CONFIG_PATH)

    test_messages = [
        "hola",
        "Necesito información sobre trámites.",
        "¿Dónde puedo encontrar el formulario?"
    ]

    for msg in test_messages:
        success, response = bot.execute_with_input(msg)
        print(f"\n=== Mensaje enviado ===\n{msg}")
        if success:
            print(f"⇨ Respuesta del bot:\n{response}")
        else:
            print("⚠️ No se pudo obtener respuesta del bot.")

if __name__ == "__main__":
    main()
```
