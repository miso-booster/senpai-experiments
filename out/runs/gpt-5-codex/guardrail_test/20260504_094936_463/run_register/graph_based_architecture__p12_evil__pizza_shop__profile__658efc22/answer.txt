### 🐍 Script en Python para enviar varias solicitudes

Este ejemplo usa el conector anterior con `CustomChatbot`. Ajusta la ruta del archivo YAML (`saic-malaga.yml`) al lugar donde lo guardes:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    connector_path = "saic-malaga.yml"  # Cambia esto si usas otro nombre o ubicación
    bot = CustomChatbot(connector_path)

    user_messages = [
        "Hola, ¿qué trámites puedo hacer aquí?",
        "Necesito información sobre citas previas.",
        "¿Hay algún teléfono de atención disponible?"
    ]

    for msg in user_messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"Usuario: {msg}")
            print(f"Bot: {response}\n")
        else:
            print(f"Ocurrió un problema con el mensaje: {msg}\n")

if __name__ == "__main__":
    main()
```
