Y aquí tienes un script en Python que usa ese conector para enviar varios mensajes de forma sencilla:

```python
import time
from pathlib import Path
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    connector_path = Path("connectors/saic-malaga.yaml")
    bot = CustomChatbot(str(connector_path))

    user_messages = [
        "hola",
        "¿Cuál es el horario de atención?",
        "Necesito información sobre trámites municipales.",
    ]

    for msg in user_messages:
        print(f"\n→ Usuario: {msg}")
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"← Bot: {response}")
        else:
            print("⚠️ No se pudo obtener respuesta del bot.")
        time.sleep(1)

if __name__ == "__main__":
    main()
```

Este script carga el conector YAML, envía cada mensaje de la lista y muestra la respuesta que llega desde la API. Si necesitas ajustar los mensajes o añadir manejo de errores más detallado, avísame y lo pulimos juntos 😊
