### 🧠 Conceptual Steps for LLM-Assisted Profile Generation

1. **Define your profile template**  
   - Set up a skeleton YAML matching the Sensei profile structure (see the guide’s “Full example profile”).  
   - Leave placeholders for dynamic sections like `user.context`, `goals`, and `chatbot.output`.

2. **Gather required inputs**  
   - Decide rating factors: target scenario (e.g., order placement), personality, required outputs, number/type of variables, etc.  
   - Make sure each variable referenced in goal strings has a declaration and a matching function/data block.

3. **Prompt your LLM**  
   - Provide it with the template and the fields you need populated.  
   - Include instructions that enforce Sensei constraints: e.g., goals list structure, correct `conversation` controls, valid interaction styles.

4. **Post-process the response**  
   - Parse the YAML to ensure it is well-formed.
   - Validate:
     - Every `{{variable}}` used in `goals` has a defined block.
     - Functions like `forward()` or `pairwise()` are used with enough variables to generate combination matrices as required.
     - `chatbot.output` matches the fields you expect to test later.

5. **Run Sensei’s existing validator**  
   - Call `validation_check.py` on the generated profile to catch broken configurations early.
