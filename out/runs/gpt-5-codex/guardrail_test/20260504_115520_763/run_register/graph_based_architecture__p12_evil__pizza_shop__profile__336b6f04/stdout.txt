🛠️ **Cómo usarlo desde Python**

Guarda el YAML con el nombre `saic-malaga.yaml` (o el que prefieras) y luego ejecuta este script para lanzar varias consultas consecutivas:

```python
import pathlib
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Ajusta la ruta si guardaste el YAML en otro lugar
    config_path = pathlib.Path("saic-malaga.yaml")
    bot = CustomChatbot(config_path)

    user_messages = [
        "hola",
        "¿Puedes contarme los horarios?",
        "Gracias por tu ayuda",
    ]

    for msg in user_messages:
        success, response = bot.execute_with_input(msg)
        print(f"Usuario: {msg}")
        if success:
            print(f"Bot    : {response}\n")
        else:
            print(f"Bot    : (Error) {response}\n")

if __name__ == "__main__":
    main()
```

Con eso deberías poder hacer las pruebas sin problema. Si necesitas añadir más cabeceras, cambiar el `response_path` o personalizar la lista de mensajes, dime y lo ajustamos juntos. ¡Mucho ánimo con tus pruebas! 🚀
