### 🐍 Script en Python para lanzar varias peticiones

Este ejemplo utiliza el `CustomChatbot` del sistema de conectores. Sustituye la ruta a la que tu archivo YAML realmente viva:

```python
import json
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    connector_path = r"E:\ESCRITORIO\Py_projects\SENPAI\graph_based\Senpai-Assistant\users\user_1\connectors\saic-malaga.yml"
    bot = CustomChatbot(connector_path)

    user_messages = [
        "hola",
        "¿Cuál es el horario de atención?",
        "Gracias por la información, ¡hasta luego!"
    ]

    for text in user_messages:
        success, response = bot.execute_with_input(text)
        print(f"\n➤ Usuario: {text}")
        if success:
            print(f"   Bot: {response}")
        else:
            print(f"   ⚠️ Error: {json.dumps(response, ensure_ascii=False, indent=2)}")

if __name__ == "__main__":
    main()
```

Este script:

1. Carga tu conector personalizado.
2. Envía una pequeña lista de mensajes (puedes ampliar o modificar este arreglo).
3. Imprime la respuesta extraída con el `response_path` que definimos.

¡Listo! Si necesitas ajustar detalles o probar otros escenarios, dime y te ayudo encantado 😊.
