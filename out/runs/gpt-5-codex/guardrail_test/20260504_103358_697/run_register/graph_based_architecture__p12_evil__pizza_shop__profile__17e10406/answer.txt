### 🧩 YAML del conector

Guarda este contenido como `saic-malaga.yaml` (o el nombre que prefieras) dentro de tu carpeta de conectores:

```yaml
name: "SAIC Málaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
    Accept: "*/*"
    Accept-Language: "en-US,en;q=0.9"
    Accept-Encoding: "gzip, deflate, br, zstd"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

> 🔎 **Consejo**: puedes simplificar los headers si no todos son necesarios, pero este YAML replica fielmente la petición que me compartiste.

### 🐍 Script en Python para enviar varias peticiones

Este script lee la configuración YAML, construye la carga con tus mensajes y muestra las respuestas del bot. Puedes ajustarlo según tus necesidades (por ejemplo, leer mensajes desde otra fuente).

```python
import json
import requests
import yaml
from pathlib import Path

def load_connector_config(config_path):
    with open(config_path, "r", encoding="utf-8") as file:
        return yaml.safe_load(file)

def send_message(connector, user_message):
    base_url = connector["base_url"]
    send_conf = connector["send_message"]

    url = f"{base_url}{send_conf['path']}"
    method = send_conf.get("method", "POST").upper()
    headers = send_conf.get("headers", {}).copy()

    payload_template = json.loads(json.dumps(send_conf["payload_template"]))
    payload_template["message"]["text"] = user_message

    response = requests.request(
        method=method,
        url=url,
        headers=headers,
        json=payload_template,
        timeout=30
    )
    response.raise_for_status()
    return response.json()

def extract_response(connector, response_json):
    path_parts = connector["response_path"].split(".")
    current = response_json
    for part in path_parts:
        if part.isdigit():
            current = current[int(part)]
        else:
            current = current[part]
    return current

def main():
    config_path = Path("saic-malaga.yaml")  # ajusta la ruta si lo guardaste en otro lugar
    connector = load_connector_config(config_path)

    user_messages = [
        "hola",
        "¿Cuál es el horario de atención?",
        "Gracias, ¡hasta luego!"
    ]

    for message in user_messages:
        try:
            raw_response = send_message(connector, message)
            bot_reply = extract_response(connector, raw_response)
            print(f"\n> Usuario: {message}")
            print(f"< Bot: {bot_reply}")
        except requests.HTTPError as http_err:
            print(f"\n¡Ups! Error HTTP con el mensaje '{message}': {http_err}")
        except Exception as err:
            print(f"\nSe produjo un error con el mensaje '{message}': {err}")

if __name__ == "__main__":
    main()
```
