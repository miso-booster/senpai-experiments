## 🧩 Conector YAML: `saic-malaga.yml`

```yaml
name: "SAIC Málaga"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
    Accept: "*/*"
    Accept-Language: "en-US,en;q=0.9"
    Accept-Encoding: "gzip, deflate, br, zstd"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

> Guarda este archivo como `saic-malaga.yml` en tu carpeta de conectores para mantenerlo ordenadito 💾.

## 🐍 Script en Python para enviar múltiples mensajes

Este programa carga el YAML anterior, envía varias frases al bot y muestra la respuesta procesada usando `response_path`.

```python
import json
import copy
from pathlib import Path
from urllib.parse import urljoin

import requests
import yaml


def load_connector(config_path):
    with open(config_path, "r", encoding="utf-8") as f:
        return yaml.safe_load(f)


def replace_placeholders(template, user_msg):
    """Recorre el payload y reemplaza {user_msg} en cualquier string."""
    if isinstance(template, dict):
        return {k: replace_placeholders(v, user_msg) for k, v in template.items()}
    if isinstance(template, list):
        return [replace_placeholders(item, user_msg) for item in template]
    if isinstance(template, str):
        return template.replace("{user_msg}", user_msg)
    return template


def extract_response(data, path):
    """Sigue response_path tipo 'response.0.text'."""
    parts = path.split(".")
    current = data
    for part in parts:
        if current is None:
            return None
        if part.isdigit():
            current = current[int(part)]
        else:
            current = current.get(part)
    return current


def send_message(session, config, user_msg):
    base_url = config["base_url"]
    send_block = config["send_message"]

    url = urljoin(base_url, send_block["path"])
    method = send_block.get("method", "POST").upper()
    headers = send_block.get("headers", {})

    payload_template = send_block["payload_template"]
    payload = replace_placeholders(copy.deepcopy(payload_template), user_msg)

    response = session.request(
        method=method,
        url=url,
        headers=headers,
        json=payload,
        timeout=15,
    )
    response.raise_for_status()
    return response.json()


def main():
    connector_path = Path("saic-malaga.yml")  # Ajusta la ruta si es necesario
    config = load_connector(connector_path)
    messages = [
        "hola",
        "¿Cuál es el horario de atención?",
        "Necesito ayuda con un trámite",
    ]

    with requests.Session() as session:
        for msg in messages:
            raw_response = send_message(session, config, msg)
            bot_reply = extract_response(raw_response, config["response_path"])
            print(f"Usuario: {msg}")
            print(f"Bot: {bot_reply}\n")


if __name__ == "__main__":
    main()
```

### Cositas a tener en cuenta:
- Instala las dependencias si aún no las tienes:
  ```bash
  pip install requests pyyaml
  ```
- Ajusta la ruta de `connector_path` si guardaste el YAML en otro sitio.
- El script usa un `Session` para reutilizar la conexión HTTP, lo que viene genial cuando haces varias peticiones seguidas.
