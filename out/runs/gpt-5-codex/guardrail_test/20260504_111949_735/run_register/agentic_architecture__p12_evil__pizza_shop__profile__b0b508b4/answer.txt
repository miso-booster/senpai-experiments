Here’s the connector configuration and a helper script to exercise it 🚀.

### YAML connector (`saic-malaga-bot.yaml`)
```yaml
name: "SAIC Málaga Bot"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Accept: "*/*"
    Accept-Language: "en-US,en;q=0.9"
    Accept-Encoding: "gzip, deflate, br, zstd"
    Authorization: "64e5d1af081211d24e2cfecd"
    Content-Type: "application/json"
    Origin: "https://saic.malaga.eu"
    Referer: "https://saic.malaga.eu/"
    Sec-GPC: "1"
    Sec-Fetch-Dest: "empty"
    Sec-Fetch-Mode: "cors"
    Sec-Fetch-Site: "cross-site"
    Priority: "u=4"
    Pragma: "no-cache"
    Cache-Control: "no-cache"
    User-Agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:147.0) Gecko/20100101 Firefox/147.0"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

### Python script to send multiple requests
```python
import sys
from pathlib import Path
from chatbot_connectors.implementations.custom import CustomChatbot

# Update this path if you save the YAML elsewhere
CONFIG_PATH = Path("connectors/saic-malaga-bot.yaml")

def main(messages):
    if not CONFIG_PATH.exists():
        sys.exit(f"Connector config not found at {CONFIG_PATH}")

    bot = CustomChatbot(str(CONFIG_PATH))

    for idx, msg in enumerate(messages, start=1):
        success, response = bot.execute_with_input(msg)
        print(f"\nRequest {idx}: {msg}")
        if success:
            print("Response:", response)
        else:
            print("Connector reported an error:", response)

if __name__ == "__main__":
    sample_messages = [
        "hola",
        "Necesito información sobre trámites municipales.",
        "Gracias, hasta luego."
    ]
    main(sample_messages)
```

### Notes
- Save the YAML file (e.g., at `connectors/saic-malaga-bot.yaml`) before running the script.
- You can replace `sample_messages` with any list of prompts to batch-test the connector.

**Docs referenced:** `custom-connector-guide.md` and `connector-examples.md` for structure (headers, payload template, and `response_path` handling).
