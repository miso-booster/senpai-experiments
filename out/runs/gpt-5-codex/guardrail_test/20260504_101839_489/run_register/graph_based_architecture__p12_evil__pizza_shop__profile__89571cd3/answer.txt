### Python helper script 🐍

This script uses the connector above to send multiple messages one after another. Just update the path so it points to where you saved the YAML file:

```python
import os
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    connector_path = r"E:\ESCRITORIO\Py_projects\SENPAI\graph_based\Senpai-Assistant\users\user_1\connectors\saic-malaga.yml"
    bot = CustomChatbot(connector_path)

    messages = [
        "hola",
        "¿Cuál es el horario de atención?",
        "Gracias, hasta luego."
    ]

    for idx, user_msg in enumerate(messages, start=1):
        success, response = bot.execute_with_input(user_msg)
        print(f"\n--- Mensaje #{idx} ---")
        print(f"Enviado: {user_msg}")
        if success:
            print(f"Respuesta: {response}")
        else:
            print("Ocurrió un error al enviar el mensaje.")
            print(f"Detalles: {response}")

if __name__ == "__main__":
    main()
```

Run it, and you’ll see the bot’s replies for each message right in your console. Let me know if you’d like to tweak headers, payload, or anything else—happy to help 😊
