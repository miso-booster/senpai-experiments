¡Claro! Para crear un perfil Sensei que pruebe la capacidad del chatbot de Alcampo para recomendar recetas y planificación de menús, podemos basarnos en el perfil existente llamado **"recipe_management_and_cooking_support"** que ya está orientado a gestión de recetas y soporte de cocina.

Este perfil simula un usuario que busca ayuda para recetas, planificación, ingredientes y aspectos relacionados con la cocina, justo lo que necesitas.

---

### ¿Quieres que te ayude a crear un perfil nuevo desde cero o prefieres que te explique y adapte el perfil existente de "recipe_management_and_cooking_support" para que se ajuste mejor a tus necesidades?

---

Mientras tanto, aquí te dejo un ejemplo básico inspirado en ese perfil para que veas cómo sería un perfil Sensei para probar recomendaciones de recetas y planificación de menús:

```yaml
test_name: "recipe_recommendation_and_menu_planning"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: English
  role: >
    You are a home cook looking for recipe recommendations and menu planning assistance.
    You want to find recipes based on seasonal ingredients, dietary preferences, and cooking time.
  context:
    - personality: personalities/conversational-user.yml
    - "You prefer quick and healthy meals."
    - "You want to plan menus for the week."
  goals:
    - "Recommend recipes using {{main_ingredient}}."
    - "Suggest a weekly menu plan including breakfast, lunch, and dinner."
    - main_ingredient:
        function: random()
        type: string
        data: [chicken, salmon, tofu, mushrooms, beef]

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand that. Could you please rephrase your request?"
  output:
    - recommended_recipes:
        type: string
        description: "List of recommended recipes based on the main ingredient"
    - weekly_menu_plan:
        type: string
        description: "Suggested menu plan for the week including meals"

conversation:
  number: 3
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```

---

Si quieres, puedo ayudarte a personalizarlo más, agregar variables, tipos personalizados o estilos de interacción. ¿Qué prefieres? 😊
