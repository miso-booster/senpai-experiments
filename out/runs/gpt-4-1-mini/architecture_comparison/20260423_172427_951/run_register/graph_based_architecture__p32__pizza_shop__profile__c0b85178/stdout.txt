¡Claro! 😊 Aquí tienes un perfil Sensei básico para probar un chatbot de pizzería que extrae el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares.

```yaml
test_name: "pizza_order_basic_test"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a customer placing an order at a pizza shop.
    You want to order a pizza and a drink.
  context:
    - "You like classic pizzas and popular drinks."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Order a {{drink}} to go with the pizza."
    - pizza_type:
        function: forward()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian, BBQ Chicken]
    - drink:
        function: forward()
        type: string
        data: [Coke, Sprite, Water, Fanta]

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand that. Could you please repeat?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered"
    - drink:
        type: string
        description: "The drink ordered"
    - order_id:
        type: string
        description: "The unique order identifier"
    - total_price:
        type: money
        description: "The final price of the order in dollars"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

Este perfil simula un usuario que ordena una pizza y una bebida, y espera que el chatbot devuelva el tipo de pizza, la bebida, el ID del pedido y el precio final (en tipo `money`, que puede incluir el símbolo `$`).

Si quieres que te ayude a ajustarlo o agregar más detalles, dime 😉.
