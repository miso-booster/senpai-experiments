Sure! Here's a Sensei profile YAML for a user seeking support related to the CAU (Centro de Atención a Usuarios). This profile includes goals to obtain the CAU’s phone number, email address, physical location, and opening hours, with appropriate chatbot output fields for extraction and validation.

```yaml
test_name: "CAU Support Information Request"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres un usuario que necesita soporte del Centro de Atención a Usuarios (CAU).
    Quieres obtener información de contacto clara y precisa para comunicarte con ellos.
  context:
    - "Busco los datos de contacto del CAU para resolver dudas o problemas técnicos."
  goals:
    - "Solicitar el número de teléfono del CAU."
    - "Pedir la dirección de la oficina física del CAU."
    - "Preguntar por el correo electrónico de contacto del CAU."
    - "Consultar los horarios de atención del CAU."

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me lo puedes decir con otras palabras? Si lo prefieres, puedes consultar nuestro catálogo de servicios."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horario de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```

This profile simulates a user who asks for each piece of CAU contact info separately (due to `single questions` style). The chatbot output fields correspond exactly to the requested data, so you can write Sensei rules later to validate that the bot provides these details.
