¡Claro! 😊 Puedo ayudarte a crear un perfil Sensei para simular un usuario que busca soporte sobre el CAU (Centro de Atención a Usuarios) de la UAM, y extraer la información clave que mencionas: número de teléfono, email, dirección física y horarios.

Aquí te dejo un ejemplo de perfil YAML que puedes usar como base para tu prueba. Está en español y enfocado en obtener esos datos específicos del chatbot:

```yaml
test_name: "Soporte CAU - Contacto y Horarios"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres un estudiante o usuario que necesita contactar al Centro de Atención a Usuarios (CAU)
    para resolver dudas o problemas relacionados con servicios tecnológicos.
    Quieres obtener información clara sobre el número de teléfono, correo electrónico,
    dirección física y horarios de atención del CAU.
  context:
    - personality: personalities/formal-user
    - "Busco soporte técnico y detalles de contacto del CAU."
  goals:
    - "¿Cuál es el número de teléfono para contactar al CAU?"
    - "¿Me puedes proporcionar el correo electrónico de contacto del CAU?"
    - "¿Dónde está ubicada la oficina física del CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: false
  fallback: "Disculpa, no he entendido tu pregunta. ¿Podrías reformularla o consultar nuestro catálogo de servicios?"
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono para contactar al CAU"
    - contact_email:
        type: string
        description: "Correo electrónico de contacto del CAU"
    - physical_address:
        type: string
        description: "Dirección física de la oficina del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```

### Explicación rápida:
- **user.role** describe el tipo de usuario y su intención.
- **user.goals** son las preguntas que el usuario hará para obtener la información deseada.
- **chatbot.output** define los campos que queremos extraer y validar tras la conversación.
- **conversation.number** y **goal_style.steps** controlan cuántas conversaciones y pasos se harán.
- **interaction_style** con `single questions` simula que el usuario hace una pregunta por turno.
