Para probarlo con Sensei, te puedo ayudar a crear algunas reglas Sensei-check que validen que el chatbot responde correctamente y de forma consistente a las preguntas sobre admisión, grados, cursos y eventos.

Aquí te dejo algunas ideas de reglas que podrías usar para empezar a probar tu perfil:

---

### 1) Regla para verificar que el chatbot siempre devuelve enlaces útiles

Queremos asegurarnos de que en cada conversación el chatbot proporcione al menos un enlace relevante para los usuarios nuevos (admisión, lista de espera, futuros estudiantes, Welcome Day).

```yaml
name: contains_important_links
description: El chatbot debe proporcionar al menos un enlace relevante para usuarios nuevos
conversations: 1
oracle: |
  admission_to_grados_link is not None or
  waitlist_info_link is not None or
  future_students_link is not None or
  welcome_day_link is not None
```

---

### 2) Regla para verificar que la fecha y hora del Welcome Day están presentes y tienen formato correcto

Esto es importante para que el usuario tenga información clara sobre el evento.

```yaml
name: welcome_day_datetime_valid
description: La fecha y hora del Welcome Day deben estar presentes y en formato correcto
conversations: 1
oracle: welcome_day_date is not None and welcome_day_time is not None
```

---

### 3) Regla metamórfica para consistencia entre diferentes grados o cursos

Si preguntas por diferentes grados o cursos, los enlaces y la información deben ser coherentes (por ejemplo, la lista de grados ofrecidos debe incluir el grado consultado).

```yaml
name: grados_consistency_across_conversations
description: La lista de grados ofrecidos debe incluir el grado consultado en cada conversación
conversations: 2
when: conv[0].grados_available is not None and conv[1].grados_available is not None
oracle: conv[0].grados_available in conv[0].grados_available and conv[1].grados_available in conv[1].grados_available
```

*Nota:* Aquí deberías adaptar la expresión para verificar que el grado o curso consultado esté en la lista `grados_available` o `cursos_available` que devuelve el chatbot. Si tienes un campo que indica el grado consultado, úsalo para comparar.

---

### 4) Regla para verificar que el costo de solicitud de admisión es un valor positivo

```yaml
name: application_fee_positive
description: El costo de solicitud de admisión debe ser un valor positivo
conversations: 1
oracle: extract_float(application_fee) > 0
```

### 5) Regla para verificar que la información de contacto de admisiones siempre esté presente

```yaml
name: contact_admissions_present
description: La información de contacto de admisiones debe estar siempre presente
conversations: 1
oracle: contact_admissions is not None and contact_admissions != ''
```
