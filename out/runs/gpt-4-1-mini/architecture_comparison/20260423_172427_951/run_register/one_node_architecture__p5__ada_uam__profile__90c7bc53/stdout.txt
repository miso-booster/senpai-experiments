Here's a Sensei profile YAML for a user seeking support related to the CAU, requesting phone number, email, physical location, and opening hours. It includes variables and chatbot output fields to extract those details for later rule checks:

```yaml
test_name: "CAU Support Information Request"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres un usuario que busca información de contacto y horarios del Centro de Atención a Usuarios (CAU).
    Quieres obtener el número de teléfono, correo electrónico, ubicación física y horarios de atención.
  context:
    - "Necesito contactar con el CAU para resolver dudas sobre servicios tecnológicos."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Me puedes proporcionar el correo electrónico de contacto del CAU?"
    - "¿Dónde está ubicado físicamente el CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: false
  fallback: "Por favor, ¿puedes reformular la pregunta? También puedes consultar nuestro catálogo de servicios."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico de contacto del CAU"
    - physical_address:
        type: string
        description: "Ubicación física del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```
