Hey there! 😊 I can help you create a Sensei profile that simulates a user asking the chatbot for items to add to their shopping cart. This profile will define the user's role, goals, and what outputs to extract from the chatbot's responses.

Here's a simple example profile YAML you can start with. You can customize the items or variables as you like:

```yaml
test_name: "Add Items to Shopping Cart"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a shopper who wants to add various grocery items to your online shopping cart.
    You ask the chatbot for help finding and adding these items.
  context:
    - "You prefer fresh and organic products when possible."
  goals:
    - "Add {{item_name}} to my shopping cart."
    - item_name:
        function: forward()
        type: string
        data:
          - apples
          - bananas
          - milk
          - bread
          - eggs
          - cheese
          - chicken breast
          - rice
          - olive oil
          - coffee

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand that. Could you please specify the item you want to add?"
  output:
    - added_item:
        type: string
        description: "Name of the item confirmed added to the shopping cart"
    - cart_total_items:
        type: int
        description: "Total number of items currently in the shopping cart"

conversation:
  number: 5
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

### Explanation:
- The user role is a shopper asking to add items.
- The `goals` include a variable `item_name` cycling through a list of common grocery items.
- The chatbot output expects to extract the confirmed added item and the current total items in the cart.
- The conversation will run 5 times, each time adding one item.
- Interaction style is single questions to keep it simple.
