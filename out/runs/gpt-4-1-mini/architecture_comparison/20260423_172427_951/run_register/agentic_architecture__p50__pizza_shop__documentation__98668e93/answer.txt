An **oracle** in the context of SENSEI rules (Sensei-check) is a condition or boolean expression that specifies what should be true for a single conversation or a set of conversations to be considered correct or valid.

Here's a simple breakdown:

- An oracle is a **boolean check** on conversation outputs.
- It can apply to **one conversation** (traditional oracle) or to **multiple conversations** (metamorphic rules).
- It uses expressions over extracted fields from the chatbot outputs (`conv[i].field_name`) or built-in helpers.
- If the oracle condition evaluates to `true`, the conversation(s) pass the check; if `false`, they fail.

For example, a single-conversation oracle might check that the price is above a certain threshold:

```yaml
oracle: extract_float(price) >= 10 and currency(price) == 'USD'
```

This means the chatbot's output price should be at least 10 USD.

Or a metamorphic oracle might compare two conversations:

```yaml
oracle: language(conv[0].chatbot_phrases) == 'ENG' and language(conv[1].chatbot_phrases) == 'ENG'
```

This checks that both conversations are in English.

In summary, the oracle is the core validation expression in a rule that defines the expected correctness condition.
