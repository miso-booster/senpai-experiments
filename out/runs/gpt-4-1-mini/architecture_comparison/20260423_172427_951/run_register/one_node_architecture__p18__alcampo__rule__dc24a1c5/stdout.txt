¡Claro! Aquí tienes una regla para verificar que el chatbot devuelve una lista no vacía en el campo `eco_friendly_toys` del `chatbot.output`. La regla asume que `eco_friendly_toys` es una cadena o lista que debe contener algún contenido (no estar vacía o nula).

```yaml
name: eco_friendly_toys_presence
description: The chatbot must return a non-empty list or description of eco-friendly toys
conversations: 1
active: true
oracle: eco_friendly_toys is not None and len(eco_friendly_toys) > 0
yields: f"eco_friendly_toys is missing or empty: {eco_friendly_toys}"
```

Si `eco_friendly_toys` es una lista en el output, esta regla funcionará bien. Si es un string con texto, también verifica que no esté vacío.
