Absolutely! To ensure your chatbot responds in the same language as the user, you can create a **profile-agnostic** metamorphic rule using the helper `responds_in_same_language()`. This helper checks if the assistant's replies match the user's language.

Here’s a simple Sensei-check rule you can use:

```yaml
name: language_consistency
description: Ensure the assistant responds in the same language as the user
conversations: 1
oracle: responds_in_same_language() is True
```

### Explanation:
- `conversations: 1` means this rule checks each conversation individually.
- The `oracle` uses the built-in helper `responds_in_same_language()` which returns `True` if the assistant replies match the user's language.
- This rule does not depend on any specific profile fields, so it works globally.

If you want a 2-conversation metamorphic version (comparing pairs of conversations in the same scenario), just let me know! But for most cases, this single-conversation rule is perfect for language consistency.
