Here's a friendly and clear Sensei profile that simulates a user asking the chatbot for items to add to their shopping cart. It includes variables for item names and quantities, with a simple output schema to capture the added items and quantities for later validation or rules.

```yaml
test_name: "shopping_cart_add_items"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a shopper who wants to add items to your shopping cart.
    You ask the chatbot for help adding specific items and quantities.
  context:
    - "You want to add groceries and household items to your cart."
  goals:
    - "Add {{quantity}} units of {{item_name}} to my shopping cart."
    - quantity:
        function: random(3)
        type: int
        data:
          - 1
          - 2
          - 3
          - 5
    - item_name:
        function: random(5)
        type: string
        data:
          - apples
          - milk
          - bread
          - eggs
          - detergent

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand that. Could you please specify the item and quantity?"
  output:
    - added_items:
        type: list[string]
        description: "List of item names added to the cart"
    - added_quantities:
        type: list[int]
        description: "Corresponding quantities for each added item"

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

This profile will generate conversations where the user asks to add a random quantity of a random item from the list to their shopping cart. The chatbot output schema expects to extract the list of added items and their quantities for validation or testing with Sensei-check rules.
