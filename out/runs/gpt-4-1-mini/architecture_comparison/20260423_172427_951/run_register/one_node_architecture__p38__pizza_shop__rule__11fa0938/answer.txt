Hey! To create a Sensei-check rule that verifies the chatbot provides an `order_id` in its output, you want a single-conversation rule that checks if the `order_id` field is present and non-empty.

Here's a simple example rule for that:

```yaml
name: order_id_is_provided
description: The chatbot must provide a non-empty order_id in the output
conversations: 1
active: true
oracle: conv[0].order_id is not None and conv[0].order_id != ""
yields: f"Missing or empty order_id in conversation {conv[0]}"
```

This rule:

- Runs on one conversation at a time (`conversations: 1`).
- Checks that `order_id` exists and is not an empty string.
- Provides a helpful message if the check fails.

If your profile exposes `order_id` in `chatbot.output`, this rule will catch cases where the chatbot forgot to include it.
