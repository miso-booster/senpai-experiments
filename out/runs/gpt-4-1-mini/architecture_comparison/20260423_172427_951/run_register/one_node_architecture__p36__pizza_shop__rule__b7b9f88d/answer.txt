Hey! I see the rule you shared is missing the `if:` condition, which is essential for metamorphic rules using `if`/`then` syntax. The `if:` part defines the condition under which the `then:` assertion applies.

In your case, you want to check that when the number of toppings in `conv[0]` is greater than in `conv[1]`, the price should also be higher.

Here's the fixed version of your rule with the `if:` condition added:

```yaml
name: more_toppings_cost_more
description: Adding more toppings to a custom pizza costs more
active: true
conversations: 2
when: conv[0].size == conv[1].size and conv[0].drink == conv[1].drink
if: len(conv[0].toppings) > len(conv[1].toppings)
then: extract_float(conv[0].price) > extract_float(conv[1].price)
```

This way, the rule says: *If* the first conversation has more toppings than the second (and size and drink are equal), *then* its price must be higher.
