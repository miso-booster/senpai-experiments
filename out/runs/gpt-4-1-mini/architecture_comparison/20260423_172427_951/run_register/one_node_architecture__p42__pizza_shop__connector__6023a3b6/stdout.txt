Thanks for sharing the details! I see a couple of issues:

1. Your connector's `path` should be `/api/public/messages` (not `/api/messages`) to match the actual request.
2. You need to add the `Authorization` header with the token you showed.
3. The payload requires fields like `conversation`, `sender_type`, `sender`, `bot`, `language`, and `url` — these must be included in `payload_template`.
4. The `response_path` should be `"response.0.text"` to extract the bot's reply from the JSON response.

Here's a fixed connector YAML based on your example:

```yaml
name: "Connector"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

This should work with your API as shown in the example request/response.
