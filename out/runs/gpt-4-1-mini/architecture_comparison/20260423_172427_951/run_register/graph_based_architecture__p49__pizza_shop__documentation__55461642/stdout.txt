Hey there! 😊 The `pairwise()` function in Sensei Profiles is a super handy way to generate test cases efficiently when you have multiple variables with different options.

### What does `pairwise()` do?

Imagine you have several variables, each with multiple possible values, and you want to test combinations of these variables. Testing **all** possible combinations can explode exponentially (think: every pizza size × every topping × every drink type — that’s a lot!).

`pairwise()` smartly generates a **subset of combinations** so that **every pair of values between any two variables appears at least once**. This way, you cover all 2-way interactions without testing every single full combination, saving time and resources.

---

### Simple example

Suppose you have:

- `size`: [small, medium, large]
- `drink`: [cola, juice]
- `topping`: [cheese, mushrooms]

If you did a full Cartesian product, you'd get 3 × 2 × 2 = 12 combinations.

With `pairwise()`, you get fewer combinations but still cover every pair of options between variables. For example, you ensure:

- Every size is tested with every drink at least once.
- Every size is tested with every topping at least once.
- Every drink is tested with every topping at least once.

---

### How to use it in a profile?

You declare variables with `function: pairwise()` like this:

```yaml
goals:
  - "Order a {{size}} pizza with {{topping}} and a {{drink}}"
  - size:
      function: pairwise()
      type: string
      data: [small, medium, large]
  - topping:
      function: pairwise()
      type: string
      data: [cheese, mushrooms]
  - drink:
      function: pairwise()
      type: string
      data: [cola, juice]
```

Sensei will generate a set of conversations covering all pairs of these options without exploding the total number of tests.

---

### Why is this great?

- **Efficiency:** Fewer conversations than full combinations.
- **Coverage:** Every pairwise interaction is tested, which often catches most bugs.
- **Scalability:** Works well when you have many variables.
