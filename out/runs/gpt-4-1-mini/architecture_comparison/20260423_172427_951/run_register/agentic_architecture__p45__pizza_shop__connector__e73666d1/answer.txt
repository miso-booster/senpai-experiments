Here is the YAML connector configuration using only the minimal required headers. The response path extracts the raw text from the JSON response. Since the connector schema does not support inline HTML stripping, you will need to handle HTML tag removal outside the connector or via post-processing in your application.

```yaml
name: "1MillionBot Minimal"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
```

To get plain text without HTML tags, you can strip tags after receiving the response in your application code. Let me know if you want help with that.
