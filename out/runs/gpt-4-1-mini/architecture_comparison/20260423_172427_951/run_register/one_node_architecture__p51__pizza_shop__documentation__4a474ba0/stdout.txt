Hey! Connectors in Sensei are the YAML configuration files that let you connect your chatbot testing framework to any chatbot API without writing code. They describe how to send user messages to your chatbot and how to extract the chatbot's replies from the API responses.

### What are connectors used for?
- To **configure communication** with your chatbot’s API.
- To **send user messages** in the right format (HTTP method, headers, payload).
- To **extract the chatbot’s response** from the JSON reply.
- To enable Sensei to **interact with any chatbot platform** flexibly.

---

### Key fields in a connector YAML:

```yaml
name: "Friendly Bot Name"          # Optional, a name for your chatbot connection
base_url: "https://api.mybot.com"  # Required, the base URL of your chatbot API

send_message:
  path: "/chat"                    # Required, API endpoint path appended to base_url
  method: "POST"                   # Optional, HTTP method (default is POST)
  headers:                        # Optional, any HTTP headers like Authorization, Content-Type
    Authorization: "Bearer token"
    Content-Type: "application/json"
  payload_template:                # Required, JSON structure with "{user_msg}" placeholder for user input
    message: "{user_msg}"
    session_id: "user123"

response_path: "response.text"    # Required, dot-separated path to extract the chatbot reply from the JSON response
```

---

### Quick summary:
- **`name`**: Friendly name for your connector.
- **`base_url`**: The API base URL.
- **`send_message.path`**: The API endpoint path.
- **`send_message.method`**: HTTP method (POST, GET, etc.).
- **`send_message.headers`**: Optional headers like auth tokens.
- **`send_message.payload_template`**: The JSON payload with `{user_msg}` where the user message goes.
- **`response_path`**: How to find the chatbot’s reply inside the JSON response.
