¡Claro! Aquí tienes un perfil Sensei para probar un chatbot de pizzería que extrae el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares. Está listo para usar y puedes adaptarlo según necesites 😊.

```yaml
test_name: "pizza_order_basic_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a customer ordering a pizza and a drink from a pizzeria.
    Specify your pizza type and drink choice clearly.
  context:
    - "You want to place a simple order for one pizza and one drink."
  goals:
    - "I want to order a {{pizza_type}} pizza."
    - "I would like a {{drink}} to drink."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian, Four cheese]
    - drink:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Iced Tea]

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand that. Could you please repeat your order?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered"
    - drink:
        type: string
        description: "The drink ordered"
    - order_id:
        type: string
        description: "Unique identifier for the order"
    - final_price:
        type: money
        description: "Final price of the order in USD"

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

Si quieres, puedo ayudarte a ajustarlo para que sea más complejo o incluya más variables. ¿Quieres? 🍕😊
