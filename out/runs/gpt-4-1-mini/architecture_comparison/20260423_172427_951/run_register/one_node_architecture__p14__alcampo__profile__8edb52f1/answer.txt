¡Claro! Te preparo un perfil SENSEI para simular un usuario que busca recomendaciones de recetas y planificación de menús en el chatbot de Alcampo. Este perfil incluirá variables para tipos de recetas, ingredientes, y objetivos relacionados con la planificación de menús.

Aquí tienes un perfil YAML listo para usar o adaptar según tus necesidades:

```yaml
test_name: "recipe_and_menu_planning"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a user interested in receiving recipe recommendations and help planning menus for the week.
    You want to explore different types of recipes, dietary preferences, and meal occasions.
  context:
    - "You want to prepare balanced meals with seasonal ingredients."
    - "You prefer recipes that are easy to cook and suitable for family dinners."
  goals:
    - "Recommend a {{recipe_type}} recipe suitable for {{meal_time}}."
    - "Suggest a weekly menu plan including {{number_of_meals}} meals."
    - "Provide ingredient lists for {{recipe_type}} recipes."
    - "Offer cooking tips for {{dietary_preference}} recipes."
    - recipe_type:
        function: forward()
        type: string
        data: [appetizer, main course, dessert, salad, soup]
    - meal_time:
        function: random()
        type: string
        data: [breakfast, lunch, dinner, snack]
    - number_of_meals:
        function: random()
        type: int
        data: [3, 5, 7]
    - dietary_preference:
        function: random()
        type: string
        data: [vegetarian, vegan, gluten-free, low-carb, no preference]

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand that. Could you please ask about recipes or menu planning?"
  output:
    - recommended_recipe:
        type: string
        description: "Name or description of the recommended recipe"
    - menu_plan:
        type: string
        description: "Weekly menu plan suggested by the chatbot"
    - ingredient_list:
        type: string
        description: "List of ingredients for the recommended recipes"
    - cooking_tips:
        type: string
        description: "Cooking tips related to dietary preferences"

conversation:
  number: 3
  goal_style:
    steps: 15
  interaction_style:
    - single questions
```

Este perfil:

- Simula un usuario que pide recetas y planes de menú.
- Usa variables para tipos de recetas, horarios de comida, número de comidas a planificar y preferencias dietéticas.
- Extrae en `chatbot.output` los campos clave para validar las respuestas del bot.
- Controla la conversación para 3 casos con 15 pasos cada uno y preguntas individuales.
