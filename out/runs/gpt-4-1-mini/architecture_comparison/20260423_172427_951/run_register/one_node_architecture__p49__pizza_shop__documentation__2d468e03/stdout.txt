Hey! Great question 😊 The `pairwise()` function in Sensei Profiles is a super handy way to efficiently cover combinations of variables in your simulated user goals without exploding the total number of conversations.

### What does `pairwise()` do?

Imagine you have several variables, each with multiple possible values. Testing **every** combination (the full Cartesian product) can become huge and expensive. Instead, `pairwise()` generates a set of conversations that covers **all pairs** of variable values at least once.

In other words, it guarantees that for every pair of variables, every possible pair of their values appears in **some** conversation — but not necessarily all combinations of all variables together.

---

### Why is this useful?

- **Efficiency:** You get broad coverage of interactions between variables without needing to test every single full combination.
- **Effectiveness:** Many bugs or issues arise from interactions between pairs of inputs, so pairwise testing is a smart compromise.
- **Scalability:** It keeps your test suite manageable and faster to run.

---

### How to use it?

In your profile YAML, you declare variables with `function: pairwise()`. For example:

```yaml
goals:
  - "Order a {{size}} {{pizza_type}} pizza with {{drink}}"
  - size:
      function: pairwise()
      type: string
      data: [small, medium, large]
  - pizza_type:
      function: pairwise()
      type: string
      data: [Margherita, Pepperoni, Vegetarian]
  - drink:
      function: pairwise()
      type: string
      data: [Coke, Water, Juice]
```

Sensei will generate a set of conversations where every pair of values between `size`, `pizza_type`, and `drink` appears at least once, but without testing all 3×3×3=27 full combos.

---

### A simple analogy

Think of pairwise like making sure every pair of shoes and socks gets tried together at least once, but you don’t try every possible outfit combination. You cover all pairs efficiently!
