In a Sensei profile, the following fields are generally **not mandatory** and are optional depending on your testing needs:

- **llm**: This section is optional. If omitted, defaults are applied (e.g., model and temperature) and the format defaults to text. You only add it when you want to override defaults or use speech mode.

- **user.context**: This is optional. It can include personalities or freeform constraints/preferences but is not required.

- **conversation.max_cost**: Optional cap on the total spend for the entire run.

- **goal_style.max_cost**: Optional cap on per-conversation spend.

- **interaction_style**: Optional list of interaction styles to simulate user behavior variations.

- **personalities** referenced in `user.context`: Optional prompt snippets for user personas.

- **custom types** in `user.goals` or `chatbot.output`: Optional unless you need specific data validation.

The **mandatory** fields typically include:

- `test_name` (string)

- `user.language` and `user.role`

- `user.goals` with variables declared properly

- `chatbot.is_starter` and `chatbot.fallback`

- `chatbot.output` fields you want to extract for validation

- `conversation.number` and `goal_style.steps` or other stopping criteria

This is based on the profile structure and guidelines in the `sensei-chat-guide.md` documentation.
