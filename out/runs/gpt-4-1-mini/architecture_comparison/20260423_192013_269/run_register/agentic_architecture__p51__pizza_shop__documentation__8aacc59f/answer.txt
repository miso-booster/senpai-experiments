Connectors in Chatbot Dojo are used to connect your chatbot testing setup to an external chatbot API without writing code. They define how to send user messages to the chatbot API and how to extract the chatbot's reply from the API response.

### What connectors are used for:
- They act as the transport layer between the simulator and the target chatbot.
- They specify the API endpoint, HTTP method, headers, and payload format to send user messages.
- They define how to parse the chatbot's reply from the JSON response using a dot-separated path.

### Key fields of a connector YAML configuration:
- `name` (optional): Friendly name for your chatbot.
- `base_url` (required): Base URL of the chatbot API.
- `send_message` (required): Defines how to send a message:
  - `path` (required): API endpoint path appended to `base_url`.
  - `method` (optional, default POST): HTTP method like POST, GET, etc.
  - `headers` (optional): Custom headers such as Authorization tokens.
  - `payload_template` (required): JSON structure with `{user_msg}` placeholder for the user message.
- `response_path` (required): Dot-separated path to extract the chatbot's reply from the JSON response.

### Example snippet:
```yaml
name: "Echo Bot"
base_url: "https://postman-echo.com"
send_message:
  path: "/post"
  method: "POST"
  payload_template:
    message: "{user_msg}"
response_path: "json.message"
```

This means when you send a user message, it will POST to `https://postman-echo.com/post` with JSON `{ "message": "user message here" }`, and the bot's reply is extracted from the JSON response at `json.message`.
