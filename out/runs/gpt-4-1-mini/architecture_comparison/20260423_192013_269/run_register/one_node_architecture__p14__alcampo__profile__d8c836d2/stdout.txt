¡Claro! Puedo ayudarte a crear un perfil SENSEI para probar la capacidad del chatbot de Alcampo en recomendar recetas y planificación de menús. Este perfil simulará un usuario interesado en buscar recetas, gestionar ingredientes, y planificar menús para diferentes ocasiones.

Aquí tienes un ejemplo de perfil YAML que puedes usar o adaptar para tu proyecto:

```yaml
test_name: "recipe_and_menu_planning"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a user interested in finding recipes and planning menus for different meals and occasions.
    You ask for recipe recommendations, ingredient lists, cooking tips, and menu suggestions.
  context:
    - personality: personalities/conversational-user.yml
    - "You want healthy, easy-to-cook recipes."
    - "You like seasonal ingredients."
  goals:
    - "Ask for recipe recommendations for {{meal_type}}."
    - "Request ingredients and cooking steps for the recipe {{recipe_name}}."
    - "Ask for menu planning ideas for {{occasion}}."
    - "Inquire about substitutions for {{ingredient}} in recipes."
    - meal_type:
        function: forward()
        type: string
        data: [breakfast, lunch, dinner, snack, dessert]
    - recipe_name:
        function: random()
        type: string
        data: [paella, gazpacho, tortilla española, crema catalana, empanadas]
    - occasion:
        function: random()
        type: string
        data: [family dinner, birthday party, healthy week, quick meals, vegetarian day]
    - ingredient:
        function: random()
        type: string
        data: [chicken, gluten, dairy, nuts, eggs]

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand your request about recipes or menu planning. Could you please rephrase?"
  output:
    - recommended_recipes:
        type: string
        description: "List of recommended recipes"
    - recipe_ingredients:
        type: string
        description: "Ingredients list for a recipe"
    - cooking_steps:
        type: string
        description: "Step-by-step cooking instructions"
    - menu_suggestions:
        type: string
        description: "Menu planning suggestions for an occasion"
    - substitution_advice:
        type: string
        description: "Advice on ingredient substitutions"

conversation:
  number: 3
  goal_style:
    steps: 20
  interaction_style:
    - single questions
```

Este perfil incluye variables para tipos de comidas, nombres de recetas, ocasiones para planificar menús e ingredientes para sustituciones, con funciones para generar combinaciones variadas. Además, define campos en `chatbot.output` para extraer las respuestas clave que luego podrías usar en reglas Sensei-check para validar la calidad y coherencia de las recomendaciones.
