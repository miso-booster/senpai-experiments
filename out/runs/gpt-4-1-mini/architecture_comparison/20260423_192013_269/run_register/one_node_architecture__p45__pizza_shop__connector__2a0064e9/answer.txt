Here's a minimal YAML connector configuration for your chatbot API. It uses only the required headers and extracts the plain text response with HTML tags removed:

```yaml
name: "1MillionBot Minimal"
base_url: "https://api.1millionbot.com"
send_message:
  path: "/api/public/messages"
  method: "POST"
  headers:
    Content-Type: "application/json"
    Authorization: "64e5d1af081211d24e2cfecd"
  payload_template:
    conversation: "6977595c744ccf01954b8797"
    sender_type: "User"
    sender: "6977595c3e4824018e496b0c"
    bot: "64e5d1af081211d24e2cfec8"
    language: "es"
    url: "https://saic.malaga.eu/"
    message:
      text: "{user_msg}"
response_path: "response.0.text"
postprocess: "remove_html"
```

Note: The `postprocess: "remove_html"` line instructs Sensei to strip HTML tags from the extracted text response, returning plain text. If your Sensei setup does not support `postprocess`, you may need to handle HTML removal in your processing pipeline.
