An **oracle** in SENSEI (Sensei-check) is a boolean condition or expression that defines the expected correctness criterion for one or more conversations. It acts as a test assertion that must hold true for the conversation(s) to pass the validation.

Here’s a simple breakdown:

- An oracle is typically used in a **single-conversation rule** (traditional oracle) or can be part of a metamorphic rule comparing multiple conversations.
- It is a Python-like expression that evaluates to `True` or `False`.
- If the oracle condition is `True`, the conversation(s) pass the check; if `False`, it means the chatbot behavior is incorrect or unexpected.
- Oracles often reference extracted outputs from the chatbot conversation, such as slots or fields defined in the profile’s `chatbot.output`.
- You can also use helper functions inside the oracle to analyze text, numbers, language, tone, uniqueness, etc.

Example from the docs for a single conversation oracle:

```yaml
name: small_base_price_floor
description: Small pizzas should cost at least $10
conversations: 1
when: size == 'small'
oracle: extract_float(price) >= 10 and currency(price) == 'USD'
```

This oracle checks that if the pizza size is small, then the price extracted from the conversation must be at least 10 USD.

In summary, the oracle is the core validation condition inside a SENSEI rule that defines what "correct" means for the chatbot output.
