Thanks for sharing your rule! I see a few issues to fix so it works correctly with Sensei-check:

1. The `conversations` count is 2, but your rule only uses `conv[0]`. For a single conversation check, use `conversations: 1`.
2. The `when` condition is filtering on `conv[0].tune_up_price == 50` but `tune_up_price` is likely a string with currency (e.g., "50 USD"), so direct equality won't work.
3. The `then` clause should be a boolean expression, not a string message.
4. The rule should parse the price as a float using `extract_float()` and check currency with `currency()` helper.
5. The `if` clause is redundant if you already filter with `when`.

Here is a corrected version that checks if the tune-up price (parsed as float) equals 50 and currency is USD, for a single conversation:

```yaml
name: check_tune_up_price
description: Checks if the tune-up price is exactly $50 USD.
conversations: 1
when: conv[0].tune_up_price is not None
oracle: extract_float(conv[0].tune_up_price) == 50 and currency(conv[0].tune_up_price) == 'USD'
```

### What I changed:
- Changed `conversations` from 2 to 1 because you only check one conversation.
- Replaced `when` condition to just check presence of `tune_up_price`.
- Used `oracle` instead of `if`/`then` with a boolean expression.
- Used `extract_float()` to parse the numeric price.
- Added `currency()` check to ensure it's in USD.
- Removed the string message from `then` (rules expect boolean expressions).
