¡Claro! Aquí tienes un perfil Sensei para probar un chatbot de pizzería que simula un usuario haciendo un pedido. El perfil define variables para tipo de pizza y bebida, y en el `chatbot.output` expone el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares, tal como pediste.

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer ordering a pizza and a drink from a pizzeria."
  context:
    - "You want to order a pizza and a drink."
  goals:
    - "I want to order a {{pizza_type}} pizza."
    - "Please add a {{drink}} to my order."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian, Four cheese]
    - drink:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Fanta]

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand that. Could you please repeat?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink:
        type: string
        description: "The drink ordered."
    - order_id:
        type: string
        description: "Unique identifier for the order."
    - final_price:
        type: currency
        description: "Final price of the order in USD."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

Este perfil genera 3 conversaciones donde el usuario ordena una pizza y una bebida, y espera que el chatbot entregue en su output los campos `pizza_type`, `drink`, `order_id` y `final_price` (en dólares).
