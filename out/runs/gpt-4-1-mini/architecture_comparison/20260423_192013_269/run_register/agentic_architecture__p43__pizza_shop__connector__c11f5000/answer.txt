Tu conector YAML está bien configurado para enviar la request y extraer la respuesta según el ejemplo que diste. La estructura del `payload_template` coincide con la request esperada:

```json
{
  "message": {
    "text": "hola"
  }
}
```

Y el `response_path: "response.text"` apunta correctamente al texto dentro del JSON de respuesta:

```json
{
  "status": "success",
  "response": {
    "text": "¡Hola! ¿Cómo puedo ayudarte hoy?"
  }
}
```

Solo asegúrate de que:

- El header `Content-Type` esté con comillas, como ya lo tienes.
- El `base_url` y el `path` estén concatenados correctamente (sin doble slash ni falta de slash).
- Si el API requiere algún otro header (como autenticación), lo agregues en `headers`.

Aquí tienes el conector para que lo uses directamente:

```yaml
name: "Test Connector 2"
base_url: "https://api.anotherexample.com"
send_message:
  path: "/api/chat"
  method: "POST"
  headers:
    Content-Type: "application/json"
  payload_template:
    message:
      text: "{user_msg}"
response_path: "response.text"
```
