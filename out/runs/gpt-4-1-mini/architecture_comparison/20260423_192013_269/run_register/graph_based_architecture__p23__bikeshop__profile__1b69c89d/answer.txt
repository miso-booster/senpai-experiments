### Why these changes?

- **`temperature` must be a float** because Sensei uses it to control randomness in LLM calls.
- **`type` fields in `chatbot.output` are mandatory** so Sensei knows how to parse and validate the extracted info.
- Use **`string` instead of `str`** for output types because Sensei expects the full word `string`.
- Quoting strings in YAML avoids parsing ambiguity.
- `is_starter` should be lowercase boolean for consistency.
