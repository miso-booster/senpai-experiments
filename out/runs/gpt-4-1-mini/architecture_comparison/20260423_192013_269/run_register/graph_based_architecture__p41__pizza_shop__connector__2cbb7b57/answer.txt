    Connection: "keep-alive"

    Sec-Fetch-Mode: "cors"
    Sec-Fetch-Site: "same-origin"
    Pragma: "no-cache"
    Cache-Control: "no-cache"

    data:
      id_user: "377611"

### A few notes:
- I kept static values like `id_user`, `idweb_user`, and `session` as in your example, but you can replace those with variables if you want dynamic sessions.

- All the headers from your request are included exactly as you provided.
- The user message placeholder is `{user_msg}` inside the nested JSON structure.
