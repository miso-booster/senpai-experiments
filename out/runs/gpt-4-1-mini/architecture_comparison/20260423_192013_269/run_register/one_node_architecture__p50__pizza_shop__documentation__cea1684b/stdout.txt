Hey! Great question 😊 In the context of **Sensei-check rules**, an **oracle** is basically a condition or a test that checks if a conversation (or multiple conversations) behaves as expected.

Think of it like a "truth test" or a "rule" that the chatbot's output must satisfy to be considered correct.

- For **single-conversation rules**, the oracle is a boolean expression that inspects the outputs of one conversation.
- For **metamorphic rules** (which compare multiple conversations), the oracle can be an expression or an `if/then` statement that asserts relationships between conversations.

For example, a simple oracle might check that the chatbot always returns a price greater than zero:

```yaml
oracle: extract_float(price) > 0
```

Or a metamorphic oracle might say: "If one order has more toppings than another (but same size and drink), then its price should be higher."

In short: **An oracle is the condition that verifies if the chatbot's behavior/output is correct or consistent according to your expectations.**
