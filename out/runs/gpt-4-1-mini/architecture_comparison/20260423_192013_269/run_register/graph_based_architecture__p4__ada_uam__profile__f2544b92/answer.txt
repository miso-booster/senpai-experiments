¡Claro! 😊 Para crear un perfil Sensei que simule un usuario que busca soporte sobre el CAU (Centro de Atención a Usuarios) y extraiga el número de teléfono, email, dirección física y horarios, podemos basarnos en la estructura que usan los perfiles Sensei.

Aquí te dejo un ejemplo de perfil YAML para ese caso, que puedes adaptar y guardar en tu carpeta `profiles/`:

```yaml
test_name: "Soporte CAU - Información de contacto"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres un usuario que necesita soporte del Centro de Atención a Usuarios (CAU)
    de la Universidad Autónoma de Madrid. Quieres obtener información clara y precisa
    sobre cómo contactar con ellos, incluyendo teléfono, correo electrónico, dirección física y horarios de atención.
  context:
    - personality: personalities/formal-user.yml
    - "Busco ayuda para resolver dudas técnicas y administrativas relacionadas con mis servicios universitarios."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Me puedes dar el correo electrónico para contactar al CAU?"
    - "¿Dónde está ubicada la oficina física del CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: false
  fallback: "Por favor, ¿me lo puedes decir con otras palabras? O puedes consultar nuestro catálogo de servicios."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```

---

### Explicación rápida:

- **user.role** define el tipo de usuario y su intención.
- **user.goals** son las preguntas que el usuario hará para obtener la info que quieres.
- **chatbot.output** define los campos que quieres extraer y validar en las respuestas del bot.
- **conversation.number** y **goal_style.steps** controlan la cantidad y duración de las conversaciones.
- **interaction_style: single questions** simula que el usuario hace una pregunta por interacción.
