Hey! Connectors in Sensei are used to connect your testing framework to an actual chatbot API. They define how to send user messages to the chatbot and how to extract the chatbot’s responses from the API replies. This lets Sensei simulate conversations with your real bot without writing code, just by configuring a YAML file.

### What connectors are used for:
- **Send user messages** to your chatbot API.
- **Receive and parse** chatbot responses.
- **Configure headers, authentication, and payloads** for API calls.
- **Extract the chatbot’s reply** from complex JSON responses using a path.

---

### Main fields in a connector YAML:

```yaml
name: "Friendly Bot Name"          # Optional, a label for your connector
base_url: "https://api.chatbot.com"  # The base URL of your chatbot API

send_message:
  path: "/chat/send"               # API endpoint path appended to base_url
  method: "POST"                  # HTTP method (POST, GET, etc.), defaults to POST
  headers:                       # Optional HTTP headers (e.g., Authorization)
    Authorization: "Bearer token"
    Content-Type: "application/json"
  payload_template:               # JSON structure sent as the request body
    message: "{user_msg}"         # {user_msg} is replaced with the user input text
    session_id: "user123"         # Optional static or dynamic fields

response_path: "data.response.text"  # Dot-separated path to extract bot reply from JSON
```

---

### Summary:
- **`name`**: Friendly name for your connector (optional).
- **`base_url`**: The root URL of your chatbot’s API.
- **`send_message`**: Defines the API call to send user messages:
  - `path`: Endpoint path.
  - `method`: HTTP method (default POST).
  - `headers`: Any required HTTP headers.
  - `payload_template`: The JSON payload with `{user_msg}` placeholder.
- **`response_path`**: How to extract the chatbot’s reply from the JSON response.
