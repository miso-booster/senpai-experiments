¡Claro! Para crear una regla en Sensei-check que verifique si el asistente confirma haber añadido la bebida que el usuario pidió, necesitamos definir una condición que busque en la conversación un turno del asistente que mencione esa confirmación.

Asumiendo que en el perfil de chat se expone un campo o que podemos buscar en las frases del asistente la confirmación (por ejemplo, que contenga palabras como "añadido", "bebida", "confirmo", "pedido", etc.), podemos usar la función `utterance_index` para detectar en qué turno el asistente menciona la confirmación.

Aquí tienes un ejemplo de regla que hace eso para una sola conversación (conversations: 1):

```yaml
name: assistant_confirms_drink_added
description: El asistente confirma que añadió la bebida que el usuario pidió
conversations: 1
oracle: utterance_index('assistant', 'bebida añadida') > 0 or utterance_index('assistant', 'bebida agregada') > 0 or utterance_index('assistant', 'confirmo la bebida') > 0
```

Esta regla busca en los turnos del asistente frases que contengan esas expresiones clave. Si alguna aparece, la regla pasa.

Si quieres que sea más flexible, puedes usar solo una palabra clave común, o combinar con expresiones más específicas según el lenguaje que use tu asistente.
