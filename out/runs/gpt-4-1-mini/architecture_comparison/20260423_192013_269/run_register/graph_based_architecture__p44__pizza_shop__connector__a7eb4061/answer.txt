```yaml

  method: "POST"

    Content-Type: "application/json"
    Authorization: "65ca19e7dbbb4e26cbeadf28"
```

### Explicación rápida:
- Cambié los valores de `Authorization`, `conversation`, `sender`, `bot`, `url` para que coincidan con los datos que me diste.
- Añadí los headers `Origin` y `Referer` porque aparecen en la petición original y a veces son necesarios para que la API acepte la llamada.
- `response_path` sigue siendo `"response.0.text"` porque la respuesta JSON que muestras tiene la estructura con `response` y el texto está en el primer elemento del array bajo la clave `text`.
