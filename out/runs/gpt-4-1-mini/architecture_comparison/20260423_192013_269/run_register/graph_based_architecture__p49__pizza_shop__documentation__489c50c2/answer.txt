Hey there! 😊 Let's dive into how the `pairwise()` function works in Sensei Profiles, especially in the `user.goals` section where you define variables.

---

### What is `pairwise()`?

`pairwise()` is a **fill function** used to generate combinations of variable values in a way that covers **every possible pair of values between two or more variables at least once** — but without creating the full Cartesian product, which can be huge!

---

### Why use `pairwise()`?

Imagine you have two variables:

- `pizza_size`: [small, medium, large]
- `drink_type`: [cola, juice, water]

A full Cartesian product would generate 3 × 3 = 9 combinations.

But if you add more variables, the combinations explode exponentially.

`pairwise()` smartly picks a smaller set of combinations that still tests every pair of values between variables. This helps catch bugs related to interactions between pairs of inputs without needing to test every possible combo.

---

### How to use `pairwise()`?

In your profile YAML, you declare variables with `pairwise()` as their fill function. For example:

```yaml
goals:
  - "Order a {{pizza_size}} pizza with a {{drink_type}}"
  - pizza_size:
      function: pairwise()
      type: string
      data: [small, medium, large]
  - drink_type:
      function: pairwise()
      type: string
      data: [cola, juice, water]
```

If you add a third variable with `pairwise()`, the system will generate a minimal set of conversations that cover **all pairs** of values across these variables.

---

### Important notes:

- You need **at least two variables** using `pairwise()` for it to work.
- `pairwise()` supports **multiple variables** at once, so it can cover pairs across all of them.
- It helps reduce the total number of conversations while maintaining good coverage.
- You can combine `pairwise()` with other fill functions like `forward()` or `random()`.
- When you use `conversation.number: combinations` or `combinations(p)` in your profile, it uses the pairwise matrix to generate conversations.

---

### Simple analogy

Think of `pairwise()` like testing all pairs of toppings on a pizza without testing every single topping combination. You want to make sure every pair of toppings is tested together at least once, but you don't want to bake every possible pizza!
