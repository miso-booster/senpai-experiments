Hey! I see the rule you shared is missing the `if:` condition, which is important for metamorphic rules that express implications. You want to say: *If* one conversation has more toppings than the other, *then* its price should be higher.

Right now, your rule only has `when:` and `then:`, but it needs an `if:` to specify the condition that triggers the price comparison.

Here’s the fixed version of your rule with the `if:` added:

```yaml
name: more_toppings_cost_more
description: Adding more toppings to a custom pizza costs more
active: true
conversations: 2
when: conv[0].size == conv[1].size and conv[0].drink == conv[1].drink
if: len(conv[0].toppings) > len(conv[1].toppings)
then: extract_float(conv[0].price) > extract_float(conv[1].price)
```

This says: When size and drink are equal, if the first conversation has more toppings than the second, then its price should be higher.
