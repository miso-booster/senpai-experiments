Hey! Great question 😊 In the context of Sensei, a **metamorphic rule** is a special kind of test rule used in **Sensei-check** to verify chatbot behavior across multiple conversations, not just one.

Here’s the scoop:

- Instead of checking if a single chatbot response is exactly right (which can be tricky for open-ended conversations), metamorphic rules check **relationships** or **invariants** between *pairs* or *sets* of conversations.
- For example, if you have two conversations where the user orders pizzas of the same size and drink but with different numbers of toppings, a metamorphic rule might say:  
  *“If conversation A has more toppings than conversation B, then the price in A should be higher than in B.”*  
  This is a monotonicity check across conversations.
- These rules help solve the **oracle problem** (hard to know the exact correct answer) by focusing on how outputs should *change* when inputs change in controlled ways.

Technically, a metamorphic rule in Sensei-check:

- Specifies how many conversations it needs (usually 2 or more).
- Optionally filters which conversations to compare (`when` clause).
- Defines the expected relation using `if`/`then` or a boolean `oracle` expression over the conversations’ extracted outputs.

So, metamorphic rules are all about **checking consistency and logical relations across multiple chatbot interactions**, making testing more robust and meaningful.
