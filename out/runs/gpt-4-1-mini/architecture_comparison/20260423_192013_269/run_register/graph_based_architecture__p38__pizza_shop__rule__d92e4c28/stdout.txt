Here’s a clean example of such a Sensei-check rule in YAML:

```yaml
name: order_id_presence
description: The chatbot must provide a non-empty order_id in every conversation
conversations: 1
oracle: conv[0].order_id is not None and conv[0].order_id != ''
```

**Explanation:**

- `conversations: 1` means this rule checks each conversation individually.
- The `oracle` expression ensures that the `order_id` field exists (`is not None`) and is not an empty string.
- `conv[0]` refers to the single conversation being checked.

name: order_id_non_empty
description: Order ID must be a non-empty string
