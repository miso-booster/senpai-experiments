Aquí tienes un perfil SENSEI para probar un chatbot de pizzería. Este perfil define la simulación de un usuario que hace pedidos de pizza y el `chatbot.output` expone los campos que solicitaste: tipo de pizza, bebida, id del pedido y precio final en dólares.

```yaml
test_name: "pizzeria_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "Customer ordering pizza and drinks at a pizzeria."
  context:
    - "You want to order a pizza with a drink."
    - "You expect a confirmation with order ID and final price."
  goals:
    - "Order a {{pizza_type}} pizza with a {{drink}}."
    - "Get the order ID and final price in USD."
    - pizza_type:
        function: forward()
        type: string
        data: [margherita, pepperoni, vegetarian, hawaiian, four cheese]
    - drink:
        function: random()
        type: string
        data: [cola, water, lemonade, iced tea]

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand that. Could you please repeat?"
  output:
    - pizza_type:
        type: string
        description: "Type of pizza ordered"
    - drink:
        type: string
        description: "Drink ordered"
    - order_id:
        type: string
        description: "Unique identifier for the order"
    - price:
        type: currency
        description: "Final price in USD"

conversation:
  number: 5
  goal_style:
    steps: 6
  interaction_style:
    - random:
      - long phrases
      - make spelling mistakes
      - single questions
```

Este perfil está basado en la guía oficial de perfiles (sensei-chat-guide.md) y sigue las mejores prácticas para definir variables en `user.goals` y campos en `chatbot.output`.
