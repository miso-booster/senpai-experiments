¡Claro! 😊 Te ayudaré a crear un perfil Sensei para probar un chatbot de pizzería que extraiga en el output el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares.

Aquí tienes un ejemplo básico y funcional para tu perfil YAML:

```yaml
test_name: "pizza_order_basic_test"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a customer placing an order at a pizza shop.
    You want to order a pizza and a drink, and confirm your order details.
  context:
    - "You like classic pizzas."
  goals:
    - "I want to order a {{pizza_type}} pizza."
    - "I would like a {{drink_type}} to drink."
    - pizza_type:
        function: forward()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian, BBQ Chicken]
    - drink_type:
        function: forward()
        type: string
        data: [Coke, Sprite, Water, Fanta]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't understand that. Could you please repeat?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered by the customer"
    - drink_type:
        type: string
        description: "The drink ordered by the customer"
    - order_id:
        type: string
        description: "The unique identifier for the order"
    - total_price:
        type: money
        description: "The final price of the order in dollars"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

---

### Explicación rápida:

- **user.goals** define que el usuario pedirá un tipo de pizza y una bebida, con valores posibles para cada uno.
- **chatbot.output** define los campos que quieres extraer: tipo de pizza, bebida, id del pedido y precio final (tipo `money` para dólares).
- Conversación con 3 iteraciones y 4 pasos por conversación, con preguntas simples (una por interacción).
