Hey! Great question 😊 In the context of **SENSEI Rules** (especially Sensei-check), an **oracle** is basically a *test condition* or *assertion* that checks whether a chatbot's behavior or output is correct for a given conversation or set of conversations.

Think of it like a "truth test" that the chatbot must pass. The oracle defines what "correct" means, so when you run your tests, if the oracle condition fails, you know something's off.

---

### More specifically:

- An **oracle** is a boolean expression written in the Sensei-check DSL (a kind of YAML + Python expressions).
- It inspects the extracted outputs from the chatbot (via `chatbot.output` fields in a profile).
- It can apply to:
  - A **single conversation** (checking one chat's outputs),
  - **Multiple conversations** (metamorphic testing, comparing pairs or tuples),
  - Or **all conversations** (global properties).

---

### Example of a simple oracle (single conversation):

```yaml
name: small_base_price_floor
description: Small pizzas should cost at least $10
conversations: 1
when: size == 'small'
oracle: extract_float(price) >= 10 and currency(price) == 'USD'
```

Here, the oracle checks that if the pizza size is small, the price extracted from the chatbot's output is at least $10 in USD.

---

### Why are oracles important?

Because chatbots are complex and their outputs can vary, oracles give you a way to **automatically verify** correctness or consistency without manually reading every conversation.
