An **oracle** in SENSEI rules is a boolean condition that defines the expected correctness or validity of a conversation (or set of conversations). It acts as a test assertion that must hold true for the conversation(s) generated by the chatbot simulation.

Here’s a simple breakdown:

- An oracle is a **boolean expression** written in the Sensei-check DSL.
- It is evaluated over one or more conversations.
- If the oracle evaluates to `true`, the conversation passes the check.
- If it evaluates to `false`, the conversation fails the check, indicating a potential problem or bug.
- Oracles can be used for single conversations or for metamorphic testing involving multiple conversations.

For example, a single-conversation oracle might check that the price mentioned by the chatbot is above a minimum:

```yaml
name: small_base_price_floor
description: Small pizzas should cost at least $10
conversations: 1
when: size == 'small'
oracle: extract_float(price) >= 10 and currency(price) == 'USD'
```

Here, the `oracle` expression checks that the extracted price is at least 10 USD for small pizzas.

Oracles can also be used in metamorphic rules comparing multiple conversations, but the key idea is that an oracle is the **expected correctness condition** that the chatbot’s output must satisfy.
