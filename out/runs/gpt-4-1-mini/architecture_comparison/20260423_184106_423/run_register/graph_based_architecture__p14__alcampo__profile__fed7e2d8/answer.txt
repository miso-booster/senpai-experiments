### Aquí te dejo un ejemplo básico de perfil para recomendar recetas y planificación de menús, basado en la estructura Sensei:

```yaml
test_name: "recipe_recommendation_and_menu_planning"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres un usuario que busca recomendaciones de recetas y ayuda para planificar menús semanales.
    Quieres encontrar recetas según temporada, agregar ingredientes a la lista de compra y recibir consejos para cocinar.
  context:
    - "Te gusta cocinar platos saludables y variados."
    - "Prefieres recetas fáciles y rápidas."
  goals:
    - "Recomiéndame recetas para la temporada de primavera."
    - "¿Cómo puedo buscar recetas por categoría en Alcampo?"
    - "Agrega los ingredientes de la receta {{recipe_name}} a mi lista de compra."
    - "¿Qué opciones tengo para guardar mis recetas favoritas?"
    - recipe_name:
        function: random()
        type: string
        data:
          - paella
          - tortilla española
          - gazpacho
          - ensalada mediterránea

chatbot:
  is_starter: false
  fallback: "Lo siento, no he entendido tu pregunta. ¿Podrías reformularla?"
  output:
    - recommended_recipes:
        type: string
        description: "Lista de recetas recomendadas para la temporada o categoría"
    - search_instructions:
        type: string
        description: "Instrucciones para buscar recetas en Alcampo"
    - ingredients_added:
        type: string
        description: "Confirmación de ingredientes añadidos a la lista de compra"
    - favorite_recipes_options:
        type: string
        description: "Opciones para guardar recetas favoritas"

conversation:
  number: 3
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```
