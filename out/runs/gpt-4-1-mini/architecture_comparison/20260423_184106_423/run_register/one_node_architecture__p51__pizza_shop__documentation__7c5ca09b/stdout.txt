Hey! Connectors in Sensei are used to connect your testing framework to an actual chatbot API. They define how to send user messages to the chatbot and how to extract the chatbot’s responses from the API replies. This way, Sensei can simulate conversations with your real chatbot without writing custom code.

### What connectors are for:
- **Send user messages** to your chatbot API.
- **Receive and parse chatbot responses** from the API.
- **Configure authentication, headers, and payload structure** for the API calls.
- **Make Sensei testing flexible** to work with any chatbot platform by just changing the connector YAML.

---

### Key fields in a connector YAML:

```yaml
name: "Friendly name for your chatbot"   # Optional but helpful
base_url: "https://api.yourchatbot.com"  # The root URL of your chatbot API

send_message:
  path: "/chat/send"                      # API endpoint path appended to base_url
  method: "POST"                          # HTTP method (default is POST)
  headers:                               # Optional HTTP headers (e.g., Authorization)
    Authorization: "Bearer your-api-key"
    Content-Type: "application/json"
  payload_template:                      # JSON structure sent as the request body
    message: "{user_msg}"                # Use {user_msg} as placeholder for user input
    session_id: "user123"                # Optional static or dynamic fields

response_path: "response.text"           # Dot-separated path to extract bot reply from JSON response
```

---

### A quick analogy:
Think of the connector as a **translator** between Sensei and your chatbot API. It knows how to send your user’s message in the right format and where to find the chatbot’s reply inside the API’s response.
