Hey! In a SENSEI profile, some fields are mandatory to define the basic simulation, while others are optional to customize behavior or add extra features.

Here’s a quick rundown of **non-mandatory (optional) fields** in a profile:

- **llm.model_prov**: The provider key for the model (optional; defaults apply if omitted).
- **llm.format.config**: Used only if `llm.format.type` is `speech` (optional).
- **user.context**: Optional list of personality YAML references or freeform context strings.
- **chatbot.is_starter**: Optional boolean; defaults to false if omitted.
- **chatbot.fallback**: Optional fallback message to avoid endless loops.
- **conversation.max_cost**: Optional cost cap for the whole run.
- **conversation.goal_style.max_cost**: Optional cost cap per conversation.
- **conversation.goal_style.export**: Optional flag to export verification data.
- **conversation.goal_style.limit**: Optional safety limit on steps.
- **conversation.interaction_style**: Optional list of interaction styles; if omitted, defaults apply.
- **user.goals variables’ `function` and `data`**: Some variables can omit `function` to use defaults.
- **Custom types**: Only needed if you want to use them; otherwise default types suffice.

So basically, the **mandatory fields** are those that define the core simulation: `test_name`, `user.language`, `user.role`, `user.goals` (with variables), `chatbot.output` (fields to extract), and `conversation.number` plus some minimal conversation controls.

Everything else helps you tune the simulation or extraction but is not strictly required.
