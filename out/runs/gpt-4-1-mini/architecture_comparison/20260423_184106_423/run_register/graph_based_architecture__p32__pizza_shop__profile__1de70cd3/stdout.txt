¡Claro! 😊 Aquí tienes un perfil Sensei básico para probar un chatbot de pizzería que extrae el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares. Lo he diseñado para que puedas usarlo directamente y adaptarlo si quieres.

```yaml
test_name: "pizza_order_basic_test"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a customer placing an order at a local pizzeria.
    You want to order a pizza and a drink, then confirm the order details.
  context:
    - "You like classic pizzas and prefer soda drinks."
  goals:
    - "I want to order a {{pizza_type}} pizza."
    - "I would like a {{drink_type}} to drink."
    - pizza_type:
        function: forward()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian, BBQ Chicken]
    - drink_type:
        function: forward()
        type: string
        data: [Coke, Sprite, Fanta, Water]

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand that. Could you please rephrase?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered by the customer."
    - drink_type:
        type: string
        description: "The type of drink ordered by the customer."
    - order_id:
        type: string
        description: "The unique identifier for the order."
    - total_price:
        type: money
        description: "The final price of the order in dollars."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

---

### Explicación rápida:
- `user.goals` define que el usuario pedirá un tipo de pizza y una bebida, con opciones predefinidas.
- En `chatbot.output` se definen los campos que quieres extraer: tipo de pizza, bebida, ID del pedido y precio (como `money` para que reconozca moneda).
- `conversation.number` es 3 para hacer 3 conversaciones distintas con combinaciones diferentes.
- `interaction_style` con `single questions` para que el usuario haga preguntas o pedidos uno a uno.
