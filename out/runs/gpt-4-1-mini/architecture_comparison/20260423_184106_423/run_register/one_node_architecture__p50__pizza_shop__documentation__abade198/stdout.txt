Hey! Great question 😊 In the context of **Sensei-check rules**, an **oracle** is basically a condition or test that tells you whether a conversation (or set of conversations) behaves correctly or not.

Think of it like a judge or a truth-checker for your chatbot’s responses. The oracle is a logical expression you write in a rule that evaluates to `True` if everything is good, or `False` if something is wrong.

For example, in a single conversation, an oracle might check that the chatbot’s extracted price is above zero:

```yaml
oracle: extract_float(price) > 0
```

In metamorphic testing (comparing multiple conversations), the oracle might check a relation between conversations, like:

```yaml
if: len(conv[0].toppings) > len(conv[1].toppings)
then: extract_float(conv[0].price) > extract_float(conv[1].price)
```

Here, the oracle is the `then` part, which expects the price to increase when toppings increase.

So, in short:

- **Oracle = the test condition that verifies correctness.**
- It can be a simple check on one conversation or a relation across multiple conversations.
- It’s written as a Python-like expression in your Sensei-check rule.
