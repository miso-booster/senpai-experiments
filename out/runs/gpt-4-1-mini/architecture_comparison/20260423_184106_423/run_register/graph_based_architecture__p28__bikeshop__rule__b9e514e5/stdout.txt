Absolutely! To ensure your chatbot responds in the same language as the user, you can create a **Sensei-check metamorphic rule** that compares the language of the chatbot's replies to the expected language.

Here’s a simple, profile-agnostic example rule that checks language consistency across conversations:

```yaml
name: language_consistency
description: Comparable cases respond in the same language as the user
conversations: 2
when: conv[0].some_input_field == conv[1].some_input_field  # Optional: filter comparable conversations
oracle: responds_in_same_language() is True
```

### Explanation:
- `responds_in_same_language()` is a built-in helper that returns `True` if the assistant replies in the same language as the user.
- This rule is **global** and does not depend on specific profile output fields.
- You can adjust the `when` filter to compare conversations with similar inputs if needed, or omit it to check all.

---

### If you want a single-conversation version (checking each conversation individually):

```yaml
name: language_consistency_single
description: Bot replies in the same language as the user in each conversation
conversations: 1
oracle: responds_in_same_language() is True
```
