¡Claro! Aquí tienes un perfil Sensei para probar un chatbot de pizzería que simula un usuario haciendo un pedido. El perfil define variables para tipo de pizza y bebida, y extrae en `chatbot.output` los campos que necesitas: tipo de pizza, bebida, ID del pedido y precio final en dólares.

```yaml
test_name: "pizza_order_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a customer ordering pizza and drinks from a pizzeria.
    You want to place an order specifying the pizza type and a drink.
  context:
    - "You want a quick and simple order."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Order a {{drink}} to drink."
    - pizza_type:
        function: forward()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian, Four cheese]
    - drink:
        function: forward()
        type: string
        data: [Coke, Sprite, Water, Iced Tea]

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand that. Could you please repeat?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered"
    - drink:
        type: string
        description: "The drink ordered"
    - order_id:
        type: string
        description: "Unique identifier for the order"
    - final_price:
        type: money
        description: "Final price of the order in USD"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

Este perfil:

- Simula un usuario que ordena una pizza y una bebida.
- Extrae en `chatbot.output` los campos que mencionaste.
- Usa tipos estándar (`string` para texto y `money` para el precio en dólares).
- Realiza 3 conversaciones con 4 pasos cada una.
