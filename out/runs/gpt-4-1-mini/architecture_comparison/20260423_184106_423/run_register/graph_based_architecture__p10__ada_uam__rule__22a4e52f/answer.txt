¡Qué perfil tan completo y genial tienes para el tema de "Usuarios Nuevos y Admisiones"! 😊 Para probarlo con Sensei, te recomiendo crear algunas reglas Sensei-check que validen la coherencia y calidad de las respuestas que el chatbot genera, usando los campos que expone en `chatbot.output`.

Aquí te dejo algunas ideas de reglas que podrías usar para empezar a probar tu perfil, con ejemplos adaptados a los campos que tienes:

---

### 1) Regla para verificar que los enlaces importantes siempre estén presentes

Queremos asegurarnos de que el chatbot siempre devuelve URLs para los procesos clave (admisión, lista de espera, futuros estudiantes, Welcome Day).

```yaml
name: required_links_present
description: El chatbot debe proporcionar enlaces para admisión, lista de espera, futuros estudiantes y Welcome Day
conversations: 1
oracle: >
  admission_to_grados_link is not None and admission_to_grados_link != '' and
  waitlist_info_link is not None and waitlist_info_link != '' and
  future_students_link is not None and future_students_link != '' and
  welcome_day_link is not None and welcome_day_link != ''
```

---

### 2) Regla para verificar que las fechas y horas del evento Welcome Day sean válidas

Queremos que la fecha y hora del evento estén presentes y tengan sentido (fecha futura, hora válida).

```yaml
name: welcome_day_datetime_valid
description: La fecha y hora del Welcome Day deben estar presentes y ser válidas
conversations: 1
oracle: welcome_day_date is not None and welcome_day_time is not None and welcome_day_date > '2023-01-01'  # ajusta según contexto actual
```

---

### 3) Regla para verificar que el costo de la solicitud de admisión sea positivo

```yaml
name: application_fee_positive
description: El costo de la solicitud de admisión debe ser un valor positivo
conversations: 1
oracle: extract_float(application_fee) > 0
```

---

### 4) Regla metamórfica para consistencia entre diferentes grados o cursos

Por ejemplo, si dos conversaciones preguntan sobre grados diferentes, los enlaces y requisitos deben ser diferentes o al menos no vacíos.

```yaml
name: different_grades_have_different_links
description: Conversaciones con distintos grados deben tener enlaces o requisitos distintos
conversations: 2
when: conv[0].grados_available != conv[1].grados_available
oracle: conv[0].admission_to_grados_link != conv[1].admission_to_grados_link or conv[0].admission_requirements != conv[1].admission_requirements
```

---

### 5) Regla para verificar que la información de contacto de admisiones siempre esté presente

```yaml
name: contact_admissions_present
description: El chatbot siempre debe proporcionar información de contacto para admisiones
conversations: 1
oracle: contact_admissions is not None and contact_admissions != ''
```

---

### Cómo usar estas reglas

1. Guarda cada regla en un archivo YAML en tu carpeta de reglas (por ejemplo, `rules/admission_links.yaml`).
2. Ejecuta Sensei-check apuntando a tu perfil y estas reglas.
3. Revisa los reportes para ver si alguna regla falla y ajusta el perfil o las reglas según sea necesario.
