Absolutely! To ensure the chatbot responds in the same language as the user, you can create a Sensei-check rule that uses the helper `responds_in_same_language()`. This helper checks if the assistant's replies match the user's language.

Here’s a simple, profile-agnostic rule you can add to your rules folder:

```yaml
name: chatbot_responds_in_same_language
description: The chatbot responds in the same language as the user
conversations: 1
active: true
oracle: responds_in_same_language()
yields: "The chatbot does not respond in the same language as the user"
```

This rule will run on each conversation individually (`conversations: 1`) and verify language consistency.
