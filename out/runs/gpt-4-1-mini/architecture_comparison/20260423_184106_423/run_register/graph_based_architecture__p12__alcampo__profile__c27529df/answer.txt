Hey! I can help you create a Sensei profile that simulates a user asking the chatbot for items to add to their shopping cart. 🛒

Since you want a profile focused on adding items to the shopping cart, I’ll create a simple example with variables for item categories and quantities, and define the chatbot output to extract relevant info like the items added and their quantities.

Here’s a basic Sensei profile YAML template for that purpose:

```yaml
test_name: "shopping_cart_add_items"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a shopper who wants to add items to your online shopping cart.
    You ask the chatbot for help adding specific products and quantities.
  context:
    - "You want to add items efficiently and confirm they are in the cart."
  goals:
    - "Add {{quantity}} units of {{item_category}} to my shopping cart."
    - quantity:
        function: forward()
        type: int
        data:
          min: 1
          max: 5
          step: 1
    - item_category:
        function: forward(quantity)
        type: string
        data:
          - fruits
          - vegetables
          - dairy
          - bakery
          - beverages

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand that. Could you please specify the items you want to add?"
  output:
    - added_items:
        type: list[string]
        description: "List of item categories confirmed added to the cart"
    - quantities:
        type: list[int]
        description: "Quantities of each item added to the cart"

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

### Explanation:
- The user role describes a shopper wanting to add items.
- The `goals` field has a template sentence with variables `{{quantity}}` and `{{item_category}}`.
- `quantity` iterates from 1 to 5.
- `item_category` depends on `quantity` and cycles through some common categories.
- The chatbot output expects a list of added items and their quantities for extraction and validation.
- Conversation runs 3 times with 5 steps max, asking single questions each turn.
