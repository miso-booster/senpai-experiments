Got it! Here's a Sensei profile for a pizza shop where the user is rude and wants things done fast. It includes 4 goals with 4 variables, two of which use `pairwise()` functions so the conversation number will be based on the pairwise matrix coverage.

```yaml
test_name: "pizza_shop_rude_fast_user"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a rude and impatient customer who wants to order pizza quickly.
    You expect fast responses and no unnecessary small talk.
  context:
    - personality: personalities/rude-user.yml
    - "You are in a hurry and want your order processed as fast as possible."
  goals:
    - "Order a {{pizza_type}} pizza with {{size}} size."
    - "Add {{toppings}} as extra toppings."
    - "Order {{number_of_drinks}} {{drink_type}} to drink."
    - "Specify delivery to {{delivery_time}}."

    - pizza_type:
        function: pairwise()
        type: string
        data: [Margherita, Pepperoni, Vegetarian, BBQ Chicken]

    - size:
        function: pairwise()
        type: string
        data: [small, medium, large]

    - toppings:
        function: forward()
        type: string
        data: [extra cheese, mushrooms, olives]

    - number_of_drinks:
        function: forward()
        type: int
        data:
          min: 1
          max: 3
          step: 1

    - drink_type:
        function: random()
        type: string
        data: [Coke, Sprite, Water]

    - delivery_time:
        function: random()
        type: string
        data: [ASAP, in 30 minutes, in 1 hour]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't get that. Please be quick and clear."
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered"
    - size:
        type: string
        description: "The size of the pizza"
    - toppings:
        type: list[string]
        description: "List of extra toppings added"
    - number_of_drinks:
        type: int
        description: "Number of drinks ordered"
    - drink_type:
        type: string
        description: "Type of drink ordered"
    - delivery_time:
        type: string
        description: "Requested delivery time"

conversation:
  number: combinations(pairwise)
  goal_style:
    steps: 6
  interaction_style:
    - single questions
```

This profile sets a rude user persona, uses pairwise coverage for `pizza_type` and `size` (which will define the conversation count), and includes other variables with forward or random functions. The conversation style is quick and to the point with single questions. Let me know if you'd like it adjusted! 😊
