Thanks for sharing your rule! I see a few issues to fix for it to work properly with Sensei-check:

1. The `conversations: 2` means it expects two conversations, but your rule only refers to `conv[0]`. For a single conversation check, use `conversations: 1`.
2. The `when` clause is a filter, but you are using it to check the price equals 50. Instead, use `when` to filter conversations where `tune_up_price` is not None.
3. The `if`/`then` structure expects boolean expressions, but your `then` is a string message, which is not valid.
4. To check the price equals 50, you should parse the price as a number (using `extract_float`) and compare it to 50.
5. The `yields` field can be used to provide a message on failure.

Here's a corrected version of your rule:

```yaml
name: check_tune_up_price
description: Checks if the tune-up price is equal to $50.
conversations: 1
when: conv[0].tune_up_price is not None
oracle: extract_float(conv[0].tune_up_price) == 50
yields: f"Tune-up price is not $50, got {conv[0].tune_up_price}"
```

**What I changed:**

- Changed `conversations` to 1 because it's a single conversation check.
- Replaced `when` to filter conversations with a non-null `tune_up_price`.
- Used `oracle` with a boolean expression to check the price equals 50.
- Added `yields` to provide a helpful message if the check fails.
- Used `extract_float` to parse the price from the string.
