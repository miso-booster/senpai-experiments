¡Claro! Te preparo un perfil Sensei para simular un usuario que busca soporte sobre el CAU de la UAM, solicitando específicamente número de teléfono, email, dirección física y horarios. Este perfil incluirá variables y objetivos claros, y definirá la extracción de esos datos en `chatbot.output` para que luego puedas crear reglas que validen esos campos.

Aquí tienes un perfil básico listo para usar:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres un usuario que necesita soporte sobre el Centro de Atención a Usuarios (CAU) de la UAM.
    Quieres obtener información clara y precisa sobre el número de teléfono, correo electrónico,
    dirección física y horarios de atención del CAU.
  context:
    - "Busco ayuda para contactar con el CAU de la Universidad Autónoma de Madrid."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Me puedes dar el correo electrónico para contactar con el CAU?"
    - "¿Dónde está ubicada la oficina física del CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: false
  fallback: "Lo siento, no entendí tu pregunta. ¿Podrías reformularla o consultar el catálogo de servicios?"
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```

Este perfil simula un usuario que hace preguntas específicas para obtener los datos de contacto del CAU. Los campos en `chatbot.output` son los que luego podrás usar en reglas para validar que el chatbot responde correctamente con esa información.
