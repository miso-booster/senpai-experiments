- The assistant’s replies are in `chatbot_phrases` (a list of strings).
- The rule checks that if lactose-free products are requested, the assistant mentions availability (e.g., “available”, “in stock”, “we have lactose-free”, etc.).

```yaml
name: lactose_free_availability_check
description: Checks that if lactose-free products are requested, the assistant confirms their availability.
conversations: 1
when: lactose_free_requested is True
oracle: >

    phrase.lower().find('lactose-free') >= 0 and

```

- `when:` filters conversations where lactose-free products were requested.
- `oracle:` scans assistant phrases to find mentions of lactose-free AND some availability keywords.
- If none found, the rule fails with the message.
