Got it! Here's a Sensei-check rule that verifies the chatbot outputs include all the necessary CAU contact information fields: phone number, email, and physical address. It checks that none of these fields are empty or missing.

```yaml
name: cau_contact_info_complete
description: The chatbot provides complete CAU contact information (email, phone, physical address)
conversations: 1
active: true
oracle: |
  conv[0].contact_email is not None and conv[0].contact_email != "" and
  conv[0].contact_phone is not None and conv[0].contact_phone != "" and
  conv[0].physical_address is not None and conv[0].physical_address != ""
yields: |
  f"Missing CAU contact info: email={conv[0].contact_email}, phone={conv[0].contact_phone}, address={conv[0].physical_address}"
```

This rule applies to single conversations (`conversations: 1`) and ensures all three fields are present and non-empty. If any field is missing or empty, it will report which ones are problematic.
