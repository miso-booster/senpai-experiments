¡Claro! 😊 Para crear una regla que verifique que el chatbot ha devuelto una lista de juguetes eco-friendly durante la conversación, necesitamos asumir que tu perfil SENSEI Chat expone un campo llamado `eco_friendly_toys` en `chatbot.output`. Este campo debería ser una lista (por ejemplo, lista de strings con nombres de juguetes).

Aquí te dejo un ejemplo de regla para una sola conversación que comprueba que:

- El campo `eco_friendly_toys` existe y no está vacío.
- Opcionalmente, que sea una lista (si quieres ser estricto).

```yaml
name: eco_friendly_toys_presence
description: Comprueba que la lista de juguetes eco-friendly se devuelve y no está vacía
conversations: 1
oracle: eco_friendly_toys is not None and len(eco_friendly_toys) > 0
```

Si quieres ser más estricto y asegurarte que `eco_friendly_toys` es una lista de strings, podríamos hacer algo así (aunque la sintaxis exacta para tipos puede ser limitada):

```yaml
name: eco_friendly_toys_valid_list
description: Comprueba que eco_friendly_toys es una lista no vacía de strings
conversations: 1
oracle: eco_friendly_toys is not None and len(eco_friendly_toys) > 0 and all(isinstance(item, str) for item in eco_friendly_toys)
```

Pero ten en cuenta que Sensei-check evalúa expresiones en un entorno restringido, así que la primera versión es más segura.
