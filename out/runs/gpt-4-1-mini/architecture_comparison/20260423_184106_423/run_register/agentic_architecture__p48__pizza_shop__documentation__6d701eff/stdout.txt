I checked the profiles documentation in `sensei-chat-guide.md`. Here's what I found about mandatory vs optional fields in a profile:

### Mandatory fields in a profile
- `test_name`: The name of the test (string).
- `user.language`: The language of the simulated user.
- `user.role`: A prompt describing the simulated user.
- `user.goals`: A list of goals with optional variables.
- `chatbot.is_starter`: Boolean indicating if the chatbot starts the conversation.
- `chatbot.fallback`: The fallback message of the bot.
- `chatbot.output`: Defines the fields to extract after the conversation.
- `conversation.number`: Number of conversations or combinations to run.
- `conversation.goal_style`: How/when a conversation ends (e.g., fixed steps).
- `conversation.interaction_style`: Interaction style(s) for the user simulator.

### Optional fields
- `llm`: Language model settings (temperature, model, format). If omitted, defaults apply.
- `user.context`: Optional context or personalities to add to the user prompt.
- `conversation.max_cost`: Optional cap on total spend for the run.
- `conversation.goal_style.max_cost`: Optional per-conversation cost cap.
- `conversation.goal_style.all_answered`: Optional stopping logic with export and limit.
- `llm.format.config`: Only if `format.type` is `speech`.
- Custom types in `user.goals` and `chatbot.output` can be used but are not mandatory.
- `user.goals` variables can have optional `function`, `type`, and `data` fields depending on complexity.

### Summary
The core required fields are `test_name`, `user.language`, `user.role`, `user.goals`, `chatbot.is_starter`, `chatbot.fallback`, `chatbot.output`, and conversation controls (`number`, `goal_style`, `interaction_style`). Other fields like `llm`, `user.context`, and cost limits are optional and used to fine-tune behavior.
