Hey there! 😊 Let's talk about the `pairwise()` function in Sensei Profiles — it's a super handy way to efficiently cover combinations of variables in your user simulation goals.

---

### What is `pairwise()`?

`pairwise()` is a function you can assign to variables in your profile's `user.goals` section. It generates test cases that cover **every possible pair of values** between two or more variables at least once — but without exploding into every full combination (which can get huge!).

---

### Why use `pairwise()`?

Imagine you have three variables:

- `pizza_size`: [small, medium, large]
- `drink_type`: [cola, juice, water]
- `toppings`: [cheese, pepperoni, mushrooms]

If you did a full Cartesian product, you'd get 3 × 3 × 3 = 27 combinations.

With `pairwise()`, you get a smaller set of conversations that still covers every pair of values between any two variables. So every pair like `(small, cola)`, `(medium, mushrooms)`, `(pepperoni, water)`, etc., appears at least once — but you don't have to test all 27 combos.

---

### How to use it?

In your profile YAML, you declare variables like this:

```yaml
goals:
  - "Order a {{pizza_size}} pizza with {{drink_type}} and {{toppings}}"
  - pizza_size:
      function: pairwise()
      type: string
      data: [small, medium, large]
  - drink_type:
      function: pairwise()
      type: string
      data: [cola, juice, water]
  - toppings:
      function: pairwise()
      type: string
      data: [cheese, pepperoni, mushrooms]
```

Sensei will generate a set of conversations that efficiently covers all pairs of these variables.

---

### A quick analogy

Think of `pairwise()` like testing every pair of shoes and socks you own, but not every possible outfit combination. You want to make sure every shoe-sock pair works well, but you don't need to try every shirt and hat combo.

---

### Important notes

- You need **at least two variables** using `pairwise()` for it to work.
- It’s great for reducing test cases while still catching most interaction bugs.
- You can combine `pairwise()` with other functions like `forward()` for nested iteration.
