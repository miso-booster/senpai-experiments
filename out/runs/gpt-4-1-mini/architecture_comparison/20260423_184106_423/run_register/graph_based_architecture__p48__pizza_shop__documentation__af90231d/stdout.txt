Hey! Great question 😊 When it comes to SENSEI Profiles, some fields are essential, while others are optional depending on your use case.

Here’s a quick rundown of fields that are **not mandatory** in a profile YAML:

- **`llm` section:**  
  - You can omit this if you want to use default LLM settings (model, temperature, format defaulting to text).  
  - Only add it if you want to override defaults or use speech mode.

- **`user.context`:**  
  - This is optional. It’s used for adding personality snippets or extra context for the simulated user but can be left out.

- **`chatbot.is_starter`:**  
  - Optional boolean indicating if the bot starts the conversation. Defaults apply if omitted.

- **`chatbot.fallback`:**  
  - Optional fallback message for the bot’s default reply when it doesn’t understand. Helpful but not strictly required.

- **`conversation.max_cost`:**  
  - Optional cost cap for the whole run.

- **`conversation.goal_style.max_cost`:**  
  - Optional per-conversation cost cap.

- **`conversation.interaction_style`:**  
  - Optional. You can leave it out if you want default interaction behavior.

- **`conversation.number`:**  
  - You can specify a fixed number or combinations, but it’s optional if you want to run a default number of conversations.

- **`chatbot.output`:**  
  - Technically optional, but if you want to write Sensei-check rules that inspect outputs, you should define this section. Without it, rules won’t have fields to reference.

---

### Summary

The **only truly mandatory fields** are those that define the **user goals** (`user.goals`) and enough info to run the simulation (like `test_name`). Everything else is optional or has defaults.

If you want to write rules later, defining `chatbot.output` is strongly recommended to expose the fields your rules will check.
