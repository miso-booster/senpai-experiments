Hey! I see the rule you shared is missing the `if:` condition, which is important in metamorphic rules when you want to express an implication like "if more toppings, then price is higher."

Your current rule has a `when:` filter but no `if:` to specify the input difference (more toppings), so the `then:` condition applies unconditionally to all pairs that match the `when:` filter, which is probably not what you want.

Here's the fixed version with the missing `if:` condition added to check that `conv[0]` has more toppings than `conv[1]`:

```yaml
name: more_toppings_cost_more
description: Adding more toppings to a custom pizza costs more
active: true
conversations: 2
when: conv[0].size == conv[1].size and conv[0].drink == conv[1].drink
if: len(conv[0].toppings) > len(conv[1].toppings)
then: extract_float(conv[0].price) > extract_float(conv[1].price)
```

This way, the rule only applies when the first conversation has strictly more toppings than the second, and then it asserts the price should be higher.
