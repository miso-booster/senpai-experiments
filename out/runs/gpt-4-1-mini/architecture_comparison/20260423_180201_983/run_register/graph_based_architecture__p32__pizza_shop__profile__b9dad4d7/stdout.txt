¡Claro! 😊 Aquí tienes un perfil Sensei básico para probar un chatbot de pizzería que extrae el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares. 

```yaml
test_name: "pizza_order_basic_test"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres un cliente que quiere ordenar una pizza y una bebida en una pizzería.
    Pregunta sobre las opciones disponibles y realiza el pedido.
  context:
    - "Quieres una pizza deliciosa y una bebida para acompañar."
  goals:
    - "Quiero ordenar una pizza {{pizza_type}}."
    - "También quiero una bebida {{drink_type}}."
    - pizza_type:
        function: forward()
        type: string
        data: [Margarita, Pepperoni, Hawaiana, Vegetariana]
    - drink_type:
        function: forward()
        type: string
        data: [Coca-Cola, Sprite, Agua, Fanta]

chatbot:
  is_starter: false
  fallback: "Disculpa, no entendí tu pedido. ¿Podrías repetirlo, por favor?"
  output:
    - pizza_type:
        type: string
        description: "El tipo de pizza ordenada por el cliente."
    - drink_type:
        type: string
        description: "La bebida ordenada por el cliente."
    - order_id:
        type: string
        description: "El identificador único del pedido."
    - total_price:
        type: money
        description: "El precio final del pedido en dólares."

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

Este perfil simula a un usuario que ordena una pizza y una bebida, y al final extrae los datos clave para validar en las reglas.
