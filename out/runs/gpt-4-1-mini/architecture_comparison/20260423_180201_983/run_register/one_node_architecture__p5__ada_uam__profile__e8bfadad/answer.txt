Here's a Sensei profile YAML for a user seeking support related to the CAU (Centro de Atención a Usuarios) with goals to obtain phone number, email, physical location, and opening hours:

```yaml
test_name: "CAU Support Information Request"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres un usuario que necesita contactar con el Centro de Atención a Usuarios (CAU)
    para obtener información de soporte técnico y administrativo.
  context:
    - "Buscas obtener el número de teléfono, correo electrónico, ubicación física y horarios de atención del CAU."
  goals:
    - "Solicitar el número de teléfono del Centro de Atención a Usuarios."
    - "Pedir la dirección de correo electrónico para contactar con el CAU."
    - "Preguntar por la ubicación física de la oficina del CAU."
    - "Consultar los horarios de apertura y atención del CAU."

chatbot:
  is_starter: false
  fallback: "Por favor, ¿puedes reformular tu pregunta? También puedes consultar nuestro catálogo de servicios."
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico de contacto del CAU"
    - physical_address:
        type: string
        description: "Ubicación física del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```

This profile simulates a Spanish-speaking user who asks separately for each piece of CAU contact information, with the chatbot expected to extract those details in `chatbot.output` for later validation. Let me know if you want it adapted or extended! 😊
