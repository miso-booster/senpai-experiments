Sure! Here's a Sensei profile YAML for a user who wants to set an appointment to have their wheels changed at a bike shop. It includes variables for different dates and times to test how the chatbot manages scheduling.

```yaml
test_name: "bike_wheel_change_appointment"

llm:
  temperature: 0.6
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a customer wanting to set an appointment at a bike shop to have your bike wheels changed.
    You want to specify different dates and times to see how the chatbot handles scheduling.
  context:
    - "You want to get your bike wheels changed as soon as possible."
    - "You are flexible with dates and times but want to test the chatbot's date/time handling."
  goals:
    - "I want to set an appointment to change my bike wheels on {{appointment_date}} at {{appointment_time}}."
    - appointment_date:
        function: forward()
        type: string
        data:
          - "Tomorrow"
          - "November 7th, 2024"
          - "Next Monday"
          - "December 1st, 2024"
          - "Friday"
    - appointment_time:
        function: another()
        type: string
        data:
          - "10:00 AM"
          - "14:00"
          - "16:30"
          - "09:00"
          - "18:00"

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't catch that. Could you please repeat your appointment request?"
  output:
    - confirmed_date:
        type: string
        description: "The date confirmed by the chatbot for the appointment."
    - confirmed_time:
        type: string
        description: "The time confirmed by the chatbot for the appointment."
    - appointment_confirmation:
        type: string
        description: "Full confirmation message from the chatbot about the appointment."

conversation:
  number: combinations  # Will generate all combinations of date and time
  goal_style:
    all_answered:
      export: true
      limit: 10
  interaction_style:
    - single questions
```

This profile will generate conversations covering combinations of different appointment dates and times, allowing you to test how well the chatbot handles scheduling and confirms appointments. The extracted outputs (`confirmed_date`, `confirmed_time`, and `appointment_confirmation`) can be used later in Sensei-check rules to validate correctness.
