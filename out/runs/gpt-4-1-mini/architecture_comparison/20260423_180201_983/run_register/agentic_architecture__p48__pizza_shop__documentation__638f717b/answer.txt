In a Sensei profile, the following fields are generally **not mandatory** (optional):

- `llm`: This section is optional. If omitted, defaults are applied (e.g., default model and temperature, and text format). You only need to add it if you want to override defaults or use speech mode.
- `user.context`: This is optional and can include personalities or freeform constraints/preferences.
- `conversation.max_cost`: Optional cap on the total spend for the whole run.
- `goal_style.max_cost`: Optional cap on per-conversation spend.
- `conversation.number`: Can be a fixed integer or combinations, but you can choose what fits your test.
- `interaction_style`: Optional; you can choose one or many styles or none.
- `personalities` referenced in `user.context` are optional.
- Custom types in `types/` are optional unless you need them.
- `chatbot.output` fields are optional in the sense that you can define as many or as few as you want, but if you want to extract or validate something, you must define it here.

The **mandatory** top-level fields are typically:

- `test_name`: to identify the profile.
- `user.language` and `user.role`: to define the simulated user.
- `user.goals`: at least one goal with variables declared.
- `chatbot.is_starter`: to indicate who starts the conversation.
- `chatbot.fallback`: a fallback message for the bot.

This is based on the profile structure and examples in the Sensei profiles documentation (`sensei-chat-guide.md`).
