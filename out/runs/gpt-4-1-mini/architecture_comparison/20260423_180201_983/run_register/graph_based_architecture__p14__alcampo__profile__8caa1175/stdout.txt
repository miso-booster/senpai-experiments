¡Claro! Para crear un perfil Sensei que pruebe la capacidad del chatbot de Alcampo para recomendar recetas y planificación de menús, podemos basarnos en el perfil existente llamado **"recipe_management_and_cooking_support"** que ya está orientado a la gestión de recetas y soporte para cocinar.

Te puedo ayudar a crear un perfil YAML personalizado para ese propósito, o bien adaptar el perfil existente para que se enfoque en probar recomendaciones de recetas y planificación de menús.

Aquí te dejo un ejemplo de perfil Sensei para ese caso, basado en la estructura estándar y el perfil de recetas:

```yaml
test_name: "recipe_recommendation_and_menu_planning"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a user looking for recipe recommendations and menu planning assistance.
    You want to find recipes based on seasonal ingredients, dietary preferences,
    and cooking time. You also want help organizing meals for the week.
  context:
    - personality: personalities/conversational-user.yml
    - "You prefer quick and healthy meals."
    - "You want to plan a weekly menu with breakfast, lunch, and dinner."
  goals:
    - "Ask for recipe recommendations using seasonal ingredients."
    - "Request suggestions for quick and healthy meals."
    - "Inquire about how to plan a weekly menu with balanced nutrition."
    - "Ask how to add recipe ingredients to a shopping list."
    - "Request tips for meal prepping and cooking efficiently."
  
chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand that. Could you please rephrase your request about recipes or menu planning?"
  output:
    - recommended_recipes:
        type: string
        description: "List of recommended recipes based on user preferences"
    - menu_plan:
        type: string
        description: "Suggested weekly menu plan with meals organized"
    - shopping_list_instructions:
        type: string
        description: "Instructions on how to add recipe ingredients to a shopping list"
    - meal_prep_tips:
        type: string
        description: "Tips for meal prepping and efficient cooking"

conversation:
  number: 3
  goal_style:
    steps: 20
  interaction_style:
    - single questions
```

---

### Explicación rápida:

- **user.role** define el tipo de usuario y sus necesidades (recetas, planificación).
- **user.goals** son las preguntas o solicitudes que el usuario hará al chatbot.
- **chatbot.output** define qué información queremos extraer y validar tras la conversación.
- **conversation.number** y **goal_style.steps** controlan la cantidad y duración de las pruebas.
- **interaction_style** con "single questions" para que el usuario haga preguntas claras y separadas.

Si quieres, puedo ayudarte a personalizarlo más, añadir variables, funciones para generar combinaciones, o integrarlo con reglas Sensei para validar respuestas. ¿Quieres que te ayude con eso? 😊
