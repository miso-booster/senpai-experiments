Absolutely! To ensure your chatbot responds in the same language as the user, you can create a **Sensei-check metamorphic rule** that compares the language of the chatbot's replies to the user's language.

Here's a simple and effective example rule that checks this consistency across two conversations with the same input conditions:

```yaml
name: language_consistency
description: Ensure chatbot replies in the same language as the user
conversations: 2
when: conv[0].input_language == conv[1].input_language
oracle: responds_in_same_language() is True
```

### Explanation:
- `conversations: 2` means the rule compares pairs of conversations.
- `when:` filters pairs where the user input language is the same (you can adapt `input_language` to your actual profile's field).
- `oracle:` uses the built-in helper `responds_in_same_language()` which returns `True` if the assistant's replies match the user's language.

---

If your profile does not explicitly expose `input_language`, you might want to adjust the `when:` condition or omit it for a global check.

If you want a simpler single-conversation check (just verifying each conversation individually), you can do:

```yaml
name: language_match_single
description: Chatbot replies in the same language as the user (single conversation)
conversations: 1
oracle: responds_in_same_language() is True
```
