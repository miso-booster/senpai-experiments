### Problemas detectados y correcciones aplicadas

1. **Falta el campo `user.role`**  
   - En tu versión original no estaba definido el campo `user.role`.  
   - Lo agregué con un texto descriptivo para que el simulador entienda el rol del usuario (importante para el contexto).

2. **Contexto mal estructurado**  
   - En tu versión original, el contexto tenía líneas sin comillas y una línea con indentación incorrecta para el tipo de dato.  
   - Lo corregí para que cada línea sea un string válido YAML.  
   - También agregué la referencia a una personalidad (`personality: personalities/curious-user`) como ejemplo, que es una práctica recomendada.

3. **Variables en goals mal definidas**  
   - En tu versión original, las variables `identificador_id_uam` y `user_account` estaban mal definidas (falta `function: forward()` y estructura correcta).  
   - Las corregí para que usen `function: forward()`, que es la forma recomendada para iterar sobre datos en Sensei.

4. **Duplicación de campos en `chatbot.output`**  
   - Tenías dos campos similares: `contact_info` y `contact_information`.  
   - Esto puede causar confusión.  
   - Te recomiendo unificar o aclarar bien su uso. Por ahora los dejé tal cual, pero si quieres puedo ayudarte a unificarlos.

5. **Conversación: agregué `max_cost` y `interaction_style`**  
   - Añadí `max_cost` para limitar el gasto total, que es buena práctica.  
   - Definí `interaction_style` para que el usuario haga preguntas individuales, acorde a tus metas.
