¡Claro! Aquí tienes una regla para Sensei-check que verifica que el chatbot haya devuelto una lista no vacía en el campo `eco_friendly_toys` del `chatbot.output`. Esta regla asume que el perfil expone ese campo como una lista o string representando la lista.

```yaml
name: eco_friendly_toys_returned
description: The chatbot returns a non-empty list of eco-friendly toys
conversations: 1
active: true
oracle: eco_friendly_toys is not None and len(eco_friendly_toys) > 0
yields: "The chatbot did not return any eco-friendly toys in the output."
```

Si `eco_friendly_toys` es una lista, esta regla comprobará que no esté vacía. Si es un string con una lista en texto, podríamos necesitar un helper para validar que no sea vacío o contenga algo significativo.
