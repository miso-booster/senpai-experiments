Here’s a version of your rule that works with Sensei-check syntax and your profile outputs. Since `user_request` isn’t part of the profile, I removed the `when` clause. Also, the `then` field must be a string expression, so I replaced it with a simple `then: True` (as a string):

```yaml
name: customer_service_contact_info
description: Ensure the chatbot provides correct contact options and information for customer service inquiries.
active: true
conversations: 2
if: conv[0].contact_options is not None and conv[0].contact_options != '' and conv[1].customer_service_number is not None and conv[1].customer_service_number != ''
then: "True"
```

This rule checks that in two conversations, the first has non-empty `contact_options` and the second has non-empty `customer_service_number`.

If you want to filter conversations by user request or intent, you would need to add such a field to your profile’s outputs first.
