¡Claro! Te preparo un perfil SENSEI para simular un usuario que busca recomendaciones de recetas y planificación de menús en el chatbot de Alcampo. Este perfil incluirá variables para distintos tipos de recetas, preferencias y objetivos, y definirá salidas para validar la información extraída.

Aquí tienes un ejemplo de perfil YAML para eso:

```yaml
test_name: "recipe_and_menu_planning"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a user interested in getting recipe recommendations and planning weekly menus.
    You want suggestions for recipes based on meal type, dietary preferences, and seasonal ingredients.
    You also want help organizing meals for the week efficiently.
  context:
    - personality: personalities/conversational-user.yml
    - "You prefer healthy and balanced meals."
    - "You want to explore new recipes and cooking tips."
  goals:
    - "Recommend a {{meal_type}} recipe using {{main_ingredient}}."
    - "Suggest a weekly menu plan including {{number_of_meals}} meals."
    - "Provide cooking tips for {{cuisine_type}} cuisine."
    - meal_type:
        function: forward()
        type: string
        data: [breakfast, lunch, dinner, snack]
    - main_ingredient:
        function: random()
        type: string
        data: [chicken, fish, tofu, vegetables, beef]
    - number_of_meals:
        function: random()
        type: int
        data: [3, 5, 7]
    - cuisine_type:
        function: random()
        type: string
        data: [Mediterranean, Asian, Mexican, Italian, French]

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand your request about recipes or menu planning. Can you please rephrase?"
  output:
    - recommended_recipe:
        type: string
        description: "Name or description of the recommended recipe"
    - weekly_menu_plan:
        type: string
        description: "Suggested weekly menu plan details"
    - cooking_tips:
        type: string
        description: "Cooking tips related to the requested cuisine"
    - recipe_ingredients:
        type: list[string]
        description: "List of ingredients for the recommended recipe"
    - preparation_time:
        type: string
        description: "Estimated preparation time for the recipe"

conversation:
  number: 3
  goal_style:
    steps: 20
  interaction_style:
    - single questions
```

Este perfil simula un usuario que pide recomendaciones de recetas y planificación de menús, con variables para tipos de comida, ingredientes, número de comidas y tipo de cocina. El `chatbot.output` define campos que luego podrían usarse en reglas para validar que el chatbot responde con recetas, ingredientes y consejos adecuados.
