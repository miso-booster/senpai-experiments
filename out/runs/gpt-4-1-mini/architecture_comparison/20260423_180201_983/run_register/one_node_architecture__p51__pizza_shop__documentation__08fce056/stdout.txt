Hey! Connectors in Sensei are used to connect your testing framework to an actual chatbot API. They let Sensei send user messages to the chatbot and receive responses, all without writing code—just by configuring a YAML file. This way, you can test any chatbot by describing how to talk to its API.

### What connectors are for:
- Define how to send user messages to your chatbot API.
- Specify HTTP method, headers, and payload format.
- Extract the chatbot’s reply from the API response.
- Enable Sensei to interact with your chatbot seamlessly during tests.

---

### Key fields in a connector YAML:

```yaml
name: "Friendly Bot Name"          # Optional, just a label for your chatbot
base_url: "https://api.chatbot.com"  # The base URL of the chatbot API

send_message:
  path: "/chat/send"               # API endpoint path appended to base_url
  method: "POST"                  # HTTP method (POST, GET, etc.), default is POST
  headers:                        # Optional HTTP headers (e.g., Authorization, Content-Type)
    Authorization: "Bearer token"
    Content-Type: "application/json"
  payload_template:               # JSON structure with a placeholder for user message
    message: "{user_msg}"         # {user_msg} is replaced by the actual user input

response_path: "response.text"    # Dot-separated path to extract chatbot reply from JSON response
```

---

### How it works:

- When Sensei sends a message, it fills `{user_msg}` in `payload_template`.
- It sends the request to `base_url + path` with the specified method and headers.
- It parses the JSON response, following `response_path` to get the chatbot’s reply text.
