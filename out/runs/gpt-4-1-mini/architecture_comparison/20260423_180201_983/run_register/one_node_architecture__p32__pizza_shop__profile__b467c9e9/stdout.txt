¡Claro! Aquí tienes un perfil sencillo para probar un chatbot de pizzería que simula un usuario haciendo un pedido. El perfil incluye variables para tipo de pizza y bebida, y define el `chatbot.output` con los campos que necesitas: tipo de pizza, bebida, ID del pedido y precio final en dólares.

```yaml
test_name: "pizza_order_basic_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a customer ordering a pizza from a pizzeria.
    You want to order a pizza and a drink.
  context:
    - "You want a quick and simple order."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Order a {{drink}} to drink."
    - pizza_type:
        function: forward()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian, BBQ Chicken]
    - drink:
        function: forward()
        type: string
        data: [Coke, Sprite, Water, Fanta]

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand that. Could you please repeat your order?"
  output:
    - pizza_type:
        type: string
        description: "Type of pizza ordered"
    - drink:
        type: string
        description: "Type of drink ordered"
    - order_id:
        type: string
        description: "Unique order identifier"
    - final_price:
        type: money
        description: "Final price of the order in USD"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```
