Hey! Great question 😊 In the context of **SENSEI RULES** (specifically Sensei-check), an **oracle** is basically a condition or a test that checks whether a chatbot’s behavior or output is correct.

Think of it like a "truth test" or a "rule" that says: *Given this conversation (or set of conversations), the chatbot’s responses should satisfy this condition.* If the condition is true, the chatbot passes the test; if not, it fails.

---

### More specifically:

- In **Sensei-check**, an oracle is a **boolean expression** written in a small domain-specific language (DSL) that evaluates fields extracted from chatbot conversations.
- It can be applied to **one conversation** (traditional oracle) or to **multiple conversations** (metamorphic testing).
- The oracle uses fields from the profile’s `chatbot.output` (like `price`, `order_id`, `size`, etc.) and helper functions (like `extract_float()`, `language()`, etc.) to verify correctness.

---

### Example of a simple oracle (single conversation):

```yaml
oracle: extract_float(price) >= 10 and currency(price) == 'USD'
```

This checks that the price extracted from the chatbot’s output is at least $10 and the currency is USD.

---

### Example of a metamorphic oracle (comparing two conversations):

```yaml
if: len(conv[0].toppings) > len(conv[1].toppings)
then: extract_float(conv[0].price) > extract_float(conv[1].price)
```

This says: *If conversation 0 has more toppings than conversation 1, then the price in conversation 0 should be higher.*

---

### TL;DR

An **oracle** is a rule or condition that tells you if the chatbot’s output is correct or consistent, helping you automatically verify chatbot behavior across many conversations.
