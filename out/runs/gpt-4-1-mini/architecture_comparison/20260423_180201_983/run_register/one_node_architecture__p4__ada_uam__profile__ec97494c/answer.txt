¡Claro! Te preparo un perfil Sensei para simular un usuario que busca soporte sobre el CAU (Centro de Atención a Usuarios) de la UAM, y que extrae específicamente el número de teléfono, email, dirección física y horarios del servicio.

Aquí tienes un perfil básico que puedes ajustar según tus necesidades:

```yaml
test_name: "Soporte CAU UAM"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres un usuario que necesita soporte del Centro de Atención a Usuarios (CAU) de la UAM.
    Quieres obtener información clara y precisa sobre el número de teléfono, correo electrónico,
    dirección física y horarios de atención del CAU.
  context:
    - "Necesito contactar con el CAU para resolver dudas técnicas y administrativas."
    - "Busco los datos de contacto oficiales para comunicarme con ellos."
  goals:
    - "¿Cuál es el número de teléfono del Centro de Atención a Usuarios de la UAM?"
    - "¿Me puedes proporcionar el correo electrónico para contactar con el CAU?"
    - "¿Dónde está ubicada físicamente la oficina del CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: false
  fallback: "Lo siento, no entendí tu pregunta. ¿Puedes reformularla o consultar el catálogo de servicios?"
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```

Este perfil:

- Define un usuario que pregunta específicamente por los datos de contacto del CAU.
- Extrae en `chatbot.output` los campos que quieres validar: teléfono, email, dirección y horarios.
- Ejecuta 3 conversaciones con hasta 10 pasos cada una, usando preguntas simples.
