¡Claro! 😊 Para crear una regla que compruebe que el chatbot ha devuelto una lista de juguetes eco-friendly durante la conversación, necesitamos asumir que el perfil SENSEI Chat tiene un campo llamado `eco_friendly_toys` en `chatbot.output`. Este campo debería ser una lista (por ejemplo, lista de nombres de juguetes).

Aquí tienes un ejemplo de regla Sensei-check para verificar que esa lista no esté vacía (es decir, que el chatbot haya devuelto al menos un juguete eco-friendly):

```yaml
name: eco_friendly_toys_returned
description: Comprueba que el chatbot devuelve una lista no vacía de juguetes eco-friendly
conversations: 1
oracle: eco_friendly_toys is not None and len(eco_friendly_toys) > 0
```

---

### Explicación rápida:

- `conversations: 1` porque esta regla se aplica a cada conversación individual.
- `eco_friendly_toys` es el campo esperado en el perfil, que debe ser una lista.
- La condición `eco_friendly_toys is not None and len(eco_friendly_toys) > 0` asegura que el campo existe y contiene al menos un juguete.
