Here is a general global rule (profile-agnostic) to check if the chatbot provides information about current promotions. It uses the helper `chatbot_returns` to detect if the assistant mentions "promotion" or "discount" anywhere in its replies. This rule does not rely on any profile-specific outputs:

```yaml
name: chatbot_mentions_promotions
description: Checks if the chatbot provides information about current promotions or discounts
conversations: 1
oracle: chatbot_returns('promotion') or chatbot_returns('discount')
on-error: "The chatbot did not mention any promotions or discounts in the conversation."
```

- This rule runs on single conversations (`conversations: 1`).
- It uses `chatbot_returns` to search for keywords in the assistant's utterances.
- It is a global rule, so it does not depend on any profile or extracted slots.
