Got it! Here's a Sensei profile YAML for an Erasmus user new to the university systems, asking for help setting up Moodle, Sigma, and related platforms. It keeps input variables minimal but defines several chatbot output fields to capture the key support info you want to validate with rules later.

```yaml
test_name: "Erasmus_User_Onboarding_Support"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are an Erasmus student who just arrived at the university.
    You are unfamiliar with how to set up and access Moodle, Sigma, and other platforms.
    You ask clear but basic questions to get step-by-step help.
  context:
    - "You are new and need guidance on platform setup."
    - "You prefer simple, clear instructions."
  goals:
    - "How do I set up my Moodle account?"
    - "Can you help me access Sigma?"
    - "What do I need to do to start using university platforms?"
    - "Where can I find help for technical issues?"
  # No variables needed for this simple scenario

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand that. Could you please rephrase?"
  output:
    - moodle_setup_instructions:
        type: string
        description: "Instructions provided to set up Moodle account"
    - sigma_access_instructions:
        type: string
        description: "Instructions provided to access Sigma platform"
    - platform_start_guide:
        type: string
        description: "General guidance on starting with university platforms"
    - tech_support_contact:
        type: string
        description: "Contact information for technical support"
    - faq_link:
        type: string
        description: "Link to FAQs or help resources"
    - common_issues:
        type: string
        description: "Common issues and troubleshooting tips mentioned"

conversation:
  number: 3
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```
