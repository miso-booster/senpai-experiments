Hey! 😊 I see you want to create a Sensei-check rule that verifies the bike shop chatbot outputs these specific values:

- Opening and closing time between 10 and 20 (I assume this means the shop opens at 10 and closes at 20)
- Tune-up price is 50
- Seat price is 20
- Tire price is 20

Let's write a **single-conversation** rule that checks these outputs for correctness.

---

Here’s a YAML rule you can use to check those fields in the chatbot output:

```yaml
name: bike_shop_price_and_hours_check
description: Checks that the bike shop opening hours and prices match expected values
conversations: 1
oracle: >
  conv[0].opening_and_closing == '10 to 20' and
  extract_float(conv[0].tune_up) == 50 and
  extract_float(conv[0].seat_price) == 20 and
  extract_float(conv[0].tire) == 20
```

---

### Explanation:

- `conv[0]` refers to the single conversation.
- `opening_and_closing` is checked as a string exactly matching `'10 to 20'` (adjust if your format differs).
- `extract_float()` extracts the numeric value from the price strings (e.g., "20 USD" → 20).
- We compare the prices numerically to the expected values.

---

If your `opening_and_closing` field is formatted differently (e.g., "10:00 - 20:00" or "10am to 8pm"), you might want to adjust the string comparison or use a more flexible check.
