¡Claro! Me encantaría ayudarte a crear un perfil Sensei para testear el chatbot de la UAM con un usuario que busca soporte sobre el CAU, específicamente para obtener el número de teléfono, email, dirección física y horarios.

Aquí te dejo un ejemplo de perfil YAML que cumple con esos requisitos. Está en español, con variables claras para los datos que quieres extraer del chatbot, y con una conversación enfocada en esos objetivos.

```yaml
test_name: "Soporte CAU - Contacto y Horarios"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: Spanish
  role: >
    Eres un usuario que necesita soporte del Centro de Atención a Usuarios (CAU)
    de la Universidad Autónoma de Madrid. Quieres obtener información precisa sobre
    el número de teléfono, correo electrónico, dirección física y horarios de atención.
  context:
    - personality: personalities/formal-user.yml
    - "Busco información clara y detallada para poder contactar con el CAU."
  goals:
    - "¿Cuál es el número de teléfono del CAU?"
    - "¿Me puedes proporcionar el correo electrónico de contacto del CAU?"
    - "¿Dónde se encuentra la dirección física del CAU?"
    - "¿Cuáles son los horarios de atención del CAU?"

chatbot:
  is_starter: false
  fallback: "Disculpa, no entendí tu pregunta. ¿Podrías reformularla o consultar nuestro catálogo de servicios?"
  output:
    - contact_phone:
        type: string
        description: "Número de teléfono del CAU"
    - contact_email:
        type: string
        description: "Correo electrónico de contacto del CAU"
    - physical_address:
        type: string
        description: "Dirección física del CAU"
    - service_hours:
        type: string
        description: "Horarios de atención del CAU"

conversation:
  number: 3
  goal_style:
    steps: 10
  interaction_style:
    - single questions
```

---

### Explicación rápida:

- **user.role** define el perfil del usuario simulando una persona formal que busca soporte.
- **user.goals** contienen las preguntas clave para obtener los datos que quieres extraer.
- **chatbot.output** define los campos que el extractor debe capturar para luego validar con reglas.
- **conversation.number** y **goal_style.steps** controlan la cantidad y duración de las conversaciones.
- **interaction_style: single questions** hace que el usuario pregunte una cosa a la vez, para claridad.
