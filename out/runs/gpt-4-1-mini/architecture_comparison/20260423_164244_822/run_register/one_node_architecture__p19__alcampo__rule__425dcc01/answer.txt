Sure! Here's a global Sensei-check rule that verifies if the chatbot mentions current promotions in its responses. Since it's not profile-bound, it uses a generic helper `only_talks_about` to check if the conversation includes the topic "promotions" or similar keywords:

```yaml
name: chatbot_mentions_current_promotions
description: The chatbot should mention current promotions or offers in its responses
conversations: 1
active: true
oracle: only_talks_about('promotions, offers, discounts, deals')
on-error: "The chatbot did not mention current promotions or related offers."
```

This rule expects the chatbot to talk about promotions, offers, discounts, or deals somewhere in the conversation. If it doesn't, the rule will fail and provide the error message.
