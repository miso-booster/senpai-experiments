I will create a new SENSEI profile YAML that simulates a user asking the chatbot to add items to their shopping cart. The profile will include:

- User language and role describing the shopping context.
- Goals with variables for items to add.
- Chatbot output fields to extract confirmation or cart summary.
- Conversation controls for a few interactions.

Here is the profile YAML:

```yaml
test_name: "shopping_cart_add_items"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a shopper who wants to add items to your online shopping cart.
    Ask the chatbot to add various products with quantities.
  context:
    - "You prefer quality products and occasional discounts."
  goals:
    - "Add {{quantity}} of {{item}} to my shopping cart"
    - quantity:
        function: random(3)
        type: int
        data:
          min: 1
          max: 5
          step: 1
    - item:
        function: random()
        type: string
        data: [\"laptop\", \"headphones\", \"coffee mug\", \"notebook\", \"smartphone case\"]

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand. Could you please repeat?"
  output:
    - last_added_item:
        type: string
        description: "The last item the chatbot confirmed adding to the cart"
    - last_added_quantity:
        type: int
        description: "The quantity of the last item added"
    - cart_total_items:
        type: int
        description: "Total number of items currently in the cart"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - random:
      - long phrases
      - single questions
      - make spelling mistakes
```

This profile will simulate a user adding different quantities of items to their cart, with the chatbot expected to confirm each addition and maintain a cart total count.
