¡Claro! Te preparo un perfil SENSEI para simular un usuario que busca recomendaciones de recetas y planificación de menús en el chatbot de Alcampo. Este perfil incluirá variables para tipos de recetas, ingredientes, y objetivos relacionados con la planificación de menús.

Aquí tienes un perfil YAML listo para usar o adaptar:

```yaml
test_name: "recipe_and_menu_planning"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a user looking for recipe recommendations and menu planning advice.
    You want to find recipes based on ingredients, dietary preferences, and occasions.
    You also want help planning weekly menus with balanced meals.
  context:
    - "You enjoy cooking and want to try new recipes."
    - "You have some dietary restrictions like vegetarian or gluten-free."
    - "You want to plan meals for the week efficiently."
  goals:
    - "Ask for recipe recommendations using {{main_ingredient}}."
    - "Request recipes suitable for a {{dietary_preference}} diet."
    - "Inquire about menu planning tips for {{meal_type}}."
    - "Ask for a weekly menu plan including {{number_of_meals}} meals."
    - main_ingredient:
        function: random()
        type: string
        data: [chicken, salmon, tofu, mushrooms, beef, lentils, potatoes]
    - dietary_preference:
        function: random()
        type: string
        data: [vegetarian, vegan, gluten-free, low-carb, dairy-free, pescatarian]
    - meal_type:
        function: random()
        type: string
        data: [breakfast, lunch, dinner, snacks]
    - number_of_meals:
        function: random()
        type: int
        data: [3, 5, 7]

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand your request about recipes or menus. Could you please rephrase?"
  output:
    - recommended_recipes:
        type: string
        description: "List or description of recommended recipes"
    - menu_plan:
        type: string
        description: "Suggested weekly menu plan"
    - dietary_advice:
        type: string
        description: "Advice related to dietary preferences"
    - cooking_tips:
        type: string
        description: "General cooking or menu planning tips"

conversation:
  number: 5
  goal_style:
    steps: 15
  interaction_style:
    - single questions
```

Este perfil simula un usuario que hace preguntas variadas sobre recetas y planificación de menús, con variables para ingredientes, tipos de dieta, tipo de comida y número de comidas en el plan semanal. Además, define campos en `chatbot.output` para extraer recomendaciones, planes y consejos que luego podrías usar en reglas Sensei-check.
