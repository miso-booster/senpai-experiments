Thanks for sharing your rule! I see a few issues that we can fix to make it work properly with Sensei-check:

1. The rule is a **single-conversation check** (price equality), so `conversations` should be `1`, not `2`.
2. The `when` clause should be a filter expression, but you wrote `conv[0].tune_up_price == 50` which compares a field to a number directly — it’s better to use `extract_float` to parse the price from the string.
3. The `if`/`then` structure expects boolean expressions, but your `then` is a string message instead of a boolean condition.
4. To check equality, you want an `oracle` or an `if`/`then` with boolean expressions.
5. The price is likely a string with currency, so use `extract_float` to get the numeric value.

Here’s a fixed version of your rule:

```yaml
name: check_tune_up_price
description: Checks if the tune-up price is exactly $50.
conversations: 1
when: conv[0].tune_up_price is not None
oracle: extract_float(conv[0].tune_up_price) == 50 and currency(conv[0].tune_up_price) == 'USD'
```

### What I changed:
- Set `conversations: 1` because this is a single-conversation check.
- Moved the price check to `oracle` with a boolean expression.
- Used `extract_float()` to parse the numeric price from the string.
- Added `currency()` check to ensure the price is in USD.
- Used `when` to filter only conversations where `tune_up_price` is present.

This rule will pass only if the extracted tune-up price is exactly 50 USD. Let me know if you want it more flexible (e.g., price ≥ 50) or if you want a message on failure! 😊
