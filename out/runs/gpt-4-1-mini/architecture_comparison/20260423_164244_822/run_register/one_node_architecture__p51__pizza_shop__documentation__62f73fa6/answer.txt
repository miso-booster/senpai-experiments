Hey! Connectors in Sensei are used to connect your testing framework to any chatbot API without writing code. They define how to send user messages to the chatbot and how to extract the chatbot’s replies from the API responses. This way, Sensei can interact with your chatbot automatically during testing.

### Key fields in a connector YAML:

```yaml
name: "Friendly name for your chatbot"          # Optional, just for identification
base_url: "https://api.yourchatbot.com"         # The base URL of your chatbot API

send_message:
  path: "/chat"                                  # API endpoint path appended to base_url
  method: "POST"                                 # HTTP method (default is POST)
  headers:                                       # Optional HTTP headers (e.g., Authorization)
    Content-Type: "application/json"
    Authorization: "Bearer your-api-key"
  payload_template:                              # JSON structure to send, with {user_msg} placeholder
    message: "{user_msg}"
    session_id: "user123"

response_path: "response.text"                   # Dot-separated path to extract bot reply from JSON response
```

---

### What these fields do:

- **name**: A friendly name for your chatbot connector (optional).
- **base_url**: The root URL of your chatbot’s API.
- **send_message.path**: The API endpoint path where messages are sent.
- **send_message.method**: HTTP method like POST, GET, etc. (defaults to POST).
- **send_message.headers**: Any custom headers needed (e.g., API keys).
- **send_message.payload_template**: The JSON payload sent to the API, with `{user_msg}` as a placeholder for the user’s message.
- **response_path**: How to find the chatbot’s reply inside the JSON response, using dot notation (e.g., `"choices.0.message.content"`).

---

This setup lets Sensei send messages and receive replies seamlessly, enabling automated testing of your chatbot.
