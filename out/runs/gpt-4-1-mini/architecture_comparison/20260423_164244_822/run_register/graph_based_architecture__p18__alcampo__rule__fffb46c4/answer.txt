¡Claro! 😊 Para crear una regla que compruebe que el chatbot ha devuelto una lista de juguetes eco-friendly, primero asumimos que tu perfil SENSEI Chat expone un campo llamado `eco_friendly_toys` dentro de `chatbot.output`. Este campo debería ser una lista (por ejemplo, lista de nombres de juguetes).

Aquí te dejo un ejemplo de regla Sensei-check para validar que ese campo existe y no está vacío en la conversación:

```yaml
name: eco_friendly_toys_returned
description: Comprueba que el chatbot devuelve una lista no vacía de juguetes eco-friendly
conversations: 1
oracle: eco_friendly_toys is not None and len(eco_friendly_toys) > 0
```

### Explicación:
- `conversations: 1` porque es una regla de una sola conversación.
- `eco_friendly_toys` debe existir (`is not None`) y contener al menos un elemento (`len(...) > 0`).
- Si quieres que la regla sea más estricta, podríamos incluso verificar que todos los elementos de la lista sean cadenas (strings), o que contengan ciertas palabras clave, pero esto depende de cómo sea el output exacto.
