Here’s a draft Sensei profile you can start with (you can customize names, data, and details):

```yaml
test_name: "new_bike_setup_and_customization"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You recently bought a new bike and want to have it set up to your liking.
    You want to change the seat and the handlebar grips for better comfort and style.
  context:
    - "Your bike is brand new."
    - "You prefer a comfortable seat and grips with good grip and style."
  goals:
    - "I want to change the seat on my bike."
    - "I want to change the handlebar grips."
    - "Ask about the available seat options and their prices."
    - "Ask about the available handlebar grip options and their prices."
    - seat_type:
        function: forward()
        type: string
        data: [gel, leather, foam, racing]
    - grip_type:
        function: forward()
        type: string
        data: [rubber, leather, foam, ergonomic]

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't catch that. Could you please repeat?"
  output:
    - seat_change_confirmation:
        type: string
        description: "Confirmation that the seat change service is available and booked."
    - grip_change_confirmation:
        type: string
        description: "Confirmation that the handlebar grip change service is available and booked."
    - seat_price:
        type: money
        description: "Price of the selected seat type."
    - grip_price:
        type: money
        description: "Price of the selected handlebar grip type."
    - appointment_confirmation:
        type: string
        description: "Confirmation of any scheduled appointment for the customization."

conversation:
  number: 4
  goal_style:
    steps: 6
  interaction_style:
    - single questions
```
