An **oracle** in the context of SENSEI rules (Sensei-check) is a boolean condition that defines the expected correctness or validity of a single conversation or a set of conversations. It is the core check that the rule performs to decide if the chatbot's behavior is correct or not.

More specifically:

- An oracle is a **boolean expression** written in the Sensei-check DSL that evaluates to `True` if the conversation(s) meet the expected condition, or `False` if they violate it.
- It is used in rules that target a single conversation or multiple conversations.
- The oracle can check outputs extracted from the chatbot conversation, such as slot values, prices, languages, or any other structured data defined in the profile's `chatbot.output`.
- If the oracle condition fails, the rule reports an error or failure for that conversation.

For example, a simple oracle rule might check that a pizza price is at least $10:

```yaml
name: small_base_price_floor
description: Small pizzas should cost at least $10
conversations: 1
when: size == 'small'
oracle: extract_float(price) >= 10 and currency(price) == 'USD'
```

Here, the `oracle` is the condition `extract_float(price) >= 10 and currency(price) == 'USD'`. If this condition is true for the conversation, the rule passes; otherwise, it fails.

In summary, the oracle is the **assertion or test condition** inside a rule that defines what "correct" means for the chatbot's output.
