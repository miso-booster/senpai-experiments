Hey there! 😊 The `pairwise()` function in Sensei Profiles is a super handy way to efficiently cover combinations of variables when generating test conversations.

### What does `pairwise()` do?

Imagine you have multiple variables, each with several possible values. Testing **every possible combination** (the full Cartesian product) can explode into a huge number of cases — often way too many to run.

`pairwise()` cleverly reduces this by ensuring that **every possible pair of values across any two variables appears at least once** in the generated conversations. This way, you cover all 2-way interactions without testing every single full combination.

---

### Simple example:

Suppose you have two variables:

- `color`: [red, blue, green]
- `size`: [small, medium, large]

A full Cartesian product would be 3 × 3 = 9 combinations:

| color | size  |
|-------|-------|
| red   | small |
| red   | medium|
| red   | large |
| blue  | small |
| blue  | medium|
| blue  | large |
| green | small |
| green | medium|
| green | large |

But with `pairwise()`, Sensei will generate a smaller set of conversations that still covers **every pair** of color and size values at least once, for example:

| color | size  |
|-------|-------|
| red   | small |
| blue  | medium|
| green | large |

This smaller set ensures that every color-size pair is tested somewhere, but you avoid running all 9.

---

### Why use `pairwise()`?

- **Efficiency:** Greatly reduces test cases while still catching most bugs related to variable interactions.
- **Coverage:** Ensures all pairs of variable values are tested.
- **Scalability:** Works well when you have many variables with many values.

---

### How to use it in a profile?

You declare it in your `user.goals` variables like this:

```yaml
goals:
  - "Order a {{color}} shirt in {{size}}"
  - color:
      function: pairwise()
      type: string
      data: [red, blue, green]
  - size:
      function: pairwise()
      type: string
      data: [small, medium, large]
```

Sensei will then generate conversations covering all pairs of colors and sizes.

---

### A quick tip:

- You need **at least two variables** using `pairwise()` for it to work.
- You can combine `pairwise()` with other functions like `forward()` for nested iteration.
- `pairwise()` is perfect when full combinations are too big but you want good interaction coverage.
