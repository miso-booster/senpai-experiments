Hey! Great question 😊 The `pairwise()` function in Sensei profiles is a smart way to generate combinations of variables for your simulated user goals without exploding the total number of conversations.

### What does `pairwise()` do?

Imagine you have multiple variables, each with several possible values. Instead of testing **every possible combination** (which can be huge!), `pairwise()` ensures that **every pair of variable values appears at least once** across your generated conversations.

### Why is this useful?

- It drastically reduces the number of test cases compared to full Cartesian product.
- Still covers all pairs of variable values, which catches most interaction bugs.
- Efficiently balances coverage and cost.

### Simple example

Suppose you have two variables:

```yaml
- color:
    function: pairwise()
    type: string
    data: [red, green, blue]
- size:
    function: pairwise()
    type: string
    data: [small, medium, large]
```

Instead of generating 3×3=9 conversations for all combinations, `pairwise()` will generate a smaller set (like 4 or 5) where every color-size pair appears at least once.

### How to use it?

- Apply `pairwise()` to **two or more variables** in your `user.goals`.
- Sensei will generate the minimal set of conversations covering all pairs.
- You can combine it with other functions like `forward()` or `random()` for more control.
