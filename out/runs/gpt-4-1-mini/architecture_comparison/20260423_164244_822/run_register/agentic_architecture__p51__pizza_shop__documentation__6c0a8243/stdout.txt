Connectors in Chatbot Dojo are used to connect your chatbot testing setup to any external chatbot API without writing code. They act as a transport layer that sends user messages to the chatbot API and receives the chatbot's replies.

### What connectors are used for:
- Define how to communicate with a chatbot API via HTTP.
- Specify the API endpoint, HTTP method, headers (like authentication), and the message payload.
- Extract the chatbot's reply from the JSON response using a path expression.
- Enable testing of real chatbot APIs seamlessly by describing the API interaction in YAML.

### Key fields in a connector YAML configuration:
| Field                     | Description                                                  | Required          |
|---------------------------|--------------------------------------------------------------|-------------------|
| `name`                    | Friendly name for your chatbot                                | No                |
| `base_url`                | Base URL of the chatbot API                                   | Yes               |
| `send_message.path`       | API endpoint path appended to the base_url                   | Yes               |
| `send_message.method`     | HTTP method (POST, GET, PUT, DELETE)                         | No (default: POST)|
| `send_message.headers`    | Custom HTTP headers (e.g., Authorization tokens)             | No                |
| `send_message.payload_template` | JSON structure with `{user_msg}` placeholder for user input | Yes               |
| `response_path`           | Dot-separated path to extract the chatbot's reply from JSON  | Yes               |

### How it works:
- The connector sends the user message (replacing `{user_msg}` in the payload) to the API endpoint.
- It receives a JSON response.
- It extracts the chatbot's reply using the `response_path` field, which navigates the JSON response using dot notation (e.g., `"response.text"` or `"data.messages.0.content"`).
