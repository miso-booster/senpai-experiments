Got it! Here's a Sensei-check rule that checks if the chatbot outputs for the Ada UAM profile include non-empty values for `contact_email`, `contact_phone`, and `physical_address` — ensuring the CAU contact info is fully provided:

```yaml
name: cau_contact_info_complete
description: The chatbot provides all necessary CAU contact info: email, phone, and physical address
conversations: 1
active: true
oracle: |
  conv[0].contact_email is not None and conv[0].contact_email.strip() != "" and
  conv[0].contact_phone is not None and conv[0].contact_phone.strip() != "" and
  conv[0].physical_address is not None and conv[0].physical_address.strip() != ""
yields: |
  f"Missing CAU contact info: email='{conv[0].contact_email}', phone='{conv[0].contact_phone}', address='{conv[0].physical_address}'"
```
