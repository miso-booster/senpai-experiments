¡Claro! Aquí tienes un perfil Sensei para probar un chatbot de pizzería que simula un usuario haciendo un pedido. El perfil incluye variables para tipo de pizza y bebida, y en el `chatbot.output` define los campos que quieres extraer: tipo de pizza, bebida, id del pedido y precio final en dólares.

```yaml
test_name: "pizza_order_basic_test"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "A customer ordering a pizza and a drink from a pizzeria."
  context:
    - "You want to order a pizza and a drink."
  goals:
    - "I want to order a {{pizza_type}} pizza."
    - "I would like a {{drink}} to go with it."
    - pizza_type:
        function: random()
        type: string
        data: [Margherita, Pepperoni, Vegetarian, Hawaiian, Four cheese]
    - drink:
        function: random()
        type: string
        data: [Coke, Sprite, Water, Iced Tea]

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand. Could you please repeat your order?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered."
    - drink:
        type: string
        description: "The drink ordered."
    - order_id:
        type: string
        description: "Unique identifier for the order."
    - final_price:
        type: money
        description: "Final price of the order in USD."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```

Este perfil simula 3 conversaciones donde el usuario pide una pizza y una bebida, y espera que el chatbot entregue en su output los campos indicados para validar con reglas después.
