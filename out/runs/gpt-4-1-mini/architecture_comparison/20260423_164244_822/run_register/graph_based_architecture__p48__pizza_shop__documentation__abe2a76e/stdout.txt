Hey! Great question about SENSEI Profiles 😊.

In a SENSEI Profile YAML, some fields are essential, while others are optional depending on your needs. Here's a quick rundown of the **non-mandatory fields** in a profile:

### Non-mandatory fields in a SENSEI Profile

- **`llm` section**  
  - You *can* omit this. If you do, defaults are applied (like default model, temperature, and text format).  
  - Use it only if you want to override defaults or specify speech format.

- **`user.context`**  
  - Optional list of extra context or personality YAML references.  
  - Useful for adding personality prompts or constraints but not strictly required.

- **`chatbot.is_starter`**  
  - Optional boolean indicating if the chatbot starts the conversation.  
  - Defaults to false if omitted.

- **`chatbot.fallback`**  
  - Optional fallback message string your bot uses when it doesn't understand.  
  - Helps avoid endless loops but not mandatory.

- **`chatbot.output`**  
  - This is optional in the sense that you can have a profile without specifying extracted outputs, but if you want to write Sensei-check rules that inspect outputs, you should define it.  
  - If you don't need structured outputs or rules, you can skip it.

- **`conversation.max_cost`**  
  - Optional cost cap for the entire run.

- **`conversation.goal_style.max_cost`**  
  - Optional cost cap per conversation.

- **`conversation.interaction_style`**  
  - Optional list of interaction styles (like "long phrases", "make spelling mistakes").  
  - Defaults to a natural style if omitted.

- **`conversation.number`**  
  - You can specify a fixed number or combinations; if omitted, defaults apply (usually 1).

---

### Summary

The **only truly mandatory fields** are:

- `test_name` (or `name`): to identify the profile.
- `user.language` and `user.role`: to define the simulated user.
- `user.goals`: what the user tries to achieve.
- `conversation.number` (or default).
- `chatbot` section with at least minimal config (even empty).

Everything else is optional and depends on your testing scenario.
