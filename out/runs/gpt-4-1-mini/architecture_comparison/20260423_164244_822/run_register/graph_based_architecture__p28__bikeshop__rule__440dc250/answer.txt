Absolutely! To ensure your chatbot responds in the same language as the user, you can create a **Sensei-check metamorphic rule** that verifies language consistency across conversations.

Here’s a simple example rule that checks if the assistant replies in the same language as the user, using the built-in helper `responds_in_same_language()`:

```yaml
name: language_consistency
description: Assistant replies in the same language as the user
conversations: 1
oracle: responds_in_same_language() is True
```

### Explanation:
- `conversations: 1` means this rule checks each conversation individually.
- The helper `responds_in_same_language()` returns `True` if the assistant’s replies match the user’s language.
- The `oracle` asserts this condition must hold.

If you want a **metamorphic rule** comparing two conversations for language consistency (e.g., different inputs but same language expected), you can do something like:

```yaml
name: language_consistency_across_variations
description: Comparable conversations respond in the same language
conversations: 2
when: conv[0].some_input_field == conv[1].some_input_field  # adjust to your profile fields
oracle: language(conv[0].chatbot_phrases) == language(conv[1].chatbot_phrases)
```

But usually, the single-conversation rule above is enough to ensure language alignment.
