Here is a general Sensei-check rule that is profile-agnostic and checks if the chatbot provides information about current promotions. It uses the helper `chatbot_returns` to look for keywords like "promotion", "discount", or "offer" in the assistant's replies. This rule does not depend on any profile outputs:

```yaml
name: chatbot_mentions_promotions
description: Checks if the chatbot provides information about current promotions or discounts
conversations: 1
active: true
oracle: chatbot_returns('promotion') or chatbot_returns('discount') or chatbot_returns('offer')
yields: "The chatbot did not mention any current promotions, discounts, or offers."
```

- This rule runs on single conversations.
- It uses `chatbot_returns` helper to detect if the assistant mentions promotions.
- It is general and does not require any specific profile.
