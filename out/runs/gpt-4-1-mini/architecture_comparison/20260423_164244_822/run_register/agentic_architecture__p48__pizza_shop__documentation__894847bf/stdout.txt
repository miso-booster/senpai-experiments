In a Sensei profile, the following fields are generally considered mandatory or essential for the profile to function, while others are optional:

### Typically Mandatory or Important Fields
- `test_name`: A string identifying the profile/test.
- `user.language`: The language of the simulated user.
- `user.role`: Describes the simulated user's role or persona.
- `user.goals`: The goals the simulated user tries to achieve, including any variables.
- `chatbot.is_starter`: Boolean indicating if the chatbot starts the conversation.
- `chatbot.fallback`: The fallback message the bot uses when it doesn't understand.
- `chatbot.output`: Defines the schema of fields to extract from the chatbot's responses.
- `conversation.number`: Number of conversations or combination matrix to run.
- `conversation.goal_style`: How the conversation ends (e.g., fixed steps).
- `conversation.interaction_style`: Styles that affect how the simulated user interacts.

### Optional Fields
- `llm`: Language model settings like temperature, model name, and format. If omitted, defaults are applied.
- `user.context`: List of optional personality YAML references or freeform constraints/preferences.
- `conversation.max_cost`: Cap on total spend for the whole run.
- `conversation.goal_style.max_cost`: Per-conversation cost cap.
- `conversation.goal_style.all_answered.export` and `limit`: For exporting verification data and safety limits.
- `conversation.interaction_style` can be omitted or customized with various styles.
- Custom data types in `user.goals` or `chatbot.output` are optional but useful for structured data.

### Summary
The profile must minimally define the user language, role, goals, chatbot output fields, and conversation controls to run properly. Other fields like `llm`, `context`, and cost caps are optional and used for fine-tuning or advanced scenarios.
