Since you want a global rule (not tied to any profile), we can use the helper `utterance_index` to check if the assistant says something about "promotion" or related keywords anywhere in the conversation.

Here’s a simple rule you can use:

```yaml
name: promotion_mentioned
description: Checks if the assistant mentions current promotions in the conversation
conversations: 1
oracle: utterance_index('assistant', 'promotion') > 0 or utterance_index('assistant', 'discount') > 0 or utterance_index('assistant', 'offer') > 0
```

### Explanation:
- `utterance_index('assistant', 'promotion') > 0` means the assistant said something containing "promotion" at some turn.
- I added "discount" and "offer" as related keywords to catch variations.
- This rule applies to single conversations (`conversations: 1`).
- It’s profile-agnostic, so no dependency on `chatbot.output`.
