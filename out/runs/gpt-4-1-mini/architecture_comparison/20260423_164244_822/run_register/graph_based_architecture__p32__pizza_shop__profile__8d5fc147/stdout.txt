¡Claro! 😊 Aquí tienes un perfil básico para probar un chatbot de pizzería que extrae el tipo de pizza, la bebida, el ID del pedido y el precio final en dólares. Está listo para que lo uses o adaptes según tus necesidades.

```yaml
test_name: "pizza_order_basic_test"

llm:
  temperature: 0.7
  model: gpt-4o-mini
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: >
    You are a customer placing an order at a pizzeria.
    You want to order a pizza and a drink, then confirm the order details.
  context:
    - "You like simple and clear communication."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Order a {{drink_type}} to drink."
    - pizza_type:
        function: forward()
        type: string
        data: [Margherita, Pepperoni, Hawaiian, Vegetarian, BBQ Chicken]
    - drink_type:
        function: forward()
        type: string
        data: [Coke, Sprite, Water, Fanta]

chatbot:
  is_starter: false
  fallback: "I'm sorry, I didn't get that. Could you please repeat your order?"
  output:
    - pizza_type:
        type: string
        description: "The type of pizza ordered"
    - drink_type:
        type: string
        description: "The drink ordered"
    - order_id:
        type: string
        description: "The unique order identifier"
    - total_price:
        type: money
        description: "The final price of the order in dollars"

conversation:
  number: 3
  goal_style:
    steps: 4
  interaction_style:
    - single questions
```

---

### Explicación rápida:
- `user.goals` define que el usuario pedirá un tipo de pizza y una bebida, con listas simples para cada variable.
- `chatbot.output` define los campos que quieres extraer: tipo de pizza, bebida, ID del pedido y precio total en dólares (`money`).
- La conversación tendrá 3 iteraciones con 4 pasos máximo para cada una.
- El estilo de interacción es con preguntas simples para que sea claro y directo.

Si quieres, puedo ayudarte a personalizarlo más o agregar estilos de interacción diferentes. ¿Quieres? 🍕🥤
