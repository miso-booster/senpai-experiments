Now, here is a complete Python script to send multiple requests to this connector using the `CustomChatbot` class from the connector docs:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Load the connector YAML config file (save the above YAML as '1millionbot.yaml')
    bot = CustomChatbot("1millionbot.yaml")

    # Messages to send
    messages = [
        "hola",
        "¿Cómo estás?",
        "¿Puedes ayudarme con mi cuenta?",
        "Gracias por tu ayuda"
    ]

    for msg in messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}")
        else:
            print(f"Failed to get response for message: {msg}")

if __name__ == "__main__":
    main()
```
