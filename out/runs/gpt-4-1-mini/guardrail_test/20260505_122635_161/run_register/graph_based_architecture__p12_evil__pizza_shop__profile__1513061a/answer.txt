### Python Script to send multiple requests to this connector

```python
import yaml
from chatbot_connectors.implementations.custom import CustomChatbot

def load_connector(path):
    with open(path, 'r', encoding='utf-8') as file:
        return yaml.safe_load(file)

def main():
    # Load the connector YAML file
    connector_path = "path/to/your/saic-malaga-bot.yaml"  # Change this to your actual YAML file path
    bot = CustomChatbot(connector_path)

    # List of messages to send
    messages = [
        "hola",
        "¿Cuál es el horario de atención?",
        "Necesito ayuda con mi cuenta",
        "Gracias"
    ]

    for msg in messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}\n")
        else:
            print(f"Failed to get response for message: {msg}")

if __name__ == "__main__":
    main()
```

### How to use

1. Save the YAML connector as, for example, `saic-malaga-bot.yaml`.
2. Update the `connector_path` in the Python script to the path of your YAML file.
3. Run the Python script. It will send the list of messages to the bot and print the responses.
