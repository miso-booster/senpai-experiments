I have reviewed the SENSEI profile structure and the relationship with rules from the documentation (`sensei-chat-guide.md` and `sensei-check-doc.md`). Here's a summary of the key points for the automation:

- A SENSEI profile is a YAML file defining:
  - `test_name`
  - `llm` settings (temperature, model, format)
  - `user` section (language, role, context, goals with variables and data functions)
  - `chatbot` section (starter flag, fallback message, and `output` fields schema)
  - `conversation` controls (number, goal_style, interaction_style)

- The `chatbot.output` defines the schema of extracted fields that rules will validate.

- Variables in `user.goals` must match exactly the placeholders used in goal strings.

- Data for variables can be explicit lists, ranges, or LLM-generated lists.

- Conversation controls and interaction styles influence the simulation.
