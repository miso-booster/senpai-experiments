### How to automate Sensei profile creation with LLMs in Python

#### 1. **Define the profile schema and template**

You want your LLM to generate YAML files matching Sensei's profile structure. So first, prepare a **template** or a **schema** that the LLM can follow. For example, you can prompt the LLM with a detailed example profile (like the one in the docs) and ask it to fill in variables.

#### 2. **Prepare the prompt for the LLM**

Your prompt should clearly describe:

- The purpose of the profile (e.g., pizza ordering user).
- The required fields (test_name, llm, user, chatbot, conversation).
- The variables and goals.
- Output fields expected from the chatbot.

Example prompt snippet:

```yaml
test_name: "pizza_order_automation"

user:
  language: English
  role: "A customer placing an order for pizza and drinks."
  goals:
    - "Order a {{pizza_type}} pizza."
    - "Select the size {{pizza_size}} for the pizza."
    - "Order a {{drink_type}} to drink."
    - pizza_type:
        function: forward()
        type: string
        data: [Margherita, Pepperoni, Vegetarian, Hawaiian]
    - pizza_size:
        function: forward()
        type: string
        data: [small, medium, large]
    - drink_type:
        function: forward()
        type: string
        data: [Coke, Sprite, Water]

chatbot:
  fallback: "I'm sorry, I did not get what you said. Can you please repeat?"
  output:
    - order_id:
        type: string
        description: "Unique identifier for the order"
    - total_cost:
        type: money
        description: "Total cost of the order including pizza and drinks"

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - default
```

#### 3. **Use Python to call the LLM API**

You can use OpenAI's Python SDK or any other LLM provider. Here’s a simplified example using OpenAI's GPT:

```python
import openai

openai.api_key = "your_api_key"

def generate_sensei_profile(prompt):
    response = openai.ChatCompletion.create(
        model="gpt-4o-mini",
        messages=[
            {"role": "system", "content": "You are an expert in creating Sensei profiles for chatbot testing."},
            {"role": "user", "content": prompt}
        ],
        temperature=0.7,
        max_tokens=800,
    )
    return response['choices'][0]['message']['content']

prompt = """
Create a Sensei profile YAML for a user ordering pizza. The profile should include:
- test_name: "pizza_order_automation"
- user role and language
- goals with variables like pizza_type, pizza_size, drink_type
- chatbot output fields like order_id, total_cost
- conversation settings with 3 conversations, 5 steps each
Use the Sensei profile YAML format.
"""

profile_yaml = generate_sensei_profile(prompt)
print(profile_yaml)
```

#### 4. **Validate the generated profile**

After generation, you should validate the YAML structure and that it meets Sensei's requirements. You can:

- Use a YAML parser (like PyYAML) to check syntax.
- Optionally, run Sensei's validation tool (`validation_check.py`) on the generated YAML.

#### 5. **Save the profile to a file**

```python
with open("profiles/generated_pizza_order_profile.yml", "w") as f:
    f.write(profile_yaml)
```

### Tips for better automation

- **Use few-shot prompting**: Provide a couple of example profiles in your prompt so the LLM learns the structure.
- **Control randomness**: Use temperature ~0.3-0.7 to balance creativity and correctness.
- **Iterate and refine**: If the profile is invalid, ask the LLM to fix errors or regenerate.
- **Add custom types or personalities** as needed by extending the prompt.
