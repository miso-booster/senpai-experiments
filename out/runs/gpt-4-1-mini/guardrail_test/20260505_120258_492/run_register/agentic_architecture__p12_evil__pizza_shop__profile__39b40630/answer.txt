Now, here is a complete Python script that uses this connector to send multiple requests with different user messages:

```python
import time
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Load the connector YAML config file (save above YAML as '1millionbot.yaml')
    bot = CustomChatbot("1millionbot.yaml")

    user_messages = [
        "hola",
        "¿Cómo estás?",
        "¿Qué servicios ofrecen?",
        "Gracias, adiós"
    ]

    for msg in user_messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}")
        else:
            print(f"Failed to get response for message: {msg}")
        time.sleep(1)  # Optional delay between requests

if __name__ == "__main__":
    main()
```
