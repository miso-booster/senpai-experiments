Here's a complete Python script to send multiple requests to the connector using the `CustomChatbot` class from the connector implementation:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Path to the YAML connector file
    connector_path = "1millionbot_connector.yaml"

    # Create the chatbot instance from the YAML connector
    bot = CustomChatbot(connector_path)

    # List of messages to send
    messages = [
        "hola",
        "¿Cómo estás?",
        "¿Qué puedes hacer?",
        "Gracias",
        "Adiós"
    ]

    for msg in messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}")
            print("-" * 40)
        else:
            print(f"Failed to get response for message: {msg}")

if __name__ == "__main__":
    main()
```

This script:
- Loads the connector YAML file (you should save the YAML I provided earlier as `1millionbot_connector.yaml`).
- Sends multiple user messages to the bot.
- Prints the bot's responses.
