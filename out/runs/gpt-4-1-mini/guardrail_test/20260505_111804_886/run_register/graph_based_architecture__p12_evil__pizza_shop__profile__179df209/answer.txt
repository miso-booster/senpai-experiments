### Now, here is a complete Python script to send multiple requests to this connector:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Load the connector YAML file (adjust path if needed)
    connector_path = "path/to/your/saic-malaga-bot.yml"
    bot = CustomChatbot(connector_path)

    # List of messages to send
    messages = [
        "hola",
        "¿Cómo estás?",
        "¿Qué servicios ofrecen?",
        "Gracias"
    ]

    for msg in messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}\n")
        else:
            print(f"Failed to get response for message: {msg}")

if __name__ == "__main__":
    main()
```

### How to use:

1. Save the YAML connector as `saic-malaga-bot.yml` (or any name you like).
2. Adjust the `connector_path` in the Python script to point to your YAML file.
3. Run the Python script. It will send each message and print the bot's reply.
