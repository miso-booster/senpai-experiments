Here's a complete Python script to send multiple requests to the connector using the `CustomChatbot` class from the connector docs:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Load the connector YAML config file
    bot = CustomChatbot("path/to/your/1millionbot_connector.yaml")

    # List of messages to send
    messages = [
        "hola",
        "¿Cómo estás?",
        "¿Qué puedes hacer?",
        "Gracias",
        "Adiós"
    ]

    for msg in messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}")
            print("-" * 40)
        else:
            print(f"Failed to get response for message: {msg}")

if __name__ == "__main__":
    main()
```

Replace `"path/to/your/1millionbot_connector.yaml"` with the actual path to the YAML connector file you created.

This script initializes the connector, sends multiple user messages, and prints out the bot's responses.
