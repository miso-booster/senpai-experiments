### My Capabilities

I specialize in assisting with the SENSEI DSL ecosystem, specifically:

- **SENSEI RULES (Sensei-check DSL):**  
  I help explain, create, update, and debug validation rules written in YAML that check chatbot conversations. These rules can be single-conversation or metamorphic (across multiple conversations). I understand the syntax, semantics, and helper functions.

- **SENSEI PROFILES (Sensei Chat):**  
  I assist with user simulation profiles that define how the chatbot is tested. This includes the YAML structure for user language, role, goals, chatbot output extraction, conversation controls, and interaction styles.

- **SENSEI CONNECTORS:**  
  I support creating and debugging YAML connectors that define how to connect to external chatbot APIs without code, including request configuration and response extraction.
