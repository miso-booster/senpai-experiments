### Minimal Sensei Profile Template for LLM Generation

Here’s a minimal profile example you can use as a prompt or template for your automation:

```yaml
test_name: "auto_generated_profile"

llm:
  temperature: 0.7
  model: gpt-4o
  model_prov: openai
  format:
    type: text

user:
  language: English
  role: "Simulated user interested in ordering a pizza with custom toppings."
  context:
    - "The user prefers vegetarian options."
  goals:
    - "Order a {{size}} pizza with {{toppings}}."
    - size:
        function: random()
        type: string
        data: [small, medium, large]
    - toppings:
        function: random()
        type: string
        data: [mushrooms, olives, peppers, onions, tomatoes]

chatbot:
  is_starter: false
  fallback: "Sorry, I didn't understand. Can you please rephrase?"
  output:
    - price:
        type: currency
        description: "Final price of the pizza order."
    - estimated_time:
        type: time("hh:mm")
        description: "Estimated preparation time."
    - order_id:
        type: string
        description: "Unique order identifier."

conversation:
  number: 3
  goal_style:
    steps: 5
  interaction_style:
    - single questions
```
