Here's a complete Python script to send multiple requests to the connector using the `CustomChatbot` class from the Chatbot Dojo framework:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Path to the YAML connector file you created
    connector_yaml_path = "path/to/your/1millionbot_connector.yaml"

    # Create the chatbot instance from the YAML connector
    bot = CustomChatbot(connector_yaml_path)

    # List of user messages to send
    user_messages = [
        "hola",
        "¿Cómo estás?",
        "¿Puedes ayudarme con mi cuenta?",
        "Gracias"
    ]

    # Send each message and print the bot's response
    for msg in user_messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}")
            print("-" * 40)
        else:
            print(f"Failed to get response for message: {msg}")

if __name__ == "__main__":
    main()
```

### How to use:
- Save your YAML connector as e.g. `1millionbot_connector.yaml`.
- Update the `connector_yaml_path` variable in the script with the correct path to that YAML file.
- Run the script. It will send the list of messages to the chatbot and print the responses.

This script uses the documented `CustomChatbot` class to load your YAML connector and send messages dynamically, printing out the chatbot's replies.
