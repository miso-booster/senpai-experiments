### Python script to send multiple requests using this connector

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Load your connector YAML file path here
    connector_path = "path/to/your/saic-malaga-bot.yaml"  # Update with your actual path

    bot = CustomChatbot(connector_path)

    # List of messages to send
    messages = [
        "hola",
        "¿Cómo estás?",
        "¿Qué servicios ofrecen?",
        "Gracias por la ayuda",
        "Adiós"
    ]

    for msg in messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}\n")
        else:
            print(f"Failed to get response for message: {msg}")

if __name__ == "__main__":
    main()
```

### How to use:

1. Save the YAML connector content in a file, for example, `saic-malaga-bot.yaml`.
2. Update the `connector_path` in the Python script to point to that YAML file.
3. Run the Python script. It will send the list of messages and print the bot's responses.
