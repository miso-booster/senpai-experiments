And here is a complete Python script to send multiple requests using this connector configuration (assuming you have the connector YAML saved as `connectors/saic_malaga.yaml` and the `CustomChatbot` class available):

```python
import time
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Load the connector config
    connector_path = "connectors/saic_malaga.yaml"
    bot = CustomChatbot(connector_path)

    user_messages = [
        "hola",
        "¿Cuál es el horario de atención?",
        "¿Pueden ayudarme con un problema técnico?",
        "Gracias, eso es todo."
    ]

    for msg in user_messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}\n")
        else:
            print(f"Failed to get response for message: {msg}\n")
        time.sleep(1)  # polite delay between requests

if __name__ == "__main__":
    main()
```

This script loads the connector, sends multiple user messages, and prints the chatbot's responses. The `{user_msg}` placeholder in the YAML payload is replaced by each message in the list. The response is extracted from the JSON path `response.0.text` as specified. Let me know if you want me to help with anything else! 😊
