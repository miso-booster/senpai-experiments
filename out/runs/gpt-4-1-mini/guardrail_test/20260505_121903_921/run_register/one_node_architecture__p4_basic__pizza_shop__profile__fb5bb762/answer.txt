### Example Sensei Profile YAML Template

```yaml
test_name: "{{ test_name }}"

llm:
  temperature: {{ temperature }}
  model: "{{ model }}"
  model_prov: "{{ model_provider }}"
  format:
    type: text

user:
  language: "{{ user_language }}"
  role: "{{ user_role }}"
  context:
    - "{{ user_context }}"
  goals:
    {% for goal in user_goals %}
    - "{{ goal }}"
    {% endfor %}
  # Variables for goals
  {% for var_name, var_data in variables.items() %}
  - {{ var_name }}:
      function: {{ var_data.function }}
      type: {{ var_data.type }}
      data: {{ var_data.data }}
  {% endfor %}

chatbot:
  is_starter: false
  fallback: "{{ chatbot_fallback }}"
  output:
    {% for output_field, output_info in chatbot_output.items() %}
    - {{ output_field }}:
        type: {{ output_info.type }}
        description: "{{ output_info.description }}"
    {% endfor %}

conversation:
  number: {{ conversation_number }}
  goal_style:
    steps: {{ goal_steps }}
  interaction_style:
    {% for style in interaction_styles %}
    - {{ style }}
    {% endfor %}
```

### How to Automate Profile Creation with Python + LLM

You can use an LLM (like OpenAI GPT) to generate the values for the placeholders above, then render this template to YAML.

Here's a simple example using Python with the `jinja2` templating library and OpenAI's API (you can adapt to other LLMs):

```python
import openai
from jinja2 import Template

openai.api_key = "YOUR_OPENAI_API_KEY"

# Define the profile template as a string (like above)
profile_template_str = """
test_name: "{{ test_name }}"

llm:
  temperature: {{ temperature }}
  model: "{{ model }}"
  model_prov: "{{ model_provider }}"
  format:
    type: text

user:
  language: "{{ user_language }}"
  role: "{{ user_role }}"
  context:
    - "{{ user_context }}"
  goals:
    {% for goal in user_goals %}
    - "{{ goal }}"
    {% endfor %}
  {% for var_name, var_data in variables.items() %}
  - {{ var_name }}:
      function: {{ var_data.function }}
      type: {{ var_data.type }}
      data: {{ var_data.data }}
  {% endfor %}

chatbot:
  is_starter: false
  fallback: "{{ chatbot_fallback }}"
  output:
    {% for output_field, output_info in chatbot_output.items() %}
    - {{ output_field }}:
        type: {{ output_info.type }}
        description: "{{ output_info.description }}"
    {% endfor %}

conversation:
  number: {{ conversation_number }}
  goal_style:
    steps: {{ goal_steps }}
  interaction_style:
    {% for style in interaction_styles %}
    - {{ style }}
    {% endfor %}
"""

def generate_profile_data(prompt):
    response = openai.ChatCompletion.create(
        model="gpt-4o-mini",
        messages=[{"role": "system", "content": "Generate a JSON with keys: test_name, temperature, model, model_provider, user_language, user_role, user_context, user_goals, variables, chatbot_fallback, chatbot_output, conversation_number, goal_steps, interaction_styles."},
                  {"role": "user", "content": prompt}],
        temperature=0.7,
        max_tokens=500,
    )
    content = response.choices[0].message.content
    # Parse the JSON output from the LLM (you may want to add error handling)
    import json
    data = json.loads(content)
    return data

def render_profile(data):
    template = Template(profile_template_str)
    return template.render(**data)

if __name__ == "__main__":
    prompt = "Create a Sensei profile for a pizza ordering chatbot user simulation."
    profile_data = generate_profile_data(prompt)
    profile_yaml = render_profile(profile_data)
    print(profile_yaml)
```

---

### What this does:

- You ask the LLM to generate structured JSON data describing the profile.
- You render that data into a valid Sensei profile YAML using a Jinja2 template.
- You get a ready-to-use Sensei profile YAML you can save and run.
