Here is a complete Python script that uses the created YAML connector to send multiple requests with different messages:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Load the connector YAML config file
    bot = CustomChatbot("path/to/your/1millionbot-connector.yaml")

    # List of messages to send
    messages = [
        "hola",
        "¿Cómo estás?",
        "¿Qué puedes hacer?",
        "Dime un chiste",
        "Gracias"
    ]

    for msg in messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}")
        else:
            print(f"Failed to get response for message: {msg}")

if __name__ == "__main__":
    main()
```

Make sure to save the YAML connector as e.g. `1millionbot-connector.yaml` and update the path in the script accordingly.
