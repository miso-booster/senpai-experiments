### Python Script to Send Multiple Requests

This script uses the `CustomChatbot` class from the connector system to load the YAML and send multiple messages.

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Load your connector YAML file (adjust the path as needed)
    connector_path = "path/to/your/saic-malaga-bot.yaml"
    bot = CustomChatbot(connector_path)

    # List of messages to send
    messages = [
        "hola",
        "¿Cuál es el horario de atención?",
        "¿Cómo puedo contactar con soporte?",
        "Gracias por la ayuda"
    ]

    for msg in messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}\n")
        else:
            print(f"Failed to get response for message: {msg}")

if __name__ == "__main__":
    main()
```
