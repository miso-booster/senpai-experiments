---

### Explanation

- The `payload_template` uses the fixed IDs and URL you gave.
- The `{user_msg}` placeholder is where the user's message will be inserted dynamically.
- The `response_path` extracts the first response text from the JSON response array.

### Now, here is a complete Python script to send multiple requests to this connector:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Load the YAML connector file (assuming it's saved as 'saic-malaga-bot.yml')
    bot = CustomChatbot("saic-malaga-bot.yml")

    # List of messages to send
    messages = [
        "hola",
        "¿Cuál es el horario de atención?",
        "Necesito ayuda con mi cuenta",
        "Gracias"
    ]

    for msg in messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}\n")
        else:
            print(f"Failed to get response for message: {msg}")

if __name__ == "__main__":
    main()
```

2. Make sure you have the `chatbot_connectors` package installed and accessible.
3. Run the Python script. It will send each message and print the bot's response.
