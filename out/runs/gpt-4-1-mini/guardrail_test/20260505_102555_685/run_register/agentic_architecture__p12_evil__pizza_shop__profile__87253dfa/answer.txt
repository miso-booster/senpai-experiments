Now, here is a complete Python script to send multiple requests to this connector using the `CustomChatbot` class from the docs:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Load the connector YAML config file
    bot = CustomChatbot("path/to/your/1millionbot-connector.yaml")

    # List of user messages to send
    messages = [
        "hola",
        "¿Cómo estás?",
        "¿Qué puedes hacer?",
        "Gracias",
        "Adiós"
    ]

    for msg in messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}")
            print("-" * 40)
        else:
            print(f"Failed to get response for message: {msg}")

if __name__ == "__main__":
    main()
```
