Here's a complete Python script to send multiple requests to the connector using the `CustomChatbot` class from the Chatbot Dojo connector implementation:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Path to the YAML connector file
    connector_yaml = "1millionbot_connector.yaml"

    # Create the chatbot instance
    bot = CustomChatbot(connector_yaml)

    # List of user messages to send
    user_messages = [
        "hola",
        "¿Cómo estás?",
        "¿Puedes ayudarme con mi cuenta?",
        "Gracias",
        "Adiós"
    ]

    # Send each message and print the response
    for msg in user_messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}")
            print("-" * 40)
        else:
            print(f"Failed to get response for message: {msg}")

if __name__ == "__main__":
    main()
```

### How to use:
1. Save the YAML connector I provided earlier as `1millionbot_connector.yaml`.
2. Run this Python script in the same directory or adjust the path accordingly.
3. The script sends multiple messages to the bot and prints the bot's replies.
