Now, here is a complete Python script that uses this connector to send multiple messages to the bot:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Load the connector YAML file (assuming saved as '1millionbot_connector.yml')
    bot = CustomChatbot("1millionbot_connector.yml")
    
    messages = [
        "hola",
        "¿Cómo estás?",
        "¿Qué puedes hacer?",
        "Gracias, adiós"
    ]
    
    for msg in messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}")
        else:
            print(f"Failed to get response for message: {msg}")

if __name__ == "__main__":
    main()
```
