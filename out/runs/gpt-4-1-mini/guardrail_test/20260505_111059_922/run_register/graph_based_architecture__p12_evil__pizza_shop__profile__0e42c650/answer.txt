### Explanation

- The `payload_template` uses your provided fixed IDs and URLs.
- `{user_msg}` is the placeholder for the user's input message.
- The `response_path` extracts the bot's reply text from the JSON response at `response[0].text`.
- All headers from your request are included for completeness.

### Python script to send multiple requests using this connector

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Path to the YAML connector file you saved, e.g., "saic-malaga-bot.yml"
    connector_path = "saic-malaga-bot.yml"
    
    # Initialize the chatbot connector
    bot = CustomChatbot(connector_path)
    
    # List of messages to send
    messages = [
        "hola",
        "¿Cuál es el horario de atención?",
        "Necesito ayuda con mi cuenta",
        "Gracias"
    ]
    
    for msg in messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}\n")
        else:
            print(f"Failed to get response for message: {msg}")

if __name__ == "__main__":
    main()
```
