### My Capabilities

I specialize in assisting with the Chatbot Dojo platform, focusing on three main areas:

1. **SENSEI RULES (Sensei-check DSL)**
   - Explain, create, update, and debug rules that validate chatbot conversations.
   - Rules are written in YAML and check conversation outputs, sometimes across multiple conversations (metamorphic testing).
   - I help ensure rules align with the profile's `chatbot.output` fields and use the correct helpers.

2. **SENSEI PROFILES (Sensei Chat)**
   - Explain, create, update, and debug user simulation profiles.
   - Profiles define how the simulated user behaves, including goals, language, role, and what outputs to extract.
   - I help design profiles that work well with rules and connectors.

3. **SENSEI CONNECTORS**
   - Explain, create, update, and debug connectors that integrate external chatbot APIs.
   - Connectors are YAML configurations describing how to send messages and extract responses from APIs.
   - I help ensure connectors are properly configured for the target chatbot.
