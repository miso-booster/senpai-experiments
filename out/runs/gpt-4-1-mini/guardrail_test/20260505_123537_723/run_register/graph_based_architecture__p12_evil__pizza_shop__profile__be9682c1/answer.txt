### Explanation:

### Now, here is a complete Python script to send multiple messages to this connector:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Path to your YAML connector file
    connector_path = "path/to/your/saic-malaga-bot.yaml"

    # Initialize the chatbot connector
    bot = CustomChatbot(connector_path)

    # List of messages to send
    messages = [
        "hola",
        "¿Cuál es el horario de atención?",
        "Necesito ayuda con mi cuenta",
        "Gracias"
    ]

    for msg in messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}\n")
        else:
            print(f"Failed to get response for message: {msg}")

if __name__ == "__main__":
    main()
```

### How to use:
1. Save the YAML connector as, for example, `saic-malaga-bot.yaml`.
2. Adjust the `connector_path` in the Python script to point to that file.
3. Run the Python script. It will send each message and print the bot's reply.
