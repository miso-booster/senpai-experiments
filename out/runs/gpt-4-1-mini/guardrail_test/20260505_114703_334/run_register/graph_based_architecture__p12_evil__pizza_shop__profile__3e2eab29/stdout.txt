### Python script to send multiple requests using this connector

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Initialize the chatbot with the YAML connector file path
    bot = CustomChatbot("path/to/your/saic-malaga-bot.yaml")

    # List of messages to send
    messages = [
        "hola",
        "¿Cómo estás?",
        "¿Qué servicios ofrecen?",
        "Gracias"
    ]

    for msg in messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}\n")
        else:
            print(f"Failed to get response for message: {msg}")

if __name__ == "__main__":
    main()
```

---

### Notes:
- Replace `"path/to/your/saic-malaga-bot.yaml"` with the actual path where you save the YAML connector.
- This script sends four example messages to the bot and prints the responses.
- The `CustomChatbot` class is from the SENSEI Connectors framework and uses the YAML config to handle requests.
