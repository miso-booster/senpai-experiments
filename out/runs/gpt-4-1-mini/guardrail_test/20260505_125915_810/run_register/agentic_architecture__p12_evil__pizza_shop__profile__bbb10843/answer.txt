Here's a complete Python script to send multiple requests to the connector you requested. It uses the `CustomChatbot` class from the Chatbot Dojo connectors implementation:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Load the connector YAML config file (adjust path as needed)
    connector_path = "millionbot_custom_connector.yaml"
    bot = CustomChatbot(connector_path)

    # List of messages to send
    messages = [
        "hola",
        "¿Cómo estás?",
        "¿Qué puedes hacer?",
        "Dime un chiste",
        "Gracias"
    ]

    for msg in messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}\n")
        else:
            print(f"Failed to get response for message: {msg}")

if __name__ == "__main__":
    main()
```

### How to use:
1. Save the YAML connector I provided earlier as `millionbot_custom_connector.yaml` (or another filename you prefer).
2. Make sure you have the `chatbot_connectors` Python package installed and accessible.
3. Run this script. It will send each message in the `messages` list to the bot and print the bot's response.
