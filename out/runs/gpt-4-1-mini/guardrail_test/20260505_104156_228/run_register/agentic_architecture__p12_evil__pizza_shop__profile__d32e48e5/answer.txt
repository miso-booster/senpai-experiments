Here's a complete Python script that uses the custom YAML connector to send multiple requests with different user messages:

```python
from chatbot_connectors.implementations.custom import CustomChatbot

def main():
    # Load the connector YAML config file
    bot = CustomChatbot("1millionbot-connector.yaml")

    # List of user messages to send
    user_messages = [
        "hola",
        "¿Cómo estás?",
        "¿Puedes ayudarme con mi cuenta?",
        "Gracias por tu ayuda"
    ]

    # Send each message and print the bot's response
    for msg in user_messages:
        success, response = bot.execute_with_input(msg)
        if success:
            print(f"User: {msg}")
            print(f"Bot: {response}")
            print("-" * 40)
        else:
            print(f"Failed to get response for message: {msg}")

if __name__ == "__main__":
    main()
```

This script assumes you saved the YAML connector as `1millionbot-connector.yaml` in the current directory. It sends multiple user messages to the bot and prints the responses.
